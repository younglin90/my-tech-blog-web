# [16-11-21] 액주 분열 정리

> 원본: `multiphase/[16-11-21] 액주 분열 정리.hwp`

액주의 속도에 따른 분열 모드
A) Rayleigh breakup
  - 생성 액적 직경 > 제트 직경
  - 노즐로부터 멀리서 분열
B) First wind-induced regime
  - 생성 액적 직경 == 제트 직경
  - 조금 멀리서 분열
C) Second wind-induced regime
  - 생성 액적 직경 < 제트 직경
  - 노즐 끝과 가까운 지점에서 분열 시작
D) Atomization regime
  - 생성 액적 직경 << 제트 직경
  - 노즐 끝에서 바로 분열 시작
