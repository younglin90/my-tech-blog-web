## 슬라이드 19
4. Summary and Conclusions
균질 혼합 모델과 Eulerian To Lagrangian 모델을 이용한 분무해석을 수행함
개발한 모델을 jet in crossflow 의 실험결과와 비교검증 하였으며 편차내에서 일치함
수평분사의 경우 column breakup과 surface breakup이 동시에 나타나 액주를 분열시켜 가장 짧은 분열거리와 높은 분열특성을 가짐
정사각형 분사는 surface breakup이 낮은 강도로 발생함
수직분사의 경우 surface breakup만 발생하며 가장 긴 분열거리를 보임
SMD분포에는 surface breakup이 column breakup보다 더 큰 영향을 끼침
