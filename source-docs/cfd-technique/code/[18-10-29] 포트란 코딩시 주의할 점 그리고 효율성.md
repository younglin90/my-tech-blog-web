● 효율적인 포트란 코딩 [2]
1.  포트란의 array는 column-major 이기 때문에, column 순서로 소환 또는 저장을 해야된다. 그렇지 않으면 저장된 데이터를 찾기 위해 긴 시간이 필요하게 된다. 예를들어 다음과 같은 행렬이 있다.

  포트란은 , , ,  와 같은 순서로 저장되므로, 다음과 같은 do-loop 로 코딩을 해야만 효율성이 좋다.
    do j = 1, n
        do i = 1, n
            ! operate on A(i,j) ...
        end do
    end do
  또한 다음과 같이
   real, dimension(n) :: a, b, c
  로 사용하기 보다는
   real, dimension(3,n) :: abc
  로 사용하는게 더 효율적이다.

2.  포트란을 효율적으로 사용하려면 loop 구문을 최소화해야한다.

3. 루프 호버 헤드 최소화
  상대적으로 짧은 루프의 경우 상당한 성능 결과가 발생할 수 있다. 예를 들면, n>m 일 때,
   do i = 1, n
       do j = 1, m
           ! ...
       end do
   end do
  보다는
   do j = 1, m
       do i = 1, n
           ! ...
       end do
   end do
  이 더 효율적이다.
