# Mesh 만들기 v1

> 원본: `LBM/Mesh 만들기 v1.hwp`

Mesh 만드는 과정 - Voxlize

stl 파일 읽기
->

voxel size를 이용해 octree 구조 voxel 생성
octree search 고려
<최초 octree 노드 생성 stl 파일에서 읽은 삼각형 메쉬가 노드에 포함되는지 확인. 포함되는 삼각형 메쉬들 주소 저장. 삼각형 메쉬가 하나이상이라도 있으면 octree 8개 child 노드 생성 child 노드도 위의 과정 반복.>

voxel 과 삼각형이 교차(intersection, 또는 포함) 하는지 확인.
교차확인은 분리축정리(Separating Axis Theorem, SAT)가 제일 효율적.
교차하면 바운더리(B) voxel 임.
 나머진 플루이드(F) 복셀임.
voxel에 교차하고 있는 삼각형 표면 주소를 일시적으로 저장해놓음.

ray tracing 기술을 이용해 내/외부 구분
voxel의 중심 포인트에서 발사한 ray가 삼각형과 교차하는지 확인
x, y, z 방향에서, 한 방향에서라도 삼각형(표면)과 교차갯수가 홀수면
그 포인트는 내부라는 뜻임.

->

각 복셀에서 D2Q9, D3Q27 등의 연결선들을 만들어준다.
->
B복셀에서 F복셀이 하나라도 연결되어 있지 않으면, 그 B복셀은 삭제
->

extrapolation boundary 방법
<B 복셀의 연결선과 삼각형 메쉬간의 intersection 포인트(I)들을 생성해준다. I 포인트들이 생성되면 연결선이 끊어진 것이다. I 포인트가 여러개일 경우, 복셀 중심점에서부터 가장 가까운곳에 생성된다. -> F-B 간의 연결선이 하나도 없을땐, 그 B 복셀은 고스트 복셀(G)로 바뀐다. 만약 삭제된 B복셀이 다른 복셀과 연결되어 있을 때, 다른 연결된 복셀 입장에선 그 삭제된 B 복셀의 중심점이 I 포인트이다. -> F 복셀 중에서, 하나라도 I 포인트를 가지고 있을 시엔 FB 복셀로 바뀐다.>
