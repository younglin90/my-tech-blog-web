## 燃烧室前面为什么要有扩压器

喷气发动机压气机出口的空气以马赫0.3~0.4流出。但在进入燃烧室之前，要专门用扩压器(diffuser，通过扩大流道来减速的管段)把速度降到一半以下。第一个原因是火焰稳定。第二个原因是热力学。向运动的气体加热，这件事本身就会削减总压(把气体等熵滞止时的压力)。入口越快，削减越多。

本文用数字来衡量这项损失。在无摩擦的等截面管道中加入使总温翻倍的热量。入口马赫数从0.10扫到0.40，用RK4积分出口状态。结论有两条。入口0.30时总压损失7.1%。入口超过0.384时，热量甚至无法全部加进去。

## 等截面管道里只加热:Rayleigh流动

原笔记(Hill & Peterson 第3.5节)的设定很简单。截面积不变，没有摩擦，也没有轴功。唯一变化的是总温 $T_0$。燃烧、液滴蒸发、焦耳加热、壁面传热都可以归入这个模型。这种流动称为Rayleigh流动。

连续方程和动量方程可以直接积分。$\rho u$ 为常数，$p + \rho u^2$ 也是常数。用马赫数表示，就得到相对入口(下标1)的静压比。

$$\frac{p}{p_1} = \frac{1 + \gamma M_1^2}{1 + \gamma M^2}$$

$\gamma$ 是比热比，$M$ 是当地马赫数。再加上状态方程和能量方程，总温与马赫数就一一对应。以声速点(下标 $*$)为参考，可写成:

$$\frac{T_0}{T_0^*} = \frac{2(\gamma + 1)M^2 \left(1 + \frac{\gamma - 1}{2}M^2\right)}{(1 + \gamma M^2)^2}$$

$T_0^*$ 是同一质量流率下达到 $M=1$ 时的总温。该函数在 $M=1$ 处取最大值1。也就是说，任何流动能接受的热量都有上限。

无论从亚声速还是超声速出发，加热都会把状态点推向熵最大点($M=1$)。加大加热量，点会停在端点并出现红色警告。负加热(冷却)则把点推向另一侧。

## 加热会把马赫数拉向1

比起封闭解，微分形式更能看清原因。把三个守恒方程写成微小变化的形式，得到如下影响系数:

$$\frac{dM^2}{M^2} = \frac{(1 + \gamma M^2)\left(1 + \frac{\gamma - 1}{2}M^2\right)}{1 - M^2}\,\frac{dT_0}{T_0}$$

分子恒为正。符号由分母 $1-M^2$ 决定。亚声速时，$dT_0>0$ 使 $M$ 增大。超声速时 $M$ 减小。两者都趋向1。并且当 $M \to 1$ 时系数发散，意味着再加一点热，马赫数就会大幅变化。

直观理解如下。加热使密度下降。$\rho u$ 不变，速度只能上升。速度上升，由动量方程可知静压下降。静压下降又使密度进一步下降。在亚声速中，这个回路会自我放大。

## 加了热，温度反而下降的区间

静温比为 $T/T^* = M^2\left[(1+\gamma)/(1+\gamma M^2)\right]^2$。它在 $M=1/\sqrt{\gamma}$ 处取最大值。对空气($\gamma=1.4$)就是 $M=0.845$。从这里到 $M=1$，加热越多，静温越低。

这看似矛盾，但能量方程并未被违反。动能的增加超过了加入的热量，差额由静焓来补。上面模拟中的橙色段就是这个区域。把入口设为0.6、加热设为0.3，状态点进入橙色段后 $T/T_1$ 开始下降。

总压则不同。加热使熵增加，因此无论亚声速还是超声速，总压总是下降。原笔记的式(3.18)给出了这个比值。笔记中指数写成了 $\gamma(\gamma-1)$，正确的是 $\gamma/(\gamma-1)$。

## 代码:总温翻倍，入口马赫数七档

我们模拟一个燃烧室。沿管长 $x\in[0,1]$ 均匀放热，使 $T_0$ 从1升到 $\tau=2$，相当于把800 K的空气加热到1600 K。对上面的影响系数关于 $T_0$ 做4000步RK4积分。当 $M^2$ 达到0.9999时判定为热壅塞(加热使流动达到声速、再也无法吸收热量的状态)。静压、静温和总压由当地马赫数计算。最后比较封闭解与RK4结果。

```python
import math

G = 1.4  # 比热比

def t0_ratio_star(M):
    """式 (3.21): T0/T0*"""
    m2 = M*M
    return 2*(G+1)*m2*(1+0.5*(G-1)*m2)/(1+G*m2)**2

def dm2_dt0(m2, t0):
    """Rayleigh影响系数: dM²/dT0"""
    return m2*(1+G*m2)*(1+0.5*(G-1)*m2)/(1-m2)/t0

def heat_march(M1, tau, n=4000):
    """沿管长 x∈[0,1] 均匀加热，用RK4推进 M²。"""
    m2, t0 = M1*M1, 1.0
    dt0 = (tau-1.0)/n
    xs, ms = [0.0], [M1]
    for i in range(n):
        k1 = dm2_dt0(m2, t0)
        k2 = dm2_dt0(m2+0.5*dt0*k1, t0+0.5*dt0)
        k3 = dm2_dt0(m2+0.5*dt0*k2, t0+0.5*dt0)
        k4 = dm2_dt0(m2+dt0*k3, t0+dt0)
        m2n = m2 + dt0*(k1+2*k2+2*k3+k4)/6
        t0 += dt0
        if not (0 < m2n < 1) or m2n > 0.9999:   # 达到声速 → 热壅塞
            return xs, ms, (i+1)/n
        m2 = m2n
        xs.append((i+1)/n); ms.append(math.sqrt(m2))
    return xs, ms, None

def ratios(M, M1):
    """相对入口的静压、静温、总压比(无摩擦等截面)"""
    p = [(1+G*M1**2)/(1+G*m**2) for m in M]
    T = [(pi*m/M1)**2 for pi, m in zip(p, M)]
    p0 = [pi*((1+0.5*(G-1)*m**2)/(1+0.5*(G-1)*M1**2))**(G/(G-1)) for pi, m in zip(p, M)]
    return p, T, p0

def m1_max(tau):
    """无壅塞地加入总温比 tau 的最大入口马赫数(二分法)"""
    lo, hi = 1e-4, 1.0
    for _ in range(60):
        mid = 0.5*(lo+hi)
        lo, hi = (mid, hi) if t0_ratio_star(mid) < 1/tau else (lo, mid)
    return 0.5*(lo+hi)

tau = 2.0   # 燃烧室: 总温翻倍
print(f"tau = T02/T01 = {tau}   M1_max (closed form) = {m1_max(tau):.4f}")
print(" M1   | M_exit  p0 loss[%]  T_max/T1  x(T_max)  choke x")
for M1 in [0.10, 0.15, 0.20, 0.25, 0.30, 0.35, 0.40]:
    x, M, xc = heat_march(M1, tau)
    p, T, p0 = ratios(M, M1)
    k = max(range(len(T)), key=T.__getitem__)
    loss = 100*(1-p0[-1])
    xtm = f"{x[k]:.3f}" if k < len(x)-1 else "exit"
    cs = f"{xc:.3f}" if xc else "-"
    print(f" {M1:.2f} | {M[-1]:.4f}  {loss:9.2f}  {max(T):8.3f}  {xtm:>8}  {cs:>7}")

# 封闭解与RK4出口马赫数比较
x, M, _ = heat_march(0.30, tau)
lo, hi = 0.30, 1.0
target = t0_ratio_star(0.30)*tau
for _ in range(60):
    mid = 0.5*(lo+hi)
    lo, hi = (mid, hi) if t0_ratio_star(mid) < target else (lo, mid)
print(f"M1=0.30: RK4 M_exit={M[-1]:.6f}  closed form={0.5*(lo+hi):.6f}")
mf = lambda M: M*(1+0.5*(G-1)*M*M)**(-(G+1)/(2*(G-1)))   # 相同 p01、T01 下的质量流量
print(f"M1 0.40 -> {m1_max(tau):.4f}: mass flow x {mf(m1_max(tau))/mf(0.40):.4f}")
print(f"heating cools the gas for {1/math.sqrt(G):.4f} < M < 1")
```

## 0.384、13.5%、x = 0.890 说明了什么

第一，总压损失大致随入口马赫数的平方增长:0.10时0.71%，0.20时2.92%，0.30时7.11%。把入口减速到0.15，损失降到1.6%。即使算上扩压器本身的损失，减速也很划算。

第二，入口0.35以下都能到达出口。但出口马赫数已达0.66。这里影响系数的分母变小，放热分布稍有波动，出口状态就会大幅摆动。

第三，入口0.40只走完管道的89%就达到声速。在此之前，x = 0.852 处静温达到最大值(入口的1.672倍)，因为流动在那里越过了 $M=0.845$。此后约4%的管段里，一边加热，气体一边变冷。

封闭解给出的极限 $M_{1,\max}=0.3836$ 是 $T_0/T_0^*(M_1)=1/\tau$ 的根。RK4的出口马赫数与封闭解吻合到小数点后第六位，说明积分是正确的。

## 壅塞的燃烧室会改写上游

真实发动机里，流动不会停在 x = 0.890。亚声速流动会把下游的信息传到上游。一旦发生壅塞，入口条件会自行调整:入口马赫数降到0.3836，正好能吸收全部热量。

在相同总压、总温下，入口马赫数从0.40降到0.3836，质量流量变为原来的0.9663倍，少进3.4%的空气。对压气机来说，这就像出口突然被堵住，工作点被推向喘振(surge，压气机内的倒流)一侧。这就是加力燃烧室点火时要放大喷管喉道的原因:按加入的热量打开通道，让上游感觉不到这个变化。

本计算忽略了摩擦。实际管道中摩擦(Fanno流动)同样把马赫数拉向1，因此真实极限低于0.384。这里热量扮演了喷管中面积的角色，可以与[收缩-扩张喷管与壅塞](/zh/posts/2026-06-18-de-laval-nozzle-choked-flow/)对照来看。用压力基求解器计算这类流动时的陷阱，见[可压缩SIMPLE中的ψp′项](/zh/posts/2026-11-09-compressible-simple-pressure-correction-psi-term/)。

## 在加力燃烧室设计表上，比τ更先要看的数字

设计加热管道或审查CFD结果时，先算 $T_0/T_0^*(M_1)$，再看τ。它的倒数就是该管道能接受的最大总温比。τ越接近这个值，出口状态对放热分布越敏感。一旦超过，就是计算域的入口条件错了。如果给定质量流量入口的模拟发散，先怀疑这个不等式，再怀疑求解器。
