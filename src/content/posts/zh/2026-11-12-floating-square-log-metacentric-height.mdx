## 把方木扔进水里，哪一面会朝上

有一根截面为正方形的长方木，密度是水的一半。扔进水里，它会怎么浮？多数人想到的是一个面朝上、平平地浮着。实际上，它以一条棱朝下的菱形姿态浮着。本文只用一个长度——稳心高度（metacentric height，衡量浮体稳定性的长度）——来解释原因。读完后，你将推导出GM公式，并逐个横倾角计算浮心，用数字确认"能平浮的密度范围"。

一本气体动力学教材的旧笔记，第3-6节"Buoyancy & stability"只留下几张图和两句话："顺时针力矩则稳定。""上部较重则产生逆时针力矩，不稳定。"这两句是今天的起点。重心高就不稳定，符合直觉。但均质方木的重心恰好在正中。那么，是什么决定了它的姿态？

## 浮心不随物体一起转动

作用在物体上的力有两个。重力通过重心G向下。浮力通过排水体积的形心B（浮心）向上。平衡时两者大小相等，且在同一条铅垂线上。

让物体稍微倾斜。G固定在物体上，随之转动。B则不然。一侧沉得更深，另一侧浮起，水下部分的形状随之改变。B向沉得更深的一侧滑动。如果滑得足够远，浮力在G的外侧向上推，把物体扶正。如果不够，浮力与重力构成力偶（大小相等、方向相反的一对力），让倾斜继续增大。

两条作用线之间的水平距离称为复原力臂GZ，起扶正作用时为正。下面的模拟可以直接操作。

## 稳心高度 GM = BM − BG

在小横倾角θ下，B移动后的浮力作用线与物体中心线交于一点，即稳心M。M在G之上则稳定。两点间的距离就是GM，小角度时复原力臂为

$$GZ \approx GM \sin\theta$$

GM只需几何就能求出。设水线面（waterplane，物体被水面切出的截面）对其轴的截面惯性矩为$I$，排水体积为$V$。

$$GM = BM - BG = \frac{I}{V} - (KG - KB)$$

$K$为龙骨（底部），$KB$为底部到浮心的高度，$KG$为底部到重心的高度。$BM = I/V$表示B随倾斜滑动的距离。水线面越宽，它越大。

## 对正方形而言，GM只是s的函数

取宽$b$、高$h$的矩形截面，按单位长度考虑。均质物体的密度比为$s = \rho_{body}/\rho_{water}$，则吃水（draft，浸没深度）为$d = sh$。

$$I = \frac{b^3}{12},\quad V = b\,s h,\quad KB = \frac{sh}{2},\quad KG = \frac{h}{2}$$

代入得

$$GM = \frac{b^2}{12\,s\,h} + \frac{s h}{2} - \frac{h}{2}$$

第一项是水线面提供的复原，后两项是G高于B带来的损失。对正方形（$b = h = 1$）可整理为

$$GM = \frac{6s^2 - 6s + 1}{12\,s}$$

分子为零的$s = (3 \pm \sqrt{3})/6$，即0.2113和0.7887，就是边界。两者之间GM为负。只有很轻或很重的方木才能平浮。该式在$s \leftrightarrow 1-s$下符号相同。把以密度$s$浮着的物体翻过来，水面以上部分就相当于密度为$1-s$的浸没物体。

这个公式只在小θ下成立。GM为负时，它不能告诉我们物体翻到哪里才停。这需要计算大角度下完整的GZ(θ)。

## 代码：在901个横倾角上用二分法求水线

计算步骤很简单。把截面旋转θ。用二分法（bisection，每次把区间减半来逼近根）求使浸没面积等于$s\,bh$的水面高度$c$。浸没多边形的形心就是B。把G放在原点，则$GZ = -x_B$。θ从0扫到90°，GZ由负变正之处就是稳定平衡。

```python
import numpy as np

def clip_below(poly, c):
    """多边形中 y < c 的部分 (Sutherland–Hodgman, 一条直线)"""
    out = []
    n = len(poly)
    for i in range(n):
        p, q = poly[i], poly[(i + 1) % n]
        pin, qin = p[1] < c, q[1] < c
        if pin:
            out.append(p)
        if pin != qin:
            t = (c - p[1]) / (q[1] - p[1])
            out.append((p[0] + t * (q[0] - p[0]), c))
    return out

def area_centroid(poly):
    A = cx = cy = 0.0
    n = len(poly)
    for i in range(n):
        x0, y0 = poly[i]; x1, y1 = poly[(i + 1) % n]
        cr = x0 * y1 - x1 * y0
        A += cr; cx += (x0 + x1) * cr; cy += (y0 + y1) * cr
    A *= 0.5
    return A, cx / (6 * A), cy / (6 * A)

def righting_arm(theta, s, b=1.0, h=1.0):
    """横倾角theta下的复原力臂GZ (G在原点, 正 = 扶正方向)"""
    co, si = np.cos(theta), np.sin(theta)
    box = [(-b/2, -h/2), (b/2, -h/2), (b/2, h/2), (-b/2, h/2)]
    poly = [(x*co - y*si, x*si + y*co) for x, y in box]
    target = s * b * h
    lo, hi = -0.8*(b+h), 0.8*(b+h)
    for _ in range(60):                       # 用二分法求水线高度c
        c = 0.5 * (lo + hi)
        sub = clip_below(poly, c)
        A = area_centroid(sub)[0] if len(sub) >= 3 else 0.0
        lo, hi = (c, hi) if A < target else (lo, c)
    _, xB, _ = area_centroid(clip_below(poly, c))
    return -xB

def floating_angles(s, b=1.0, h=1.0, n=901):
    th = np.linspace(0, np.pi/2, n)
    gz = np.array([righting_arm(t, s, b, h) for t in th])
    gm = (righting_arm(1e-4, s, b, h)) / 1e-4
    stable = [0.0] if gm > 0 else []
    for i in range(1, n - 2):                 # GZ 由 − 变 + 处 = 稳定平衡
        if gz[i] < -1e-9 and gz[i+1] > -1e-9:
            stable.append(np.degrees(th[i] - gz[i]*(th[i+1]-th[i])/(gz[i+1]-gz[i])))
    if b != h and gz[-2] < 0:                 # 90°(竖立姿态)也是平衡
        stable.append(90.0)
    return gm, stable

print("square section (b/h = 1), homogeneous body, s = rho_body / rho_water")
print(" s     GM_theory   GM_numeric   stable heel (deg)")
for s in [0.10, 0.20, 0.22, 0.24, 0.30, 0.50, 0.70, 0.76, 0.80, 0.90]:
    gm_th = 1/(12*s) + s/2 - 0.5
    gm, st = floating_angles(s)
    print(f"{s:.2f}  {gm_th:+.5f}    {gm:+.5f}     {', '.join(f'{a:.1f}' for a in st)}")
print()
print("s = 0.5, widening the section (h = 1)")
print(" b/h   GM_theory   stable heel (deg)")
for b in [1.0, 1.1, 1.2, 1.25, 1.3, 1.5]:
    s = 0.5
    gm_th = b*b/(12*s) + s/2 - 0.5
    gm, st = floating_angles(s, b=b)
    print(f"{b:.2f}  {gm_th:+.5f}    {', '.join(f'{a:.1f}' for a in st)}")
print(f"\ncritical s: (3-sqrt3)/6 = {(3-np.sqrt(3))/6:.4f}, (3+sqrt3)/6 = {(3+np.sqrt(3))/6:.4f}")
```

## 读表：45°、23.5°，以及b/h = 1.225

第一，数值GM与理论GM在五位有效数字上一致。小角度斜率$dGZ/d\theta$正好等于$I/V - BG$。公式本身没有近似，只有小角度这个条件。

第二，s = 0.30、0.50、0.70时，45°是唯一稳定点。正方形对称，45°处GZ恒为零。GM足够负时，被推离0°的物体会翻到下一个对称姿态，即菱形。

第三，在边界内侧不远的s = 0.22、0.24，方木停在中间角度13.7°和23.5°。76.3°和66.5°是从对面一侧量得的同一姿态。平浮姿态失稳的那一刻，方木并不会跳到45°。倾角从0°连续增大，在s ≈ 0.28附近到达45°（同一代码给出s = 0.28时41.2°，0.29时45.0°）。GM的符号只说明稳定与否，停在哪个角度由整条GZ曲线决定。

第四，密度保持0.5而只加宽截面，GM在$b^2/6 = 1/4$，即$b/h = \sqrt{1.5} \approx 1.225$处过零。表中1.20到1.25之间的符号变化就是它。宽度相差22%，就区分了菱形与平浮两种姿态。

## 这一计算在船舶设计与CFD中的位置

船舶稳性校核就是把上面的代码换成真实船体。用水线面切割三维船体代替二维截面，画出随横倾角变化的GZ曲线。规范除了GM下限，还要求GZ曲线下的面积（复原能量）。正如今天的表所示，仅凭小角度GM无法判断大角度行为。

在把VOF（volume of fluid，用体积分数追踪界面的方法）与六自由度刚体运动耦合的浮体CFD中，同样的计算也是第一道检验。把物体放在静水面上，看模拟能否得到正确的静平衡姿态。若不对，通常是质量、惯性或重心输入有误。压力场收敛到静水压$p = \rho g (c - y)$后，浮力与B应与今天的多边形计算一致。静止流体中应力只剩$-p\mathbf{I}$的过程，在[讨论应力散度∇·τ的文章](/zh/posts/2026-11-03-stress-divergence-variable-viscosity-laplacian/)中由牛顿第二定律整理过。

自由衰减（free decay）试验用的也是同一个GM。小角度下横摇是一个摆：$I_{roll}\ddot\theta = -m g\,GM\,\theta$。由测得的固有周期即可反推GM。一页静水力计算就成了动力学验证的基准。与需要用动量来分析损失的[突扩管Borda–Carnot损失](/zh/posts/2026-11-05-borda-carnot-sudden-expansion-lost-velocity/)不同，这里只靠静水压积分就能闭合问题。

## 给驳船装货前要核对的一个不等式

$$\frac{b^2}{12\,s\,h} > \frac{h}{2} - \frac{sh}{2} + \Delta_G$$

$\Delta_G$是货物使重心升高的量。左边随船宽的平方增大，右边随G每次升高而增大。在甲板上堆货会增大$\Delta_G$。货物轻则$s$变小，左边也随之增大。谁占上风，这一行就能判断。在第一个模拟中把b/h设为1.25，只需把G shift上调+0.1，就能看到截面倾覆。
