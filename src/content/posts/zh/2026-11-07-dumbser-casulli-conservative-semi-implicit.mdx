## 压力解对了，激波却晚到了十个网格

两段代码几乎相同。同样的交错网格，同样的对流通量，同样的 Δt。两者都隐式求解压力，以避开声速 CFL 限制。然而在压力比 10⁵ 的激波管中，一个的激波落在精确解位置。另一个落后 0.048，约十个网格。

区别只有一处：能量用什么来更新。本文阅读 Dumbser 与 Casulli 2016 年的论文，并用约 130 行 Python 复现这一差别。读完之后，你可以用数字说明为什么"基于压力"和"守恒"是需要分别检查的两种性质。

## 论文瞄准的问题

在低马赫数(流速远小于声速)流动中，显式 Godunov 格式按声速选取 Δt。流速 1 m/s、声速 3,700 m/s 时，步数增加 3,700 倍。另一方面，源自不可压缩领域的半隐式压力格式按流速选取 Δt，但在激波面前通常会失去守恒性。

Dumbser 与 Casulli 把两种要求放进同一个格式。密度和对流项显式处理，动量中的压力项和能量中的速度项隐式处理。状态方程(EOS)也不必是理想气体。van der Waals、Redlich–Kwong 这类三次 EOS 都能在同一框架内求解。另一种低马赫数思路见[参考状态 IMEX 双流体求解器解读](/zh/posts/2026-11-01-rs-imex-two-fluid-material-cfl/)。

## 代入到只剩压力

网格是交错布置的(staggered grid，压力在单元中心、速度在单元边界)。压力 $p_i$ 与总能 $(\rho E)_i$ 位于中心，密度 $\rho_{i+1/2}$ 与动量 $(\rho u)_{i+1/2}$ 位于界面。动量方程只在新时间层取压力。

$$
(\rho u)^{n+1}_{i+\frac12} = F(\rho u)^n_{i+\frac12} - \frac{\Delta t}{\Delta x}\left(p^{n+1}_{i+1} - p^{n+1}_i\right)
$$

$F(\rho u)$ 是显式对流算子，$\Delta t$ 与 $\Delta x$ 是时间和空间步长。

把它代入能量方程的焓通量 $h\,(\rho u)$。未知量就只剩下压力。

$$
\Delta x\,\rho^{n+1}_i e\!\left(p^{n+1}_i,\rho^{n+1}_i\right) - \frac{\Delta t^2}{\Delta x}\left[h_{i+\frac12}\left(p_{i+1}-p_i\right) - h_{i-\frac12}\left(p_i-p_{i-1}\right)\right]^{n+1} = b_i
$$

$e$ 是比内能，$h = e + p/\rho$ 是界面比焓，$b_i$ 汇总了已知项。

$h$ 与动能用 Picard 迭代(用上一次迭代值冻结系数后重新求解)处理。论文称 3 次就足够。于是方程写成 $\mathbf V(\mathbf p) + \mathbf T\mathbf p = \mathbf b$。$\mathbf T$ 是对称半正定的三对角矩阵。$\mathbf V$ 是逐单元计算 $\Delta x\,\rho_i e(p_i,\rho_i)$ 的对角函数。

## 非线性只在对角线上

这一结构是论文的第二根支柱。无论 EOS 多复杂，非线性只进入 $\mathbf V$，即对角线。只要 $e$ 随压力单调递增，Casulli 一系的嵌套 Newton 法就有收敛保证。理想气体 $\rho e = p/(\gamma-1)$ 是线性的。van der Waals 的 $e$ 对 $p$ 也是线性的，论文报告 Newton "恰好一次迭代收敛"。

选择 Redlich–Kwong 并增大 attraction $a$，右侧 $V(p)$ 曲线偏离直线弦，迭代次数随之增加。反过来，把 κ(=$\Delta t^2 h/\Delta x^2$，实际上是声学 CFL 的平方)调到 10⁴，迭代次数几乎不变。耦合矩阵 $\mathbf T$ 是线性的，大 Δt 不会让 Newton 变难。

## 最后一行：能量如何更新

求出压力后有两种选择。一种是用压力解更新动量，再以通量形式重写能量(论文式 24)。

$$
(\rho E)^{n+1}_i = F(\rho E)^n_i - \frac{\Delta t}{\Delta x}\left(h_{i+\frac12}(\rho u)^{n+1}_{i+\frac12} - h_{i-\frac12}(\rho u)^{n+1}_{i-\frac12}\right)
$$

$F(\rho E)$ 是只含动能对流的显式算子。离开一个单元的能量恰好进入相邻单元。

另一种是经典的基于压力的做法。不解能量方程，而是半隐式求解原始变量压力方程 $p_t + u p_x + \gamma p u_x = 0$。在光滑流动中两者等价。但在间断处，$\gamma p\,u_x$ 不是守恒形式。Rankine–Hugoniot 条件(激波两侧守恒量通量必须平衡)不再成立，激波速度随之偏离。与[LU-SGS 中被丢弃的项决定收敛的故事](/zh/posts/2026-11-06-lu-sgs-factorization-error-cfl-limit/)一样，这里也是"看似很小的一项"决定了结果。

## 代码：同样的 Δt，两种能量处理

一维交错网格 200 个单元，γ = 1.4，基于流速的 CFL 0.5，求解 Sod 问题和 Toro 的 RP3(压力比 $10^5$)。初始流速为 0，所以 Δt 从 $10^{-4}$ 起步，每步最多放大 1.1 倍。精确激波位置由精确 Riemann 解的 $p^*$ 计算。最后再运行论文的 RP0(密度跳跃 $10^5$ 的接触间断)，比较步数。

```python
import numpy as np

G = 1.4

def star_state(rL, uL, pL, rR, uR, pR):
    # 精确 Riemann 解的 p*, u* (Toro, Newton 迭代)
    def fk(p, r, pk):
        a = np.sqrt(G * pk / r)
        if p > pk:
            A, B = 2 / ((G + 1) * r), (G - 1) / (G + 1) * pk
            return (p - pk) * np.sqrt(A / (p + B))
        return 2 * a / (G - 1) * ((p / pk) ** ((G - 1) / (2 * G)) - 1)
    p = 0.5 * (pL + pR)
    for _ in range(100):
        f = fk(p, rL, pL) + fk(p, rR, pR) + uR - uL
        d = 1e-7 * p
        df = (fk(p + d, rL, pL) + fk(p + d, rR, pR) - fk(p - d, rL, pL) - fk(p - d, rR, pR)) / (2 * d)
        p = max(p - f / df, 1e-10)
    u = 0.5 * (uL + uR) + 0.5 * (fk(p, rR, pR) - fk(p, rL, pL))
    return p, u

def thomas(a, b, c, d):
    n = len(d); cp = np.zeros(n); dp = np.zeros(n)
    cp[0], dp[0] = c[0] / b[0], d[0] / b[0]
    for i in range(1, n):
        m = b[i] - a[i] * cp[i - 1]
        cp[i] = c[i] / m; dp[i] = (d[i] - a[i] * dp[i - 1]) / m
    x = np.zeros(n); x[-1] = dp[-1]
    for i in range(n - 2, -1, -1):
        x[i] = dp[i] - cp[i] * x[i + 1]
    return x

def si_staggered(rp, N=200, cfl=0.5, picard=3):
    rL, uL, pL, rR, uR, pR, xd, tend = rp
    dx = 1.0 / N
    xf = -0.5 + dx * np.arange(N + 1)            # 界面: rho, rho*u
    xc = 0.5 * (xf[:-1] + xf[1:])                # 单元: p, rho*E
    rf = np.where(xf < xd, rL, rR); mf = rf * np.where(xf < xd, uL, uR)
    p = np.where(xc < xd, pL, pR)
    rk = lambda r, m: 0.5 * m**2 / r
    def cell_rk(r, m):
        k = rk(r, m); return 0.5 * (k[:-1] + k[1:])
    rE = p / (G - 1) + cell_rk(rf, mf)
    E0 = rE.sum() * dx
    t, dt, steps, cmax = 0.0, 1e-4, 0, 0.0
    while t < tend - 1e-12:
        u = mf / rf
        rc = 0.5 * (rf[:-1] + rf[1:])
        cmax = max(cmax, np.max(np.abs(np.r_[u[:-1], u[1:]]) + np.sqrt(G * np.r_[p, p] / np.r_[rc, rc])))
        dt = min(cfl * dx / max(np.abs(u).max(), 1e-12), 1.1 * dt, tend - t)
        # (11)(12)(14)(15): 界面密度与动量 — 显式对流
        umax = np.maximum(np.abs(u[:-1]), np.abs(u[1:]))
        fr = 0.5 * (mf[:-1] + mf[1:]) - 0.5 * umax * (rf[1:] - rf[:-1])
        fm = 0.5 * (u[:-1] * mf[:-1] + u[1:] * mf[1:]) - 0.5 * umax * (mf[1:] - mf[:-1])
        rn = rf.copy(); Fm = mf.copy()
        rn[1:-1] -= dt / dx * (fr[1:] - fr[:-1])
        Fm[1:-1] -= dt / dx * (fm[1:] - fm[:-1])
        # (17)(18): 仅动能对流为显式
        kc = cell_rk(rf, mf)
        fk = 0.5 * u[1:-1] * (kc[1:] + kc[:-1]) - 0.5 * np.abs(u[1:-1]) * (kc[1:] - kc[:-1])
        fk = np.r_[u[0] * kc[0], fk, u[-1] * kc[-1]]
        FE = rE - dt / dx * (fk[1:] - fk[:-1])
        m, pr = Fm.copy(), p.copy()
        for r in range(picard):                   # Picard: 用上一次迭代值冻结 h, rho*k
            pf = np.maximum(0, np.r_[pr[0], np.maximum(pr[:-1], pr[1:]), pr[-1]])
            h = G / (G - 1) * pf / rn
            kc = cell_rk(rn, m)
            b = dx * (FE - kc) - dt * (h[1:] * Fm[1:] - h[:-1] * Fm[:-1])
            w = dt**2 * h / dx                        # T 矩阵的界面系数 (对称)
            w[0] = w[-1] = 0.0                        # 边界面动量保持不变
            diag = dx / (G - 1) + w[1:] + w[:-1]      # V(p)=dx*p/(G-1): 理想气体为线性
            pr = thomas(-w[:-1], diag, -w[1:], b)
            m = Fm.copy(); m[1:-1] -= dt / dx * (pr[1:] - pr[:-1])   # (23)
        pf = np.maximum(0, np.r_[pr[0], np.maximum(pr[:-1], pr[1:]), pr[-1]])
        h = G / (G - 1) * pf / rn
        rE = FE - dt / dx * (h[1:] * m[1:] - h[:-1] * m[:-1])   # (24) 通量形式
        p = (G - 1) * (rE - cell_rk(rn, m))       # 由守恒量重新计算压力
        rf, mf = rn, m
        t += dt; steps += 1
    return xc, p, mf / rf, rf, steps, cmax, (rE.sum() * dx - E0)

def shock_x(xc, p, pstar, pR):
    mid = 0.5 * (pstar + pR)
    i = np.where(p > mid)[0].max()
    return xc[i] + (p[i] - mid) / (p[i] - p[i + 1]) * (xc[i + 1] - xc[i])

def si_primitive(rp, N=200, cfl=0.5):
    # 非守恒对照: 用压力方程 p_t + u p_x + G p u_x = 0 代替能量方程, 半隐式
    rL, uL, pL, rR, uR, pR, xd, tend = rp
    dx = 1.0 / N
    xf = -0.5 + dx * np.arange(N + 1); xc = 0.5 * (xf[:-1] + xf[1:])
    rf = np.where(xf < xd, rL, rR); mf = rf * np.where(xf < xd, uL, uR)
    p = np.where(xc < xd, pL, pR)
    E0 = (p / (G - 1) + 0.5 * (0.5 * mf[:-1]**2 / rf[:-1] + 0.5 * mf[1:]**2 / rf[1:])).sum() * dx
    t, dt, steps = 0.0, 1e-4, 0
    while t < tend - 1e-12:
        u = mf / rf
        dt = min(cfl * dx / max(np.abs(u).max(), 1e-12), 1.1 * dt, tend - t)
        umax = np.maximum(np.abs(u[:-1]), np.abs(u[1:]))
        fr = 0.5 * (mf[:-1] + mf[1:]) - 0.5 * umax * (rf[1:] - rf[:-1])
        fm = 0.5 * (u[:-1] * mf[:-1] + u[1:] * mf[1:]) - 0.5 * umax * (mf[1:] - mf[:-1])
        rn = rf.copy(); Fm = mf.copy()
        rn[1:-1] -= dt / dx * (fr[1:] - fr[:-1]); Fm[1:-1] -= dt / dx * (fm[1:] - fm[:-1])
        uc = 0.5 * (u[:-1] + u[1:])
        pg = np.r_[p[0], p, p[-1]]
        Fp = p - dt / dx * (np.maximum(uc, 0) * (pg[1:-1] - pg[:-2]) + np.minimum(uc, 0) * (pg[2:] - pg[1:-1]))
        w = dt**2 / (dx**2 * rn); w[0] = w[-1] = 0.0
        gp = G * p
        b = Fp - dt / dx * gp * (Fm[1:] / rn[1:] - Fm[:-1] / rn[:-1])
        p = thomas(-gp * w[:-1], 1 + gp * (w[1:] + w[:-1]), -gp * w[1:], b)
        mf = Fm.copy(); mf[1:-1] -= dt / dx * (p[1:] - p[:-1]); rf = rn
        t += dt; steps += 1
    E1 = (p / (G - 1) + 0.5 * (0.5 * mf[:-1]**2 / rf[:-1] + 0.5 * mf[1:]**2 / rf[1:])).sum() * dx
    return xc, p, mf / rf, rf, steps, E1 - E0

probs = {
    "Sod": (1.0, 0.0, 1.0, 0.125, 0.0, 0.1, 0.0, 0.2),
    "RP3": (1.0, 0.0, 1000.0, 1.0, 0.0, 0.01, 0.1, 0.012),
}
for name, rp in probs.items():
    ps, us = star_state(*rp[:6])
    rR, pR, xd, tend = rp[3], rp[5], rp[6], rp[7]
    q = (G - 1) / (G + 1)
    rs = rR * (ps / pR + q) / (q * ps / pR + 1)          # 激波后密度 (Rankine-Hugoniot)
    xs = xd + rs * us / (rs - rR) * tend
    print(f"{name}: exact shock x={xs:.4f}  p*={ps:.3f}  rho*={rs:.3f}")
    xc, p, u, r, n, cmax, dE = si_staggered(rp)
    print(f"  conservative SI   steps={n:3d}  shock x={shock_x(xc, p, ps, pR):.4f}"
          f"  p*={p[(xc > xd) & (xc < xs - 0.03)].mean():8.3f}  rho_max={r.max():6.3f}  dE={dE:+.1e}")
    xc, p, u, r, n, dE = si_primitive(rp)
    print(f"  primitive p-eq SI steps={n:3d}  shock x={shock_x(xc, p, ps, pR):.4f}"
          f"  p*={p[(xc > xd) & (xc < xs - 0.03)].mean():8.3f}  rho_max={r.max():6.3f}  dE={dE:+.1e}")
rp0 = (1000.0, 1.0, 1e5, 0.01, 1.0, 1e5, -0.25, 0.5)
xc, p, u, r, n, cmax, dE = si_staggered(rp0)
print(f"RP0 (rho 1e5 jump, M<0.085): steps={n}  explicit |u|+c CFL would need {int(0.5 / (0.5 * (1 / 200) / cmax)):,d}")
print(f"  max|p/1e5-1|={np.abs(p / 1e5 - 1).max():.1e}  max|u-1|={np.abs(u - 1).max():.1e}")
```

## 0.048 与 381 说明了什么

RP3 精确解的激波在 $x = 0.3822$，$p^* = 460.9$。守恒格式给出 0.3882 和 459.2。0.006 的差距来自一阶格式的数值耗散，激波被抹平了约一个网格。加密网格即可缩小。

原始变量压力方程给出 0.3337 和 381.1。激波晚到 0.048(约十个网格)，平台压力低 17%。密度峰值 11.7，是精确值 6.0 的两倍。能量变化 $-1.1\times10^2$，约占初始总能的 7%。丢失的能量削弱了激波，弱激波走得更慢。加密网格也消除不了这一误差，因为非守恒格式收敛到错误的弱解(weak solution)。

Sod 问题方向相同。守恒格式为 0.3597，原始格式为 0.3188(精确 0.3504)，误差分别为 +0.009 和 −0.032。压力比越小，差距越小。因此只用 Sod 验证过的压力基代码很容易漏掉这个问题。

在 RP0 中，接触间断处密度跳跃 $10^5$ 倍，但压力和速度分别保持在 $10^{-10}$、$10^{-8}$ 量级不变。共用 224 步。若按 $|u|+c$ 的显式 CFL 计算，约需 75 万步。这个数字就是论文所说的 "large time steps"。

## 这个一维复现无法展示的内容

论文格式是一阶精度。论文本身也承认 RP5(双稀疏波)中密度出现非物理拐折，RP6(碰撞激波)中激波后有振荡。对极强激波，论文建议在压力通量中加入式 (25) 的 Rusanov 型耗散。本文代码省略了该项。

三次 EOS 的真正考验是 Redlich–Kwong。此时 $e(p)$ 是非线性的，嵌套 Newton 才真正发挥作用。本文的 Python 只处理理想气体，这部分仅在第一个模拟中近似展示。二维粘性扩展和顶盖驱动方腔结果也未涉及。Δt 斜坡(×1.1)并非论文内容，而是本文为静止初始条件做的选择。

## 信任压力基可压缩代码之前要跑的一个算例

Sod 太温和了。运行压力比 $10^5$ 的 RP3，并输出总能的变化。如果能量守恒到机器精度、激波落在精确位置一两个网格之内，那就是守恒格式。如果能量丢失几个百分点、激波落后，那么无论压力解得多精确，这段代码都处理不了激波。
