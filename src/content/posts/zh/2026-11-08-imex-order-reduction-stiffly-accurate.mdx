## 两个二阶IMEX，只有一个变成了一阶

我用两个二阶IMEX格式算了同一个问题。刚性参数 $\varepsilon=1$ 时，两者都是干净的二阶。把 $\varepsilon$ 降到 $10^{-6}$，一个仍给出2.01，另一个变成了0.99。两者都稳定，解没有发散。错的只有阶数。

本文讨论的就是这个差别。Orlando、Boscarino和Russo（2025）在低马赫Euler方程中给这一性质起了名字：渐近精度（AA, asymptotically-accurate），它不同于渐近保持（AP, asymptotic-preserving）。读完后你会知道该看Butcher表的哪一行。

## AP和AA是两个不同的承诺

将低马赫Euler方程无量纲化后，动量方程中出现 $\frac{1}{M^2}\nabla p$。这意味着声波比流动快 $1/M$ 倍。IMEX（implicit-explicit，只对部分项做隐式处理的时间积分）对这个压力项做隐式处理，对对流项做显式处理。这样Δt由流速而非声速决定。

论文的定义如下。AP格式的稳定条件不依赖于 $M$，并且在 $M\to0$ 时成为不可压缩Euler方程的相容离散。AA更进一步：在 $M\to0$ 时也要**保持高阶精度**。AP承诺的是"不发散，并走向正确的极限"。AA承诺的是"以设计阶数走向那个极限"。

如果Δt与 $M$ 无关，$\Delta t/M^2$ 就会非常大。这称为刚性极限。之前的文章 [Orlando–Bonaventura的AP IMEX](/zh/posts/2026-05-03-orlando-bonaventura-ap-imex-nonideal-gas/) 说明了时间步在这一区域能够存活。今天的问题是：这一步是几阶的。

## 试验台：Prothero–Robinson方程

直接求解完整的Euler方程会混入空间误差。因此我们使用刚性ODE的标准测试问题。

$$
y'(t) = \underbrace{\varphi'(t)}_{\text{explicit}} + \underbrace{\frac{\varphi(t)-y}{\varepsilon}}_{\text{implicit}}, \qquad y(0)=\varphi(0)
$$

$\varphi(t)=\sin t$ 是慢解，$\varepsilon$ 是弛豫时间。精确解为 $y=\varphi$。

$\varepsilon$ 扮演低马赫问题中 $M^2$ 的角色。第二项把解拉向慢流形 $y=\varphi$。这与低马赫压力项把密度场拉向不可压缩状态的结构相同。第一项是慢强迫项，做显式处理。

对比对象有两个。一个是论文二阶计算所用的IMEX-RK(2,2,2)，即Giraldo等人的ARK2，是 $\gamma=1-1/\sqrt2$ 的type II格式。另一个是合作者Russo与Pareschi提出的IMEX-SSP2(2,2,2)，是对角元同为 $\gamma$ 的type I格式。两者都是二阶，隐式部分都满足 $R(\infty)=0$。

## 原因：最后一级是不是答案

差别在论文的定义3.2中。若隐式部分矩阵 $A$ 的最后一行等于权重 $b$，则称该格式刚性精确（SA, stiffly accurate）。

$$
a_{sl} = b_l, \qquad l=1,\dots,s
$$

$a_{sl}$ 是隐式Butcher矩阵的最后一行，$b_l$ 是最终更新的权重。

若满足SA，最终更新值就等于最后一级的值。在刚性极限下，每一级都被投影到流形上。ARK2的 $c_s=1$，所以最后一级落在 $\varphi(t_{n+1})$ 附近。剩下的只有显式权重差异带来的 $O(\Delta t^2)$ 误差。

SSP2中 $A$ 的最后一行是 $(1-2\gamma,\gamma)$，而 $b=(1/2,1/2)$。最终值由各级斜率的加权和重新组装。在刚性极限下，这些斜率含有 $(\varphi-Y)/\varepsilon$ 形式的 $0/0$。混合这些极限值的结果只能把 $\varphi$ 再现到 $O(\Delta t)$。误差不会累积，因此这个局部误差就是全局误差。

论文还指出了type II的陷阱。type II格式中 $A$ 不可逆。因此SA加上A稳定性也不能保证L稳定（一步内把刚性分量衰减为零）。需要额外条件 $\mathbf{e}_{s-1}^\top \hat{\mathcal{A}}^{-1}\mathbf{a}=0$。论文使用的格式全部是SA，隐式部分全部L稳定。

## 代码：4个ε × 6个Δt

隐式级关于 $y$ 是线性的，因此可以用闭式求解。误差在 $t=2$ 处测量。

```python
import math

g = 1 - 1/math.sqrt(2)
d = math.sqrt(2)/4
al = (3 + 2*math.sqrt(2))/6
# (A_exp, A_imp, b) — both schemes share b between explicit/implicit parts
SCHEMES = {
    "ARK2  (type II, SA)": ([[0, 0, 0], [2*g, 0, 0], [1-al, al, 0]],
                           [[0, 0, 0], [g, g, 0], [d, d, g]],
                           [d, d, g]),
    "SSP2  (type I, non-SA)": ([[0, 0], [1, 0]],
                              [[g, 0], [1-2*g, g]],
                              [0.5, 0.5]),
}

def pr_imex(scheme, eps, dt, T=2.0):
    """Prothero-Robinson: y' = phi'(t) [explicit] + (phi(t)-y)/eps [implicit], phi=sin"""
    Ae, Ai, b = scheme
    s = len(b)
    ce = [sum(r) for r in Ae]
    ci = [sum(r) for r in Ai]
    y, t = 0.0, 0.0
    for _ in range(int(round(T/dt))):
        FE, FI = [0.0]*s, [0.0]*s
        for l in range(s):
            rhs = y + dt*sum(Ae[l][m]*FE[m] + Ai[l][m]*FI[m] for m in range(l))
            a = dt*Ai[l][l]/eps
            Y = (rhs + a*math.sin(t + ci[l]*dt))/(1 + a)   # linear implicit stage
            FE[l] = math.cos(t + ce[l]*dt)
            FI[l] = (math.sin(t + ci[l]*dt) - Y)/eps
        y += dt*sum(b[l]*(FE[l] + FI[l]) for l in range(s))
        t += dt
    return abs(y - math.sin(t))

dts = [0.1/2**k for k in range(6)]
for name, sc in SCHEMES.items():
    print(name)
    print("  eps    " + "".join(f"{'dt='+format(h,'.4g'):>12}" for h in dts) + "   order")
    for eps in [1.0, 1e-2, 1e-4, 1e-6]:
        e = [pr_imex(sc, eps, h) for h in dts]
        p = math.log2(e[-2]/e[-1])
        print(f"  {eps:<6.0e}" + "".join(f"{x:12.2e}" for x in e) + f"  {p:6.2f}")
```

## Δt < ε之前都不是二阶

$\varepsilon=1$ 那一行是非刚性问题。两种格式都是2.00，只是SSP2的误差常数大3.7倍。

$\varepsilon=10^{-2}$ 那一行是关键。从Δt=0.1到0.025，SSP2的误差每次只减小2.5倍、3.1倍。直到Δt低于ε的0.00625之后，才每次减小3.9倍。当Δt/ε小于1时，阶数才恢复。

在 $\varepsilon=10^{-6}$ 时，即使把Δt缩小32倍，Δt/ε仍超过3,000。SSP2始终是一阶，误差/Δt几乎恒定在0.29。ARK2最终为6.11e-07。在相同Δt下相差1,480倍。

低马赫代码中 $\varepsilon\approx M^2$。$M=10^{-3}$ 时 $\varepsilon=10^{-6}$。把Δt降到 $M^2$ 以下，等于放弃了使用IMEX的理由本身。所以非SA格式在低马赫区域实际上就是一阶格式。

ARK2在 $\varepsilon=10^{-4}$ 一行的阶数2.40，是误差常数随ε变化的过渡区效应。这里不要直接相信阶数，应看误差大小。

## 论文在Euler方程上验证了什么

论文比较了两条时间积分路线。一条是IMEX：把动量和能量隐式耦合，用不动点迭代求解弱非线性压力方程。另一条是SI-IMEX：对刚性依赖做线性化，避开非线性方程。空间离散采用DG（间断伽辽金）。

移动涡（traveling vortex）收敛测试的结果并不整齐。二阶IMEX-RK(2,2,2)配合一次DG，在 $M=10^{-2}$ 时就已出现精度下降。四阶ARS型和type II格式在 $M=10^{-3}$ 以内达到预期阶数。但IMEX方法在 $M=10^{-2}$ 时出现了降阶。$M=10^{-4}$ 以下误差饱和。

作者没有断定饱和的原因。他们把四边形网格DG的低马赫不准确性、双精度舍入误差以及刚性ODE特有的降阶一并列为可能原因。也就是说，仅靠时间积分的AA并不能解决低马赫精度问题。

对非理想气体，状态方程会让压力方程更加非线性。SI-IMEX分析了这种依赖，扩展为只需求解线性方程。这相当于从另一侧绕开了昨天 [Dumbser–Casulli弱非线性压力方程](/zh/posts/2026-11-07-dumbser-casulli-conservative-semi-implicit/) 所面对的同一问题。采用参考状态线性化的 [双流体IMEX求解器](/zh/posts/2026-11-01-rs-imex-two-fluid-material-cfl/) 也属于同一系列。

## 选IMEX表之前，先比较最后一行

把新的IMEX格式放进代码之前，先比较隐式部分 $A$ 的最后一行和 $b$。如果不相等，就不要指望在低马赫区域得到设计阶数。然后用 $\varepsilon=10^{-6}$ 跑一次上面40行左右的Prothero–Robinson测试。如果看不到斜率2，这张表也许是AP，但不是AA。
