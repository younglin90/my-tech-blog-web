## Δt放大20倍，棒的中央降到了零下

一根两端固定为0度的棒，初始温度取 $\sin x$ 形状。这是热方程，答案是确定的。形状不变，振幅按 $e^{-\alpha t}$ 衰减。任何地方都不可能低于0。

FTCS(前向时间、中心空间的显式格式)在 $r=\alpha\Delta t/\Delta x^2$ 超过0.5时就会发散。于是换成号称"无条件稳定显式格式"的DuFort–Frankel。把 $r$ 从0.5调到10，时间步长放大20倍。计算没有发散。但在 $t=1.48$ 时，中央温度变成了 $-0.83$。精确解是 $+0.052$。

本文追查这个负值从何而来。先说结论：在大 $\Delta t$ 下，DuFort–Frankel解的不是热方程，而是阻尼波动方程。读完之后，你可以用一行式子算出这个格式真正的 $\Delta t$ 上限。

## 三种格式，同一根棒

素材来自金文相教授计算流体力学课程的作业HW#2。21个网格点，$\alpha=2$，初始条件 $\sin x$，比较三种格式。

$$
u_i^{n+1}=u_i^n+r\left(u_{i+1}^n-2u_i^n+u_{i-1}^n\right)
$$

这是FTCS。$u_i^n$ 是网格点 $i$、时间层 $n$ 的温度。它最简单，只在 $r\le 1/2$ 时稳定。

DuFort–Frankel从Leapfrog(使用前后两个时间层的中心时间差分)出发。Leapfrog用于扩散时，对任何 $r$ 都不稳定。于是把中心点 $u_i^n$ 换成前后平均 $(u_i^{n+1}+u_i^{n-1})/2$。

$$
(1+2r)\,u_i^{n+1}=(1-2r)\,u_i^{n-1}+2r\left(u_{i+1}^n+u_{i-1}^n\right)
$$

它仍是显式格式，不需要解矩阵。代价是需要三个时间层，第一步必须用别的方法生成。原作业先用FTCS走了一步。

Laasonen是全隐式格式(BTCS)，每一步求解一个三对角矩阵。

$$
-r\,u_{i-1}^{n+1}+(1+2r)\,u_i^{n+1}-r\,u_{i+1}^{n+1}=u_i^n
$$

在下面的模拟中亲手操作一下。左边是DuFort–Frankel放大因子的两个根，右边是一个Fourier模态的振幅如何逐步变化。

## 稳定却出错：放大因子的两个根

代入 $u_i^n=G^n e^{\mathrm{i}\,i\theta}$，得到关于 $G$ 的二次方程。$\theta=k\Delta x$ 是模态在每个网格上的相位。

$$
G_\pm=\frac{2r\cos\theta\pm\sqrt{1-4r^2\sin^2\theta}}{1+2r}
$$

根号内变为负数时，两个根是共轭复数。此时模长与 $\theta$ 无关。

$$
|G_\pm|^2=\frac{2r-1}{2r+1}<1
$$

对任何 $r$ 都小于1。这就是"无条件稳定"的全部含义。但复数 $G$ 不只是缩小模长，它每一步都会旋转相位。振幅以 $\rho^n\cos(n\varphi+\psi)$ 的形式振荡。热方程的模态不会振荡，只会单调衰减。

根变为复数的阈值是 $2r\sin\theta=1$。对基本模态 $\theta=\Delta x=\pi/20$，有 $r^*=1/(2\sin\theta)=3.196$。波长越短，$\sin\theta$ 越大，越早开始振荡。

阈值以下也不安全。$r=2$ 时基本模态的 $|G_+|$ 为0.9462，而精确的每步衰减率是 $e^{-\alpha\Delta t}=0.9518$。每一步多冷却0.6%，60步后累积到30%。

## 修正方程：热方程里藏着波动项

原因在截断误差里。对DuFort–Frankel做Taylor展开，就得到它实际求解的方程(修正方程，modified equation)。

$$
u_t=\alpha u_{xx}-\alpha\left(\frac{\Delta t}{\Delta x}\right)^2u_{tt}+\frac{\alpha\Delta x^2}{12}u_{xxxx}+\cdots
$$

问题出在 $u_{tt}$ 项，其系数是 $(\Delta t/\Delta x)^2$。即使同时缩小 $\Delta t$ 和 $\Delta x$，只要这个比值固定，它就不会消失。DuFort–Frankel只有在 $\Delta t/\Delta x\to 0$ 时才与热方程相容(consistent)。这称为条件相容性。

令 $\lambda=\Delta t/\Delta x$，该方程就是电报方程(telegraph equation，阻尼波动方程)。

$$
\alpha\lambda^2u_{tt}+u_t=\alpha u_{xx}
$$

波速为 $1/\lambda=\Delta x/\Delta t$，即每步一格，恰好是显式格式传递信息的最大速度。代入模态 $e^{\mathrm{i}kx-\sigma t}$ 得 $\alpha\lambda^2\sigma^2-\sigma+\alpha k^2=0$。要使 $\sigma$ 为实数，需要 $4\alpha^2\lambda^2k^2\le 1$，即 $\Delta t\le\Delta x/(2\alpha k)$。换成 $r$ 就是 $r\le 1/(2k\Delta x)=3.18$，与放大因子给出的3.196几乎相同。两种分析指向同一条边界。

## 代码：sin x棒在r = 0.5, 2, 5, 10下

沿用原作业的设置，推进到 $t\approx1.5$。三种格式取相同的 $r$，输出中央温度、最大误差以及计算过程中中央温度的最小值。

```python
import numpy as np

ALPHA, PEAK, NX = 2.0, 1.0, 21          # 与原作业HW#2相同的设置
DX = np.pi / (NX - 1)
X = np.linspace(0.0, np.pi, NX)
T_END = 1.5

def exact_u(t):
    return PEAK * np.exp(-ALPHA * t) * np.sin(X)

def ftcs_heat(u, r):
    v = u.copy()
    v[1:-1] = u[1:-1] + r * (u[2:] - 2 * u[1:-1] + u[:-2])
    return v

def laasonen_heat(u, r):
    n = NX - 2                           # 内部点三对角 (Thomas)
    a = np.full(n, -r); b = np.full(n, 1 + 2 * r); c = np.full(n, -r)
    d = u[1:-1].copy()
    for i in range(1, n):
        m = a[i] / b[i - 1]
        b[i] -= m * c[i - 1]; d[i] -= m * d[i - 1]
    s = np.zeros(n); s[-1] = d[-1] / b[-1]
    for i in range(n - 2, -1, -1):
        s[i] = (d[i] - c[i] * s[i + 1]) / b[i]
    v = np.zeros_like(u); v[1:-1] = s
    return v

def dufort_step(u_old, u, r):
    v = np.zeros_like(u)
    v[1:-1] = ((1 - 2 * r) * u_old[1:-1] + 2 * r * (u[2:] + u[:-2])) / (1 + 2 * r)
    return v

def march_heat(method, r, start="ftcs"):
    dt = r * DX**2 / ALPHA
    nstep = max(2, int(round(T_END / dt)))
    u = PEAK * np.sin(X)
    hist = [u[NX // 2]]
    if method == "dufort":
        u_old = u
        u = ftcs_heat(u, r) if start == "ftcs" else exact_u(dt)
        hist.append(u[NX // 2])
        for _ in range(nstep - 1):
            u_old, u = u, dufort_step(u_old, u, r)
            hist.append(u[NX // 2])
    else:
        step = ftcs_heat if method == "ftcs" else laasonen_heat
        for _ in range(nstep):
            u = step(u, r)
            hist.append(u[NX // 2])
    t = nstep * dt
    err = np.max(np.abs(u - exact_u(t)))
    return t, nstep, u[NX // 2], exact_u(t)[NX // 2], err, np.array(hist)

print(f"dx = {DX:.5f}, r* (DF fundamental mode turns complex) = {1/(2*np.sin(DX)):.3f}")
print(" r     method    steps   t      u_mid     exact     max_err   min(u_mid) over run")
for r in [0.5, 2.0, 5.0, 10.0]:
    for m in ["ftcs", "dufort", "laasonen"]:
        t, n, um, ue, e, h = march_heat(m, r)
        if not np.isfinite(e) or e > 1.0:
            print(f"{r:4.1f}  {m:9s} {n:5d}  {t:5.3f}   BLOWUP (|u|max = {np.max(np.abs(h)):.1e})")
            continue
        print(f"{r:4.1f}  {m:9s} {n:5d}  {t:5.3f}  {um:8.5f}  {ue:8.5f}  {e:.2e}  {h.min():+.4f}")
print()
print("DuFort-Frankel per-step |G| of the fundamental mode vs exact decay per step")
for r in [0.5, 2.0, 3.0, 3.2, 5.0, 10.0]:
    dt = r * DX**2 / ALPHA
    th = DX
    disc = 1 - 4 * r * r * np.sin(th)**2
    G = (2 * r * np.cos(th) + np.sqrt(complex(disc))) / (1 + 2 * r)
    print(f"r = {r:4.1f}  |G| = {abs(G):.4f}  exact = {np.exp(-ALPHA*dt):.4f}  "
          f"phase/step = {np.degrees(np.angle(G)):6.2f} deg")
print()
print("DuFort-Frankel start-up: FTCS first step vs exact first step (r = 5)")
for s in ["ftcs", "exact"]:
    t, n, um, ue, e, h = march_heat("dufort", 5.0, start=s)
    print(f"start = {s:5s}  u_mid = {um:+.5f}  max_err = {e:.3e}")
```

| 稳定条件 | $r\le 1/2$ | 无条件 | 无条件 |
| 相容性 | 无条件 | 仅当 $\Delta t/\Delta x\to0$ | 无条件 |
| 时间精度 | $O(\Delta t)$ | $O(\Delta t^2)$ + $O(\lambda^2)$ | $O(\Delta t)$ |
| 每步开销 | 逐点更新 | 逐点更新，存2层 | 三对角求解 |
| 启动 | 直接开始 | 第一步另算 | 直接开始 |
| $r=0.5$ 最大误差 | 6.15e-04 | 6.15e-04 | 1.23e-03 |
| $r=10$ 中央温度 | 发散 | $-0.827$ | $+0.071$ |
| 失败表现 | 奇偶振荡暴涨 | 安静地振荡到零以下 | 衰减过慢 |

输出中能读出三点。第一，$r=0.5$ 时FTCS与DuFort–Frankel一致到小数点后五位。原作业的平均误差0.8954e-3和0.8976e-3几乎相同，也是这个原因。第二，$r=10$ 时Laasonen的误差为1.95e-02，虽然大，但符号正确。第三，FTCS发散的程度取决于 $r$ 和步数。$r=10$ 只有12步，所以停在6.3。

FTCS藏不住失败，数值一爆炸谁都能发现。DuFort–Frankel的失败是安静的。数值有限，剖面形状仍是 $\sin x$，只有符号错了。即便用验证算例测收敛阶，如果固定 $\Delta t/\Delta x$ 加密网格，这个误差也不会趋于0。这和[收敛阶在不同验证算例中结果不同的故事](/zh/posts/2026-10-07-sod-vortex-order-verification/)是同一个陷阱。

## r = 0.5时两种格式给出相同数字的原因

代入 $r=1/2$，DuFort–Frankel式中的 $(1-2r)u_i^{n-1}$ 项消失。

$$
u_i^{n+1}=\tfrac12\left(u_{i+1}^n+u_{i-1}^n\right)
$$

FTCS取 $r=1/2$ 也正好是这个式子。式子相同，误差自然相同。原作业把DuFort–Frankel的误差解释为"累积所致"。实际上，在 $r=0.5$ 下根本无法观察到两种方法的差别。差别只在 $r>1/2$ 时出现，而这正是选用DuFort–Frankel的理由。

还检查了启动步的影响。$r=5$ 时，第一步用FTCS，中央温度为 $-0.0916$；用精确解，则为 $-0.0902$。正如原作业所观察到的，第一步几乎没有影响。但原因不是误差累积，而是复数根产生的振荡。

这个问题并非扩散独有。单个Courant数压垮格式的边界，在[MSTACS压缩差分的Courant极限](/zh/posts/2026-10-25-mstacs-slope-three-courant-limit/)中也见过。如果目标是大 $\Delta t$，能同时保证精度和稳定性的是隐式格式。对非定常问题，像[双时间步循环](/zh/posts/2026-10-30-dual-time-steady-preconditioner-inner-iterations/)那样接受内迭代通常更好。

## 给DuFort–Frankel设Δt之前要算的比值

先确定需要分辨的最短波长 $\ell$，$k=2\pi/\ell$。然后只需检查这个不等式。

$$
\Delta t\le\frac{\Delta x}{2\alpha k}
$$

越过这条线，该波长的模态就会随时间振荡。即使没越过，$\Delta t/\Delta x$ 大时衰减也会过快。"无条件稳定"只意味着不会发散，并不意味着在解正确的方程。
