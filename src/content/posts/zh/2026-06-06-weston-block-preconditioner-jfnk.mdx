## 这篇论文所处的位置

- **作者**: B. Weston, R. Nourgaliev, J.-P. Delplanque, A. T. Barker (LLNL / UC Davis)
- **期刊**: *Journal of Computational Physics*, **397**, 108847 (2019)
- **标题**: *Preconditioning a Newton-Krylov solver for all-speed melt pool flow physics*
- **一句话**: 用完全隐式 JFNK 求解含相变的全速度（all-speed）可压缩 Navier–Stokes，并以**原始变量块 Schur 补预条件**压住低 Mach 刚性。

常见的预条件 — element-block SOR、monolithic AMG、block Gauss–Seidel — 在时间步或 Mach 走向极端时，迭代次数都会爆炸。论文交出来的是 `vP-vT` Schur 补。物理耦合的块形状被原样抄进预条件矩阵。

## 为何 M 趋零时雅可比矩阵会生病

全速度意味着一套代码从不可压（$M\to 0$）一直解到超音速。麻烦在低 Mach 极限。声波速度 $c$ 与流速 $u$ 之比按 $c/u = 1/M$ 拉开。$M=10^{-3}$ 时，声音比流体快 1000 倍。

走完全隐式，这两个尺度便混进同一个雅可比矩阵。压力–速度耦合块按 $1/M^2$ 增大，矩阵的条件数随之爆炸。Krylov 求解器在特征值散得很开的矩阵上爬行。这就是 GMRES 停不下来的原因。

把 $M$ 按代码里的四个点放下，$\beta=1/M^2$ 立刻出来。$M=1$ 时 $\beta=1$。$M=10^{-1}$ 时 $\beta=10^{2}$。$M=10^{-2}$ 时 $\beta=10^{4}$。$M=10^{-3}$ 时 $\beta=10^{6}$。压力–速度块里的一格放大一百万倍。格点数是 $n=64$，间距 $dx=1/64$，四种情况都一样。矩阵规模也停在 $2n=128$。变的只是乘上 $\beta$ 之后的谱。

用声学 CFL 去卡时间步，就是 $\Delta t \propto M\Delta x$。$M$ 从 1 降到 $10^{-3}$，允许的步长缩成千分之一。完全隐式解开这个限制，把条件数交给 $\beta$。同一份刚性被预条件反向放大的地方，写在[声速 CFL 为 10 的块预条件](/zh/posts/2026-08-29-block-preconditioner-acoustic-cfl-loop-gain/)里。

JFNK（Jacobian-Free Newton–Krylov）从不显式构造雅可比矩阵，只用 Fréchet 差分近似矩阵–向量积。

$$
J\boldsymbol{\kappa} \approx \frac{F(x + h\boldsymbol{\kappa}) - F(x)}{h}
$$

$F$ 是非线性残差，$\boldsymbol{\kappa}$ 是 Krylov 向量，$h$ 是一个小的有限数。不存矩阵，内存就少一块。没有预条件时，低 Mach 下这个差分就在散开的特征值上往前爬。

## 弃保守变量，转向原始变量 $(P,v,T)$

第一步是换变量。不用保守变量 $U=(\rho, \rho v, E)$，改解原始变量 $W=(P, v, T)$，因为低 Mach 下原始变量的条件数好得多。

$$
\frac{\partial F(x)}{\partial U}\frac{\partial U}{\partial W}\,\delta W = -F(x)
$$

$\partial U/\partial W$ 是变量变换雅可比。残差 $F$ 仍按满足守恒律来书写，因此**只换变量并不破坏质量、动量与能量守恒**。接着把自由度按场归并，排成 $3\times3$ 块矩阵。

$$
M = \begin{bmatrix} M_{vv} & M_{vP} & M_{vT} \\ M_{Pv} & M_{PP} & M_{PT} \\ M_{Tv} & M_{TP} & M_{TT} \end{bmatrix}
$$

每个块对应一个原始场（速度、压力、温度）。这个排列是下一步分解的踏板。

## 块 LU 与速度–压力 Schur 补

压力–温度耦合（$M_{PT}, M_{TP}$）很弱。把两者丢掉，块 LU 分解就变得干净，剩下的核是**速度–压力 Schur 补**。

$$
S_{vP} = M_{PP} - M_{Pv}\,M_{vv}^{-1}\,M_{vP}
$$

$S_{vP}$ 是消去速度之后只剩压力的有效方程，与 SIMPLE 家族的压力修正方程同一骨架。把预条件 $P$ 取成这种块上三角形式，$P^{-1}A$ 的特征值便聚到 1 附近。用精确的 $S$ 时，$A=LU$ 的 $U$ 恰好等于 $P$，于是 $P^{-1}A$ 与一个幂零（unipotent）下三角相似，**所有特征值都精确为 1**。GMRES 两三步就结束。

这两三步和停机条件扣在一起。下面代码的容差是 `rtol=1e-8`，迭代上限是 `maxiter=500`，restart 长度是 `2n=128`。特征值聚到一点，Krylov 子空间两步就关上。聚不拢，就会先撞上 500 次的上限。

## Python — 随 Mach 下降数 GMRES 迭代次数

去掉温度，用 2 场 $(v,P)$ 的 toy 只重现核心。块系统为 $A=\begin{bmatrix} I & \beta G \\ D_v & I\end{bmatrix}$，$\beta=1/M^2$。预条件是精确 Schur 补 $S=I-\beta D_v G$。

```python
import numpy as np
from scipy.sparse import diags, eye, bmat
from scipy.sparse.linalg import gmres, LinearOperator, splu

n = 64
dx = 1.0 / n

def fwd_diff():
    # 周期边界前向差分 (压力梯度算子)
    D = diags([-1.0, 1.0], [0, 1], shape=(n, n)).tolil()
    D[-1, 0] = 1.0
    return (D / dx).tocsr()

G = fwd_diff()
Dv = (-G.T).tocsr()          # 散度 = -G^T  ->  Dv*G ~ 拉普拉斯

def all_speed_system(M):
    beta = 1.0 / M**2        # 低 Mach 刚性系数
    A = bmat([[eye(n), beta * G], [Dv, eye(n)]]).tocsr()
    return A, beta

def schur_preconditioner(beta):
    # 速度-压力 Schur 补 S = M_PP - M_Pv M_vv^{-1} M_vP = I - beta Dv G
    S = (eye(n) - beta * (Dv @ G)).tocsc()
    luS = splu(S)
    def apply(r):
        ru, rp = r[:n], r[n:]
        zp = luS.solve(rp)               # S z_p = r_p
        zu = ru - beta * (G @ zp)        # z_u = r_u - beta G z_p
        return np.concatenate([zu, zp])
    return LinearOperator((2 * n, 2 * n), matvec=apply)

def count_iters(M, use_prec):
    A, beta = all_speed_system(M)
    b = np.random.default_rng(0).standard_normal(2 * n)
    P = schur_preconditioner(beta) if use_prec else None
    it = {"k": 0}
    x, info = gmres(A, b, M=P, rtol=1e-8, maxiter=500, restart=2 * n,
                    callback=lambda xk: it.__setitem__("k", it["k"] + 1))
    return it["k"]

print(f"{'Mach':>8}  {'no-prec':>8}  {'Schur':>6}")
for M in [1.0, 1e-1, 1e-2, 1e-3]:
    print(f"{M:>8.0e}  {count_iters(M, False):>8d}  {count_iters(M, True):>6d}")
```

没有预条件时，$M$ 越小，迭代次数越爬到几十、几百，到 $M=10^{-3}$ 时连 500 次的上限都进不去。Schur 这边把 $S=I-\beta D_v G$ 用 LU 解一次，GMRES 两三步就把残差降到 1e-11。$M=1$（$\beta=1$）和 $M=10^{-3}$（$\beta=10^{6}$）的 Schur 迭代次数相同，这就是特征值聚在 1 的数字。

## 亲手编写时存疑的三件事

**精确的 $S$ 只在 toy 里免费。** 这里用 LU 精确求解 $S=I-\beta D_v G$，两步收敛。实战中 $S_{vP}=M_{PP}-M_{Pv}M_{vv}^{-1}M_{vP}$ 里的 $M_{vv}^{-1}$ 是稠密逆，根本无法构造。论文用近似求解 $S$（例如一次 AMG V-cycle），而该近似的质量决定了外层迭代次数。迭代次数不随 Mach 粘住的代价，就藏在这里。

**耦合丢到何处为止。** 论文称丢掉 $M_{PT}, M_{TP}$ 不损鲁棒性。这是对着熔池物性做的假设。在强可压缩热耦合（爆燃、燃烧）里，同样的截断可能让收敛停住。预条件要不要简化，由物理决定。

**JFNK 的 Fréchet 差分 $h$。** $h$ 太小，舍入误差进来；$h$ 太大，截断误差污染矩阵–向量积。预条件再好，$h$ 调偏，Newton 也会停滞。从 OpenFOAM 的分离式（SIMPLE）转向完全耦合隐式时，最先碰到的就是这里。

## 收束 — 预条件并非免费

GMRES 在 1000 次、残差 1e-2 停下的那个夜晚，并没有因为更用力地解雅可比而结束。预条件得照搬耦合结构本身。Schur 补是消去速度之后的压力方程，精确求解就把特征值聚到 1。实战里 $S_{vP}$ 中的 $M_{vv}^{-1}$ 是稠密的，论文用一次 AMG V-cycle 做近似。近似一粗，外层迭代就从两三步重新拉开。

不存雅可比、只留矩阵–向量积的岔路，和[运算符重载自动微分](/zh/posts/2026-07-05-adoo-automatic-differentiation-jacobian/)接在一起。JFNK 用 Fréchet 差分 $h$ 替换那个乘积。$h$ 一偏，预条件再好，Newton 也停在原地。下一步在同一个 toy 上用 AMG 把 $S$ 解松，看外层迭代离开两三步有多远。
