## 还没运行FlameMaster，手算就差了458 K

2018年夏天，我第一次安装了FlameMaster(层流火焰面计算程序)。为了验证结果，我先手算了绝热火焰温度。化学计量甲烷–空气得到2783 K。程序给出的是2200 K出头。我以为程序错了，翻了很久输入文件。错的其实是手算。

原因在比热。手算时我一路用的是298 K的cp(定压比热)。程序用的是`gri.30.therm`文件里的温度多项式。本文说明这个多项式是什么、怎样从文件中读取。然后用两种方式求解同一个能量平衡，用数字说明458 K的差距从何而来。

## 绝热火焰温度就是面积匹配

绝热火焰温度(adiabatic flame temperature)指无热损失燃烧时产物达到的温度。反应释放的热$Q$全部用于加热产物。写成式子是$Q = \int_{T_0}^{T_{ad}} C_p(T)\,dT$。其中$C_p$是全部产物的热容。

从图上看，$C_p(T)$曲线下的面积等于$Q$的位置就是$T_{ad}$。$C_p$为常数时，面积是矩形。$C_p$随温度增大时，同样的面积在更短的区间内就能填满。下面的模拟可以直接动手操作。

热量累积时，蓝色面积(NASA多项式)和红色矩形(常温cp)以相同速度扩大。但蓝色曲线在1000 K之后继续上升。所以蓝色端点先停下来。打开按组分堆叠，可以看到差距大部分来自H₂O和CO₂两条带。降低φ(当量比)，N₂和剩余O₂的比重变大，差距随之缩小。

## 1971年，热力学表缩成了14个系数

1960年代的火箭推进剂计算使用JANAF热化学表。那是按温度列出cp、h、s的厚厚一本表。要用计算机求解平衡，就得对表格插值。NASA Lewis研究中心的Gordon和McBride把它换成了多项式。1971年报告NASA SP-273中整理的形式，就是今天的7系数多项式。

每个组分的温度范围分成两段，通常是300–1000 K和1000–5000 K。每段7个系数，所以每个组分14个。1980年代，Sandia的CHEMKIN采用了这一格式。此后GRI-Mech、Cantera、FlameMaster都直接读取同样的文件。2002年出现了分段更多的9系数格式。不过大多数燃烧反应机理文件仍是7系数。

## 推导：一个cp多项式给出h和s

起点只有cp。

$$
\frac{c_p}{R} = a_1 + a_2 T + a_3 T^2 + a_4 T^3 + a_5 T^4
$$

$R$为气体常数，$a_1$–$a_5$为该区间的系数。对$dh = c_p\,dT$积分得到焓。积分常数就是$a_6$。

$$
\frac{h}{RT} = a_1 + \frac{a_2}{2}T + \frac{a_3}{3}T^2 + \frac{a_4}{4}T^3 + \frac{a_5}{5}T^4 + \frac{a_6}{T}
$$

$a_6$中包含生成焓(由参考状态的元素生成该组分时的焓)。因此计算H₂O的$h(298.15\,\text{K})$会得到−241.8 kJ/mol。熵由$ds = c_p\,dT/T$积分得到，积分常数为$a_7$。

$$
\frac{s^\circ}{R} = a_1 \ln T + a_2 T + \frac{a_3}{2}T^2 + \frac{a_4}{3}T^3 + \frac{a_5}{4}T^4 + a_7
$$

$s^\circ$是标准压力1 bar下的熵，用于计算平衡常数。绝热火焰温度只需要$h$。

### thermo文件中一个组分占四行

原始笔记的第一步是`CreateBinFile -i gri.30.therm -m gri.30.trans`。这条命令读取的`.therm`文件是80列定宽格式。每个组分占四行。

- 第1行：组分名、元素组成、相态(G)，以及$T_{low}$、$T_{high}$、$T_{mid}$
- 第2行：**高温段**$a_1$–$a_5$
- 第3行：高温$a_6$、$a_7$，低温$a_1$–$a_3$
- 第4行：低温$a_4$–$a_7$

高温系数排在前面。自己写解析器时很容易把顺序弄反。弄反之后会在常温下使用高温多项式，结果悄无声息地出错。$T_{mid}$也可能因组分而异，需要读取第1行第66–73列。把1000 K写死，混用不同来源的数据时就会出问题。

## 代码：用两种比热求解同一个平衡

假设甲烷–空气贫燃。忽略离解，只考虑完全燃烧。反应式为$\text{CH}_4 + \tfrac{2}{\phi}(\text{O}_2 + 3.76\,\text{N}_2) \to \text{CO}_2 + 2\text{H}_2\text{O} + 2(\tfrac{1}{\phi}-1)\text{O}_2 + \tfrac{7.52}{\phi}\text{N}_2$。要解的方程如下。

$$
f(T) = H_\text{prod}(T) - H_\text{reac}(T_0) = 0, \qquad T^{k+1} = T^k - \frac{f(T^k)}{C_{p,\text{prod}}(T^k)}
$$

$f$的导数恰好就是$C_p$，因此Newton迭代很自然。系数直接取自GRI-Mech 3.0的`.therm`文件。

```python
# 取自gri.30.therm的NASA 7系数: (T_mid, 低温 a1..a7, 高温 a1..a7)
NASA = {
 "CH4": (1000., [5.14987613E+00,-1.36709788E-02,4.91800599E-05,-4.84743026E-08,1.66693956E-11,-1.02466476E+04,-4.64130376E+00],

 "O2":  (1000., [3.78245636E+00,-2.99673416E-03,9.84730201E-06,-9.68129509E-09,3.24372837E-12,-1.06394356E+03,3.65767573E+00],
                [3.28253784E+00,1.48308754E-03,-7.57966669E-07,2.09470555E-10,-2.16717794E-14,-1.08845772E+03,5.45323129E+00]),
 "N2":  (1000., [3.298677E+00,1.4082404E-03,-3.963222E-06,5.641515E-09,-2.444854E-12,-1.0208999E+03,3.950372E+00],
                [2.92664E+00,1.4879768E-03,-5.68476E-07,1.0097038E-10,-6.753351E-15,-9.227977E+02,5.980528E+00]),
 "CO2": (1000., [2.35677352E+00,8.98459677E-03,-7.12356269E-06,2.45919022E-09,-1.43699548E-13,-4.83719697E+04,9.90105222E+00],
                [3.85746029E+00,4.41437026E-03,-2.21481404E-06,5.23490188E-10,-4.72084164E-14,-4.87591660E+04,2.27163806E+00]),
 "H2O": (1000., [4.19864056E+00,-2.03643410E-03,6.52040211E-06,-5.48797062E-09,1.77197817E-12,-3.02937267E+04,-8.49032208E-01],
                [3.03399249E+00,2.17691804E-03,-1.64072518E-07,-9.70419870E-11,1.68200992E-14,-3.00042971E+04,4.96677010E+00]),
}
R = 8.314462618  # J/(mol K)

def coeffs(sp, T):
    tm, lo, hi = NASA[sp]
    return lo if T < tm else hi

def cp_R(sp, T):
    a = coeffs(sp, T)
    return a[0] + a[1]*T + a[2]*T**2 + a[3]*T**3 + a[4]*T**4

def h_RT(sp, T):
    a = coeffs(sp, T)
    return a[0] + a[1]*T/2 + a[2]*T**2/3 + a[3]*T**3/4 + a[4]*T**4/5 + a[5]/T

def mixture(phi):
    # CH4 + (2/phi)(O2 + 3.76 N2) -> CO2 + 2 H2O + 2(1/phi-1) O2 + 7.52/phi N2  (phi<=1)
    reac = {"CH4": 1.0, "O2": 2/phi, "N2": 7.52/phi}
    prod = {"CO2": 1.0, "H2O": 2.0, "O2": 2*(1/phi - 1), "N2": 7.52/phi}
    return reac, prod

def H(mix, T, frozen_cp=False):
    # 混合物焓 [J]; frozen_cp=True时始终使用298 K比热
    if frozen_cp:
        return sum(n*R*(h_RT(s, 298.15)*298.15 + cp_R(s, 298.15)*(T-298.15)) for s, n in mix.items())
    return sum(n*R*T*h_RT(s, T) for s, n in mix.items())

def Cp(mix, T, frozen_cp=False):
    Tc = 298.15 if frozen_cp else T
    return sum(n*R*cp_R(s, Tc) for s, n in mix.items())

def flame_newton(phi, frozen_cp=False, T0=1500.0, tol=1e-6):
    reac, prod = mixture(phi)
    Hr = H(reac, 298.15)
    T, it = T0, 0
    while True:
        f = H(prod, T, frozen_cp) - Hr
        dT = -f / Cp(prod, T, frozen_cp)
        T += dT; it += 1
        if abs(dT) < tol: return T, it

print("species  h(298)/kJ/mol  cp(298)/R  cp(2000)/R  jump@1000K(cp/R)")
for s in NASA:
    jump = cp_R(s, 1000.0) - cp_R(s, 999.999999)
    print(f"{s:5s} {h_RT(s,298.15)*R*298.15/1000:12.2f} {cp_R(s,298.15):10.3f} {cp_R(s,2000.):11.3f} {jump:+14.2e}")

print("\nphi   T_ad(NASA)  iters  T_ad(cp298)  iters  overshoot")
for phi in [0.5, 0.6, 0.7, 0.8, 0.9, 1.0]:
    Tn, itn = flame_newton(phi)
    Tf, itf = flame_newton(phi, frozen_cp=True)
    print(f"{phi:.1f} {Tn:10.1f} {itn:5d} {Tf:11.1f} {itf:5d} {Tf-Tn:+9.1f}")

reac, prod = mixture(1.0)
Tn, _ = flame_newton(1.0)
cpm = (H(prod, Tn) - H(prod, 298.15)) / (Tn - 298.15)
print(f"\nphi=1: mean cp of products = {cpm/Cp(prod,298.15):.3f} x cp(298)")
```

## 读数字：1.226、458，还有2

先看第一张表里的$h(298)$是否与文献一致：CO₂ −393.51、H₂O −241.82、CH₄ −74.60 kJ/mol。抄写系数时的笔误在这里立刻暴露。1000 K处低温段与高温段cp之差小于$10^{-6}$。GRI数据在$T_{mid}$处经过拟合保证连续。

cp的温度依赖性因组分而异。从298 K到2000 K，N₂上升24%，H₂O上升54%，CO₂上升63%。CH₄是2.8倍。对全部产物平均，是298 K值的1.226倍。需要升高的温度幅度也就缩短了同样的倍数。$(2783.4 - 298)/(2325.6 - 298) = 1.226$正是这个比值。

高估幅度随φ增大。φ = 0.5时154 K，φ = 1时458 K。火焰越热，经过cp大幅上升的区间就越长。常温cp一侧总是2次迭代。它的$f(T)$是直线，第一次Newton就落到根上。第二次只是确认。

这个2325.6 K也不是真实值。超过2000 K后，CO₂和H₂O会部分离解为CO、H₂、OH。离解是吸热的。做平衡计算，化学计量甲烷–空气约为2225 K，又低了100 K。要计入离解就需要平衡常数，这时就要用到$s^\circ$和$a_7$。

## 这个多项式如今用在哪里

FlameMaster笔记的下一步是用`ScanMan`读取反应机理。逆反应速率常数由平衡常数计算。而平衡常数又来自这个多项式的$h$和$s$。热力学数据出错，污染的不只是温度，还有反应速率。逆反应常数的计算在[讨论平衡常数单位的文章](/zh/posts/2026-10-22-reverse-rate-kp-kc-unit-dissociation/)中有详细介绍。

火焰面库(flamelet library)也是一样。FlameMaster生成的温度表经β-PDF积分后进入湍流燃烧模型。表中温度差几百K，平均温度也差同样多。积分过程见[presumed β-PDF一文](/zh/posts/2026-10-27-presumed-beta-pdf-mean-flame-temperature/)。这部分热量在燃烧室内如何改变可压缩流动，见[Rayleigh流动与热壅塞](/zh/posts/2026-11-17-rayleigh-flow-thermal-choking-combustor/)。

CFD程序求解组分输运方程时同样如此。每个网格单元都要由$h$反求$T$。上面代码中的Newton迭代在每个单元、每个时间步都要运行。所以商用程序会预先把系数做成表格。

## 拿到新机理文件时先手算核对的三个数

拿到新的反应机理，先打开`.therm`。计算主要产物的$h(298)$，与文献值对照。检查cp在$T_{mid}$处是否连续。最后用几次Newton迭代求完全燃烧绝热火焰温度，与程序结果比较。如果程序结果低100 K左右，那是离解的作用。如果差距超过400 K，说明某处藏着常温cp。
