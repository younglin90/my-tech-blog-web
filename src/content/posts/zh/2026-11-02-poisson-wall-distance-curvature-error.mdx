## 离圆柱一个半径远的点，壁面距离是多少

答案显然是 $a$。可是商用求解器的“PDE 壁距离”选项在这个点给出 $1.38a$。在球旁边测同样的距离得到 $2.0a$，在管内中心得到 $0.71a$。本文追踪这些数字的来源。从 1994 年 Spalding 的想法出发，推导曲率误差公式 $d \approx y(1+\kappa y/2)$。最后用一维径向实验验证这个公式。读完之后，你可以用一句话判断 PDE 壁距离能信到什么程度。

壁面距离（wall distance，单元中心到最近无滑移壁面的距离）是湍流模型的必需输入。Spalart–Allmaras 的耗散项正比于 $(\tilde\nu/d)^2$。SST 的混合函数和两层模型也要用 $d$。精确距离的求法已在 [Eikonal 方程与 Fast Marching 一文](/zh/posts/2026-04-22-wall-distance-eikonal-fast-marching/)中讨论过。今天看一种更老、更简单的方法。

## 1994 年，用热传导测距离

Spalding 当时在算杂乱室内空间（“cluttered spaces”）的湍流换热。用几何方法逐个求到大量障碍物的距离，对当年的计算机是沉重负担。于是他用了手头现成的工具：扩散方程求解器。求解一个壁面温度为 0、内部有均匀热源的稳态导热问题。温度越高，离壁越远，这就是直觉。

STAR-CCM+ 理论指南原样写下了这一点。

$$
\nabla^2 \phi = -1, \qquad \phi = 0 \ \text{on } \Gamma_w, \qquad \nabla\phi\cdot\mathbf{n} = 0 \ \text{on } \Gamma_o
$$

$\phi$ 是与距离相关的辅助变量，$\Gamma_w$ 是壁面，$\Gamma_o$ 是其他边界，$\mathbf{n}$ 是边界法向。距离由下式恢复。

$$
d = -|\nabla\phi| + \sqrt{|\nabla\phi|^2 + 2\phi}
$$

同一份指南把两种方法并列。Implicit Tree 是对表面三角形的精确投影，PDE 被描述为“更快但近似”。近似到什么程度，并没有写。

## 为什么一维时是精确的

考虑一块平板和高度 $H$ 处的对称边界。$\phi'' = -1$、$\phi(0)=0$、$\phi'(H)=0$ 的解为：

$$
\phi(y) = Hy - \frac{y^2}{2}, \qquad \phi'(y) = H - y
$$

$y$ 是离壁距离。从两式中消去 $H$，得到 $\phi = y\,\phi' + y^2/2$。这是关于 $y$ 的二次方程，它的正根正是上面的恢复公式。也就是说，恢复公式是假设“局部一维抛物线剖面”后反推出来的。只要这个假设成立，不论 $H$ 多大都精确得到 $d=y$。两壁之间的通道中，代入 $\phi = y(L-y)/2$ 也精确得到 $d=\min(y, L-y)$。

## 曲面上哪里出了问题

在圆柱外（$r \ge a$），拉普拉斯算子多出 $\phi'/r$ 项。径向方程为 $\phi'' + (k/r)\phi' = -1$，$k$ 为 0（平板）、1（圆柱）、2（球）。外边界 $R$ 处施加 Neumann 条件的圆柱解为：

$$
\phi = \frac{R^2}{2}\ln\frac{r}{a} - \frac{r^2-a^2}{4}, \qquad \phi' = \frac{R^2}{2r} - \frac{r}{2}
$$

当 $R \gg r$ 时 $\phi'^2 \gg 2\phi$，因此 $d \approx \phi/\phi' \approx r\ln(r/a)$。用 $y=r-a$ 展开：

$$
d \approx y\left(1 + \frac{k\,y}{2a}\right)
$$

球同理得到 $d \approx r(r-a)/a = y(1+y/a)$，与 $k=2$ 吻合。$k/a$ 是壁面主曲率之和 $\kappa$（凸为正）。原因很简单。凸面外侧等值线发散，通量被稀释，$\phi'$ 比一维抛物线衰减得更快。恢复公式把这种衰减读成“离壁更远”。凹面则相反，通量汇聚，距离被读短。管内中心代入 $\phi = (a^2-r^2)/4$，精确得到 $d = a/\sqrt2 \approx 0.707a$。

## 代码：平板、圆柱、球、管内的径向一维计算

用 160 个节点离散径向方程，用 SOR（Successive Over-Relaxation，加权 Gauss–Seidel）求解。外边界用虚拟节点施加 Neumann 条件。由恢复公式求出 $d$ 后，输出离壁 $y=0.1, 0.5, 1.0$ 处的 $d_{PDE}/y$。

```python
import math

def poisson_phi(k, r0, r1, wall_at_r1, n, tol=1e-9):
    """用 SOR 求解 phi'' + (k/r) phi' = -1。壁面(phi=0)在一端，另一端 dphi/dr=0。"""
    h = (r1 - r0) / n
    r = [r0 + i * h for i in range(n + 1)]
    phi = [0.0] * (n + 1)
    omega = 2.0 / (1.0 + math.sin(math.pi / (2 * n)))
    wall = n if wall_at_r1 else 0
    for it in range(1, 200001):
        dmax = 0.0
        for i in range(n + 1):
            if i == wall:
                continue
            if i == 0 and r[0] == 0.0:          # 管中心: (1+k) phi'' = -1
                new = phi[1] + h * h / (2.0 * (1 + k))
            elif i == 0 or i == n:              # 外边界 Neumann (ghost = 内侧相邻点)
                j = 1 if i == 0 else n - 1
                new = phi[j] + 0.5 * h * h
            else:
                c = k * h / (2.0 * r[i])
                new = 0.5 * ((1 - c) * phi[i - 1] + (1 + c) * phi[i + 1] + h * h)
            du = omega * (new - phi[i])
            phi[i] += du
            dmax = max(dmax, abs(du))
        if dmax < tol * max(phi[0], phi[n]):
            return r, phi, it
    return r, phi, it

def spalding_d(r, phi):
    """d = -|grad phi| + sqrt(|grad phi|^2 + 2 phi)"""
    n = len(r) - 1
    h = r[1] - r[0]
    d = []
    for i in range(n + 1):
        if i == 0:
            g = (-3 * phi[0] + 4 * phi[1] - phi[2]) / (2 * h)
        elif i == n:
            g = (3 * phi[n] - 4 * phi[n - 1] + phi[n - 2]) / (2 * h)
        else:
            g = (phi[i + 1] - phi[i - 1]) / (2 * h)
        g = abs(g)
        d.append(-g + math.sqrt(g * g + 2 * max(phi[i], 0.0)))
    return d

def ratio_at(r, d, wall_r, y):
    """离壁 y 处的 d_PDE / d_exact (线性插值)"""
    target = wall_r + y if r[0] == wall_r else wall_r - y
    for i in range(len(r) - 1):
        lo, hi = sorted((r[i], r[i + 1]))
        if lo <= target <= hi:
            t = (target - r[i]) / (r[i + 1] - r[i])
            return (d[i] + t * (d[i + 1] - d[i])) / y
    return float('nan')

a = 1.0
cases = [  # (名称, k, r0, r1, 壁在 r1 侧?)
    ("flat  H=5", 0, a, a + 5, False),
    ("cyl   R=2", 1, a, 2.0, False),
    ("cyl   R=5", 1, a, 5.0, False),
    ("cyl   R=20", 1, a, 20.0, False),
    ("sph   R=5", 2, a, 5.0, False),
    ("sph   R=20", 2, a, 20.0, False),
    ("pipe  inside", 1, 0.0, a, True),
]
ys = [0.1, 0.5, 1.0]
print(f"{'case':<13}{'k':>3}{'N':>5}{'SOR it':>8}" + "".join(f"{'y='+str(y):>9}" for y in ys))
for name, k, r0, r1, wall_hi in cases:
    n = 160
    r, phi, it = poisson_phi(k, r0, r1, wall_hi, n)
    d = spalding_d(r, phi)
    wall_r = r1 if wall_hi else r0
    row = [ratio_at(r, d, wall_r, y) for y in ys]
    print(f"{name:<13}{k:>3}{n:>5}{it:>8}" + "".join(f"{v:>9.3f}" for v in row))

print("\nnear-wall model d/y = 1 + k*y/(2a):", "  ".join(
    f"k={k}: " + "/".join(f"{1 + k * y / (2 * a):.3f}" for y in ys) for k in (1, 2)))
```

## 1.38、2.00、0.71 说明了什么

平板在所有 $y$ 处都是 1.000，与一维推导一致。圆柱在 $y=0.1a$ 处为 1.05，与模型 $1+y/2a$ 吻合。在 $y=a$ 处为 1.38，小于模型的 1.50，因为在这个距离二阶展开已经失效。球几乎完全沿着 $1+y/a$，在 $y=a$ 处达到 2.0。

外边界 $R$ 也会改变结果。精确的壁距离与外部盒子大小无关。但 Poisson 解依赖于直到 Neumann 边界的整个区域。$R=2$ 圆柱在 $y=a$ 处的 1.128，并非曲率误差小，而是边界太近带来的“偶然精度”。

迭代次数也值得看。平板 1,006 次，球 $R=20$ 为 22,189 次。球外区域大部分是 $\phi$ 很大的远场，Neumann 边界一侧的误差衰减很慢。“PDE 更快”的前提是线性求解器足够好。实际求解器用的是[多重网格](/zh/posts/2026-05-06-multigrid-v-cycle-poisson-acceleration/)而不是 SOR。

## 如今 PDE 壁距离怎么用

尽管如此，这个方法存活了下来。原因在于湍流模型使用 $d$ 的方式。SA 耗散项 $(\tilde\nu/d)^2$ 在近壁处大，离壁后迅速消失。若第一层网格 $y^+ \sim 1$，近壁的 $y$ 比曲率半径小几千倍。那里的误差 $\kappa y/2$ 不到 0.1%。

问题出在曲率半径与边界层厚度相当的地方：细导线、翼型后缘、叶尖间隙。若圆柱在 $y=a$ 处 $d$ 偏大 1.38 倍，SA 耗散就变为 $1/1.38^2 \approx 0.52$ 倍。在凹角内侧则相反，耗散被放大。

也有改进版本。Tucker 一系的方法使用 $p$-Poisson（$\nabla\cdot(|\nabla\phi|^{p-2}\nabla\phi)=-1$），当 $p\to\infty$ 时逼近 Eikonal 方程。也有直接求解 Hamilton–Jacobi 形式的方法。在非结构网格上，$\nabla\phi$ 本身还取决于[非正交修正](/zh/posts/2026-07-01-non-orthogonal-diffusion-correction/)的质量。

## 把壁距离选项切到 PDE 之前要看的一个值

找出网格中最小的曲率半径 $a_{min}$。再估计其附近湍流模型对 $d$ 敏感的高度，大致是边界层厚度 $\delta$。若 $\delta/a_{min}$ 小于 0.1，PDE 壁距离误差在 5% 以内。超过 0.5 时，类球形状可能偏差 50%。这时换用 Implicit Tree 或 Eikonal 类方法更稳妥。
