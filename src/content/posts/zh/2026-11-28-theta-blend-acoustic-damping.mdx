## 越稳定,声波消失得越多

隐式方法(implicit method)即使加大时间步长也不会发散。所以低马赫可压缩求解器会隐式处理声学项。可是最稳定的后向欧拉(Backward Euler, BE)会悄悄抹掉声波。我们的可压缩多相代码在声学反射算例中正是如此。反射波振幅小了约23%。本文把 Dimarco、Loubère、Michel-Dansac、Vignal(2017)的 IMEX-TVD 思路缩成一维并复现。读完后,你能用数字解释为什么要逐单元混合 BE 与 Crank–Nicolson(CN),以及这种做法在哪里失效。

## 一个傅里叶模态每步损失什么

最简单的模型是线性对流 $u_t + u_x = 0$。一维声学系统的黎曼不变量(沿特征线保持不变的量)$p + \rho c\,u$ 恰好满足这个方程。因此可以把一列声波当作对流来看。

θ 格式在当前时刻与下一时刻之间对空间通量做加权平均。

$$
u_i^{n+1} - u_i^n + \nu\left[\theta\,\delta F^{n+1} + (1-\theta)\,\delta F^{n}\right]_i = 0
$$

$\nu = c\Delta t/\Delta x$ 是声学 CFL 数,$\delta F$ 是中心面通量之差。$\theta = 1$ 为 BE,$\theta = 1/2$ 为 CN。

代入波数为 $\kappa = k\Delta x$ 的模态,就得到单步放大因子。

$$
|G|^2 = \frac{1 + (1-\theta)^2 s^2}{1 + \theta^2 s^2}, \qquad s = \nu \sin\kappa
$$

$\theta = 1/2$ 时分子分母相等,$|G| = 1$,振幅毫无损失。$\theta = 1$ 时 $|G| = 1/\sqrt{1+s^2}$,每步都在缩小。单步损失虽小,累积几百步就很可观。

## 为什么 CN 也不是答案

CN 保持振幅,但色散(不同波长传播速度不同的现象)原样保留。短波走得慢。光滑的高斯脉冲几乎不受影响。台阶形脉冲则不同。台阶含有大量短波,它们落后时会留下波纹。这就是吉布斯振荡(Gibbs oscillation)。

BE 对短波衰减很强,所以台阶附近保持单调。BE 属于 TVD(total variation diminishing,总变差不增加)一侧。两种格式的优缺点恰好相反。

## 论文的思路:逐单元选取 θ

Dimarco 等(2017)在低马赫欧拉方程中处理了这个问题。一阶隐式解满足 TVD,但耗散大。二阶解精确,但会振荡。论文用限制器逐单元混合二者,同时追求二阶精度和 TVD。

本文把这一思路缩减为一个 θ。由当前解 $u^n$ 计算斜率比 $r_i$,再用 minmod 截断。

$$
\phi_i = \max\!\left(0, \min(1, r_i)\right), \qquad \theta_i = 1 - \tfrac{1}{2}\phi_i
$$

$r_i = (u_i - u_{i-1})/(u_{i+1} - u_i)$ 是左右两侧斜率之比。光滑处 $r_i \approx 1$,于是 $\theta_i = 1/2$(CN)。间断或极值处 $r_i \le 0$,于是 $\theta_i = 1$(BE)。面 $i+1/2$ 取两侧单元中较大的 θ。

θ 由 $u^n$ 确定,所以方程组仍是线性的,不需要牛顿迭代。这与 [Thomann–Iollo–Puppo 松弛格式](/zh/posts/2026-11-22-jin-xin-relaxation-linear-implicit-pressure/)的目标相同。由于写成面通量形式,质量也守恒到机器精度。

## 代码:让高斯和台阶各绕一圈

把周期区间 $[0,1]$ 分成 200 个单元。用三种格式把高斯脉冲和台阶脉冲恰好对流一圈。精确解就是初始形状。高斯看最大值,台阶看最大值和最小值。

```python
import numpy as np

N = 200                      # cells on periodic [0, 1]
dx = 1.0 / N
x = (np.arange(N) + 0.5) * dx

def face_theta(u, mode):
    """theta at face i+1/2: 1 = Backward Euler, 1/2 = Crank-Nicolson"""
    if mode == "BE":
        return np.ones(N)
    if mode == "CN":
        return np.full(N, 0.5)
    # BLEND: minmod smoothness ratio from u^n
    dm = u - np.roll(u, 1)
    dp = np.roll(u, -1) - u
    r = dm / np.where(np.abs(dp) < 1e-12, 1e-12, dp)
    phi = np.clip(np.minimum(1.0, r), 0.0, 1.0)   # 1 smooth, 0 jump/extremum
    th = 1.0 - 0.5 * phi
    return np.maximum(th, np.roll(th, -1))        # take the safer neighbor

def theta_step(u, nu, mode):
    """one implicit step of u_t + u_x = 0, central face flux, per-face theta"""
    tp = face_theta(u, mode)          # face i+1/2
    tm = np.roll(tp, 1)               # face i-1/2
    i = np.arange(N)
    A = np.eye(N)
    A[i, i] += 0.5 * nu * (tp - tm)
    A[i, (i + 1) % N] += 0.5 * nu * tp
    A[i, (i - 1) % N] -= 0.5 * nu * tm
    f = 0.5 * (u + np.roll(u, -1))    # explicit part of face flux
    rhs = u - nu * ((1 - tp) * f - (1 - tm) * np.roll(f, 1))
    return np.linalg.solve(A, rhs)

gauss = np.exp(-((x - 0.5) / 0.08) ** 2)
square = np.where(np.abs(x - 0.5) < 0.15, 1.0, 0.0)

print(" nu  scheme  gauss_peak  square_max  square_min   mass")
for nu in (0.5, 1.0, 2.0):
    steps = int(round(N / nu))        # exactly one lap around the box
    for mode in ("BE", "CN", "BLEND"):
        g, s = gauss.copy(), square.copy()
        for _ in range(steps):
            g = theta_step(g, nu, mode)
            s = theta_step(s, nu, mode)
        print(f"{nu:4.1f}  {mode:6s}  {g.max():10.4f}  {s.max():10.4f}"
              f"  {s.min():10.4f}  {s.sum() * dx:.6f}")
```

## 读表:0.75、1.31 和 0.95

CFL 0.5 时,BE 的高斯峰值为 0.7497,一圈损失25%,与开头反射波23%的衰减同一量级。CN 为 0.9976,几乎完全保持。代价是台阶最大值 1.3142、最小值 −0.2945,过冲超过31%。如果这是密度或体积分数,负值就意味着计算中断。

BLEND 的高斯为 0.9452,台阶为 1.0245 和 −0.0263。振幅损失降到 BE 的五分之一,振荡不到 CN 的十分之一。所有情况质量都是 0.300000。

CFL 2 时情况变了。BLEND 的高斯峰值降到 0.6142,接近 BE 的 0.4939。原因有两个。其一,minmod 把光滑极值也当作间断而选 BE,这是所有 TVD 限制器共有的削峰(clipping)。其二,CFL 大时单步 BE 损失 $s^2$ 变大,那几个单元把整体拉低。论文也对二阶修正设有 CFL 限制。

## 这个玩具模型与论文的距离

论文对完整欧拉方程做 IMEX 分裂:对流显式,声学隐式。这里只保留了一个声学特征。论文的限制器约束的是一阶隐式解与二阶解之差,这里简化为逐面 θ。所以应看趋势,而非具体数字。

同一组资料里还有其他选择。Arun 等(2019)用两级 ARS(2,2,2) IMEX-RK 代替 BE,把衰减从 $O(\Delta t)$ 降到 $O(\Delta t^2)$。不过二阶 IMEX 在刚性极限下仍可能降阶,相关案例见[M→0 时降为一阶的 IMEX](/zh/posts/2026-11-08-imex-order-reduction-stiffly-accurate/)。

## 怀疑声学衰减时最先要改的数字

如果反射或共振振幅偏小,先检查 θ。若 θ = 1,把实际的 $\nu$ 和每波长单元数代入上面的放大因子,算出一个周期的损失。若与观测误差相近,元凶就是时间积分。下一步是逐面选取 θ。然后把 CFL 降到 1 附近,确认 BLEND 停留在 CN 一侧。"隐式格式可以随意加大 CFL"这一想法,正是衰减的起点。
