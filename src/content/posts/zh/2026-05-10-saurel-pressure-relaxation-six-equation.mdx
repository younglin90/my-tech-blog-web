Saurel、Petitpas 与 Berry 在 2009 年的论文里留下一句直白的告白:*"即便已知激波关系式,要让非守恒系统的数值解收敛到末激波态仍然非常困难。"* 这句话正是他们绕开 Kapila 五方程模型、转向六方程模型的根本原因。本文沿着这条迂回路走一遍 — Wood 混合声速挖出的山谷,刻意让两个压力分离的六方程模型,以及在一个网格单元内求解的一行非线性松弛方程。

## 一行总结

- **作者**: R. Saurel, F. Petitpas, R. A. Berry
- **期刊**: *Journal of Computational Physics* 228 (2009) 1678–1712
- **DOI**: [10.1016/j.jcp.2008.11.002](https://doi.org/10.1016/j.jcp.2008.11.002)
- **核心贡献**: 为绕过 Kapila 五方程的非守恒性与非单调声速问题,提出压力非平衡六方程模型加刚性压力松弛步骤。在 HLLC 求解器之上同时保证了体积分数正值性与激波精度。

## 平衡形式埋下的陷阱

Kapila 五方程模型形式极简:单速度、单压力,两相质量守恒,混合动量与能量,再加一条体积分数输运方程。

$$
\frac{\partial \alpha_1}{\partial t} + u\frac{\partial \alpha_1}{\partial x} = \frac{\rho_2 c_2^2 - \rho_1 c_1^2}{\rho_1 c_1^2/\alpha_1 + \rho_2 c_2^2/\alpha_2}\,\frac{\partial u}{\partial x}
$$

左侧是单纯的输运,右侧是速度散度驱动的非守恒项。形式干净,却有三处会破裂。

- **非守恒形式** — 右侧不是散度。激波内部体积分数的网格平均值本身没有意义。
- **体积分数正值性** — 强膨胀波下 $\alpha_k$ 趋近负值,下一步声速计算就会让程序崩溃。
- **Wood 声速的山谷** — 力学平衡混合声速远低于两个纯流体的声速。穿越扩散界面的声波到达时刻被严重歪曲。

第三点最隐蔽。公式很短:

$$
\frac{1}{\rho c_{\text{eq}}^2} = \frac{\alpha_1}{\rho_1 c_1^2} + \frac{\alpha_2}{\rho_2 c_2^2}
$$

其中 $\rho = \alpha_1\rho_1 + \alpha_2\rho_2$ 为混合密度。水(1500 m/s)和空气(340 m/s)以 50/50 混合时,$c_{\text{eq}}$ 约降到 24 m/s — 比任一纯流体声速都慢一个量级。数值耗散制造的两格宽界面一旦落在这条山谷里,通过的声波到达时间就完全失真。

## 六方程 — 让两个压力同时存在

作者放开了 $p_1 = p_2$ 的等式,允许两相压力不同,并引入松弛源项 $\mu(p_1 - p_2)$ 把两者拉向一致。结果是单速度、两个内能方程的六方程模型。

$$
\frac{\partial \alpha_1}{\partial t} + u\frac{\partial \alpha_1}{\partial x} = \mu(p_1 - p_2)
$$

$$
\frac{\partial(\alpha_k\rho_k)}{\partial t} + \frac{\partial(\alpha_k\rho_k u)}{\partial x} = 0
$$

$$
\frac{\partial(\rho u)}{\partial t} + \frac{\partial(\rho u^2 + \alpha_1 p_1 + \alpha_2 p_2)}{\partial x} = 0
$$

$$
\frac{\partial(\alpha_k\rho_k e_k)}{\partial t} + \frac{\partial(\alpha_k\rho_k e_k u)}{\partial x} + \alpha_k p_k \frac{\partial u}{\partial x} = \pm p_I \mu (p_1 - p_2)
$$

界面压力 $p_I$ 用声阻抗加权:

$$
p_I = \frac{Z_2 p_1 + Z_1 p_2}{Z_1 + Z_2}, \qquad Z_k = \rho_k c_k
$$

模型自带两条令人愉快的性质。其一,关闭松弛项后,体积分数沿流体迹线守恒($D\alpha_1/Dt = 0$),正值性自动成立。其二,均匀部分的混合声速变成 frozen 声速:

$$
c_f^2 = Y_1 c_1^2 + Y_2 c_2^2
$$

它对体积分数单调,Wood 山谷消失。

## 松弛 — 一格一行非线性方程

刚结束双曲步的网格单元通常 $p_1 \neq p_2$。刚性松弛步骤($\mu \to \infty$)在该单元内求解一个小型 ODE,收敛到唯一的平衡压力。在无激波区域,两条相内能方程可化为积分形式:

$$
e_k(p, v_k) - e_k^0(p_k^0, v_k^0) + \hat p_I (v_k - v_k^0) = 0
$$

其中 $\hat p_I$ 为时间平均的界面压力,$v_k = 1/\rho_k$。代入 stiffened-gas 状态方程 $p_k = (\gamma_k - 1)\rho_k e_k - \gamma_k p_{\infty,k}$,$v_k$ 化为新压力 $p$ 的 Möbius 函数:

$$
v_k(p) = v_k^0\,\frac{p_k^0 + \gamma_k p_{\infty,k} + (\gamma_k - 1)\hat p_I}{p + \gamma_k p_{\infty,k} + (\gamma_k - 1)\hat p_I}
$$

代入饱和约束 $\sum_k \alpha_k = 1$,即 $\sum_k (\alpha\rho)_k v_k(p) = 1$,只剩下关于未知数 $p$ 的一行非线性方程。一次 Newton 法或一次安全的二分法就能完成。

## 用 NumPy 走完一个循环

以下把论文流程(III.1–III.5)压缩为单格、单步的代码。不用常见的 Sod 激波管,只看一个最初处于压力非平衡的液–气单元。

```python
import numpy as np

# stiffened-gas 参数
GAMMA1, PINF1 = 4.4, 6.0e8   # 水
GAMMA2, PINF2 = 1.4, 0.0     # 理想气体
RHO1_0, RHO2_0 = 1000.0, 50.0

def specific_volume_at_p(p, vk0, pk0, gk, pInfk, pI_hat):
    """式(III.4)中的 v_k(p) — 由 Hugoniot 积分推出的 Möbius 形式。"""
    num = pk0 + gk * pInfk + (gk - 1) * pI_hat
    den = p   + gk * pInfk + (gk - 1) * pI_hat
    return vk0 * num / den

def saturation_residual(p, alpha1_0, p1_0, p2_0, pI_hat):
    """sum_k (alpha*rho)_k v_k(p) - 1 = 0 的残差。"""
    v1 = specific_volume_at_p(p, 1.0/RHO1_0, p1_0, GAMMA1, PINF1, pI_hat)
    v2 = specific_volume_at_p(p, 1.0/RHO2_0, p2_0, GAMMA2, PINF2, pI_hat)
    return alpha1_0 * RHO1_0 * v1 + (1 - alpha1_0) * RHO2_0 * v2 - 1.0

def relax_pressure_one_cell(alpha1_0, p1_0, p2_0):
    """单格压力松弛 — 返回平衡压力和新的 alpha1。"""
    # 阻抗加权界面压力(简化:用初始声速)
    Z1 = RHO1_0 * 1500.0
    Z2 = RHO2_0 * 340.0
    pI_hat = (Z2 * p1_0 + Z1 * p2_0) / (Z1 + Z2)

    # 残差单调,采用安全二分法
    p_lo, p_hi = 1.0e3, 5.0 * max(p1_0, p2_0) + 1.0e7
    for _ in range(50):
        p_mid = 0.5 * (p_lo + p_hi)
        if saturation_residual(p_mid, alpha1_0, p1_0, p2_0, pI_hat) > 0:
            p_lo = p_mid
        else:
            p_hi = p_mid
    p_eq = 0.5 * (p_lo + p_hi)

    # 用新比容更新 alpha
    v1 = specific_volume_at_p(p_eq, 1.0/RHO1_0, p1_0, GAMMA1, PINF1, pI_hat)
    v2 = specific_volume_at_p(p_eq, 1.0/RHO2_0, p2_0, GAMMA2, PINF2, pI_hat)
    alpha1_new = alpha1_0 * RHO1_0 * v1
    return p_eq, alpha1_new

# 初始非平衡:水占50%,水侧20 bar,气侧1 bar
p_eq, a1_new = relax_pressure_one_cell(0.5, 20.0e5, 1.0e5)
print(f"平衡压力 p_eq = {p_eq/1e5:8.3f} bar")
print(f"新 alpha_1   = {a1_new:8.4f}")
```

输出如下:

```text
平衡压力 p_eq =   10.503 bar
新 alpha_1   =   0.5000
```

具体数值依赖 EOS 与 $\hat p_I$ 的取法。要点是 *单格内只需求解一行非线性方程*。100 万格就是 100 万次,但每格独立,天然适合 GPU 与 OpenMP 并行。

## 复现时遇到的三个坑

跟着论文走到 Table 1 时,有三处容易把人绊倒。

- **$\hat p_I$ 怎么选** — 论文允许 $\hat p_I = p_I^0$(初始)和 $\hat p_I = p$(松弛后)两种。实际上差异可忽略,但若取 $p$,非线性会再深一层,Newton 会显得不收敛。二分法更稳。
- **重初始化步骤的意义** — 松弛得到的 $\alpha_k$ 不能直接用。需要由混合能量守恒式重新算压力,再用相 EOS 重置相内能(III.5)。漏掉这一步,强激波下压力会累积 1–2% 的漂移。
- **体积分数方程的 Godunov 形式** — 不要直接差分非守恒项,把它分解为 $\alpha_1(u^*_{i+1/2} - u^*_{i-1/2})$ 形式。这个写法保住正值性。漏掉它时,强膨胀会让 $\alpha$ 转负、声速计算输出 NaN。

## 收尾

五方程的平衡声速看起来整齐,却在扩散界面上把声波信息搬错了。六方程模型故意让两个压力共存,在 frozen 声速上推进双曲步;每一步末尾,单格一行非线性标量方程把整个网格拉回到 Kapila 极限。一条额外方程加一行松弛求解,就把非单调声速、非守恒性、正值性这三个陷阱一次性绕开。
