## 板向前走,底部流体却向后走

两块平板之间充满流体。上板向右移动,下板固定。按常识,所有流体都应被拖向右边。可是只要把下游压力稍微抬高,底部附近的流体就开始向左流。本文说明这个分界为什么恰好在 $P=-1$。截面流量为零的 $P=-3$ 也一并讨论。最后用有限体积法(FVM,用单元平均值求解守恒律的离散方法)复现同样的结果。并用数字确认一个陷阱:就在阈值附近,网格会把符号翻过来。

素材来自本科粘性流体力学的手写笔记。Couette 流动(动板拖动的剪切流)旁边写着 "adverse pressure gradient"。下面的草图里,底部附近的速度箭头向后弯折。这是学习边界层分离之前最简单的分离模型。

## 一条直线加一条抛物线

设板间距为 $h$,上板速度为 $U$。流动充分发展后,速度只依赖 $y$。此时动量方程只剩压力梯度与粘性力的平衡。

$$
\mu \frac{d^2 u}{dy^2} = \frac{dp}{dx}, \qquad u(0)=0,\quad u(h)=U
$$

$\mu$ 是动力粘度,$dp/dx$ 是流向压力梯度。方程是线性的。所以解可以拆成两部分之和:没有压力梯度的 Couette 解,以及两板静止的 Poiseuille 解(压差推动的抛物线流动)。

$$
\frac{u}{U} = \frac{y}{h} + P\,\frac{y}{h}\left(1-\frac{y}{h}\right), \qquad P = -\frac{h^2}{2\mu U}\frac{dp}{dx}
$$

$P$ 是无量纲压力参数。压力沿下游降低($dp/dx<0$)时 $P>0$,即顺压梯度。下游压力更高时 $P<0$,即逆压梯度(adverse pressure gradient)。抛物线部分与[平板 Poiseuille 解析解](/zh/posts/2026-03-28-poiseuille-flow-analytical-solution/)形状相同,只是符号由 $P$ 决定。

## P = −1:壁面剪切为零的时刻

固定壁的剪切应力与速度梯度成正比。对上面的解求导即可得到。

$$
\tau_{\text{bottom}} = \mu \left.\frac{du}{dy}\right|_{0} = \frac{\mu U}{h}(1+P), \qquad \tau_{\text{top}} = \frac{\mu U}{h}(1-P)
$$

$\tau_{\text{bottom}}$ 作用在下壁,$\tau_{\text{top}}$ 作用在上板。$P=-1$ 时下壁剪切恰好为零。边界层理论定义分离点的条件,正是壁面剪切为零。$P<-1$ 时近壁梯度为负,也就是紧贴壁面的流体在倒流。

回流层厚度是 $u=0$ 的高度,由 $y/h\,(1+P-Py/h)=0$ 得出。

$$
\frac{y_r}{h} = 1 + \frac{1}{P} \quad (P<-1)
$$

$P=-2$ 时下半部分回流。$P=-3$ 时下方 2/3 回流。截面流量也算一下。

$$
\frac{Q}{Uh} = \int_0^1 \frac{u}{U}\, d\!\left(\frac{y}{h}\right) = \frac{1}{2} + \frac{P}{6}
$$

$P=-3$ 时流量为零。上板一直在动,但穿过截面的净质量为零。向前的上层与向后的下层恰好抵消。

为什么偏偏从底部先翻转?逆压梯度在整个截面上施加相同的力。上板附近的流体一直被板拖着走。底部流体被壁面拉住,本来就慢。受到同样的反向力,最慢的一层最先越过零。这和[阻力危机与边界层分离](/zh/posts/2026-06-09-drag-crisis-boundary-layer-separation/)中的机理相同。区别只有一点:这里流动是平行的,分离泡不会闭合,回流层沿 $x$ 方向无限延伸。

## 代码:从静止出发,时间推进到定常

既然有解析解,代码就是用来验证的。从静止流体出发,把非定常方程推进到定常。无量纲形式为 $u_t = 2P + u_{yy}$,时间单位是 $h^2/\nu$。

- 网格:40 个单元中心,$\Delta y = 1/40$。
- 壁面条件:用虚拟单元(ghost cell,放在壁外的假想单元)线性插值匹配壁面值。
- 时间:显式 Euler,$\Delta t = 0.4\Delta y^2$(低于扩散稳定极限 0.5)。
- 停止条件:单步变化率 $\max|\Delta u|/\Delta t < 10^{-8}$。
- 测量:下壁梯度(二阶精度公式)、流量、负值单元比例、相对解析解的最大误差。

```python
def exact_profile(y, P):
    # u/U = y/h + P (y/h)(1 - y/h)
    return y + P * y * (1.0 - y)

def couette_poiseuille_march(P, N=40, tol=1e-8):
    # 无量纲: u_t = 2P + u_yy, u(0)=0, u(1)=1, 从静止出发
    dy = 1.0 / N
    y = [(j + 0.5) * dy for j in range(N)]
    dt = 0.4 * dy * dy
    u = [0.0] * N
    steps = 0
    while True:
        ue = [-u[0]] + u + [2.0 - u[-1]]   # ghost: 下壁 u=0, 上壁 u=1
        dmax = 0.0
        for j in range(N):
            lap = (ue[j + 2] - 2.0 * ue[j + 1] + ue[j]) / (dy * dy)
            du = dt * (2.0 * P + lap)
            u[j] += du
            dmax = max(dmax, abs(du))
        steps += 1
        if dmax / dt < tol:
            break
    tau0 = (9.0 * u[0] - u[1]) / (3.0 * dy)      # 二阶精度壁面梯度
    Q = sum(u) * dy
    back = sum(1 for v in u if v < 0) * dy
    err = max(abs(u[j] - exact_profile(y[j], P)) for j in range(N))
    return steps, steps * dt, tau0, Q, back, err

print(f"{'P':>5} {'steps':>6} {'t_ss':>6} {'tau_bot':>8} {'exact':>6} {'Q':>7} {'backflow':>8} {'max_err':>9}")
for P in [2.0, 0.0, -0.5, -1.0, -2.0, -3.0, -4.0]:
    s, t, tau, Q, b, e = couette_poiseuille_march(P)
    print(f"{P:5.1f} {s:6d} {t:6.3f} {tau:8.4f} {1 + P:6.2f} {Q:7.4f} {b:8.3f} {e:9.2e}")
```

## 读输出:8,000 步、0.675,以及 −0.0167

**到达定常的时间几乎与 $P$ 无关。** 所有工况都是 $t_{ss}\approx 2$,约 8,000 步。扩散最慢的模态按 $e^{-\pi^2 t}$ 衰减。把残差降到 $10^{-8}$ 需要 $t \approx \ln(10^{9})/\pi^2 \approx 2$。压力梯度只改变最终形状,不改变时间尺度。

**流量和回流厚度与解析解吻合。** $P=-3$ 时 $Q=-0.0006$,与解析值 0 在网格误差范围内一致。回流比例 0.675 与解析值 $2/3$ 相差不到一个单元宽度。$P=-2$ 的 0.500、$P=-4$ 的 0.750 也完全符合 $1+1/P$。

**问题出在 $P=-1$。** 解析解是 $u=y^2$,不应有负值。可是代码报告壁面梯度 −0.0167,还有一个回流单元(0.025)。罪魁祸首是虚拟单元。线性插值漏掉了近壁曲率,于是每个单元都偏差 $|P|\Delta y^2/4$。`max_err` 列正是这个值($P=2$ 时为 $3.12\times10^{-4}$)。壁面梯度误差也能从表中读出:每一行都是 $\tfrac{2}{3}P\Delta y$。$P=-1$ 时这个误差为 −0.0167,真值是 0,符号就这样翻了过来。

教训很简单。用壁面剪切的符号判断分离,在阈值附近,网格误差就掌握了判决权。这与[同一代码给出两种收敛阶的原因](/zh/posts/2026-10-07-sod-vortex-order-verification/)是同一回事。必须先知道测量量对什么敏感。这里,壁面边界处理的一阶误差掩盖了内部的二阶精度。

## 这个速度剖面实际用在哪里

**润滑理论。** 滑动轴承的间隙就是间距极小的 Couette–Poiseuille 流动。Reynolds 润滑方程就是把上面的流量式 $Q = Uh/2 - (h^3/12\mu)\,dp/dx$ 代入质量守恒。间隙收窄的一侧压力积聚,这个压力作为逆压梯度起作用,使流量平衡。

**壁面函数与分离判断。** 湍流模型的壁面函数把近壁区当作 Couette 流动处理。逆压梯度一强,这个假设就失效。这就是壁面函数在分离前区域不准确的原因。

**代码验证。** 这个解能一次检验压力梯度、动壁和粘性项。解析解是二次多项式,二阶精度格式的内部误差应为零。剩下的误差几乎全部来自边界处理,因此很适合单独测试壁面边界的实现。
