## 护套加厚，导线会更凉还是更热

一根半径 5 mm 的铜线温度为 100 °C，周围空气 25 °C。为了减少热损失，给它包了 6 mm 厚的保温层(k = 0.055 W/m·K)。算一下就会发现，热损失没有减少，反而增加了 23%。

本文解释这个反直觉的结果从何而来。把两个圆柱热阻相加再求导，就得到临界保温半径(critical insulation radius，使热损失达到最大的保温层外半径)$r_{cr} = k/h$。接着用有限体积法(FVM)对保温层做时间推进，用数值验证这个值。读完之后，拿到保温规格时只需做一次除法，就能判断"这个厚度到底有没有用"。

## 两个方向相反的热阻

稳态下，每米圆柱的热流量 $q'$ 等于温差除以热阻(温差与热流量之比)。包上保温层后，两个热阻串联。一个是穿过保温层的导热热阻。另一个是外表面向空气散热的对流热阻。

加厚保温层会增大导热热阻。但外表面积也随之增大。表面积变大，对流热阻就会减小。总和是增是减，取决于两者变化速度的较量。

## 圆柱导热热阻 ln(r_o/r_i)/2πk 从何而来

无内热源的稳态圆柱导热方程如下。

$$
\frac{1}{r}\frac{d}{dr}\left(k\,r\,\frac{dT}{dr}\right)=0
$$

$r$ 为径向坐标，$k$ 为导热系数，$T$ 为温度。积分两次得到 $T(r)=C_1\ln r + C_2$。温度沿半径呈对数下降。

热流量为 $q = -k\,(2\pi r L)\,dT/dr$。代入对数分布后 $r$ 被约去，得到与半径无关的常数。按单位长度整理即得导热热阻。

$$
R'_{cond}=\frac{\ln(r_o/r_i)}{2\pi k},\qquad R'_{conv}=\frac{1}{2\pi r_o h}
$$

$r_i$ 为导线半径，$r_o$ 为保温层外半径，$h$ 为对流换热系数。若是平板，导热热阻与厚度成正比增长。圆柱则只按对数增长。而对流热阻按 $1/r_o$ 减小。在细圆柱上，对数增长慢，$1/r_o$ 减小快。这就是反转的根源。

## 是最大值而不是最小值:对 R'_tot 求导

将总热阻 $R'_{tot}=R'_{cond}+R'_{conv}$ 对 $r_o$ 求导并令其为零。

$$
\frac{dR'_{tot}}{dr_o}=\frac{1}{2\pi k\,r_o}-\frac{1}{2\pi h\,r_o^{2}}=0
\;\;\Rightarrow\;\; r_{cr}=\frac{k}{h}
$$

原讲义的问题是"是否存在使热损失最小的最佳厚度"。二阶导数在 $r_{cr}$ 处为正。所以这一点是热阻的最小值，也就是热损失的最大值。使热损失最小的有限厚度并不存在。

代入例题数值，$r_{cr}=0.055/5=0.011$ m。导线半径 5 mm 比它小。因此在 6 mm 厚度以内，保温层包得越多，热损失越大。在电气布线中这反而是优点。薄护套同时承担了电绝缘和散热。

## 代码:用有限体积法对保温层做时间推进，确认稳态

只有解析解略显单调。把保温层分成 20 个单元，从 25 °C 开始。导线一侧固定为 100 °C，外侧为对流边界(Robin 条件，表面热流与表面-空气温差成正比)。用显式时间推进，直到导线侧流入热流与空气侧流出热流之差小于 $10^{-4}$。

```python
import math

r_i, k, h = 0.005, 0.055, 5.0          # 导线半径 [m], 保温层 k [W/m K], h [W/m2 K]
T_i, T_inf = 100.0, 25.0               # 导线 / 空气温度 [C]
rho_c = 4.0e4                          # 保温层 rho*c [J/m3 K]
N, tol = 20, 1e-4                      # 单元数, 稳态判据容差

def q_line_exact(r_o):
    R = math.log(r_o / r_i) / (2*math.pi*k) + 1.0 / (2*math.pi*r_o*h)
    return (T_i - T_inf) / R

def insulation_march(r_o):
    dr = (r_o - r_i) / N
    rf = [r_i + j*dr for j in range(N + 1)]
    V = [math.pi*(rf[j+1]**2 - rf[j]**2) for j in range(N)]
    G = [2*math.pi*rf[j]*k/dr for j in range(1, N)]          # 内部面导热系数
    G0 = 2*math.pi*r_i*k/(dr/2)                               # 导线 -> 单元 0
    Gout = 1/((dr/2)/(2*math.pi*r_o*k) + 1/(2*math.pi*r_o*h)) # 单元 N-1 -> 空气
    Gsum = [0.0]*N
    for j, g in enumerate(G):
        Gsum[j] += g; Gsum[j+1] += g
    Gsum[0] += G0; Gsum[-1] += Gout
    dt = 0.45*min(rho_c*V[j]/Gsum[j] for j in range(N))       # 显式稳定极限
    T = [T_inf]*N; n = 0
    while True:
        dQ = [0.0]*N
        for j, g in enumerate(G):
            f = g*(T[j] - T[j+1]); dQ[j] -= f; dQ[j+1] += f
        q_in = G0*(T_i - T[0]); q_out = Gout*(T[-1] - T_inf)
        dQ[0] += q_in; dQ[-1] -= q_out
        T = [T[j] + dt*dQ[j]/(rho_c*V[j]) for j in range(N)]
        n += 1
        if abs(q_in - q_out) < tol*q_out:
            return n, n*dt, q_out, T[-1]

r_cr = k / h
q_bare = q_line_exact(r_i)
print(f"r_cr = k/h = {r_cr*1e3:.1f} mm,  bare wire q' = {q_bare:.2f} W/m")
print(" r_o[mm]  steps     t[s]   q'_num  q'_exact  err[%]  T_s[C]")
for r_o in [0.007, 0.011, 0.020, 0.030, 0.050]:
    n, t, q, Ts = insulation_march(r_o)
    qe = q_line_exact(r_o)
    print(f"{r_o*1e3:7.0f} {n:6d} {t:8.1f} {q:8.2f} {qe:8.2f} {100*(q-qe)/qe:7.3f} {Ts:7.1f}")
r = r_cr
while q_line_exact(r) > q_bare:
    r += 1e-5
print(f"insulation starts to pay off only beyond r_o = {r*1e3:.1f} mm")
```

## 解读输出:23%、32 mm 和 0.653%

第一个数字是 23%。裸导线的 11.78 W/m 在 $r_{cr}$ 处增加到 14.49 W/m。尽管表面温度已降到 67.5 °C。温差缩小了，但面积变为 2.2 倍，对流散热占了上风。

第二个是 32 mm，即保温层开始优于裸导线的位置。它是导线半径的 6.4 倍，约为 $r_{cr}$ 的 3 倍。即使在 30 mm 时，损失仍为 11.98 W/m，比裸导线大。"只要超过临界半径就行"这一常见误解是错的。越过 $r_{cr}$ 之后还要再包很多才能回本。

第三个是 0.653% 的误差。单元数相同，层越厚误差越大。原因是单元内温度按线性处理，与对数分布存在偏差。当 $r_o/r_i$ 为 10 时，第一个单元与最后一个单元的梯度相差 10 倍。若改用按 $\ln r$ 等间距的网格，这一误差几乎消失。

步数也值得注意。7 mm 的保温层只需 13 秒物理时间就达到稳态，却用了 12,227 步。薄层的单元小，显式稳定条件会压低 $\Delta t$。扩散格式的这一限制以及绕开它的尝试，可参见 [DuFort–Frankel 一文](/zh/posts/2026-11-04-dufort-frankel-negative-temperature/)。

## 球体变为 2k/h，以及 h 并非常数时

球体也做同样的计算。导热热阻为 $(1/r_i-1/r_o)/(4\pi k)$，对流热阻为 $1/(4\pi r_o^2 h)$。求导得 $r_{cr}=2k/h$，是圆柱的两倍。因为表面积按 $r^2$ 增长，对流热阻下降得更快。

实际问题中 $h$ 并非常数。水平圆柱自然对流时，$h$ 大致与直径的 $-1/4$ 次方成正比。半径增大时 $h$ 略降，$r_{cr}$ 因而比公式略大。辐射也会叠加到等效 $h$ 上。表面发射率高时 $h$ 变大，$r_{cr}$ 变小。在杆上布置多个热源的一维导热代码见 [加热器闭包一文](/zh/posts/2026-11-23-closure-late-binding-heater-sources/)。给那段代码加上本文的 Robin 边界，就能做同样的实验。

在 CFD 中，这一讨论关系到共轭传热(conjugate heat transfer，同时求解固体导热与流体对流)的网格设计。如果把薄护套层压成一两个网格，其导热热阻就像消失了一样。上面的代码即使用 20 个单元，在厚层上也有 0.65% 的误差。层内网格沿径向拉伸布置更为稳妥。

## 拿到管道保温规格书，先算一下 k/h

确定保温厚度之前先算 $k/h$。静止空气中 $h$ 为 5~10 W/m²·K，保温材料 $k$ 为 0.03~0.06 W/m·K。这样 $r_{cr}$ 落在 3~12 mm 范围内。

像蒸汽管道这样外径达数十毫米以上的，已经大于 $r_{cr}$。这时包得越厚损失越小。陷阱在于信号线、热电偶护套、细冷媒管这类半径只有几毫米的情况。此时需要算出热损失低于裸圆柱的半径，再据此确定厚度。本例中这个值是 32 mm。
