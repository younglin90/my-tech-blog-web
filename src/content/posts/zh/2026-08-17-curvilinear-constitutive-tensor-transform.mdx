## 变形没动，能量却涨了2.5倍

壳单元的刚度矩阵通常这样组装：在高斯积分点上构造应变-位移矩阵 $\mathbf{B}$，乘以本构矩阵 $\mathbf{C}$，再积分 $\mathbf{B}^{\mathsf T}\mathbf{C}\mathbf{B}$。问题在于这两个矩阵诞生于不同的坐标系。

$\mathbf{C}$ 是材料属性，因此定义在材料试验所用的坐标系里，也就是贴在壳面上的**局部正交笛卡尔坐标系**。而 $\mathbf{B}$ 来自形函数的导数。形函数写在单元的**自然坐标系** $(r^1, r^2, r^3)$ 中，单元一旦弯曲或畸变，这个坐标系既不正交也不归一。

有一种情况两个坐标系恰好重合：单元是矩形且曲面是平的。如果只用平面模型跑分片试验，那就只是在这个巧合上做验证。一旦把单元贴到曲面上，巧合就消失了。

## 基不正交，分量就有两套

自然坐标 $r^i$ 变化时物理位置 $\mathbf{x}$ 移动的方向，就是协变基。

$$
\mathbf{g}_i = \frac{\partial \mathbf{x}}{\partial r^i}
$$

$\mathbf{x}$ 是笛卡尔位置矢量，$r^i$ 是单元的自然坐标。这三个矢量彼此不正交，长度也不是1。

在不正交的基上写一个矢量的分量有两种做法。沿基矢量按平行四边形法则分解，得到的系数是逆变分量 $v^i$。向每个基矢量作垂线投影，那些投影是协变分量 $v_i$。

$$
\mathbf{v} = v^i \mathbf{g}_i, \qquad v_i = \mathbf{v}\cdot\mathbf{g}_i
$$

在标准正交基下这两种作图落在同一点。只用过笛卡尔坐标的眼睛看不见这条缝。文首的旋钮已经把两行数字拉开了。白色箭头换了坐标还是同一个矢量。

## 度量张量把丢掉的长度还回来

连接这两套分量的就是度量张量。

$$
g_{ij} = \mathbf{g}_i \cdot \mathbf{g}_j, \qquad v_i = g_{ij}\, v^j
$$

$g_{ij}$ 把基矢量的长度和夹角装进一个矩阵。对角元 $g_{11}, g_{22}, g_{33}$ 是各基的长度平方，非对角元是夹角余弦乘以长度。

要量长度，就必须经过这个矩阵。

$$
|\mathbf{v}|^2 = g_{ij}\, v^i v^j = v_i v^i
$$

第二个等号才是要点。把协变分量和逆变分量**配对**相乘，度量会自动抵消。反过来，把逆变分量各自平方再相加($v^i v^i$)，那不是长度。可视化最底下一行用红色显示了这个值。

连续介质力学给应力用逆变、给应变用协变，原因就在这里。虚功必须是标量，只有把第二类Piola-Kirchhoff应力的逆变分量 $S^{ij}$ 与Green-Lagrange应变的协变分量 $E_{ij}$ 配对，$S^{ij}E_{ij}$ 才与坐标系无关。这和网格度量在流动求解器里干的事一样 — [曲线坐标变换与网格度量](/zh/posts/2026-06-17-curvilinear-coordinate-transformation-grid-metrics/)里讲的雅可比矩阵，在这里就是基矢量本身。

## 逆变基就是雅可比逆矩阵的行

要把协变分量转回逆变，需要 $g^{ij} = [g_{ij}]^{-1}$，用这个矩阵构造的基就是逆变基。

$$
\mathbf{g}^i = g^{ij}\mathbf{g}_j, \qquad \mathbf{g}^i \cdot \mathbf{g}_j = \delta^i_j
$$

$\delta^i_j$ 是克罗内克delta。也就是说 $\mathbf{g}^1$ 同时垂直于 $\mathbf{g}_2$ 和 $\mathbf{g}_3$，长度则调到与 $\mathbf{g}_1$ 的点积恰好为1。

实现时不需要求两次逆。把协变基按**列**堆成矩阵 $\mathbf{J}$，则

$$
\mathbf{J} = [\,\mathbf{g}_1\;\mathbf{g}_2\;\mathbf{g}_3\,], \qquad \mathbf{g}^i = \big(\mathbf{J}^{-1}\big)_{i\bullet}
$$

$\big(\mathbf{J}^{-1}\big)_{i\bullet}$ 表示 $\mathbf{J}^{-1}$ 的第 $i$ 行。

$\mathbf{J}$ 正是从自然坐标到物理坐标的雅可比矩阵。为了在每个积分点求 $\det\mathbf{J}$，这个矩阵早就算好了。逆变基是顺带得到的。

## 四阶张量要乘四次方向余弦

现在进入正题。把定义在局部笛卡尔基 $\mathbf{e}_p$ 上的本构张量 $C^{pqrs}$ 搬到自然坐标系。搬二阶张量要乘两次方向余弦，四阶张量就乘四次。

$$
\tilde{C}^{ijkl} = (\mathbf{g}^i\!\cdot\mathbf{e}_p)(\mathbf{g}^j\!\cdot\mathbf{e}_q)(\mathbf{g}^k\!\cdot\mathbf{e}_r)(\mathbf{g}^l\!\cdot\mathbf{e}_s)\, C^{pqrs}
$$

指标 $i,j,k,l$ 在自然坐标里，$p,q,r,s$ 在局部笛卡尔坐标里。应变那一侧方向相反。

$$
\tilde{\varepsilon}_{ij} = (\mathbf{g}_i\!\cdot\mathbf{e}_p)(\mathbf{g}_j\!\cdot\mathbf{e}_q)\,\varepsilon_{pq}
$$

本构张量挂上 $\mathbf{J}^{-1}$，应变挂上 $\mathbf{J}$。所以两者缩并时雅可比矩阵正好抵消，能量保持不变。反过来说，只变换应变而放着本构张量不管，就会剩下四个 $\mathbf{J}$。那四个就是表里的误差列。`skew` 和 `|g_2|` 把这一列胀成什么样，输出正后方的柱子上再看。

## 用Python测出的各扭斜角度下的能量

在平面应力各向同性材料上固定一个应变状态，只扭动坐标系，用两种方式计算应变能。材料常数与原始文档一致($E = 2.1\times10^6$，$\nu = 0.3$)。

```python
import numpy as np

def natural_basis(skew_deg, stretch=1.0):
    """列为协变基 g_i = dx/dr^i 的雅可比矩阵 J"""
    a = np.deg2rad(skew_deg)
    g1 = np.array([1.0, 0.0])
    g2 = stretch * np.array([np.sin(a), np.cos(a)])
    return np.column_stack([g1, g2])

def plane_stress_tensor(E=2.1e6, nu=0.3):
    """局部笛卡尔坐标系下的各向同性平面应力四阶张量 C^{pqrs}"""
    lam = E * nu / (1.0 - nu**2)
    mu = E / (2.0 * (1.0 + nu))
    d = np.eye(2)
    return (lam * np.einsum('pq,rs->pqrs', d, d)
            + mu * (np.einsum('pr,qs->pqrs', d, d) + np.einsum('ps,qr->pqrs', d, d)))

def rotate_fourth_order(C, Jinv):
    """C^{ijkl} = (g^i.e_p)(g^j.e_q)(g^k.e_r)(g^l.e_s) C^{pqrs}, g^i = J^-1 的第i行"""
    return np.einsum('ip,jq,kr,ls,pqrs->ijkl', Jinv, Jinv, Jinv, Jinv, C)

def strain_energy(C, eps):
    return 0.5 * np.einsum('pqrs,pq,rs->', C, eps, eps)

def to_voigt2d(C):
    """2D Voigt: (00,11,01) -> 3x3"""
    idx = [(0, 0), (1, 1), (0, 1)]
    return np.array([[C[p, q, r, s] for (r, s) in idx] for (p, q) in idx])

# 一个物理应变状态(局部笛卡尔分量)。无论坐标怎么取，这个张量都不变。
eps_cart = np.array([[1.0e-3, 4.0e-4],
                     [4.0e-4, -6.0e-4]])
C_cart = plane_stress_tensor()
U_ref = strain_energy(C_cart, eps_cart)

print("skew   g11     g12     g22    | U_correct     U_naive      err%")
print("-" * 68)
for skew in [0, 5, 10, 15, 20, 30, 40, 45]:
    J = natural_basis(skew)
    g = J.T @ J                       # 度量张量 g_ij
    Jinv = np.linalg.inv(J)           # 行 = 逆变基 g^i
    eps_nat = J.T @ eps_cart @ J      # 协变应变分量
    C_nat = rotate_fourth_order(C_cart, Jinv)
    U_ok = strain_energy(C_nat, eps_nat)
    U_bad = strain_energy(C_cart, eps_nat)   # 漏掉变换的代码
    err = 100.0 * (U_bad - U_ok) / U_ok
    print(f"{skew:3d}   {g[0,0]:.3f}  {g[0,1]:+.3f}  {g[1,1]:.3f} |"
          f" {U_ok:.6e}  {U_bad:.6e}  {err:+8.2f}")

print()
print("orthogonal (skew=0), only |g2| stretched")
for st in [1.0, 1.5, 2.0]:
    J = natural_basis(0, stretch=st)
    Jinv = np.linalg.inv(J)
    eps_nat = J.T @ eps_cart @ J
    U_ok = strain_energy(rotate_fourth_order(C_cart, Jinv), eps_nat)
    U_bad = strain_energy(C_cart, eps_nat)
    print(f"  stretch={st:.1f}  g22={(J.T@J)[1,1]:.2f}  err% = {100*(U_bad-U_ok)/U_ok:+9.2f}")

print()
print(f"Cartesian reference U_ref   = {U_ref:.6e}")
J = natural_basis(30)
Jinv = np.linalg.inv(J)
C_nat = rotate_fourth_order(C_cart, Jinv)
eps_nat = J.T @ eps_cart @ J
print(f"skew=30 after transform     = {strain_energy(C_nat, eps_nat):.6e}  (invariant)")

# 折成Voigt形式后是否得到同样的值
Cv = to_voigt2d(C_nat)
ev = np.array([eps_nat[0, 0], eps_nat[1, 1], 2.0 * eps_nat[0, 1]])
print(f"skew=30 via Voigt 3x3       = {0.5 * ev @ Cv @ ev:.6e}")

# Voigt空间中的应变变换矩阵 A: e_v(nat) = A e_v(cart)
def voigt_map(J):
    cols = []
    for e in (np.array([[1, 0], [0, 0]]), np.array([[0, 0], [0, 1]]), np.array([[0, .5], [.5, 0]])):
        n = J.T @ e @ J
        cols.append([n[0, 0], n[1, 1], 2 * n[0, 1]])
    return np.array(cols).T

A = voigt_map(J)
Cv_cart = to_voigt2d(C_cart)
Ai = np.linalg.inv(A)
print("Voigt congruence C_nat = A^-T C_cart A^-1  residual =",
      f"{np.max(np.abs(Ai.T @ Cv_cart @ Ai - Cv)):.3e}")
```

## 折成Voigt形式后就是一个6×6矩阵

没人会把四指标数组原样带进生产代码。应力和应变张量对称，独立分量只剩6个，四阶张量折成 $6\times6$ 矩阵(上面的代码是二维的，所以是 $3\times3$)。

折叠之后变换依然在。如果应变的Voigt矢量按 $\tilde{\boldsymbol\varepsilon}_v = \mathbf{A}\,\boldsymbol\varepsilon_v$ 变换，那么能量不变就要求本构矩阵接受一次合同变换。

$$
\tilde{\mathbf{C}}_v = \mathbf{A}^{-\mathsf T}\,\mathbf{C}_v\,\mathbf{A}^{-1}
$$

$\mathbf{A}$ 的元素是方向余弦的乘积。上面输出最后一行的残差 $9.3\times10^{-10}$ 证实了这条路径与四阶张量缩并给出同一个答案。真实壳代码里常见的 `T` 矩阵就是它。剪切修正系数5/6和平面应力假设($\sigma_{33}=0$)要在构造 $\mathbf{C}_v$ 时先在局部笛卡尔坐标系里体现，顺序不能颠倒 — 平面应力条件只在定义了厚度方向的那个坐标系里才有意义。

## 有限体积法里同样的错误出现在哪

这不是结构代码独有的错误。曲线网格有限体积法算粘性应力张量时，同样的结构会再出现。应变率从自然坐标的导数拿来，牛顿黏性 $\tau = 2\mu \mathbf{D}$ 按笛卡尔形式直接乘上去，上表的误差列就原样回来。45° 那一列的 +152.61% 就是它。手上的分量是物理分量还是协变分量，缩并时上指标有没有配下指标，这两件事先看。只在正交网格上通过的验证，看不见这一列。

[用对角线叉积量曲线单元面积](/zh/posts/2026-10-13-diagonal-cross-product-cell-area-green-gauss/)的时候，Green–Gauss 看的也是同一份度量。[壳的剪切闭锁与 MITC 绑定](/zh/posts/2026-08-12-mitc-shell-shear-locking/)若是在改单元的*格式*，这里要问的是这份格式在哪个坐标系里读。格式改了，坐标系漏了，平面分片试验照样通过。一张 45°，或者一张 $|\mathbf{g}_2| = 1.5$，就把表切开。
