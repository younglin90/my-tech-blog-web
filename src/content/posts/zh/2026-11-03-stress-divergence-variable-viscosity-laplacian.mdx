## 压力推了1，壁面却顶住了1.5

给平行通道加一个压力梯度。上壁被加热，黏度只有下壁的十分之一。稳态时，两面壁上的剪切力之和应当等于压力的推力。计算结果却不是这样：壁面承受的力是压力的1.5倍。流量比解析解多了17.7%。

问题出在一行代码。黏性项写成了 $\mu\nabla^2\mathbf{u}$，也就是教科书上不可压缩 Navier–Stokes 方程的原样。本文从单个流体微元重新推导这一项。并指出"黏度为常数"这一假设是在推导的哪一步混进来的。最后给出一个一行测试，用来判断自己代码里的黏性项属于哪种形式。

## 对一个流体微元写牛顿第二定律

取出一个小长方体流体微元。用密度代替质量，牛顿第二定律就变成单位体积的形式。

$$
\rho \frac{D\mathbf{u}}{Dt} = \rho\,\mathbf{g} + \mathbf{f}_{\text{surf}}
$$

$D/Dt$ 是物质导数（跟随微元看到的时间变化率），$\rho\mathbf{g}$ 是体积力，$\mathbf{f}_{\text{surf}}$ 是单位体积的表面力。

表面力来自微元六个面上的应力。应力 $\sigma_{ij}$ 是作用在垂直于 $i$ 轴的面上、沿 $j$ 方向的力。静止或匀速的微元，前后两面的应力相互抵消。微元加速，就说明前后两面的应力不同。写出 $x$ 方向的净力，剩下三个导数。

$$
f_x\,dx\,dy\,dz = \left(\frac{\partial \sigma_{xx}}{\partial x} + \frac{\partial \sigma_{yx}}{\partial y} + \frac{\partial \sigma_{zx}}{\partial z}\right) dx\,dy\,dz
$$

括号里是应力张量的散度。张量取散度得到向量。于是运动方程归结为一行。

$$
\rho \frac{D\mathbf{u}}{Dt} = \rho\,\mathbf{g} + \nabla\cdot\boldsymbol{\sigma}, \qquad \sigma_{ij} = -p\,\delta_{ij} + \tau_{ij}
$$

$p$ 是压力，$\tau_{ij}$ 是黏性应力，$\delta_{ij}$ 是克罗内克符号。到这里为止，对黏度没有做任何假设。只有一个事实："黏性力是面应力之差"。

在下面的模拟中亲手操作一下。它跟踪加热通道里的一个流体微元，显示其上下表面的剪切应力，以及用两种方式计算出的应力差。

绿色条 $\partial\tau/\partial y$ 无论微元在哪里、多大，始终是 −1，正好与压力1平衡。调高黏度比 $r$，再把微元上下移动。橙色条 $\mu\,\partial^2u/\partial y^2$ 随位置变化，红色的"虚假净力"偏离了零。

## 应力张量为什么必须对称

假设 $\tau_{xy}$ 与 $\tau_{yx}$ 不相等。两者之差会产生绕 $z$ 轴的力矩。力矩正比于面积 × 力臂，即 $dx^3$。转动惯量正比于质量 × 长度²，即 $dx^5$。

$$
\dot\omega_z \approx \frac{12\,(\tau_{xy}-\tau_{yx})}{\rho\,(dx^2+dy^2)}
$$

$\dot\omega_z$ 是微元的角加速度。把微元缩小到零，角加速度趋于无穷。连续介质要有意义，就必须 $\tau_{xy}=\tau_{yx}$。三个轴都适用同样的论证。所以应力张量是对称的，独立分量有6个。

## ∇·τ 变成 μ∇²u 的两个条件

牛顿流体（应力与应变率成线性比例的流体）的本构关系如下。

$$
\tau_{ij} = \mu\left(\frac{\partial u_i}{\partial x_j} + \frac{\partial u_j}{\partial x_i}\right) + \lambda\,\delta_{ij}\,\nabla\cdot\mathbf{u}
$$

$\mu$ 是动力黏度，$\lambda$ 是第二黏度。括号里是应变率张量的两倍。静止流体没有变形，黏性应力也为零。[从分子运动论看黏度的起源](/zh/posts/2026-05-14-viscosity-kinetic-origin-transport-analogy/)中讨论的 $\mu$ 正是这个比例常数。

现在取散度。$\mu$ 不提到导数外面，原样保留。

$$
\frac{\partial \tau_{ij}}{\partial x_j} = \mu\,\nabla^2 u_i + \mu\,\frac{\partial (\nabla\cdot\mathbf{u})}{\partial x_i} + \frac{\partial \mu}{\partial x_j}\left(\frac{\partial u_i}{\partial x_j} + \frac{\partial u_j}{\partial x_i}\right) + \frac{\partial (\lambda\,\nabla\cdot\mathbf{u})}{\partial x_i}
$$

只保留第一项需要两个条件。一是不可压缩 $\nabla\cdot\mathbf{u}=0$，它消去第二、第四项。二是 $\nabla\mu=0$，即黏度为常数。没有这个条件，第三项不会消失。

在平行通道 $u(y)$ 中，式子更简单。记压力梯度为 $G=-dp/dx$，稳态动量方程为：

$$
0 = G + \frac{d}{dy}\left(\mu\,\frac{du}{dy}\right) \;\Rightarrow\; \tau(y) = \mu\,\frac{du}{dy} = C - G\,y
$$

$C$ 是由壁面条件 $u(0)=u(1)=0$ 确定的常数。无论 $\mu$ 如何变化，剪切应力都是直线。$\mu$ 只改变速度梯度。而 $\mu\nabla^2u$ 形式求解的是 $\mu u''=-G$。两者之差恰好是 $\mu' u'$。黏度为常数时，通道回到 [Poiseuille 流动的解析解](/zh/posts/2026-03-28-poiseuille-flow-analytical-solution/)。

## 代码：加热通道，两种黏性项

取无量纲通道 $H=1$, $G=1$，黏度从下壁的1按指数分布变到上壁的 $1/r$。从静止开始做时间推进，直到稳态。只改变黏性项。`div` 在单元面上构造 $\mu\,\partial u/\partial y$ 再取差。`lap` 用单元中心的 $\mu$ 乘以二阶差分。最后把内部控制体的动量收支（压力 − 两端面剪切力）作为残差输出。

```python
import numpy as np

# 无量纲通道: H=1, rho=1, 压力梯度 G=-dp/dx=1
# 黏度从下壁 1 指数衰减到上壁 1/r (加热的上壁)
N = 41
y = np.linspace(0.0, 1.0, N)
dy = y[1] - y[0]

def trap(f, x):
    return float(np.sum(0.5 * (f[1:] + f[:-1]) * np.diff(x)))

def mu_profile(yy, r):
    return np.exp(-np.log(r) * yy)

def exact_heated_channel(r, m=20001):
    # mu u' = C - y,  u(0)=u(1)=0  → C = ∫y/mu / ∫1/mu
    s = np.linspace(0.0, 1.0, m)
    w = 1.0 / mu_profile(s, r)
    C = trap(s * w, s) / trap(w, s)
    du = (C - s) * w
    u = np.concatenate([[0.0], np.cumsum(0.5 * (du[1:] + du[:-1]) * (s[1] - s[0]))])
    return trap(u, s), C, -(C - 1.0)   # Q, tau_bottom, tau_top(壁面作用在流体上的力)

def viscous_term(u, mu_c, mu_f, form):
    if form == "div":       # ∂y(mu ∂y u): 面应力之差
        tau_f = mu_f * (u[1:] - u[:-1]) / dy
        return (tau_f[1:] - tau_f[:-1]) / dy
    else:                   # mu ∇²u: 中心黏度 × 曲率
        return mu_c[1:-1] * (u[2:] - 2 * u[1:-1] + u[:-2]) / dy**2

def time_march_channel(r, form, tol=1e-10):
    mu_c = mu_profile(y, r)
    mu_f = mu_profile(0.5 * (y[1:] + y[:-1]), r)
    dt = 0.4 * dy**2 / mu_c.max()
    u = np.zeros(N)
    for n in range(1, 2_000_000):
        du = dt * (1.0 + viscous_term(u, mu_c, mu_f, form))
        u[1:-1] += du
        if np.abs(du).max() / dt < tol:
            break
    Q = trap(u, y)
    tau_f = mu_f * (u[1:] - u[:-1]) / dy
    # 内部控制体 [dy/2, 1-dy/2] 的动量收支: 压力 = 两端面剪切力 → 残差
    balance = 1.0 * (1.0 - dy) - (tau_f[0] - tau_f[-1])
    return Q, balance, n

print(" r    Q_exact   Q_div     Q_lap     err_lap%  balance_div  balance_lap  steps")
for r in [1, 2, 5, 10, 30]:
    Qe, tb, tt = exact_heated_channel(r)
    Qd, bd, nd = time_march_channel(r, "div")
    Ql, bl, nl = time_march_channel(r, "lap")
    print(f"{r:3d}  {Qe:.5f}  {Qd:.5f}  {Ql:.5f}  {100*(Ql-Qe)/Qe:+7.1f}  {bd:+.1e}     {bl:+.1e}       {nd}")
```

## 17.7% 和 −0.5 为何同源

`div` 的残差是 $10^{-11}$，即收敛容差的量级。这不是巧合。把内部单元的黏性项全部相加，相邻面应力两两抵消，形成裂项求和。只剩下两端面的应力。推导中的"面应力之差"在离散方程里同样成立。

`lap` 没有这种结构。每个单元乘的是自己中心的 $\mu_i$，相邻单元之间没有共享的面应力。求和时消不掉。结果在 $r=10$ 时，域内出现了相当于压力50%的虚假体积力。壁面除了压力1之外，还要顶住0.5的虚假力。这就是残差 −0.5。

流量偏大也来自同一项。被丢掉的项是 $\mu' u' = -\ln r\,(C-y)$。其大小正比于 $\ln r$，在两壁附近最大。`lap` 只用局部黏度决定曲率（$u''=-G/\mu$）。在黏度为 $1/r$ 的上壁一侧，曲率变成 $r$ 倍，这一效应累积起来，使整个速度剖面鼓胀。$r=30$ 时误差增至39%，残差为 −1.3，虚假力超过了压力本身。

$r=1$ 时的 −0.1% 是另一类误差。两种形式给出相同的值，加密网格就会减小。它只是二阶差分的离散误差。

## 这个错误实际藏在哪里

温度相关黏度（加热壁面、润滑油、岩浆）是最常见的情形。湍流 RANS 求解器也一样。涡黏度 $\mu_t$ 在壁面为零，向外增大数百倍。此时 $\nabla\cdot[(\mu+\mu_t)(\nabla\mathbf{u}+\nabla\mathbf{u}^T)]$ 中的转置项 $\nabla\mathbf{u}^T$ 也不能丢。它在平行流中为零，但在二维分离流中会重新出现。多相流界面的黏度比超过100倍，问题更严重。

有限体积法（FVM）用面通量书写，通常就是 `div` 形式。危险的是有限差分代码，以及"因为不可压缩"就复用拉普拉斯算子的代码。OpenFOAM 的 `fvm::laplacian(nuEff, U)` 也是使用面黏度的 `div` 形式。不过转置项是以 `fvc::div(nuEff*dev2(T(fvc::grad(U))))` 单独加上的。

## 去掉常黏度假设之前先跑的一行测试

施加黏度比为10的指数分布，运行到稳态。然后比较内部单元黏性项之和与两端面应力之差。若两者在收敛容差内相等，就是守恒形式。若相差0.5，代码某处还留着 $\mu\nabla^2u$。这个残差比流量更早发现问题。17.7%的流量误差会和其他误差混在一起，而残差只有是零或不是零两种结果。
