## 截面扩大一倍的接头处,压力会升多少

一根细管突然接到粗管上。截面积变为两倍,流速减半。按伯努利方程,压升是 $\tfrac12\rho V_1^2 \times 0.75$。实测却在 $0.5$ 左右。伯努利高估了1.5倍。

最早把这个差距写成公式的,是18世纪法国的工兵学者。本文沿着这个公式,也就是Borda–Carnot公式展开。推导用动量而不是能量。损失去了哪里,用Carnot的“失去的速度”定理来解释。最后直接求解一个两股流混合的管道,用数字核对。读完后,你能判断突扩损失系数 $K=(1-\sigma)^2$ 何时成立、何时失效。

## 革命时期工兵军官眼中的“失去的速度”

Lazare Carnot于1771年进入Mézières皇家工程学院。他的老师是Gaspard Monge。Monge接替了Bossut在该校的数学教席。Bossut后来与达朗贝尔一起测量流体阻力。Borda则更早深入研究过牛顿的流体阻力理论。

Carnot在1784年发表了一篇关于机械的论文。文中引入了非弹性碰撞中的“能量损失”这一在当时颇为陌生的概念。两个物体相撞并粘在一起时,动量保留下来,动能(vis viva,当时称“活力”)却减少了。Carnot精确计算了这部分减少量:损失等于每个物体在碰撞中**失去的速度**所对应的动能之和。

Carnot把同样的思想用到管内流动上。截面突然扩大或缩小时,伯努利定理不再成立,会出现水头损失(流动损失的能量折算成高度)。这一关系式就是今天的Borda–Carnot公式。Carnot后来在革命政府的救国委员会中重组了军队。他的儿子就是热力学中的Sadi Carnot。

## 推导:只需假设台阶面压力等于 $p_1$

取控制体(用来核算质量和动量收支的假想盒子),从台阶紧后方一直到流动重新均匀的位置。忽略壁面摩擦。质量守恒很简单。

$$V_2 = \sigma V_1, \qquad \sigma = \frac{A_1}{A_2}$$

$V_1, V_2$ 分别是细管和粗管的平均流速,$\sigma$ 是截面比。

关键假设只有一个:作用在台阶面(扩大处的环形壁,面积 $A_2-A_1$)上的压力等于来流射流的压力 $p_1$。台阶角后方的涡区几乎静止,射流从旁边笔直穿过,因此射流压力直接传给静止流体。在此假设下,轴向动量收支为:

$$p_1 A_1 + p_1 (A_2 - A_1) - p_2 A_2 = \rho V_2^2 A_2 - \rho V_1^2 A_1$$

左边是入口、台阶面和出口压力的合力,右边是流出动量通量减去流入通量。整理得:

$$p_2 - p_1 = \rho V_2 (V_1 - V_2) = \rho V_1^2\,\sigma(1-\sigma)$$

而伯努利给出 $p_2-p_1=\tfrac12\rho V_1^2(1-\sigma^2)$。$\sigma=0.5$ 时,动量给出 $0.25\rho V_1^2$,伯努利给出 $0.375\rho V_1^2$。开头的1.5倍就是这个比值。把两者之差换算成单位质量能量,就是损失。

$$h_L = \frac{(V_1 - V_2)^2}{2g} = (1-\sigma)^2 \frac{V_1^2}{2g}$$

$h_L$ 是水头损失,$g$ 是重力加速度。损失系数 $K=(1-\sigma)^2$ 在管道排入大水箱的极限($\sigma\to0$)下等于1,意味着射流的动能全部损失。

## 损失就是失去速度的动能

再看 $h_L$ 的分子 $(V_1-V_2)^2$。流体微团以 $V_1$ 进入、以 $V_2$ 离开,失去的速度是 $V_1-V_2$。损失恰好是以这个失去的速度运动的动能。这与Carnot的碰撞定理形式相同。

设质量 $m_1$ 以速度 $V_1$ 撞上静止的 $m_2$ 并粘在一起。碰后速度为 $V=m_1V_1/(m_1+m_2)$。损失为:

$$\Delta E = \tfrac12 m_1 (V_1 - V)^2 + \tfrac12 m_2 (0 - V)^2$$

每一项都是该物体失去(或获得)的速度所对应的动能。在突扩中,台阶后方的静止流体扮演 $m_2$。但这部分流体不会被带往下游,不贡献质量流量,所以第二项消失。

这一观点可以直接推广到两股流的混合。速度不同的多根流管(由流线围成的细管)在同一管道中混合时,损失为:

$$\Delta e = \frac{1}{Q}\sum_k \tfrac12 (u_k - V_2)^2\, \Delta\psi_k$$

$Q$ 是总流量,$\Delta\psi_k$ 是流管 $k$ 携带的流量,$u_k$ 是该流管的入口速度。混合过程的细节(湍流还是层流扩散)不进入此式。只要质量和动量对得上,损失就确定了。正如之前文章[不同流线上的伯努利常数](/zh/posts/2026-09-03-bernoulli-constant-across-streamlines/)所示,每根流管的伯努利常数各不相同,这一点在这里很关键。

## 代码:用80根流管求解两股流的混合管道

真实台阶后方的涡需要二维计算。这里求解一个更简单、但物理原理相同的问题。等截面管道中流入中央射流(宽度 $\sigma$,速度1)和外侧慢流(速度 $\varepsilon$)。壁面为滑移壁。两股流通过黏性 $\nu$ 混合。

把边界层近似(忽略流向扩散的抛物型近似)写成von Mises坐标(以流函数 $\psi$ 作为横向坐标的变换):

$$\frac{\partial u}{\partial x} = \nu\,\frac{\partial^2}{\partial \psi^2}\!\left(\frac{u^2}{2}\right) - \frac{1}{\rho u}\frac{dp}{dx}$$

每个网格是一根携带相同流量的流管。每一步用牛顿法确定压力梯度 $dp/dx$,使流管宽度之和 $\sum \Delta\psi/u$ 等于管道宽度。这样写,离散格式也能严格守恒动量。$\varepsilon\to0$ 就是Borda–Carnot的静止流体极限。

```python
import numpy as np

def stream_tubes(sigma, eps, n=40):
    # n 根流管(流量均为 dpsi):中间为射流(u=1),外侧为慢流(u=eps)
    Q = sigma + eps * (1 - sigma)
    dpsi = Q / n
    n_jet = round(n * sigma / Q)
    k = np.arange(n)
    jet = np.abs(k - (n - 1) / 2) < n_jet / 2
    u = np.where(jet, 1.0, eps)
    return u, dpsi, jet

def mix_step(u, P, dpsi, nu, H, dx):
    q = u**2 / 2
    qg = np.concatenate(([q[0]], q, [q[-1]]))          # 滑移壁: dq/dpsi = 0
    Dq = nu * (qg[2:] - 2 * q + qg[:-2]) / dpsi**2     # (1/u) * 黏性项
    for _ in range(20):                                 # 由管道宽度守恒确定 dp/dx (牛顿法)
        un = u + dx * (Dq - P / u)
        if un.min() <= 0:
            return None, P                              # 慢流管停滞 -> 回流
        f = np.sum(dpsi / un) - H
        df = np.sum(dpsi * dx / (u * un**2))
        P -= f / df
        if abs(f) < 1e-13:
            break
    return u + dx * (Dq - P / u), P

def mixing_duct(sigma, eps, nu, n=40, tol=1e-3):
    u, dpsi, jet = stream_tubes(sigma, eps, n)
    u0 = u.copy()
    H = np.sum(dpsi / u)                    # 管道宽度 (~1)
    Q = n * dpsi                            # 每根流管流量相同
    V2 = Q / H
    M0 = np.sum(u * dpsi) / H               # 入口动量通量 / H
    dp_mom = M0 - V2**2                     # 动量守恒给出的压升
    E0 = np.sum(u**2 / 2 * dpsi) / Q
    x, p, P, x99 = 0.0, 0.0, 0.0, None
    while np.abs(u - V2).max() > tol:
        dx = 0.4 * dpsi**2 / (nu * u.max())
        un, P = mix_step(u, P, dpsi, nu, H, dx)
        if un is None:
            return dict(stall=True, x=x, dp=p, dp_mom=dp_mom)
        u, x, p = un, x + dx, p + P * dx
        if x99 is None and p >= 0.99 * dp_mom:
            x99 = x
    loss = E0 - (p + np.sum(u**2 / 2 * dpsi) / Q)
    # Carnot 定理:各流管损失(获得)速度的动能之和
    carnot = np.sum(0.5 * (u0 - V2)**2 * dpsi) / Q
    return dict(stall=False, x99=x99, V2=V2, dp=p, dp_mom=dp_mom,
                dp_bern=0.5 * (1 - V2**2), loss=loss, carnot=carnot)

print("Borda-Carnot limit (eps=0, sigma=0.5): dp = %.4f, loss = %.4f, Bernoulli dp = %.4f"
      % (0.5 * 0.5, 0.5 * 0.5**2, 0.5 * (1 - 0.5**2)))
print(" eps    nu     V2    dp_num  dp_mom  dp_Bern  loss    Carnot   x99")
for eps, nu in [(0.8, 0.004), (0.6, 0.004), (0.4, 0.004), (0.2, 0.004),
                (0.1, 0.004), (0.05, 0.004), (0.2, 0.002), (0.2, 0.008)]:
    r = mixing_duct(0.5, eps, nu, n=80)
    if r["stall"]:
        print(f"{eps:4.2f} {nu:6.3f}  STALL at x={r['x']:.2f}  "
              f"dp={r['dp']:.4f} of {r['dp_mom']:.4f}")
        continue
    print(f"{eps:4.2f} {nu:6.3f} {r['V2']:6.3f} {r['dp']:7.4f} {r['dp_mom']:7.4f} "
          f"{r['dp_bern']:7.4f} {r['loss']:7.4f} {r['carnot']:7.4f} {r['x99']:6.1f}")
```

## 0.1599与0.3270,以及ν改变不了的东西

从输出表中可以读出三点。

第一,所有行中 `dp_num` 与 `dp_mom` 在小数点后四位一致。数值解一步步计算了混合过程,但结果早已由入口与出口的动量差决定。压升是动量收支的结果。

第二,`loss` 与 `Carnot` 也在所有行中一致。在每根流管速度变为 $V_2$ 的过程中,管道损失了能量。这一损失与失去速度的动能之和严格相等,正是Carnot在碰撞中计算的量。

第三,$\nu$ 从0.002变到0.008,改变了四倍。`x99`(达到最终压力99%所需的距离)从16.2缩短到4.1,而 `dp_num` 和 `loss` 仍为0.1599和0.0831。黏性只决定损失**在哪里**发生,不决定损失**有多少**。

伯努利(沿射流流线)在同一行给出0.3270,是真实值的2.0倍。$\varepsilon=0.8$ 时为0.0960对0.0100,差距达9.6倍。两股流速度差越小,真实压升本身越小,而伯努利跟不上这一变化。随着 $\varepsilon$ 减小,`dp_num` 逼近0.2255($\varepsilon=0.05$),朝着Borda–Carnot的极限值0.25靠拢。

$\varepsilon=0.03$ 及以下时计算停止。逆压梯度让慢流停了下来,而抛物型推进无法表示回流。在真实的突扩中,恰恰在这里形成回流区。Borda的假设“台阶面压力 = $p_1$”就是用静止流体替代了这个回流区。

## 今天的Borda–Carnot:从管网K值到一维代码

管道设计手册中的突扩损失系数 $K=(1-A_1/A_2)^2$ 正是这个公式。它与湍流实验值大体吻合,因为台阶后的回流接近静止流体的假设。管网分析程序、一维热工水力系统程序以及燃料系统分析至今仍以它为默认值。

失效的情形也很明确。第一,入口速度分布不均匀时,动量通量不再是 $\rho V^2 A$。对于充分发展的层流管流,动量修正系数 $\beta=4/3$,能量修正系数 $\alpha=2$。[管截面速度分布与动能修正系数](/zh/posts/2026-09-17-kinetic-energy-coefficient-pipe-profile/)中讨论的 $\alpha$ 会直接进入公式。第二,低雷诺数下回流区本身变长,壁面摩擦也掺杂进来。第三,在缓扩的扩压管(diffuser)中分离推迟,$K$ 小得多。

CFD中也会遇到同样的问题。准一维(quasi-1D)管流程序单独离散面积变化项 $p\,dA/dx$。当面积在一个单元内突变时,这个 $p$ 取什么值,正是Borda的假设。用上游压力会得到Borda–Carnot损失;像光滑喷管那样处理,则得到无损失的伯努利解。引射器(用高速射流卷吸低速流的装置)和射流泵的混合管设计,用的也正是上面代码中的动量收支。

## 从表中取出突扩K值之前要确认的两个条件

使用 $K=(1-\sigma)^2$ 之前先确认两点:入口速度分布是否接近均匀(充分发展湍流时 $\beta\approx1.02$ 即可);雷诺数是否足够大,能在台阶后形成可视为静止流体的回流区。两者都满足时,压升就是 $\rho V_2(V_1-V_2)$,损失就是失去速度的动能。不必追问两股流如何混合。
