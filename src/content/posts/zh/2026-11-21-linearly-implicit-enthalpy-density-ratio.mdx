## 同样 112 步，其中一个在第 40 步发散

我写了两份半隐式（semi-implicit）可压缩求解器。差别只有一行：计算焓时，密度用 $\rho^n$ 还是 $\rho^{n+1}$ 做分母。测试是最简单的那种。在压力和速度都均匀的流场里放一个密度鼓包，让它在周期区域里绕一圈。精确解就是"鼓包原样平移"。

$\rho^{n+1}$ 版本用 112 步走完一圈，速度误差约 $2\times10^{-4}$。$\rho^n$ 版本无论马赫数是 0.5 还是 0.01，都恰好在第 40 步发散。

本文解读 Battisti 和 Boscheri 2025 年发表在 JCP 上的论文 *A linearly implicit shock capturing scheme for compressible two-phase flows at all Mach numbers*。论文式 (18) 用一行把焓定义为 $\rho^n h^n/\rho^{n+1}$，随即带过。读完本文，你可以自己推导出这一行为什么必要，并用一维单相复现代码核对数字。

## 等压平流中焓通量为什么必须是常数

半隐式格式分两步更新动量和能量。先显式计算对流（流体携带物理量的项），得到带星号的中间值 $\rho^\star, q^\star$。再隐式求解含压力的项。

能量方程的隐式部分包含焓通量 $h\,q$。其中 $h = \gamma p/((\gamma-1)\rho)$ 是比焓（单位质量的焓），$q=\rho u$ 是动量。这一项的散度驱动压力变化。

现在考虑 $u$ 和 $p$ 均匀的情形。显式对流以相同速度输运 $q$ 和 $\rho$，所以对流之后 $q^\star = u\,\rho^\star$ 严格成立。焓通量写成：

$$
h\,q^\star = \frac{\gamma p}{\gamma-1}\,u\,\frac{\rho^\star}{\rho_{\text{den}}}
$$

$\rho_{\text{den}}$ 是构造焓时所除的密度。若 $\rho_{\text{den}} = \rho^\star = \rho^{n+1}$，比值为 1。通量在空间上为常数，散度为零，压力不变。若 $\rho_{\text{den}}=\rho^n$，比值 $\rho^\star/\rho^n$ 在鼓包附近起伏。这个起伏每一步都变成一个虚假的压力源。

下面的模拟可以直接动手操作。它让鼓包流动，并把两种分母给出的通量和压力源并排画出。

## 论文的模型：Baer–Nunziato 七方程

论文研究的是 Baer–Nunziato 模型。两相（phase）各有质量、动量、能量方程，再加上固相体积分数 $\phi_s$ 的输运方程，共七个方程。界面压力 $p_I$ 和界面速度 $\mathbf{u}_I$ 通过非守恒项把两相耦合起来。

每一相采用刚性气体（stiffened gas）状态方程。内能对压力是线性的，这一点后面很关键。

$$
\rho_\alpha e_\alpha = \frac{p_\alpha + \gamma_\alpha \pi_\alpha}{\gamma_\alpha - 1}
$$

$\gamma_\alpha$ 是比热比，$\pi_\alpha$ 是模拟液体的刚化压力。空气取 $\pi=0$，水取数亿 Pa 量级。

## 哪些项隐式，哪些项显式

论文的一阶半离散格式（式 12）这样划分各项。带上相下标 $\alpha$，只写动量和能量方程：

$$
(\rho_\alpha\phi_\alpha\mathbf{u}_\alpha)^{n+1} = \mathbf{q}^\star_\alpha - \Delta t\,\nabla(\phi_\alpha p_\alpha)^{n+1} + \Delta t\,p_I^n\nabla\phi_\alpha^{n+1}
$$

$$
(\rho_\alpha\phi_\alpha E_\alpha)^{n+1} = E^\star_\alpha - \Delta t\,\nabla\cdot\big(h^n_\alpha(\rho_\alpha\phi_\alpha\mathbf{u}_\alpha)^{n+1}\big) + \Delta t\,p_I^n\mathbf{u}_I^n\nabla\phi_\alpha^{n+1}
$$

$\mathbf{q}^\star_\alpha, E^\star_\alpha$ 是显式施加非线性对流通量后的值。压力梯度和焓通量在隐式一侧。携带声波的刚性（stiff）项正是这两项。

关键在于把能量通量拆成动能部分 $\rho k\mathbf{u}$ 和焓部分 $h\rho\mathbf{u}$。动能部分视为对流，显式计算。焓部分与压力一起隐式处理。

## 让压力方程保持线性的两个手段

把动量方程代入能量方程，得到关于 $(\phi_\alpha p_\alpha)^{n+1}$ 的波动方程（式 17）。如果不做处理，新时间层的动能 $\tfrac12\rho u^2$ 会以未知量平方的形式出现。论文用两个手段避免这一点。

第一，对动能做半隐式线性化（式 15）：

$$
(\rho_\alpha\phi_\alpha k_\alpha)^{n+1} := \frac12\,\frac{(\rho_\alpha\phi_\alpha\mathbf{u}_\alpha)^n}{(\rho_\alpha\phi_\alpha)^n}\,(\rho_\alpha\phi_\alpha\mathbf{u}_\alpha)^{n+1}
$$

一个旧速度 $\mathbf{u}^n$ 乘一个新动量，平方项消失。

第二，刚性气体状态方程使内能成为压力的一次式。两者叠加，压力方程组严格线性。无需牛顿迭代，一次 GMRES 即可求解。这就是论文称之为"线性隐式（linearly implicit）"的原因。

论文也写明了代价（Remark 1）。线性化的动能使热力学一致性偏离 $O(\Delta t^q)$，$q$ 是格式的时间精度阶数。

最后是式 (18)。波动方程中的焓取为：

$$
h^n_\alpha := \frac{\rho^n_\alpha h^n_\alpha}{\rho^{n+1}_\alpha}
$$

分子是旧时间层的焓密度，分母是显式对流后已知的新密度。这正是让上一节比值 $\rho^\star/\rho_{\text{den}}$ 等于 1 的选择。论文借此证明了离散层面对等速、等压流动的保持（well-balanced 性质的一部分）。

## 时间步长只看物质速度

压力和焓项是隐式的，所以声速从时间步长条件中消失。论文的条件（式 11）为：

$$
\Delta t \le \mathrm{CFL}\,\min_\Omega \frac{\varrho}{\max(|\mathbf{u}_f\cdot\mathbf{n}|, |\mathbf{u}_s\cdot\mathbf{n}|)}
$$

$\varrho$ 是网格的特征长度，$\mathbf{u}_f, \mathbf{u}_s$ 是两相速度。马赫数为 0.01 时，声学库朗数可达约 90。时间步长上的这一收益，在[参考态 IMEX 双流体求解器解读](/zh/posts/2026-11-01-rs-imex-two-fluid-material-cfl/)中已详细讨论。

本文论文的不同之处在于隐式项采用中心差分离散，声学项中不引入迎风（upwind）耗散。低马赫数下与声速成正比的数值黏性会抹掉解，这一问题在[渐近保持 IMEX 波动格式解读](/zh/posts/2026-06-21-asymptotic-preserving-low-mach-wave/)中已经看到。激波只靠对流项的 TVD 有限体积来捕捉。

## 代码：简化为一维单相的线性隐式格式，两种分母

复现简化为单相、理想气体（$\pi=0$）、一阶精度。取体积分数 $\phi=1$，所有 $p_I$ 项都消失。剩下的是式 (13) 的显式对流、式 (17) 的线性压力方程和式 (14) 的守恒型更新。

- 100 个网格，周期边界，$\gamma=1.4$
- 初始条件：$\rho = 1 + 0.2\,e^{-((x-0.5)/0.05)^2}$，$p = 1/\gamma$（声速 ≈ 1），$u_0 = $ 马赫数
- 三种格式对比：显式 Rusanov（耗散含声速）、半隐式 + 式 (18)、半隐式 + 分母 $\rho^n$
- 一圈（$T=1/u_0$）内测量：步数、最大 $|u-u_0|/u_0$、鼓包高度保持率

```python
import numpy as np

g, N = 1.4, 100
dx = 1.0 / N
x = (np.arange(N) + 0.5) * dx
R = lambda a: np.roll(a, -1)   # i+1 (周期边界)
L = lambda a: np.roll(a, 1)    # i-1

def initial(mach):
    rho = 1.0 + 0.2 * np.exp(-((x - 0.5) / 0.05) ** 2)   # 密度鼓包
    u = np.full(N, mach)
    p = np.full(N, 1.0 / g)                               # c ≈ 1 → u0 = 马赫数
    return rho, rho * u, p / (g - 1) + 0.5 * rho * u**2

def rusanov(Ul, Ur, Fl, Fr, a):
    return 0.5 * (Fl + Fr) - 0.5 * a * (Ur - Ul)

def explicit_step(rho, q, E, dt):
    u = q / rho
    p = (g - 1) * (E - 0.5 * rho * u**2)
    s = np.abs(u) + np.sqrt(g * p / rho)
    a = np.maximum(s, R(s))                               # 含声速的耗散
    out = []
    for U, F in zip([rho, q, E], [q, q * u + p, (E + p) * u]):
        f = rusanov(U, R(U), F, R(F), a)
        out.append(U - dt / dx * (f - L(f)))
    return out

def semi_implicit_step(rho, q, E, dt, h_den="new"):
    u = q / rho
    p = (g - 1) * (E - 0.5 * rho * u**2)
    k = 0.5 * rho * u**2
    a = np.maximum(np.abs(u), R(np.abs(u)))               # 仅物质速度
    star = []                                             # 式 (13): 显式对流
    for U, F in zip([rho, q, k], [q, q * u, k * u]):
        f = rusanov(U, R(U), F, R(F), a)
        star.append(U - dt / dx * (f - L(f)))
    rs, qs, ks = star
    Es = E - (k - ks)
    den = rs if h_den == "new" else rho                   # 式 (18): rho^{n+1} vs rho^n
    h = g * p / ((g - 1) * den)
    hf, qf = 0.5 * (h + R(h)), 0.5 * (qs + R(qs))
    # 式 (17): 关于压力线性的波动方程，中心差分
    i = np.arange(N); ip, im = (i + 1) % N, (i - 1) % N
    c2 = dt**2 / dx**2
    A = np.zeros((N, N))
    A[i, i] = 1 / (g - 1) + c2 * (hf + L(hf))
    A[i, ip] = -u * dt / (4 * dx) - c2 * hf
    A[i, im] = +u * dt / (4 * dx) - c2 * L(hf)
    b = Es - 0.5 * u * qs - dt / dx * (hf * qf - L(hf * qf))
    pn = np.linalg.solve(A, b)
    qn = qs - dt * (R(pn) - L(pn)) / (2 * dx)             # 式 (14b)
    qfn = qf - dt * (R(pn) - pn) / dx
    En = Es - dt / dx * (hf * qfn - L(hf * qfn))          # 式 (14c)
    return rs, qn, En

def lap(mach, scheme, cfl=0.9, h_den="new"):
    rho, q, E = initial(mach)
    T = 1.0 / mach                                        # 绕区域一圈
    speed = mach + 1.0 if scheme == "explicit" else mach
    n = int(np.ceil(T / (cfl * dx / speed)))
    dt, du = T / n, 0.0
    for k in range(n):
        if scheme == "explicit":
            rho, q, E = explicit_step(rho, q, E, dt)
        else:
            rho, q, E = semi_implicit_step(rho, q, E, dt, h_den)
        du = max(du, np.abs(q / rho - mach).max() / mach)
        if not np.isfinite(du) or du > 1:
            return n, f"blow@{k + 1}", np.nan
    return n, f"{du:.1e}", (rho.max() - 1) / 0.2

print("Mach | explicit: steps  peak | eq18 rho^n+1: steps  du/u0   peak "
      "| rho^n: CFL0.9    CFL0.3 du/u0")
for M in [0.5, 0.1, 0.03, 0.01]:
    ne, _, pe = lap(M, "explicit")
    ni, di, pi = lap(M, "semi")
    _, d9, _ = lap(M, "semi", 0.9, "old")
    _, d3, _ = lap(M, "semi", 0.3, "old")
    print(f"{M:4.2f} | {ne:15d} {pe:5.3f} | {ni:19d} {di:>7s} {pi:5.3f} "
          f"| {d9:>12s} {d3:>12s}")
```

## 读表：112、0.738、40 和 1%

**112.** 半隐式格式的步数与马赫数无关。时间步长是 $0.9\,\Delta x/u_0$，一圈耗时 $1/u_0$。显式格式在马赫数 0.01 时需要 11,223 步，约为 100 倍。

**0.738.** 使用式 (18) 的半隐式格式，鼓包高度同样与马赫数无关，因为对流耗散只与 $|u|$ 成正比。显式 Rusanov 的耗散系数包含声速。从马赫数 0.03 起，其鼓包高度饱和在 0.089。这正是把鼓包质量均匀摊到整个区域后的高度，也就是说鼓包已被完全抹平。

**40.** 分母取 $\rho^n$ 的格式在四个马赫数下都在第 40 步发散。虚假压力源的大小为 $\rho^\star/\rho^n - 1$，由物质库朗数和鼓包斜率决定。马赫数不出现在这个比值中，所以发散的步数也相同。

**1%.** 把 CFL 降到 0.3，$\rho^n$ 格式也能撑过一圈，但速度误差约为 1%，约是式 (18) 的 $2\times10^{-4}$ 的 50 倍。只看等压平流测试，这很容易被当作"小噪声"忽略。在界面要穿过数百次的实际计算中，它会不断累积。

## 本复现省略了什么

论文的主体是两相模型。复现省略了以下全部内容：

- 界面压力 $p_I$ 和体积分数梯度项。论文对这些非守恒项的离散保证了运动平衡态的保持（3.7 节）。
- 压力、速度松弛（relaxation）源项。论文在求解齐次系统之后单独进行松弛（3.5 节）。
- 二阶 IMEX 时间推进、TVD 重构以及二阶数值耗散（3.2 节、3.4 节）。
- 低马赫极限下趋向混合物模型的渐近保持证明（3.6 节）。

因此"40 步"只是这个一维设置下的数字，并非普适常数。但产生比值 $\rho^\star/\rho_{\text{den}}$ 的结构在单相和两相中是一样的。两相情形下，只是由 $\rho_\alpha\phi_\alpha$ 占据同一位置。

## 给基于压力的半隐式代码加的第一个测试

写好一个新的半隐式求解器后，先别急着跑激波管，先跑等速等压的密度鼓包。精确解显而易见，一旦出错数字会跳得很明显。检查三件事：

1. 焓（或任何包含 $p/\rho$ 的系数）除的是哪个密度？若该系数进入隐式步，就除以显式对流之后的密度。
2. 把物质 CFL 提高到接近 1 时，$|u-u_0|/u_0$ 是否仍停留在舍入误差附近？
3. 把马赫数逐级降低一个数量级时，鼓包高度是否不变？若有变化，说明声学项中某处仍残留与声速成正比的耗散。
