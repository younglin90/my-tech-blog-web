## 只用一块面板，升力却完全准确

我用一个涡(vortex)近似攻角5°的平板翼。面板只有一块。结果升力系数与理论值 $2\pi\alpha$ 在小数点后四位一致。接着把控制点往前挪了半格。这一次即使把面板加到64块，升力也恰好只有一半。

"网格越密误差越小"的直觉在这里失灵了。本文推导空气动力学教材中"涡放1/4、控制点放3/4"的规则从何而来。然后用代码测量位置改变后什么会被破坏。读完之后，你可以用一个数字检查涡格法(VLM)或面板代码的布置规则。

## 薄翼理论要求什么：涡片 γ(x)

薄翼理论(thin airfoil theory)把翼型换成铺在弦线上的涡片(vortex sheet，连续分布的涡)。设涡片强度为 $\gamma(x)$。条件只有一个：不能有流动穿过翼面。

$$
\frac{1}{2\pi}\int_0^c \frac{\gamma(x')\,dx'}{x-x'} = V_\infty\left(\alpha - \frac{dz}{dx}\right), \qquad 0<x<c
$$

$V_\infty$ 是来流速度，$\alpha$ 是攻角，$z(x)$ 是中弧线，$c$ 是弦长。左边是涡片诱导的下洗(downwash，向下的法向速度)。此外还要加上后缘处 $\gamma(c)=0$ 的 Kutta 条件。

平板($z=0$)的解是经典结果。

$$
\gamma(x) = 2V_\infty\alpha\sqrt{\frac{c-x}{x}}, \qquad \Gamma = \int_0^c\gamma\,dx = \pi c V_\infty\alpha
$$

$\Gamma$ 是总环量。代入 Kutta–Joukowski 定理 $L'=\rho V_\infty\Gamma$，得到 $C_L = 2\pi\alpha$。环量与升力的关系在[环量与升力：Kutta–Joukowski](/zh/posts/2026-05-07-circulation-lift-kutta-joukowski/)中讨论过。还有一个重要事实：这个分布的形心(centroid)恰好位于 $c/4$。所以平板对1/4弦点的力矩为零。

## 一个涡、一个控制点 — 半弦长规则从何而来

把连续涡片换成一个点涡。涡放在 $x=a$，控制点(collocation point，施加不穿透条件的点)放在 $x=b$。点涡在距离 $r$ 处诱导的速度是 $\Gamma/(2\pi r)$。控制点处的下洗必须等于 $V_\infty\alpha$。

$$
\frac{\Gamma}{2\pi(b-a)} = V_\infty\alpha \quad\Longrightarrow\quad \Gamma = 2\pi(b-a)V_\infty\alpha
$$

要让这个 $\Gamma$ 等于精确值 $\pi cV_\infty\alpha$，必须 $b-a=c/2$。升力只由间距决定。涡的位置 $a$ 本身不进入升力。

$a$ 出现在力矩里。前缘力矩为 $M_{LE}=-\rho V_\infty\Gamma a$。精确涡片的合力作用在 $c/4$。所以要让力矩也正确，必须 $a=c/4$。两个条件合起来就是 $a=c/4$、$b=3c/4$。这就是教材中的 lumped vortex 规则。用弦向压差分布 $\Delta C_p = 2\gamma/V_\infty$ 来表述也是一样的。这种布置用一个点涡同时匹配两个数：合力的大小和作用点。

到这里还只是一块面板的情形。如果把弦分成 $N$ 块面板，每块内按相同比例放置涡和控制点，会怎样？按直觉，$N$ 越大，布置的影响应该越小。

## 代码：改变涡与控制点位置，面板1到64块

把弦长分成 $N$ 块等距面板。面板 $j$ 的涡位于 $x_j + a\,\Delta x$，控制点位于 $x_j + b\,\Delta x$。在所有控制点施加不穿透条件，得到 $N\times N$ 线性方程组。第一个实验在平板上固定 $a=0.25$，只改变 $b$。第二个实验在抛物线弯度 $z=4hx(1-x)$ 上比较三种布置。

```python
import numpy as np

def lumped_vortex(N, a, b, alpha, h=0.0):
    """薄翼(c=1, V=1)：每块面板中涡位于比例 a，控制点位于比例 b"""
    xe = np.linspace(0.0, 1.0, N + 1)
    dx = xe[1:] - xe[:-1]
    xv = xe[:-1] + a * dx                  # 涡的位置
    xc = xe[:-1] + b * dx                  # 控制点位置
    slope = 4 * h * (1 - 2 * xc)           # 抛物线弯度 z = 4h x(1-x)
    A = 1.0 / (2 * np.pi * (xc[:, None] - xv[None, :]))
    G = np.linalg.solve(A, alpha - slope)  # 控制点处法向速度为0
    CL = 2 * G.sum()                       # Kutta-Joukowski
    Cm_le = -2 * (G * xv).sum()
    return CL, Cm_le

Ns = (1, 2, 4, 16, 64)
alpha = np.radians(5.0)
CL0 = 2 * np.pi * alpha
print(f"[1] flat plate, alpha=5deg, CL / 2*pi*alpha   (a = 0.25)")
print(f"{'b':>6} " + "".join(f"{'N=' + str(n):>9}" for n in Ns))
for b in (0.50, 0.65, 0.75, 0.85, 1.00):
    print(f"{b:6.2f} " + "".join(f"{lumped_vortex(n, 0.25, b, alpha)[0] / CL0:9.4f}" for n in Ns))

al, h = np.radians(2.0), 0.04
CLx = 2 * np.pi * (al + 2 * h)
Cmx = -np.pi / 2 * (al + 4 * h)
print(f"\n[2] parabolic camber h=0.04c, alpha=2deg  exact CL={CLx:.4f}  Cm_le={Cmx:.4f}")
print(f"{'(a,b)':>11} " + "".join(f"{'N=' + str(n):>9}" for n in Ns) + "   <- CL error %")
for a, b in ((0.25, 0.75), (0.00, 0.50), (0.50, 1.00)):
    errs = [100 * (lumped_vortex(n, a, b, al, h)[0] / CLx - 1) for n in Ns]
    print(f"({a:.2f},{b:.2f}) " + "".join(f"{e:+9.2f}" for e in errs))
print(f"{'(a,b)':>11} " + "".join(f"{'N=' + str(n):>9}" for n in Ns) + "   <- Cm_le error %")
for a, b in ((0.25, 0.75), (0.00, 0.50), (0.50, 1.00)):
    errs = [100 * (lumped_vortex(n, a, b, al, h)[1] / Cmx - 1) for n in Ns]
    print(f"({a:.2f},{b:.2f}) " + "".join(f"{e:+9.2f}" for e in errs))
```

## 为什么 2(b−a) 与面板数无关

表[1]的数字很干净。每一行都是 $2(b-a)$：$b=0.5$ 时为0.5，$b=1.0$ 时为1.5。面板加到64块，第四位小数也不变。

原因在于等距网格的自相似性。影响系数的形式是 $1/\big(2\pi\Delta x\,(i-j+b-a)\big)$。整个矩阵只依赖间距比 $b-a$。一块面板上产生的 $2(b-a)$ 倍误差，在细分后以相同结构重复出现。不管网格多密，每块面板都在用同一条错误规则。这是不会收敛消失的相容性误差(consistency error)。

反过来，只要 $b-a=1/2$，无论 $N$ 是多少，总环量都是精确的。J. C. James 在1972年解析地证明了这种"惊人的精度"。单个离散环量 $\Gamma_j$ 与精确 $\gamma$ 在该面板上的积分并不相同。但它们的总和恰好正确。

## 加上弯度后，只有 a = 1/4 能幸存

对平板而言，只要 $b-a=1/2$ 就够了。代码里 $(0, 0.5)$ 和 $(0.5, 1.0)$ 的平板升力也都准确。加上弯度，情况就变了。抛物线弯度的精确解是 $C_L = 2\pi(\alpha + 2h/c)$。

$(0.25, 0.75)$ 从一块面板起误差就是0.00%。$(0, 0.5)$ 从−69.62%开始，$N$ 每翻一倍误差减半。这是一阶收敛。$(0.5, 1.0)$ 大小相同、符号相反。涡偏前时升力偏小，偏后时升力偏大。

弯度斜率 $dz/dx$ 随位置变化。控制点前后移动，采样到的斜率就不同。只有涡和控制点同时放对，这种采样误差才会相互抵消。平衡点就是 $a=1/4$。

力矩的表现不同。$(0.25, 0.75)$ 的 $C_{m,LE}$ 误差从 −41.05 → −10.26 → −2.57，每次缩小为四分之一。这是二阶收敛。一块面板时力矩误差为41%。平板的合力作用在 $c/4$，但弯度会在1/4点产生纯力矩 $C_{m,c/4} = -\pi h/c$。单个点涡无法表示这个力偶(couple)。另外两种布置的力矩也只有一阶收敛。

## 涡格法与面板法中的1/4–3/4

这条规则并不止于教材习题。三维涡格法(VLM)把马蹄涡(horseshoe vortex)的附着涡放在每块面板的1/4弦处，控制点放在3/4弦处。即使弦向只用一块面板，二维截面升力也能算准，原因正是上面的结果。

与用复势构造圆柱绕流的方法([复势与 d'Alembert 佯谬](/zh/posts/2026-05-21-complex-potential-cylinder-dalembert/))比较，区别就很明显。那里用保角映射得到精确解。面板法放弃精确解，转而离散地布置奇点。布置规则决定了精度。

非等距网格需要小心。像余弦分布那样面板长度变化时，自相似性被破坏。于是1/4–3/4不再"与面板数无关地精确"，而变成随网格加密而收敛的普通近似。

## 移动涡之前先打印的一个比值

检查自己的 VLM 或面板代码很简单。用一块面板求解平板，输出 $C_L/2\pi\alpha$。如果不是1，把这个值除以2，就是你实际使用的涡—控制点间距。若输出0.5000，说明控制点离涡只有1/4块面板，而不是半块。这个误差即使网格加密64倍也不会消失。

接着加入抛物线弯度，检查 $N=1$ 时 $C_L$ 是否等于 $2\pi(\alpha+2h)$。若相等，涡就在1/4点。这个两行的测试能比网格收敛研究更早发现布置错误。
