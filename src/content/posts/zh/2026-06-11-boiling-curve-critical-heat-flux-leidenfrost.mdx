1934 年的东京，拔山一边升高镍铬丝的电流，一边看水里的气泡。气泡最猛的时候和丝熔断的时候之间，他什么也没看见。那段空白里，热流密度并不跟着过热度一起上升。

在 Temperature control 里推动 ΔTe 滑条，工作点沿着曲线走。换成 Heat-flux control，同一个热流密度会分出两个壁温。

把热流密度推过峰顶，点就从核态沸腾那一支跳到膜态沸腾那一支。拔山那根丝熔化的位置，就是这一跳。

## 沸腾曲线 — 一张图里的四个区域

沸腾是发生在固体和液体边界上的蒸发。壁面热流密度写成

$$q'' = h\,(T_s - T_{sat}) = h\,\Delta T_e$$

$T_s$ 是壁温，$T_{sat}$ 是饱和温度（水，1 个大气压，100°C），$\Delta T_e$ 是二者之差，也就是过热度。$h$ 是对流换热系数。

过热度加大，$q''$ 好像会单调上升。画在双对数坐标上，四个区间依次出现。

- **自然对流**（$\Delta T_e \lesssim 5$°C）：几乎没有气泡。浮力驱动的自然对流把热带走。
- **核态沸腾**（$5 \lesssim \Delta T_e \lesssim 30$°C）：气泡从成核点涌出。$q''$ 在这里最陡。
- **过渡沸腾**（$30 \lesssim \Delta T_e \lesssim 120$°C）：蒸汽膜开始部分盖住壁面。$q''$ 下降。
- **膜态沸腾**（$\Delta T_e \gtrsim 120$°C）：连续的蒸汽膜盖住壁面。辐射加进来，$q''$ 再次上升。

图上那个点走的就是这四段。热流密度一旦固定，过渡段就不是稳定的工作点。点会跳到核态沸腾，或者跳到膜态沸腾。

## 核态沸腾 — 气泡把热量汲上来

核态沸腾之所以冷得下来，与其说是气泡本身，不如说是气泡离开的位置涌进冷液体。壁面附近的液体一直在换。

Rohsenow 把这一段的热流密度写成

$$
q''_s = \mu_l\, h_{fg}\sqrt{\frac{g(\rho_l - \rho_v)}{\sigma}}
\left(\frac{c_{p,l}\,\Delta T_e}{C_{s,f}\,h_{fg}\,Pr_l^{\,n}}\right)^3
$$

$\mu_l$ 是液体黏度，$h_{fg}$ 是蒸发潜热，$\rho_l,\rho_v$ 是液体和蒸汽的密度，$\sigma$ 是表面张力，$c_{p,l}$ 是液体比热，$Pr_l$ 是液体 Prandtl 数。$C_{s,f}$ 是表面和液体组合的实验常数。水-铂是 0.013。

$q''_s$ 按 $\Delta T_e$ 的三次方上升。过热度只抬一点，热流密度就跳得很大。反应堆堆芯、CPU 水冷、锅炉都盯着这道窄带。潜热靠扩散离开，是另一条路。[同样的潜热靠扩散把表面晾干](/zh/posts/2026-07-30-evaporation-source-term-d2-law-lee-model/) 的时候，壁面低于饱和温度也会进行。

## 临界热流密度 — Zuber 预言的悬崖

三次方维持不久。气泡太密就会彼此粘住、盖住壁面，液体再也碰不到壁。就在那之前，$q''$ 达到最大。这就是临界热流密度（CHF）。水在 1 个大气压下超过 1 MW/m²。

Zuber 从蒸汽柱发生 Kelvin–Helmholtz 失稳的条件写下 CHF。

$$
q''_{max} \approx 0.149\, h_{fg}\, \rho_v
\left[\frac{\sigma\, g\,(\rho_l - \rho_v)}{\rho_v^2}\right]^{1/4}
$$

符号与前面相同，$\rho_v$ 是蒸汽密度。壁温和表面材料都不在这个式子里。CHF 只由流体物性决定。

热流密度受控的加热一旦越过 CHF，工作点就从核态沸腾跳到膜态沸腾。同样的热流密度要靠膜态沸腾扛住，壁温得升高几百度。金属在那之前就化了。拔山看见的那一跳就是这个。

## 膜态沸腾与莱顿弗罗斯特

过渡沸腾的尽头，$q''$ 再次落到最低，那一点是莱顿弗罗斯特点。再往外，连续蒸汽膜盖住壁面，液体碰不到固体。热量只能靠穿过蒸汽的导热和辐射。蒸汽的导热比液体差得远。

锅只是比较烫的时候，水滴沸腾着很快消失。锅非常烫的时候，水滴浮在自己的蒸汽膜上，留得更久。

水平圆柱上的膜态沸腾写成

$$
\overline{Nu}_D = C\left[\frac{g(\rho_l-\rho_v)\,h'_{fg}\,D^3}{\nu_v\, k_v\,(T_s - T_{sat})}\right]^{1/4}
$$

$D$ 是直径，$\nu_v, k_v$ 是蒸汽的运动黏度和导热系数，$C$ 是形状常数（水平圆柱 0.62，球 0.67）。$h'_{fg} = h_{fg} + 0.8\,c_{p,v}(T_s - T_{sat})$ 是按蒸汽过热修正过的潜热。过热度出现在分母的 1/4 次上，所以壁再烫，$h$ 反而变钝。

## Python — 亲手画出沸腾曲线

用 1 个大气压下水的物性，把 Rohsenow 核态沸腾和 Zuber 的 CHF 放进同一张表。

```python
import numpy as np

# 水, 1个大气压下的饱和物性
g    = 9.81       # m/s^2
rho_l = 957.9     # kg/m^3
rho_v = 0.5956
h_fg  = 2257e3    # J/kg
sigma = 0.0589    # N/m
mu_l  = 279e-6    # N.s/m^2
cp_l  = 4217.0    # J/kg.K
Pr_l  = 1.76
Csf, n = 0.013, 1.0   # 水-铂

def rohsenow_nucleate_flux(dTe):
    """Rohsenow 核态沸腾热流密度 q'' (W/m^2)."""
    bracket = np.sqrt(g * (rho_l - rho_v) / sigma)
    ja = cp_l * dTe / (Csf * h_fg * Pr_l**n)
    return mu_l * h_fg * bracket * ja**3

def zuber_critical_heat_flux():
    """Zuber 临界热流密度 (W/m^2)."""
    return 0.149 * h_fg * rho_v * (
        sigma * g * (rho_l - rho_v) / rho_v**2) ** 0.25

chf = zuber_critical_heat_flux()
print(f"CHF (Zuber)      = {chf/1e6:.3f} MW/m^2")

# 扫描核态沸腾分支, 找出达到 CHF 的过热度
for dTe in [5, 10, 20, 30, 40]:
    q = rohsenow_nucleate_flux(dTe)
    flag = "  <-- 超过 CHF (Rohsenow 失效)" if q > chf else ""
    print(f"dTe={dTe:3d} C : q''={q/1e6:6.3f} MW/m^2{flag}")
```

运行结果如下。

```text
CHF (Zuber)      = 1.259 MW/m^2
dTe=  5 C : q''= 0.017 MW/m^2
dTe= 10 C : q''= 0.137 MW/m^2
dTe= 20 C : q''= 1.094 MW/m^2
dTe= 30 C : q''= 3.692 MW/m^2  <-- 超过 CHF (Rohsenow 失效)
```

把表面温度滑条从 90°C 推到 400°C，水滴会从贴着壁面沸腾，变到浮上蒸汽膜。分界就在这条滑条上移动。

<LeidenfrostDropletDemo />

130°C 附近它冒着泡很快消失，超过 200°C 反而更烫、却留得更久。表里 30°C 那一行是已经越过 CHF 的核态沸腾尽头，这只滑条上的膜是同一条曲线的另一头。

把 10°C 那一行的 0.137 乘八，是 1.096。20°C 那一行是 1.094。乘二十七是 3.699，30°C 那一行是 3.692。过热度变成两倍、三倍时，三次方在表内是对得上的。

热流密度除以过热度就得到 $h$。5°C 是 3400 W/m²K，10°C 是 13700，20°C 是 54700。过热度加倍，$h$ 变成四倍。$q''$ 按三次方走，$h$ 就按平方走。

CHF 的 1.259 与 20°C 的 1.094 之比是 1.15。它的立方根大约是 1.048，$20\times 1.048$ 落在 21°C 附近。Rohsenow 碰到 Zuber 天花板的地方不是 30°C 那一行，而是大约 21°C。30°C 的 3.692 是 1.259 的 2.93 倍。那一行是关联式离开自己适用范围之后才印出来的数。

把 5°C 那一行的 0.017 乘八，是 0.136。10°C 那一行是 0.137，相差 0.001。10 除以 5 的热流密度之比是 8.06，2 的三次方是 8。20 除以 10 是 7.99。30 除以 20 是 3.375，与 1.5 的三次方相同。温度比不是 2 的时候，三次方仍然留到印出的三位。

0.017 是 CHF 的 1.35%。0.137 是 10.9%。30°C 那一行除以过热度，$h$ 是 123067 W/m²K。54700 乘以 2.25 是 123075。2.25 是 1.5 的平方。在印出的三位上，平方对得上。这个 $h$ 是越过天花板之后，式子给出的数。

Rohsenow 在 30°C 越过 CHF，不是式子写错了。它离开了适用范围。真实曲线在 CHF 处折下来。两个式子一起用的时候，必须把 1.259 MW/m² 当成天花板压住。

## 无量纲数的语言 — Jakob 与 Bond

**Jakob 数**是液体吸收的显热与潜热之比。

$$Ja = \frac{c_{p,l}\,\Delta T_e}{h_{fg}}$$

$Ja$ 小，就是潜热压过显热。水的潜热很大，沸腾里 $Ja$ 就小。Rohsenow 括号里的那一项就是这个 $Ja$。

**Bond 数**是浮力与表面张力之比。

$$Bo = \frac{g(\rho_l - \rho_v)\,L^2}{\sigma}$$

气泡的尺度 $L$ 从这两者的平衡里出来。直径按 $D_b \propto \sqrt{\sigma / [g(\rho_l-\rho_v)]}$ 来定。CHF 式子的四次方根里出现表面张力和密度差，原因在这里。气泡的大小和脱离频率决定热流密度的上限。

## 把已经离开适用范围的 30°C 一行当成设计点

20°C 时热流密度已经是天花板的 87%，两个式子相遇的地方大约是 21°C。把 30°C 那一行的 3.692 写成核态沸腾的设计热流密度，壁面没法在核态沸腾里接下这个热流。工作点跳进膜态沸腾，扛住同一个 $q''$ 的壁温会升高几百度。

蒸汽膜盖住壁面之后，还能不能靠摩擦读出热流密度，是另一件事。[只靠壁面摩擦估计热流密度的那个类比](/zh/posts/2026-06-23-reynolds-analogy-friction-heat/) 说的是液体还碰得到壁的时候。膜一旦夹在中间，这个类比还在不在，这张表并不回答。
