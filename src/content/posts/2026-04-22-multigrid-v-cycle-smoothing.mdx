오후 세 시, 32×32 격자에서 Poisson 방정식이 2초 만에 수렴했다. 같은 코드를 256×256으로 바꿨더니 3분을 기다려도 잔차가 움직이지 않는다. CPU는 바쁘다. 반복은 돌고 있다. 그런데 오차가 안 준다. 이 포스트는 그 정체의 원인을 푸리에 관점에서 해부하고, 격자 계층을 쌓는 것만으로 한 자릿수 이상 가속하는 방법을 본다. 다루는 것은 기하 멀티그리드(Geometric Multigrid, 격자 계층을 직접 쌓는 방식)의 V-cycle과 그 각 구성 요소다.

## Gauss-Seidel이 멈추는 순간

1D Poisson 문제 $-u'' = f$를 풀자. $N$개 격자점에 Gauss-Seidel(점별 반복 해법) 반복을 돌리면 처음 몇 번은 잔차가 뚝뚝 떨어진다. 그러다 어느 지점부터 곡선이 수평이 된다.

격자를 2배 키우면 정체가 더 심해진다. 반복 횟수는 $O(N^2)$ 스케일로 는다. CPU 사이클이 아까워진다.

원인을 보려면 오차 $e = u - u^*$를 푸리에 모드(sine 기저 $\sin(k\pi x)$)로 분해해야 한다.

## 오차의 푸리에 분해가 설명하는 정체

Jacobi 반복의 증폭 계수(한 번 반복에서 오차가 곱해지는 값)는 주파수 $k$에 대해 이렇다.

$$
\lambda_k = 1 - \omega \left(1 - \cos\frac{k\pi}{N}\right)
$$

여기서 $\omega$는 완화 계수(보통 2/3), $k$는 주파수 번호(1~N-1), $N$은 격자 수.

고주파($k \approx N/2$)에서는 $\cos(k\pi/N) \approx 0$이어서 $\lambda_k \approx 1/3$. 한 번에 1/3로 줄어든다. 빠르다.

저주파($k = 1$)에서는 $\cos(\pi/N) \approx 1 - (\pi/N)^2 / 2$. 증폭 계수가 거의 1에 붙는다. 한 번 반복에 0.0001%씩 준다. 안 풀린다.

결국 Gauss-Seidel은 **국소 평균 연산자**라서 짧은 파장만 smoothing한다. 긴 파장 오차는 남는다. 이것이 정체의 정체다.

## 왜 거친 격자로 넘기면 풀리는가

관찰 하나. 원래 격자($h = 1/N$)에서 긴 파장인 오차는, 두 배 거친 격자($H = 2h$)에서 보면 **짧은 파장**이다. 점 개수가 반이니 같은 sine 한 주기가 격자 단위로 두 배 빠르게 보인다.

이 관찰이 전부다. 거친 격자에서는 그 오차가 다시 고주파가 되어 smoother가 빨리 잡는다. 잡은 오차를 원래 격자로 되돌려 더해주면, 원래 격자의 저주파 오차가 제거된다.

이를 재귀적으로 쌓으면 모든 파장의 오차가 각자의 격자에서 "짧은 파장" 모드로 공격받는다. 반복 횟수가 격자 크기에 **거의 독립**이 된다. $O(N)$ 수렴. 이것이 멀티그리드의 전체 이야기다.

## V-cycle의 구성 요소

V-cycle은 세 연산자를 재귀로 엮은 패턴이다.

**Smoothing.** 각 레벨에서 몇 번($\nu_1$회) 반복을 돌려 고주파 오차를 지운다. Gauss-Seidel이나 weighted Jacobi를 쓴다.

**Restriction.** fine 격자의 잔차를 coarse 격자로 내린다. full-weighting 연산자가 전형적이다.

$$
r_i^{2h} = \tfrac{1}{4} r_{2i-1}^h + \tfrac{1}{2} r_{2i}^h + \tfrac{1}{4} r_{2i+1}^h
$$

여기서 $r^h$는 fine 잔차, $r^{2h}$는 coarse 잔차, 인덱스 $i$는 coarse 격자점.

**Prolongation.** coarse 격자에서 구한 보정 $e^{2h}$를 fine 격자로 올린다. 선형 보간이 기본이다. 같은 격자점은 복사, 중간점은 양쪽 평균.

이 셋을 아래 순서로 엮으면 V-cycle이 된다.

1. fine에서 $\nu_1$회 smoothing.
2. 잔차 계산 → restriction → coarse의 우변으로 사용.
3. coarse에서 재귀적으로 V-cycle. 가장 거친 레벨에선 직접 해를 구한다.
4. coarse 보정 → prolongation → fine 해에 더함.
5. fine에서 $\nu_2$회 post-smoothing.

경로를 그리면 레벨 축에서 아래로 내려갔다 올라온다. 그래서 V.

## Python으로 본 2-level multigrid

토이 문제로 $N=128$ Poisson을 풀자. weighted Jacobi smoother + 2-level V-cycle.

```python
import numpy as np

def poisson_operator(u, n):
    h2 = (1.0 / n) ** 2
    Au = np.zeros_like(u)
    Au[1:-1] = (2 * u[1:-1] - u[:-2] - u[2:]) / h2
    return Au

def weighted_jacobi(u, f, n, omega=2/3, sweeps=2):
    h2 = (1.0 / n) ** 2
    for _ in range(sweeps):
        u_new = u.copy()
        u_new[1:-1] = (1 - omega) * u[1:-1] + \
            omega * 0.5 * (u[:-2] + u[2:] + h2 * f[1:-1])
        u = u_new
    return u

def full_weighting_restrict(r_fine, n_fine):
    n_coarse = n_fine // 2
    r_coarse = np.zeros(n_coarse + 1)
    for i in range(1, n_coarse):
        j = 2 * i
        r_coarse[i] = 0.25 * r_fine[j-1] + 0.5 * r_fine[j] + 0.25 * r_fine[j+1]
    return r_coarse

def linear_prolongate(e_coarse, n_fine):
    n_coarse = n_fine // 2
    e_fine = np.zeros(n_fine + 1)
    e_fine[0:n_fine+1:2] = e_coarse
    e_fine[1:n_fine:2] = 0.5 * (e_fine[0:n_fine-1:2] + e_fine[2:n_fine+1:2])
    return e_fine

def two_level_vcycle(u, f, n):
    u = weighted_jacobi(u, f, n, sweeps=3)            # pre-smooth
    r = f - poisson_operator(u, n)                    # 잔차 f - Au
    r2h = full_weighting_restrict(r, n)               # coarse RHS
    e2h = np.zeros(n // 2 + 1)
    e2h = weighted_jacobi(e2h, r2h, n // 2, sweeps=20)  # coarse 근사 해
    e = linear_prolongate(e2h, n)                     # fine 보정
    u = u + e
    u = weighted_jacobi(u, f, n, sweeps=3)            # post-smooth
    return u

# 실행: N=128, f = sin(pi x) + 0.6 sin(8 pi x)
n = 128
x = np.linspace(0, 1, n + 1)
f = np.sin(np.pi * x) + 0.6 * np.sin(8 * np.pi * x)
u = np.zeros(n + 1)

for k in range(15):
    u = two_level_vcycle(u, f, n)
    r = np.linalg.norm(f - poisson_operator(u, n))
    print(f"cycle {k+1:2d}: ||r|| = {r:.3e}")
```

이 코드로 $N=128$에서 15 cycle이면 잔차가 기계 정밀도까지 내려간다. 같은 정밀도를 weighted Jacobi 단독으로 얻으려면 수천 번 반복이 필요하다.

## 실무 팁과 함정

**가장 거친 격자는 직접 풀어라.** 보통 4~8점까지 내려가서 tridiagonal solver나 LU로 끝낸다. smoother로 계속 가면 거친 격자에서도 정체가 생긴다.

**smoothing 횟수는 적게.** $\nu_1 = \nu_2 = 1\text{~}2$가 전형적이다. 더 많이 돌려도 수렴률 개선이 적다. V-cycle 자체가 모드별로 나눠 공격하므로 한 레벨에 오래 머물 이유가 없다.

**격자 정렬이 틀어지면 무너진다.** $N$이 2의 거듭제곱이어야 restriction이 깨끗하다. 그렇지 않으면 경계 처리에서 오차가 섞여 수렴이 느려진다.

**비정렬 격자에선 AMG를 써라.** 기하 계층을 쌓기 어려우면 algebraic multigrid(AMG, 대수적 멀티그리드)가 행렬 계수만으로 coarse level을 만든다. 비용은 크지만 복잡한 형상에 일반적으로 잘 먹힌다.

**전처리자로 먼저 쓰이는 경우가 많다.** Krylov 솔버의 전처리자로 V-cycle을 1~2회만 적용하는 조합이 실무의 주력이다. 자체 수렴 특성보다 Krylov의 수렴을 가속하는 용도가 더 흔하다.

## 기억할 점

- Gauss-Seidel은 고주파 오차만 빨리 지운다. 저주파 오차는 거친 격자로 넘기면 고주파처럼 보이고 다시 빨리 지워진다.
- V-cycle은 smoothing + restriction + prolongation을 재귀로 엮어 모든 파장 모드를 각자의 격자에서 공격한다. 수렴률이 격자 크기에 거의 독립.
- Krylov 솔버와는 경쟁이 아니라 조합이다. V-cycle을 전처리자로 쓰면 실무에서 가장 빠른 Poisson/압력 solver가 된다.
