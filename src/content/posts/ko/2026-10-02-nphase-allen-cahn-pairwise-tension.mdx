## σ₁₂에 1.00을 넣고 0.78을 돌려받았다

3상 phase-field 코드에 상 1, 상 2, 상 3을 넣었다. 1-2 표면장력 입력란에 1.00을 적었다. 평형이 된 계면을 가로질러 자유에너지를 적분했다. 0.78이 나왔다.

빠진 쪽은 상 3이었다. 계산 영역 어디에도 상 3은 없었다. 초기값으로 심어둔 양은 $10^{-3}$. 그런데 평형 계면 한가운데에서 상 3의 체적율이 0.21까지 올라와 있었다.

이 글은 그 21%가 어디서 오는지 끝까지 따라간다. 쌍별로 적은 $\sigma_{ij}$가 성분별 기울기 계수 $\kappa_i$로 되돌아오는 산수, $\kappa_i$의 부호가 Neumann 삼각형의 닫힘 조건과 같은 식이라는 사실, 그리고 없는 상이 계면으로 새는 것을 막는 항 하나를 본다. 끝에는 같은 격자에 닫힘 방식 네 가지를 걸어 숫자로 비교한다.

## 체적율 N개는 자유도 N개가 아니다

$N$개의 불혼합 유체를 다룰 때 체적율 $c_i$는 제약 하나를 들고 있다.

$$
\sum_{i=1}^{N} c_i = 1, \qquad 0 \le c_i \le 1
$$

자유도는 $N-1$개다. 그런데 코드를 짜면 배열은 $N$개가 생기고, 각 배열에 Allen–Cahn 방정식 하나씩을 붙이는 것이 가장 자연스럽다. 두상 코드를 복사해서 성분 수만 늘리면 정확히 그 모양이 된다.

그러면 총합이 깨진다. 각 상의 화학포텐셜 $\mu_i$를 독립적으로 쓰고 $\partial_t c_i = -M \mu_i$를 적으면

$$
\partial_t \sum_i c_i = -M \sum_i \mu_i
$$

이고, 오른쪽이 0일 이유가 없다. 실험에서 $\left|\sum c_i - 1\right|$이 0.859까지 벌어졌다. 계면이 녹아버리고 표면장력은 0.026으로 내려앉는다.

교과서적 처방은 Lagrange 승수다. $\bar\mu = \frac{1}{N}\sum_j \mu_j$를 빼면

$$
\partial_t c_i = -M\left(\mu_i - \bar\mu\right)
$$

합의 시간변화가 정확히 0이 된다. 아래 시뮬레이션에서 두 닫힘을 직접 갈아 끼워보자.

왼쪽 버튼으로 `3 equations, no closure`를 고르면 $\sum c_i - 1$ 띠가 아래로 무너지면서 세 곡선이 전부 뭉개진다. `mean projection`으로 바꾸면 띠는 $10^{-13}$에 붙지만 빨간 $c_3$ 봉우리가 계면 한가운데에서 올라오고 `sigma_eff`가 1.00 아래로 내려간다. `Lambda` 슬라이더를 올리면 그 봉우리가 눌린다.

## 쌍별 σᵢⱼ를 성분별 κᵢ로 되돌린다

자유에너지는 보통 쌍별로 적는다.

$$
E = \int_\Omega \left[ \sum_{i<j} \beta_{ij}\, c_i^2 c_j^2 + \sum_i \frac{\kappa_i}{2} \left|\nabla c_i\right|^2 \right] d\Omega
$$

$\beta_{ij}$는 $i$-$j$ 쌍의 이중우물 깊이, $\kappa_i$는 성분 $i$의 기울기 에너지 계수다. 벌점은 쌍별인데 기울기 계수는 성분별이다. 이 비대칭이 뒤에서 전부 문제를 만든다.

$\beta_{ij}$와 $\kappa_i$는 직접 고르는 값이 아니다. 두상 극한에서 물리량으로 묶인다. $c_2 = 1 - c_1$을 넣으면 위 식은

$$
E = \int \left[ \beta_{12}\, c^2(1-c)^2 + \frac{\kappa_1 + \kappa_2}{2}\left|\nabla c\right|^2 \right] d\Omega
$$

가 되고, 익숙한 두상 형태 $\beta c^2(1-c)^2 + \frac{\lambda}{2}|\nabla c|^2$와 비교하면 $\lambda = \kappa_1 + \kappa_2$다. 1차원 평형에서 $\lambda c'' = dE_0/dc$를 한 번 적분하면 $\frac{\lambda}{2}c'^2 = E_0$, 즉 $c' = \sqrt{2\beta/\lambda}\, c(1-c)$다. 해는 tanh이고

$$
c(x) = \frac{1}{2}\left[1 + \tanh\frac{2x}{D}\right], \qquad \sigma = \int \left[E_0 + \frac{\lambda}{2}c'^2\right] dx = \frac{2\lambda}{3D}
$$

여기서 $D$는 계면 두께(격자 셀 수), $\sigma$는 표면장력이다. 두 관계를 뒤집으면

$$
\beta_{ij} = \frac{12\,\sigma_{ij}}{D}, \qquad \kappa_i + \kappa_j = \frac{3}{2}\,\sigma_{ij} D
$$

$\beta_{ij}$는 쌍마다 바로 떨어진다. $\kappa_i$는 세 식을 연립해야 나온다. 3상이면

$$
\kappa_i = \frac{3D}{4}\left(\sigma_{ij} + \sigma_{ik} - \sigma_{jk}\right)
$$

성분별 계수 하나가 쌍별 표면장력 셋의 조합이다. 이것이 이 글의 중심 식이다. [두상 보존형 Allen–Cahn에서 이동도와 반확산 항을 따로 다룬 글](/ko/posts/2026-09-18-conservative-allen-cahn-lbm-interface/)에서는 $\lambda$ 하나뿐이었다. 상이 셋이 되면 $\lambda$가 셋으로 갈라지고, 갈라지는 방식이 뺄셈이다.

## κ₃가 음수로 넘어가는 자리

뺄셈이라는 말은 부호를 잃을 수 있다는 뜻이다. $\sigma_{13} + \sigma_{23} < \sigma_{12}$이면 $\kappa_3 < 0$이 된다. 기울기 에너지가 아래로 열린다. 계면을 날카롭게 만들수록 에너지가 내려가므로 해는 격자 간격까지 붕괴한다. 모델이 깨지는 것이 아니라 애초에 적분이 아래로 유계가 아니다.

같은 조건이 다른 이름으로도 알려져 있다. 삼중점에서 세 표면장력이 균형을 이루면 각 상의 쐐기각 $\theta_i$가 정해진다.

$$
\cos\theta_1 = \frac{\sigma_{23}^2 - \sigma_{12}^2 - \sigma_{13}^2}{2\,\sigma_{12}\sigma_{13}}
$$

$\theta_1$은 상 1이 차지하는 각이고, 나머지 둘은 첨자를 돌려서 얻는다. 이 $\cos$이 $[-1, 1]$을 벗어나는 조건이 정확히 $\kappa_i < 0$인 조건이다. 즉 **Neumann 삼각형이 닫히는가**와 **모델이 well-posed인가**가 같은 부등식이다. 아래 슬라이더로 세 $\sigma$를 직접 흔들어보자.

$\sigma_{12}=1.00$을 고정하고 $\sigma_{13}, \sigma_{23}$을 함께 내리면 붉은 $\kappa_3$ 막대가 왼쪽으로 넘어가는 순간 삼각형이 끊어지고 상 3의 쐐기가 180°로 벌어진다. 상 3이 1-2 계면을 완전히 적시는 상태다. $\sigma=(1.00, 0.80, 0.60)$에서는 쐐기각이 143.1° / 126.9° / 90.0°로 떨어진다 — 3-4-5 직각삼각형이라 상 3의 각이 정확히 직각이다.

## 같은 격자에 닫힘 네 가지를 걸었다

1차원 격자 200셀, $D=4$, $\sigma=(1.00, 0.80, 0.60)$. 왼쪽은 상 1, 오른쪽은 상 2, 상 3은 계면에 $10^{-3}$만 심는다. 8000스텝 완화시킨 뒤 $\left|\sum c_i - 1\right|$, $\max c_3$, 그리고 계면을 가로지른 자유에너지 적분(= 실현된 표면장력)을 잰다.

```python
import math
import numpy as np

D, MOB, DT, NX = 4.0, 1.0 / 3.0, 0.2, 200


def pair_to_component(s12, s13, s23):
    """쌍별 표면장력에서 성분별 기울기 계수 kappa_i와 쌍별 벌점 beta_ij로."""
    f = 0.75 * D
    kap = np.array([f * (s12 + s13 - s23),
                    f * (s12 + s23 - s13),
                    f * (s13 + s23 - s12)])
    bet = 12.0 / D * np.array([[0, s12, s13], [s12, 0, s23], [s13, s23, 0]])
    return kap, bet


def neumann_wedges(s12, s13, s23):
    """Neumann 삼각형이 닫히면 세 상의 쐐기각(도), 아니면 None."""
    args = [(s23 ** 2 - s12 ** 2 - s13 ** 2) / (2 * s12 * s13),
            (s13 ** 2 - s12 ** 2 - s23 ** 2) / (2 * s12 * s23),
            (s12 ** 2 - s13 ** 2 - s23 ** 2) / (2 * s13 * s23)]
    if any(abs(a) > 1 for a in args):
        return None
    return [math.degrees(math.acos(a)) for a in args]


def _ext(a):
    return np.concatenate(([a[0]], a, [a[-1]]))


def lap1d(a):
    e = _ext(a)
    return e[:-2] - 2 * a + e[2:]


def grad1d(a):
    e = _ext(a)
    return (e[2:] - e[:-2]) / 2.0


def chem_potential(c, kap, bet, lam3):
    c1, c2, c3 = c
    dbulk = np.array([
        2 * bet[0, 1] * c1 * c2 ** 2 + 2 * bet[0, 2] * c1 * c3 ** 2 + 2 * lam3 * c1 * (c2 * c3) ** 2,
        2 * bet[0, 1] * c2 * c1 ** 2 + 2 * bet[1, 2] * c2 * c3 ** 2 + 2 * lam3 * c2 * (c1 * c3) ** 2,
        2 * bet[0, 2] * c3 * c1 ** 2 + 2 * bet[1, 2] * c3 * c2 ** 2 + 2 * lam3 * c3 * (c1 * c2) ** 2,
    ])
    return np.array([dbulk[i] - kap[i] * lap1d(c[i]) for i in range(3)])


def line_tension(c, kap, bet, lam3):
    """계면을 가로지른 자유에너지 적분 = 실현된 표면장력."""
    c1, c2, c3 = c
    e = (bet[0, 1] * (c1 * c2) ** 2 + bet[0, 2] * (c1 * c3) ** 2
         + bet[1, 2] * (c2 * c3) ** 2 + lam3 * (c1 * c2 * c3) ** 2)
    for i in range(3):
        e = e + 0.5 * kap[i] * grad1d(c[i]) ** 2
    return float(e.sum())


def initial_profile(seed):
    x = np.arange(NX) - NX / 2
    c3 = seed * np.exp(-(x / D) ** 2)
    c1 = 0.5 * (1 - np.tanh(2 * x / D)) * (1 - c3)
    c2 = 0.5 * (1 + np.tanh(2 * x / D)) * (1 - c3)
    return np.array([c1, c2, c3])


def relax(kap, bet, closure, lam3=0.0, steps=8000, seed=1e-3):
    c = initial_profile(0.0 if closure == 'two-phase' else seed)
    for _ in range(steps):
        mu = chem_potential(c, kap, bet, lam3)
        if closure == 'two-phase':
            m = 0.5 * (mu[0] + mu[1])
            rhs = np.array([mu[0] - m, mu[1] - m, np.zeros(NX)])
        elif closure == 'independent':
            rhs = mu
        else:
            rhs = mu - mu.mean(axis=0)
        c = c - MOB * DT * rhs
        if not np.isfinite(c).all() or np.abs(c).max() > 1e3:
            return None, None, None
    return c, float(np.abs(c.sum(axis=0) - 1.0).max()), line_tension(c, kap, bet, lam3)


print("== pairwise sigma_ij -> per-component kappa_i (D = %.1f) ==" % D)
print("%-20s %-26s %-8s %s" % ("sigma_12,13,23", "kappa_1,2,3", "closes", "wedge angles [deg]"))
for s in [(1.0, 1.0, 1.0), (1.0, 0.8, 0.6), (1.0, 0.55, 0.55), (1.0, 0.4, 0.4)]:
    kap, _ = pair_to_component(*s)
    th = neumann_wedges(*s)
    print("%-20s %-26s %-8s %s" % (
        "%.2f %.2f %.2f" % s,
        "%+.2f %+.2f %+.2f" % tuple(kap),
        "yes" if kap.min() > 0 else "NO",
        "-" if th is None else "%.1f %.1f %.1f (sum %.1f)" % (th[0], th[1], th[2], sum(th))))

kap, bet = pair_to_component(1.0, 0.8, 0.6)
print()
print("== 1-2 interface at equilibrium, phase 3 seeded at 1e-3 (input sigma_12 = 1.00) ==")
print("%-30s %-13s %-9s %s" % ("closure", "max|sum c-1|", "max c_3", "sigma_eff"))
cases = [("A two-phase (c_3 frozen)", 'two-phase', 0.0),
         ("B three equations, no closure", 'independent', 0.0),
         ("C mean projection", 'projected', 0.0),
         ("D mean projection + Lambda=400", 'projected', 400.0)]
for tag, closure, lam3 in cases:
    c, drift, sig = relax(kap, bet, closure, lam3)
    if c is None:
        print("%-30s diverged" % tag)
        continue
    print("%-30s %-13.2e %-9.4f %.4f" % (tag, drift, c[2].max(), sig))

print()
print("== triple-penalty Lambda scan (mean projection) ==")
print("%-10s %-10s %-10s %s" % ("Lambda", "max c_3", "sigma_eff", "vs input"))
for lam3 in (0.0, 10.0, 30.0, 60.0, 150.0, 400.0):
    c, drift, sig = relax(kap, bet, 'projected', lam3)
    print("%-10.0f %-10.4f %-10.4f %+.1f%%" % (lam3, c[2].max(), sig, (sig - 1.0) * 100))
```

## Σc는 1e-13인데 계면이 21.9% 가벼워졌다

A는 상 3을 아예 동결한 두상 계산이다. $\sigma_{\rm eff} = 0.9665$ — 입력 1.00 대비 3.3% 낮다. 이건 모델 결함이 아니라 계면 4셀의 이산화 오차다. $\kappa_1 + \kappa_2 = \frac{3}{2}\sigma_{12}D$ 관계가 제대로 맞는다는 확인이다.

B는 세 식을 독립으로 푼 경우다. 합이 0.859 어긋나고 표면장력은 0.0257까지 사라진다. 계면이 녹았다.

C가 문제의 줄이다. 평균 투영으로 합은 $2.6\times10^{-13}$까지 잡았다. 그런데 $\max c_3 = 0.2114$, $\sigma_{\rm eff} = 0.7809$다. 입력 대비 21.9% 낮다. 제약은 지켰는데 물리가 틀렸다.

제약 위반은 눈에 보인다. 21.9%는 보이지 않는다. 그래서 더 비싸다.

## 없는 상이 계면으로 새는 산수

왜 새는지는 벌크 에너지만 따로 떼면 바로 보인다. 1-2 계면 중앙에서 대칭을 가정하고 $c_3 = p$, $c_1 = c_2 = (1-p)/2$를 넣는다.

$$
E_0(p) = \frac{\beta_{12}}{16}(1-p)^4 + \frac{\beta_{13} + \beta_{23}}{4}\,p^2 (1-p)^2
$$

$p$로 미분해서 $p=0$에서 값을 본다. 두 번째 항은 $p^2$로 시작하므로 미분값에 기여하지 않는다. 남는 것은 첫 항뿐이다.

$$
\left.\frac{dE_0}{dp}\right|_{p=0} = -\frac{\beta_{12}}{4}
$$

항상 음수다. $\sigma_{13}$, $\sigma_{23}$이 얼마든 상관없다. **쌍별 4차 우물에서는 이진 계면에 세 번째 상을 넣는 방향이 언제나 내리막이다.** $\beta_{12} = 3.0$이면 기울기가 $-0.75$다.

실제 숫자로도 확인된다. $p=0$에서 $E_0 = \beta_{12}/16 = 0.1875$. 측정된 $p = 0.2114$를 넣으면 $E_0 = 0.1018$이다. 45.7% 내려간다. 벌크는 상 3을 반긴다. 막아주는 것은 $\kappa_3 |\nabla c_3|^2$ 하나뿐이고, $\kappa_3 = 1.20$으로는 0.21에서야 균형이 잡힌다.

[다화학종 LBM에서 $\tau_k$가 서로 다를 때 총 질량이 어긋난 경우](/ko/posts/2026-09-23-multicomponent-lbm-correction-velocity/)와 구조가 닮았다. 거기서도 성분별로 자유롭게 고른 계수가 전체 제약을 건드렸다. 다만 그쪽은 장부가 안 맞아 즉시 들켰고, 이쪽은 장부가 맞는데 값이 틀린다.

## 3중 벌점항 Λ가 사는 자리

처방은 세 상이 한 점에 겹치는 것을 직접 벌하는 항이다.

$$
E_0 \;\to\; E_0 + \Lambda \sum_{i<j<k} c_i^2 c_j^2 c_k^2
$$

스캔 결과를 보면 $\Lambda$가 올라갈수록 $\max c_3$이 0.2114 → 0.0512로 눌리고 $\sigma_{\rm eff}$는 0.7809 → 0.9715로 돌아온다. $\Lambda = 400$에서 입력 대비 −2.9%, 즉 A의 이산화 오차 −3.3%와 사실상 같은 자리다. 상 3을 동결한 것과 구별되지 않는다.

다만 이 항은 새는 구멍을 메우지 않는다. $\Lambda c_1^2c_2^2c_3^2$를 $p$로 미분해도 $p=0$에서 0이다. $-\beta_{12}/4$라는 내리막 기울기는 그대로 남는다. $\Lambda$가 하는 일은 봉우리가 자란 뒤에 벽을 세우는 것이다. 그래서 $\Lambda$를 올려도 $c_3$이 0으로 가지 않고 0.05에서 멈춘다.

구멍 자체를 막으려면 자유도를 $N-1$개로 줄이고 $c_N = 1 - \sum_{i<N} c_i$로 닫거나, 국소적으로 없는 상의 방정식을 아예 풀지 않아야 한다. A가 바로 그 경우고, 그래서 $\max c_3$이 정확히 0이다.

## LBM 코드에 σ를 적을 때 실제로 정하는 것

쌍별 $\sigma_{ij}$ 표 하나를 입력하는 순간 세 가지가 동시에 정해진다.

첫째, $\kappa_i = \frac{3D}{4}(\sigma_{ij} + \sigma_{ik} - \sigma_{jk})$의 부호. 모든 삼중조합에 대해 양수인지 실행 전에 확인한다. 3상이면 조합 하나지만 5상이면 10개다. 하나라도 음수면 그 조합이 어딘가에서 만나는 순간 터진다.

둘째, 삼중점의 쐐기각. $\cos\theta_i$ 세 개를 뽑아 합이 360°인지 본다. 이것이 실질적으로 $\kappa_i > 0$ 검사와 같지만, 각도는 결과와 눈으로 비교할 수 있다.

셋째, 실현된 표면장력. 입력한 $\sigma_{12}$가 아니라 평형 프로파일에서 적분한 값을 쓴다. [이산 LBE의 점성이 연속식의 값과 다른 것](/ko/posts/2026-09-28-lbm-half-step-viscosity-taylor-expansion/)과 같은 종류의 문제다. LBM 쪽에서는 이 차이가 힘항을 타고 들어온다. 표면장력이 21.9% 작으면 Laplace 압력도, 모세관파 속도도 그만큼 틀린다. 그런데 $\sum c_i = 1$은 $10^{-13}$으로 완벽하다. 검증 지표를 제약 위반에만 걸어두면 이 21.9%는 끝까지 보이지 않는다.
