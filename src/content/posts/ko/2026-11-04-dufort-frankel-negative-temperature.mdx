## Δt를 20배 키웠더니 막대 한가운데가 영하로 내려갔다

양 끝을 0도로 잡은 막대에 $\sin x$ 모양 온도를 깔았다. 열방정식이니 답은 정해져 있다. 모양은 그대로, 진폭만 $e^{-\alpha t}$로 줄어든다. 어디서도 0 아래로 내려갈 수 없다.

FTCS(전진 시간·중심 공간 양해법)는 $r=\alpha\Delta t/\Delta x^2$가 0.5를 넘으면 터진다. 그래서 "무조건 안정한 양해법"이라는 DuFort–Frankel로 바꿨다. $r$을 0.5에서 10으로, 시간 간격을 20배 키웠다. 계산은 터지지 않았다. 그런데 $t=1.48$에서 가운데 온도가 $-0.83$이 나왔다. 엄밀해는 $+0.052$다.

이 글은 그 음수가 어디서 오는지 따라간다. 결론부터 말하면 DuFort–Frankel은 큰 $\Delta t$에서 열방정식을 풀지 않는다. 감쇠 파동방정식을 푼다. 읽고 나면 이 스킴의 실제 $\Delta t$ 상한을 한 줄로 계산할 수 있다.

## 세 스킴, 같은 막대

소재는 김문상 교수 전산유체역학 과제 HW#2다. 21개 격자, $\alpha=2$, 초기 조건 $\sin x$로 세 스킴을 비교한다.

$$
u_i^{n+1}=u_i^n+r\left(u_{i+1}^n-2u_i^n+u_{i-1}^n\right)
$$

FTCS다. $u_i^n$은 격자점 $i$, 시간층 $n$의 온도다. 가장 단순하고 $r\le 1/2$에서만 안정하다.

DuFort–Frankel은 Leapfrog(앞뒤 두 시간층을 쓰는 중심 시간차분)에서 출발한다. Leapfrog를 확산에 쓰면 어떤 $r$에서도 불안정하다. 그래서 중심점 $u_i^n$을 앞뒤 평균 $(u_i^{n+1}+u_i^{n-1})/2$로 바꿔 넣는다.

$$
(1+2r)\,u_i^{n+1}=(1-2r)\,u_i^{n-1}+2r\left(u_{i+1}^n+u_{i-1}^n\right)
$$

여전히 양해법이다. 행렬을 풀 필요가 없다. 대신 시간층 세 개가 필요하다. 첫 스텝은 다른 방법으로 만들어야 한다. 소스 과제는 FTCS로 한 스텝을 먼저 나갔다.

Laasonen은 완전 음해법(BTCS)이다. 매 스텝 삼중대각 행렬을 푼다.

$$
-r\,u_{i-1}^{n+1}+(1+2r)\,u_i^{n+1}-r\,u_{i+1}^{n+1}=u_i^n
$$

아래 시뮬레이션에서 직접 조작해보자. 왼쪽은 DuFort–Frankel 증폭 계수의 두 근, 오른쪽은 한 Fourier 모드의 진폭이 스텝마다 어떻게 변하는지다.

$r$ 슬라이더를 3.2 근처에서 천천히 올려보자. 두 근이 실수축에서 만나 위아래로 갈라진다. 그 순간부터 초록 곡선이 0을 가로질러 음수로 내려간다. 두 근은 언제나 점선 원 안에 있다. 그래서 터지지는 않는다.

## 안정한데 왜 틀리나: 증폭 계수의 두 근

$u_i^n=G^n e^{\mathrm{i}\,i\theta}$를 넣으면 $G$에 대한 2차식이 나온다. $\theta=k\Delta x$는 모드의 격자당 위상이다.

$$
G_\pm=\frac{2r\cos\theta\pm\sqrt{1-4r^2\sin^2\theta}}{1+2r}
$$

근호 안이 음수가 되면 두 근은 켤레 복소수다. 이때 크기는 $\theta$와 무관하다.

$$
|G_\pm|^2=\frac{2r-1}{2r+1}<1
$$

어떤 $r$에서도 1보다 작다. 이것이 "무조건 안정"의 전부다. 하지만 복소수 $G$는 크기만 줄이지 않는다. 스텝마다 위상을 돌린다. 진폭은 $\rho^n\cos(n\varphi+\psi)$ 꼴로 진동한다. 열방정식의 모드는 진동하지 않는다. 단조 감소만 한다.

근이 복소수로 바뀌는 문턱은 $2r\sin\theta=1$이다. 기본 모드 $\theta=\Delta x=\pi/20$이면 $r^*=1/(2\sin\theta)=3.196$이다. 짧은 파장일수록 $\sin\theta$가 커서 더 일찍 진동한다.

문턱 아래도 안전하지 않다. $r=2$에서 기본 모드의 $|G_+|$는 0.9462다. 엄밀한 감쇠율은 $e^{-\alpha\Delta t}=0.9518$이다. 한 스텝에 0.6%씩 더 식는다. 60스텝이면 30%가 된다.

## 수정 방정식: 열방정식 안에 파동항이 숨어 있다

이유는 절단 오차에 있다. DuFort–Frankel을 Taylor 전개하면 실제로 푸는 식(수정 방정식, modified equation)이 나온다.

$$
u_t=\alpha u_{xx}-\alpha\left(\frac{\Delta t}{\Delta x}\right)^2u_{tt}+\frac{\alpha\Delta x^2}{12}u_{xxxx}+\cdots
$$

$u_{tt}$ 항이 문제다. 계수가 $(\Delta t/\Delta x)^2$다. $\Delta t$와 $\Delta x$를 같이 줄여도 이 비가 고정이면 사라지지 않는다. DuFort–Frankel은 $\Delta t/\Delta x\to 0$일 때만 열방정식과 일관(consistent)하다. 이것을 조건부 일관성이라 부른다.

$\lambda=\Delta t/\Delta x$로 두면 이 식은 전신 방정식(telegraph equation, 감쇠 파동방정식)이다.

$$
\alpha\lambda^2u_{tt}+u_t=\alpha u_{xx}
$$

파동 속도는 $1/\lambda=\Delta x/\Delta t$다. 한 스텝에 한 칸이다. 양해법이 정보를 옮길 수 있는 최대 속도와 같다. 모드 $e^{\mathrm{i}kx-\sigma t}$를 넣으면 $\alpha\lambda^2\sigma^2-\sigma+\alpha k^2=0$이다. $\sigma$가 실수이려면 $4\alpha^2\lambda^2k^2\le 1$, 즉 $\Delta t\le\Delta x/(2\alpha k)$여야 한다. 이를 $r$로 바꾸면 $r\le 1/(2k\Delta x)=3.18$이다. 증폭 계수의 3.196과 거의 같다. 두 분석이 같은 경계를 가리킨다.

## 코드: sin x 막대를 r = 0.5, 2, 5, 10으로

소스 과제 설정 그대로 $t\approx1.5$까지 진행한다. 세 스킴을 같은 $r$로 돌리고 가운데 온도, 최대 오차, 진행 중 가운데 온도의 최솟값을 찍는다.

```python
import numpy as np

ALPHA, PEAK, NX = 2.0, 1.0, 21          # 소스 HW#2와 같은 설정
DX = np.pi / (NX - 1)
X = np.linspace(0.0, np.pi, NX)
T_END = 1.5

def exact_u(t):
    return PEAK * np.exp(-ALPHA * t) * np.sin(X)

def ftcs_heat(u, r):
    v = u.copy()
    v[1:-1] = u[1:-1] + r * (u[2:] - 2 * u[1:-1] + u[:-2])
    return v

def laasonen_heat(u, r):
    n = NX - 2                           # 내부점 삼중대각 (Thomas)
    a = np.full(n, -r); b = np.full(n, 1 + 2 * r); c = np.full(n, -r)
    d = u[1:-1].copy()
    for i in range(1, n):
        m = a[i] / b[i - 1]
        b[i] -= m * c[i - 1]; d[i] -= m * d[i - 1]
    s = np.zeros(n); s[-1] = d[-1] / b[-1]
    for i in range(n - 2, -1, -1):
        s[i] = (d[i] - c[i] * s[i + 1]) / b[i]
    v = np.zeros_like(u); v[1:-1] = s
    return v

def dufort_step(u_old, u, r):
    v = np.zeros_like(u)
    v[1:-1] = ((1 - 2 * r) * u_old[1:-1] + 2 * r * (u[2:] + u[:-2])) / (1 + 2 * r)
    return v

def march_heat(method, r, start="ftcs"):
    dt = r * DX**2 / ALPHA
    nstep = max(2, int(round(T_END / dt)))
    u = PEAK * np.sin(X)
    hist = [u[NX // 2]]
    if method == "dufort":
        u_old = u
        u = ftcs_heat(u, r) if start == "ftcs" else exact_u(dt)
        hist.append(u[NX // 2])
        for _ in range(nstep - 1):
            u_old, u = u, dufort_step(u_old, u, r)
            hist.append(u[NX // 2])
    else:
        step = ftcs_heat if method == "ftcs" else laasonen_heat
        for _ in range(nstep):
            u = step(u, r)
            hist.append(u[NX // 2])
    t = nstep * dt
    err = np.max(np.abs(u - exact_u(t)))
    return t, nstep, u[NX // 2], exact_u(t)[NX // 2], err, np.array(hist)

print(f"dx = {DX:.5f}, r* (DF fundamental mode turns complex) = {1/(2*np.sin(DX)):.3f}")
print(" r     method    steps   t      u_mid     exact     max_err   min(u_mid) over run")
for r in [0.5, 2.0, 5.0, 10.0]:
    for m in ["ftcs", "dufort", "laasonen"]:
        t, n, um, ue, e, h = march_heat(m, r)
        if not np.isfinite(e) or e > 1.0:
            print(f"{r:4.1f}  {m:9s} {n:5d}  {t:5.3f}   BLOWUP (|u|max = {np.max(np.abs(h)):.1e})")
            continue
        print(f"{r:4.1f}  {m:9s} {n:5d}  {t:5.3f}  {um:8.5f}  {ue:8.5f}  {e:.2e}  {h.min():+.4f}")
print()
print("DuFort-Frankel per-step |G| of the fundamental mode vs exact decay per step")
for r in [0.5, 2.0, 3.0, 3.2, 5.0, 10.0]:
    dt = r * DX**2 / ALPHA
    th = DX
    disc = 1 - 4 * r * r * np.sin(th)**2
    G = (2 * r * np.cos(th) + np.sqrt(complex(disc))) / (1 + 2 * r)
    print(f"r = {r:4.1f}  |G| = {abs(G):.4f}  exact = {np.exp(-ALPHA*dt):.4f}  "
          f"phase/step = {np.degrees(np.angle(G)):6.2f} deg")
print()
print("DuFort-Frankel start-up: FTCS first step vs exact first step (r = 5)")
for s in ["ftcs", "exact"]:
    t, n, um, ue, e, h = march_heat("dufort", 5.0, start=s)
    print(f"start = {s:5s}  u_mid = {um:+.5f}  max_err = {e:.3e}")
```

## 비교 매트릭스: 무엇을 얻고 무엇을 내주나

출력에서 세 가지가 읽힌다. 첫째, $r=0.5$에서 FTCS와 DuFort–Frankel은 소수 다섯째 자리까지 같다. 소스 과제의 평균 오차 0.8954e-3과 0.8976e-3이 거의 같았던 것도 같은 이유다. 둘째, $r=10$에서 Laasonen의 오차는 1.95e-02다. 크지만 부호는 맞다. 셋째, FTCS의 발산은 크기가 $r$과 스텝 수에 달려 있다. $r=10$은 12스텝뿐이라 6.3에서 멈췄다.

FTCS는 실패를 숨기지 못한다. 숫자가 폭발하니 누구나 알아챈다. DuFort–Frankel의 실패는 조용하다. 값은 유한하고 프로파일 모양도 $\sin x$ 그대로다. 부호만 틀린다. 검증 케이스로 수렴 차수를 재더라도 $\Delta t/\Delta x$를 고정한 채 격자를 줄이면 이 오차는 0으로 가지 않는다. [수렴 차수가 검증 케이스마다 다르게 나온 이야기](/ko/posts/2026-10-07-sod-vortex-order-verification/)와 같은 함정이다.

## r = 0.5에서 두 스킴이 같은 숫자를 낸 이유

$r=1/2$을 넣으면 DuFort–Frankel 식의 $(1-2r)u_i^{n-1}$ 항이 사라진다.

$$
u_i^{n+1}=\tfrac12\left(u_{i+1}^n+u_{i-1}^n\right)
$$

FTCS에 $r=1/2$를 넣어도 정확히 이 식이 된다. 두 스킴이 같은 식이니 오차도 같다. 소스 과제는 "DuFort–Frankel 오차는 누적 때문"이라고 해석했다. 실제로는 $r=0.5$에서 두 방법의 차이를 관찰할 수 없었다. 차이는 $r>1/2$에서만 드러난다. 그 영역이 바로 DuFort–Frankel을 쓰는 이유다.

시작 스텝 효과도 확인했다. $r=5$에서 첫 스텝을 FTCS로 하면 가운데 온도가 $-0.0916$, 엄밀해로 하면 $-0.0902$다. 소스의 관찰대로 첫 스텝은 거의 영향이 없다. 하지만 원인은 오차 누적이 아니다. 복소수 근이 만드는 진동이 원인이다.

이 문제는 확산에만 있지 않다. Courant 수 하나가 스킴을 무너뜨리는 경계는 [MSTACS 압축 차분의 Courant 한계](/ko/posts/2026-10-25-mstacs-slope-three-courant-limit/)에서도 봤다. 큰 $\Delta t$가 목적이라면 정확도와 안정성을 함께 보장하는 쪽은 음해법이다. 비정상 문제에서는 [이중 시간 루프](/ko/posts/2026-10-30-dual-time-steady-preconditioner-inner-iterations/)처럼 내부 반복을 감수하는 편이 낫다.

## DuFort–Frankel에 Δt를 넣기 전에 계산할 비

해석하려는 가장 짧은 파장 $\ell$을 정한다. $k=2\pi/\ell$이다. 그다음 이 부등식만 확인한다.

$$
\Delta t\le\frac{\Delta x}{2\alpha k}
$$

이 선을 넘으면 그 파장의 모드는 시간에 따라 진동한다. 넘지 않더라도 $\Delta t/\Delta x$가 크면 감쇠가 빨라진다. "무조건 안정"은 터지지 않는다는 뜻일 뿐이다. 맞는 방정식을 푼다는 뜻은 아니다.
