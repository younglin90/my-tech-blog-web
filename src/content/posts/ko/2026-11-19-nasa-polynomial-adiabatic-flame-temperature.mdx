## FlameMaster를 돌리기 전, 손계산이 458 K 틀렸다

2018년 여름, FlameMaster(층류 화염편 계산 코드)를 처음 깔았다. 결과를 검증하려고 단열화염온도를 손으로 먼저 계산했다. 화학양론 메탄–공기에서 2783 K가 나왔다. 코드는 2200 K대를 내놓았다. 코드가 틀린 줄 알고 입력 파일을 한참 뒤졌다. 틀린 쪽은 손계산이었다.

원인은 비열이었다. 손계산에서는 298 K의 cp(정압비열)를 끝까지 썼다. 코드는 `gri.30.therm` 파일의 온도 다항식을 썼다. 이 글은 그 다항식이 무엇인지, 파일에서 어떻게 읽는지 다룬다. 그리고 같은 에너지 평형을 두 방식으로 풀어 458 K 차이가 어디서 오는지 숫자로 보인다.

## 단열화염온도는 면적 맞추기다

단열화염온도(adiabatic flame temperature)는 열 손실 없이 연소했을 때 생성물이 도달하는 온도다. 반응이 내놓은 열 $Q$는 전부 생성물을 데우는 데 쓰인다. 식으로는 $Q = \int_{T_0}^{T_{ad}} C_p(T)\,dT$다. 여기서 $C_p$는 생성물 전체의 열용량이다.

그래프로 보면 $C_p(T)$ 곡선 아래 면적이 $Q$와 같아지는 지점이 $T_{ad}$다. $C_p$가 상수면 면적은 직사각형이다. $C_p$가 온도와 함께 커지면 같은 면적을 더 짧은 구간에서 채운다. 아래 시뮬레이션에서 직접 조작해보자.

열이 쌓이는 동안 파란 면적(NASA 다항식)과 빨간 직사각형(상온 cp)은 같은 속도로 넓어진다. 그런데 파란 곡선은 1000 K 이후 계속 올라간다. 그래서 파란 끝점이 먼저 멈춘다. 종별 쌓기를 켜면 차이의 대부분이 H₂O와 CO₂ 띠에서 온다는 것이 보인다. φ(당량비)를 낮추면 N₂와 남는 O₂ 비중이 커지고 간격이 줄어든다.

## 1971년, 열역학 표가 계수 14개로 줄었다

1960년대 로켓 추진제 계산에는 JANAF 열화학 표가 쓰였다. 온도마다 cp, h, s를 적은 두꺼운 표였다. 컴퓨터로 평형을 풀려면 표를 보간해야 했다. NASA Lewis 연구소의 Gordon과 McBride는 이를 다항식으로 바꿨다. 1971년 보고서 NASA SP-273에 정리된 형식이 지금의 7계수 다항식이다.

한 화학종의 온도 범위를 둘로 나눈다. 보통 300–1000 K와 1000–5000 K다. 구간마다 계수 7개를 둔다. 그래서 한 종당 14개다. 1980년대 Sandia의 CHEMKIN이 이 형식을 채택했다. 이후 GRI-Mech, Cantera, FlameMaster가 같은 파일을 그대로 읽는다. 2002년에는 구간을 늘린 9계수 형식이 나왔다. 하지만 연소 반응 메커니즘 파일은 아직 대부분 7계수다.

## 유도: cp 다항식 하나에서 h와 s가 나온다

출발점은 cp 하나다.

$$
\frac{c_p}{R} = a_1 + a_2 T + a_3 T^2 + a_4 T^3 + a_5 T^4
$$

$R$은 기체상수, $a_1$–$a_5$는 해당 구간의 계수다. 엔탈피는 $dh = c_p\,dT$를 적분해 얻는다. 적분상수가 $a_6$다.

$$
\frac{h}{RT} = a_1 + \frac{a_2}{2}T + \frac{a_3}{3}T^2 + \frac{a_4}{4}T^3 + \frac{a_5}{5}T^4 + \frac{a_6}{T}
$$

$a_6$에는 생성 엔탈피(원소 기준 상태에서 그 종을 만들 때의 엔탈피)가 들어 있다. 그래서 $h(298.15\,\text{K})$를 계산하면 H₂O는 −241.8 kJ/mol이 나온다. 엔트로피는 $ds = c_p\,dT/T$를 적분한다. 적분상수가 $a_7$이다.

$$
\frac{s^\circ}{R} = a_1 \ln T + a_2 T + \frac{a_3}{2}T^2 + \frac{a_4}{3}T^3 + \frac{a_5}{4}T^4 + a_7
$$

$s^\circ$는 표준압력 1 bar에서의 엔트로피다. 평형상수 계산에 쓰인다. 단열화염온도에는 $h$만 있으면 된다.

### thermo 파일 한 종은 네 줄이다

원본 노트의 첫 단계는 `CreateBinFile -i gri.30.therm -m gri.30.trans`였다. 이 명령이 읽는 `.therm` 파일은 80칸 고정 폭이다. 한 화학종이 네 줄을 차지한다.

- 1행: 종 이름, 원소 조성, 상(G), 그리고 $T_{low}$, $T_{high}$, $T_{mid}$
- 2행: **고온 구간** $a_1$–$a_5$
- 3행: 고온 $a_6$, $a_7$, 저온 $a_1$–$a_3$
- 4행: 저온 $a_4$–$a_7$

고온 계수가 먼저 나온다. 직접 파서를 짜다 보면 이 순서를 뒤집기 쉽다. 뒤집으면 상온에서 고온 다항식을 쓰게 된다. 결과는 조용히 틀린다. $T_{mid}$도 종마다 다를 수 있다. 1행 66–73칸 값을 읽어야 한다. 1000 K를 하드코딩하면 다른 출처 데이터를 섞을 때 깨진다.

## 코드: 같은 평형을 두 가지 비열로 푼다

메탄–공기 희박 연소를 가정한다. 해리는 무시하고 완전연소만 본다. 반응식은 $\text{CH}_4 + \tfrac{2}{\phi}(\text{O}_2 + 3.76\,\text{N}_2) \to \text{CO}_2 + 2\text{H}_2\text{O} + 2(\tfrac{1}{\phi}-1)\text{O}_2 + \tfrac{7.52}{\phi}\text{N}_2$다. 풀어야 할 식은 다음과 같다.

$$
f(T) = H_\text{prod}(T) - H_\text{reac}(T_0) = 0, \qquad T^{k+1} = T^k - \frac{f(T^k)}{C_{p,\text{prod}}(T^k)}
$$

$f$의 도함수가 정확히 $C_p$이므로 Newton 반복이 자연스럽다. 계수는 GRI-Mech 3.0 `.therm`에서 그대로 옮겼다.

```python
# gri.30.therm에서 옮긴 NASA 7계수: (T_mid, 저온 a1..a7, 고온 a1..a7)
NASA = {
 "CH4": (1000., [5.14987613E+00,-1.36709788E-02,4.91800599E-05,-4.84743026E-08,1.66693956E-11,-1.02466476E+04,-4.64130376E+00],
                [7.48514950E-02,1.33909467E-02,-5.73285809E-06,1.22292535E-09,-1.01815230E-13,-9.46834459E+03,1.84373180E+01]),
 "O2":  (1000., [3.78245636E+00,-2.99673416E-03,9.84730201E-06,-9.68129509E-09,3.24372837E-12,-1.06394356E+03,3.65767573E+00],
                [3.28253784E+00,1.48308754E-03,-7.57966669E-07,2.09470555E-10,-2.16717794E-14,-1.08845772E+03,5.45323129E+00]),
 "N2":  (1000., [3.298677E+00,1.4082404E-03,-3.963222E-06,5.641515E-09,-2.444854E-12,-1.0208999E+03,3.950372E+00],
                [2.92664E+00,1.4879768E-03,-5.68476E-07,1.0097038E-10,-6.753351E-15,-9.227977E+02,5.980528E+00]),
 "CO2": (1000., [2.35677352E+00,8.98459677E-03,-7.12356269E-06,2.45919022E-09,-1.43699548E-13,-4.83719697E+04,9.90105222E+00],
                [3.85746029E+00,4.41437026E-03,-2.21481404E-06,5.23490188E-10,-4.72084164E-14,-4.87591660E+04,2.27163806E+00]),
 "H2O": (1000., [4.19864056E+00,-2.03643410E-03,6.52040211E-06,-5.48797062E-09,1.77197817E-12,-3.02937267E+04,-8.49032208E-01],
                [3.03399249E+00,2.17691804E-03,-1.64072518E-07,-9.70419870E-11,1.68200992E-14,-3.00042971E+04,4.96677010E+00]),
}
R = 8.314462618  # J/(mol K)

def coeffs(sp, T):
    tm, lo, hi = NASA[sp]
    return lo if T < tm else hi

def cp_R(sp, T):
    a = coeffs(sp, T)
    return a[0] + a[1]*T + a[2]*T**2 + a[3]*T**3 + a[4]*T**4

def h_RT(sp, T):
    a = coeffs(sp, T)
    return a[0] + a[1]*T/2 + a[2]*T**2/3 + a[3]*T**3/4 + a[4]*T**4/5 + a[5]/T

def mixture(phi):
    # CH4 + (2/phi)(O2 + 3.76 N2) -> CO2 + 2 H2O + 2(1/phi-1) O2 + 7.52/phi N2  (phi<=1)
    reac = {"CH4": 1.0, "O2": 2/phi, "N2": 7.52/phi}
    prod = {"CO2": 1.0, "H2O": 2.0, "O2": 2*(1/phi - 1), "N2": 7.52/phi}
    return reac, prod

def H(mix, T, frozen_cp=False):
    # 혼합물 엔탈피 [J]; frozen_cp=True면 298 K 비열을 끝까지 쓴다
    if frozen_cp:
        return sum(n*R*(h_RT(s, 298.15)*298.15 + cp_R(s, 298.15)*(T-298.15)) for s, n in mix.items())
    return sum(n*R*T*h_RT(s, T) for s, n in mix.items())

def Cp(mix, T, frozen_cp=False):
    Tc = 298.15 if frozen_cp else T
    return sum(n*R*cp_R(s, Tc) for s, n in mix.items())

def flame_newton(phi, frozen_cp=False, T0=1500.0, tol=1e-6):
    reac, prod = mixture(phi)
    Hr = H(reac, 298.15)
    T, it = T0, 0
    while True:
        f = H(prod, T, frozen_cp) - Hr
        dT = -f / Cp(prod, T, frozen_cp)
        T += dT; it += 1
        if abs(dT) < tol: return T, it

print("species  h(298)/kJ/mol  cp(298)/R  cp(2000)/R  jump@1000K(cp/R)")
for s in NASA:
    jump = cp_R(s, 1000.0) - cp_R(s, 999.999999)
    print(f"{s:5s} {h_RT(s,298.15)*R*298.15/1000:12.2f} {cp_R(s,298.15):10.3f} {cp_R(s,2000.):11.3f} {jump:+14.2e}")

print("\nphi   T_ad(NASA)  iters  T_ad(cp298)  iters  overshoot")
for phi in [0.5, 0.6, 0.7, 0.8, 0.9, 1.0]:
    Tn, itn = flame_newton(phi)
    Tf, itf = flame_newton(phi, frozen_cp=True)
    print(f"{phi:.1f} {Tn:10.1f} {itn:5d} {Tf:11.1f} {itf:5d} {Tf-Tn:+9.1f}")

reac, prod = mixture(1.0)
Tn, _ = flame_newton(1.0)
cpm = (H(prod, Tn) - H(prod, 298.15)) / (Tn - 298.15)
print(f"\nphi=1: mean cp of products = {cpm/Cp(prod,298.15):.3f} x cp(298)")
```

## 숫자 읽기: 1.226, 458, 그리고 2

첫 표에서 $h(298)$ 값이 문헌과 맞는지 먼저 본다. CO₂ −393.51, H₂O −241.82, CH₄ −74.60 kJ/mol이다. 계수를 옮기다 생긴 오타는 여기서 바로 드러난다. 1000 K에서 저온·고온 cp의 차이는 $10^{-6}$ 이하다. GRI 데이터는 $T_{mid}$에서 이어지도록 맞춰져 있다.

cp의 온도 의존성은 종마다 다르다. N₂는 298 K에서 2000 K까지 24% 오른다. H₂O는 54%, CO₂는 63% 오른다. CH₄는 2.8배다. 생성물 전체로 평균 내면 298 K 값의 1.226배다. 데워야 할 온도폭은 그만큼 짧아진다. $(2783.4 - 298)/(2325.6 - 298) = 1.226$이 정확히 이 비다.

과대평가 폭은 φ와 함께 커진다. φ = 0.5에서 154 K, φ = 1에서 458 K다. 화염이 뜨거울수록 cp가 크게 오른 구간을 더 많이 지나기 때문이다. 상온 cp 쪽은 반복이 늘 2회다. $f(T)$가 직선이라 첫 Newton 한 번에 근에 닿는다. 두 번째는 확인용이다.

이 2325.6 K도 실제 값은 아니다. 2000 K를 넘으면 CO₂와 H₂O가 CO, H₂, OH로 일부 해리된다. 해리는 흡열이다. 평형 계산을 하면 화학양론 메탄–공기는 약 2225 K가 된다. 또 100 K가 빠지는 셈이다. 해리까지 넣으려면 평형상수가 필요하다. 그때 $s^\circ$와 $a_7$이 쓰인다.

## 지금 이 다항식이 쓰이는 자리

FlameMaster 노트의 다음 단계는 `ScanMan`으로 메커니즘을 읽는 것이었다. 반응 속도의 역반응 상수는 평형상수로 계산된다. 그 평형상수가 다시 이 다항식의 $h$와 $s$에서 나온다. 열역학 데이터 오류는 온도뿐 아니라 반응 속도까지 오염시킨다. 역반응 상수 계산은 [평형상수 단위를 다룬 글](/ko/posts/2026-10-22-reverse-rate-kp-kc-unit-dissociation/)에서 자세히 봤다.

화염편 라이브러리(flamelet library)에서도 같다. FlameMaster가 만든 온도 테이블은 β-PDF로 적분되어 난류 연소 모델에 들어간다. 테이블 온도가 수백 K 틀리면 평균 온도도 그만큼 틀린다. 그 적분 과정은 [presumed β-PDF 글](/ko/posts/2026-10-27-presumed-beta-pdf-mean-flame-temperature/)에 있다. 연소기 안에서 이 열이 압축성 유동을 어떻게 바꾸는지는 [Rayleigh 유동과 열적 초킹](/ko/posts/2026-11-17-rayleigh-flow-thermal-choking-combustor/)에서 다뤘다.

CFD 코드가 종 수송 방정식을 풀 때도 마찬가지다. 셀마다 $h$에서 $T$를 거꾸로 구한다. 위 코드의 Newton 반복이 매 셀, 매 시간 단계마다 돈다. 그래서 상용 코드들은 계수를 미리 테이블로 만들어 둔다.

## 메커니즘 파일을 받으면 먼저 손으로 확인할 세 숫자

새 반응 메커니즘을 받으면 `.therm`부터 연다. 주요 생성물의 $h(298)$이 문헌값과 맞는지 계산한다. $T_{mid}$에서 cp가 이어지는지 본다. 마지막으로 완전연소 단열화염온도를 Newton 몇 번으로 구해 코드 결과와 비교한다. 코드 결과가 이보다 100 K 안팎 낮다면 해리 효과다. 400 K 넘게 차이 난다면 어딘가 상온 cp가 숨어 있다.
