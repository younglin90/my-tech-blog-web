## 원기둥에서 반지름만큼 떨어진 점의 벽거리는 몇일까

답은 당연히 $a$다. 그런데 상용 솔버의 "PDE 벽거리" 옵션은 이 점에서 $1.38a$를 낸다. 같은 거리를 구 옆에서 재면 $2.0a$가 되고, 관 안쪽 중심에서는 $0.71a$가 된다. 이 글은 그 숫자가 어디서 오는지 따라간다. 1994년 Spalding의 착상에서 출발해 곡률 오차 공식 $d \approx y(1+\kappa y/2)$를 유도한다. 마지막에는 1D 반경 실험으로 그 공식을 확인한다. 읽고 나면 PDE 벽거리를 어디까지 믿어도 되는지 한 줄로 판단할 수 있다.

벽거리(wall distance, 셀 중심에서 가장 가까운 no-slip 벽까지의 거리)는 난류 모델의 필수 입력이다. Spalart–Allmaras의 소산항은 $(\tilde\nu/d)^2$에 비례한다. SST의 블렌딩 함수와 2층 모델도 $d$를 쓴다. 정확한 거리를 구하는 방법은 [Eikonal 방정식과 Fast Marching 글](/ko/posts/2026-04-22-wall-distance-eikonal-fast-marching/)에서 다뤘다. 오늘은 그보다 더 오래되고 더 단순한 방법을 본다.

모양을 `Flat wall`에서 `Convex`와 `Concave`로 바꿔 보자. 색은 $d_{PDE}/d_{exact}$이고, 반지름 $a$가 곡률을 정한다.

`Flat wall`에서는 실선(PDE)과 점선(정확)이 겹치고 색이 하얗다. `Convex`로 바꾸면 원기둥 주변이 붉어지고(과대평가), `Concave`에서는 파래진다(과소평가). 반지름 $a$를 줄여 곡률을 키우면 같은 프로브 거리에서도 비율이 더 벌어진다.

## 1994년, 열전도로 거리를 재다

Spalding은 복잡한 실내 공간("cluttered spaces")의 난류 열전달을 풀고 있었다. 수많은 장애물 각각까지의 거리를 기하학적으로 찾는 일은 당시 컴퓨터에 부담이었다. 그는 대신 이미 갖고 있던 도구, 확산 방정식 솔버를 썼다. 벽에서 0이고 내부에 균일한 열원이 있는 정상 열전도 문제를 푼다. 온도가 높을수록 벽에서 멀다는 직관이다.

STAR-CCM+ 이론 가이드는 이를 그대로 적는다.

$$
\nabla^2 \phi = -1, \qquad \phi = 0 \ \text{on } \Gamma_w, \qquad \nabla\phi\cdot\mathbf{n} = 0 \ \text{on } \Gamma_o
$$

$\phi$는 거리와 관련된 보조 변수, $\Gamma_w$는 벽, $\Gamma_o$는 그 외 경계, $\mathbf{n}$은 경계 법선이다. 거리는 다음 식으로 복원한다.

$$
d = -|\nabla\phi| + \sqrt{|\nabla\phi|^2 + 2\phi}
$$

같은 가이드는 두 방법을 나란히 놓는다. Implicit Tree는 표면 삼각형에 대한 정확한 사영이고, PDE는 "빠르지만 근사"라고 한다. 그 근사가 얼마나 큰지는 적혀 있지 않다.

## 1D에서는 왜 정확한가

평판 하나와 높이 $H$의 대칭 경계를 생각한다. $\phi'' = -1$, $\phi(0)=0$, $\phi'(H)=0$의 해는 다음과 같다.

$$
\phi(y) = Hy - \frac{y^2}{2}, \qquad \phi'(y) = H - y
$$

$y$는 벽에서의 거리다. 이 두 식에서 $H$를 지우면 $\phi = y\,\phi' + y^2/2$가 남는다. $y$에 대한 2차 방정식이고, 양의 근이 바로 위의 복원 공식이다. 즉 복원식은 "국소적으로 1D 포물선 프로파일"을 가정하고 역산한 것이다. 이 가정이 맞으면 $H$가 얼마든 $d=y$가 정확히 나온다. 두 벽 사이 채널에서도 $\phi = y(L-y)/2$를 넣으면 $d=\min(y, L-y)$가 정확히 나온다.

## 곡면에서는 무엇이 깨지나

원기둥 바깥($r \ge a$)에서는 라플라시안에 $\phi'/r$ 항이 붙는다. 반경 방향 식은 $\phi'' + (k/r)\phi' = -1$이다. $k$는 0(평판), 1(원기둥), 2(구)다. 원기둥, 바깥 경계 $R$에서 Neumann 조건이면 해는 다음과 같다.

$$
\phi = \frac{R^2}{2}\ln\frac{r}{a} - \frac{r^2-a^2}{4}, \qquad \phi' = \frac{R^2}{2r} - \frac{r}{2}
$$

$R \gg r$이면 $\phi'^2 \gg 2\phi$이므로 $d \approx \phi/\phi' \approx r\ln(r/a)$가 된다. $y=r-a$로 전개하면 다음과 같다.

$$
d \approx y\left(1 + \frac{k\,y}{2a}\right)
$$

구도 같은 방식으로 $d \approx r(r-a)/a = y(1+y/a)$가 나와 $k=2$에 맞는다. $k/a$는 벽 주곡률의 합 $\kappa$(볼록이 양수)다. 원인은 단순하다. 볼록면 바깥에서는 등고선이 퍼지며 플럭스가 희석되고, $\phi'$이 1D 포물선보다 빨리 줄어든다. 복원식은 그 감소를 "벽에서 더 멀다"로 읽는다. 오목면에서는 반대로 플럭스가 모여 거리를 짧게 읽는다. 관 내부 중심에서는 $\phi = (a^2-r^2)/4$를 넣어 $d = a/\sqrt2 \approx 0.707a$가 정확히 나온다.

## 코드: 평판·원기둥·구·관 내부를 반경 1D로

반경 방정식을 노드 160개로 이산화하고 SOR(Successive Over-Relaxation, 가중치를 둔 Gauss–Seidel)로 푼다. 바깥 경계는 고스트 노드로 Neumann을 건다. 복원식으로 $d$를 구한 뒤 벽에서 $y=0.1, 0.5, 1.0$인 점의 $d_{PDE}/y$를 출력한다.

```python
import math

def poisson_phi(k, r0, r1, wall_at_r1, n, tol=1e-9):
    """phi'' + (k/r) phi' = -1 를 SOR로 푼다. 벽(phi=0)은 한쪽 끝, 반대쪽은 dphi/dr=0."""
    h = (r1 - r0) / n
    r = [r0 + i * h for i in range(n + 1)]
    phi = [0.0] * (n + 1)
    omega = 2.0 / (1.0 + math.sin(math.pi / (2 * n)))
    wall = n if wall_at_r1 else 0
    for it in range(1, 200001):
        dmax = 0.0
        for i in range(n + 1):
            if i == wall:
                continue
            if i == 0 and r[0] == 0.0:          # 관 중심: (1+k) phi'' = -1
                new = phi[1] + h * h / (2.0 * (1 + k))
            elif i == 0 or i == n:              # 바깥 경계 Neumann (ghost = 안쪽 이웃)
                j = 1 if i == 0 else n - 1
                new = phi[j] + 0.5 * h * h
            else:
                c = k * h / (2.0 * r[i])
                new = 0.5 * ((1 - c) * phi[i - 1] + (1 + c) * phi[i + 1] + h * h)
            du = omega * (new - phi[i])
            phi[i] += du
            dmax = max(dmax, abs(du))
        if dmax < tol * max(phi[0], phi[n]):
            return r, phi, it
    return r, phi, it

def spalding_d(r, phi):
    """d = -|grad phi| + sqrt(|grad phi|^2 + 2 phi)"""
    n = len(r) - 1
    h = r[1] - r[0]
    d = []
    for i in range(n + 1):
        if i == 0:
            g = (-3 * phi[0] + 4 * phi[1] - phi[2]) / (2 * h)
        elif i == n:
            g = (3 * phi[n] - 4 * phi[n - 1] + phi[n - 2]) / (2 * h)
        else:
            g = (phi[i + 1] - phi[i - 1]) / (2 * h)
        g = abs(g)
        d.append(-g + math.sqrt(g * g + 2 * max(phi[i], 0.0)))
    return d

def ratio_at(r, d, wall_r, y):
    """벽에서 y 떨어진 점의 d_PDE / d_exact (선형 보간)"""
    target = wall_r + y if r[0] == wall_r else wall_r - y
    for i in range(len(r) - 1):
        lo, hi = sorted((r[i], r[i + 1]))
        if lo <= target <= hi:
            t = (target - r[i]) / (r[i + 1] - r[i])
            return (d[i] + t * (d[i + 1] - d[i])) / y
    return float('nan')

a = 1.0
cases = [  # (이름, k, r0, r1, 벽이 r1쪽?)
    ("flat  H=5", 0, a, a + 5, False),
    ("cyl   R=2", 1, a, 2.0, False),
    ("cyl   R=5", 1, a, 5.0, False),
    ("cyl   R=20", 1, a, 20.0, False),
    ("sph   R=5", 2, a, 5.0, False),
    ("sph   R=20", 2, a, 20.0, False),
    ("pipe  inside", 1, 0.0, a, True),
]
ys = [0.1, 0.5, 1.0]
print(f"{'case':<13}{'k':>3}{'N':>5}{'SOR it':>8}" + "".join(f"{'y='+str(y):>9}" for y in ys))
for name, k, r0, r1, wall_hi in cases:
    n = 160
    r, phi, it = poisson_phi(k, r0, r1, wall_hi, n)
    d = spalding_d(r, phi)
    wall_r = r1 if wall_hi else r0
    row = [ratio_at(r, d, wall_r, y) for y in ys]
    print(f"{name:<13}{k:>3}{n:>5}{it:>8}" + "".join(f"{v:>9.3f}" for v in row))

print("\nnear-wall model d/y = 1 + k*y/(2a):", "  ".join(
    f"k={k}: " + "/".join(f"{1 + k * y / (2 * a):.3f}" for y in ys) for k in (1, 2)))
```

## 1.38, 2.00, 0.71이 말하는 것

평판은 모든 $y$에서 1.000이다. 1D 유도 그대로다. 원기둥은 $y=0.1a$에서 1.05로, 모델 $1+y/2a$와 맞는다. $y=a$에서는 1.38로, 모델의 1.50보다 작다. 2차 전개가 이미 깨지는 거리이기 때문이다. 구는 $1+y/a$를 거의 그대로 따라 $y=a$에서 2.0이 된다.

바깥 경계 $R$도 결과를 바꾼다. 정확한 벽거리는 바깥 상자 크기를 모른다. 그러나 Poisson 해는 Neumann 경계까지의 전체 영역에 의존한다. $R=2$ 원기둥의 $y=a$ 값 1.128은 곡률이 아니라 경계가 가까워서 얻은 "우연한 정확도"다.

반복수도 봐야 한다. 평판은 1,006회, 구 $R=20$은 22,189회다. 구 바깥 영역은 대부분 $\phi$가 큰 원거리이고, Neumann 경계 쪽 오차가 느리게 빠진다. "PDE가 빠르다"는 말은 선형 솔버가 좋다는 전제 위에 서 있다. 실무 솔버는 SOR 대신 [멀티그리드](/ko/posts/2026-05-06-multigrid-v-cycle-poisson-acceleration/)를 쓴다.

## 오늘의 PDE 벽거리는 어떻게 쓰이나

그래도 이 방법은 살아남았다. 이유는 난류 모델이 $d$를 쓰는 방식에 있다. SA 소산항 $(\tilde\nu/d)^2$은 벽 근처에서 크고 멀어지면 빠르게 사라진다. 첫 셀이 $y^+ \sim 1$인 격자라면 벽 근처의 $y$는 곡률 반경보다 수천 배 작다. 그 영역의 오차 $\kappa y/2$는 0.1%도 안 된다.

문제는 곡률 반경과 경계층 두께가 비슷해지는 곳이다. 가는 와이어, 날개 뒷전, 블레이드 팁 간극이 그렇다. 원기둥 $y=a$에서 $d$가 1.38배면 SA 소산은 $1/1.38^2 \approx 0.52$배가 된다. 오목한 모서리 안쪽에서는 반대로 소산이 커진다.

개선판도 있다. Tucker 계열은 $p$-Poisson($\nabla\cdot(|\nabla\phi|^{p-2}\nabla\phi)=-1$)을 써서 $p\to\infty$에서 Eikonal에 접근한다. Hamilton–Jacobi 형태로 바로 푸는 방법도 있다. 비정렬 격자에서는 $\nabla\phi$ 자체가 [비직교 보정](/ko/posts/2026-07-01-non-orthogonal-diffusion-correction/) 품질에 좌우된다는 점도 기억해야 한다.

## 벽거리 옵션을 PDE로 바꾸기 전에 볼 한 값

내 격자에서 가장 작은 곡률 반경 $a_{min}$을 찾는다. 그리고 그 근처에서 난류 모델이 $d$에 민감한 높이, 대략 경계층 두께 $\delta$를 잰다. $\delta/a_{min}$이 0.1보다 작으면 PDE 벽거리의 오차는 5% 안쪽이다. 0.5를 넘으면 구 형상에서는 50%까지 틀린다. 그때는 Implicit Tree나 Eikonal 계열로 바꾸는 편이 낫다.
