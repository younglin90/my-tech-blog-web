## 확산이 늘어났는데 왜 화염이 꺼지는가

화염편 라이브러리를 만들 때 격자 하나를 손으로 정해야 한다. 스칼라 소산율 $\chi_{st}$를 어디까지 늘려놓고 표를 끊을지다. 너무 짧게 끊으면 난류 계산 중에 표 밖을 조회하고, 너무 길게 잡으면 존재하지도 않는 해를 찾느라 Newton이 헛돈다. 그 경계를 눈으로 보려고 1차원 화염편 방정식을 직접 풀어봤다.

결과부터 적는다. $\chi_{st}$를 0.05에서 10.12 1/s까지, 202배 키우는 동안 최고 온도는 2258.8 K에서 1960.9 K로 13.2%만 내려갔다. 그리고 한 걸음 더 갔더니 해가 없어졌다. 온도가 서서히 0으로 가는 것이 아니라, 버티던 해가 통째로 사라진다.

역설처럼 들린다. 확산은 반응물을 화염면으로 실어 나르는 유일한 수단이다. 비예혼합 화염에서 연료와 산화제는 서로 다른 쪽에서 오고, 분자확산 말고는 만날 길이 없다. 그런데 그 확산을 키웠더니 불이 꺼졌다.

## 화염을 스칼라 하나로 적을 수 있는 조건은 무엇인가

모든 화학종의 확산계수가 같다고 두자. 이 가정을 쓰면 유동 입자의 혼합 상태는 보존 스칼라 하나로 결정된다. 혼합분율(mixture fraction) $Z$다. $Z=0$이 순수 산화제, $Z=1$이 순수 연료다.

Peters는 1984년에 $Z$를 독립변수로 삼는 좌표 변환을 제안했다. 3차원 공간 좌표 대신 $Z$ 위에서 방정식을 적으면, 화염면에 수직인 방향 하나만 남는다.

$$
\rho \frac{\partial Y_k}{\partial t} = \rho \frac{\chi}{2} \frac{\partial^2 Y_k}{\partial Z^2} + \dot{\omega}_k
$$

$Y_k$는 화학종 $k$의 질량분율, $\dot{\omega}_k$는 생성률, $\chi$는 스칼라 소산율이다. 에너지 방정식도 같은 꼴을 갖는다.

$$
\rho \frac{\partial T}{\partial t} = \rho \frac{\chi}{2} \frac{\partial^2 T}{\partial Z^2} - \frac{1}{c_p}\sum_k h_k \dot{\omega}_k
$$

$T$는 온도, $c_p$는 정압비열, $h_k$는 화학종 엔탈피다. Ferreira는 뒤에 $c_p$가 일정하다는 조건을 풀어 더 일반적인 형태를 제시했지만, $c_p$가 상수면 위 식으로 돌아온다.

여기서 주목할 것은 유동이 사라졌다는 점이다. 속도장도, 압력도, 3차원 격자도 없다. 난류가 화염에 하는 일이 전부 $\chi$ 하나에 압축되어 들어갔다. 난류 화염의 다른 축소 — 예혼합 쪽의 주름 가설 — 은 [난류가 화염을 빠르게 하다 꺾이는 지점](/ko/posts/2026-07-28-turbulent-flame-speed-damkohler-bending/)에서 다뤘다.

## 스칼라 소산율은 무엇의 역수인가

$\chi$의 정의는 단순하다.

$$
\chi = 2D\,\left|\nabla Z\right|^2
$$

$D$는 확산계수다. 차원을 보면 1/s다. 확산에 걸리는 특성 시간의 역수로 읽으면 된다.

난류가 화염편을 잡아 늘리면 $Z$의 구배가 커진다. $\chi$는 구배의 제곱에 붙으므로 더 빠르게 커진다. 반응면으로 들어오는 분자확산이 늘어나고, 동시에 반응면에서 **빠져나가는 열전달도 같은 비율로 늘어난다**. 반응물이 반응할 수 있는 체류시간은 줄어든다.

이것이 앞의 역설의 답이다. 확산은 반응물을 데려오지만 열도 가져간다. 화학반응은 온도에 지수적으로 붙어 있으므로, 열을 잃는 쪽이 항상 먼저 이긴다.

대향류 층류 화염에서 $\chi$의 $Z$ 의존성은 닫힌 형태로 적을 수 있다. Pitsch가 DNS로 검증한 형태다.

$$
\chi(Z) = \chi_{st}\,\frac{\exp\!\left(-2\left[\mathrm{erfc}^{-1}(2Z)\right]^2\right)}{\exp\!\left(-2\left[\mathrm{erfc}^{-1}(2Z_{st})\right]^2\right)}
$$

$\chi_{st}$는 화학당량 혼합분율 $Z_{st}$에서의 값이다. 라이브러리의 인덱스가 되는 단 하나의 숫자다. 그리고 $Z_{st}$는 연료와 공기의 조성만으로 정해진다.

$$Z_{st} = \frac{1}{1 + s\,Y_{F,1}/Y_{O,0}}$$

$s$는 연료 1 kg을 태우는 데 필요한 산소 질량, $Y_{F,1}$은 연료 쪽 유입 질량분율, $Y_{O,0}$은 산화제 쪽 산소 질량분율이다.

## 소염 한계는 코드로 어떻게 잡는가

한 단계 비가역 반응 $F + s\,O \to (1+s)P$를 쓰면 미지 함수가 하나로 줄어든다. 확산계수가 같으므로 $Y_F + T/q$는 $Z$에 대해 선형이다.

$$
Y_F(Z) + \frac{T(Z)}{q} = \frac{T_0}{q} + Z\left(Y_{F,1} + \frac{T_1 - T_0}{q}\right)
$$

$q$는 연료 단위 질량당 발열량을 온도 단위로 적은 것이다. $Y_O$도 같은 방식으로 $T$에 묶인다. 그래서 풀 것은 $T(Z)$ 하나, 3중대각 행렬 하나다.

전략은 연속화다. 아주 작은 $\chi_{st}$에서 Burke–Schumann 해로 출발한다. $\chi_{st}$를 1.35배씩 올리며 Newton을 돌리고, 이전 해를 다음 초기추정으로 넘긴다. 연소 해가 사라지는 순간 Newton은 수렴하지 못하거나 상온으로 떨어진다. 그 사이를 기하평균으로 40번 이분하면 한계값이 나온다.

```python
import math

N = 201
H = 1.0 / (N - 1)
ZG = [i * H for i in range(N)]
T_OX, T_FU = 300.0, 300.0      # 양쪽 유입 온도 [K]
S_RATIO = 4.0                  # 연료 1 kg당 산소 [kg]
Y_OX = 0.232                   # 공기 중 산소 질량분율
Q_HEAT = 36000.0               # 발열량을 온도로 환산 [K]
T_ACT = 24000.0                # 활성화 온도 [K]
A_PRE = 2.0e10                 # 전지수 인자 [1/s]

def inv_erfc(y):
    lo, hi = -6.0, 6.0
    for _ in range(80):
        mid = 0.5 * (lo + hi)
        if math.erfc(mid) > y: lo = mid
        else: hi = mid
    return 0.5 * (lo + hi)

def chi_profile(chi_st, z_st):
    # Pitsch의 대향류 형태. 양끝에서 0이 되므로 바닥을 깔아준다
    f = lambda z: math.exp(-2.0 * inv_erfc(2.0 * z) ** 2)
    fst = f(z_st)
    out = []
    for z in ZG:
        v = f(min(max(z, 1e-9), 1 - 1e-9)) / fst
        out.append(chi_st * max(v, 1e-4))
    return out

def couple_species(z, temp, y_fu):
    # 결합 함수: Y_F, Y_O를 T와 Z만으로 복원한다
    yf = (T_OX / Q_HEAT + z * (y_fu + T_FU / Q_HEAT - T_OX / Q_HEAT)) - temp / Q_HEAT
    yo = (Y_OX + S_RATIO * T_OX / Q_HEAT
          + z * (S_RATIO * T_FU / Q_HEAT - Y_OX - S_RATIO * T_OX / Q_HEAT)) - S_RATIO * temp / Q_HEAT
    return max(yf, 0.0), max(yo, 0.0)

def tridiag_sweep(a, b, c, d):
    n = len(b)
    cp = [0.0] * n; dp = [0.0] * n
    cp[0] = c[0] / b[0]; dp[0] = d[0] / b[0]
    for i in range(1, n):
        m = b[i] - a[i] * cp[i - 1]
        cp[i] = c[i] / m
        dp[i] = (d[i] - a[i] * dp[i - 1]) / m
    x = [0.0] * n
    x[-1] = dp[-1]
    for i in range(n - 2, -1, -1):
        x[i] = dp[i] - cp[i] * x[i + 1]
    return x

def newton_flamelet(chi, guess, y_fu, itmax=60):
    T = list(guess)
    n = N - 2
    for _ in range(itmax):
        a = [0.0] * n; b = [0.0] * n; c = [0.0] * n; r = [0.0] * n
        for k in range(n):
            i = k + 1
            yf, yo = couple_species(ZG[i], T[i], y_fu)
            ex = math.exp(-T_ACT / T[i])
            w = A_PRE * yf * yo * ex
            dw = A_PRE * ex * (-yo / Q_HEAT - yf * S_RATIO / Q_HEAT + yf * yo * T_ACT / T[i] ** 2)
            if yf <= 0.0 or yo <= 0.0: w = 0.0; dw = 0.0
            cf = chi[i] / (2.0 * H * H)
            r[k] = -(cf * (T[i + 1] - 2 * T[i] + T[i - 1]) + Q_HEAT * w)
            a[k] = cf if k > 0 else 0.0
            b[k] = -2.0 * cf + Q_HEAT * dw
            c[k] = cf if k < n - 1 else 0.0
        d = tridiag_sweep(a, b, c, r)
        lim = max(abs(v) for v in d)
        scale = min(1.0, 200.0 / lim) if lim > 200.0 else 1.0   # 온도 갱신 제한
        for k in range(n):
            T[k + 1] = max(T[k + 1] + scale * d[k], 280.0)
        if lim < 1e-6:
            return T, True
    return T, False

def burke_schumann(y_fu):
    # 무한 반응속도 극한 — 연속화의 출발점
    z_st = 1.0 / (1.0 + S_RATIO * y_fu / Y_OX)
    T = []
    for z in ZG:
        if z <= z_st: T.append(T_OX + (T_FU - T_OX) * z + Q_HEAT * y_fu * z)
        else: T.append(T_OX + (T_FU - T_OX) * z + Q_HEAT * y_fu * z_st * (1 - z) / (1 - z_st))
    return z_st, T

def extinction_scan(y_fu, chi0=0.05, growth=1.35, steps=60):
    z_st, T = burke_schumann(y_fu)
    chi_st = chi0
    hist = []
    last_ok = None
    while steps > 0:
        chi = chi_profile(chi_st, z_st)
        Tn, ok = newton_flamelet(chi, T, y_fu)
        tmax = max(Tn)
        if not ok or tmax < 1000.0:
            break
        T = Tn; last_ok = (chi_st, tmax, list(Tn))
        hist.append((chi_st, tmax))
        chi_st *= growth; steps -= 1
    lo, hi = last_ok[0], chi_st
    base = last_ok[2]
    for _ in range(40):                      # 마지막 연소 해를 기하 이분으로 조인다
        mid = math.sqrt(lo * hi)
        Tn, ok = newton_flamelet(chi_profile(mid, z_st), base, y_fu)
        if ok and max(Tn) > 1000.0: lo, base = mid, Tn
        else: hi = mid
    return z_st, hist, lo, base

if __name__ == "__main__":
    z_st, hist, chi_q, Tq = extinction_scan(1.0)
    print("Z_st = %.4f   T_ad(Burke-Schumann) = %.1f K" % (z_st, max(burke_schumann(1.0)[1])))
    print("  chi_st [1/s]    T_max [K]   drop [K]")
    tad = hist[0][1]
    for c, t in hist[::3]:
        print("    %9.4f    %8.1f    %7.1f" % (c, t, tad - t))
    print("    %9.4f    %8.1f    %7.1f   <- quench" % (chi_q, max(Tq), tad - max(Tq)))
    print("chi range %.4f -> %.4f = x%.1f,  T_max drop = %.1f %%"
          % (hist[0][0], chi_q, chi_q / hist[0][0], 100.0 * (tad - max(Tq)) / tad))
    print()
    print("  Y_F1     Z_st    T_ad [K]   chi_q [1/s]")
    for yf in (1.0, 0.5, 0.25, 0.125):
        zs, h, cq, _ = extinction_scan(yf)
        print("   %5.3f   %6.4f    %7.1f    %9.3f" % (yf, zs, max(burke_schumann(yf)[1]), cq))
```

## 연료를 희석하면 한계가 왜 더 크게 무너지는가

출력의 두 번째 표가 그것을 보여준다. 연료 질량분율을 1.0에서 0.125로, 8배 희석했다. 단열 화염온도는 2273.2 K에서 1719.8 K로 24% 내려갔다. 그런데 소염 한계 $\chi_q$는 10.123에서 0.561로, 18배 떨어졌다.

온도가 24% 내려갈 때 한계가 1800% 내려간 셈이다. 이유는 Arrhenius 항에 있다. 반응률은 $\exp(-T_a/T)$에 붙어 있고, 여기서 $T_a = 24000$ K다. $T$가 2273에서 1720으로 가면 지수는 $-10.6$에서 $-14.0$으로 움직인다. 지수 차이 3.4는 곱으로 30배다.

$Z_{st}$가 0.055에서 0.317로 옮겨간 것도 같은 방향으로 작용한다. 앞의 첫 번째 시뮬레이션에서 `Z_st`를 오른쪽으로 밀어보면 보인다. $\chi(Z)$의 봉우리는 $Z=0.5$ 근처에 있으므로, $Z_{st}$가 커질수록 반응대가 봉우리에 가까워진다. 같은 신장률로 더 많은 소산을 맞는다.

실무에서 이 조합이 나오는 자리가 배기가스 재순환(EGR)이다. 연료나 산화제를 불활성 기체로 희석하면 $T_{ad}$는 완만하게 내려가는데 소염 한계는 급격히 내려간다. 국소 소염이 먼저 나타나고, 그다음에 화염 부상(lift-off)이, 마지막에 날아감(blow-off)이 온다.

## 화염편 라이브러리를 만들 때 실제로 흥정하는 것

$\chi_{st}$ 격자를 $\chi_q$까지 꽉 채워 만들면 계산은 촘촘해지지만 무릎 근처에서 표가 급격히 휘어 보간 오차가 커진다. 반대로 여유를 두고 끊으면 난류 계산이 표 밖을 조회한다. 실제로 흥정하는 것은 "어디까지 계산하느냐"가 아니라 **"무릎을 표의 몇 개 점으로 표현하느냐"**다.

정상 화염편 라이브러리는 구조적으로 무릎을 넘어간 상태를 담지 못한다. $\chi_{st} > \chi_q$인 셀에서 무엇을 반환할지는 표가 아니라 모델이 정해야 한다. 동결 해로 보내거나, 별도의 소염 확률로 가중하거나, 비정상 화염편(unsteady flamelet)으로 넘어가야 한다.

그리고 $\chi_{st}$ 자체가 난류 모델의 출력이라는 점을 잊기 쉽다. LES에서는 부격자 스칼라 소산을 모델해서 넣는데, 그 모델 상수가 [동적 Smagorinsky 계수](/ko/posts/2026-09-15-dynamic-smagorinsky-germano-identity/)처럼 국소적으로 흔들린다. 라이브러리가 아무리 정확해도, 인덱스가 2배 틀리면 무릎의 어느 쪽에 있는지가 뒤집힌다.

다음에 화염편 계산이 근거 없이 상온으로 떨어지면, 반응 메커니즘보다 $\chi_{st}$ 입력부터 확인하자. 대개 무릎의 오른쪽을 조회하고 있다.
