## 나무 각재를 물에 던지면 어느 면이 위로 올까

단면이 정사각형인 긴 각재가 있다. 밀도는 물의 절반이다. 물에 던지면 어떻게 뜰까. 대부분은 한 면이 위를 보는 평평한 자세를 떠올린다. 실제로는 모서리 하나가 아래를 향한 다이아몬드 자세로 뜬다. 이 글은 그 이유를 메타센터 높이(metacentric height, 부유체 안정성을 재는 길이) 하나로 설명한다. 끝까지 읽으면 GM 공식을 유도하고, 경사각마다 부력중심을 직접 계산해서 "평평하게 뜨는 밀도 구간"을 숫자로 확인할 수 있다.

기체역학 교재를 옮긴 오래된 노트의 3-6절 'Buoyancy & stability'에는 그림 몇 장과 짧은 메모만 남아 있다. "시계방향 모멘트면 안정." "위쪽이 무거우면 반시계방향 모멘트, 불안정." 이 두 줄이 오늘의 출발점이다. 무게중심이 높으면 불안정하다는 건 직관과 맞는다. 그런데 균질한 각재는 무게중심이 정확히 가운데다. 무엇이 자세를 정할까.

## 부력의 중심은 물체와 함께 움직이지 않는다

물체에 작용하는 힘은 두 개다. 무게는 무게중심 G에서 아래로 작용한다. 부력은 잠긴 부피의 중심 B(부력중심)에서 위로 작용한다. 평형에서는 두 힘의 크기가 같고 같은 연직선 위에 있다.

물체를 조금 기울이면 G는 물체에 붙어 함께 돈다. B는 그렇지 않다. 한쪽이 더 잠기고 반대쪽이 떠오르면서 잠긴 부분의 모양이 바뀐다. B는 더 잠긴 쪽으로 미끄러진다. 이 이동이 충분히 크면 부력이 G의 바깥쪽에서 밀어 올려 물체를 되돌린다. 모자라면 부력과 무게가 짝힘(couple, 크기가 같고 방향이 반대인 두 힘)을 이뤄 기울기를 키운다.

두 힘 작용선 사이의 수평 거리를 복원팔(righting arm) GZ라 부른다. 되돌리는 쪽이면 양수다. 아래 시뮬레이션에서 직접 조작해보자.

## 메타센터 높이 GM = BM − BG

작은 경사각 θ에서 B가 이동한 뒤 지나는 부력 작용선은 물체 중심선과 한 점에서 만난다. 이 점이 메타센터 M이다. M이 G보다 위에 있으면 안정이다. 둘 사이의 거리가 GM이고, 작은 각에서 복원팔은 다음과 같다.

$$GZ \approx GM \sin\theta$$

GM은 기하학만으로 구할 수 있다. 수선면(waterplane, 물체가 수면을 자르는 단면)을 축으로 한 단면 2차 모멘트를 $I$, 잠긴 부피를 $V$라 하자.

$$GM = BM - BG = \frac{I}{V} - (KG - KB)$$

$K$는 바닥(keel), $KB$는 바닥에서 부력중심까지, $KG$는 바닥에서 무게중심까지의 높이다. $BM = I/V$는 B가 기울기에 따라 얼마나 멀리 미끄러지는지를 나타낸다. 수선면이 넓을수록 커진다.

## 정사각형에서는 GM이 s만의 함수다

폭 $b$, 높이 $h$인 직사각 단면을 단위 길이로 보자. 균질한 물체의 밀도비를 $s = \rho_{body}/\rho_{water}$라 하면 흘수(draft, 잠긴 깊이)는 $d = sh$다.

$$I = \frac{b^3}{12},\quad V = b\,s h,\quad KB = \frac{sh}{2},\quad KG = \frac{h}{2}$$

이를 대입하면 다음을 얻는다.

$$GM = \frac{b^2}{12\,s\,h} + \frac{s h}{2} - \frac{h}{2}$$

첫 항은 수선면이 주는 복원, 나머지 두 항은 G가 B보다 높아서 생기는 손해다. 정사각형($b = h = 1$)이면 이렇게 정리된다.

$$GM = \frac{6s^2 - 6s + 1}{12\,s}$$

분자가 0이 되는 $s = (3 \pm \sqrt{3})/6$, 곧 0.2113과 0.7887이 경계다. 그 사이에서는 GM이 음수다. 아주 가볍거나 아주 무거운 각재만 평평하게 뜬다. 식은 $s \leftrightarrow 1-s$에 대해 부호가 같다. 밀도 $s$로 뜬 물체를 뒤집으면 수면 위 부분이 밀도 $1-s$로 잠긴 물체와 같은 문제가 되기 때문이다.

이 식은 작은 θ에서만 맞다. GM이 음수일 때 물체가 어디까지 넘어가서 멈추는지는 말해주지 않는다. 그건 큰 각에서 GZ(θ) 전체를 계산해야 안다.

## 코드: 경사각 901개마다 흘수선을 이분법으로

계산 순서는 단순하다. 단면을 θ만큼 회전한다. 잠긴 넓이가 $s\,bh$가 되는 수면 높이 $c$를 이분법(bisection, 구간을 반씩 줄여 근을 찾는 방법)으로 찾는다. 잠긴 다각형의 도심이 B다. G를 원점에 두면 $GZ = -x_B$다. θ를 0~90°로 쓸며 GZ가 음에서 양으로 바뀌는 곳이 안정 평형이다.

```python
import numpy as np

def clip_below(poly, c):
    """다각형 중 y < c 인 부분 (Sutherland–Hodgman, 직선 하나)"""
    out = []
    n = len(poly)
    for i in range(n):
        p, q = poly[i], poly[(i + 1) % n]
        pin, qin = p[1] < c, q[1] < c
        if pin:
            out.append(p)
        if pin != qin:
            t = (c - p[1]) / (q[1] - p[1])
            out.append((p[0] + t * (q[0] - p[0]), c))
    return out

def area_centroid(poly):
    A = cx = cy = 0.0
    n = len(poly)
    for i in range(n):
        x0, y0 = poly[i]; x1, y1 = poly[(i + 1) % n]
        cr = x0 * y1 - x1 * y0
        A += cr; cx += (x0 + x1) * cr; cy += (y0 + y1) * cr
    A *= 0.5
    return A, cx / (6 * A), cy / (6 * A)

def righting_arm(theta, s, b=1.0, h=1.0):
    """경사각 theta에서 복원팔 GZ (G는 원점, 양수 = 되돌리는 쪽)"""
    co, si = np.cos(theta), np.sin(theta)
    box = [(-b/2, -h/2), (b/2, -h/2), (b/2, h/2), (-b/2, h/2)]
    poly = [(x*co - y*si, x*si + y*co) for x, y in box]
    target = s * b * h
    lo, hi = -0.8*(b+h), 0.8*(b+h)
    for _ in range(60):                       # 흘수선 높이 c를 이분법으로
        c = 0.5 * (lo + hi)
        sub = clip_below(poly, c)
        A = area_centroid(sub)[0] if len(sub) >= 3 else 0.0
        lo, hi = (c, hi) if A < target else (lo, c)
    _, xB, _ = area_centroid(clip_below(poly, c))
    return -xB

def floating_angles(s, b=1.0, h=1.0, n=901):
    th = np.linspace(0, np.pi/2, n)
    gz = np.array([righting_arm(t, s, b, h) for t in th])
    gm = (righting_arm(1e-4, s, b, h)) / 1e-4
    stable = [0.0] if gm > 0 else []
    for i in range(1, n - 2):                 # GZ: − → + 로 바뀌는 곳 = 안정 평형
        if gz[i] < -1e-9 and gz[i+1] > -1e-9:
            stable.append(np.degrees(th[i] - gz[i]*(th[i+1]-th[i])/(gz[i+1]-gz[i])))
    if b != h and gz[-2] < 0:                 # 90°(세워진 자세)도 평형
        stable.append(90.0)
    return gm, stable

print("square section (b/h = 1), homogeneous body, s = rho_body / rho_water")
print(" s     GM_theory   GM_numeric   stable heel (deg)")
for s in [0.10, 0.20, 0.22, 0.24, 0.30, 0.50, 0.70, 0.76, 0.80, 0.90]:
    gm_th = 1/(12*s) + s/2 - 0.5
    gm, st = floating_angles(s)
    print(f"{s:.2f}  {gm_th:+.5f}    {gm:+.5f}     {', '.join(f'{a:.1f}' for a in st)}")
print()
print("s = 0.5, widening the section (h = 1)")
print(" b/h   GM_theory   stable heel (deg)")
for b in [1.0, 1.1, 1.2, 1.25, 1.3, 1.5]:
    s = 0.5
    gm_th = b*b/(12*s) + s/2 - 0.5
    gm, st = floating_angles(s, b=b)
    print(f"{b:.2f}  {gm_th:+.5f}    {', '.join(f'{a:.1f}' for a in st)}")
print(f"\ncritical s: (3-sqrt3)/6 = {(3-np.sqrt(3))/6:.4f}, (3+sqrt3)/6 = {(3+np.sqrt(3))/6:.4f}")
```

## 표 읽기: 45°, 23.5°, 그리고 b/h = 1.225

첫째, 수치 GM과 이론 GM이 다섯 자리까지 같다. 작은 각 기울기 $dGZ/d\theta$가 정확히 $I/V - BG$라는 뜻이다. 공식에 근사는 없다. 작은 각이라는 조건만 있다.

둘째, s = 0.30, 0.50, 0.70에서는 45°가 유일한 안정점이다. 정사각형은 대칭이라 45°에서 GZ가 항상 0이다. GM이 충분히 음수면 0°에서 밀려난 물체가 다음 대칭 자세인 다이아몬드까지 간다.

셋째, 경계 바로 안쪽인 s = 0.22, 0.24에서는 중간 각 13.7°, 23.5°에 멈춘다. 76.3°와 66.5°는 같은 자세를 반대편 면 기준으로 잰 값이다. 평평한 자세가 불안정해지는 순간 45°로 뛰지 않는다. 기울기가 0°에서 연속적으로 자라 s ≈ 0.28 근처에서 45°에 닿는다(같은 코드로 s = 0.28이면 41.2°, 0.29면 45.0°). GM 부호는 안정 여부만 알려주고, 멈추는 각은 GZ 곡선 전체가 정한다.

넷째, 밀도를 0.5로 두고 폭만 넓히면 $b^2/6 = 1/4$, 곧 $b/h = \sqrt{1.5} \approx 1.225$에서 GM이 0을 지난다. 표의 1.20 → 1.25 사이 부호 전환이 그것이다. 폭 22%가 다이아몬드와 평평한 자세를 가른다.

## 선박 설계와 CFD에서 이 계산이 쓰이는 자리

선박 복원성 검토는 위 코드를 실제 선체 형상으로 바꾼 것이다. 단면 대신 3D 선체를 수면으로 자르고, 각도별 GZ 곡선을 그린다. 규정은 GM의 하한과 함께 GZ 곡선 아래 넓이(복원 에너지)도 요구한다. 오늘 표가 보여준 것처럼 작은 각 GM만으로는 큰 각 거동을 알 수 없기 때문이다.

VOF(volume of fluid, 계면을 체적분율로 추적하는 기법)와 6자유도 강체 운동을 결합한 부유체 CFD에서도 같은 계산이 첫 검증이 된다. 정지 수면에 물체를 놓고 시뮬레이션이 정적 평형 자세를 맞히는지 본다. 이것이 틀리면 대개 질량·관성·무게중심 입력이 잘못된 것이다. 압력장이 정수압 $p = \rho g (c - y)$로 수렴하면 부력과 B는 오늘 다각형 계산과 같아야 한다. 정지 유체에서 응력이 $-p\mathbf{I}$만 남는 과정은 [응력 발산 ∇·τ를 다룬 글](/ko/posts/2026-11-03-stress-divergence-variable-viscosity-laplacian/)에서 Newton 제2법칙으로 정리했다.

자유 감쇠(free decay) 시험도 같은 GM을 쓴다. 작은 각에서 롤 운동은 $I_{roll}\ddot\theta = -m g\,GM\,\theta$인 진자다. 측정한 고유 주기로 GM을 역산할 수 있다. 정수압에서 출발하는 한 장짜리 계산이 동역학 검증 기준이 되는 셈이다. 손실을 운동량으로 따져야 하는 [급확대관의 Borda–Carnot 손실](/ko/posts/2026-11-05-borda-carnot-sudden-expansion-lost-velocity/)과 달리, 여기서는 정수압 적분만으로 답이 닫힌다.

## 바지선에 화물을 싣기 전에 확인할 부등식 하나

$$\frac{b^2}{12\,s\,h} > \frac{h}{2} - \frac{sh}{2} + \Delta_G$$

$\Delta_G$는 화물로 올라간 무게중심의 높이 변화다. 좌변은 폭의 제곱으로 자라고, 우변은 G를 올릴 때마다 커진다. 갑판 위에 화물을 쌓으면 $\Delta_G$가 커진다. 가벼운 화물이면 $s$가 작아져 좌변도 커진다. 둘 중 무엇이 이기는지는 이 한 줄로 판단된다. 첫 번째 시뮬레이션에서 b/h를 1.25로 두고 G shift를 +0.1만 올려도 단면이 넘어가는 것을 확인해보자.
