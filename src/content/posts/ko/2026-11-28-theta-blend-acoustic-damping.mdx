## 안정할수록 음파가 사라진다

음해법(implicit method)은 시간 간격을 키워도 터지지 않는다. 그래서 저마하 압축성 솔버는 음향 항을 음해로 푼다. 그런데 가장 안정한 후방 오일러(Backward Euler, BE)는 음파를 조용히 지운다. 우리 압축성 다상 코드의 음향 반사 케이스에서도 그랬다. 반사파 진폭이 약 23% 작게 나왔다. 이 글은 Dimarco, Loubère, Michel-Dansac, Vignal(2017)의 IMEX-TVD 아이디어를 1D로 줄여 재현한다. 읽고 나면 BE와 크랭크–니콜슨(Crank–Nicolson, CN)을 셀마다 섞는 이유와 그 한계를 숫자로 설명할 수 있다.

## 한 개의 푸리에 모드가 매 스텝 잃는 것

가장 단순한 모델은 선형 이류 $u_t + u_x = 0$이다. 1D 음향계의 리만 불변량(Riemann invariant, 특성선을 따라 일정한 양) $p + \rho c\,u$가 정확히 이 식을 따른다. 그러니 음파 하나를 이류로 봐도 된다.

θ-스킴은 공간 플럭스를 현재와 다음 시각 사이에서 가중 평균한다.

$$
u_i^{n+1} - u_i^n + \nu\left[\theta\,\delta F^{n+1} + (1-\theta)\,\delta F^{n}\right]_i = 0
$$

$\nu = c\Delta t/\Delta x$는 음향 CFL 수, $\delta F$는 중앙 면 플럭스의 차분이다. $\theta = 1$이면 BE, $\theta = 1/2$이면 CN이다.

파수 $\kappa = k\Delta x$인 모드를 넣으면 한 스텝 증폭률이 나온다.

$$
|G|^2 = \frac{1 + (1-\theta)^2 s^2}{1 + \theta^2 s^2}, \qquad s = \nu \sin\kappa
$$

$\theta = 1/2$이면 분자와 분모가 같아 $|G| = 1$이다. 진폭을 하나도 잃지 않는다. $\theta = 1$이면 $|G| = 1/\sqrt{1+s^2}$로 매 스텝 줄어든다. 한 스텝 손실은 작아도 수백 스텝이 쌓이면 크다.

## CN이 정답이 아닌 이유

CN은 진폭을 보존하지만 분산(dispersion, 파장마다 속도가 다른 현상)은 그대로다. 짧은 파장은 느리게 간다. 매끈한 가우스 펄스에는 큰 문제가 없다. 계단 모양 펄스는 다르다. 계단에는 짧은 파장이 많고, 그것들이 뒤처지며 물결을 만든다. 이것이 깁스 진동(Gibbs oscillation)이다.

BE는 짧은 파장을 강하게 감쇠한다. 그래서 계단 근처가 단조롭게 남는다. BE는 TVD(total variation diminishing, 총변동이 늘지 않는 성질)를 만족하는 쪽이다. 두 스킴의 장단점이 정확히 반대다.

## 논문의 착상: θ를 셀마다 고른다

Dimarco 외(2017)는 저마하 오일러 방정식에서 이 문제를 다뤘다. 1차 음해 해는 TVD지만 확산이 크다. 2차 해는 정확하지만 진동한다. 논문은 둘을 리미터로 셀마다 섞어 2차 정확도와 TVD를 함께 노린다.

이 글은 그 착상을 θ 하나로 줄인다. 현재 해 $u^n$에서 기울기 비 $r_i$를 계산하고 minmod로 자른다.

$$
\phi_i = \max\!\left(0, \min(1, r_i)\right), \qquad \theta_i = 1 - \tfrac{1}{2}\phi_i
$$

$r_i = (u_i - u_{i-1})/(u_{i+1} - u_i)$는 양쪽 기울기의 비다. 매끈하면 $r_i \approx 1$이라 $\theta_i = 1/2$(CN)이다. 불연속이나 극값에서는 $r_i \le 0$이라 $\theta_i = 1$(BE)이다. 면 $i+1/2$에는 양옆 셀 중 큰 θ를 쓴다.

θ를 $u^n$에서 정하므로 연립방정식은 여전히 선형이다. 뉴턴 반복이 필요 없다. 이 점은 [Thomann–Iollo–Puppo 완화 기법](/ko/posts/2026-11-22-jin-xin-relaxation-linear-implicit-pressure/)이 노린 목표와 같다. 면 플럭스 형태라서 질량도 기계 정밀도로 보존된다.

## 코드: 가우스와 계단을 한 바퀴 돌린다

주기 상자 $[0,1]$을 200셀로 나눈다. 가우스 펄스와 계단 펄스를 세 스킴으로 정확히 한 바퀴 이류시킨다. 정확해는 처음 모양 그대로다. 가우스는 최댓값을, 계단은 최댓값·최솟값을 본다.

```python
import numpy as np

N = 200                      # cells on periodic [0, 1]
dx = 1.0 / N
x = (np.arange(N) + 0.5) * dx

def face_theta(u, mode):
    """theta at face i+1/2: 1 = Backward Euler, 1/2 = Crank-Nicolson"""
    if mode == "BE":
        return np.ones(N)
    if mode == "CN":
        return np.full(N, 0.5)
    # BLEND: minmod smoothness ratio from u^n
    dm = u - np.roll(u, 1)
    dp = np.roll(u, -1) - u
    r = dm / np.where(np.abs(dp) < 1e-12, 1e-12, dp)
    phi = np.clip(np.minimum(1.0, r), 0.0, 1.0)   # 1 smooth, 0 jump/extremum
    th = 1.0 - 0.5 * phi
    return np.maximum(th, np.roll(th, -1))        # take the safer neighbor

def theta_step(u, nu, mode):
    """one implicit step of u_t + u_x = 0, central face flux, per-face theta"""
    tp = face_theta(u, mode)          # face i+1/2
    tm = np.roll(tp, 1)               # face i-1/2
    i = np.arange(N)
    A = np.eye(N)
    A[i, i] += 0.5 * nu * (tp - tm)
    A[i, (i + 1) % N] += 0.5 * nu * tp
    A[i, (i - 1) % N] -= 0.5 * nu * tm
    f = 0.5 * (u + np.roll(u, -1))    # explicit part of face flux
    rhs = u - nu * ((1 - tp) * f - (1 - tm) * np.roll(f, 1))
    return np.linalg.solve(A, rhs)

gauss = np.exp(-((x - 0.5) / 0.08) ** 2)
square = np.where(np.abs(x - 0.5) < 0.15, 1.0, 0.0)

print(" nu  scheme  gauss_peak  square_max  square_min   mass")
for nu in (0.5, 1.0, 2.0):
    steps = int(round(N / nu))        # exactly one lap around the box
    for mode in ("BE", "CN", "BLEND"):
        g, s = gauss.copy(), square.copy()
        for _ in range(steps):
            g = theta_step(g, nu, mode)
            s = theta_step(s, nu, mode)
        print(f"{nu:4.1f}  {mode:6s}  {g.max():10.4f}  {s.max():10.4f}"
              f"  {s.min():10.4f}  {s.sum() * dx:.6f}")
```

## 표 읽기: 0.75, 1.31, 그리고 0.95

CFL 0.5에서 BE의 가우스 봉우리는 0.7497이다. 한 바퀴에 25%를 잃었다. 앞서 말한 반사파 23% 감쇠와 같은 크기다. CN은 0.9976으로 거의 보존한다. 대신 계단 최댓값이 1.3142, 최솟값이 −0.2945다. 31%를 넘어 튄다. 밀도나 체적분율이라면 음수는 곧 계산 중단이다.

BLEND는 가우스 0.9452, 계단 1.0245와 −0.0263이다. 진폭 손실은 BE의 5분의 1로 줄고, 진동은 CN의 10분의 1 이하다. 질량은 모든 경우 0.300000으로 같다.

CFL 2에서는 그림이 바뀐다. BLEND 가우스 봉우리가 0.6142로 떨어져 BE(0.4939)에 가까워진다. 이유는 두 가지다. 첫째, minmod는 매끈한 극값도 불연속으로 보고 BE를 고른다. TVD 리미터 공통의 극값 깎기(clipping)다. 둘째, CFL이 크면 한 스텝 BE 손실 $s^2$이 커져 그 몇 셀이 전체를 끌어내린다. 논문도 2차 보정에는 CFL 제한을 둔다.

## 이 장난감과 논문 사이의 거리

논문은 오일러 방정식 전체를 IMEX로 나눈다. 대류는 양해, 음향은 음해다. 여기서는 음향 특성 하나만 남겼다. 논문의 리미터는 1차 음해 해와 2차 해의 차이를 제한하는 구조다. 여기서는 그것을 면별 θ로 단순화했다. 따라서 숫자 자체보다 경향을 봐야 한다.

같은 소스 묶음의 다른 선택지도 있다. Arun 외(2019)는 BE 대신 ARS(2,2,2) 2단 IMEX-RK를 써서 감쇠를 $O(\Delta t)$에서 $O(\Delta t^2)$로 낮춘다. 다만 2차 IMEX도 강성 극한에서 차수를 잃을 수 있다. 그 사례는 [M→0에서 1차로 떨어진 IMEX](/ko/posts/2026-11-08-imex-order-reduction-stiffly-accurate/)에 정리했다.

## 음향 감쇠를 의심할 때 먼저 바꿔볼 숫자

반사파나 공명 진폭이 작게 나오면 θ부터 확인한다. θ = 1이라면 위 증폭률 식에 실제 $\nu$와 파장당 셀 수를 넣어 한 주기 손실을 계산해본다. 그 값이 관측 오차와 비슷하면 원인은 시간 적분이다. 다음은 θ를 면마다 고르는 것이다. 그리고 CFL을 1 근처로 낮춰 BLEND가 CN 쪽에 머무는지 본다. 음해법이니 CFL을 마음껏 키워도 된다는 생각이 감쇠의 출발점이다.
