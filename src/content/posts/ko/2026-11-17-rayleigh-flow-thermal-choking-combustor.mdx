## 연소기 앞에는 왜 디퓨저가 있을까

제트 엔진 압축기 출구의 공기는 마하수 0.3~0.4로 빠져나온다. 그런데 연소기에 들어가기 전에 일부러 디퓨저(diffuser, 유로를 넓혀 감속하는 관)로 속도를 절반 이하로 줄인다. 화염 안정이 첫 번째 이유다. 두 번째 이유는 열역학이다. 움직이는 기체에 열을 넣는 일 자체가 전압(stagnation pressure, 기체를 등엔트로피로 정지시켰을 때의 압력)을 깎는다. 입구가 빠를수록 더 많이 깎인다.

이 글은 그 손실을 숫자로 잰다. 마찰 없는 등단면 덕트에 전온도를 2배로 올리는 열을 넣는다. 입구 마하수를 0.10에서 0.40까지 바꿔 가며 출구 상태를 RK4로 적분한다. 결론은 둘이다. 입구 0.30이면 전압을 7.1% 잃는다. 입구 0.384를 넘으면 열을 끝까지 넣을 수조차 없다.

## 등단면 덕트에 열만 넣는다: Rayleigh 유동

원본 노트(Hill & Peterson 3.5절)의 설정은 단순하다. 단면적이 일정하고 마찰이 없다. 벽을 통한 일도 없다. 바뀌는 것은 전온도 $T_0$ 하나뿐이다. 연소, 액적 증발, 줄 가열, 벽 열전달이 모두 이 모델에 들어간다. 이런 흐름을 Rayleigh 유동이라 부른다.

연속식과 운동량식은 바로 적분된다. $\rho u$가 상수이고 $p + \rho u^2$도 상수다. 둘을 마하수로 쓰면 입구(아래첨자 1) 대비 정압비가 나온다.

$$\frac{p}{p_1} = \frac{1 + \gamma M_1^2}{1 + \gamma M^2}$$

$\gamma$는 비열비, $M$은 국소 마하수다. 상태방정식과 에너지식을 더하면 전온도와 마하수가 일대일로 묶인다. 음속점(아래첨자 $*$)을 기준으로 쓰면 다음과 같다.

$$\frac{T_0}{T_0^*} = \frac{2(\gamma + 1)M^2 \left(1 + \frac{\gamma - 1}{2}M^2\right)}{(1 + \gamma M^2)^2}$$

$T_0^*$는 같은 질량유속에서 $M=1$이 되는 전온도다. 이 함수의 최댓값은 $M=1$에서 1이다. 즉 어떤 흐름이든 넣을 수 있는 열에는 상한이 있다.

아래 T–s 선도에서 직접 조작해보자. 입구 마하수와 가열량을 바꾸면 상태점이 Rayleigh 선을 따라 움직인다.

아음속에서 시작하든 초음속에서 시작하든 가열은 점을 엔트로피 최대점($M=1$)으로 민다. 가열량을 키우면 점이 그 끝에 멈추고 빨간 경고가 뜬다. 음수 가열(냉각)은 점을 반대쪽으로 보낸다.

## 열을 넣으면 마하수는 1로 끌려간다

닫힌 식 대신 미분형을 쓰면 원인이 더 잘 보인다. 세 보존식을 미소 변화로 정리하면 다음 영향계수가 나온다.

$$\frac{dM^2}{M^2} = \frac{(1 + \gamma M^2)\left(1 + \frac{\gamma - 1}{2}M^2\right)}{1 - M^2}\,\frac{dT_0}{T_0}$$

분자는 항상 양수다. 부호는 분모 $1-M^2$가 정한다. 아음속에서는 $dT_0>0$이면 $M$이 커진다. 초음속에서는 $M$이 작아진다. 둘 다 1을 향한다. 그리고 $M \to 1$에서 계수가 발산한다. 열을 조금만 더 넣어도 마하수가 크게 움직인다는 뜻이다.

직관은 이렇다. 가열하면 밀도가 떨어진다. 질량유속 $\rho u$가 같으니 속도가 올라야 한다. 속도가 오르면 운동량식 때문에 정압이 떨어진다. 정압이 떨어지면 밀도가 더 떨어진다. 아음속에서는 이 고리가 스스로 증폭된다.

## 열을 넣었는데 온도가 내려가는 구간

정온도 비는 $T/T^* = M^2\left[(1+\gamma)/(1+\gamma M^2)\right]^2$이다. 이 식은 $M=1/\sqrt{\gamma}$에서 최대가 된다. 공기($\gamma=1.4$)라면 $M=0.845$다. 그 위에서 $M=1$까지는 열을 넣을수록 정온도가 내려간다.

모순처럼 보이지만 에너지식은 지켜진다. 넣은 열보다 운동에너지 증가가 더 크다. 그 차이를 정엔탈피가 메운다. 위 시뮬레이션에서 주황색 구간이 이 영역이다. 입구 0.6, 가열 0.3으로 두면 점이 주황 구간에 들어서며 $T/T_1$이 줄기 시작한다.

전압은 경우가 다르다. 가열은 엔트로피를 늘린다. 그래서 아음속이든 초음속이든 전압은 항상 떨어진다. 원본 노트의 식 (3.18)이 그 비율이다. 노트에는 지수가 $\gamma(\gamma-1)$로 적혀 있지만 $\gamma/(\gamma-1)$이 맞다.

## 코드: 전온도 2배, 입구 마하수 일곱 단계

연소기 하나를 흉내 낸다. 덕트 길이 $x\in[0,1]$에 열을 균일하게 넣어 $T_0$를 1에서 $\tau=2$로 올린다. 800 K 공기를 1600 K로 데우는 셈이다. 위 영향계수를 $T_0$에 대해 RK4로 4000단계 적분한다. $M^2$가 0.9999에 닿으면 열적 초킹(thermal choking, 가열로 음속에 도달해 더 이상 열을 받을 수 없는 상태)으로 판정한다. 정압·정온·전압은 국소 마하수로 계산한다. 마지막으로 닫힌 해와 RK4 결과를 비교한다.

```python
import math

G = 1.4  # 비열비

def t0_ratio_star(M):
    """식 (3.21): T0/T0*"""
    m2 = M*M
    return 2*(G+1)*m2*(1+0.5*(G-1)*m2)/(1+G*m2)**2

def dm2_dt0(m2, t0):
    """Rayleigh 영향계수: dM²/dT0"""
    return m2*(1+G*m2)*(1+0.5*(G-1)*m2)/(1-m2)/t0

def heat_march(M1, tau, n=4000):
    """덕트 길이 x∈[0,1]에 열을 균일하게 넣으며 M²를 RK4로 전진."""
    m2, t0 = M1*M1, 1.0
    dt0 = (tau-1.0)/n
    xs, ms = [0.0], [M1]
    for i in range(n):
        k1 = dm2_dt0(m2, t0)
        k2 = dm2_dt0(m2+0.5*dt0*k1, t0+0.5*dt0)
        k3 = dm2_dt0(m2+0.5*dt0*k2, t0+0.5*dt0)
        k4 = dm2_dt0(m2+dt0*k3, t0+dt0)
        m2n = m2 + dt0*(k1+2*k2+2*k3+k4)/6
        t0 += dt0
        if not (0 < m2n < 1) or m2n > 0.9999:   # 음속 도달 → 열적 초킹
            return xs, ms, (i+1)/n
        m2 = m2n
        xs.append((i+1)/n); ms.append(math.sqrt(m2))
    return xs, ms, None

def ratios(M, M1):
    """입구 대비 정압·정온·전압 비 (마찰 없는 등단면)"""
    p = [(1+G*M1**2)/(1+G*m**2) for m in M]
    T = [(pi*m/M1)**2 for pi, m in zip(p, M)]
    p0 = [pi*((1+0.5*(G-1)*m**2)/(1+0.5*(G-1)*M1**2))**(G/(G-1)) for pi, m in zip(p, M)]
    return p, T, p0

def m1_max(tau):
    """T0 비 tau를 초킹 없이 넣을 수 있는 최대 입구 마하수 (이분법)"""
    lo, hi = 1e-4, 1.0
    for _ in range(60):
        mid = 0.5*(lo+hi)
        lo, hi = (mid, hi) if t0_ratio_star(mid) < 1/tau else (lo, mid)
    return 0.5*(lo+hi)

tau = 2.0   # 연소기: 전온도 2배
print(f"tau = T02/T01 = {tau}   M1_max (closed form) = {m1_max(tau):.4f}")
print(" M1   | M_exit  p0 loss[%]  T_max/T1  x(T_max)  choke x")
for M1 in [0.10, 0.15, 0.20, 0.25, 0.30, 0.35, 0.40]:
    x, M, xc = heat_march(M1, tau)
    p, T, p0 = ratios(M, M1)
    k = max(range(len(T)), key=T.__getitem__)
    loss = 100*(1-p0[-1])
    xtm = f"{x[k]:.3f}" if k < len(x)-1 else "exit"
    cs = f"{xc:.3f}" if xc else "-"
    print(f" {M1:.2f} | {M[-1]:.4f}  {loss:9.2f}  {max(T):8.3f}  {xtm:>8}  {cs:>7}")

# 닫힌 해와 RK4 출구 마하수 비교
x, M, _ = heat_march(0.30, tau)
lo, hi = 0.30, 1.0
target = t0_ratio_star(0.30)*tau
for _ in range(60):
    mid = 0.5*(lo+hi)
    lo, hi = (mid, hi) if t0_ratio_star(mid) < target else (lo, mid)
print(f"M1=0.30: RK4 M_exit={M[-1]:.6f}  closed form={0.5*(lo+hi):.6f}")
mf = lambda M: M*(1+0.5*(G-1)*M*M)**(-(G+1)/(2*(G-1)))   # 같은 p01·T01에서의 질량유량
print(f"M1 0.40 -> {m1_max(tau):.4f}: mass flow x {mf(m1_max(tau))/mf(0.40):.4f}")
print(f"heating cools the gas for {1/math.sqrt(G):.4f} < M < 1")
```

## 0.384, 13.5%, x = 0.890이 말하는 것

첫째, 전압 손실은 입구 마하수의 제곱에 가깝게 늘어난다. 0.10에서 0.71%, 0.20에서 2.92%, 0.30에서 7.11%다. 입구를 0.15로 감속하면 손실은 1.6%로 줄어든다. 디퓨저 자체의 손실을 감안해도 감속할 이유가 충분하다.

둘째, 입구 0.35까지는 출구에 닿는다. 그러나 출구 마하수가 0.66으로 이미 빠르다. 영향계수의 분모가 작아지는 구간이다. 열 방출 분포가 조금만 흔들려도 출구 상태가 크게 흔들린다.

셋째, 입구 0.40은 덕트의 89%만 지나고 음속에 닿는다. 그 전 x = 0.852에서 정온도가 최대(입구의 1.672배)였다. 거기서 $M=0.845$를 지났기 때문이다. 이후 4% 구간 동안은 열을 넣는데 기체가 식었다.

닫힌 해로 구한 한계 $M_{1,\max}=0.3836$은 $T_0/T_0^*(M_1)=1/\tau$의 근이다. RK4 출구 마하수는 닫힌 해와 소수 여섯째 자리까지 같다. 적분이 맞다는 확인이다.

## 초킹된 연소기는 상류를 바꾼다

실제 엔진에서 x = 0.890에서 흐름이 멈추지는 않는다. 아음속 흐름은 하류 정보를 상류로 전한다. 초킹이 일어나면 입구 조건이 스스로 바뀐다. 열을 다 받을 수 있을 만큼 입구 마하수가 0.3836으로 내려간다.

같은 전압·전온도에서 입구 마하수가 0.40에서 0.3836으로 내려가면 질량유량은 0.9663배가 된다. 3.4%의 공기가 덜 들어간다. 압축기 입장에서는 갑자기 출구가 막힌 것과 같다. 작동점이 서지(surge, 압축기 역류) 쪽으로 밀린다. 애프터버너 점화 때 노즐 목을 넓히는 이유가 여기 있다. 열을 넣은 만큼 통로를 열어 상류가 이 변화를 느끼지 못하게 한다.

이 계산은 마찰을 뺐다. 실제 덕트는 마찰(Fanno 유동)도 마하수를 1로 끈다. 그래서 실제 한계는 0.384보다 낮다. 노즐에서 면적이 하던 일을 여기서는 열이 한다는 점은 [수축-확산 노즐과 초킹](/ko/posts/2026-06-18-de-laval-nozzle-choked-flow/)과 나란히 놓고 보면 분명해진다. 압력 기반 솔버로 이런 흐름을 풀 때의 함정은 [압축성 SIMPLE의 ψp′ 항](/ko/posts/2026-11-09-compressible-simple-pressure-correction-psi-term/)에서 다뤘다.

## 애프터버너 설계표에서 τ보다 먼저 볼 숫자

가열 덕트를 설계하거나 CFD 결과를 검토할 때는 τ보다 $T_0/T_0^*(M_1)$을 먼저 계산하자. 그 역수가 그 덕트가 받을 수 있는 최대 전온도비다. τ가 그 값에 가까울수록 출구 상태는 열 방출 분포에 민감해진다. 넘으면 계산 영역의 입구 조건이 틀린 것이다. 고정 질량유량 경계를 둔 시뮬레이션이 발산한다면 솔버보다 이 부등식을 먼저 의심하자.
