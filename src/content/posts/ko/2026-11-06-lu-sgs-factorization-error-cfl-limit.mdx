## CFL을 10⁸으로 올렸더니 1,012번이 걸렸다

음해법(implicit scheme)이니 CFL은 클수록 좋다고 배운다. 선형 문제라면 $\Delta\tau\to\infty$에서 뉴턴법 한 번과 같다. 한 번에 정상해에 닿아야 한다. 32×32 확산 문제에 CFL을 $10^8$으로 넣었다. 행렬을 정확히 푼 음해법은 2회에 끝났다. LU-SGS는 1,012회가 걸렸다.

같은 문제에서 흐름을 45°로 바꾸면 LU-SGS는 7회에 끝난다. 135°로 돌리면 26회다. CFL은 똑같이 $10^8$이다. 이 글은 이 세 숫자가 어디서 오는지 따라간다. 답은 LU-SGS가 분해하면서 버린 한 항, $LD^{-1}U$다. 읽고 나면 CFL을 키워도 왜 반복수가 바닥에 붙는지 설명할 수 있다.

## LU-SGS가 실제로 푸는 행렬

정상 문제 $A\phi=b$를 가상 시간(pseudo time, 수렴만을 위한 가짜 시간)으로 전진시킨다. 한 반복은 다음 선형계를 푼다.

$$
\left(\frac{I}{\Delta\tau}+A\right)\Delta\phi=-R,\qquad R=A\phi-b
$$

$\Delta\tau$는 가상 시간 간격, $R$은 잔차(residual, 방정식을 만족하지 못한 양)다. 이 행렬을 매번 정확히 푸는 것은 비싸다. LU-SGS는 $A$를 대각 $D_A$, 아래 삼각 $L$, 위 삼각 $U$로 쪼개고, 왼쪽 행렬을 다음 곱으로 바꾼다.

$$
M=(D+L)\,D^{-1}\,(D+U)=D+L+U+LD^{-1}U,\qquad D=\frac{I}{\Delta\tau}+D_A
$$

$D+L+U$는 원래 행렬과 정확히 같다. 남는 것은 $LD^{-1}U$ 하나다. 이 항이 근사 분해의 오차다. 원본 노트의 부록 A에는 이 자리에 "Neglect" 한 단어만 적혀 있다. 대신 얻는 것은 두 번의 스윕이다. 하향 스윕(lower sweep)은 $(D+L)y=-R$을 셀 번호 순으로, 상향 스윕(upper sweep)은 $(D+U)\Delta\phi=Dy$를 역순으로 푼다.

이 항이 언제 0이 되는지는 그림으로 보는 것이 빠르다. 아래 시뮬레이션에서 직접 조작해보자. 왼쪽은 CFL = ∞에서 점 하나에 넣은 단위 원천에 $M^{-1}$을 한 번 적용한 결과다. 오른쪽은 정확한 응답 $A^{-1}e$다.

45° 버튼을 누르면 하향 스윕만으로 플룸이 오른쪽 위로 다 그려지고 오차가 거의 0이다. 135°로 바꾸면 하향 스윕은 위로만, 상향 스윕은 왼쪽으로만 정보를 옮긴다. 두 스윕을 거쳐도 계단 모양이 남는다. $\nu$를 키우면 어느 각도에서든 오차가 커진다.

## 버린 항은 언제 0인가

1차 풍상(upwind) 대류에서 셀은 상류 이웃에만 연결된다. 셀 번호가 $k=i+Nj$이면 서쪽·남쪽 이웃은 $L$에, 동쪽·북쪽 이웃은 $U$에 들어간다. 흐름이 45°면 상류는 서쪽과 남쪽이다. 대류 성분은 모두 $L$에 있고 $U$에는 작은 확산 계수만 남는다. 그래서 $LD^{-1}U\approx 0$이다. 225°면 반대로 $L$이 비고 역시 0에 가깝다.

135°는 다르다. 상류가 동쪽과 남쪽이다. 하나는 $U$에, 하나는 $L$에 있다. 곱 $LD^{-1}U$가 두 대류 계수의 곱만큼 살아난다. 순수 확산은 네 이웃이 모두 연결되므로 방향과 상관없이 이 항이 남는다.

이제 $\Delta\tau\to\infty$를 넣어 보자. $D\to D_A$가 되고 $M$은 대칭 Gauss–Seidel(SGS) 전처리 행렬과 같아진다. 반복 오차는 매번 $I-M^{-1}A$가 곱해진다. 이 행렬은 더 이상 $\Delta\tau$에 의존하지 않는다. CFL을 아무리 키워도 수렴률은 SGS의 스펙트럼 반경에서 멈춘다. 반대로 $\Delta\tau$가 작으면 $D$가 커서 $LD^{-1}U$가 상대적으로 작다. 그때는 LU-SGS와 정확한 음해법이 거의 같은 반복수를 낸다.

## 코드: 32×32 대류-확산, CFL 다섯 단계

정사각 영역에 $b=1$을 깔고 벽에서 $\phi=0$으로 잡았다. 세 경우를 비교한다. 대류 45°와 135°(속도 1, $\nu=10^{-4}$, 셀 Péclet 수 약 312), 그리고 순수 확산($\nu=1$)이다. CFL은 1부터 $10^8$까지 다섯 단계다. 상대 잔차 $10^{-8}$까지의 반복수를 LU-SGS와 정확한 음해법(매 반복 LU 직접 풀이)으로 잰다.

```python
import numpy as np
import scipy.sparse as sp
from scipy.sparse.linalg import spsolve_triangular, splu

N = 32
h = 1.0 / N

def build_operator(theta_deg, a, nu):
    # 1차 풍상 대류 + 중심 확산, 벽 φ=0, 셀 번호 k = i + N*j
    ax, ay = a*np.cos(np.radians(theta_deg)), a*np.sin(np.radians(theta_deg))
    rows, cols, vals = [], [], []
    for j in range(N):
        for i in range(N):
            k = i + N*j
            diag = (abs(ax) + abs(ay))/h + 4*nu/h**2
            rows.append(k); cols.append(k); vals.append(diag)
            for di, dj in ((-1,0),(1,0),(0,-1),(0,1)):
                ii, jj = i+di, j+dj
                if not (0 <= ii < N and 0 <= jj < N):
                    continue
                c = -nu/h**2
                if di == -1 and ax > 0: c -= ax/h
                if di ==  1 and ax < 0: c += ax/h
                if dj == -1 and ay > 0: c -= ay/h
                if dj ==  1 and ay < 0: c += ay/h
                rows.append(k); cols.append(ii + N*jj); vals.append(c)
    A = sp.csr_matrix((vals, (rows, cols)), shape=(N*N, N*N))
    spec = (abs(ax) + abs(ay))/h + 4*nu/h**2
    return A, spec

def pseudo_march(A, spec, cfl, method, tol=1e-8, itmax=5000):
    b = np.ones(N*N)
    phi = np.zeros(N*N)
    dtau = cfl / spec
    D = sp.diags(A.diagonal() + 1.0/dtau)
    L = sp.tril(A, k=-1); U = sp.triu(A, k=1)
    if method == "exact":  # 매 반복 (I/Δτ + A)를 정확히 푼다
        lu = splu((A + sp.identity(N*N)/dtau).tocsc())
    else:
        DL = (D + L).tocsr(); DU = (D + U).tocsr(); d = D.diagonal()
    r0 = np.linalg.norm(A @ phi - b)
    hist = [1.0]
    for it in range(1, itmax+1):
        R = A @ phi - b
        if method == "exact":
            dphi = lu.solve(-R)
        else:
            y = spsolve_triangular(DL, -R, lower=True)          # 하향 스윕 (D+L) y = -R
            dphi = spsolve_triangular(DU, d*y, lower=False)     # 상향 스윕 (D+U) Δφ = D y
        phi += dphi
        hist.append(np.linalg.norm(A @ phi - b) / r0)
        if hist[-1] < tol:
            break
    rate = (hist[-1]/hist[max(0, len(hist)-11)])**(1/min(10, len(hist)-1))
    return it, rate

cases = [("advection 45deg", 45, 1.0, 1e-4),
         ("advection 135deg", 135, 1.0, 1e-4),
         ("diffusion only", 45, 0.0, 1.0)]
cfls = [1, 10, 100, 1e4, 1e8]
print(f"N={N}, tol=1e-8, iterations (LU-SGS / exact implicit)")
print("case               " + "".join(f"{'CFL='+format(c,'g'):>14}" for c in cfls))
for name, th, a, nu in cases:
    A, spec = build_operator(th, a, nu)
    line = f"{name:<19}"
    for c in cfls:
        n1, _ = pseudo_march(A, spec, c, "lusgs")
        n2, _ = pseudo_march(A, spec, c, "exact")
        line += f"{f'{n1}/{n2}':>14}"
    print(line)

# CFL=1e8에서 점근 수렴률과 버린 항의 크기
print("\nasymptotic residual factor per iteration at CFL=1e8")
for name, th, a, nu in cases:
    A, spec = build_operator(th, a, nu)
    n, rate = pseudo_march(A, spec, 1e8, "lusgs")
    Lm = sp.tril(A, k=-1); Um = sp.triu(A, k=1)
    Dinv = sp.diags(1.0/A.diagonal())
    drop = sp.linalg.norm(Lm @ Dinv @ Um) / sp.linalg.norm(A)
    print(f"{name:<19} rate={rate:.4f}  ||L D^-1 U||/||A||={drop:.4f}")
```

위 코드를 브라우저에서 직접 돌려보자. 기본값은 135°, CFL = $10^8$이다. 주황 곡선이 26회, 파란 곡선이 2회에서 초록 점선에 닿는다.

## 7, 26, 1,012가 가르는 것

CFL = 1에서는 세 경우 모두 두 방법의 반복수가 같거나 비슷하다. $\Delta\tau$가 작아 $D$가 지배하기 때문이다. 이때 반복수를 정하는 것은 가상 시간 자체의 느림이다. 분해 오차는 아직 문제가 아니다.

CFL이 100을 넘으면 길이 갈린다. 정확한 음해법은 9, 3, 2회로 계속 줄어든다. 마지막 2회는 $10^{-8}$ 크기의 $I/\Delta\tau$가 남긴 잔차를 한 번 더 지우는 몫이다. LU-SGS는 45°에서 7회, 135°에서 26회, 확산에서 1,012회로 고정된다. CFL을 $10^4$에서 $10^8$로 만 배 키워도 한 회도 줄지 않았다.

135°의 수렴 이력을 보면 성격이 보인다. 처음 15회 동안 잔차는 반복당 약 8%씩만 줄었다. 그 뒤 급격히 떨어졌다. 한 번의 스윕 쌍이 정보를 흐름 방향으로 몇 칸밖에 옮기지 못하기 때문으로 보인다. 정보가 영역을 다 건너간 뒤에야 빠른 수렴이 시작된다.

확산은 더 단순하다. CFL = $10^8$에서 반복당 잔차 감소율은 0.9821이었다. 모델 Poisson 문제에서 Gauss–Seidel의 스펙트럼 반경은 $\cos^2(\pi/(N+1))$다. SGS는 GS를 정방향·역방향으로 한 번씩 한다. 대략 제곱하면 $\cos^4(\pi/33)\approx 0.9820$으로 측정값과 맞는다. $\ln 10^{-8}/\ln 0.9821\approx 1{,}020$으로 실제 1,012회와 거의 같다. 이 값은 $h^2$에 비례해 나빠진다. 격자를 두 배로 늘리면 반복수는 약 네 배가 된다.

## 버린 항의 노름은 수렴을 예측하지 못한다

출력 마지막 표는 $\|LD^{-1}U\|/\|A\|$도 함께 보여준다. 45°는 0.0022로 거의 0이다. 135°는 0.197로 수렴률 0.190과 비슷하다. 그런데 확산은 0.134로 135°보다 작다. 수렴률은 0.982로 훨씬 나쁘다.

노름은 모든 모드를 한꺼번에 잰다. 확산 문제에서 SGS는 고주파 오차를 잘 지운다. 남는 것은 영역 전체에 걸친 저주파 모드다. 이 모드에서 $M^{-1}A$의 고유값이 0에 가깝다. 버린 항의 크기가 아니라 어느 모드에 작용하느냐가 수렴을 정한다. 이것이 확산 지배 문제에서 LU-SGS 단독으로는 부족하고 다중격자(multigrid)나 Krylov 가속이 붙는 이유다.

## 원본 노트의 두 문장 다시 읽기

2018년 코드 구조 노트에는 LU-SGS 옆에 이런 메모가 있다. "Implicit scheme is the same as the concept of residual smooth scheme." 위 결과가 그 뜻을 보여준다. CFL = ∞의 LU-SGS는 정상해를 찾는 반복법이라기보다 잔차를 평활화하는 연산자다. 실제 시간 정확도나 큰 시간 간격의 이득은 $M$이 $I/\Delta\tau+A$에 가까울 때만 나온다.

같은 노트의 최종형은 이중 시간(dual time) 전진이다. 그때 $D$에는 실제 시간 항 $3/(2\Delta t)$가 더해진다. 이 항은 대각에만 들어간다. 그래서 가상 시간 CFL이 무한대여도 $D$가 커져 $LD^{-1}U$가 상대적으로 줄어든다. 비정상 계산의 내부 반복이 정상 계산보다 LU-SGS와 궁합이 좋은 이유다. 예조건까지 얹은 이중 시간 루프의 반복수 문제는 [이중 시간 예조건 실험](/ko/posts/2026-10-30-dual-time-steady-preconditioner-inner-iterations/)에서 다뤘다. LU-SGS 자체의 유도와 점성 반경 처리는 [LU-SGS 입문 글](/ko/posts/2026-06-22-lu-sgs-implicit-time-integration/)에 있다.

## 가상 시간 CFL을 키우기 전에 볼 것

반복수가 CFL 증가에 반응하지 않으면 분해 오차가 바닥을 정했다는 신호다. 그때 CFL을 더 올려도 소용없다. 볼 것은 두 가지다. 하나는 흐름 방향과 셀 번호의 관계다. 셀 순서만 바꿔도 반복수가 크게 달라지는 사례는 [RCM 재정렬 글](/ko/posts/2026-10-16-lu-sgs-cell-ordering-reverse-cuthill-mckee/)에 있다. 다른 하나는 확산의 비중이다. 셀 Péclet 수가 1 근처 이하인 영역이 넓다면 SGS의 $h^2$ 한계를 다른 가속법으로 넘어야 한다.

간단한 진단이 있다. CFL을 $10^2$, $10^4$, $10^6$으로 세 번 돌려 반복수를 적는다. 셋이 같다면 그 숫자가 당신 격자와 셀 순서에서 LU-SGS가 낼 수 있는 최선이다.
