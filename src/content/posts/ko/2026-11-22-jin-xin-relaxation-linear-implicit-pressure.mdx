## a를 키우면 안전해질 줄 알았다

완화 기법(relaxation scheme, 비선형 항을 보조 변수로 바꿔 선형계로 푸는 방법)에는 오래된 상식이 있다. 완화 속도 $a$는 물리 음속보다 크기만 하면 된다. 크면 수치 확산이 늘 뿐 계산은 안전하다. 이 상식을 음해(implicit) 압력 솔버에 그대로 가져갔다. $a$를 음속의 10배로 두었다. 결과는 확산이 아니었다. 밀도 펄스가 녹지 않고 0.106의 진폭으로 남았다. Newton 해는 같은 시점에 $1.5\times10^{-5}$였다.

이 글은 Thomann–Iollo–Puppo(2023)의 "Implicit relaxed all Mach number schemes"를 1D로 줄여 재현한다. 읽고 나면 세 가지를 얻는다. 완화가 왜 Newton 반복을 없애는지 알게 된다. 음해 스킴에서 $a$가 왜 하한뿐 아니라 사실상 상한도 갖는지 알게 된다. 그리고 그 두 한계를 한 줄 식으로 계산하는 법을 얻는다.

## 논문이 바꾼 한 줄

저마하 압축성 유동에서 음향파는 유속보다 수십 배 빠르다. 양해법은 시간 간격을 음속에 맞춰야 한다. 그래서 압력 항만 음해로 푸는 IMEX(양해·음해 혼합 적분) 분리가 표준이 됐다. [Peluchon(2017) 음향-수송 분리](/ko/posts/2026-05-30-peluchon-acoustic-transport-imex/)와 [어제 본 Battisti–Boscheri 선형 음해 압력식](/ko/posts/2026-11-21-linearly-implicit-enthalpy-density-ratio/)이 모두 이 계열이다.

문제는 상태방정식이다. 압력 $p(\rho)$가 밀도의 비선형 함수면 음해 압력식도 비선형이 된다. 매 스텝 Newton 반복이 필요하다. Thomann, Iollo, Puppo는 여기서 플럭스를 바꾸지 않고 **변수를 하나 늘렸다**. 압력 자리에 보조 변수 $w$를 넣고, $w$가 선형 파동 방정식을 따르게 한다.

$$
\partial_t \rho + \partial_x m = 0,\qquad
\partial_t m + \partial_x w = 0,\qquad
\partial_t w + a^2\,\partial_x m = \frac{p(\rho) - w}{\varepsilon}
$$

$m=\rho u$는 운동량, $w$는 완화된 압력, $a$는 상수 완화 속도, $\varepsilon$은 완화 시간이다. $\varepsilon\to0$이면 $w=p(\rho)$로 원래 계가 돌아온다. 이 구조 자체는 [Jin–Xin·Suliciu 완화 기법](/ko/posts/2026-07-04-jin-xin-suliciu-relaxation-scheme/)에서 다룬 것과 같다. 새로운 점은 이것을 **음해 압력 단계**에 넣었다는 데 있다. 왼쪽 세 식은 상수계수 선형계다. 그래서 음해로 풀어도 선형계 하나로 끝난다.

## Newton이 필요한 이유, 필요 없어지는 이유

재료 속도로 운동량을 먼저 양해 이류해 $m^*$를 만든다. 그다음 압력 부분을 후방 오일러로 닫는다. 원래 압력을 그대로 쓰면 이렇게 된다.

$$
\rho^{n+1} - \Delta t^2\,\delta_{xx}\,p(\rho^{n+1}) = \rho^n - \Delta t\,\delta_x m^*
$$

$\delta_x$, $\delta_{xx}$는 면 기준 1차·2차 차분이다. 미지수 $\rho^{n+1}$이 $p(\cdot)$ 안에 들어 있다. 그래서 Newton이다. 완화계를 쓰면 $w^n = p(\rho^n)$으로 투영한 뒤 $w$에 대해 푼다.

$$
w^{n+1} - a^2\Delta t^2\,\delta_{xx}\,w^{n+1} = p(\rho^n) - a^2\Delta t\,\delta_x m^*
$$

좌변 행렬은 $a$와 $\Delta t$만으로 정해진다. 상태에 의존하지 않는다. 한 번 분해해 두면 시간 간격이 같을 동안 계속 재사용할 수 있다. 밀도는 그 뒤에 $\rho^{n+1}=\rho^n-\Delta t\,\delta_x m_f^{n+1}$로 명시적으로 갱신된다.

그럼 $a$는 무엇을 대가로 치르나. 운동량을 끄고 밀도 모드 하나만 보면 한 스텝 증폭률이 닫힌 식으로 나온다.

$$
G_{N}(\theta) = \frac{1}{1+\nu^2 s^2},\qquad
G_{R}(\theta) = 1 - \frac{c^2}{a^2}\,\frac{z}{1+z},\quad z = \frac{a^2}{c^2}\,\nu^2 s^2
$$

$\nu=c\Delta t/\Delta x$는 음향 쿠랑 수, $s=2\sin(\theta/2)$, $\theta$는 무차원 파수다. $G_N$은 선형화한 Newton, $G_R$은 완화 스킴이다. $a=c$를 넣으면 $G_R=1/(1+z)=G_N$이 된다. **완화 스킴은 $a=c$에서 Newton 한 번과 같다.**

## 두 한계를 식으로 읽기

$\nu$가 큰 음해 영역에서는 고파수일수록 $z\gg1$이다. 그러면 $G_R \to 1 - c^2/a^2$이다. 이 한 줄에 양쪽 한계가 다 들어 있다.

- **하한**: $|G_R|\le1$이려면 $c^2/a^2 \le 2$, 즉 $a \ge c/\sqrt{2}$. 양해 완화의 부분특성 조건 $a\ge c$보다 느슨하다. 후방 오일러가 감쇠를 일부 보태기 때문이다.
- **상한(사실상)**: $a\gg c$면 $G_R\to1$이다. 감쇠도 진동도 없이 모드가 그대로 남는다. $a=10c$면 스텝당 1%만 줄어든다.

왜 이런 일이 생기나. $a$가 크면 $w$ 방정식의 음해 확산 $a^2\Delta t^2\delta_{xx}$가 압력 섭동을 거의 평평하게 지운다. 운동량에 걸리는 압력 구배가 사라진다. 밀도는 원래 질량 플럭스만큼만 움직인다. 결국 압력이 밀도를 되돌리는 힘이 $c^2/a^2$배로 약해진다. 양해 스킴에서 큰 $a$는 "번짐"이었다. 음해 스킴에서는 "얼어붙음"이다.

## 코드: 같은 펄스를 세 번 — 양해, Newton, 완화

1D 등엔트로피 Euler($p=\rho^{1.4}$, 주기 경계)에서 배경 마하수 0.05로 흐르는 밀도 펄스(진폭 0.2)를 띄운다. 유체가 영역의 1/4을 지날 때까지 돌린다. 양해 Rusanov는 음속 기준 CFL 0.9, 두 음해 스킴은 재료 속도 기준 CFL 0.9다. 완화 스킴은 $a/c_{\max}$를 0.5에서 10까지 쓸어 Newton 해와의 L2 차이를 잰다.

```python
import numpy as np
np.seterr(all="ignore")

# 1D 등엔트로피 Euler: p = rho^gamma, 주기 경계, 저마하 음향 펄스
N, gam = 200, 1.4
dx = 1.0 / N
x = (np.arange(N) + 0.5) * dx
c0 = np.sqrt(gam)
A0 = 0.2                             # 밀도 펄스 진폭
u0 = 0.05 * c0                       # 배경 마하수 0.05
T = 0.25 / u0                        # 유체가 영역의 1/4을 지나는 시간

def pres(r):
    return r**gam

def cyclic_solve(lo, di, up, b):
    # 주기 삼중대각: Thomas + Sherman-Morrison
    n = len(b); g = -di[0]
    d = di.copy(); d[0] -= g; d[-1] -= lo[0] * up[-1] / g
    def thomas(rhs):
        cp = np.zeros(n); dp = np.zeros(n)
        cp[0] = up[0] / d[0]; dp[0] = rhs[0] / d[0]
        for i in range(1, n):
            m = d[i] - lo[i] * cp[i-1]
            cp[i] = up[i] / m; dp[i] = (rhs[i] - lo[i] * dp[i-1]) / m
        y = np.zeros(n); y[-1] = dp[-1]
        for i in range(n - 2, -1, -1):
            y[i] = dp[i] - cp[i] * y[i+1]
        return y
    uvec = np.zeros(n); uvec[0] = g; uvec[-1] = up[-1]
    y = thomas(b); q = thomas(uvec)
    vfac = (y[0] + lo[0] * y[-1] / g) / (1 + q[0] + lo[0] * q[-1] / g)
    return y - vfac * q

def advect_m(r, m, dt):
    # 재료 속도만 보는 양해 Rusanov: (rho u^2)_x
    u = m / r; f = m * u
    s = np.maximum(np.abs(u), np.abs(np.roll(u, -1)))
    F = 0.5 * (f + np.roll(f, -1)) - 0.5 * s * (np.roll(m, -1) - m)
    return m - dt / dx * (F - np.roll(F, 1))

def face_mom(ms, w, dt):
    mf = 0.5 * (ms + np.roll(ms, -1))
    return mf - dt / dx * (np.roll(w, -1) - w)

def relaxed_step(r, m, dt, a):
    # Jin-Xin 완화: w_t + a^2 m_x = 0 을 음해로 -> 선형, 상수계수, 한 번 풀기
    ms = advect_m(r, m, dt)
    k = (a * dt / dx)**2
    mf0 = 0.5 * (ms + np.roll(ms, -1))
    rhs = pres(r) - a**2 * dt / dx * (mf0 - np.roll(mf0, 1))
    w = cyclic_solve(np.full(N, -k), np.full(N, 1 + 2 * k), np.full(N, -k), rhs)
    mf = face_mom(ms, w, dt)
    rn = r - dt / dx * (mf - np.roll(mf, 1))
    mn = 0.5 * (mf + np.roll(mf, 1))   # 면 운동량을 셀로 평균
    return rn, mn, 1

def newton_step(r, m, dt, tol=1e-10):
    # 원래 비선형 압력 p(rho^{n+1})을 그대로 음해로 -> Newton 반복
    ms = advect_m(r, m, dt)
    mf0 = 0.5 * (ms + np.roll(ms, -1))
    b = r - dt / dx * (mf0 - np.roll(mf0, 1))
    k = (dt / dx)**2
    rn = r.copy(); it = 0
    while True:
        p = pres(rn)
        res = rn - k * (np.roll(p, -1) - 2 * p + np.roll(p, 1)) - b
        if np.max(np.abs(res)) < tol:
            break
        dp = gam * rn**(gam - 1)
        lo = -k * np.roll(dp, 1); up = -k * np.roll(dp, -1)
        rn = rn - cyclic_solve(lo, 1 + 2 * k * dp, up, res)
        it += 1
        if it > 50:
            return rn * np.nan, ms, it
    w = pres(rn)
    mf = face_mom(ms, w, dt)
    mn = 0.5 * (mf + np.roll(mf, 1))   # 면 운동량을 셀로 평균
    return rn, mn, it

def rusanov_acoustic_step(r, m, dt):
    u = m / r; p = pres(r); c = np.sqrt(gam * r**(gam - 1))
    U = np.array([r, m]); F = np.array([m, m * u + p])
    s = np.maximum(np.abs(u) + c, np.roll(np.abs(u) + c, -1))
    Fh = 0.5 * (F + np.roll(F, -1, axis=1)) - 0.5 * s * (np.roll(U, -1, axis=1) - U)
    U = U - dt / dx * (Fh - np.roll(Fh, 1, axis=1))
    return U[0], U[1], 0

def run(kind, cfl, a_ratio=1.0):
    r = 1 + A0 * np.exp(-((x - 0.5) / 0.05)**2)
    m = r * u0
    mass0 = r.sum() * dx
    cmax = np.sqrt(gam * r.max()**(gam - 1))
    if kind == 'explicit':
        dt = cfl * dx / (u0 + cmax)
    else:
        dt = cfl * dx / u0
    nst = int(np.ceil(T / dt)); dt = T / nst
    its = 0
    for _ in range(nst):
        if kind == 'explicit':
            r, m, i = rusanov_acoustic_step(r, m, dt)
        elif kind == 'newton':
            r, m, i = newton_step(r, m, dt)
        else:
            r, m, i = relaxed_step(r, m, dt, a_ratio * cmax)
        if not np.all(np.isfinite(r)):
            return dict(steps=nst, solves=its, amp=np.nan, mass=np.nan, r=r)
        its += i
    return dict(steps=nst, solves=its, amp=r.max() - r.mean(), mass=abs(r.sum() * dx - mass0), r=r)

print(f"M0 = 0.05, N = {N}, A0 = {A0}, T = {T:.3f} (flow moves L/4)")
ex = run('explicit', 0.9)
nw = run('newton', 0.9)
print(f"{'scheme':<16}{'steps':>7}{'lin.solves':>12}{'amp':>11}{'|dmass|':>11}")
print(f"{'explicit':<16}{ex['steps']:>7}{'-':>12}{ex['amp']:>11.2e}{ex['mass']:>11.1e}")
print(f"{'implicit Newton':<16}{nw['steps']:>7}{nw['solves']:>12}{nw['amp']:>11.2e}{nw['mass']:>11.1e}")
print()
print(f"{'a/c_max':<9}{'solves':>8}{'amp':>11}{'L2 vs Newton':>15}")
for ar in [0.5, 0.7, 0.8, 0.9, 1.0, 1.5, 3.0, 10.0]:
    rx = run('relaxed', 0.9, ar)
    d = np.sqrt(np.mean((rx['r'] - nw['r'])**2))
    print(f"{ar:<9}{rx['solves']:>8}{rx['amp']:>11.2e}{d:>15.2e}")
```

## 표 읽기: 102와 56, 0.5의 폭발, 10의 0.106

**스텝 수.** 양해는 1208스텝, 음해는 56스텝이다. 비율 21.6은 $(u_0+c)/u_0$와 거의 같다. 대신 음해 두 스킴은 음향 펄스를 $10^{-5}$ 수준까지 지운다. 양해는 $2.84\times10^{-2}$을 남긴다. 저마하 음해 기법이 음향을 버리고 시간 간격을 사는 거래다.

**선형 풀이 수.** Newton은 56스텝에 102회, 스텝당 1.8회다. 펄스가 감쇠하면 잔차가 금방 작아져 1회로 끝나는 스텝이 많다. 완화는 정확히 스텝당 1회다. 1D에서는 1.8배 차이뿐이다. 그러나 완화 행렬은 상수다. 3D 비정렬 격자에서 분해나 전처리기를 한 번 만들어 재사용할 수 있다는 점이 진짜 이득이다.

**$a/c_{\max}$ 0.9~1.0.** Newton과의 L2 차이가 $3\sim5\times10^{-6}$이다. 선형 분석대로 $a\approx c$면 두 스킴은 거의 같다. 남는 차이는 $c$가 위치마다 달라서 생긴다.

**0.5와 0.7.** $c^2/a^2=4$이므로 $G_R\to-3$이다. 5스텝 만에 터졌다. 0.7은 $c_{\max}$ 기준으로는 경계선 $1/\sqrt2\approx0.707$ 아래다. 하지만 펄스 밖의 음속은 $c_{\max}$의 0.93배라 실효 $a/c$가 0.75가 된다. 그래서 살아남았다. 대신 L2 차이가 $2.6\times10^{-4}$로 커졌다.

**3과 10.** $a=3c_{\max}$에서 L2가 $9.2\times10^{-5}$로 Newton에서 멀어진다. $a=10c_{\max}$면 진폭이 0.106이다. $G_R\approx0.99$를 56번 곱하면 $0.2\times0.99^{56}\approx0.11$이다. 표의 숫자를 한 줄 식이 거의 그대로 맞힌다.

## 논문과 이 1D 장난감 사이의 거리

이 재현은 논문의 구조만 빌렸다. 차이는 분명히 적어 둔다.

- 논문은 전체 Euler와 강성 기체(stiffened gas)·탄성 재료까지 다룬다. 여기서는 에너지 방정식이 없는 등엔트로피 계다.
- 논문은 다차원에서 압력에 대한 선형 타원형 방정식을 분리해 푼다. 여기서는 주기 삼중대각 하나다.
- 면 운동량을 셀로 평균하는 단계는 이 글의 단순화다. 넓은 중심 구배로 셀 운동량을 갱신하면 홀짝 모드가 자라 150스텝 전에 터졌다.
- 논문은 $a$를 국소 최대 음속 근처로 잡는다. 이 글의 상한 이야기는 그 선택이 왜 합리적인지에 대한 보충 설명이다.

## 완화 속도 a를 정하는 자리

음해 완화 솔버에 $a$를 넣을 때는 $G_R\to1-c^2/a^2$ 한 줄을 먼저 계산한다. 하한은 $c_{\max}/\sqrt2$, 실무 하한은 여유를 둔 $c_{\max}$다. 상한은 정해진 값이 없다. 하지만 $c^2/a^2$가 스텝당 감쇠율이라는 사실은 남는다. $a$를 $c_{\max}$의 1~1.5배에 두면 선형계 하나로 Newton과 같은 답을 얻는다. 그 이상 키우는 것은 안전 여유가 아니다. 압력이 일을 하지 않게 만드는 것이다.
