## 패널 하나로 풀었는데 양력이 정확했다

받음각 5°의 평판 날개를 와류(vortex) 하나로 근사했다. 패널은 딱 1개다. 그런데 양력계수가 이론값 $2\pi\alpha$와 소수 넷째 자리까지 같았다. 제어점을 반 칸 앞으로 옮겼다. 이번에는 패널을 64개로 늘려도 양력이 정확히 절반이었다.

격자를 늘리면 오차가 준다는 직관이 여기서는 통하지 않는다. 이 글은 항공역학 교재의 "와류는 1/4, 제어점은 3/4" 규칙이 어디서 오는지 유도한다. 그리고 위치를 바꾸면 무엇이 깨지는지 코드로 잰다. 다 읽고 나면 와류 격자법(VLM)이나 패널 코드의 배치 규칙을 숫자 하나로 점검할 수 있다.

## 얇은 날개 이론이 요구하는 것: 와류 시트 γ(x)

얇은 날개 이론(thin airfoil theory)은 날개를 시위선 위에 깔린 와류 시트(vortex sheet, 연속 분포 와류)로 바꾼다. 시트 세기를 $\gamma(x)$라 하자. 조건은 하나다. 날개 표면을 뚫고 지나가는 유동이 없어야 한다.

$$
\frac{1}{2\pi}\int_0^c \frac{\gamma(x')\,dx'}{x-x'} = V_\infty\left(\alpha - \frac{dz}{dx}\right), \qquad 0<x<c
$$

$V_\infty$는 자유류 속도, $\alpha$는 받음각, $z(x)$는 캠버선, $c$는 시위다. 좌변은 시트가 유도하는 내리흐름(downwash, 아래로 향하는 수직 속도)이다. 여기에 뒷전에서 $\gamma(c)=0$인 Kutta 조건이 붙는다.

평판($z=0$)의 해는 잘 알려져 있다.

$$
\gamma(x) = 2V_\infty\alpha\sqrt{\frac{c-x}{x}}, \qquad \Gamma = \int_0^c\gamma\,dx = \pi c V_\infty\alpha
$$

$\Gamma$는 전체 순환이다. Kutta–Joukowski 정리 $L'=\rho V_\infty\Gamma$에 넣으면 $C_L = 2\pi\alpha$가 나온다. 순환과 양력의 관계는 [순환과 양력, Kutta–Joukowski](/ko/posts/2026-05-07-circulation-lift-kutta-joukowski/)에서 다뤘다. 또 하나 중요한 사실이 있다. 이 분포의 도심(centroid)은 정확히 $c/4$에 있다. 그래서 평판의 1/4 시위점 모멘트가 0이다.

## 와류 하나, 제어점 하나 — 반 시위 규칙은 어디서 오나

연속 시트를 점 와류 하나로 바꾼다. 와류는 $x=a$, 제어점(collocation point, 비투과 조건을 거는 점)은 $x=b$에 둔다. 점 와류가 거리 $r$에 유도하는 속도는 $\Gamma/(2\pi r)$다. 제어점에서 내리흐름이 $V_\infty\alpha$와 같아야 한다.

$$
\frac{\Gamma}{2\pi(b-a)} = V_\infty\alpha \quad\Longrightarrow\quad \Gamma = 2\pi(b-a)V_\infty\alpha
$$

이 $\Gamma$가 정확한 값 $\pi cV_\infty\alpha$와 같으려면 $b-a=c/2$여야 한다. 양력은 간격 하나로 정해진다. 와류 위치 $a$ 자체는 양력에 들어가지 않는다.

$a$는 모멘트에서 등장한다. 앞전 모멘트는 $M_{LE}=-\rho V_\infty\Gamma a$다. 정확한 시트의 합력은 $c/4$에 걸린다. 그러니 $a=c/4$여야 모멘트까지 맞는다. 두 조건을 합치면 $a=c/4$, $b=3c/4$다. 이것이 교재의 lumped vortex 규칙이다. 시위를 가로지르는 압력차 분포 $\Delta C_p = 2\gamma/V_\infty$로 쓰면 같은 말이다. 합력의 크기와 작용점, 두 숫자를 점 와류 하나로 맞추는 배치다.

여기까지는 패널 1개 이야기다. 패널을 $N$개로 나누면 어떻게 될까. 각 패널 안에 같은 비율로 와류와 제어점을 둔다. 직관대로라면 $N$이 커질수록 배치의 영향은 사라져야 한다.

## 코드: 와류·제어점 위치를 바꿔가며 패널 1~64개

시위를 $N$개 등간격 패널로 나눈다. 패널 $j$의 와류는 $x_j + a\,\Delta x$, 제어점은 $x_j + b\,\Delta x$에 둔다. 모든 제어점에서 비투과 조건을 걸면 $N\times N$ 선형계가 된다. 첫 실험은 평판에서 $a=0.25$로 고정하고 $b$만 바꾼다. 둘째 실험은 포물선 캠버 $z=4hx(1-x)$에 세 가지 배치를 비교한다.

```python
import numpy as np

def lumped_vortex(N, a, b, alpha, h=0.0):
    """얇은 날개(c=1, V=1): 패널마다 와류는 a, 제어점은 b 위치(패널 길이 비율)"""
    xe = np.linspace(0.0, 1.0, N + 1)
    dx = xe[1:] - xe[:-1]
    xv = xe[:-1] + a * dx                  # 와류 위치
    xc = xe[:-1] + b * dx                  # 제어점 위치
    slope = 4 * h * (1 - 2 * xc)           # 포물선 캠버 z = 4h x(1-x)
    A = 1.0 / (2 * np.pi * (xc[:, None] - xv[None, :]))
    G = np.linalg.solve(A, alpha - slope)  # 제어점에서 수직속도 0
    CL = 2 * G.sum()                       # Kutta-Joukowski
    Cm_le = -2 * (G * xv).sum()
    return CL, Cm_le

Ns = (1, 2, 4, 16, 64)
alpha = np.radians(5.0)
CL0 = 2 * np.pi * alpha
print(f"[1] flat plate, alpha=5deg, CL / 2*pi*alpha   (a = 0.25)")
print(f"{'b':>6} " + "".join(f"{'N=' + str(n):>9}" for n in Ns))
for b in (0.50, 0.65, 0.75, 0.85, 1.00):
    print(f"{b:6.2f} " + "".join(f"{lumped_vortex(n, 0.25, b, alpha)[0] / CL0:9.4f}" for n in Ns))

al, h = np.radians(2.0), 0.04
CLx = 2 * np.pi * (al + 2 * h)
Cmx = -np.pi / 2 * (al + 4 * h)
print(f"\n[2] parabolic camber h=0.04c, alpha=2deg  exact CL={CLx:.4f}  Cm_le={Cmx:.4f}")
print(f"{'(a,b)':>11} " + "".join(f"{'N=' + str(n):>9}" for n in Ns) + "   <- CL error %")
for a, b in ((0.25, 0.75), (0.00, 0.50), (0.50, 1.00)):
    errs = [100 * (lumped_vortex(n, a, b, al, h)[0] / CLx - 1) for n in Ns]
    print(f"({a:.2f},{b:.2f}) " + "".join(f"{e:+9.2f}" for e in errs))
print(f"{'(a,b)':>11} " + "".join(f"{'N=' + str(n):>9}" for n in Ns) + "   <- Cm_le error %")
for a, b in ((0.25, 0.75), (0.00, 0.50), (0.50, 1.00)):
    errs = [100 * (lumped_vortex(n, a, b, al, h)[1] / Cmx - 1) for n in Ns]
    print(f"({a:.2f},{b:.2f}) " + "".join(f"{e:+9.2f}" for e in errs))
```

기본값(B = (0, 0.5), $h=0.04$, $\alpha=2°$)에서 주황 실선이 기울기 −1로 내려가고 $N=64$에서 −1.09%에 닿는다. `camber h/c`를 0으로 내리고 B를 (0.25, 0.50)으로 맞추면 주황 실선이 수평이 된다. 표 [1]의 0.5000이 그대로 재현된다.

## 2(b−a)가 패널 수와 무관한 이유

표 [1]의 숫자는 깔끔하다. 모든 행이 $2(b-a)$다. $b=0.5$면 0.5, $b=1.0$이면 1.5다. 패널을 64개로 늘려도 넷째 자리까지 그대로다.

이유는 등간격 격자의 자기상사성에 있다. 영향 계수는 $1/\big(2\pi\Delta x\,(i-j+b-a)\big)$ 꼴이다. 행렬 전체가 간격 비 $b-a$ 하나에만 의존한다. 패널 1개에서 생긴 $2(b-a)$ 배 오차가 패널을 나눠도 같은 구조로 반복된다. 격자를 아무리 촘촘히 해도 패널마다 똑같이 틀린 규칙을 쓰는 셈이다. 수렴하지 않는 일관성 오차(consistency error)다.

반대로 $b-a=1/2$이면 $N$과 상관없이 전체 순환이 정확하다. J. C. James가 1972년에 이 "놀라운 정확도"를 해석적으로 보였다. 이산 순환 $\Gamma_j$ 각각은 정확한 $\gamma$를 패널 위에서 적분한 값과 다르다. 그런데 합만은 정확히 맞는다.

## 캠버가 붙으면 a = 1/4만 살아남는다

평판에서는 $b-a=1/2$이기만 하면 됐다. 실제로 코드에서 $(0, 0.5)$나 $(0.5, 1.0)$도 평판 양력은 정확하다. 캠버가 붙으면 이야기가 달라진다. 포물선 캠버의 정확한 해는 $C_L = 2\pi(\alpha + 2h/c)$다.

$(0.25, 0.75)$는 패널 1개부터 오차가 0.00%다. $(0, 0.5)$는 −69.62%에서 시작해 $N$이 두 배가 될 때마다 오차가 반으로 준다. 1차 수렴이다. $(0.5, 1.0)$은 부호만 반대로 같은 크기다. 와류가 앞으로 쏠리면 양력이 작게, 뒤로 쏠리면 크게 나온다.

캠버의 기울기 $dz/dx$는 위치마다 다르다. 제어점이 앞뒤로 움직이면 다른 기울기를 샘플링한다. 와류 위치와 제어점 위치가 동시에 맞아야 이 샘플링 오차가 상쇄된다. 그 균형점이 $a=1/4$이다.

모멘트는 다르게 움직인다. $(0.25, 0.75)$의 $C_{m,LE}$ 오차는 −41.05 → −10.26 → −2.57로 4배씩 준다. 2차 수렴이다. 패널 1개로는 모멘트가 41% 틀린다. 평판이라면 합력이 $c/4$에 걸리지만 캠버는 1/4점에 순수 모멘트 $C_{m,c/4} = -\pi h/c$를 만든다. 점 와류 하나는 이 짝힘(couple)을 표현할 수 없다. 다른 두 배치는 모멘트도 1차로만 수렴한다.

## 와류 격자법·패널법 속의 1/4–3/4

이 규칙은 교재 연습문제에서 끝나지 않는다. 3차원 와류 격자법(VLM)은 말굽 와류(horseshoe vortex)의 결속 와류를 각 패널 1/4 시위에 둔다. 제어점은 3/4 시위에 둔다. 시위 방향 패널 하나만 써도 2차원 단면 양력이 맞는 이유가 바로 위의 결과다.

복소 포텐셜로 원기둥 주위 유동을 만든 방식([복소 포텐셜과 d'Alembert 역설](/ko/posts/2026-05-21-complex-potential-cylinder-dalembert/))과 비교하면 차이가 보인다. 그쪽은 등각사상으로 정확한 해를 얻는다. 패널법은 정확한 해를 포기하고 특이점을 이산 배치한다. 그 배치 규칙이 정확도를 결정한다.

비등간격 격자에서는 주의가 필요하다. 코사인 간격처럼 패널 길이가 바뀌면 자기상사성이 깨진다. 그러면 1/4–3/4가 더 이상 "패널 수와 무관하게 정확"하지 않다. 대신 격자를 늘리면 수렴하는 보통의 근사가 된다.

## 와류 위치를 옮기기 전에 확인할 비 하나

자기 VLM 코드나 패널 코드를 점검하는 방법은 단순하다. 평판 하나를 패널 1개로 풀어 $C_L/2\pi\alpha$를 출력한다. 1이 아니면 그 값을 2로 나눈 것이 실제로 쓰고 있는 와류–제어점 간격이다. 0.5000이 나왔다면 제어점이 와류에서 반 패널이 아니라 1/4 패널 떨어져 있다. 그 오차는 격자를 64배로 늘려도 사라지지 않는다.

이어서 포물선 캠버를 넣고 $N=1$에서 $C_L$이 $2\pi(\alpha+2h)$와 맞는지 본다. 맞으면 와류가 1/4에 있다. 이 두 줄짜리 시험이 배치 오류를 격자 수렴 연구보다 먼저 잡아낸다.
