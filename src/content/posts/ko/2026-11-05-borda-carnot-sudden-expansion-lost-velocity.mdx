## 단면이 두 배가 되는 이음부에서 압력은 얼마나 오를까

지름이 작은 관이 갑자기 큰 관으로 이어진다. 단면적은 두 배가 된다. 유속은 절반으로 준다. 베르누이 식을 쓰면 압력 상승은 $\tfrac12\rho V_1^2 \times 0.75$다. 실제로 재면 $0.5$ 근처가 나온다. 베르누이가 1.5배 크게 잡은 것이다.

이 차이를 처음 식으로 쓴 사람들은 18세기 프랑스의 공병 학자들이다. 이 글은 그 식, Borda–Carnot 식을 따라간다. 유도에는 에너지 대신 운동량을 쓴다. 손실이 어디서 오는지는 Carnot의 "잃어버린 속도" 정리로 설명한다. 마지막에는 두 흐름이 섞이는 덕트를 직접 풀어 숫자로 확인한다. 읽고 나면 급확대 손실계수 $K=(1-\sigma)^2$가 언제 맞고 언제 틀리는지 판단할 수 있다.

## 혁명기 공병 장교가 본 '잃어버린 속도'

Lazare Carnot는 1771년 Mézières 왕립공과대학에 들어갔다. 스승은 Gaspard Monge였다. 그 학교의 수학 교수 자리는 원래 Bossut의 것이었다. Bossut는 이후 달랑베르와 함께 유체저항을 측정했다. Borda는 그보다 앞서 뉴턴의 유체저항을 깊이 연구한 학자다.

Carnot는 1784년 기계에 관한 논문을 냈다. 여기서 비탄성 충돌의 "에너지 손실"이라는 개념을 들여왔다. 당시로서는 낯선 생각이었다. 두 물체가 부딪혀 붙으면 운동량은 남지만 운동에너지(vis viva, 당시 표현으로 '살아 있는 힘')는 줄어든다. Carnot는 그 줄어든 양을 정확히 셌다. 각 물체가 충돌로 **잃은 속도**의 운동에너지를 모두 더한 값이 손실이라는 것이다.

Carnot는 같은 생각을 관 속 흐름에 적용했다. 단면이 급히 넓어지거나 좁아지면 베르누이 정리가 성립하지 않는다. 손실 수두(head loss, 유동이 잃는 에너지를 높이로 환산한 값)가 생긴다. 이 관계식이 오늘날 Borda–Carnot 식이다. 이 사람은 이후 혁명정부 공안위원회에서 군대를 재조직했다. 그의 아들이 열역학의 Sadi Carnot다.

슬라이더 $\sigma=A_1/A_2$를 움직이며 가운데 그래프의 두 압력선을 비교해 보자. 보라색 점선(베르누이)과 초록 실선(Borda–Carnot)의 간격이 빨간 손실 띠다. $\sigma$가 작을수록 제트가 더 세게 '부딪혀' 손실이 커진다.

## 유도: 계단면 압력이 $p_1$이라는 가정 하나

검사체적(control volume, 질량·운동량 수지를 세는 가상의 상자)을 계단 바로 뒤에서 흐름이 다시 균일해지는 곳까지 잡는다. 벽 마찰은 무시한다. 질량 보존은 간단하다.

$$V_2 = \sigma V_1, \qquad \sigma = \frac{A_1}{A_2}$$

$V_1, V_2$는 좁은 관과 넓은 관의 평균 유속이고 $\sigma$는 단면비다.

핵심 가정은 하나다. 계단면(넓어지는 벽, 면적 $A_2-A_1$)에 걸리는 압력이 들어오는 제트의 압력 $p_1$과 같다는 것이다. 계단 모서리 뒤의 와류 영역은 거의 정지해 있고, 제트는 그 옆을 곧게 빠져나간다. 그래서 제트의 압력이 그대로 정지 유체에 전해진다. 이 가정 아래 축방향 운동량 수지는 다음과 같다.

$$p_1 A_1 + p_1 (A_2 - A_1) - p_2 A_2 = \rho V_2^2 A_2 - \rho V_1^2 A_1$$

좌변은 입구·계단면·출구에 걸린 압력의 합력, 우변은 나가는 운동량 플럭스에서 들어오는 플럭스를 뺀 값이다. 정리하면 다음을 얻는다.

$$p_2 - p_1 = \rho V_2 (V_1 - V_2) = \rho V_1^2\,\sigma(1-\sigma)$$

반면 베르누이는 $p_2-p_1=\tfrac12\rho V_1^2(1-\sigma^2)$를 준다. $\sigma=0.5$면 운동량 쪽은 $0.25\rho V_1^2$, 베르누이 쪽은 $0.375\rho V_1^2$이다. 서두의 1.5배가 이 비율이다. 두 값의 차이를 질량당 에너지로 바꾸면 손실이 된다.

$$h_L = \frac{(V_1 - V_2)^2}{2g} = (1-\sigma)^2 \frac{V_1^2}{2g}$$

$h_L$은 손실 수두, $g$는 중력가속도다. 손실계수 $K=(1-\sigma)^2$는 관을 큰 탱크로 방출하는 극한($\sigma\to0$)에서 1이 된다. 제트의 운동에너지가 모두 사라진다는 뜻이다.

## 손실은 잃어버린 속도의 운동에너지다

$h_L$의 분자 $(V_1-V_2)^2$를 다시 보자. 유체 입자는 $V_1$으로 들어와 $V_2$로 나간다. 입자가 잃은 속도는 $V_1-V_2$다. 손실은 정확히 그 잃은 속도로 움직이는 운동에너지다. Carnot의 충돌 정리와 같은 꼴이다.

질량 $m_1$이 속도 $V_1$로 정지한 $m_2$에 부딪혀 붙는 경우를 보자. 충돌 후 속도는 $V=m_1V_1/(m_1+m_2)$다. 손실은 다음과 같다.

$$\Delta E = \tfrac12 m_1 (V_1 - V)^2 + \tfrac12 m_2 (0 - V)^2$$

각 항은 그 물체가 잃은(또는 얻은) 속도의 운동에너지다. 급확대에서는 계단 뒤 정지 유체가 $m_2$ 역할을 한다. 다만 그 유체는 흐름에 실려 나가지 않는다. 그래서 질량유량에 기여하지 않고 둘째 항이 사라진다.

이 관점은 두 흐름이 섞이는 경우로 바로 넓어진다. 속도가 다른 여러 유선관(stream tube, 유선으로 둘러싸인 가는 관)이 한 덕트에서 섞이면 손실은 다음이다.

$$\Delta e = \frac{1}{Q}\sum_k \tfrac12 (u_k - V_2)^2\, \Delta\psi_k$$

$Q$는 총 유량, $\Delta\psi_k$는 유선관 $k$가 나르는 유량, $u_k$는 그 관의 입구 속도다. 섞이는 과정의 세부(난류인지, 층류 확산인지)는 이 식에 들어가지 않는다. 운동량과 질량만 맞으면 손실은 정해진다. 이전 글 [유선마다 다른 베르누이 상수](/ko/posts/2026-09-03-bernoulli-constant-across-streamlines/)에서 본 것처럼, 유선관마다 베르누이 상수가 다르다는 사실도 여기서 중요하다.

## 코드: 두 흐름이 섞이는 덕트를 유선관 80개로

진짜 계단 뒤의 와류는 2D 계산이 필요하다. 여기서는 더 간단하면서 같은 원리를 담은 문제를 푼다. 단면이 일정한 덕트에 가운데 제트(폭 $\sigma$, 속도 1)와 바깥 느린 흐름(속도 $\varepsilon$)이 들어온다. 벽은 미끄럼 벽이다. 두 흐름은 점성 $\nu$로 섞인다.

경계층 근사(유동 방향 확산을 무시하는 포물형 근사)를 von Mises 좌표(유선함수 $\psi$를 가로 좌표로 쓰는 변환)로 쓰면 다음과 같다.

$$\frac{\partial u}{\partial x} = \nu\,\frac{\partial^2}{\partial \psi^2}\!\left(\frac{u^2}{2}\right) - \frac{1}{\rho u}\frac{dp}{dx}$$

각 격자는 같은 유량을 나르는 유선관 하나다. 압력구배 $dp/dx$는 유선관 폭의 합 $\sum \Delta\psi/u$가 덕트 폭과 같도록 매 스텝 뉴턴법으로 정한다. 이렇게 쓰면 이산식에서도 운동량이 정확히 보존된다. $\varepsilon\to0$이 Borda–Carnot의 정지 유체 극한이다.

```python
import numpy as np

def stream_tubes(sigma, eps, n=40):
    # 유선관 n개(같은 유량 dpsi): 가운데는 제트(u=1), 바깥은 느린 흐름(u=eps)
    Q = sigma + eps * (1 - sigma)
    dpsi = Q / n
    n_jet = round(n * sigma / Q)
    k = np.arange(n)
    jet = np.abs(k - (n - 1) / 2) < n_jet / 2
    u = np.where(jet, 1.0, eps)
    return u, dpsi, jet

def mix_step(u, P, dpsi, nu, H, dx):
    q = u**2 / 2
    qg = np.concatenate(([q[0]], q, [q[-1]]))          # 미끄럼 벽: dq/dpsi = 0
    Dq = nu * (qg[2:] - 2 * q + qg[:-2]) / dpsi**2     # (1/u) * 점성항
    for _ in range(20):                                 # 단면적 보존으로 dp/dx 결정 (뉴턴)
        un = u + dx * (Dq - P / u)
        if un.min() <= 0:
            return None, P                              # 느린 유선관이 멈춤 -> 역류
        f = np.sum(dpsi / un) - H
        df = np.sum(dpsi * dx / (u * un**2))
        P -= f / df
        if abs(f) < 1e-13:
            break
    return u + dx * (Dq - P / u), P

def mixing_duct(sigma, eps, nu, n=40, tol=1e-3):
    u, dpsi, jet = stream_tubes(sigma, eps, n)
    u0 = u.copy()
    H = np.sum(dpsi / u)                    # 덕트 폭 (~1)
    Q = n * dpsi                            # 유선관마다 같은 유량
    V2 = Q / H
    M0 = np.sum(u * dpsi) / H               # 입구 운동량 플럭스 / H
    dp_mom = M0 - V2**2                     # 운동량 보존이 주는 압력 상승
    E0 = np.sum(u**2 / 2 * dpsi) / Q
    x, p, P, x99 = 0.0, 0.0, 0.0, None
    while np.abs(u - V2).max() > tol:
        dx = 0.4 * dpsi**2 / (nu * u.max())
        un, P = mix_step(u, P, dpsi, nu, H, dx)
        if un is None:
            return dict(stall=True, x=x, dp=p, dp_mom=dp_mom)
        u, x, p = un, x + dx, p + P * dx
        if x99 is None and p >= 0.99 * dp_mom:
            x99 = x
    loss = E0 - (p + np.sum(u**2 / 2 * dpsi) / Q)
    # Carnot 정리: 각 유선관이 잃은(얻은) 속도의 운동에너지 합
    carnot = np.sum(0.5 * (u0 - V2)**2 * dpsi) / Q
    return dict(stall=False, x99=x99, V2=V2, dp=p, dp_mom=dp_mom,
                dp_bern=0.5 * (1 - V2**2), loss=loss, carnot=carnot)

print("Borda-Carnot limit (eps=0, sigma=0.5): dp = %.4f, loss = %.4f, Bernoulli dp = %.4f"
      % (0.5 * 0.5, 0.5 * 0.5**2, 0.5 * (1 - 0.5**2)))
print(" eps    nu     V2    dp_num  dp_mom  dp_Bern  loss    Carnot   x99")
for eps, nu in [(0.8, 0.004), (0.6, 0.004), (0.4, 0.004), (0.2, 0.004),
                (0.1, 0.004), (0.05, 0.004), (0.2, 0.002), (0.2, 0.008)]:
    r = mixing_duct(0.5, eps, nu, n=80)
    if r["stall"]:
        print(f"{eps:4.2f} {nu:6.3f}  STALL at x={r['x']:.2f}  "
              f"dp={r['dp']:.4f} of {r['dp_mom']:.4f}")
        continue
    print(f"{eps:4.2f} {nu:6.3f} {r['V2']:6.3f} {r['dp']:7.4f} {r['dp_mom']:7.4f} "
          f"{r['dp_bern']:7.4f} {r['loss']:7.4f} {r['carnot']:7.4f} {r['x99']:6.1f}")
```

## 0.1599와 0.3270, 그리고 ν가 바꾸지 못한 것

출력 표에서 세 가지를 읽을 수 있다.

첫째, `dp_num`과 `dp_mom`은 모든 행에서 소수 넷째 자리까지 같다. 수치 해는 섞임 과정을 한 스텝씩 계산했다. 그런데 결과는 입구 운동량과 출구 운동량의 차이로 이미 정해져 있었다. 압력 상승은 운동량 수지의 결과다.

둘째, `loss`와 `Carnot`도 모든 행에서 같다. 덕트는 각 유선관의 속도가 $V_2$로 바뀌는 동안 에너지를 잃었다. 그 양은 잃은 속도의 운동에너지 합과 정확히 일치한다. Carnot가 충돌에서 셌던 그 양이다.

셋째, $\nu$를 0.002에서 0.008로 네 배 바꿨다. `x99`(최종 압력의 99%에 닿는 거리)는 16.2에서 4.1로 줄었다. `dp_num`과 `loss`는 0.1599, 0.0831 그대로다. 점성은 **어디서** 손실이 생기는지만 정한다. **얼마나** 생기는지는 정하지 않는다.

베르누이(제트 유선 기준)는 같은 행에서 0.3270을 준다. 실제의 2.0배다. $\varepsilon=0.8$에서는 0.0960 대 0.0100으로 9.6배까지 벌어진다. 두 흐름의 속도 차가 작을수록 압력 상승 자체가 작아지는데, 베르누이는 이를 따라가지 못한다. $\varepsilon$를 줄이면 `dp_num`은 0.2255($\varepsilon=0.05$)까지 다가간다. Borda–Carnot 극한값 0.25 쪽이다.

$\varepsilon=0.03$ 이하에서는 계산이 멈춘다. 역압력구배가 느린 유체를 세워 버린다. 포물형 행진은 역류를 표현할 수 없다. 실제 급확대에서는 바로 이 자리에 재순환 영역이 생긴다. Borda의 가정 "계단면 압력 = $p_1$"은 이 재순환 영역을 정지 유체로 대체한 것이다.

## 오늘의 Borda–Carnot: 배관망 K값부터 1D 코드까지

배관 설계 편람의 급확대 손실계수 $K=(1-A_1/A_2)^2$는 이 식 그대로다. 난류 실험값과도 대체로 잘 맞는다. 계단 뒤 재순환이 정지 유체 가정에 가깝기 때문이다. 이 값은 배관망 해석 코드, 1D 열유체 시스템 코드, 연료 계통 해석에서 지금도 기본값으로 쓰인다.

맞지 않는 경우도 분명하다. 첫째, 입구 속도 분포가 균일하지 않으면 운동량 플럭스가 $\rho V^2 A$가 아니다. 완전 발달 층류 관 유동이라면 운동량 보정계수 $\beta=4/3$, 에너지 보정계수 $\alpha=2$가 붙는다. [관 단면 속도 분포와 운동에너지 계수](/ko/posts/2026-09-17-kinetic-energy-coefficient-pipe-profile/)에서 다룬 $\alpha$가 그대로 식에 들어간다. 둘째, 저 레이놀즈수에서는 재순환 영역 자체가 길어지고 벽 마찰이 섞여 들어온다. 셋째, 완만한 확산관(diffuser)에서는 박리가 늦어져 $K$가 훨씬 작다.

CFD 쪽에서도 같은 질문이 나온다. 준1차원(quasi-1D) 관 유동 코드는 면적 변화 항 $p\,dA/dx$를 따로 이산화한다. 면적이 한 셀 안에서 급변할 때 그 $p$를 어느 값으로 잡느냐가 곧 Borda의 가정이다. 상류 압력을 쓰면 Borda–Carnot 손실이 나온다. 매끄러운 노즐처럼 처리하면 손실 없는 베르누이 해가 나온다. 이젝터(ejector, 빠른 제트로 느린 흐름을 끌어들이는 장치)와 제트 펌프의 혼합관 설계도 위 코드의 운동량 수지를 그대로 쓴다.

## 급확대 K를 표에서 꺼내기 전에 확인할 두 조건

$K=(1-\sigma)^2$를 쓰기 전에 두 가지를 본다. 입구 속도 분포가 거의 균일한가(난류 완전 발달이면 $\beta\approx1.02$로 충분하다). 계단 뒤에 정지 유체로 볼 만한 재순환 영역이 생길 만큼 레이놀즈수가 큰가. 둘 다 그렇다면 압력 상승은 $\rho V_2(V_1-V_2)$이고 손실은 잃어버린 속도의 운동에너지다. 섞이는 방식은 묻지 않아도 된다.
