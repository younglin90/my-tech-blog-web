## 1칸짜리 계면, 그리고 1.063

사각파 하나를 다섯 바퀴 돌렸다. MUSCL–van Leer는 계면 하나에 25칸을 썼다. 같은 코드에 샤프닝 플럭스 한 줄을 더하자 1칸이 됐다. 그런데 체적분율 최댓값이 1.06336이었다. 체적분율은 0과 1 사이여야 한다.

이 글은 Zhao 외(2025, *Physics of Fluids*)의 MMACM-Ex 논문(5방정식 모델용 극한 계면 샤프닝)을 읽고 핵심 플럭스를 1D로 재현한다. 얻을 것은 두 가지다. 첫째, 하류(downwind) 값을 섞어 계면을 세우는 원리. 둘째, 논문이 증명한 시간 간격 조건 $\Delta t < \Delta x/9\bar u$가 어디서 오고, 실제로 얼마나 빡빡한지다.

## 논문이 고친 자리

5방정식 모델(두 상의 부분 밀도·운동량·에너지·체적분율을 푸는 확산 계면 모델)은 압축성 다상 유동의 표준이다. 문제는 리만 솔버의 수치 확산이다. 시간이 지날수록 계면이 번진다. 번진 계면은 기포 붕괴나 충격파–기포 상호작용의 작은 구조를 지운다.

흔한 처방은 재구성을 바꾸는 것이다. THINC나 고차 리미터가 그렇다. [압축형 리미터 β 글](/ko/posts/2026-10-24-compressive-beta-limiter-volume-fraction/)이 그 계열이다. MMACM-Ex는 반대로 간다. 재구성은 저차로 두고, 플럭스를 하나 더 얹는다.

$$
\overline{\mathbf F} = \widehat{\mathbf F} + \widehat{\mathbf G}
$$

$\widehat{\mathbf F}$는 HLLC 리만 플럭스, $\widehat{\mathbf G}$는 계면 샤프닝 플럭스다. $\widehat{\mathbf G}$의 모든 성분은 인공 체적 플럭스 $J_k$ 하나에 상의 밀도·운동량·에너지를 곱해 만든다. 그래서 질량·운동량·에너지 보존이 깨지지 않는다(He–Tan 2024의 일관성 틀).

## 하류 값을 얼마나 섞을까 — 특성 함수 H(r)

체적분율 성분의 샤프닝 플럭스는 이렇다. 셀 면 $i+1/2$에서 $\bar u>0$이라 하자.

$$
J_{i+1/2} = \widetilde{\mathcal H}_{i+1/2}\left(\bar u\,\alpha_{i+1} - \widehat F_{\alpha,i+1/2}\right)
$$

$\alpha_{i+1}$은 하류 셀 값, $\widehat F_\alpha$는 풍상(upwind) 리만 플럭스, $\widetilde{\mathcal H}$는 풍상 셀에서 잰 특성 함수다. 두 플럭스를 더하면 면 값이 풍상 재구성값 $\alpha^L$과 하류 값 사이의 내분이 된다.

$$
\overline F_{\alpha,i+1/2} = \bar u\left[\alpha^L_{i+1/2} + \mathcal H_i\left(\alpha_{i+1} - \alpha^L_{i+1/2}\right)\right]
$$

$\mathcal H=0$이면 원래 플럭스, $\mathcal H=1$이면 순수 하류 기법이다. 하류 기법은 계면을 세우지만 혼자 쓰면 진동하며 발산한다. 그래서 $\mathcal H$는 기울기 비 $r_i=(\alpha_i-\alpha_{i-1})/(\alpha_{i+1}-\alpha_i)$의 리미터처럼 설계된다.

$$
\mathcal H(r) = 1 - \left(\frac{1-|r|}{1+|r|}\right)^4
$$

$r=1$(계면 한가운데의 고른 기울기)에서 1, $r\to0$이나 $r\to\infty$(계면 가장자리)에서 0으로 간다. 다차원에서는 MYC 법선의 $|n_x|$를 곱한다. 이 함수는 계면 셀(식 19, $\varepsilon<\alpha<1-\varepsilon$이고 단조)에서만 켠다.

아래 시뮬레이션에서 직접 조작해보자. 왼쪽은 이동하는 계면과 셀별 $\mathcal H$, 오른쪽은 $\mathcal H(r)$ 곡선이다.

지수 p를 바꾸며 $r=0$ 근처의 빨간 접선 기울기를 보자. 기울기는 항상 $2p$다. 계면 폭을 줄이면 빨간 탐침점이 곡선의 가파른 앞자락으로 미끄러진다.

## 지수 4가 시간 간격을 정한다

$r\to0$에서 $(1-r)/(1+r)\approx 1-2r$이다. 4제곱하면 $1-8r$이다. 따라서 $\mathcal H\approx 8r$이다. 논문 그림 1의 삽입 그래프가 이 기울기다.

논문은 Zalesak식 FCT(flux-corrected transport, 보정 플럭스를 극값 안으로 제한하는 기법) 논리로 안정 조건을 세운다. 과대값을 막는 상한은 다음과 같다.

$$
R_{in} \approx \left(\frac{\Delta x}{\bar u\,\Delta t} - 1\right) r_i
$$

$\mathcal H < R_{in}$이면 새 극값이 생기지 않는다. $\mathcal H<8r$을 넣으면 $\Delta x/(\bar u\Delta t)-1>8$, 즉 $\Delta t<\Delta x/9\bar u$다. 일반 지수 $p$라면 $\Delta t<\Delta x/((2p+1)\bar u)$다.

여기서 $\bar u$는 음속이 아니라 **재료 속도**다. 논문은 CFL 0.4를 쓰면서 "CFL < 0.6이면 쉽게 만족한다"고 말한다. 압축성 문제에서는 $\Delta t$가 $\max(|u|+c)$로 정해지기 때문이다. 물–공기 충격관에서 물의 음속은 2,000 m/s를 넘는다. 재료 속도 기준 Courant 수는 0.4보다 훨씬 작다.

## 코드: 같은 사각파, 세 가지 플럭스, Courant 수 일곱 단계

조건이 빡빡한지 보려면 $c=0$인 순수 이류가 좋다. 그러면 Courant 수가 곧 재료 Courant 수다. 격자 200칸, 폭 0.3의 사각파, 주기 경계, SSP-RK3로 다섯 바퀴를 돌린다.

```python
import numpy as np

def vanleer_face(a):
    # 왼쪽 상태 α^L_{i+1/2} (주기 경계, u>0)
    dm = a - np.roll(a, 1)
    dp = np.roll(a, -1) - a
    with np.errstate(divide='ignore', invalid='ignore'):
        r = np.where(np.abs(dp) > 1e-14, dm / dp, 0.0)
    phi = (r + np.abs(r)) / (1 + np.abs(r))
    return a + 0.5 * phi * dp

def sharpen_weight(a, p=4, eps=1e-4):
    # 특성 함수 H(r) = 1 - ((1-|r|)/(1+|r|))^p, 계면 셀(식 19)에서만
    dm = a - np.roll(a, 1)
    dp = np.roll(a, -1) - a
    with np.errstate(divide='ignore', invalid='ignore'):
        r = np.where(np.abs(dp) > 1e-14, dm / dp, 0.0)
    H = 1 - ((1 - np.abs(r)) / (1 + np.abs(r))) ** p
    iface = (a > eps) & (a < 1 - eps) & (dm * dp > 0)
    return np.where(iface, H, 0.0)

def rhs(a, scheme, u, dx, p):
    if scheme == "upwind1":
        F = u * a
    else:
        F = u * vanleer_face(a)          # 리만 플럭스 F^
        if scheme == "mmacm_ex":
            Ht = sharpen_weight(a, p)    # 풍상 셀 값 H~ (u>0 → i)
            J = Ht * (u * np.roll(a, -1) - F)   # 하류(downwind) 반확산 플럭스
            F = F + J
    return -(F - np.roll(F, 1)) / dx

def advect(scheme, N=200, cfl=0.4, periods=5, p=4):
    dx, u = 1.0 / N, 1.0
    x = (np.arange(N) + 0.5) * dx
    a = ((x > 0.35) & (x < 0.65)).astype(float)
    a0 = a.copy()
    dt = cfl * dx / u
    steps = int(round(periods / dt))
    for _ in range(steps):           # SSP-RK3
        a1 = a + dt * rhs(a, scheme, u, dx, p)
        a2 = 0.75 * a + 0.25 * (a1 + dt * rhs(a1, scheme, u, dx, p))
        a = a / 3 + 2 / 3 * (a2 + dt * rhs(a2, scheme, u, dx, p))
    width = np.sum((a > 0.01) & (a < 0.99)) / 2   # 계면 하나당 셀 수
    L1 = np.mean(np.abs(a - a0))
    return width, a.min(), a.max(), L1, steps

print("N=200, square wave, 5 periods")
print(f"{'scheme':>9} {'CFL':>5} {'cells':>6} {'min':>10} {'max':>9} {'L1':>8}")
for s in ["upwind1", "vanleer", "mmacm_ex"]:
    w, lo, hi, L1, n = advect(s)
    print(f"{s:>9} {0.4:5.2f} {w:6.1f} {lo:10.2e} {hi:9.5f} {L1:8.5f}")
print("\nMMACM-Ex CFL scan (p=4, bound 1/(2p+1) = 0.111)")
for c in [0.1, 0.11, 0.13, 0.2, 0.4, 0.6, 0.8]:
    w, lo, hi, L1, n = advect("mmacm_ex", cfl=c)
    print(f"{'mmacm_ex':>9} {c:5.2f} {w:6.1f} {lo:10.2e} {hi:9.5f} {L1:8.5f}")
print("\nexponent p scan (CFL 0.4)")
for p in [1, 2, 4, 8]:
    w, lo, hi, L1, n = advect("mmacm_ex", p=p)
    print(f"{'p='+str(p):>9} {0.4:5.2f} {w:6.1f} {lo:10.2e} {hi:9.5f} {L1:8.5f}")
```

## 숫자 읽기: 2칸과 1칸의 차이

첫 표가 논문의 주장을 그대로 보여준다. 1차 풍상은 다섯 바퀴 만에 사각파를 지웠다. 최댓값이 0.657이다. van Leer는 경계를 지키지만 계면당 25칸이다. MMACM-Ex는 L1 오차를 4분의 1로 줄였다.

다만 CFL 0.4의 "1칸"은 좋은 소식이 아니다. 경계 안의 0.10~0.13에서는 계면이 정확히 2칸이고 오차가 0.0012다. 0.4로 올리면 계면이 1칸으로 더 얇아진다. 동시에 −0.063과 1.063이 생기고 오차는 9배가 된다. 과대값이 계면을 계단처럼 깎아낸 결과다. 논문이 말한 "2칸 미만"은 경계 안에서 나오는 2칸이다.

조건 $1/9=0.111$은 충분조건이다. 0.13에서도 경계가 지켜졌다. 0.20에서 처음 0.26%가 넘쳤다. $\mathcal H<8r$이 최악의 경우라 실제 문턱은 조금 더 위에 있다.

지수 스캔은 단조롭지 않다. p=1은 21% 넘친다. p=2는 2.3%로 가장 작다. p=4와 p=8은 6% 근처다. CFL 0.4는 네 경우 모두 각자의 충분조건 밖이다. 그러니 이 표는 "어느 p가 안전한가"가 아니라 "경계 밖에서는 p가 결과를 예측 가능하게 바꾸지 않는다"로 읽어야 한다.

## 이 재현이 다루지 않은 것

논문 결과의 대부분은 2D·3D다. 공기–R22 충격파–기포, 수중 폭발, 3D 기포 붕괴가 있다. 거기서는 $|n_x|$ 가중과 HLLC 면 속도 $\bar u$가 함께 들어간다. 이 1D 실험은 체적분율 방정식 하나만 떼어냈다. 부분 밀도·에너지 성분의 일관성은 시험하지 않았다.

또 하나는 재구성 시 계면 셀의 $\rho_k$를 상수로 두는 처리다(Zhang et al.). 단일 스칼라 이류에는 나타나지 않는다. 일관성 플럭스의 의미는 [안티확산 IST 글](/ko/posts/2026-07-25-interface-sharpening-anti-diffusion/)과 비교하면 선명하다. IST는 별도 샤프닝 방정식을 매 스텝 풀고, MMACM-Ex는 플럭스 안에 녹인다. 하류 값이 Courant 수 천장을 내리는 현상은 [VOF 이류 CFL 상한 글](/ko/posts/2026-08-16-vof-interface-advection-cfl-limit/)의 NVD 분석과 같은 뿌리다.

## 저마하·저속 계면 문제에 이 플럭스를 넣는다면

음속이 $\Delta t$를 잡아주는 고속 압축성 문제라면 걱정할 일이 거의 없다. 하지만 암시적 음향 처리로 $\Delta t$를 재료 속도에 맞춰 키운 저마하 코드는 다르다. 그 순간 Courant 수가 0.4~0.8이 되고, 위 표의 아래쪽 줄이 현실이 된다. 이식 전에 $\max|\bar u|\,\Delta t/\Delta x < 1/(2p+1)$ 한 줄을 로그에 찍어두자. 넘는다면 샤프닝 플럭스에 Zalesak 제한을 직접 걸거나, 샤프닝 단계만 부분 스텝으로 나누는 편이 안전하다.
