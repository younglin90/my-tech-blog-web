## 격자를 4배 촘촘히 했더니 입자가 2.6배 늦게 식었다

알루미늄 입자 연소를 계산하던 연구실이 격자를 키웠다. 노드 1개, 셀 2,662개에서 노드 20개로 늘렸다. 해상도가 오르면 답이 좋아질 거라 믿었다. 그런데 입자 근처 기체 온도가 이상하게 튀었다. 이 글은 그 원인을 셀 하나짜리 열원에서 찾는다. 읽고 나면 입자 소스항(source term, 입자가 기체에 주는 질량·열·운동량)을 어떤 폭으로 퍼뜨려야 하는지 숫자로 판단할 수 있다.

결론부터 말한다. 같은 입자를 같은 물리 조건에 두고 격자만 16³에서 64³로 바꿨다. 입자 온도가 절반이 되는 시간이 0.0106에서 0.0274로 늘었다. 물리는 그대로인데 답이 격자를 따라간다. 격자 수렴(grid convergence, 격자를 줄일수록 답이 한 값으로 모이는 성질)이 깨진 것이다.

## 슬라이드 한 장: 셀 1개 대신 27개

원본 자료는 논문 리뷰 슬라이드다. Al 입자 연소 메커니즘을 다룬 Beckstead(2005)와 Feng(2018)을 인용한다. 핵심 메모는 짧다. "기존 계산 방식: 입자가 포함된 cell + 26 sten." 그리고 "차이를 주변 sten으로 분배." 대가도 적혀 있다. "계산시간 증가, 약 2주 정도."

입자 단계는 셋으로 나뉜다. 기상(gas phase) 단계, 그리고 두 번의 기화(vaporizing) 단계다. 기화 단계에서 입자는 질량과 열을 기체로 내보낸다. 그 양을 입자가 들어 있는 셀 하나에 몽땅 넣으면 문제가 생긴다. 그래서 주변 26개 셀까지, 3×3×3 블록에 나눠 넣었다.

이 처방이 정말 문제를 고치는지가 이 글의 질문이다. 아래 시뮬레이션에서 직접 조작해보자.

격자 수 N을 키우면서 빨간 커널(cell)의 점이 오른쪽 그래프에서 어떻게 올라가는지 보라. 노란 27셀은 기울기만 완만하다. 파란 가우시안만 N이 커져도 평평하다.

## 점 열원은 3차원에서 무한대다

정상 상태에서 점 열원 $Q$ 주변 온도는 거리 $r$에 반비례한다.

$$
T(r) = \frac{Q}{4\pi k\, r}
$$

$k$는 기체 열전도율, $r$은 입자 중심에서 거리다. $r \to 0$이면 온도가 발산한다. 1차원에서는 점 열원 온도가 유한하다. 2차원은 로그로 발산한다. 3차원만 $1/r$로 터진다.

셀 하나에 열을 넣으면 수치해는 이 발산을 셀 크기에서 잘라낸다. 그래서 입자가 "보는" 셀 온도는 다음처럼 된다.

$$
T_{\text{seen}} = \frac{g\,Q}{k\,\Delta x}, \qquad g \approx 0.253
$$

$\Delta x$는 셀 간격, $g$는 7점 라플라시안의 격자 그린 함수(lattice Green's function) 원점값이다. 격자를 반으로 줄이면 입자가 보는 온도가 두 배가 된다.

입자의 열 손실은 입자와 주변 온도 차로 정해진다.

$$
Q = H\,(T_p - T_{\text{seen}}) = \frac{H\,T_p}{1 + H g / (k\,\Delta x)}
$$

$H$는 입자-기체 열교환 계수, $T_p$는 입자 온도다. 분모의 두 항은 직렬 저항이다. $1/H$는 입자 표면 저항, $g/(k\Delta x)$는 입자가 데운 자기 셀의 저항이다. [원통의 임계 단열 반경](/ko/posts/2026-11-24-critical-insulation-radius-cylinder/)에서 본 것과 같은 저항 합산 구조다. 다른 점이 하나 있다. 두 번째 저항이 물리가 아니라 격자에서 나온다.

## 세 가지 분배 방식 비교

27셀 블록에 균등 분배하면 실효 폭이 $3\Delta x$가 된다. 자기 가열은 약 1/3로 줄어든다. 하지만 여전히 $\Delta x$에 비례한다. 격자를 3배 더 줄이면 같은 문제가 돌아온다.

해법은 폭을 물리 길이로 묶는 것이다. 가우시안 커널(Gaussian kernel, 종 모양 가중치)의 표준편차 $\sigma$를 고정한다.

$$
w_i = \frac{\exp\!\left(-|\mathbf{x}_i - \mathbf{x}_p|^2 / 2\sigma^2\right)}{\sum_j \exp\!\left(-|\mathbf{x}_j - \mathbf{x}_p|^2 / 2\sigma^2\right)}
$$

$w_i$는 셀 $i$가 받는 비율, $\mathbf{x}_p$는 입자 위치다. 입자가 보는 온도도 같은 가중치로 평균한다. 그러면 자기 가열 저항이 $\Delta x$ 대신 $\sigma$에 묶인다. 격자를 줄여도 $\sigma$는 그대로다.

## 코드: 주기 상자 속 입자 하나, 커널 세 가지 × 격자 다섯 단계

길이 1인 주기 상자 중앙에 온도 1인 입자를 둔다. 기체는 0에서 출발해 3D 확산한다. 입자와 기체는 열을 주고받는다. 입자 온도가 0.5가 되는 시간을 잰다. 결합항은 점-음해(point-implicit)로 풀어 세밀한 격자에서도 폭주하지 않게 했다.

```python
import numpy as np

# 주기 상자(L=1) 속 고온 입자 1개: 기체 3D 확산 + 입자-기체 열교환(양방향 결합)
ALPHA, H, CP, SIGMA = 1.0, 0.25, 0.002, 0.06

def kernel_weights(N, kind):
    dx = 1.0 / N
    c = N // 2
    W = np.zeros((N, N, N))
    if kind == "cell":
        W[c, c, c] = 1.0
    elif kind == "stencil27":
        W[c-1:c+2, c-1:c+2, c-1:c+2] = 1.0
    else:  # 물리 폭 SIGMA로 고정한 가우시안
        x = (np.arange(N) - c) * dx
        r2 = x[:, None, None]**2 + x[None, :, None]**2 + x[None, None, :]**2
        W = np.exp(-r2 / (2 * SIGMA**2))
    return W / W.sum()

def cool_particle(N, kind):
    dx = 1.0 / N
    dt = 0.9 * dx**2 / (6 * ALPHA)
    W = kernel_weights(N, kind)
    s = (W**2).sum() / dx**3          # 유효 역체적: 입자가 '보는' 기체의 크기
    Tg = np.zeros((N, N, N))
    Tp, t, seen_max = 1.0, 0.0, 0.0
    while Tp > 0.5:
        lap = sum(np.roll(Tg, k, a) for a in range(3) for k in (1, -1)) - 6 * Tg
        Tg += dt * ALPHA * lap / dx**2
        seen = (W * Tg).sum()
        Q = H * (Tp - seen) / (1 + H * dt * (1 / CP + s))   # 점-음해 결합
        Tg += dt * Q * W / dx**3
        Tp -= dt * Q / CP
        t += dt
        seen_max = max(seen_max, seen + dt * Q * s)
    return t, seen_max

print(f"isolated particle (Tg fixed 0): t_half = {CP/H*np.log(2):.5f}")
print(f"{'N':>4} {'dx':>7} | {'cell':>14} | {'stencil27':>14} | {'gauss':>14}")
for N in (16, 24, 32, 48, 64):
    row = [cool_particle(N, k) for k in ("cell", "stencil27", "gauss")]
    print(f"{N:>4} {1/N:7.4f} | " + " | ".join(f"{t:.5f} ({m:.3f})" for t, m in row))
```


## 표 읽기: 0.0274, 0.0096, 0.0059

기준은 기체를 0으로 붙잡아 둔 고립 입자다. 이때 반감 시간은 0.00555다.

셀 1개 방식은 N=16에서 이미 1.9배 느리다. N=64에서는 4.9배다. 괄호 안 숫자는 입자가 본 기체 온도 최댓값이다. 0.383에서 0.770까지 올랐다. 입자 온도 1의 77%를 자기가 데운 셀에서 본다. 열을 내보낼 온도 차가 사라진 것이다.

27셀 방식은 덜 나쁘지만 같은 방향이다. 0.00645에서 0.00956으로 48% 늘었다. 셀 1개 방식의 N=24 근처 오차가 27셀의 N=64에서 다시 나타난다. 블록 폭이 $3\Delta x$이니 예상대로다.

가우시안은 N=24부터 0.0059~0.0060에 머문다. 본 온도도 0.045로 고정이다. N=16에서 0.00645로 약간 다른 것은 $\sigma=0.06$이 $\Delta x=0.0625$보다 작아서다. 커널이 셀 하나를 덮지 못하면 다시 셀 방식으로 돌아간다.

## 비교 매트릭스: 무엇을 고정하고 무엇을 지불하나

| 방식 | 실효 폭 | 격자 수렴 | 비용 | 함정 |
|---|---|---|---|---|
| 셀 1개 | $\Delta x$ | 깨짐 ($\propto 1/\Delta x$) | 최소 | 세밀할수록 나빠짐 |
| 27셀 균등 | $3\Delta x$ | 깨짐 (3배 지연) | 27배 접근 | 경계·병렬 경계에서 고스트 셀 필요 |
| 가우시안 $\sigma$ 고정 | $\sigma$ | 유지 ($\Delta x < \sigma$) | $(\sigma/\Delta x)^3$ 셀 | $\sigma$가 새 모델 상수가 됨 |

27셀 방식의 "2주"는 이 표의 둘째 줄 비용이다. 셀마다 이웃 26개를 읽고 쓰려면 병렬 분할 경계에서 통신이 늘어난다. [DEM 섹터 크기](/ko/posts/2026-10-08-dem-sector-neighbor-search/) 글에서 본 이웃 탐색 비용과 같은 종류다.

가우시안도 공짜는 아니다. $\Delta x$가 작아지면 커널이 덮는 셀 수가 세제곱으로 늘어난다. 그리고 $\sigma$를 무엇으로 정할지가 새 질문이 된다. 흔한 선택은 입자 지름의 몇 배, 또는 입자 주위 경계층 두께다.

## Al 입자 계산에서 커널 폭을 정할 때 물어볼 질문

먼저 $\Delta x$와 입자 지름 $d_p$를 비교한다. $\Delta x \gg d_p$라면 셀 방식도 견딘다. 자기 가열 저항이 표면 저항보다 작기 때문이다. $H g/(k\Delta x)$를 한 번 계산해보면 된다. 이 값이 0.1을 넘으면 커널을 바꿀 때다.

다음으로 격자를 한 단계 줄여 같은 입자의 연소 시간을 비교한다. Beckstead 상관식은 연소 시간을 입자 지름의 약 1.8제곱에 묶는다. 격자만 바꿨는데 연소 시간이 움직였다면 그 차이는 물리가 아니다.

마지막으로 분배 폭과 보간 폭을 같게 맞춘다. 열을 넣는 커널과 온도를 읽는 커널이 다르면 에너지 보존과 자기 가열 상쇄가 동시에 깨진다. 위 코드는 `W` 하나로 둘 다 처리한다.
