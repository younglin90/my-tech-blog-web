## 압력은 1을 미는데 벽은 1.5를 버텼다

평행 채널에 압력구배 하나를 걸었다. 위벽은 가열되어 점성이 아래벽의 10분의 1이다. 정상 상태에서 두 벽이 받는 전단력의 합은 압력이 미는 힘과 같아야 한다. 그런데 계산해 보니 벽은 압력보다 1.5배 큰 힘을 버티고 있었다. 유량은 해석해보다 17.7% 많았다.

버그는 한 줄이었다. 점성항을 $\mu\nabla^2\mathbf{u}$로 썼다. 교과서의 비압축성 Navier–Stokes 식 그대로다. 이 글은 그 식이 어디서 왔는지 유체 요소 하나에서 다시 유도한다. 그리고 그 유도의 어느 단계에서 "점성 일정"이라는 가정이 끼어드는지 보여준다. 끝에는 내 코드의 점성항이 어느 쪽인지 가려내는 한 줄짜리 테스트가 있다.

## 유체 요소 하나에 Newton 제2법칙을 쓰면

작은 직육면체 유체 요소를 떼어낸다. 질량 대신 밀도를 쓰면 Newton 제2법칙은 단위체적당 식이 된다.

$$
\rho \frac{D\mathbf{u}}{Dt} = \rho\,\mathbf{g} + \mathbf{f}_{\text{surf}}
$$

$D/Dt$는 물질도함수(요소를 따라가며 본 시간 변화), $\rho\mathbf{g}$는 체적력, $\mathbf{f}_{\text{surf}}$는 단위체적당 표면력이다.

표면력은 요소의 여섯 면에 걸린 응력에서 나온다. 응력 $\sigma_{ij}$는 $i$축에 수직인 면에 걸린 $j$방향 힘이다. 정지해 있거나 등속인 요소라면 앞면과 뒷면의 응력이 서로 상쇄된다. 요소가 가속된다는 것은 앞뒷면 응력이 다르다는 뜻이다. $x$방향 순 힘을 쓰면 세 개의 도함수가 남는다.

$$
f_x\,dx\,dy\,dz = \left(\frac{\partial \sigma_{xx}}{\partial x} + \frac{\partial \sigma_{yx}}{\partial y} + \frac{\partial \sigma_{zx}}{\partial z}\right) dx\,dy\,dz
$$

괄호 안은 응력 텐서의 발산이다. 텐서에 발산을 취하면 벡터가 나온다. 그래서 운동방정식은 다음 한 줄로 정리된다.

$$
\rho \frac{D\mathbf{u}}{Dt} = \rho\,\mathbf{g} + \nabla\cdot\boldsymbol{\sigma}, \qquad \sigma_{ij} = -p\,\delta_{ij} + \tau_{ij}
$$

$p$는 압력, $\tau_{ij}$는 점성 응력, $\delta_{ij}$는 크로네커 델타다. 여기까지는 점성에 대해 아무 가정도 없다. 점성력은 "면 응력의 차이"라는 사실만 있다.

아래 시뮬레이션에서 직접 조작해보자. 가열 채널 안의 유체 요소 하나에 걸린 윗면·아랫면 전단응력과, 그 차이를 두 가지 방식으로 계산한 값을 나란히 보여준다.

초록 막대 $\partial\tau/\partial y$는 요소 위치와 크기에 상관없이 항상 −1이다. 압력 1과 정확히 상쇄된다. 점성비 $r$을 올리고 요소를 위아래로 움직여 보자. 주황 막대 $\mu\,\partial^2u/\partial y^2$는 위치마다 달라지고, 빨간 "가짜 순 힘"이 0에서 벗어난다.

## 응력 텐서는 왜 대칭이어야 하나

$\tau_{xy}$와 $\tau_{yx}$가 다르다고 해 보자. 그 차이는 요소를 $z$축으로 돌리는 토크를 만든다. 토크는 면적 × 팔 길이, 즉 $dx^3$에 비례한다. 관성 모멘트는 질량 × 길이², 즉 $dx^5$에 비례한다.

$$
\dot\omega_z \approx \frac{12\,(\tau_{xy}-\tau_{yx})}{\rho\,(dx^2+dy^2)}
$$

$\dot\omega_z$는 요소의 각가속도다. 요소를 0으로 줄이면 각가속도가 무한대가 된다. 연속체가 의미를 가지려면 $\tau_{xy}=\tau_{yx}$여야 한다. 세 축 모두에 같은 논리가 적용된다. 그래서 응력 텐서는 대칭이고, 독립 성분은 6개다.

## ∇·τ가 μ∇²u가 되는 두 가지 조건

뉴턴 유체(응력이 변형률에 선형 비례하는 유체)의 구성식은 다음과 같다.

$$
\tau_{ij} = \mu\left(\frac{\partial u_i}{\partial x_j} + \frac{\partial u_j}{\partial x_i}\right) + \lambda\,\delta_{ij}\,\nabla\cdot\mathbf{u}
$$

$\mu$는 점성계수, $\lambda$는 제2점성계수다. 괄호 안은 변형률 텐서의 두 배다. 정지 유체에서는 변형이 없으니 점성 응력도 0이다. [평균 자유 행로로 본 점성의 기원](/ko/posts/2026-05-14-viscosity-kinetic-origin-transport-analogy/)에서 다룬 $\mu$가 바로 이 비례상수다.

이제 발산을 취한다. $\mu$를 미분 밖으로 꺼내지 않고 그대로 둔다.

$$
\frac{\partial \tau_{ij}}{\partial x_j} = \mu\,\nabla^2 u_i + \mu\,\frac{\partial (\nabla\cdot\mathbf{u})}{\partial x_i} + \frac{\partial \mu}{\partial x_j}\left(\frac{\partial u_i}{\partial x_j} + \frac{\partial u_j}{\partial x_i}\right) + \frac{\partial (\lambda\,\nabla\cdot\mathbf{u})}{\partial x_i}
$$

첫 항만 남기려면 두 조건이 필요하다. 하나는 비압축성 $\nabla\cdot\mathbf{u}=0$이다. 이것으로 둘째·넷째 항이 사라진다. 다른 하나는 $\nabla\mu=0$, 점성 일정이다. 셋째 항은 이 조건 없이는 사라지지 않는다.

평행 채널 $u(y)$에서는 식이 더 단순하다. 압력구배를 $G=-dp/dx$라 하면 정상 상태 운동량식은 다음과 같다.

$$
0 = G + \frac{d}{dy}\left(\mu\,\frac{du}{dy}\right) \;\Rightarrow\; \tau(y) = \mu\,\frac{du}{dy} = C - G\,y
$$

$C$는 벽 조건 $u(0)=u(1)=0$에서 정해지는 상수다. 전단응력은 $\mu$가 어떻게 변하든 직선이다. $\mu$는 속도 기울기만 바꾼다. 반면 $\mu\nabla^2u$ 형태는 $\mu u''=-G$를 푼다. 둘의 차이가 정확히 $\mu' u'$다. 점성 일정 채널은 [Poiseuille 유동의 해석해](/ko/posts/2026-03-28-poiseuille-flow-analytical-solution/)로 돌아간다.

## 코드: 가열된 채널, 두 가지 점성항

무차원 채널 $H=1$, $G=1$에서 점성을 아래벽 1, 위벽 $1/r$로 지수 분포시킨다. 정지 상태에서 시간 전진해 정상 상태까지 간다. 점성항만 두 가지로 바꾼다. `div`는 셀 면에서 $\mu\,\partial u/\partial y$를 만들고 그 차이를 취한다. `lap`은 셀 중심 $\mu$에 2차 차분을 곱한다. 마지막에 내부 검사체적의 운동량 수지(압력힘 − 양 끝 면 전단력)를 잔차로 출력한다.

```python
import numpy as np

# 무차원 채널: H=1, rho=1, 압력구배 G=-dp/dx=1
# 점성은 아래벽 1 → 위벽 1/r 로 지수 감소 (가열된 위벽)
N = 41
y = np.linspace(0.0, 1.0, N)
dy = y[1] - y[0]

def trap(f, x):
    return float(np.sum(0.5 * (f[1:] + f[:-1]) * np.diff(x)))

def mu_profile(yy, r):
    return np.exp(-np.log(r) * yy)

def exact_heated_channel(r, m=20001):
    # mu u' = C - y,  u(0)=u(1)=0  → C = ∫y/mu / ∫1/mu
    s = np.linspace(0.0, 1.0, m)
    w = 1.0 / mu_profile(s, r)
    C = trap(s * w, s) / trap(w, s)
    du = (C - s) * w
    u = np.concatenate([[0.0], np.cumsum(0.5 * (du[1:] + du[:-1]) * (s[1] - s[0]))])
    return trap(u, s), C, -(C - 1.0)   # Q, tau_bottom, tau_top(벽이 유체에 거는 힘)

def viscous_term(u, mu_c, mu_f, form):
    if form == "div":       # ∂y(mu ∂y u): 면 응력의 차
        tau_f = mu_f * (u[1:] - u[:-1]) / dy
        return (tau_f[1:] - tau_f[:-1]) / dy
    else:                   # mu ∇²u: 중심 점성 × 곡률
        return mu_c[1:-1] * (u[2:] - 2 * u[1:-1] + u[:-2]) / dy**2

def time_march_channel(r, form, tol=1e-10):
    mu_c = mu_profile(y, r)
    mu_f = mu_profile(0.5 * (y[1:] + y[:-1]), r)
    dt = 0.4 * dy**2 / mu_c.max()
    u = np.zeros(N)
    for n in range(1, 2_000_000):
        du = dt * (1.0 + viscous_term(u, mu_c, mu_f, form))
        u[1:-1] += du
        if np.abs(du).max() / dt < tol:
            break
    Q = trap(u, y)
    tau_f = mu_f * (u[1:] - u[:-1]) / dy
    # 내부 검사체적 [dy/2, 1-dy/2]의 운동량 수지: 압력힘 = 양 끝 면의 전단력 → 잔차
    balance = 1.0 * (1.0 - dy) - (tau_f[0] - tau_f[-1])
    return Q, balance, n

print(" r    Q_exact   Q_div     Q_lap     err_lap%  balance_div  balance_lap  steps")
for r in [1, 2, 5, 10, 30]:
    Qe, tb, tt = exact_heated_channel(r)
    Qd, bd, nd = time_march_channel(r, "div")
    Ql, bl, nl = time_march_channel(r, "lap")
    print(f"{r:3d}  {Qe:.5f}  {Qd:.5f}  {Ql:.5f}  {100*(Ql-Qe)/Qe:+7.1f}  {bd:+.1e}     {bl:+.1e}       {nd}")
```

  2  0.11739  0.11731  0.11919     +1.5  +6.3e-11     -3.9e-02       13347

## 17.7%와 −0.5가 같은 원인인 이유

`div`의 잔차는 $10^{-11}$, 즉 수렴 허용치 수준이다. 이것은 우연이 아니다. 내부 셀의 점성항을 모두 더하면 이웃 면 응력이 서로 지워지는 망원급수가 된다. 남는 것은 양 끝 면의 응력뿐이다. 앞에서 유도한 "면 응력의 차이"가 이산식에서도 그대로 성립한다.

`lap`은 이 구조가 없다. 셀마다 중심 $\mu_i$를 곱하니 이웃 셀과 공유하는 면 응력이 없다. 더해도 지워지지 않는다. 그 결과 $r=10$에서 내부에 압력의 50%만큼 가짜 체적력이 생긴다. 벽은 압력 1에 더해 가짜 힘 0.5까지 버틴다. 잔차 −0.5가 그것이다.

유량 과대평가도 같은 항에서 나온다. 빠진 항은 $\mu' u' = -\ln r\,(C-y)$다. 크기는 $\ln r$에 비례하고 두 벽 근처에서 가장 크다. `lap`은 곡률을 국소 점성 하나로 정한다($u''=-G/\mu$). 점성이 $1/r$인 위벽 쪽에서 곡률이 $r$배로 커지고, 그 효과가 바닥까지 쌓여 속도 분포 전체가 부푼다. $r=30$이면 오차는 39%로 커지고 잔차는 −1.3이 된다. 압력보다 큰 가짜 힘이다.

$r=1$의 −0.1%는 다른 종류다. 두 형식이 같은 값을 주고 격자를 늘리면 줄어든다. 2차 차분의 이산화 오차일 뿐이다.

## 이 오류가 실제로 숨어 있는 자리

온도 의존 점성(가열 벽, 윤활유, 마그마)은 가장 흔한 경우다. 난류 RANS 솔버도 같다. 와점성 $\mu_t$는 벽에서 0이고 바깥으로 수백 배 커진다. 이 경우 $\nabla\cdot[(\mu+\mu_t)(\nabla\mathbf{u}+\nabla\mathbf{u}^T)]$에서 전치항 $\nabla\mathbf{u}^T$도 버리면 안 된다. 평행 유동에서는 0이지만 2D 박리 유동에서는 살아난다. 다상 유동의 계면은 점성비가 100배를 넘으니 더 심하다.

유한체적법(FVM)은 면 플럭스로 쓰니 대개 `div` 형태다. 위험한 곳은 유한차분 코드와, "비압축이니까"라며 라플라시안 연산자를 재사용한 코드다. OpenFOAM의 `fvm::laplacian(nuEff, U)`도 면 점성을 쓰는 `div` 형태다. 다만 전치항은 `fvc::div(nuEff*dev2(T(fvc::grad(U))))`로 따로 붙는다.

## 점성 일정 가정을 지우기 전에 돌려볼 한 줄

점성비 10짜리 지수 분포를 걸고 정상 상태까지 돌린다. 그리고 내부 셀 점성항의 합과 양 끝 면 응력 차를 비교한다. 두 값이 수렴 허용치 안에서 같으면 보존형이다. 0.5만큼 다르면 어딘가에 $\mu\nabla^2u$가 남아 있다. 이 잔차가 유량보다 먼저 잡아낸다. 유량 17.7%는 다른 오차와 섞여 보이지만, 잔차는 0이냐 아니냐로 갈린다.
