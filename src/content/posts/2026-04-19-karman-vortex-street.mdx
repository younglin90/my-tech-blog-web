강바닥에 박힌 나무 기둥 뒤를 바라보면 물이 좌우로 번갈아 뒤틀리며 흘러내리는 것을 볼 수 있다. 위성 사진에서는 화산섬 뒤에서 수백 킬로미터까지 이어지는 구름 소용돌이 행렬이 찍히기도 한다. 이것이 **카르만 와열(Kármán Vortex Street)**이다 — 둔체(bluff body) 뒤에서 주기적으로 교번(交番)하며 방출되는 와류 열(vortex street).

1911년 헝가리 물리학자 **테오도어 폰 카르만**이 이 현상을 수학적으로 규명했다. 그는 두 줄로 배열된 반무한 점(point vortex) 배열의 안정 조건을 풀어, 와류 간격비가 특정값($h/a \approx 0.281$)일 때만 패턴이 안정함을 보였다. 오늘은 이 "규칙적인 혼돈"의 물리를 파헤쳐보자.

## 언제, 어디서 나타나는가

카르만 와열은 **레이놀즈 수** $Re$가 대략 40~$10^6$ 구간에서 발생한다.

$$Re = \frac{U D}{\nu}$$

여기서 $U$는 자유류 속도, $D$는 원통 직경, $\nu$는 동점성계수다.

| $Re$ 범위 | 현상 |
|---|---|
| $< 5$ | 포복류(creeping flow), 와류 없음 |
| $5$–$47$ | 정상 대칭 쌍와류 (fixed wake) |
| $47$–$190$ | **층류 카르만 와열** 시작 |
| $190$–$10^5$ | 점진적 난류화, 교번 와류 지속 |
| $> 10^5$ | 난류 경계층, 와류 방출 계속 |

$Re \approx 47$ 부근에서 정상 대칭 해가 불안정해지며 주기해로 전환되는데, 이를 수학적으로 **홉프 분기(Hopf bifurcation)**라 부른다. 작은 교란이 증폭되어 안정적인 주기 운동이 태어나는 순간이다.

**현실 세계의 카르만 와열:**

- **구름 소용돌이**: 카나리아 제도나 페로 제도 같은 고립된 섬 뒤에서 위성 사진으로 관찰 가능
- **교량 케이블**: 강풍 시 케이블이 윙윙 우는 이유
- **열교환기 핀**: 냉각 핀 배열 뒤 반복 와류 → 진동 피로 문제
- **해저 파이프라인**: 해류에 의한 VIV(와류 유발 진동, Vortex-Induced Vibration)
- **물고기 꼬리 지느러미**: 추진에 유리한 역(逆) 카르만 와열 생성

## 물리 메커니즘: 왜 교번하는가

원통 표면의 경계층을 생각해보자. 유동이 충분히 빠르면 경계층은 원통 뒤쪽에서 **분리(separation)**된다. 분리점 근처에서 상하 두 개의 자유 전단층(free shear layer)이 형성되고, 각 전단층은 와도(vorticity)를 농축시키며 와류 코어를 키운다.

핵심은 **비대칭 불안정성**이다. 상단 와류가 어느 정도 성장하면, 그것이 하단 전단층을 잡아당겨 하단 와류의 성장을 막는다. 대신 상단 와류는 임계 크기에 달해 원통 뒤로 떨어져 나가고(방출), 이번에는 하단 전단층이 자유롭게 성장한다. 이 교번 과정이 안정적으로 반복되면서 규칙적인 와열을 형성한다.

이 역학을 단순화하면 와류의 순환(circulation) $\Gamma$와 방출 주파수 $f$ 사이 관계로 볼 수 있다:

$$\Gamma \sim U D, \quad f \sim \frac{U}{D} \cdot St$$

## 스트로할 수: 자연의 리듬

와류 방출 주파수를 무차원화한 것이 **스트로할 수(Strouhal number)**다:

$$St = \frac{f D}{U}$$

놀라운 점은 $Re \approx 100$–$10^5$ 범위에서 $St \approx 0.20$–$0.21$로 거의 일정하다는 것이다. 이 보편성 덕분에 직경과 유속만 알면 와류 방출 주파수를 예측할 수 있다.

예를 들어 직경 $D = 0.1\,\text{m}$ 파이프에 $U = 1\,\text{m/s}$ 수류가 흐를 때:

$$f = St \cdot \frac{U}{D} = 0.21 \times \frac{1}{0.1} = 2.1\,\text{Hz}$$

이 주파수가 구조물의 고유진동수와 일치하면 **공진(resonance)** 위험이 생긴다.

## Python 시각화: 와도장 시뮬레이션

2D 비압축 Navier-Stokes 방정식의 와도-유동함수(vorticity-streamfunction) 공식화로 간단히 시뮬레이션할 수 있다. 아래는 **와도장의 시간 발전**을 시각화하는 코드다.

```python
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.animation import FuncAnimation

# 격자 설정
Nx, Ny = 256, 128
Lx, Ly = 4.0, 2.0
dx, dy = Lx / Nx, Ly / Ny
x = np.linspace(0, Lx, Nx)
y = np.linspace(0, Ly, Ny)
X, Y = np.meshgrid(x, y)

# 원통 마스크 (중심: 0.5, 1.0 / 반지름: 0.1)
cx, cy, R = 0.5, 1.0, 0.1
mask = (X - cx)**2 + (Y - cy)**2 < R**2

def point_vortex_velocity(xv, yv, gamma, X, Y, eps=1e-3):
    """점 와류에 의한 속도장"""
    dx = X - xv
    dy = Y - yv
    r2 = dx**2 + dy**2 + eps**2
    u = -gamma / (2 * np.pi) * dy / r2
    v =  gamma / (2 * np.pi) * dx / r2
    return u, v

# 카르만 와열 패턴 근사: 점 와류 쌍 시리즈
def karman_street_field(t, n_vortices=6):
    U_inf = 1.0
    St = 0.21
    f = St * U_inf / (2 * R)
    T = 1.0 / f
    a = 2 * R * 1.5  # 와류 간 횡간격
    h = a * 0.281    # 안정 조건의 종횡비

    u_total = np.ones_like(X) * U_inf
    v_total = np.zeros_like(X)

    for k in range(n_vortices):
        phase = k * T
        xc = cx + U_inf * (t - phase) * 0.8
        if xc < 0 or xc > Lx:
            continue
        # 상단 와류 (시계방향, gamma < 0)
        u, v = point_vortex_velocity(xc, cy + h/2, -1.5, X, Y)
        u_total += u; v_total += v
        # 하단 와류 (반시계방향, gamma > 0), 절반 주기 지연
        xc2 = cx + U_inf * (t - phase - T/2) * 0.8
        if 0 < xc2 < Lx:
            u, v = point_vortex_velocity(xc2, cy - h/2, +1.5, X, Y)
            u_total += u; v_total += v

    # 와도 계산 (curl of velocity)
    omega = (np.gradient(v_total, dx, axis=1) -
             np.gradient(u_total, dy, axis=0))
    omega[mask] = 0  # 원통 내부 마스킹
    return omega, u_total, v_total

# 단일 스냅샷 시각화
fig, axes = plt.subplots(1, 2, figsize=(14, 5))
t_snap = 3.0
omega, u, v = karman_street_field(t_snap)

# 와도장
im1 = axes[0].contourf(X, Y, omega, levels=50,
                        cmap='RdBu_r', vmin=-8, vmax=8)
circle = plt.Circle((0.5, 1.0), 0.1, color='k', zorder=5)
axes[0].add_patch(circle)
axes[0].set_title(f'Vorticity Field  ($Re \\approx 100$,  $t = {t_snap}$)')
axes[0].set_aspect('equal')
axes[0].set_xlabel('x/D'); axes[0].set_ylabel('y/D')
plt.colorbar(im1, ax=axes[0], label='$\\omega$ [s$^{-1}$]')

# 유선 + 속도 크기
speed = np.sqrt(u**2 + v**2)
im2 = axes[1].contourf(X, Y, speed, levels=30, cmap='viridis')
axes[1].streamplot(X, Y, u, v, density=1.5, color='white',
                   linewidth=0.5, arrowsize=0.8)
circle2 = plt.Circle((0.5, 1.0), 0.1, color='k', zorder=5)
axes[1].add_patch(circle2)
axes[1].set_title('Speed + Streamlines')
axes[1].set_aspect('equal')
axes[1].set_xlabel('x/D')
plt.colorbar(im2, ax=axes[1], label='$|U|$ [m/s]')

plt.tight_layout()
plt.savefig('karman_vortex_snapshot.png', dpi=150)
plt.show()
```

이 코드는 점 와류 근사를 사용하므로 실제 CFD 해와 완전히 동일하지 않지만, **와도의 교번 패턴**과 **후류(wake) 내 속도 분포**를 직관적으로 보여준다.

## 공학적 중요성

### 타코마 내로스 교량 붕괴 (1940)

1940년 11월, 미국 워싱턴주 타코마 내로스 교량이 바람에 의해 붕괴됐다. 오랫동안 카르만 와열에 의한 공진으로 알려졌으나, 현재는 공기탄성 **플러터(flutter)** 불안정성이 주 원인으로 평가된다. 그럼에도 이 사례는 유체-구조 연성(FSI)의 중요성을 일깨운 역사적 사건이다.

### VIV (Vortex-Induced Vibration)

해저 파이프라인, 해양 플랫폼 라이저, 교량 케이블에서 VIV는 실질적 위협이다. 와류 방출 주파수 $f_{vortex}$가 구조물 고유진동수 $f_n$에 가까워지면 **잠금(lock-in)** 현상이 발생해 진폭이 폭발적으로 커진다:

$$f_{vortex} \approx f_n \implies \text{lock-in} \implies A/D \sim 0.5 \text{–} 1.5$$

이를 억제하기 위해 **헬리컬 스트레이크(helical strake)**를 파이프에 부착해 와류 방출의 공간적 상관성(spanwise correlation)을 낮춘다.

### 음파 방출

공기 중 원통 주변 유동에서 카르만 와열은 **에올리언 음(Aeolian tone)**을 발생시킨다. 전선이 바람에 울리는 소리가 바로 이것이다. 주파수는 역시 스트로할 수로 예측 가능하다.

## CFD 시뮬레이션 주의사항

실제로 카르만 와열을 CFD로 재현할 때 흔히 겪는 함정들이 있다.

**격자 설계**
- 원통 표면: O-mesh로 균일한 경계층 격자, $y^+ < 1$ (와류 방출 해석에는 $y^+ \approx 1$ 권장)
- 후류 영역: 충분히 세밀하게. 와류 코어 지름의 $\sim 10$배 격자 폭으로 최소 10개 셀 필요
- 도메인 크기: 하류 방향 $\geq 20D$, 측면 $\geq 10D$ (경계 반사 방지)

**시간 간격**
$$\Delta t \leq \frac{T_{vortex}}{100} = \frac{D}{100 \cdot St \cdot U}$$

CFL 수 기반으로도 확인: $\text{CFL} = U \Delta t / \Delta x < 0.5$

**난류 모델**
| $Re$ | 권장 접근법 |
|---|---|
| $< 1000$ | 층류 계산 (NS 직접) |
| $10^3$–$10^4$ | URANS (SST $k$-$\omega$) |
| $10^4$–$10^6$ | LES 또는 DES |
| $> 10^6$ | Hybrid LES/RANS |

**주의**: RANS는 시간 평균량 예측엔 충분하나, 와류 방출의 **비정상 다이내믹스**를 정량적으로 재현하려면 LES/DES가 훨씬 우수하다.

**결과 검증**
- $C_D$ (항력계수): $Re \approx 100$에서 $C_D \approx 1.2$–$1.4$
- $St \approx 0.20$–$0.21$ 확인 (FFT로 $C_L$ 신호 분석)
- 격자 독립성: 2–3단계 격자 세분화로 $C_D$, $St$ 수렴 확인

## 더 깊이 들어가려면

카르만 와열은 비선형 유체역학의 교과서 예제이면서도 지금도 활발히 연구되는 주제다. 세 가지 방향이 특히 흥미롭다:

1. **3차원 효과**: $Re > 190$에서 span 방향 불안정성(Mode A, Mode B)이 출현해 순수 2D 와열이 깨진다
2. **역 카르만 와열**: 물고기나 새의 추진 메커니즘 — 일반 카르만 와열과 반대 회전 방향의 와류가 추력을 생성
3. **능동 제어**: 표면 블로잉/석션, 회전 원통으로 와류 방출 억제 또는 주파수 조절 → 항력 감소
