쿠에트 유동(Couette flow)은 두 평행 평판 사이에서 **한쪽 벽이 등속으로 움직이는** 가장 단순한 전단 유동이다.
압력 구배가 전혀 없는 순수 전단(pure shear) 문제이기 때문에, 포아즈이유 유동과 짝을 이루어 **점성항 검증의 기본 중 기본**으로 쓰인다.

오늘은 쿠에트 유동의 해석해를 손으로 유도하고, 간단한 유한차분 코드로 수렴 차수를 확인한 뒤, 일반화된 **Couette-Poiseuille 복합 유동**까지 확장해본다.

## 문제 설정

### 형상 및 경계 조건

두 무한 평행 평판 사이의 완전 발달 층류를 고려한다.

- 채널 높이: $H$ (평판은 $y = 0$과 $y = H$에 위치)
- 하판 ($y=0$): 고정 $\Rightarrow$ $u(0) = 0$
- 상판 ($y=H$): 속도 $U$로 등속 이동 $\Rightarrow$ $u(H) = U$
- 구동력: **압력 구배 없음** $\dfrac{dp}{dx} = 0$ (순수 벽 구동)

### 지배 방정식

완전 발달 조건($\partial/\partial x = 0$, $v = 0$)과 $dp/dx = 0$을 $x$-방향 나비에–스토크스에 적용:

$$\mu \frac{d^2 u}{dy^2} = 0$$

점성항만 남은 **가장 단순한 형태의 경계값 문제**다.

## 해석해 유도

### 1단계: 1차 적분

$$\frac{du}{dy} = A_1$$

### 2단계: 2차 적분

$$u(y) = A_1 y + A_2$$

### 3단계: 경계 조건 적용

$u(0) = 0 \Rightarrow A_2 = 0$

$u(H) = U \Rightarrow A_1 H = U \Rightarrow A_1 = U/H$

### 최종 해석해

$$\boxed{u(y) = U \frac{y}{H}}$$

**완벽한 선형 프로파일**이다. 포아즈이유의 포물선 프로파일과 정확히 대비되는 결과로, 구동 메커니즘의 차이가 속도장의 형태로 고스란히 드러난다.

## 물리적 해석

### 전단 응력

$$\tau = \mu \frac{du}{dy} = \mu \frac{U}{H} = \text{const}$$

쿠에트 유동에서 전단 응력은 $y$에 무관하게 **유동 단면 전체에서 동일**하다. 이는 운동량이 오직 분자 점성 확산만으로 이동하는 순수 전단 상태임을 의미한다.

### 벽면 마찰 마력

면적 $A$ 상판을 일정 속도 $U$로 끄는 데 필요한 동력:

$$P = \tau \, U \, A = \frac{\mu U^2 A}{H}$$

점도와 속도 제곱에는 비례하고 채널 폭에는 반비례한다. **lubrication(윤활)** 이론의 기초가 바로 이 관계다.

### 체적 유량

$$Q = \int_0^H u \, dy = \frac{U}{H} \int_0^H y \, dy = \frac{U H}{2}$$

평균 속도는 $\bar{u} = U/2$. 상판만 움직이는 것이므로 당연하지만, 포아즈이유($\bar{u} = (2/3) u_{\max}$)와 비교하면 단면 활용도가 낮다.

## 일반화: Couette–Poiseuille 복합 유동

압력 구배 $dp/dx = -G$가 추가되면 해는 두 성분의 **선형 중첩**이 된다:

$$u(y) = U\frac{y}{H} + \frac{G}{2\mu} y(H - y)$$

무차원 파라미터:

$$P^\ast = -\frac{H^2}{2 \mu U} \frac{dp}{dx} = \frac{G H^2}{2 \mu U}$$

- $P^\ast = 0$: 순수 쿠에트 (선형)
- $0 < P^\ast < 1$: 포물선 + 선형, 역류 없음
- $P^\ast > 1$: **하판 근처에서 역류 발생** — 윤활유막의 역류, 슬라이더 베어링 모델링에서 중요

## Python으로 해석해 시각화

```python
import numpy as np
import matplotlib.pyplot as plt

# 파라미터
H, U, mu = 1.0, 1.0, 1.0
y = np.linspace(0, H, 200)

fig, ax = plt.subplots(figsize=(6, 5))

# 순수 쿠에트
ax.plot(y / H, y / H, "k-", lw=2, label=r"$P^\ast=0$ (pure Couette)")

# Couette-Poiseuille 복합
for P in [0.5, 1.0, 2.0, -1.0]:
    G = 2 * mu * U * P / H**2
    u = U * y / H + G / (2 * mu) * y * (H - y)
    ax.plot(u / U, y / H, lw=1.5, label=fr"$P^\ast={P}$")

ax.axvline(0, color="gray", lw=0.8, ls="--")
ax.set_xlabel(r"$u / U$")
ax.set_ylabel(r"$y / H$")
ax.set_title("Couette–Poiseuille 속도 프로파일")
ax.legend(fontsize=9)
plt.tight_layout()
plt.savefig("couette_profiles.png", dpi=150)
plt.show()
```

$P^\ast = -1$ 곡선에서 하판 근처 역류가 뚜렷하게 보인다.

## 유한차분법으로 수치 검증

### FD 이산화

$d^2 u / dy^2 = 0$을 2차 중앙차분으로 이산화한다. 균일 격자 $\Delta y = H / (N-1)$, 내부 노드 $i = 1, \ldots, N-2$:

$$\frac{u_{i+1} - 2 u_i + u_{i-1}}{(\Delta y)^2} = 0$$

경계: $u_0 = 0$, $u_{N-1} = U$.

### Python 구현

```python
import numpy as np

def solve_couette_fd(N, H=1.0, U=1.0):
    """
    N : 총 격자점 수 (경계 포함)
    returns (y, u_num, u_exact, L2_error)
    """
    dy = H / (N - 1)
    y  = np.linspace(0, H, N)

    # 내부 노드에 대한 선형계 구성 (size N-2)
    M = N - 2
    diag  = -2 * np.ones(M)
    upper =  np.ones(M - 1)
    lower =  np.ones(M - 1)
    A = np.diag(diag) + np.diag(upper, k=1) + np.diag(lower, k=-1)

    # 우변: 경계조건 이관 (u_0=0, u_{N-1}=U 항)
    rhs = np.zeros(M)
    rhs[-1] = -U  # 마지막 내부 노드에서 u_{N-1}=U가 오른쪽으로 이동

    u_inner = np.linalg.solve(A, rhs)
    u_num   = np.concatenate([[0.0], u_inner, [U]])
    u_exact = U * y / H

    L2 = np.sqrt(np.mean((u_num - u_exact)**2))
    return y, u_num, u_exact, L2

# 격자 수렴 테스트
print(f"{'N':>4} {'Δy':>8} {'L2 error':>12} {'order':>8}")
prev = None
for N in [5, 10, 20, 40, 80, 160]:
    _, _, _, err = solve_couette_fd(N)
    order = np.log2(prev / err) if prev else float("nan")
    print(f"{N:>4d} {1/(N-1):>8.4f} {err:>12.3e} {order:>8.2f}")
    prev = err
```

### 수렴 결과 (예시 출력)

| $N$ | $\Delta y$ | $L_2$ 오차 | 수렴 차수 |
|----:|-----------|------------|----------|
| 5 | 0.2500 | 4.44e-17 | — |
| 10 | 0.1111 | 5.55e-17 | ~0 |
| 20 | 0.0526 | 6.66e-17 | ~0 |
| 40 | 0.0256 | 8.88e-17 | ~0 |

> **주목**: 해석해가 **1차 다항식(선형)**이므로, 2차 중앙차분법은 이론적으로도 정확히 해를 재현한다. 오차는 전적으로 부동소수점 반올림 수준이다. 이는 쿠에트 유동을 "코드가 돌긴 하는지" 검증하는 **최초의 샌드위치 테스트**로 쓰는 이유다.

2차 정확도를 진짜로 측정하고 싶다면 Couette–Poiseuille 복합 유동(해석해가 2차 다항식)으로 넘어가야 한다.

## OpenFOAM 설정 힌트

쿠에트 유동을 OpenFOAM `icoFoam`으로 재현할 때 핵심:

### `0/U` — 속도 경계 조건

```cpp
boundaryField
{
    bottomWall
    {
        type    noSlip;              // 하판 고정
    }
    topWall
    {
        type    fixedValue;
        value   uniform (1 0 0);     // 상판을 U=1 로 이동
    }
    sides
    {
        type    empty;               // 2D 문제
    }
}
```

### `0/p` — 압력

```cpp
boundaryField
{
    bottomWall  { type zeroGradient; }
    topWall     { type zeroGradient; }
    sides       { type empty; }
}
```

### 검증 체크리스트

1. **정상 상태 도달**: 초기 조건에서 확산 시간 $t \sim H^2 / \nu$까지 구동
2. **선형 프로파일 확인**: 수직 단면 평균 속도가 $U/2$에 수렴
3. **벽면 전단 응력**: 상하판 $\tau_w = \mu U / H$와 일치 (부호 반대)

## 마무리

쿠에트 유동은 너무 단순해서 오히려 놓치기 쉬운 교훈을 준다.

- 해석해가 **선형**이라는 사실만으로 2차 중앙차분법은 기계 정밀도까지 정답을 맞춘다
- 따라서 쿠에트 단독으로는 **수렴 차수 측정이 불가능**하다 — 포아즈이유 또는 Couette–Poiseuille로 확장이 필수
- 반대로, 쿠에트에서조차 틀린 답이 나온다면 **no-slip 경계조건 자체를 의심해야 한다**

다음 포스트에서는 쿠에트 유동의 **비정상(unsteady) 형태** — Stokes 제1문제 — 로 넘어가, 시간 의존 점성 확산을 어떻게 검증하는지 살펴보자.
