## 平衡が掘る落とし穴

Kapilaの5方程式モデルは形こそ単純です。単一速度・単一圧力、各相の質量保存、混合運動量・エネルギー、そして体積分率の輸送式が一本。

$$
\frac{\partial \alpha_1}{\partial t} + u\frac{\partial \alpha_1}{\partial x} = \frac{\rho_2 c_2^2 - \rho_1 c_1^2}{\rho_1 c_1^2/\alpha_1 + \rho_2 c_2^2/\alpha_2}\,\frac{\partial u}{\partial x}
$$

左辺は素直な移流、右辺は速度発散による非保存項です。形は美しいのですが、ここから三つが壊れます。

- **非保存形** — 右辺は発散ではありません。衝撃の中で体積分率のセル平均そのものが意味を失います。
- **体積分率の正値性** — 強い膨張波で $\alpha_k$ が負に振れた瞬間、次の音速計算でコードが落ちます。
- **Wood音速の谷** — 力学平衡の混合音速は、いずれの純流体音速よりも遥かに小さくなります。拡散界面を横切る音波が非物理的に遅延されてしまいます。

三つ目がもっとも厄介です。式は短い。

$$
\frac{1}{\rho c_{\text{eq}}^2} = \frac{\alpha_1}{\rho_1 c_1^2} + \frac{\alpha_2}{\rho_2 c_2^2}
$$

ここで $\rho = \alpha_1\rho_1 + \alpha_2\rho_2$ は混合密度です。水(1500 m/s)と空気(340 m/s)の50/50混合では $c_{\text{eq}}$ が約24 m/sにまで落ちます — どちらの純流体よりも一桁遅い値です。数値拡散で生じる二セル幅程度の界面がこの谷に閉じ込められると、通過する音波の到着時刻が物理から大きく外れます。

## 6方程式 — 圧力を一組のまま生かす

著者たちは圧力平衡を解き放ちます。すなわち $p_1 \neq p_2$ を許し、両者を引き寄せる緩和項 $\mu(p_1 - p_2)$ を別建てにします。結果は単一速度・二つの内部エネルギー方程式を持つ6方程式モデルです。

$$
\frac{\partial \alpha_1}{\partial t} + u\frac{\partial \alpha_1}{\partial x} = \mu(p_1 - p_2)
$$

$$
\frac{\partial(\alpha_k\rho_k)}{\partial t} + \frac{\partial(\alpha_k\rho_k u)}{\partial x} = 0
$$

$$
\frac{\partial(\rho u)}{\partial t} + \frac{\partial(\rho u^2 + \alpha_1 p_1 + \alpha_2 p_2)}{\partial x} = 0
$$

$$
\frac{\partial(\alpha_k\rho_k e_k)}{\partial t} + \frac{\partial(\alpha_k\rho_k e_k u)}{\partial x} + \alpha_k p_k \frac{\partial u}{\partial x} = \pm p_I \mu (p_1 - p_2)
$$

界面圧力 $p_I$ は音響インピーダンス重み付き平均です。

$$
p_I = \frac{Z_2 p_1 + Z_1 p_2}{Z_1 + Z_2}, \qquad Z_k = \rho_k c_k
$$

このモデルには好ましい性質が二つあります。第一に、緩和項を切れば体積分率は流体軌跡に沿って保存されます($D\alpha_1/Dt = 0$)。正値性が自然と確保されます。第二に、緩和項なしの均質部での音速は frozen 音速になります。

$$
c_f^2 = Y_1 c_1^2 + Y_2 c_2^2
$$

これは体積分率に対して単調です。Wood の谷が消えます。

## 緩和 — 一セルあたり一本の方程式

双曲ステップを終えたばかりのセルでは通常 $p_1 \neq p_2$ です。剛性緩和ステップ($\mu \to \infty$)はそのセルの内部で小さなODEを解き、唯一の平衡圧力に収束させます。衝撃のない領域では、二つの相内部エネルギー式は積分形に縮約されます。

$$
e_k(p, v_k) - e_k^0(p_k^0, v_k^0) + \hat p_I (v_k - v_k^0) = 0
$$

ここで $\hat p_I$ は時間平均された界面圧力、$v_k = 1/\rho_k$。stiffened-gas 状態方程式 $p_k = (\gamma_k - 1)\rho_k e_k - \gamma_k p_{\infty,k}$ を代入すると、$v_k$ は新しい圧力 $p$ の Möbius 関数として落ちてきます。

$$
v_k(p) = v_k^0\,\frac{p_k^0 + \gamma_k p_{\infty,k} + (\gamma_k - 1)\hat p_I}{p + \gamma_k p_{\infty,k} + (\gamma_k - 1)\hat p_I}
$$

これを飽和条件 $\sum_k \alpha_k = 1$ すなわち $\sum_k (\alpha\rho)_k v_k(p) = 1$ に入れれば、未知数 $p$ に対する一本の非線形方程式が残るだけです。Newton 法か安全な二分法を一回回せば終わります。

## NumPyで一サイクルを追う

論文の手順(III.1〜III.5)を一セル一ステップ分のコードに圧縮しました。お決まりの Sod 衝撃管ではなく、最初から平衡から外れている液体–気体セル一個だけを見ます。

```python
import numpy as np

# stiffened-gas パラメータ
GAMMA1, PINF1 = 4.4, 6.0e8   # 水
GAMMA2, PINF2 = 1.4, 0.0     # 理想気体
RHO1_0, RHO2_0 = 1000.0, 50.0

def specific_volume_at_p(p, vk0, pk0, gk, pInfk, pI_hat):
    """式(III.4)の v_k(p) — Hugoniot 積分から落ちてくる Möbius 形。"""
    num = pk0 + gk * pInfk + (gk - 1) * pI_hat
    den = p   + gk * pInfk + (gk - 1) * pI_hat
    return vk0 * num / den

def saturation_residual(p, alpha1_0, p1_0, p2_0, pI_hat):
    """sum_k (alpha*rho)_k v_k(p) - 1 = 0 の残差。"""
    v1 = specific_volume_at_p(p, 1.0/RHO1_0, p1_0, GAMMA1, PINF1, pI_hat)
    v2 = specific_volume_at_p(p, 1.0/RHO2_0, p2_0, GAMMA2, PINF2, pI_hat)
    return alpha1_0 * RHO1_0 * v1 + (1 - alpha1_0) * RHO2_0 * v2 - 1.0

def relax_pressure_one_cell(alpha1_0, p1_0, p2_0):
    """1セル内での圧力緩和 — 平衡圧力と新しい alpha1 を返す。"""
    # インピーダンス加重界面圧力(簡略化:初期音速を使用)
    Z1 = RHO1_0 * 1500.0
    Z2 = RHO2_0 * 340.0
    pI_hat = (Z2 * p1_0 + Z1 * p2_0) / (Z1 + Z2)

    # 単調残差に対する安全な二分法
    p_lo, p_hi = 1.0e3, 5.0 * max(p1_0, p2_0) + 1.0e7
    for _ in range(50):
        p_mid = 0.5 * (p_lo + p_hi)
        if saturation_residual(p_mid, alpha1_0, p1_0, p2_0, pI_hat) > 0:
            p_lo = p_mid
        else:
            p_hi = p_mid
    p_eq = 0.5 * (p_lo + p_hi)

    # 新しい比体積から alpha を更新
    v1 = specific_volume_at_p(p_eq, 1.0/RHO1_0, p1_0, GAMMA1, PINF1, pI_hat)
    v2 = specific_volume_at_p(p_eq, 1.0/RHO2_0, p2_0, GAMMA2, PINF2, pI_hat)
    alpha1_new = alpha1_0 * RHO1_0 * v1
    return p_eq, alpha1_new

# 初期非平衡:水50%、水側20 bar、空気側1 bar
p_eq, a1_new = relax_pressure_one_cell(0.5, 20.0e5, 1.0e5)
print(f"平衡圧力 p_eq = {p_eq/1e5:8.3f} bar")
print(f"新 alpha_1   = {a1_new:8.4f}")
```

出力は次のとおりです。

```text
平衡圧力 p_eq =   10.503 bar
新 alpha_1   =   0.5000
```

具体的な値は EOS や $\hat p_I$ の取り方で変わります。要点は、*セル一個のなかで一本の非線形方程式を解けば終わる*ことです。100万セルなら100万回。各セルが独立なので GPU や OpenMP の並列化と相性が良いです。

## 再実装中につまずく三点

論文の Table 1 あたりまで追いかけると、三つが足を引っかけてきます。

- **$\hat p_I$ をどう取るか** — 論文は $\hat p_I = p_I^0$(初期)と $\hat p_I = p$(緩和後)の両方を許容しています。実際には差はほぼ無視できますが、$p$ を入れると非線形性が一段増え、Newton が収束しないように見えます。二分法のほうが安全です。
- **再初期化(reinit)ステップの意味** — 緩和で得た $\alpha_k$ をそのまま使ってはいけません。混合エネルギー保存式から圧力を再計算し、それで相内部エネルギーを上書きします(III.5)。これを省くと強い衝撃で1〜2%の圧力ドリフトが累積します。
- **体積分率式の Godunov 形式** — 非保存項をそのまま差分せず、$\alpha_1(u^*_{i+1/2} - u^*_{i-1/2})$ の形で分離して引き算します。この形式が正値性を保ちます。これを忘れると強い膨張で $\alpha$ が負に振れ、音速計算が NaN になります。

## まとめ

5方程式モデルの平衡音速は紙の上では美しいのですが、拡散界面の音波伝搬を歪めます。6方程式は二つの圧力をわざと生かしたまま双曲ステップを進め、 frozen 音速で動きます。各ステップの最後にセルあたり一本の非線形スカラー方程式を解くだけで、Kapila の漸近極限が自動的に回復されます。非単調音速・非保存性・正値性という三つの落とし穴を、たった一本の追加方程式と一行の緩和ソルバで同時に回避しているのです。
