## なぜ燃焼器の前にディフューザがあるのか

ジェットエンジンの圧縮機出口では、空気はマッハ0.3〜0.4で流れ出ます。ところが燃焼器に入る前に、わざわざディフューザ(流路を広げて減速させる管)で速度を半分以下に落とします。第一の理由は火炎の安定です。第二の理由は熱力学です。動いている気体に熱を加えること自体が全圧(気体を等エントロピー的に静止させたときの圧力)を削ります。入口が速いほど、削られる量も大きくなります。

この記事ではその損失を数字で測ります。摩擦のない等断面ダクトに、全温度を2倍にする熱を加えます。入口マッハ数を0.10から0.40まで変え、出口状態をRK4で積分します。結論は二つです。入口0.30なら全圧を7.1%失います。入口0.384を超えると、熱を最後まで入れることすらできません。

## 等断面ダクトに熱だけを加える:Rayleigh流れ

元ノート(Hill & Peterson 3.5節)の設定は単純です。断面積は一定で、摩擦も軸仕事もありません。変わるのは全温度 $T_0$ だけです。燃焼、液滴の蒸発、ジュール加熱、壁面伝熱がすべてこのモデルに入ります。この流れをRayleigh流れと呼びます。

連続の式と運動量の式はすぐに積分できます。$\rho u$ が一定で、$p + \rho u^2$ も一定です。マッハ数で書くと、入口(添字1)に対する静圧比が得られます。

$$\frac{p}{p_1} = \frac{1 + \gamma M_1^2}{1 + \gamma M^2}$$

$\gamma$ は比熱比、$M$ は局所マッハ数です。状態方程式とエネルギー式を加えると、全温度とマッハ数が一対一に結びつきます。音速点(添字 $*$)を基準にすると次のようになります。

$$\frac{T_0}{T_0^*} = \frac{2(\gamma + 1)M^2 \left(1 + \frac{\gamma - 1}{2}M^2\right)}{(1 + \gamma M^2)^2}$$

$T_0^*$ は同じ質量流束で $M=1$ になる全温度です。この関数の最大値は $M=1$ での1です。つまり、どんな流れにも加えられる熱には上限があります。

亜音速から始めても超音速から始めても、加熱は点をエントロピー最大点($M=1$)へ押しやります。加熱量を増やすと点はその先端で止まり、赤い警告が出ます。負の加熱(冷却)は点を反対側へ動かします。

## 熱を加えるとマッハ数は1へ引き寄せられる

閉じた式より微分形のほうが原因がよく見えます。三つの保存式を微小変化で整理すると、次の影響係数が得られます。

$$\frac{dM^2}{M^2} = \frac{(1 + \gamma M^2)\left(1 + \frac{\gamma - 1}{2}M^2\right)}{1 - M^2}\,\frac{dT_0}{T_0}$$

分子は常に正です。符号は分母 $1-M^2$ が決めます。亜音速では $dT_0>0$ なら $M$ が増えます。超音速では $M$ が減ります。どちらも1へ向かいます。そして $M \to 1$ で係数は発散します。わずかな熱でマッハ数が大きく動くということです。

直観的にはこうです。加熱すると密度が下がります。$\rho u$ が一定なので速度が上がるしかありません。速度が上がると運動量式により静圧が下がります。静圧が下がると密度がさらに下がります。亜音速ではこのループが自ら増幅します。

## 熱を加えたのに温度が下がる区間

静温度比は $T/T^* = M^2\left[(1+\gamma)/(1+\gamma M^2)\right]^2$ です。この式は $M=1/\sqrt{\gamma}$ で最大になります。空気($\gamma=1.4$)なら $M=0.845$ です。そこから $M=1$ までは、熱を加えるほど静温度が下がります。

矛盾に見えますが、エネルギー式は守られています。加えた熱より運動エネルギーの増加のほうが大きいのです。その差を静エンタルピーが埋めます。上のシミュレーションではオレンジ色の区間がこの領域です。入口0.6、加熱0.3にすると、点がオレンジ区間に入ったところで $T/T_1$ が減り始めます。

全圧は事情が違います。加熱はエントロピーを増やします。そのため亜音速でも超音速でも全圧は必ず下がります。元ノートの式(3.18)がその比です。ノートでは指数が $\gamma(\gamma-1)$ と書かれていますが、正しくは $\gamma/(\gamma-1)$ です。

## コード:全温度2倍、入口マッハ数7段階

燃焼器を一つ模擬します。ダクト長 $x\in[0,1]$ に熱を一様に加え、$T_0$ を1から $\tau=2$ へ上げます。800 Kの空気を1600 Kに加熱するイメージです。上の影響係数を $T_0$ について4000ステップのRK4で積分します。$M^2$ が0.9999に達したら熱的チョーク(加熱によって音速に達し、それ以上熱を受け取れない状態)と判定します。静圧・静温度・全圧は局所マッハ数から計算します。最後に閉じた解とRK4の結果を比べます。

```python
import math

G = 1.4  # 比熱比

def t0_ratio_star(M):
    """式 (3.21): T0/T0*"""
    m2 = M*M
    return 2*(G+1)*m2*(1+0.5*(G-1)*m2)/(1+G*m2)**2

def dm2_dt0(m2, t0):
    """Rayleigh影響係数: dM²/dT0"""
    return m2*(1+G*m2)*(1+0.5*(G-1)*m2)/(1-m2)/t0

def heat_march(M1, tau, n=4000):
    """ダクト長 x∈[0,1] に熱を一様に加えながら M² をRK4で前進。"""
    m2, t0 = M1*M1, 1.0
    dt0 = (tau-1.0)/n
    xs, ms = [0.0], [M1]
    for i in range(n):
        k1 = dm2_dt0(m2, t0)
        k2 = dm2_dt0(m2+0.5*dt0*k1, t0+0.5*dt0)
        k3 = dm2_dt0(m2+0.5*dt0*k2, t0+0.5*dt0)
        k4 = dm2_dt0(m2+dt0*k3, t0+dt0)
        m2n = m2 + dt0*(k1+2*k2+2*k3+k4)/6
        t0 += dt0
        if not (0 < m2n < 1) or m2n > 0.9999:   # 音速到達 → 熱的チョーク
            return xs, ms, (i+1)/n
        m2 = m2n
        xs.append((i+1)/n); ms.append(math.sqrt(m2))
    return xs, ms, None

def ratios(M, M1):
    """入口に対する静圧・静温度・全圧比(摩擦なし等断面)"""
    p = [(1+G*M1**2)/(1+G*m**2) for m in M]
    T = [(pi*m/M1)**2 for pi, m in zip(p, M)]
    p0 = [pi*((1+0.5*(G-1)*m**2)/(1+0.5*(G-1)*M1**2))**(G/(G-1)) for pi, m in zip(p, M)]
    return p, T, p0

def m1_max(tau):
    """全温度比 tau をチョークなしで加えられる最大入口マッハ数(二分法)"""
    lo, hi = 1e-4, 1.0
    for _ in range(60):
        mid = 0.5*(lo+hi)
        lo, hi = (mid, hi) if t0_ratio_star(mid) < 1/tau else (lo, mid)
    return 0.5*(lo+hi)

tau = 2.0   # 燃焼器: 全温度2倍
print(f"tau = T02/T01 = {tau}   M1_max (closed form) = {m1_max(tau):.4f}")
print(" M1   | M_exit  p0 loss[%]  T_max/T1  x(T_max)  choke x")
for M1 in [0.10, 0.15, 0.20, 0.25, 0.30, 0.35, 0.40]:
    x, M, xc = heat_march(M1, tau)
    p, T, p0 = ratios(M, M1)
    k = max(range(len(T)), key=T.__getitem__)
    loss = 100*(1-p0[-1])
    xtm = f"{x[k]:.3f}" if k < len(x)-1 else "exit"
    cs = f"{xc:.3f}" if xc else "-"
    print(f" {M1:.2f} | {M[-1]:.4f}  {loss:9.2f}  {max(T):8.3f}  {xtm:>8}  {cs:>7}")

# 閉じた解とRK4出口マッハ数の比較
x, M, _ = heat_march(0.30, tau)
lo, hi = 0.30, 1.0
target = t0_ratio_star(0.30)*tau
for _ in range(60):
    mid = 0.5*(lo+hi)
    lo, hi = (mid, hi) if t0_ratio_star(mid) < target else (lo, mid)
print(f"M1=0.30: RK4 M_exit={M[-1]:.6f}  closed form={0.5*(lo+hi):.6f}")
mf = lambda M: M*(1+0.5*(G-1)*M*M)**(-(G+1)/(2*(G-1)))   # 同じ p01・T01 での質量流量
print(f"M1 0.40 -> {m1_max(tau):.4f}: mass flow x {mf(m1_max(tau))/mf(0.40):.4f}")
print(f"heating cools the gas for {1/math.sqrt(G):.4f} < M < 1")
```

## 0.384、13.5%、x = 0.890 が示すこと

第一に、全圧損失は入口マッハ数のほぼ2乗で増えます。0.10で0.71%、0.20で2.92%、0.30で7.11%です。入口を0.15まで減速すれば損失は1.6%に下がります。ディフューザ自体の損失を考えても、減速する理由は十分です。

第二に、入口0.35までは出口に届きます。しかし出口マッハ数はすでに0.66です。影響係数の分母が小さくなる区間なので、熱放出分布がわずかに揺れるだけで出口状態が大きく揺れます。

第三に、入口0.40ではダクトの89%を通ったところで音速に達します。その手前の x = 0.852 で静温度は最大(入口の1.672倍)でした。そこで $M=0.845$ を通過したからです。その後の4%の区間では、熱を加えているのに気体が冷えていました。

閉じた解で求めた限界 $M_{1,\max}=0.3836$ は $T_0/T_0^*(M_1)=1/\tau$ の根です。RK4の出口マッハ数は閉じた解と小数第6位まで一致します。積分が正しいことの確認です。

## チョークした燃焼器は上流を書き換える

実際のエンジンでは、x = 0.890 で流れが止まることはありません。亜音速流は下流の情報を上流へ伝えます。チョークが起きると入口条件が自ら変わります。熱をすべて受け取れるよう、入口マッハ数が0.3836まで下がります。

同じ全圧・全温度で入口マッハ数が0.40から0.3836に下がると、質量流量は0.9663倍になります。3.4%少ない空気しか入りません。圧縮機から見れば出口が急に塞がれたのと同じで、作動点はサージ(圧縮機の逆流)側へ押されます。アフターバーナー点火時にノズルスロートを広げる理由はここにあります。加えた熱の分だけ流路を開き、上流がこの変化を感じないようにするのです。

この計算は摩擦を無視しています。実際のダクトでは摩擦(Fanno流れ)もマッハ数を1へ引き寄せるので、本当の限界は0.384より低くなります。ノズルで面積が担う役割をここでは熱が担っている点は、[先細末広ノズルとチョーク](/ja/posts/2026-06-18-de-laval-nozzle-choked-flow/)と並べると明確になります。こうした流れを圧力ベースのソルバーで解くときの落とし穴は[圧縮性SIMPLEのψp′項](/ja/posts/2026-11-09-compressible-simple-pressure-correction-psi-term/)で扱いました。

## アフターバーナーの設計表でτより先に見る数字

加熱ダクトを設計するとき、あるいはCFDの結果を検討するときは、τより先に $T_0/T_0^*(M_1)$ を計算しましょう。その逆数が、そのダクトが受け入れられる最大の全温度比です。τがその値に近いほど、出口状態は熱放出分布に敏感になります。超えていれば、計算領域の入口条件が間違っています。質量流量固定の境界を置いたシミュレーションが発散したら、ソルバーより先にこの不等式を疑いましょう。
