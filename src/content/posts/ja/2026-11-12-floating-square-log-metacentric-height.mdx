## 角材を水に投げ込むと、どの面が上を向くか

断面が正方形の長い角材があります。密度は水の半分です。水に投げ込むと、どう浮くでしょうか。多くの人は一つの面が上を向いた平らな姿勢を思い浮かべます。実際には、角の一つが真下を向いたダイヤモンドの姿勢で浮きます。この記事では、その理由をメタセンタ高さ(metacentric height、浮体の安定性を測る長さ)一つで説明します。読み終えるころには、GMの式を導き、傾斜角ごとに浮心を計算して「平らに浮く密度の範囲」を数値で確かめられます。

気体力学の教科書を写した古いノートの3-6節「Buoyancy & stability」には、図が数枚と短いメモしか残っていません。「時計回りのモーメントなら安定」「上が重いと反時計回りのモーメント、不安定」。この二行が今日の出発点です。重心が高いと不安定、というのは直感どおりです。しかし均質な角材の重心はちょうど中央にあります。では、何が姿勢を決めるのでしょうか。

## 浮心は物体と一緒には動かない

物体に働く力は二つです。重さは重心Gから下向きに働きます。浮力は没水部分の図心B(浮心)から上向きに働きます。釣り合いでは二つの力は大きさが等しく、同じ鉛直線上にあります。

物体を少し傾けると、Gは物体に固定されたまま一緒に回ります。Bはそうではありません。片側が深く沈み、反対側が浮き上がって、没水部分の形が変わります。Bは深く沈んだ側へ滑ります。この移動が十分大きければ、浮力がGの外側から押し上げて物体を戻します。足りなければ、浮力と重さが偶力(大きさが等しく向きが逆の二つの力)となり、傾きを大きくします。

二つの力の作用線の水平距離を復原てこGZと呼びます。戻す向きなら正です。下のシミュレーションで実際に操作してみましょう。

既定値(b/h = 1、s = 0.5)でReleaseを押すと、5°傾けた角材は0°に戻らず45°まで倒れます。幅b/hを1.25以上に広げるか、G shiftを−0.09より下げると、GZが緑に変わり、0°付近で振動しながら止まります。

## メタセンタ高さ GM = BM − BG

小さな傾斜角θでBが移動したあと、浮力の作用線は物体の中心線と一点で交わります。この点がメタセンタMです。MがGより上にあれば安定です。二点間の距離がGMで、小角では復原てこは次のようになります。

$$GZ \approx GM \sin\theta$$

GMは幾何学だけで求まります。水線面(waterplane、物体を水面で切った断面)の軸まわりの断面二次モーメントを$I$、没水体積を$V$とします。

$$GM = BM - BG = \frac{I}{V} - (KG - KB)$$

$K$は底(キール)、$KB$は底から浮心まで、$KG$は底から重心までの高さです。$BM = I/V$は、傾きに応じてBがどれだけ遠くへ滑るかを表します。水線面が広いほど大きくなります。

## 正方形ではGMはsだけの関数になる

幅$b$、高さ$h$の長方形断面を単位長さで考えます。均質な物体の密度比を$s = \rho_{body}/\rho_{water}$とすると、喫水(draft、沈む深さ)は$d = sh$です。

$$I = \frac{b^3}{12},\quad V = b\,s h,\quad KB = \frac{sh}{2},\quad KG = \frac{h}{2}$$

代入すると次の式を得ます。

$$GM = \frac{b^2}{12\,s\,h} + \frac{s h}{2} - \frac{h}{2}$$

第1項は水線面による復原、残りの二項はGがBより高いことによる損失です。正方形($b = h = 1$)では次のように整理されます。

$$GM = \frac{6s^2 - 6s + 1}{12\,s}$$

分子がゼロになる$s = (3 \pm \sqrt{3})/6$、すなわち0.2113と0.7887が境界です。その間ではGMは負です。非常に軽いか非常に重い角材だけが平らに浮きます。式の符号は$s \leftrightarrow 1-s$で対称です。密度$s$で浮く物体を裏返すと、水面より上の部分が密度$1-s$で沈んだ物体と同じ問題になるからです。

この式は小さなθでのみ成り立ちます。GMが負のとき、物体がどこまで倒れて止まるかは教えてくれません。それには大角度でのGZ(θ)全体を計算する必要があります。

## コード:901個の傾斜角ごとに喫水線を二分法で

計算手順は単純です。断面をθだけ回転させます。没水面積が$s\,bh$になる水面高さ$c$を二分法(bisection、区間を半分ずつ縮めて根を探す方法)で求めます。没水多角形の図心がBです。Gを原点に置けば$GZ = -x_B$です。θを0〜90°で掃引し、GZが負から正に変わる所が安定な釣り合いです。

```python
import numpy as np

def clip_below(poly, c):
    """多角形のうち y < c の部分 (Sutherland–Hodgman, 直線1本)"""
    out = []
    n = len(poly)
    for i in range(n):
        p, q = poly[i], poly[(i + 1) % n]
        pin, qin = p[1] < c, q[1] < c
        if pin:
            out.append(p)
        if pin != qin:
            t = (c - p[1]) / (q[1] - p[1])
            out.append((p[0] + t * (q[0] - p[0]), c))
    return out

def area_centroid(poly):
    A = cx = cy = 0.0
    n = len(poly)
    for i in range(n):
        x0, y0 = poly[i]; x1, y1 = poly[(i + 1) % n]
        cr = x0 * y1 - x1 * y0
        A += cr; cx += (x0 + x1) * cr; cy += (y0 + y1) * cr
    A *= 0.5
    return A, cx / (6 * A), cy / (6 * A)

def righting_arm(theta, s, b=1.0, h=1.0):
    """傾斜角thetaでの復原てこGZ (Gは原点, 正 = 戻す向き)"""
    co, si = np.cos(theta), np.sin(theta)
    box = [(-b/2, -h/2), (b/2, -h/2), (b/2, h/2), (-b/2, h/2)]
    poly = [(x*co - y*si, x*si + y*co) for x, y in box]
    target = s * b * h
    lo, hi = -0.8*(b+h), 0.8*(b+h)
    for _ in range(60):                       # 喫水線の高さcを二分法で
        c = 0.5 * (lo + hi)
        sub = clip_below(poly, c)
        A = area_centroid(sub)[0] if len(sub) >= 3 else 0.0
        lo, hi = (c, hi) if A < target else (lo, c)
    _, xB, _ = area_centroid(clip_below(poly, c))
    return -xB

def floating_angles(s, b=1.0, h=1.0, n=901):
    th = np.linspace(0, np.pi/2, n)
    gz = np.array([righting_arm(t, s, b, h) for t in th])
    gm = (righting_arm(1e-4, s, b, h)) / 1e-4
    stable = [0.0] if gm > 0 else []
    for i in range(1, n - 2):                 # GZが − → + に変わる所 = 安定な釣り合い
        if gz[i] < -1e-9 and gz[i+1] > -1e-9:
            stable.append(np.degrees(th[i] - gz[i]*(th[i+1]-th[i])/(gz[i+1]-gz[i])))
    if b != h and gz[-2] < 0:                 # 90°(立てた姿勢)も釣り合い
        stable.append(90.0)
    return gm, stable

print("square section (b/h = 1), homogeneous body, s = rho_body / rho_water")
print(" s     GM_theory   GM_numeric   stable heel (deg)")
for s in [0.10, 0.20, 0.22, 0.24, 0.30, 0.50, 0.70, 0.76, 0.80, 0.90]:
    gm_th = 1/(12*s) + s/2 - 0.5
    gm, st = floating_angles(s)
    print(f"{s:.2f}  {gm_th:+.5f}    {gm:+.5f}     {', '.join(f'{a:.1f}' for a in st)}")
print()
print("s = 0.5, widening the section (h = 1)")
print(" b/h   GM_theory   stable heel (deg)")
for b in [1.0, 1.1, 1.2, 1.25, 1.3, 1.5]:
    s = 0.5
    gm_th = b*b/(12*s) + s/2 - 0.5
    gm, st = floating_angles(s, b=b)
    print(f"{b:.2f}  {gm_th:+.5f}    {', '.join(f'{a:.1f}' for a in st)}")
print(f"\ncritical s: (3-sqrt3)/6 = {(3-np.sqrt(3))/6:.4f}, (3+sqrt3)/6 = {(3+np.sqrt(3))/6:.4f}")
```

## 表の読み方:45°、23.5°、そしてb/h = 1.225

第一に、数値GMと理論GMが5桁まで一致します。小角での傾き$dGZ/d\theta$がちょうど$I/V - BG$だということです。式に近似はありません。小角という条件があるだけです。

第二に、s = 0.30、0.50、0.70では45°が唯一の安定点です。正方形は対称なので、45°ではGZが常にゼロです。GMが十分に負なら、0°から押し出された物体は次の対称姿勢であるダイヤモンドまで倒れます。

第三に、境界のすぐ内側のs = 0.22、0.24では中間の角度13.7°、23.5°で止まります。76.3°と66.5°は同じ姿勢を反対側の面から測った値です。平らな姿勢が不安定になった瞬間に45°へ跳ぶわけではありません。傾きは0°から連続的に増え、s ≈ 0.28付近で45°に達します(同じコードでs = 0.28なら41.2°、0.29なら45.0°)。GMの符号は安定か否かだけを教えてくれます。止まる角度はGZ曲線全体が決めます。

第四に、密度を0.5のまま幅だけ広げると、$b^2/6 = 1/4$、つまり$b/h = \sqrt{1.5} \approx 1.225$でGMがゼロを横切ります。表の1.20から1.25の間の符号の切り替わりがそれです。幅22%の違いがダイヤモンドと平らな姿勢を分けます。

## 船舶設計とCFDでこの計算が使われる場面

船の復原性評価は、上のコードを実際の船体形状に置き換えたものです。断面の代わりに3D船体を水線面で切り、角度ごとのGZ曲線を描きます。規則はGMの下限に加えて、GZ曲線の下の面積(復原エネルギー)も求めます。今日の表が示したように、小角のGMだけでは大角度の挙動が分からないからです。

VOF(volume of fluid、界面を体積率で追跡する手法)と6自由度剛体運動を組み合わせた浮体CFDでも、同じ計算が最初の検証になります。静水面に物体を置き、シミュレーションが静的な釣り合い姿勢を再現するかを確認します。外れる場合、たいていは質量・慣性・重心の入力が間違っています。圧力場が静水圧$p = \rho g (c - y)$に収束すれば、浮力とBは今日の多角形計算と一致するはずです。静止流体で応力が$-p\mathbf{I}$だけになる過程は、[応力発散∇·τを扱った記事](/ja/posts/2026-11-03-stress-divergence-variable-viscosity-laplacian/)でニュートンの第二法則から整理しました。

自由減衰(free decay)試験も同じGMを使います。小角での横揺れは$I_{roll}\ddot\theta = -m g\,GM\,\theta$の振り子です。測定した固有周期からGMを逆算できます。静水圧から始まる一枚の計算が、動力学の検証基準になるわけです。損失を運動量で考える必要がある[急拡大管のBorda–Carnot損失](/ja/posts/2026-11-05-borda-carnot-sudden-expansion-lost-velocity/)とは違い、ここでは静水圧の積分だけで答えが閉じます。

## はしけに荷を積む前に確かめる不等式一つ

$$\frac{b^2}{12\,s\,h} > \frac{h}{2} - \frac{sh}{2} + \Delta_G$$

$\Delta_G$は荷によって上がった重心高さの変化です。左辺は幅の二乗で増え、右辺はGを上げるたびに大きくなります。甲板に荷を積み上げると$\Delta_G$が増えます。軽い荷なら$s$が小さくなり、左辺も大きくなります。どちらが勝つかはこの一行で判断できます。最初のシミュレーションでb/h = 1.25にし、G shiftを+0.1上げるだけで断面が転覆することを確かめてみましょう。
