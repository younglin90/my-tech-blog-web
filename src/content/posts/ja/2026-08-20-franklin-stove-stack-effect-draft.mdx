## 1741年、煙をわざわざ下へ流した暖炉

ベンジャミン・フランクリンは1741年に暖炉を設計し直しました。狙いは単純です。煙突からそのまま
抜けていく熱を、部屋の中でもう一度つかまえることでした。当時のヨーロッパは人口が急増して薪が
不足しており、暖房効率は生存に直結する問題でした。

彼が採った方法は流路を折り返すことです。火から昇った煙をバッフル（baffle、流路を横切って流れを
曲げる板）の上へ越えさせ、鋳鉄の壁に沿って**下へ**降ろし、そのあとで煙突へ上げます。降りる間に
鋳鉄が温まり、その熱が部屋へ放射されます。当時の記録はこれを「サイフォン現象」と呼びました。

煙突の頂点の高さは変わりません。煙が最終的に得る高度差も同じです。ところがこの暖炉は、煙が
部屋へ漏れることで悪名を得ました。この記事では、その損が正確にどこでどれだけ生じるのかを浮力の
帳簿に書き出します。答えは一行です — 浮力は高さではなく、**熱いときの高さ**でしか稼げません。

`down-leg` を 0 から 1 m へ動かすと、煙突の頂点は 7 m のまま正味ドラフトだけが減ります。

## ドラフトは密度差に高さを掛けた量である

煙突が煙を引き上げる力をドラフト（draft、通風力）と呼びます。これはポンプではなく静水圧の差です。
外気の柱と内側の煙の柱で重さが違うために生じます。

高さ $H$ の煙道（flue）に対して、ドラフトは次のように書けます。

$$
\Delta p_{\text{draft}} = \int_0^{H} \left( \rho_\infty - \rho(z) \right) g \, \mathrm{d}z
$$

$\rho_\infty$ は外気密度、$\rho(z)$ は高さ $z$ での煙の密度、$g$ は重力加速度です。煙道の内外で
絶対圧はほぼ等しいので理想気体では $\rho = p_0 / (R T)$ が成り立ち、煙温度が $T_g$ で一様なら
積分はすぐに解けます。

$$
\Delta p_{\text{draft}} = \rho_\infty g H \left( 1 - \frac{T_\infty}{T_g} \right)
$$

10 °C の外気（$\rho_\infty = 1.247$ kg/m³）、煙温度 500 K、煙突高さ 7 m を入れると 37 Pa に
なります。実際の暖炉のドラフトは 10〜30 Pa なので、大きさは合っています。

ここで効いてくるのは $\mathrm{d}z$ が積分の中にあることです。浮力は総高さに一度だけ掛ける量では
なく、**1 m ごとにその場の密度で買い足していく量**です。フランクリンが支払った代金はここにあります。

## 浮力は熱いときの高さでしか稼げない

経路を三区間に切ります。バッフルまでの上昇（$+0.8$ m）、下降流路（$-h_d$）、煙突
（$+6.2 + h_d$ m）です。三区間の高度変化を足すと $h_d$ によらず常に 7 m です。ところが各区間の
浮力寄与は、その区間を通るときの煙の密度で計算されます。

煙は壁へ熱を失いながら冷えていきます。経路座標 $s$ に沿って書けば一階の常微分方程式ひとつです。

$$
\frac{\mathrm{d}T}{\mathrm{d}s} = -\frac{U P}{\dot{m} c_p} \left( T - T_\infty \right)
$$

$U$ は総括熱伝達係数、$P$ は煙道の周長、$\dot{m}$ は質量流量、$c_p$ は定圧比熱です。解は指数
減衰で、その減衰長が $\dot{m} c_p / (U P)$ である点があとで効いてきます。

これで損が見えます。下降流路は経路の中で**二番目に熱い**区間です。密度がほぼ最小なので
$(\rho_\infty - \rho)$ がほぼ最大になり、そこへ負の $\mathrm{d}z$ が掛かります。逆に、その 1 m を
取り返す煙突区間の煙は、すでに鋳鉄へ熱を渡して冷えています。高く売って安く買うのではなく、高く
買って安く売っているわけです。

さらに、フランクリン暖炉では下降流路が**部屋の中**にあります。つまり最も熱を奪われる区間でも
あります。暖房効率のために設計したまさにその特徴が、煙突の使うはずだった浮力の予算を先に
消費してしまいます。

## ループひとつで閉じる運動量収支

流量 $\dot{m}$ は浮力と損失が釣り合うところで決まります。煙道を一周する運動量収支です。

$$
\sum_{i} \int_{L_i} (\rho_\infty - \rho) g \, \mathrm{d}z = \int_0^{L} \frac{f}{D} \frac{\dot{m}^2}{2 \rho A^2} \, \mathrm{d}s + K \frac{\dot{m}^2}{2 \rho_e A^2}
$$

左辺が浮力水頭、右辺が摩擦損失と局所損失（曲がり・出口）です。$f$ は Darcy 摩擦係数、$D$ は
煙道直径、$A$ は断面積、$K$ は局所損失係数、$\rho_e$ は出口密度です。管摩擦項の形は Darcy 摩擦の標準形です。密度差が流れを生む側は、[下から温められて自ら回り始める自然対流](/ja/posts/2026-06-04-natural-convection-rayleigh-benard/)と同じ浮力です。

この式は見かけほど素直ではありません。$\dot{m}$ が増えると右辺は $\dot{m}^2$ で増えますが、左辺も
一緒に増えます。流量が多いほど滞留時間が短くなり、煙が熱いまま煙突を通るからです。この
フィードバックのため、残差 $\Delta p - \Delta p_{\text{loss}}$ は $\dot{m}$ について上に凸となり、
根がふたつ現れます。下側の根は不安定で、実際の運転点は**上側の根**です。

## Python で書き出した浮力の帳簿

経路を細かく刻んで温度を行進させ、区間ごとの浮力水頭を別々に集めてから、上側の根を二分法で
求めます。下降高さを 0 から 1.2 m まで掃引します。

```python
import math

G, R_AIR, CP = 9.81, 287.0, 1100.0
T_AMB, P_ATM = 283.0, 101325.0
D_FLUE = 0.15
A_FLUE = math.pi * D_FLUE ** 2 / 4.0
PERIM = math.pi * D_FLUE
F_DARCY, K_MINOR = 0.030, 3.0
U_ROOM, U_STACK = 40.0, 5.0        # 室内の鋳鉄流路 / 煙突の組積 [W/m2K]
Z_TOP, Z_BAFFLE = 7.0, 0.80        # 煙突出口 / バッフル上端 [m]
A_MOUTH, V_SPILL = 0.12, 0.25      # 焚口の開口面積 [m2] / 逆流限界の面速度 [m/s]


def gas_density(T):
    return P_ATM / (R_AIR * T)


def march_flue(mdot, h_down, T_fire, n=120):
    # 上昇 / 下降 / 煙突の三区間をたどり、区間ごとの浮力水頭と総損失を集める
    legs = [(Z_BAFFLE, +1.0, U_ROOM),
            (h_down, -1.0, U_ROOM),
            (Z_TOP - Z_BAFFLE + h_down, +1.0, U_STACK)]
    T, loss, heads = T_fire, 0.0, []
    rho_a = gas_density(T_AMB)
    for L, sgn, U in legs:
        head = 0.0
        if L > 0.0:
            ds = L / n
            for _ in range(n):
                T_new = T_AMB + (T - T_AMB) * math.exp(-U * PERIM * ds / (mdot * CP))
                rho = gas_density(0.5 * (T + T_new))
                head += (rho_a - rho) * G * sgn * ds
                loss += F_DARCY / D_FLUE * 0.5 * mdot ** 2 / (rho * A_FLUE ** 2) * ds
                T = T_new
        heads.append(head)
    loss += K_MINOR * 0.5 * mdot ** 2 / (gas_density(T) * A_FLUE ** 2)
    return heads, loss, T


def solve_mdot(h_down, T_fire, lo=1e-3, hi=0.4, n=100):
    # 浮力 = 損失の上側（安定）の根。根がなければ 0.0
    grid = [lo * (hi / lo) ** (i / (n - 1.0)) for i in range(n)]
    res = []
    for m in grid:
        heads, loss, _ = march_flue(m, h_down, T_fire)
        res.append(sum(heads) - loss)
    k = max(range(n), key=lambda i: res[i])
    if res[k] <= 0.0:
        return 0.0
    a, b = grid[k], grid[-1]
    for _ in range(40):
        m = 0.5 * (a + b)
        heads, loss, _ = march_flue(m, h_down, T_fire)
        a, b = (m, b) if sum(heads) - loss > 0.0 else (a, m)
    return 0.5 * (a + b)


print("h_down[m]  mdot[kg/s]  V_exit[m/s]  draft[Pa]  T_exit[K]")
for i in range(0, 7):
    h = 0.2 * i
    m = solve_mdot(h, 700.0)
    heads, loss, T_e = march_flue(m, h, 700.0)
    print(f"  {h:4.2f}     {m:8.4f}     {m / (gas_density(T_e) * A_FLUE):6.2f}"
          f"     {sum(heads):7.2f}    {T_e:7.1f}")

for h in (0.0, 1.0):
    m = solve_mdot(h, 700.0)
    heads, loss, T_e = march_flue(m, h, 700.0)
    print(f"\nbuoyancy ledger  h_down = {h:.1f} m, mdot = {m:.4f} kg/s")
    for name, val in zip(["rise to baffle", "descent      ", "chimney      "], heads):
        print(f"  {name}  {val:+7.2f} Pa")
    print(f"  net             {sum(heads):+7.2f} Pa   (loss {loss:.2f} Pa)")

mdot_spill = gas_density(T_AMB) * A_MOUTH * V_SPILL
print(f"\nspillage threshold: mdot < {mdot_spill:.4f} kg/s")
for h in (0.0, 1.0):
    lo, hi = 290.0, 700.0
    for _ in range(30):
        mid = 0.5 * (lo + hi)
        lo, hi = (mid, hi) if solve_mdot(h, mid) < mdot_spill else (lo, mid)
    print(f"  h_down = {h:.1f} m -> spills below T_fire = {0.5 * (lo + hi):6.1f} K")
```

帳簿を二行だけ比べれば十分です。下降流路 1 m は直接 $-6.16$ Pa を持っていきます。そして煙突は
1 m 長くなったにもかかわらず、寄与が $+39.15$ から $+38.32$ Pa へ**減りました**。伸びた 1 m を
通る煙がすでにより冷えているからです。ふたつの損を合わせると 6.99 Pa で、正味ドラフトの減少分
7.00 Pa とぴたりと一致します。

帳簿の引き算を欄ごとに残すと、7.00 の出どころが見えます。下降 1 m の浮力は $-6.16$ Pa です。煙突の寄与は $+39.15$ から $+38.32$ へ、$0.83$ Pa 減ります。$6.16+0.83=6.99$ で、正味ドラフトは $44.72-37.72=7.00$ です。0.01 Pa の差は表示桁です。バッフルまでの上昇は $+5.57$ から $+5.56$ で、ほとんどそのままです。損の大半は下降の欄で、残りは長くなった煙突がかえって稼げなくなった分です。

流量も一緒に動きます。$h_d=0$ では 0.0629 kg/s、出口速度 5.59 m/s、出口温度 554.5 K です。$h_d=1.0$ m では 0.0593 kg/s、4.51 m/s、474.2 K です。温度は 80.3 K 下がり、流量は 0.0036 kg/s 減ります。0.2 m ごとの表ではドラフトが 44.72、43.48、42.16、40.76、39.29、37.72、36.05 と、およそ 1.2 から 1.7 Pa ずつ減ります。間隔が少しずつ開くのは、下降が深いほど室内の鋳鉄（$U=40$）で長く冷えるからです。煙突の組積 $U=5$ との 8 倍の差です。

逆流のしきい値 0.0374 kg/s は $\rho_\infty \times 0.12 \times 0.25$ です。10 °C で $\rho_\infty=1.247$ なら $1.247\times 0.12=0.14964$、これに 0.25 を掛けると 0.03741 で、出力の 0.0374 と一致します。この流量を下回る火の温度は 335.2 K から 377.0 K へ上がります。差は 41.8 K で、本文が 42 K と呼んだ余裕です。勢いよく燃える 700 K ではどちらもしきい値の上にあります。火が衰える区間だけで、1 m の下降が先に部屋を煙で満たします。

## 焚口が先に音を上げる — 42 K の余裕が消えた

ドラフトが 44.7 から 37.7 Pa へ減っただけで、ただちに煙が部屋へ出てくるわけではありません。
実際の限界は焚口の開口にあります。火口を通る面速度が概ね 0.25 m/s を下回ると、熱い煙が開口の
上側から漏れ出し始めます。この基準を流量に直すと 0.0374 kg/s です。

出力の最後の二行が、そのしきい値を温度に換算したものです。下降流路がなければ、煙温度が 335 K を
下回るまで持ちこたえます。下降流路が 1 m あると 377 K ですでに音を上げます。**42 K の余裕が
消えた**わけです。

火が勢いよく燃えている間は、どちらもよく吸い込みます。問題は火をつける瞬間と、火が衰える瞬間です。
フランクリン暖炉が「煙る暖炉」として記憶された理由はここにあります。結局 1780 年代に
デイヴィッド・リッテンハウスが下降流路を取り払い、煙道をまっすぐ煙突へ上げる L 字構造に改め、
その形が以後の標準になりました。

## 中立面 — 部屋ひとつで同じ計算が繰り返される

同じ静水圧の理屈は、煙突のない部屋でもそのまま働きます。内外の密度が違えばふたつの静水圧直線の
傾きが変わり、傾きの違う二直線はちょうど一箇所の高さで交わります。その高さが中立面
（neutral plane）$z_n$ です。

$$
\Delta p(z) = p_{\text{out}} - p_{\text{in}} = (\rho_\infty - \rho_i) g \left( z_n - z \right)
$$

開口が上下にふたつあり、面積が $A_1, A_2$、高さが $z_1, z_2$ なら、両開口の質量流量が等しいという
条件から $z_n$ が閉じた形で出てきます。

$$
z_n = \frac{\rho_\infty A_1^2 z_1 + \rho_i A_2^2 z_2}{\rho_\infty A_1^2 + \rho_i A_2^2}
$$

中立面より下では外気が入り、上では室内の空気が出ていきます。下の図で開口の高さと面積比、室温を
変えてみましょう。

上側の開口を大きくすると中立面がそちらへ引き寄せられます。大きな穴は小さな圧力差でも同じ流量を
通せるからです。そして室温を 283 K より下げると、青い直線が反対に傾き、二本の矢印がどちらも
反転します。

## 開口に 0 Pa を載せると中立面がその面に張り付く

圧力境界の基準高さを外すと、開口に `totalPressure = 0` を載せた瞬間、中立面がその面に固定されます。外側の柱の静水圧勾配は、$\rho_\infty g z$ を引いた動圧にしてはじめて残ります。引かなければ解は収束するのに流量が数倍ずれます。上の計算の温度差は 200 K を超え、密度変化は 50% を超えます。$\rho \approx \rho_0 (1 - \beta \Delta T)$ で押すと、浮力そのものが別の値になります。煙突は低マッハの圧縮性か可変密度へ進むべきです。

ループ収支の根がふたつあることも、反復にそのまま出ます。初期流量を 0 の近くに置くと、ソルバーは下側の根へ滑ってドラフトなしに座ります。この多重解は [鍋底の対流から Lorenz 方程式が分かれる場所](/ja/posts/2026-07-09-rayleigh-benard-convection-lorenz/) と同じ構造です。上側の根の近くから始めるか、流量を押さえたまま徐々に緩めるほうが残ります。フランクリンは熱を部屋に留めました。その熱は煙突の予算で、下降 1 m が帳簿から 7.00 Pa を引きました。
