## 被覆を厚くすると電線は冷えるのか、熱くなるのか

半径5 mmの銅線が100 °Cになっています。周囲の空気は25 °Cです。熱損失を減らそうと、断熱材(k = 0.055 W/m·K)を6 mm巻きました。計算すると損失は減りません。むしろ23%増えます。

この記事では、この直観に反する結果がどこから来るのかを扱います。円筒の熱抵抗を二つ足して微分すると、臨界断熱半径(critical insulation radius、熱損失が最大になる断熱層の外半径)$r_{cr} = k/h$ が出てきます。続いて断熱層を有限体積法(FVM)で時間発展させ、この値を数値で確かめます。読み終えれば、断熱仕様を見た瞬間に「この厚さは効くのか」を割り算一回で判断できます。

## 逆向きに動く二つの抵抗

定常状態では、円筒1 mあたりの熱流量 $q'$ は温度差を熱抵抗(温度差を熱流量で割った値)で割ったものです。断熱材を巻くと、抵抗が二つ直列に入ります。一つは断熱層を通る伝導抵抗です。もう一つは外表面から空気へ移る対流抵抗です。

厚くすると伝導抵抗は増えます。しかし外表面積も同時に増えます。表面積が増えると対流抵抗は減ります。和が増えるか減るかは、二つの変化の速さ比べです。

## 円筒の伝導抵抗 ln(r_o/r_i)/2πk はどこから来るか

発熱のない定常円筒伝導の式は次のとおりです。

$$
\frac{1}{r}\frac{d}{dr}\left(k\,r\,\frac{dT}{dr}\right)=0
$$

$r$ は半径座標、$k$ は熱伝導率、$T$ は温度です。二回積分すると $T(r)=C_1\ln r + C_2$ になります。温度は半径に対して対数的に下がります。

熱流量は $q = -k\,(2\pi r L)\,dT/dr$ です。対数分布を代入すると $r$ が約分され、半径によらない定数になります。単位長さあたりにまとめると伝導抵抗が得られます。

$$
R'_{cond}=\frac{\ln(r_o/r_i)}{2\pi k},\qquad R'_{conv}=\frac{1}{2\pi r_o h}
$$

$r_i$ は電線半径、$r_o$ は断熱層の外半径、$h$ は対流熱伝達率です。平板なら伝導抵抗は厚さに比例して増えます。円筒では対数でしか増えません。一方、対流抵抗は $1/r_o$ で減ります。細い円筒では対数の増加は遅く、$1/r_o$ の減少は速いのです。これが逆転の根源です。

## 最小ではなく最大: R'_tot を微分する

全抵抗 $R'_{tot}=R'_{cond}+R'_{conv}$ を $r_o$ で微分してゼロと置きます。

$$
\frac{dR'_{tot}}{dr_o}=\frac{1}{2\pi k\,r_o}-\frac{1}{2\pi h\,r_o^{2}}=0
\;\;\Rightarrow\;\; r_{cr}=\frac{k}{h}
$$

元の講義ノートの問いは「熱損失を最小にする最適厚さはあるか」でした。二階微分は $r_{cr}$ で正です。つまりこの点は抵抗の最小、熱損失の最大です。熱損失を最小にする有限の厚さは存在しません。

例の値を入れると $r_{cr}=0.055/5=0.011$ m です。電線半径5 mmはこれより小さいです。したがって厚さ6 mmまでは、巻くほど熱損失が増えます。電気配線ではこれがむしろ利点になります。薄い被覆が電気絶縁と冷却を同時に担ってくれます。

## コード: 断熱層を有限体積法で時間発展させて定常を確かめる

解析解だけでは物足りません。断熱層を20セルに分け、25 °Cから出発させます。電線側は100 °C固定、外側は対流境界(Robin条件、表面熱流束が表面と空気の温度差に比例)です。陽的時間発展で、電線側の流入熱流量と空気側の流出熱流量が $10^{-4}$ 以内で一致するまで回します。

```python
import math

r_i, k, h = 0.005, 0.055, 5.0          # 電線半径 [m], 断熱材 k [W/m K], h [W/m2 K]
T_i, T_inf = 100.0, 25.0               # 電線 / 空気温度 [C]
rho_c = 4.0e4                          # 断熱材 rho*c [J/m3 K]
N, tol = 20, 1e-4                      # セル数, 定常判定の許容値

def q_line_exact(r_o):
    R = math.log(r_o / r_i) / (2*math.pi*k) + 1.0 / (2*math.pi*r_o*h)
    return (T_i - T_inf) / R

def insulation_march(r_o):
    dr = (r_o - r_i) / N
    rf = [r_i + j*dr for j in range(N + 1)]
    V = [math.pi*(rf[j+1]**2 - rf[j]**2) for j in range(N)]
    G = [2*math.pi*rf[j]*k/dr for j in range(1, N)]          # 内部面コンダクタンス
    G0 = 2*math.pi*r_i*k/(dr/2)                               # 電線 -> セル 0
    Gout = 1/((dr/2)/(2*math.pi*r_o*k) + 1/(2*math.pi*r_o*h)) # セル N-1 -> 空気
    Gsum = [0.0]*N
    for j, g in enumerate(G):
        Gsum[j] += g; Gsum[j+1] += g
    Gsum[0] += G0; Gsum[-1] += Gout
    dt = 0.45*min(rho_c*V[j]/Gsum[j] for j in range(N))       # 陽解法の安定限界
    T = [T_inf]*N; n = 0
    while True:
        dQ = [0.0]*N
        for j, g in enumerate(G):
            f = g*(T[j] - T[j+1]); dQ[j] -= f; dQ[j+1] += f
        q_in = G0*(T_i - T[0]); q_out = Gout*(T[-1] - T_inf)
        dQ[0] += q_in; dQ[-1] -= q_out
        T = [T[j] + dt*dQ[j]/(rho_c*V[j]) for j in range(N)]
        n += 1
        if abs(q_in - q_out) < tol*q_out:
            return n, n*dt, q_out, T[-1]

r_cr = k / h
q_bare = q_line_exact(r_i)
print(f"r_cr = k/h = {r_cr*1e3:.1f} mm,  bare wire q' = {q_bare:.2f} W/m")
print(" r_o[mm]  steps     t[s]   q'_num  q'_exact  err[%]  T_s[C]")
for r_o in [0.007, 0.011, 0.020, 0.030, 0.050]:
    n, t, q, Ts = insulation_march(r_o)
    qe = q_line_exact(r_o)
    print(f"{r_o*1e3:7.0f} {n:6d} {t:8.1f} {q:8.2f} {qe:8.2f} {100*(q-qe)/qe:7.3f} {Ts:7.1f}")
r = r_cr
while q_line_exact(r) > q_bare:
    r += 1e-5
print(f"insulation starts to pay off only beyond r_o = {r*1e3:.1f} mm")
```

## 出力を読む: 23%、32 mm、そして0.653%

最初の数字は23%です。裸の電線の11.78 W/mが $r_{cr}$ で14.49 W/mに増えました。表面温度は67.5 °Cまで下がったにもかかわらずです。温度差は縮みましたが、面積が2.2倍になり対流量が勝ったのです。

二つ目は32 mmです。断熱材が裸の電線より良くなる点です。電線半径の6.4倍、$r_{cr}$ の約3倍です。30 mmでもまだ11.98 W/mで、裸より損失が大きいです。「臨界半径を超えれば十分」というよくある誤解は間違いです。$r_{cr}$ を越えてからも、さらにかなり巻かないと元が取れません。

三つ目は誤差0.653%です。セル数は同じなのに、厚い層ほど誤差が大きくなります。セル内で温度を線形とみなす近似が対数分布からずれるためです。$r_o/r_i$ が10なら、最初のセルと最後のセルの勾配は10倍違います。等間隔格子の代わりに $\ln r$ 基準の等間隔格子を使えば、この誤差はほぼ消えます。

ステップ数にも注目です。7 mmの層は物理時間13秒で定常に達しますが、12,227ステップかかりました。薄い層はセルが小さく、陽解法の安定条件が $\Delta t$ を削ります。拡散スキームのこの限界と、それを回避する試みは [DuFort–Frankel の記事](/ja/posts/2026-11-04-dufort-frankel-negative-temperature/) で扱いました。

## 球なら 2k/h、そして h が定数でないとき

球でも同じ計算をします。伝導抵抗は $(1/r_i-1/r_o)/(4\pi k)$、対流抵抗は $1/(4\pi r_o^2 h)$ です。微分すると $r_{cr}=2k/h$ となり、円筒の2倍です。表面積が $r^2$ で増え、対流抵抗がより速く減るためです。

実際の問題では $h$ は定数ではありません。自然対流の水平円筒では、$h$ はおおよそ直径の $-1/4$ 乗に比例します。半径が大きくなると $h$ がやや下がり、その分 $r_{cr}$ は式より少し大きくなります。放射も等価な $h$ に加わります。表面放射率が高いと $h$ が大きくなり、$r_{cr}$ は小さくなります。棒の上に熱源を複数置く1D伝導コードは [ヒーターのクロージャ記事](/ja/posts/2026-11-23-closure-late-binding-heater-sources/) にあります。そのコードに今回のRobin境界を付ければ、同じ実験がすぐにできます。

CFDでは、この議論は共役熱伝達(conjugate heat transfer、固体の伝導と流体の対流を同時に解く解析)の格子設計につながります。薄い被覆層を格子1〜2個でつぶすと、伝導抵抗が消えたように見えます。上のコードは20セルでも厚い層で0.65%の誤差を出しました。層内の格子は半径方向に引き伸ばして取るほうが安全です。

## 配管断熱の仕様書を受け取ったら、まず k/h を割ってみる

断熱厚さを決める前に $k/h$ を計算します。静止空気なら $h$ は5〜10 W/m²·K、断熱材の $k$ は0.03〜0.06 W/m·Kです。すると $r_{cr}$ は3〜12 mmの範囲です。

蒸気配管のように外径が数十mm以上なら、すでに $r_{cr}$ より大きいです。この場合は巻くほど損失が減ります。落とし穴は信号線、熱電対のシース、細い冷媒管のように半径が数mmの場合です。そのときは裸の円筒より損失が減る半径まで計算して厚さを決める必要があります。今回の例ではその値が32 mmでした。
