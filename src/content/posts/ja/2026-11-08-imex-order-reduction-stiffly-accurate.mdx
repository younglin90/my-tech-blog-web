## 同じ2次IMEXが2つ、片方だけ1次になった

2次のIMEX法を2つ、同じ問題で走らせました。硬さのパラメータ $\varepsilon=1$ では、どちらもきれいな2次でした。$\varepsilon=10^{-6}$ に下げると、片方は2.01のままです。もう片方は0.99になりました。どちらも安定で、解は発散していません。間違っていたのは次数だけです。

本記事はこの差を扱います。Orlando、Boscarino、Russo（2025）は低マッハEuler方程式でこの性質に名前を付けました。漸近保存（AP, asymptotic-preserving）とは区別される漸近精度（AA, asymptotically-accurate）です。読み終えるころには、Butcher表のどの行を見ればよいかがわかります。

## APとAAは別の約束です

低マッハEuler方程式を無次元化すると、運動量式に $\frac{1}{M^2}\nabla p$ が現れます。音波が流れの $1/M$ 倍速いという意味です。IMEX（implicit-explicit、一部の項だけを陰的に解く時間積分）はこの圧力項を陰的に、移流項を陽的に扱います。するとΔtは音速ではなく流速で決まります。

論文の定義はこうです。AP法は安定条件が $M$ に依存せず、$M\to0$ で非圧縮Euler方程式の一貫した離散化になります。AAはさらに一歩進みます。$M\to0$ でも**高次精度を保つ**ことが求められます。APは「発散せず正しい極限へ向かう」という約束です。AAは「その極限へ設計次数で向かう」という約束です。

Δtが $M$ に無関係に大きいと、$\Delta t/M^2$ は巨大になります。これを硬い極限と呼びます。以前の記事 [Orlando–BonaventuraのAP IMEX](/ja/posts/2026-05-03-orlando-bonaventura-ap-imex-nonideal-gas/) では、この領域でステップが生き残ることを見ました。今日の問いは、そのステップが何次かです。

下のシミュレーションで実際に操作してみましょう。1ステップ内の段の値と最終更新値が、$\varepsilon$ に応じてどこへ行くかを示します。

εスイープを再生すると、両方の段の点が黄色い曲線（遅い多様体）に吸い寄せられます。それでも青の最終点は目標の円の近くに残り、オレンジの最終点は段が曲線上にあっても外れます。Δtを小さくして、右のグラフの2つの平坦部がそれぞれどこまで下がるか比べてみてください。

## 試験台：Prothero–Robinson方程式

Euler方程式をまるごと解くと空間誤差が混ざります。そこで硬いODEの標準的な試験問題を使います。

$$
y'(t) = \underbrace{\varphi'(t)}_{\text{explicit}} + \underbrace{\frac{\varphi(t)-y}{\varepsilon}}_{\text{implicit}}, \qquad y(0)=\varphi(0)
$$

$\varphi(t)=\sin t$ は遅い解、$\varepsilon$ は緩和時間です。厳密解は $y=\varphi$ です。

$\varepsilon$ が低マッハ問題の $M^2$ の役割を担います。第2項は解を遅い多様体 $y=\varphi$ へ引き戻します。低マッハの圧力項が密度場を非圧縮状態へ引き戻すのと同じ構造です。第1項は遅い強制項で、陽的に扱います。

比較対象は2つです。1つは論文が2次計算に使ったIMEX-RK(2,2,2)です。Giraldoらによる ARK2 で、$\gamma=1-1/\sqrt2$ のtype II法です。もう1つは共著者RussoがPareschiと作ったIMEX-SSP2(2,2,2)です。対角要素が同じ $\gamma$ のtype I法です。どちらも2次で、どちらも陰的部分は $R(\infty)=0$ です。

## 原因：最終段が答えになっているか

違いは論文の定義3.2にあります。陰的部分の行列 $A$ の最終行が重み $b$ と等しいとき、硬い精度（SA, stiffly accurate）を持つといいます。

$$
a_{sl} = b_l, \qquad l=1,\dots,s
$$

$a_{sl}$ は陰的Butcher行列の最終行、$b_l$ は最終更新の重みです。

SAなら最終更新値は最終段の値と一致します。硬い極限では各段が多様体上へ射影されます。ARK2は $c_s=1$ なので、最終段は $\varphi(t_{n+1})$ の近くに来ます。残る誤差は陽的部分の重みの差による $O(\Delta t^2)$ だけです。

SSP2は $A$ の最終行が $(1-2\gamma,\gamma)$、$b=(1/2,1/2)$ です。最終値は段の傾きの重み付き和から組み立て直されます。硬い極限では、その傾きに $(\varphi-Y)/\varepsilon$ 型の $0/0$ が含まれます。その極限値を混ぜた結果は $\varphi$ を $O(\Delta t)$ までしか再現しません。誤差は蓄積しないので、この局所誤差がそのまま大域誤差になります。

論文はtype IIの落とし穴も指摘しています。type IIでは $A$ が正則ではありません。そのためSAにA安定性を加えても、L安定（硬い成分を1ステップで0に減衰させる性質）は保証されません。追加条件 $\mathbf{e}_{s-1}^\top \hat{\mathcal{A}}^{-1}\mathbf{a}=0$ が必要です。論文で使う手法はすべてSAで、陰的部分はすべてL安定です。

## コード：ε 4通り × Δt 6通り

陰的段は $y$ について線形なので、閉じた式で解きます。誤差は $t=2$ で測ります。

```python
import math

g = 1 - 1/math.sqrt(2)
d = math.sqrt(2)/4
al = (3 + 2*math.sqrt(2))/6
# (A_exp, A_imp, b) — both schemes share b between explicit/implicit parts
SCHEMES = {
    "ARK2  (type II, SA)": ([[0, 0, 0], [2*g, 0, 0], [1-al, al, 0]],
                           [[0, 0, 0], [g, g, 0], [d, d, g]],
                           [d, d, g]),
    "SSP2  (type I, non-SA)": ([[0, 0], [1, 0]],
                              [[g, 0], [1-2*g, g]],
                              [0.5, 0.5]),
}

def pr_imex(scheme, eps, dt, T=2.0):
    """Prothero-Robinson: y' = phi'(t) [explicit] + (phi(t)-y)/eps [implicit], phi=sin"""
    Ae, Ai, b = scheme
    s = len(b)
    ce = [sum(r) for r in Ae]
    ci = [sum(r) for r in Ai]
    y, t = 0.0, 0.0
    for _ in range(int(round(T/dt))):
        FE, FI = [0.0]*s, [0.0]*s
        for l in range(s):
            rhs = y + dt*sum(Ae[l][m]*FE[m] + Ai[l][m]*FI[m] for m in range(l))
            a = dt*Ai[l][l]/eps
            Y = (rhs + a*math.sin(t + ci[l]*dt))/(1 + a)   # linear implicit stage
            FE[l] = math.cos(t + ce[l]*dt)
            FI[l] = (math.sin(t + ci[l]*dt) - Y)/eps
        y += dt*sum(b[l]*(FE[l] + FI[l]) for l in range(s))
        t += dt
    return abs(y - math.sin(t))

dts = [0.1/2**k for k in range(6)]
for name, sc in SCHEMES.items():
    print(name)
    print("  eps    " + "".join(f"{'dt='+format(h,'.4g'):>12}" for h in dts) + "   order")
    for eps in [1.0, 1e-2, 1e-4, 1e-6]:
        e = [pr_imex(sc, eps, h) for h in dts]
        p = math.log2(e[-2]/e[-1])
        print(f"  {eps:<6.0e}" + "".join(f"{x:12.2e}" for x in e) + f"  {p:6.2f}")
```

## Δt < ε になるまでは2次ではない

$\varepsilon=1$ の行は硬くない問題です。両手法とも2.00で、誤差定数だけSSP2が3.7倍大きくなります。

$\varepsilon=10^{-2}$ の行が肝心です。SSP2の誤差は、Δt=0.1から0.025までは2.5倍、3.1倍ずつしか減りません。Δtがεを下回る0.00625以降で、ようやく3.9倍ずつ減ります。次数はΔt/εが1を下回ったときに回復します。

$\varepsilon=10^{-6}$ では、Δtを32分の1にしてもΔt/εは3,000を超えます。SSP2は最後まで1次です。誤差/Δtはほぼ0.29で一定です。ARK2は6.11e-07で終わります。同じΔtで1,480倍の差です。

低マッハコードでは $\varepsilon\approx M^2$ です。$M=10^{-3}$ なら $\varepsilon=10^{-6}$ です。Δtを $M^2$ 以下に下げることは、IMEXを使う理由そのものを捨てることです。したがってSAでない手法は、低マッハ領域では事実上1次の手法です。

ARK2の $\varepsilon=10^{-4}$ 行の次数2.40は、誤差定数がεとともに変わる遷移域の効果です。この次数はそのまま信じず、誤差の大きさを見るべきです。

## 論文がEuler方程式で確かめたこと

論文は2つの時間積分の道筋を比べています。1つは運動量とエネルギーを陰的に連成し、弱非線形の圧力方程式を固定点反復で解くIMEXです。もう1つは硬い依存性を線形化し、非線形方程式を避けるSI-IMEXです。空間はDG（不連続ガラーキン法）です。

移動渦（traveling vortex）の収束試験の結果はすっきりしません。2次IMEX-RK(2,2,2)と1次DGの組み合わせは、$M=10^{-2}$ ですでに精度低下を示しました。4次のARS型・type II法は $M=10^{-3}$ まで期待どおりの次数を出しました。ただしIMEX法は $M=10^{-2}$ で次数低下を経験しています。$M=10^{-4}$ 以下では誤差が飽和しました。

著者らは飽和の原因を断定していません。四角形格子DGの低マッハ不正確性、倍精度の丸め誤差、硬いODE特有の次数低下を、ともに候補として挙げています。時間積分のAAだけで低マッハ精度が片付くわけではない、ということです。

非理想気体では、状態方程式が圧力方程式をさらに非線形にします。SI-IMEXはこの依存性を解析し、線形方程式だけを解くように拡張されました。昨日の [Dumbser–Casulliの弱非線形圧力方程式](/ja/posts/2026-11-07-dumbser-casulli-conservative-semi-implicit/) と同じ問題を、別の側から回避した形です。基準状態線形化を用いた [2流体IMEXソルバー](/ja/posts/2026-11-01-rs-imex-two-fluid-material-cfl/) も同じ系統です。

## IMEXの表を選ぶ前に、最終行を1つ比べる

新しいIMEX法をコードに入れる前に、陰的部分 $A$ の最終行と $b$ を比べましょう。一致しなければ、低マッハ領域で設計次数を期待してはいけません。次に、上の40行ほどのProthero–Robinson試験を $\varepsilon=10^{-6}$ で一度走らせてください。傾き2が出なければ、その表はAPではあってもAAではありません。
