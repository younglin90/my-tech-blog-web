傘のアイコンも絵文字も、雨粒を涙型に描きます。上がとがって下が丸いあの形です。実際にそんな雨粒は存在しません。直径2mmを超える大きな粒は、下が平らなハンバーガーのバンズ形に押しつぶされます。さらに大きくなると中央が袋のように膨らみ、やがて破裂します。

破裂の判定はWeber数ひとつです。1987年にO'RourkeとAmsdenが作ったTAB(Taylor Analogy Breakup)は、その判定をばねの振動に置き換えました。振幅が半径を超える瞬間が破裂です。

Weberのスライダーを12未満に下げると変形$y$は1に届かず、12を超えると最初の山で粒が割れます。

## 雨粒は涙型ではない

落下する液滴の中では、二つの力が競い合っています。ひとつは周囲の空気が表面を叩く**空気力学的な力**です。粒を横に押しつぶします。もうひとつは**表面張力**で、粒を再び球に戻そうとします。

小さな粒では表面張力が圧倒します。だから常に球形です。粒が大きくなるほど、あるいは相対速度が速くなるほど、空気力学的な力が増します。ある瞬間、表面張力が耐えられなくなります。粒は平らになり、膨らみ、ついに細かく砕けます。この過程を**二次分裂(secondary breakup)**と呼びます。ノズルから出た液柱が粒へ切れる[一次分裂](/ja/posts/2026-04-23-plateau-rayleigh-jet-breakup/)とは区別します。

ディーゼルエンジン、ロケットインジェクタ、農薬スプレー。燃料や液体を細かく砕くあらゆる装置が、この現象の上で動いています。粒が小さいほど表面積が大きくなり、蒸発と燃焼が速くなります。

## Weber数 — 慣性が表面張力に勝つ目盛り

二つの力の比をひとつの数にしたものがWeber数(慣性力/表面張力の比)です。

$$
We = \frac{\rho_g\, u_{rel}^2\, d}{\sigma}
$$

$\rho_g$は気体密度、$u_{rel}$は粒と気体の相対速度、$d$は粒の直径、$\sigma$は表面張力です。分子は気体が粒を叩く動圧、分母は表面張力が粒をつかむ力です。

$We$が小さいと粒はおとなしく振動するだけです。$We$がある臨界値を超えると粒は破裂します。実験的に、この**臨界Weber数は約12**付近です。水滴でも燃料滴でも、この値の上では生き残れません。

ここに粘性の役割を測る第二の無次元数が加わります。Ohnesorge数(粘性力/√(慣性・表面張力))です。

$$
Oh = \frac{\mu_l}{\sqrt{\rho_l\, \sigma\, d}}
$$

$\mu_l$は液体の粘度、$\rho_l$は液体密度です。粘性の大きな粒(ハチミツの粒を思い浮かべてください)は変形への抵抗が大きくなります。$Oh$が大きくなると臨界Weber数が上に押し上げられます。破裂しにくいということです。

## Taylorの類推:液滴をばねに吊るす

Weber数は「破裂するかしないか」だけを教えます。「いつ、どう」破裂するかは、粒の変形を時間について解く必要があります。ここでG.I. Taylorの洞察が登場します。振動しながらゆがむ粒を、**ばね・質量・減衰振動子**に対応させたのです。

三つの力をひとつずつ対にします。ばねの復元力は表面張力です。質量にかかる外力は気体の空気力学的な抗力です。減衰力は液体の粘性です。この類推を方程式に移すと、変形量$y$についての2階常微分方程式が得られます。

$$
\frac{d^2 y}{dt^2} = \frac{C_F}{C_b}\frac{\rho_g}{\rho_l}\frac{u^2}{r^2} - \frac{C_k \sigma}{\rho_l r^3}\, y - \frac{C_d \mu_l}{\rho_l r^2}\frac{dy}{dt}
$$

$y$は粒の赤道が膨らんだ度合い(無次元変形)、$r$は半径です。右辺の第一項が空気が押す強制力、第二項が表面張力の復元、第三項が粘性減衰です。係数$C_F, C_k, C_d, C_b$は実験で定める定数で、O'Rourke–Amsdenはそれぞれ$1/3,\ 8,\ 5,\ 1/2$を使いました。

強制力と復元力が釣り合うと、粒はある**定常変形**$y_{eq}$に落ち着きます。

$$
y_{eq} = \frac{C_F}{C_b\, C_k}\, We_r
$$

$We_r$は半径基準のWeber数です。変形がWeber数に正比例するのが要点です。Weberが2倍なら粒も2倍つぶれます。

## 変形パラメータ y と分裂の引き金

TABモデルの規則は単純です。**$y>1$になると粒が分裂します。**$y=1$は、粒の赤道の膨らみが半径と等しくなる瞬間です。振幅がそこまで大きくなると、粒は円形を保てません。

ここで減衰のない振動の性質が重要になります。静止状態から急に強制力を受けると、振動子は定常値$y_{eq}$を通り越して最大$2y_{eq}$まで**オーバーシュート**します。だから$y_{eq}$が0.5でも、つまり定常変形が半分だけでも、最初の振動で$y=1$に達して破裂しうるのです。このオーバーシュートが臨界Weber数を理論的に下げます。

上の曲線で、最初の山が1を超えるかどうかがこのオーバーシュートです。Ohnesorgeがその山を削ります。

## Python — 液滴ひとつを振動させて破裂させる

上の類推をそのままコードに移します。無次元時間で積分し、$y$が1を超える瞬間を探します。

```python
import numpy as np

def weber(rho_g, u, d, sigma):
    """気体慣性と表面張力の比(直径基準)。"""
    return rho_g * u**2 * d / sigma

def tab_breakup(We, Oh, dt=0.01, t_max=40.0):
    """無次元TAB振動子を積分し、分裂時刻(無次元τ)を返す。
    y>1 なら分裂、最後まで y<1 なら None(生存)。"""
    C_F, C_k, C_d, C_b = 1/3, 8.0, 5.0, 1/2
    omega2 = C_k                       # 無次元固有振動数^2
    forcing = (C_F / C_b) * (We / 2)   # 定常変形 y_eq = forcing/omega2 = We/24
    damp = C_d * Oh * np.sqrt(C_k)     # Ohnesorge が減衰を大きくする
    y, ydot, t = 0.0, 0.0, 0.0
    while t < t_max:
        acc = forcing - omega2 * y - damp * ydot
        ydot += acc * dt
        y += ydot * dt
        t += dt
        if y >= 1.0:
            return t                   # 分裂!
    return None

for We in [6, 10, 12, 20, 40]:
    tau = tab_breakup(We, Oh=0.02)
    tag = f"分裂 tau={tau:.2f}" if tau else "生存"
    print(f"We={We:5.1f}  ->  {tag}")
```

出力は臨界Weber数をそのまま見せてくれます。

```text
We=  6.0  ->  生存
We= 10.0  ->  生存
We= 12.0  ->  分裂 tau=1.14
We= 20.0  ->  分裂 tau=0.74
We= 40.0  ->  分裂 tau=0.50
```

はしごのWeber目盛りを上げると、形は振動から袋へ、次いで膜はがれ、破局へと変わります。

We=10まではオーバーシュートが1に届かず生き残ります。We=12で最初の山がぎりぎり線を越えます。Weberが大きくなるほど分裂時刻$\tau$は短くなります。強く叩くほど速く破裂します。物理と正確に一致します。

コード注釈の定数がこの臨界を固定します。$C_F=1/3$、$C_b=1/2$、$C_k=8$なら$y_{eq}=We/24$です。無減衰オーバーシュートの頂上は$2y_{eq}=We/12$です。頂上が1になる場所が$We=12$です。$We=6$なら頂上は$0.5$、$We=10$なら$10/12\approx 0.83$です。どちらも1未満で、出力の生存と合います。$We=20$では$y_{eq}=20/24\approx 0.83$となり、オーバーシュートが加わって$\tau=0.74$へ早まります。$We=40$では$y_{eq}\approx 1.67$で、平衡そのものが1の向こうにあり、$\tau=0.50$まで縮みます。$dt=0.01$なら$\tau=1.14$は114ステップ、$0.50$は50ステップです。減衰は$5\times 0.02\times\sqrt{8}$で、$\sqrt{8}\approx 2.83$なので約$0.283$です。出力の$Oh=0.02$は、12のすぐ上に掛かる薄い値です。

## 分裂モードのはしご

臨界値を超えても、すべての粒が同じように破裂するわけではありません。Weber数が大きくなる順に、分裂の**形**が変わります。振動 → 袋(bag) → 混合(multimode) → 膜はがれ(sheet-thinning) → 破局(catastrophic)です。各段階は実験で明確に区別されるおおよそのWeber境界を持ちます。

上のはしごの低い段が袋です。$We \approx 12$の袋分裂は、粒の中央が薄い膜に膨らんで弾ける、最も低エネルギーの分裂です。$We$が数百に達すると、表面そのものが波のようにはがれる破局分裂になります。TABモデルはもともと袋分裂領域を狙って作られました。だから低Weberでよく合いますが、40MPaを超える高圧噴射のようにWeberが極端に大きい領域では貫通距離を短く見積もる限界があります。その領域にはKHRTや波動分裂モデルを重ねます。

## We=12を粘性なしの境界に固定すると、粘っこい粒を見逃す

無減衰では頂上は$2y_{eq}=We/12$です。$We=12$なら頂上はちょうど1です。出力の$Oh=0.02$は山を少し削っても、$\tau=1.14$で越えます。$Oh$をさらに上げると、同じ12でも1に届かないことがあります。臨界を12に打ち込んでOhnesorgeを外すと、蜂蜜のように粘る液体は生き残るのに、モデルはすでに破裂させています。

変形が大きくなると抗力も一緒に変わります。TABが$y$だけを見て分裂時刻を切ると、[つぶれた粒の抗力](/ja/posts/2026-09-08-droplet-drag-deformation-vaporization/)が軌跡に与える変化は落ちます。$We=40$の$\tau=0.50$はすでに袋領域の外で、その上ではこのばねが貫通距離を短く見ます。
