## aを大きくすれば安全だと思っていた

緩和法(relaxation scheme、非線形項を補助変数に置き換えて線形系として解く手法)には古い常識があります。緩和速度 $a$ は物理音速より大きければよい。大きければ数値拡散が増えるだけで計算は安全だ、というものです。この常識をそのまま陰的圧力ソルバーに持ち込み、$a$ を音速の10倍にしました。結果は拡散ではありませんでした。密度パルスは減衰せず、振幅0.106のまま残りました。同じ時刻のNewton解は $1.5\times10^{-5}$ でした。

本記事ではThomann–Iollo–Puppo(2023)の "Implicit relaxed all Mach number schemes" を1次元に縮めて再現します。読み終えると次の3点が得られます。緩和がなぜNewton反復を消すのか。陰的スキームでは $a$ になぜ下限だけでなく実質的な上限もあるのか。そしてその2つの限界を1行の式で計算する方法です。

## 論文が変えた1行

低マッハ数の圧縮性流れでは、音波は流速より数十倍速く進みます。陽解法は時間刻みを音速に合わせる必要があります。そのため圧力項だけを陰的に解くIMEX(陽的・陰的混合時間積分)分割が標準になりました。[Peluchon(2017)の音響-輸送分割](/ja/posts/2026-05-30-peluchon-acoustic-transport-imex/)も、[昨日のBattisti–Boscheriの線形陰的圧力式](/ja/posts/2026-11-21-linearly-implicit-enthalpy-density-ratio/)も、この系統です。

問題は状態方程式です。圧力 $p(\rho)$ が密度の非線形関数なら、陰的圧力式も非線形になります。毎ステップNewton反復が必要です。Thomann、Iollo、Puppoはここでフラックスには手を付けず、**変数を1つ増やしました**。圧力の位置に補助変数 $w$ を置き、$w$ が線形波動方程式に従うようにします。

$$
\partial_t \rho + \partial_x m = 0,\qquad
\partial_t m + \partial_x w = 0,\qquad
\partial_t w + a^2\,\partial_x m = \frac{p(\rho) - w}{\varepsilon}
$$

$m=\rho u$ は運動量、$w$ は緩和された圧力、$a$ は定数の緩和速度、$\varepsilon$ は緩和時間です。$\varepsilon\to0$ で $w=p(\rho)$ となり元の系に戻ります。この構造自体は[Jin–Xin・Suliciu緩和法](/ja/posts/2026-07-04-jin-xin-suliciu-relaxation-scheme/)で扱ったものと同じです。新しいのは、これを**陰的圧力段**に組み込んだ点です。左辺の3式は定数係数の線形系なので、陰的に解いても線形系1つで済みます。

## Newtonが必要な理由、不要になる理由

まず運動量を物質速度で陽的に移流して $m^*$ を作ります。次に圧力部分を後退オイラーで閉じます。本来の圧力をそのまま使うと次のようになります。

$$
\rho^{n+1} - \Delta t^2\,\delta_{xx}\,p(\rho^{n+1}) = \rho^n - \Delta t\,\delta_x m^*
$$

$\delta_x$、$\delta_{xx}$ は面基準の1階・2階差分です。未知数 $\rho^{n+1}$ が $p(\cdot)$ の中に入っています。だからNewtonです。緩和系では $w^n = p(\rho^n)$ に射影してから $w$ について解きます。

$$
w^{n+1} - a^2\Delta t^2\,\delta_{xx}\,w^{n+1} = p(\rho^n) - a^2\Delta t\,\delta_x m^*
$$

左辺の行列は $a$ と $\Delta t$ だけで決まり、状態に依存しません。一度分解すれば、時間刻みが同じ間は使い回せます。密度はその後 $\rho^{n+1}=\rho^n-\Delta t\,\delta_x m_f^{n+1}$ で陽的に更新されます。

では $a$ は何を代償にするのでしょうか。運動量を切って密度モード1つだけを見ると、1ステップの増幅率が閉じた式で得られます。

$$
G_{N}(\theta) = \frac{1}{1+\nu^2 s^2},\qquad
G_{R}(\theta) = 1 - \frac{c^2}{a^2}\,\frac{z}{1+z},\quad z = \frac{a^2}{c^2}\,\nu^2 s^2
$$

$\nu=c\Delta t/\Delta x$ は音響クーラン数、$s=2\sin(\theta/2)$、$\theta$ は無次元波数です。$G_N$ は線形化Newton、$G_R$ は緩和スキームです。$a=c$ を代入すると $G_R=1/(1+z)=G_N$ になります。**緩和スキームは $a=c$ でNewton 1回と同じです。**

## 2つの限界を式で読む

$\nu$ が大きい陰的領域では、高波数ほど $z\gg1$ です。すると $G_R \to 1 - c^2/a^2$ となります。この1行に両方の限界が入っています。

- **下限**: $|G_R|\le1$ には $c^2/a^2 \le 2$、つまり $a \ge c/\sqrt{2}$ が必要です。陽的緩和の部分特性条件 $a\ge c$ より緩いのは、後退オイラーが減衰を一部補うからです。
- **実質的な上限**: $a\gg c$ なら $G_R\to1$ です。減衰も振動もなく、モードがそのまま残ります。$a=10c$ なら1ステップで1%しか減りません。

なぜこうなるのでしょうか。$a$ が大きいと、$w$ 方程式の陰的拡散 $a^2\Delta t^2\delta_{xx}$ が圧力の擾乱をほぼ平らに消してしまいます。運動量にかかる圧力勾配が消えます。密度は元の質量フラックス分しか動きません。結果として、圧力が密度を引き戻す力が $c^2/a^2$ 倍に弱まります。陽的スキームでは大きな $a$ は「にじみ」でした。陰的スキームでは「凍結」です。

## コード: 同じパルスを3通りで — 陽的、Newton、緩和

1次元等エントロピーEuler($p=\rho^{1.4}$、周期境界)で、背景マッハ数0.05で流れる密度パルス(振幅0.2)を置きます。流体が領域の1/4を通過するまで計算します。陽的Rusanovは音速基準のCFL 0.9、2つの陰的スキームは物質速度基準のCFL 0.9です。緩和スキームは $a/c_{\max}$ を0.5から10まで振り、Newton解とのL2差を測ります。

```python
import numpy as np
np.seterr(all="ignore")

# 1次元等エントロピーEuler: p = rho^gamma、周期境界、低マッハ音響パルス
N, gam = 200, 1.4
dx = 1.0 / N
x = (np.arange(N) + 0.5) * dx
c0 = np.sqrt(gam)
A0 = 0.2                             # 密度パルスの振幅
u0 = 0.05 * c0                       # 背景マッハ数 0.05
T = 0.25 / u0                        # 流体が領域の1/4を通過する時間

def pres(r):
    return r**gam

def cyclic_solve(lo, di, up, b):
    # 周期三重対角: Thomas + Sherman-Morrison
    n = len(b); g = -di[0]
    d = di.copy(); d[0] -= g; d[-1] -= lo[0] * up[-1] / g
    def thomas(rhs):
        cp = np.zeros(n); dp = np.zeros(n)
        cp[0] = up[0] / d[0]; dp[0] = rhs[0] / d[0]
        for i in range(1, n):
            m = d[i] - lo[i] * cp[i-1]
            cp[i] = up[i] / m; dp[i] = (rhs[i] - lo[i] * dp[i-1]) / m
        y = np.zeros(n); y[-1] = dp[-1]
        for i in range(n - 2, -1, -1):
            y[i] = dp[i] - cp[i] * y[i+1]
        return y
    uvec = np.zeros(n); uvec[0] = g; uvec[-1] = up[-1]
    y = thomas(b); q = thomas(uvec)
    vfac = (y[0] + lo[0] * y[-1] / g) / (1 + q[0] + lo[0] * q[-1] / g)
    return y - vfac * q

def advect_m(r, m, dt):
    # 物質速度だけを見る陽的Rusanov: (rho u^2)_x
    u = m / r; f = m * u
    s = np.maximum(np.abs(u), np.abs(np.roll(u, -1)))
    F = 0.5 * (f + np.roll(f, -1)) - 0.5 * s * (np.roll(m, -1) - m)
    return m - dt / dx * (F - np.roll(F, 1))

def face_mom(ms, w, dt):
    mf = 0.5 * (ms + np.roll(ms, -1))
    return mf - dt / dx * (np.roll(w, -1) - w)

def relaxed_step(r, m, dt, a):
    # Jin-Xin緩和: w_t + a^2 m_x = 0 を陰的に -> 線形・定数係数・1回の求解
    ms = advect_m(r, m, dt)
    k = (a * dt / dx)**2
    mf0 = 0.5 * (ms + np.roll(ms, -1))
    rhs = pres(r) - a**2 * dt / dx * (mf0 - np.roll(mf0, 1))
    w = cyclic_solve(np.full(N, -k), np.full(N, 1 + 2 * k), np.full(N, -k), rhs)
    mf = face_mom(ms, w, dt)
    rn = r - dt / dx * (mf - np.roll(mf, 1))
    mn = 0.5 * (mf + np.roll(mf, 1))   # 面運動量をセルへ平均
    return rn, mn, 1

def newton_step(r, m, dt, tol=1e-10):
    # 本来の非線形圧力 p(rho^{n+1}) をそのまま陰的に -> Newton反復
    ms = advect_m(r, m, dt)
    mf0 = 0.5 * (ms + np.roll(ms, -1))
    b = r - dt / dx * (mf0 - np.roll(mf0, 1))
    k = (dt / dx)**2
    rn = r.copy(); it = 0
    while True:
        p = pres(rn)
        res = rn - k * (np.roll(p, -1) - 2 * p + np.roll(p, 1)) - b
        if np.max(np.abs(res)) < tol:
            break
        dp = gam * rn**(gam - 1)
        lo = -k * np.roll(dp, 1); up = -k * np.roll(dp, -1)
        rn = rn - cyclic_solve(lo, 1 + 2 * k * dp, up, res)
        it += 1
        if it > 50:
            return rn * np.nan, ms, it
    w = pres(rn)
    mf = face_mom(ms, w, dt)
    mn = 0.5 * (mf + np.roll(mf, 1))   # 面運動量をセルへ平均
    return rn, mn, it

def rusanov_acoustic_step(r, m, dt):
    u = m / r; p = pres(r); c = np.sqrt(gam * r**(gam - 1))
    U = np.array([r, m]); F = np.array([m, m * u + p])
    s = np.maximum(np.abs(u) + c, np.roll(np.abs(u) + c, -1))
    Fh = 0.5 * (F + np.roll(F, -1, axis=1)) - 0.5 * s * (np.roll(U, -1, axis=1) - U)
    U = U - dt / dx * (Fh - np.roll(Fh, 1, axis=1))
    return U[0], U[1], 0

def run(kind, cfl, a_ratio=1.0):
    r = 1 + A0 * np.exp(-((x - 0.5) / 0.05)**2)
    m = r * u0
    mass0 = r.sum() * dx
    cmax = np.sqrt(gam * r.max()**(gam - 1))
    if kind == 'explicit':
        dt = cfl * dx / (u0 + cmax)
    else:
        dt = cfl * dx / u0
    nst = int(np.ceil(T / dt)); dt = T / nst
    its = 0
    for _ in range(nst):
        if kind == 'explicit':
            r, m, i = rusanov_acoustic_step(r, m, dt)
        elif kind == 'newton':
            r, m, i = newton_step(r, m, dt)
        else:
            r, m, i = relaxed_step(r, m, dt, a_ratio * cmax)
        if not np.all(np.isfinite(r)):
            return dict(steps=nst, solves=its, amp=np.nan, mass=np.nan, r=r)
        its += i
    return dict(steps=nst, solves=its, amp=r.max() - r.mean(), mass=abs(r.sum() * dx - mass0), r=r)

print(f"M0 = 0.05, N = {N}, A0 = {A0}, T = {T:.3f} (flow moves L/4)")
ex = run('explicit', 0.9)
nw = run('newton', 0.9)
print(f"{'scheme':<16}{'steps':>7}{'lin.solves':>12}{'amp':>11}{'|dmass|':>11}")
print(f"{'explicit':<16}{ex['steps']:>7}{'-':>12}{ex['amp']:>11.2e}{ex['mass']:>11.1e}")
print(f"{'implicit Newton':<16}{nw['steps']:>7}{nw['solves']:>12}{nw['amp']:>11.2e}{nw['mass']:>11.1e}")
print()
print(f"{'a/c_max':<9}{'solves':>8}{'amp':>11}{'L2 vs Newton':>15}")
for ar in [0.5, 0.7, 0.8, 0.9, 1.0, 1.5, 3.0, 10.0]:
    rx = run('relaxed', 0.9, ar)
    d = np.sqrt(np.mean((rx['r'] - nw['r'])**2))
    print(f"{ar:<9}{rx['solves']:>8}{rx['amp']:>11.2e}{d:>15.2e}")
```

## 表を読む: 102と56、0.5の発散、10の0.106

**ステップ数.** 陽的は1208ステップ、陰的は56ステップです。比21.6は $(u_0+c)/u_0$ とほぼ同じです。代わりに陰的スキームは2つとも音響パルスを $10^{-5}$ レベルまで消します。陽的は $2.84\times10^{-2}$ を残します。音響を捨てて時間刻みを買う、低マッハ陰的手法の取引です。

**線形求解回数.** Newtonは56ステップで102回、1ステップあたり1.8回です。パルスが減衰すると残差がすぐ小さくなり、1回で終わるステップが多くなります。緩和は正確に1ステップ1回です。1次元では1.8倍の差にすぎません。しかし緩和の行列は定数です。3次元非構造格子で分解や前処理を一度作って使い回せることが本当の利点です。

**$a/c_{\max}$ 0.9〜1.0.** Newtonとの L2 差は $3\sim5\times10^{-6}$ です。線形解析の通り、$a\approx c$ なら2つのスキームはほぼ同じです。残る差は $c$ が場所ごとに違うことから生じます。

**0.5と0.7.** $c^2/a^2=4$ なので $G_R\to-3$ です。5ステップで発散しました。0.7は $c_{\max}$ 基準では境界 $1/\sqrt2\approx0.707$ より下です。しかしパルスの外の音速は $c_{\max}$ の0.93倍なので、実効的な $a/c$ は0.75になり、生き残りました。その代わりL2差は $2.6\times10^{-4}$ に増えました。

**3と10.** $a=3c_{\max}$ でL2は $9.2\times10^{-5}$ とNewtonから離れます。$a=10c_{\max}$ では振幅が0.106です。$G_R\approx0.99$ を56回掛けると $0.2\times0.99^{56}\approx0.11$。表の数字を1行の式がほぼそのまま当てています。

## 論文とこの1次元おもちゃとの距離

この再現は論文の構造だけを借りています。違いを明記しておきます。

- 論文は完全Euler、硬化気体(stiffened gas)、弾性材料まで扱います。ここではエネルギー式のない等エントロピー系です。
- 論文は多次元で圧力の線形楕円型方程式を分離して解きます。ここでは周期三重対角系1つです。
- 面運動量をセルへ平均する段階は本記事の簡略化です。広い中心勾配でセル運動量を更新すると偶奇モードが育ち、150ステップ前に発散しました。
- 論文は $a$ を局所最大音速付近に取ります。本記事の上限の話は、その選択がなぜ妥当かを補足する説明です。

## 緩和速度aを決める場所

陰的緩和ソルバーに $a$ を入れるときは、まず $G_R\to1-c^2/a^2$ の1行を計算します。下限は $c_{\max}/\sqrt2$、余裕を持たせた実務上の下限は $c_{\max}$ です。上限に決まった値はありません。ただし $c^2/a^2$ が1ステップあたりの減衰率だという事実は残ります。$a$ を $c_{\max}$ の1〜1.5倍に置けば、線形系1つでNewtonと同じ答えが得られます。それ以上大きくするのは安全余裕ではありません。圧力を働かせなくしているだけです。
