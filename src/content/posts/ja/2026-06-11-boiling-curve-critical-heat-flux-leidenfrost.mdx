1934年の東京で、抜山はニクロム線の電流を上げながら水中の気泡を見ていました。気泡が最も激しいときと、線が溶けて切れるときのあいだを、彼は何も見ていません。その空白では、熱流束は過熱度と一緒には上がりません。

Temperature control で ΔTe のスライダーを動かすと作動点が曲線に沿って歩き、Heat-flux control に切り替えると同じ熱流束に壁温が二つに分かれます。

熱流束を山の上へ押すと、点は核沸騰の枝から膜沸騰の枝へ飛びます。抜山の線が溶けた場所がその跳躍です。

## 沸騰曲線 — 一枚のグラフに収まる四つの領域

沸騰は固体と液体の境界で起きる蒸発です。壁の熱流束は次のように書きます。

$$q'' = h\,(T_s - T_{sat}) = h\,\Delta T_e$$

$T_s$ は壁温、$T_{sat}$ は飽和温度（水、1気圧、100°C）、$\Delta T_e$ はその差である過熱度です。$h$ は対流熱伝達率です。

過熱度を上げれば $q''$ も単調に上がりそうです。対数-対数で描くと、四つの区間が順に出ます。

- **自由対流**（$\Delta T_e \lesssim 5$°C）: 気泡はほとんどありません。浮力が作る自然対流が熱を運びます。
- **核沸騰**（$5 \lesssim \Delta T_e \lesssim 30$°C）: 気泡が核生成点から湧きます。$q''$ が最も急です。
- **遷移沸騰**（$30 \lesssim \Delta T_e \lesssim 120$°C）: 蒸気膜が壁を部分的に覆い始めます。$q''$ は下がります。
- **膜沸騰**（$\Delta T_e \gtrsim 120$°C）: 連続した蒸気膜が壁を覆います。放射が加わり $q''$ は再び上がります。

先の点が歩く曲線が、この四つの区間です。熱流束を固定すると遷移区間は安定な作動点にならず、点は核沸騰か膜沸騰のどちらかへ跳びます。

## 核沸騰 — 気泡が熱を汲み上げる

核沸騰がよく冷やす理由は気泡そのものより、気泡が去った場所へ冷たい液体が入る撹拌です。壁近くの液体が入れ替わり続けます。

Rohsenow はこの区間の熱流束を次のように書きました。

$$
q''_s = \mu_l\, h_{fg}\sqrt{\frac{g(\rho_l - \rho_v)}{\sigma}}
\left(\frac{c_{p,l}\,\Delta T_e}{C_{s,f}\,h_{fg}\,Pr_l^{\,n}}\right)^3
$$

$\mu_l$ は液体の粘性、$h_{fg}$ は蒸発潜熱、$\rho_l,\rho_v$ は液体と蒸気の密度、$\sigma$ は表面張力、$c_{p,l}$ は液体の比熱、$Pr_l$ は液体の Prandtl 数です。$C_{s,f}$ は表面と液体の組合せの実験定数です。水と白金は 0.013 です。

$q''_s$ は $\Delta T_e$ の三乗で上がります。過熱度を少し上げても熱流束は大きく跳びます。原子炉炉心、CPU の水冷、ボイラがこの狭い幅を狙います。潜熱が拡散で抜ける道は沸騰と別です。[同じ潜熱が拡散で乾いていく場合](/ja/posts/2026-07-30-evaporation-source-term-d2-law-lee-model/) は、壁が飽和温度より下でも進みます。

## 限界熱流束 — Zuberが予測した崖

三乗は長く続きません。気泡が密になりすぎると互いにくっついて壁を覆い、液体が壁に触れる道が塞がります。その直前で $q''$ が最大になります。これが限界熱流束（CHF）です。水は1気圧で 1 MW/m² を超えます。

Zuber は、蒸気柱が Kelvin–Helmholtz で不安定になる条件から CHF を書きました。

$$
q''_{max} \approx 0.149\, h_{fg}\, \rho_v
\left[\frac{\sigma\, g\,(\rho_l - \rho_v)}{\rho_v^2}\right]^{1/4}
$$

記号は前と同じで、$\rho_v$ は蒸気密度です。壁温も表面の材質もこの式にはありません。CHF は流体の物性だけで決まります。

熱流束を制御する加熱で CHF を超えると、作動点は核沸騰から膜沸騰へ跳びます。同じ熱流束を膜沸騰で持つには、壁温が数百度上がらなければなりません。金属はその前に溶けます。抜山が見た跳躍がこれです。

## 膜沸騰とライデンフロスト

遷移沸騰の終わりで $q''$ が再び最小になる点が、ライデンフロスト点です。その先では連続した蒸気膜が壁を覆い、液体は壁に触れません。熱は蒸気を横切る伝導と放射だけで伝わります。蒸気の熱伝導率は液体よりずっと低いです。

適度に熱いフライパンでは水滴が沸騰してすぐ消えます。とても熱いフライパンでは、水滴が自分の蒸気膜の上に浮いて、より長く残ります。

水平円柱の膜沸騰の熱伝達は次の形です。

$$
\overline{Nu}_D = C\left[\frac{g(\rho_l-\rho_v)\,h'_{fg}\,D^3}{\nu_v\, k_v\,(T_s - T_{sat})}\right]^{1/4}
$$

$D$ は直径、$\nu_v, k_v$ は蒸気の動粘性と熱伝導率、$C$ は形状の定数（水平円柱 0.62、球 0.67）です。$h'_{fg} = h_{fg} + 0.8\,c_{p,v}(T_s - T_{sat})$ は蒸気の過熱を補正した潜熱です。過熱度が分母の 1/4 乗にあるので、壁をさらに熱くしても $h$ はむしろ鈍くなります。

## Python — 沸騰曲線を自分で描く

水の1気圧の物性で、Rohsenow の核沸騰と Zuber の CHF を同じ表に載せます。

```python
import numpy as np

# 水、1気圧の飽和物性
g    = 9.81       # m/s^2
rho_l = 957.9     # kg/m^3
rho_v = 0.5956
h_fg  = 2257e3    # J/kg
sigma = 0.0589    # N/m
mu_l  = 279e-6    # N.s/m^2
cp_l  = 4217.0    # J/kg.K
Pr_l  = 1.76
Csf, n = 0.013, 1.0   # 水-白金

def rohsenow_nucleate_flux(dTe):
    """Rohsenow 核沸騰熱流束 q'' (W/m^2)."""
    bracket = np.sqrt(g * (rho_l - rho_v) / sigma)
    ja = cp_l * dTe / (Csf * h_fg * Pr_l**n)
    return mu_l * h_fg * bracket * ja**3

def zuber_critical_heat_flux():
    """Zuber 限界熱流束 (W/m^2)."""
    return 0.149 * h_fg * rho_v * (
        sigma * g * (rho_l - rho_v) / rho_v**2) ** 0.25

chf = zuber_critical_heat_flux()
print(f"CHF (Zuber)      = {chf/1e6:.3f} MW/m^2")

# 核沸騰の枝をスキャンしてCHFに達する過熱度を探す
for dTe in [5, 10, 20, 30, 40]:
    q = rohsenow_nucleate_flux(dTe)
    flag = "  <-- CHF 超過 (Rohsenow 無効)" if q > chf else ""
    print(f"dTe={dTe:3d} C : q''={q/1e6:6.3f} MW/m^2{flag}")
```

実行結果は次のとおりです。

```text
CHF (Zuber)      = 1.259 MW/m^2
dTe=  5 C : q''= 0.017 MW/m^2
dTe= 10 C : q''= 0.137 MW/m^2
dTe= 20 C : q''= 1.094 MW/m^2
dTe= 30 C : q''= 3.692 MW/m^2  <-- CHF 超過 (Rohsenow 無効)
```

表面温度のスライダーを 90°C から 400°C へ動かすと、水滴が壁に付いて沸騰する状態から、蒸気膜の上に浮く境界が移動します。

130°C 付近では泡を吹きながら早く消え、200°C を超えると、より熱いのに長く残ります。表の 30°C の行はすでに CHF を超えた核沸騰の端で、このスライダーの膜は同じ曲線の反対側です。

10°C の行の 0.137 を八倍すると 1.096 です。20°C の行は 1.094 です。二十七倍なら 3.699 で、30°C の行は 3.692 です。過熱度を二倍、三倍したときの三乗が、表の中で合っています。

熱流束を過熱度で割ると $h$ が出ます。5°C で 3400 W/m²K、10°C で 13700、20°C で 54700 です。過熱度が二倍になると $h$ は四倍になります。$q''$ が三乗なら $h$ は二乗です。

CHF の 1.259 と 20°C の 1.094 の比は 1.15 です。その三乗根は約 1.048 で、$20\times 1.048$ は 21°C の近くです。Rohsenow が Zuber の天井に触れる場所は 30°C の行ではなく、約 21°C です。30°C の 3.692 は 1.259 の 2.93 倍です。その行は、式が自分の範囲を出たあとに印字された数字です。

5°C の行の 0.017 を八倍すると 0.136 です。10°C の行は 0.137 なので、差は 0.001 です。10 を 5 で割った熱流束の比は 8.06 で、2 の三乗は 8 です。20 を 10 で割ると 7.99 です。30 を 20 で割ると 3.375 で、1.5 の三乗と同じです。温度比が 2 でなくても、三乗は印字された三桁まで残ります。

0.017 は CHF の 1.35% です。0.137 は 10.9% です。30°C の行を過熱度で割った $h$ は 123067 W/m²K です。54700 に 2.25 を掛けると 123075 です。2.25 は 1.5 の二乗です。印字された三桁では二乗が合います。その $h$ は天井を超えた式の数字です。

Rohsenow が 30°C で CHF を超えるのは、式が間違っているからではありません。適用範囲を外れました。実際の曲線は CHF で折れて下がります。二つの式を一緒に使うときは、1.259 MW/m² を天井として強制する必要があります。

## 無次元数の言葉 — JakobとBond

**Jakob 数**は、液体が受け取る顕熱と潜熱の比です。

$$Ja = \frac{c_{p,l}\,\Delta T_e}{h_{fg}}$$

$Ja$ が小さいと、潜熱が顕熱を圧倒します。水は潜熱が大きいので、沸騰では $Ja$ が小さくなります。Rohsenow の括弧の中の項が、この $Ja$ です。

**Bond 数**は、浮力と表面張力の比です。

$$Bo = \frac{g(\rho_l - \rho_v)\,L^2}{\sigma}$$

気泡の大きさ $L$ は、この二つの釣り合いから出ます。直径は $D_b \propto \sqrt{\sigma / [g(\rho_l-\rho_v)]}$ で決まります。CHF の式の四乗根の中に表面張力と密度差が入る理由です。気泡の大きさと離脱の頻度が、熱流束の上限を決めます。

## すでに範囲を出た30°Cの行を設計点にした失敗

20°C ですでに天井の 87% で、二つの式が出会うのは約 21°C です。30°C の行の 3.692 を核沸騰の設計熱流束として書くと、壁はその熱流束を核沸騰では受け取れません。作動点は膜沸騰へ跳び、同じ $q''$ を持つ壁温が数百度上がります。

蒸気膜が壁を覆ったあとでも、摩擦から熱流束を読めるかは別の問いです。[壁面摩擦だけで熱流束を推定する相似](/ja/posts/2026-06-23-reynolds-analogy-friction-heat/) は、液体が壁に触れているときの話です。膜が挟まるとその相似が残るか、この表は言いません。
