## Δtを20倍にしたら、棒の中央が氷点下に下がった

両端を0度に固定した棒に、$\sin x$ 形の温度を置きました。熱方程式なので答えは決まっています。形はそのままで、振幅だけが $e^{-\alpha t}$ で減ります。どこでも0を下回ることはありません。

FTCS(前進時間・中心空間の陽解法)は、$r=\alpha\Delta t/\Delta x^2$ が0.5を超えると発散します。そこで「無条件安定な陽解法」と呼ばれるDuFort–Frankelに切り替えました。$r$ を0.5から10へ、時間刻みを20倍にしました。計算は発散しませんでした。ところが $t=1.48$ で中央の温度が $-0.83$ になりました。厳密解は $+0.052$ です。

この記事では、その負の値がどこから来るのかを追います。先に結論を言うと、DuFort–Frankelは大きな $\Delta t$ では熱方程式を解いていません。減衰波動方程式を解いています。読み終えるころには、このスキームの本当の $\Delta t$ 上限を1行で計算できます。

## 3つのスキーム、同じ棒

題材は金文相(キム・ムンサン)教授の数値流体力学の課題HW#2です。格子21点、$\alpha=2$、初期条件 $\sin x$ で3つのスキームを比べます。

$$
u_i^{n+1}=u_i^n+r\left(u_{i+1}^n-2u_i^n+u_{i-1}^n\right)
$$

これがFTCSです。$u_i^n$ は格子点 $i$、時間層 $n$ の温度です。最も単純で、$r\le 1/2$ でのみ安定です。

DuFort–FrankelはLeapfrog(前後2つの時間層を使う中心時間差分)から出発します。Leapfrogを拡散に使うと、どの $r$ でも不安定です。そこで中心点 $u_i^n$ を前後の平均 $(u_i^{n+1}+u_i^{n-1})/2$ に置き換えます。

$$
(1+2r)\,u_i^{n+1}=(1-2r)\,u_i^{n-1}+2r\left(u_{i+1}^n+u_{i-1}^n\right)
$$

依然として陽解法なので、行列を解く必要はありません。ただし時間層が3つ必要です。最初の1ステップは別の方法で作らなければなりません。元の課題ではFTCSで1ステップ先に進めていました。

Laasonenは完全陰解法(BTCS)です。毎ステップ三重対角行列を解きます。

$$
-r\,u_{i-1}^{n+1}+(1+2r)\,u_i^{n+1}-r\,u_{i+1}^{n+1}=u_i^n
$$

下のシミュレーションで実際に操作してみましょう。左はDuFort–Frankelの増幅係数の2つの根、右は1つのFourierモードの振幅がステップごとにどう変わるかです。

$r$ スライダーを3.2付近でゆっくり上げてみてください。2つの根が実軸上で出会い、上下に分かれます。その瞬間から緑の曲線が0を横切って負に下がります。2つの根は常に点線の円の内側にあります。だから発散はしません。

## 安定なのになぜ間違うのか:増幅係数の2つの根

$u_i^n=G^n e^{\mathrm{i}\,i\theta}$ を代入すると $G$ の2次式が得られます。$\theta=k\Delta x$ はモードの格子あたりの位相です。

$$
G_\pm=\frac{2r\cos\theta\pm\sqrt{1-4r^2\sin^2\theta}}{1+2r}
$$

根号の中が負になると、2つの根は共役複素数になります。このとき大きさは $\theta$ によりません。

$$
|G_\pm|^2=\frac{2r-1}{2r+1}<1
$$

どの $r$ でも1より小さくなります。これが「無条件安定」のすべてです。しかし複素数の $G$ は大きさを縮めるだけではありません。ステップごとに位相を回します。振幅は $\rho^n\cos(n\varphi+\psi)$ の形で振動します。熱方程式のモードは振動しません。単調に減衰するだけです。

根が複素数に変わるしきい値は $2r\sin\theta=1$ です。基本モード $\theta=\Delta x=\pi/20$ なら $r^*=1/(2\sin\theta)=3.196$ です。短い波長ほど $\sin\theta$ が大きく、早く振動し始めます。

しきい値より下でも安全ではありません。$r=2$ で基本モードの $|G_+|$ は0.9462です。厳密な減衰率は $e^{-\alpha\Delta t}=0.9518$ です。1ステップごとに0.6%ずつ余分に冷えます。60ステップで30%になります。

## 修正方程式:熱方程式の中に波動項が隠れている

理由は打ち切り誤差にあります。DuFort–FrankelをTaylor展開すると、実際に解いている式(修正方程式、modified equation)が出てきます。

$$
u_t=\alpha u_{xx}-\alpha\left(\frac{\Delta t}{\Delta x}\right)^2u_{tt}+\frac{\alpha\Delta x^2}{12}u_{xxxx}+\cdots
$$

問題は $u_{tt}$ 項です。係数が $(\Delta t/\Delta x)^2$ です。$\Delta t$ と $\Delta x$ を一緒に小さくしても、この比が一定なら消えません。DuFort–Frankelが熱方程式と整合(consistent)するのは $\Delta t/\Delta x\to 0$ のときだけです。これを条件付き整合性と呼びます。

$\lambda=\Delta t/\Delta x$ とおくと、この式は電信方程式(telegraph equation、減衰波動方程式)になります。

$$
\alpha\lambda^2u_{tt}+u_t=\alpha u_{xx}
$$

波の速さは $1/\lambda=\Delta x/\Delta t$ です。1ステップで1セルです。陽解法が情報を運べる最大の速さと同じです。モード $e^{\mathrm{i}kx-\sigma t}$ を入れると $\alpha\lambda^2\sigma^2-\sigma+\alpha k^2=0$ となります。$\sigma$ が実数であるには $4\alpha^2\lambda^2k^2\le 1$、つまり $\Delta t\le\Delta x/(2\alpha k)$ が必要です。これを $r$ で書くと $r\le 1/(2k\Delta x)=3.18$ です。増幅係数の3.196とほぼ同じです。2つの解析が同じ境界を指しています。

## コード:sin xの棒をr = 0.5, 2, 5, 10で

元の課題の設定のまま $t\approx1.5$ まで進めます。3つのスキームを同じ $r$ で回し、中央温度、最大誤差、計算中の中央温度の最小値を出力します。

```python
import numpy as np

ALPHA, PEAK, NX = 2.0, 1.0, 21          # 元の課題HW#2と同じ設定
DX = np.pi / (NX - 1)
X = np.linspace(0.0, np.pi, NX)
T_END = 1.5

def exact_u(t):
    return PEAK * np.exp(-ALPHA * t) * np.sin(X)

def ftcs_heat(u, r):
    v = u.copy()
    v[1:-1] = u[1:-1] + r * (u[2:] - 2 * u[1:-1] + u[:-2])
    return v

def laasonen_heat(u, r):
    n = NX - 2                           # 内部点の三重対角 (Thomas)
    a = np.full(n, -r); b = np.full(n, 1 + 2 * r); c = np.full(n, -r)
    d = u[1:-1].copy()
    for i in range(1, n):
        m = a[i] / b[i - 1]
        b[i] -= m * c[i - 1]; d[i] -= m * d[i - 1]
    s = np.zeros(n); s[-1] = d[-1] / b[-1]
    for i in range(n - 2, -1, -1):
        s[i] = (d[i] - c[i] * s[i + 1]) / b[i]
    v = np.zeros_like(u); v[1:-1] = s
    return v

def dufort_step(u_old, u, r):
    v = np.zeros_like(u)
    v[1:-1] = ((1 - 2 * r) * u_old[1:-1] + 2 * r * (u[2:] + u[:-2])) / (1 + 2 * r)
    return v

def march_heat(method, r, start="ftcs"):
    dt = r * DX**2 / ALPHA
    nstep = max(2, int(round(T_END / dt)))
    u = PEAK * np.sin(X)
    hist = [u[NX // 2]]
    if method == "dufort":
        u_old = u
        u = ftcs_heat(u, r) if start == "ftcs" else exact_u(dt)
        hist.append(u[NX // 2])
        for _ in range(nstep - 1):
            u_old, u = u, dufort_step(u_old, u, r)
            hist.append(u[NX // 2])
    else:
        step = ftcs_heat if method == "ftcs" else laasonen_heat
        for _ in range(nstep):
            u = step(u, r)
            hist.append(u[NX // 2])
    t = nstep * dt
    err = np.max(np.abs(u - exact_u(t)))
    return t, nstep, u[NX // 2], exact_u(t)[NX // 2], err, np.array(hist)

print(f"dx = {DX:.5f}, r* (DF fundamental mode turns complex) = {1/(2*np.sin(DX)):.3f}")
print(" r     method    steps   t      u_mid     exact     max_err   min(u_mid) over run")
for r in [0.5, 2.0, 5.0, 10.0]:
    for m in ["ftcs", "dufort", "laasonen"]:
        t, n, um, ue, e, h = march_heat(m, r)
        if not np.isfinite(e) or e > 1.0:
            print(f"{r:4.1f}  {m:9s} {n:5d}  {t:5.3f}   BLOWUP (|u|max = {np.max(np.abs(h)):.1e})")
            continue
        print(f"{r:4.1f}  {m:9s} {n:5d}  {t:5.3f}  {um:8.5f}  {ue:8.5f}  {e:.2e}  {h.min():+.4f}")
print()
print("DuFort-Frankel per-step |G| of the fundamental mode vs exact decay per step")
for r in [0.5, 2.0, 3.0, 3.2, 5.0, 10.0]:
    dt = r * DX**2 / ALPHA
    th = DX
    disc = 1 - 4 * r * r * np.sin(th)**2
    G = (2 * r * np.cos(th) + np.sqrt(complex(disc))) / (1 + 2 * r)
    print(f"r = {r:4.1f}  |G| = {abs(G):.4f}  exact = {np.exp(-ALPHA*dt):.4f}  "
          f"phase/step = {np.degrees(np.angle(G)):6.2f} deg")
print()
print("DuFort-Frankel start-up: FTCS first step vs exact first step (r = 5)")
for s in ["ftcs", "exact"]:
    t, n, um, ue, e, h = march_heat("dufort", 5.0, start=s)
    print(f"start = {s:5s}  u_mid = {um:+.5f}  max_err = {e:.3e}")
```

## 比較マトリクス:何を得て、何を手放すか

| 項目 | FTCS | DuFort–Frankel | Laasonen |
|---|---|---|---|
| 安定条件 | $r\le 1/2$ | 無条件 | 無条件 |
| 整合性 | 無条件 | $\Delta t/\Delta x\to0$ のときのみ | 無条件 |
| 時間精度 | $O(\Delta t)$ | $O(\Delta t^2)$ + $O(\lambda^2)$ | $O(\Delta t)$ |
| ステップあたりの費用 | 点ごとの更新 | 点ごとの更新、2層保存 | 三重対角の求解 |
| 開始 | すぐ | 最初のステップを別途 | すぐ |
| $r=0.5$ の最大誤差 | 6.15e-04 | 6.15e-04 | 1.23e-03 |
| $r=10$ の中央温度 | 発散 | $-0.827$ | $+0.071$ |
| 失敗の姿 | 偶奇振動が爆発 | 静かに振動し0を下回る | 減衰が遅い |

出力から3つのことが読み取れます。1つ目、$r=0.5$ でFTCSとDuFort–Frankelは小数第5位まで一致します。元の課題の平均誤差0.8954e-3と0.8976e-3がほぼ同じだったのも同じ理由です。2つ目、$r=10$ でLaasonenの誤差は1.95e-02です。大きいですが符号は合っています。3つ目、FTCSの発散の大きさは $r$ とステップ数で決まります。$r=10$ は12ステップしかないので6.3で止まりました。

FTCSは失敗を隠せません。数値が爆発するので誰でも気づきます。DuFort–Frankelの失敗は静かです。値は有限で、プロファイルの形も $\sin x$ のままです。符号だけが違います。検証ケースで収束次数を測っても、$\Delta t/\Delta x$ を固定したまま格子を細かくすると、この誤差は0に向かいません。[収束次数が検証ケースごとに違って出た話](/ja/posts/2026-10-07-sod-vortex-order-verification/)と同じ落とし穴です。

## r = 0.5で2つのスキームが同じ数値を出した理由

$r=1/2$ を入れると、DuFort–Frankelの式の $(1-2r)u_i^{n-1}$ 項が消えます。

$$
u_i^{n+1}=\tfrac12\left(u_{i+1}^n+u_{i-1}^n\right)
$$

FTCSに $r=1/2$ を入れても、まさにこの式になります。同じ式なので誤差も同じです。元の課題は「DuFort–Frankelの誤差は蓄積によるもの」と解釈していました。実際には、$r=0.5$ では2つの方法の違いを観察できなかったのです。違いは $r>1/2$ でのみ現れます。その領域こそDuFort–Frankelを使う理由です。

開始ステップの影響も確認しました。$r=5$ で最初のステップをFTCSにすると中央温度は $-0.0916$、厳密解にすると $-0.0902$ です。元の課題の観察どおり、最初のステップはほとんど影響しません。ただし原因は誤差の蓄積ではありません。複素数の根が生む振動が原因です。

この問題は拡散だけのものではありません。1つのCourant数がスキームを崩す境界は、[MSTACS圧縮差分のCourant限界](/ja/posts/2026-10-25-mstacs-slope-three-courant-limit/)でも見ました。大きな $\Delta t$ が目的なら、精度と安定性を両方保証するのは陰解法です。非定常問題では、[二重時間ループ](/ja/posts/2026-10-30-dual-time-steady-preconditioner-inner-iterations/)のように内部反復を受け入れるほうが良いでしょう。

## DuFort–FrankelにΔtを渡す前に計算する比

解像したい最も短い波長 $\ell$ を決めます。$k=2\pi/\ell$ です。あとはこの不等式だけを確認します。

$$
\Delta t\le\frac{\Delta x}{2\alpha k}
$$

この線を越えると、その波長のモードは時間とともに振動します。越えなくても $\Delta t/\Delta x$ が大きければ減衰が速すぎます。「無条件安定」は発散しないという意味にすぎません。正しい方程式を解いているという意味ではありません。
