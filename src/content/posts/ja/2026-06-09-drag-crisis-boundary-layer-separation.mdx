同じ速度なら、なめらかなボールのほうが空気をきれいに切ると思いがちです。ゴルフボールはその予想を崩します。ディンプル（小さな凹み）が何百もあっても、なめらかな球のほぼ二倍遠くへ飛びます。差の正体は抗力危機（drag crisis）です。抗力係数$C_D$があるReynolds数で崖のように落ちる区間です。

境界層のボタンを層流から乱流へ切り替えると、剥離点が後ろへずれ、陰になった後流の幅が狭くなります。

乱流側で後流がどれだけ細るかを見てください。幅が落ちると圧力抗力は半分以下になります。より乱れた境界層が抗力を削る場面です。

## 圧力抗力と摩擦抗力

ボールが受ける力は二つです。表面をかすめる粘性が生む摩擦抗力（skin friction）。前後の圧力差が生む圧力抗力（form drag）。

ボールのような鈍い物体（bluff body）では圧力抗力がほとんど全部です。前面は空気がぶつかって高圧です。後面は流れが離れた場所なので低圧が残ります。その差がボールを後ろへ引きます。

全体を一つの係数にまとめると次です。

$$F_D = \tfrac{1}{2}\, \rho\, U^2\, A\, C_D$$

$\rho$は密度、$U$は相対速度、$A$は正面投影面積、$C_D$は抗力係数です。ゴルフボールが触るのは$C_D$です。値はReynolds数に対して平らで、そのあと急に落ちます。

$$Re = \frac{\rho\, U\, D}{\mu}$$

$D$は直径、$\mu$は粘性係数です。$Re$は慣性力と粘性力の比です。

## 境界層が壁を離れる瞬間

圧力抗力の大きさは、流れがいつ壁を離れるかで決まります。境界層剥離（separation）です。

ボールの前半分では空気が速くなり、圧力は下がります。後半分は逆です。減速しながら圧力が戻ります。逆圧力勾配（adverse pressure gradient、流れ方向に圧力が増す状態）です。

壁近くの空気は、すでに粘性で運動量を多く失っています。この向かい風を最後まで支えられません。止まり、押し戻されます。そこで境界層が離れ、後ろには広い低圧の後流（wake）が残ります。

剥離が早いほど後流は広い。後流が広いほど圧力抗力は大きい。

## 層流境界層と乱流境界層の分業

剥離角は、境界層が層流か乱流かで分かれます。

層流境界層は層どうしが混ざりません。壁近くは遅く運動量に乏しいので、逆圧力勾配に会うと早く折れます。前方のよどみ点から約82°です。

乱流境界層は外側の速い空気を壁側へ引き込みます。壁近くがより頑丈です。同じ向かい風をより長く支えます。剥離は約120°まで押しやられ、後流は狭くなります。上のボタンで見えた幅の差は、この角度の差です。壁近くがなぜ持つかは、管内で[層が分かれていく構造](/ja/posts/2026-05-05-reynolds-pipe-transition-turbulence/)と一緒に見ると数字になります。

## 抗力危機 — $C_D$が崖のように落ちる

なめらかな球の$C_D$は$Re \sim 10^3$から$3{\times}10^5$まで約0.4〜0.5にとどまります。

$Re \approx 3{\times}10^5$付近で0.1を下回ります。流れの向きが変わったわけではありません。境界層が層流から乱流へ遷移（transition）し、剥離点が後ろへ押されたのです。狭くなった後流が係数を引き下げます。この急落が抗力危機です。

表面が粗いほど遷移はより低い$Re$で始まります。ディンプルはわざと粗くした表面です。ゴルフボールの飛行$Re$（約$2{\times}10^5$）は、なめらかな球ならまだ危機の手前、高い$C_D$の側です。ディンプルはその崖を前倒しし、飛行速度ですでに低い$C_D$を使わせます。曲線を手で動かす図は、数字の出力の直後に置きます。

## Python — ゴルフボールの抗力を危機の前後で

なめらかな球とディンプル球を同じ速度に入れます。直径0.0427 m、速度70 m/sです。

```python
import math

def cd_subcritical(Re):
    # Clift-Gauvin 相関式 (Re < 3e5 で有効)
    return (24.0 / Re) * (1 + 0.15 * Re**0.687) + 0.42 / (1 + 42500 * Re**-1.16)

def smoothstep(x, a, b):
    t = max(0.0, min(1.0, (x - a) / (b - a)))
    return t * t * (3 - 2 * t)

def drag_coefficient(Re, roughness):
    # roughness 0(なめらか)〜1(ディンプル): 臨界 Re を左へ移す
    sub = cd_subcritical(Re)
    log_re = math.log10(Re)
    log_crit = 5.55 - 1.35 * roughness
    t = smoothstep(log_re, log_crit - 0.18, log_crit + 0.18)
    sup = 0.08 + 0.13 * smoothstep(log_re, log_crit, 7.0)  # 危機後の枝
    return sub * (1 - t) + sup * t

def drag_force(U, D, roughness, rho=1.2, mu=1.8e-5):
    Re = rho * U * D / mu
    Cd = drag_coefficient(Re, roughness)
    A = math.pi * (D / 2) ** 2          # 正面投影面積
    Fd = 0.5 * rho * U**2 * A * Cd
    return Re, Cd, Fd

D = 0.0427   # ゴルフボール直径 [m]
U = 70.0     # ドライバー直後の速度 [m/s]

for label, rough in [("smooth", 0.0), ("dimpled", 0.85)]:
    Re, Cd, Fd = drag_force(U, D, rough)
    print(f"{label}: Re={Re:.2e}  C_D={Cd:.3f}  F_D={Fd:.3f} N")
```

出力:

```text
smooth: Re=1.99e+05  C_D=0.487  F_D=2.049 N
dimpled: Re=1.99e+05  C_D=0.116  F_D=0.488 N
```

roughnessスライダーを上げると崖が左へ動きます。logReマーカーを5.3付近に置くと、なめらかな曲線はまだ平地で、粗い曲線はすでに底です。出力の0.487と0.116がその二点です。

出力の2.049 Nと0.488 Nは同じ動圧から分かれます。$0.5 \times 1.2 \times 70^{2} = 2940$ Paです。直径0.0427 mの投影面積は約$1.432 \times 10^{-3}$ m²で、動圧との積は4.210 Nになります。0.487を掛けると2.049 N、0.116を掛けると0.488 Nなので、比は4.20です。

臨界の対数は$5.55 - 1.35 \times$ roughnessです。0なら5.55で、$Re$は約$3.55 \times 10^{5}$です。0.85なら4.40で、$Re$は約$2.53 \times 10^{4}$です。飛行$Re = 1.99 \times 10^{5}$の対数は5.299です。滑らかな球の遷移窓は5.37で開くので、5.299はまだ外にあり、亜臨界の枝が0.487を返します。ディンプルは窓を過ぎて超臨界の枝にいます。その枝は0.08から始まり、対数7で0.21になります。roughness 0.85のsmoothstepは0.275で、$0.08 + 0.13 \times 0.275 = 0.116$が出力と一致します。

roughnessを1まで上げると、同じ5.299でsmoothstepは0.341になり、$C_D$は0.124、力は約0.52 Nへ戻ります。ディンプル臨界の真ん中、$Re$約$2.53 \times 10^{4}$は8.9 m/sです。70 m/sはその上にあります。ボールがそこまで遅くなると、粗い面も高い$C_D$へ戻ります。

## ディンプル、そして別の舞台

同じ角度の話は別の道具にも出ます。自動車は後尾を整えて剥離を遅らせ、後流を減らします。クリケットはボールの片側だけを磨き、両側の剥離点をずらします。円柱にトリップワイヤー（境界層を乱流にする細い針金）を巻くと、危機が前倒しになります。

抗力を決めるのは、粘性が直接削る摩擦の量より、流れがいつ壁を離れるかです。

## 粗さを足すと抗力が戻る位置

70 m/sはすでに危機の後ろです。そこでroughnessを0.85より上げると、$C_D$は0.116から0.124へ戻ります。出力の4.20倍という開きは、スライダーの端ではありません。

熱が出入りする面にディンプルを付けると、壁面摩擦も一緒に増えます。その摩擦が熱伝達へどう換算されるかは、[抗力だけ測って熱を当てる相似](/ja/posts/2026-06-23-reynolds-analogy-friction-heat/)が問います。圧力抗力を下げるために遷移を早めた面へ、熱の請求が別に届くでしょうか。
