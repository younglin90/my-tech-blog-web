## Prを変えたのに、なぜ温度は変わらないのか

Couette流路を一つ考えます。下の壁は静止し、上の壁は速度$U$で滑ります。両壁の温度は同じです。それでも中央は温まります。粘性が運動エネルギーを熱に変えるからです(粘性加熱、viscous heating)。中央の温度上昇はPrandtl数(Pr、運動量拡散と熱拡散の比)にちょうど比例します。

この記事では、格子ボルツマン(LB、Lattice Boltzmann)熱モデルでPrを変える方法を扱います。分布関数を二組に分け、緩和時間を別々に与えるとPrは簡単に変わるように見えます。実際に回すと、熱伝導は変わるのに粘性加熱はPr=1の値から動きません。その理由と、一行で済む解決策である準平衡(quasi-equilibrium)$g^*$を持ち帰ってください。

下のシミュレーションで実際に操作してみましょう。一点で非平衡を一度だけ蹴り、衝突ステップごとに各モーメントがどれだけ残るかを示します。

Prスライダーを0.71にすると、オレンジ(応力)と緑の破線(g*モデルの粘性仕事流束)は最後まで重なります。赤(単純な2-τモデル)は紫(熱伝導)の時計に従い、応力から離れていきます。Pr=1に動かすと四本の線が二本にまとまります。

## 一組の分布関数はPr=1しか知らない

BGK衝突演算子は、すべての非平衡モーメントを同じ速さ$\omega$で平衡へ引き寄せます。応力も熱流束も同じ時計で緩和します。そのため粘性係数と熱伝導係数が同じ$\omega$に縛られます。連続BGK方程式からPr=1が出てくる理由はこれです。

空気のPrは0.71、水は約7です。Pr=1に縛られたモデルでは、境界層厚さの比すら合いません。処方は二通りあります。一つは衝突演算子の中で熱流束モーメントだけを別の速さで緩和させる方法です(MRT、Shakhov型)。もう一つはエネルギーを別の分布関数に任せる方法です。この記事は二つ目の道をたどります。

## 二組:fは質量・運動量、gは全エネルギー

2-populationモデルでは、$f_i$が密度と運動量を、$g_i$が全エネルギー$E=\rho(c_vT+u^2/2)$を運びます($i=0,\dots,Q-1$)。運動方程式は次のとおりです。

$$
f_i(\mathbf{x}+\mathbf{c}_i,\,t+1)=f_i+\omega_\mu\,(f_i^{eq}-f_i)
$$

$$
g_i(\mathbf{x}+\mathbf{c}_i,\,t+1)=g_i+\omega_\mu\,(g_i^{eq}-g_i)+(\omega_\kappa-\omega_\mu)\,(g_i^{*}-g_i)
$$

$\omega_\mu$は粘性(動粘性係数$\nu$)を、$\omega_\kappa$は熱伝導(熱拡散率$\alpha$)を決める緩和係数です。$g_i^{eq}$は局所平衡、$g_i^*$は準平衡分布です。

二つの係数は拡散係数と次のようにつながります。

$$
\nu=c_s^2\left(\frac{1}{\omega_\mu}-\frac12\right),\qquad
\alpha=c_s^2\left(\frac{1}{\omega_\kappa}-\frac12\right),\qquad
\mathrm{Pr}=\frac{\nu}{\alpha}
$$

$c_s^2=1/3$は格子音速の二乗です。$\tau_\mu=1/\omega_\mu$、$\tau_\kappa=1/\omega_\kappa$と書くと$\mathrm{Pr}=(\tau_\mu-\tfrac12)/(\tau_\kappa-\tfrac12)$です。

## エネルギー流束の中に粘性仕事が隠れている

この記事のおもちゃモデルでは、$g^{eq}$のモーメントを三つだけ決めます。0次は$E$、1次(エネルギー流束)は$(E+p)\mathbf{u}$、2次は$c_s^2E\,\mathbf{I}+E\,\mathbf{u}\mathbf{u}$です。1次モーメントの非平衡部分$\mathbf{Q}$が実際の熱流束です。

Chapman–Enskog展開(小さなKnudsen数で非平衡を解く展開)の1次では$\mathbf{Q}\approx-\tau\,\nabla\!\cdot\!\mathbf{R}^{eq}$です。ここで$\nabla(c_s^2E)$が二つに分かれます。

$$
\nabla(c_s^2E)=c_s^2\rho c_v\nabla T+c_s^2\rho\,(\mathbf{u}\!\cdot\!\nabla)\mathbf{u}+\dots
$$

第1項はFourierの熱伝導です。第2項が粘性仕事$-\mathbf{u}\cdot\boldsymbol{\sigma}$の材料です。この項は$f$の非平衡応力$\boldsymbol{\Pi}^{neq}=\mathbf{P}-\mathbf{P}^{eq}\approx-\tau_\mu\rho c_s^2(\nabla\mathbf{u}+\nabla\mathbf{u}^T)$とまったく同じ形をしています。問題は前に付く$\tau$です。

$g$を平衡だけに$\omega_\kappa$で引き寄せると、二つの項がどちらも$\tau_\kappa$を伴って出てきます。粘性仕事の係数が$\nu$ではなく$\alpha$に比例してしまいます。熱伝導は正しいのに、粘性加熱はPr=1のときの値に残ります。最初のvizの赤い線がこれです。

## 準平衡g*:流束だけを応力の時計に結びつける

解決策は$g^*$の定義一行です。$g^*$は$g^{eq}$とすべてのモーメントが等しく、エネルギー流束だけが異なります。

$$
\mathbf{q}^{*}=\mathbf{q}^{eq}+\mathbf{u}\cdot(\mathbf{P}-\mathbf{P}^{eq})
$$

$\mathbf{P}$は$f$から測った実際の運動量流束、$\mathbf{P}^{eq}$はその平衡値です。

運動方程式の1次モーメントを取ると、二つの非平衡モーメントの1ステップ更新が得られます。

$$
\mathbf{Q}'=(1-\omega_\kappa)\,\mathbf{Q}+(\omega_\kappa-\omega_\mu)\,\mathbf{u}\cdot\boldsymbol{\Pi}^{neq},\qquad
\boldsymbol{\Pi}'^{neq}=(1-\omega_\mu)\,\boldsymbol{\Pi}^{neq}
$$

$\mathbf{Q}$自体は$\omega_\kappa$で緩和します。そのため熱伝導は$\alpha$に従います。同時に$\mathbf{Q}=\mathbf{u}\cdot\boldsymbol{\Pi}^{neq}$なら、次のステップでも$\mathbf{Q}'=\mathbf{u}\cdot\boldsymbol{\Pi}'^{neq}$が保たれます。粘性仕事の部分は応力の時計$\omega_\mu$に乗ります。Chapman–Enskogで計算しても、$\tau_\kappa$の付いた粘性仕事が$(\omega_\kappa-\omega_\mu)$項と打ち消し合い、$\tau_\mu$だけが残ります。

$\omega_\kappa=\omega_\mu$なら$g^*$項は消えます。このときは単一緩和モデルと同じでPr=1です。$g^*$はPr$\ne1$のときだけ働く補正です。力項の高次モーメントが守るべき境界は[力の項が守るべき線](/ja/posts/2026-09-30-lbm-forcing-term-third-moment-limit/)で扱いました。ここでも同じ問いです。どのモーメントをどの速さで緩和させるか。

## コード:同じCouette流路、二種類のg

解析解は簡単です。定常エネルギー式は$kT''+\mu(u')^2=0$です。速度が線形なら温度は放物線になります。

$$
\theta(y)\equiv\frac{T-T_0}{U^2/(8c_v)}=4\,\mathrm{Pr}\,\eta(1-\eta),\qquad \eta=\frac{y}{H}
$$

中央の最大値は$\theta_{max}=\mathrm{Pr}$です。下のコードはD2Q9を$x$方向1セルの周期とし、$y$方向だけを解きます。壁は非平衡外挿(Guo)境界です。簡単のため$f$は等温平衡を使い、エネルギーは一方向にだけ結合します。低マッハ($U=0.1$)のCouette流では圧力が一様なので、この簡略化は結果を変えません。

```python
import numpy as np

# D2Q9、x方向1セル周期 → y方向の1D配列
cx = np.array([0, 1, 0, -1, 0, 1, -1, -1, 1])
cy = np.array([0, 0, 1, 0, -1, 1, 1, -1, -1])
w = np.array([4/9] + [1/9]*4 + [1/36]*4)
CV, T0 = 1.0, 1.0

def feq_lattice(rho, ux):
    cu = cx[:, None]*ux
    return w[:, None]*rho*(1 + 3*cu + 4.5*cu**2 - 1.5*ux**2)

def geq_energy(E, rho, ux):
    p = rho*(E/rho - 0.5*ux**2)/CV          # p = rho*T
    qx = (E + p)*ux
    cu = cx[:, None]*ux
    return w[:, None]*(E + 3*cx[:, None]*qx + 4.5*E*cu**2 - 1.5*E*ux**2)

def couette_heating(Pr, quasi, N=21, U=0.1, tau_mu=1.0, steps=8000):
    om_mu = 1/tau_mu
    om_ka = 1/(0.5 + (tau_mu - 0.5)/Pr)
    rho = np.ones(N); ux = np.zeros(N)
    E = rho*CV*T0*np.ones(N)
    f = feq_lattice(rho, ux); g = geq_energy(E, rho, ux)
    uw = np.zeros(N); uw[-1] = U
    for _ in range(steps):
        rho = f.sum(0); ux = (cx[:, None]*f).sum(0)/rho; E = g.sum(0)
        fe = feq_lattice(rho, ux); ge = geq_energy(E, rho, ux)
        Pxy = ((cx*cy)[:, None]*(f - fe)).sum(0)
        f = f + om_mu*(fe - f)
        if quasi:   # g*: エネルギー流束にu·(P - P_eq)を加えた準平衡
            gs = ge + w[:, None]*3*cy[:, None]*(ux*Pxy)
            g = g + om_mu*(ge - g) + (om_ka - om_mu)*(gs - g)
        else:       # 単純な2-τ: gは平衡へω_κでのみ緩和
            g = g + om_ka*(ge - g)
        for k in range(9):
            f[k] = np.roll(f[k], cy[k]); g[k] = np.roll(g[k], cy[k])
        for wall, nb in ((0, 1), (N-1, N-2)):   # 非平衡外挿の壁
            r = f[:, nb].sum(); un = (cx*f[:, nb]).sum()/r; En = g[:, nb].sum()
            fn = feq_lattice(np.array([r]), np.array([un]))[:, 0]
            gn = geq_energy(np.array([En]), np.array([r]), np.array([un]))[:, 0]
            Ew = r*(CV*T0 + 0.5*uw[wall]**2)
            f[:, wall] = feq_lattice(np.array([r]), np.array([uw[wall]]))[:, 0] + f[:, nb] - fn
            g[:, wall] = geq_energy(np.array([Ew]), np.array([r]), np.array([uw[wall]]))[:, 0] + g[:, nb] - gn
    rho = f.sum(0); ux = (cx[:, None]*f).sum(0)/rho
    T = (g.sum(0)/rho - 0.5*ux**2)/CV
    theta = (T - T0)/(U**2/(8*CV))
    return theta.max(), ux

print(" Pr   exact   2-tau(g_eq)   g* quasi-eq")
for Pr in (0.5, 0.71, 1.0, 2.0):
    a, _ = couette_heating(Pr, False)
    b, u = couette_heating(Pr, True)
    print(f"{Pr:4.2f}  {Pr:6.3f}   {a:9.3f}    {b:9.3f}")
print(f"u(mid)/U = {u[10]/0.1:.4f}")
```

```text
0.71   0.710       1.000        0.710
1.00   1.000       1.000        1.000
2.00   2.000       1.000        1.997
u(mid)/U = 0.5000
```

## 1.000という数字が語ること

単純な2-τの列はPrに関係なく1.000です。誤差ではなく構造です。粘性仕事の係数は$\tau_\kappa-\tfrac12$に、熱伝導係数も$\tau_\kappa-\tfrac12$に比例します。両者の比である$\theta_{max}$では$\tau_\kappa$がちょうど約分されます。空気(Pr=0.71)なら壁間の温度上昇を41%過大に予測します。水のようなPr=7の流体なら7分の1に過小予測します。

$g^*$の列は0.498、0.710、1.000、1.997です。格子21点で解析解と0.4%以内です。残りの差は壁境界と解像度から来ます。中央速度$u/U=0.5000$は、二つのモデルが同じ$f$を使うので同一です。粘性加熱の誤りは流れ場には現れません。温度場を解析解と比べなければ見逃します。

## 圧縮性に進むとfにも準平衡が付く

この記事の$f$は等温平衡を使いました。圧縮性2-populationモデルでは$f$側にも準平衡$f^*$が入ります。D2Q9の3次モーメントには$c_{ix}^3=c_{ix}$という欠陥があります。そのため温度が変わったりマッハ数が大きくなったりすると、応力に誤差項が生じます。[D2Q9を決めた三つのエルミート根](/ja/posts/2026-10-05-gauss-hermite-quadrature-lattice-velocities/)で見たあの欠陥です。$f^*$はこの欠陥を補正する圧力テンソルを持ちます。運動量流束を直すのが$f^*$、エネルギー流束に粘性仕事を付けるのが$g^*$です。

原理は同じです。保存量(密度・運動量・全エネルギー)は平衡と準平衡が共有します。違うのは、緩和速度を別に与えるべきモーメント一つだけです。非理想流体の圧力項をどこに入れるか悩んだ[非理想LBM forcingの二つの形](/ja/posts/2026-08-21-nonideal-lbm-pressure-vs-freeenergy-forcing/)も、結局は同じ問いでした。

## 熱LBコードでτκを別に与えるときに確かめる一行

エネルギー分布の衝突式を開き、$\omega_\kappa$がどこに掛かっているかを見ます。$g$全体が$\omega_\kappa$で平衡に引き寄せられていれば、粘性加熱はPr=1の値です。確認はCouetteを一回回せば十分です。$\theta_{max}$がPrに従わなければ、準平衡項が抜けています。

逆に$\omega_\kappa=\omega_\mu$だけで検証していれば、このバグはずっと隠れたままです。熱LBの検証表には、Pr$\ne1$の粘性加熱問題を少なくとも一つ入れておきましょう。熱伝導だけを見る試験(静止流体の温度拡散)では、この項を試せません。
