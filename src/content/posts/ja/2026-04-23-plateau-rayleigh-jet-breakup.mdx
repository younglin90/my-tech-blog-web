キッチンの蛇口を半分だけ開けます。最初の一握りは滑らかな水柱です。10 cmほどで規則的な滴に切れます。毎日見る光景ですが、連続体がなぜ自ら切れるのかはすぐには答えられません。

1849年のプラトーは、表面積が減る波長だけを残しました。1879年のレイリーは、その中で最も速く伸びる波長を分散関係から拾いました。エンジンノズルとインクジェットが今も使う目盛りは **ウェーバー数**（慣性力／表面張力）と **オーネゾルゲ数**（粘性／慣性・表面張力）です。太い滴で残るジェットと、霧になるジェットがあります。

波数 $kR$ のスライダーを動かすと、柱に載る波長と成長率曲線上の点が一緒に動きます。

$kR$ を 0.2 から 0.7 に上げると成長が速くなり、滴への分裂が早まり、$kR$ を 1.1 に超えると曲線は底に張り付いて柱は滑らかなままです。オーネゾルゲ数を 0 から 0.4 に上げても遅くなるだけで、不安定な $kR$ の範囲は変わりません。

## なぜ連続体は分裂する道を選ぶのか

表面張力は表面積を減らそうとする力です。同じ体積の液体であれば、球形であるときが最も表面積が小さくなります。そのため、無重力状態の水の塊は球形になります。

それでは、同じ体積の長い水柱と、その水を一定の間隔で切り分けて作った液滴の鎖では、どちらの表面積が小さいでしょうか。直感に反して、**液滴の鎖の方が小さくなります**。ただし、切り分ける間隔が水柱の円周よりも長い場合に限ります。水柱が自ら分裂するのはこれが理由です。エネルギーの低い状態へと転がり落ちようとする、自然な結果なのです。

## プラトーの幾何学的直感

プラトーは、半径 $R$ の円柱が軸方向に波長 $\lambda$ の微小な変形を受けたときの表面積の変化を計算しました。

$$
\Delta A \propto \left[1 - \left(\frac{2\pi R}{\lambda}\right)^{2}\right]
$$

ここで、$2\pi R/\lambda$ は無次元波数 $kR$（波数 $k = 2\pi/\lambda$ と半径の積）です。この値が1より小さければ $\Delta A < 0$ となり、摂動が大きくなるほど表面積が減少するため、エネルギー的に有利になります。逆に1より大きければ $\Delta A > 0$ となり、摂動は収束します。

この条件を書き直すと単純です。

$$
\lambda > 2\pi R \ \Rightarrow \ \text{不安定}, \qquad \lambda < 2\pi R \ \Rightarrow \ \text{安定}
$$

**円柱の円周よりも長い波長だけが成長します。** この基準がプラトー限界（Plateau limit）です。

## レイリーの線形安定性

プラトーは「どの波長が成長できるか」という問いにのみ答えました。「どの波長が最も速く成長するか」については、その30年後、レイリーが非粘性ナビエ・ストークス方程式に微小な摂動 $\eta = \epsilon e^{\sigma t} \cos(kx)$ を導入し、分散関係から導き出しました。

$$
\sigma^{2} = \frac{\sigma_{s}}{\rho R^{3}} \, kR \, \bigl(1 - (kR)^{2}\bigr) \, \frac{I_{1}(kR)}{I_{0}(kR)}
$$

ここで、$\sigma$ は成長率（単位 $s^{-1}$）、$\sigma_{s}$ は表面張力（N/m）、$\rho$ は液体の密度、$I_{0}, I_{1}$ は変形ベッセル関数です。右辺の括弧内の $1-(kR)^{2}$ は、まさにプラトー限界そのものです。

最大値は $kR \approx 0.697$ で得られ、対応する波長は $\lambda_{\max} \approx 9.02 R$ です。水柱は、自身の半径の約 **9倍の周期** で切り分けられることを好みます。この周期が、実際の水道の蛇口から出る液滴の間隔をほぼ正確に説明しています。

粘性を考慮に入れると、チャンドラセカール（Chandrasekhar）が整理した通り、$\sigma$ は減少しますが、$kR < 1$ という不安定性の境界自体は変わりません。粘性は **成長を遅らせる** だけであり、分裂の必要条件には影響を与えません。

## ウェーバーとオーネゾルゲ：分裂レジームのマップ

水道のようにゆっくり流れる場合には上記の説明で十分ですが、ロケット燃焼器やディーゼルインジェクターの高圧噴射では、周囲の気体の慣性も関わってきます。ここで、2つの無次元数が登場します。

$$
We = \frac{\rho_{g} U^{2} D}{\sigma_{s}}, \qquad Oh = \frac{\mu_{l}}{\sqrt{\rho_{l} \sigma_{s} D}}
$$

$We$ は気体の慣性と表面張力の比、$Oh$ は液体の粘性と（慣性・表面張力）の比です。実験データを統合すると、ジェットの速度が上がるにつれて、4段階のレジームを通過します。

| レジーム | 主な力 | 液滴サイズ vs ジェット径 | 分裂位置 |
|---|---|---|---|
| **Rayleigh breakup** | 表面張力 | 液滴 > ジェット径 | ノズルから遠い |
| **First wind-induced** | 表面張力 + 気体慣性 | 液滴 ≈ ジェット径 | ノズルから少し離れた所 |
| **Second wind-induced** | 気体慣性が支配的 | 液滴 < ジェット径 | ノズル近傍 |
| **Atomization** | 純粋な慣性破壊 | 液滴 ≪ ジェット径 | ノズル出口で直ちに |

$Oh$ が小さい場合（$< 0.1$）、レジームは $We$ だけで決まります。$Oh$ が大きくなると粘性の補正が必要になり、実務では $Oh(We)^{0.5}$ のような合成数で境界を引きます。水道やインクジェットは通常 **Rayleigh breakup** 領域にあります。ディーゼルインジェクターは **Atomization** を狙い、$We$ を $10^{5}$ 以上まで上げます。ジェットがすでに滴になったあと、気体がその滴をさらに裂く計算は [ウェーバー数と Taylor 類推分裂](/ja/posts/2026-07-07-tab-droplet-breakup-weber/)が受け取ります。ここでの $We$ はレジームを選び、そちらのノートは滴一つの振動を追います。

## 一波長の体積が滴の直径を決める

最も速い波長は $\lambda_{\max} \approx 9.02 R$ です。切れる一区間の体積は円柱 $\pi R^{2}\lambda$ なので $9.02\pi R^{3}$ です。同じ体積の球は $\frac{4}{3}\pi a^{3} = 9.02\pi R^{3}$ で、$a^{3}/R^{3} = 9.02 \times 3/4 = 6.765$ です。三乗根は約 1.89。滴の直径はジェット径の約 1.9 倍に座ります。表の Rayleigh の欄だけが「滴はジェットより太い」と書く理由が、この体積です。

不安定が開く長さは円周で、$\lambda > 2\pi R$、約 $6.28 R$ です。$9.02/6.28 \approx 1.44$ なので、最速の周期は切れ始める波長より 44% 長いだけです。ノズルがそれより短いしわしか入れなければ、柱は滑らかなまま残ります。

成長率の二乗の先頭は $\sigma_{s}/(\rho R^{3})$ です。$kR$ に付く因子は波数だけに依存するので、ピークの $\sigma$ は $R^{-3/2}$ で小さくなります。コードが書いたケースは半径 1 mm、$\sigma \approx 380\,\mathrm{s}^{-1}$、時間は約 18 ms です。速度 1 m/s を掛けると分裂位置は 1.8 cm です。流しの 10–15 cm と同じ数字ではありません。柱が太くなれば、同じ式が時間を伸ばします。

## Python で最も速い波長を探す

ベッセル関数を用いたレイリーの分散関係をそのままコードに落とし込み、最適な波数を数値的に探索します。`scipy` の `i0`, `i1` を使用します。

```python
import numpy as np
from scipy.special import i0, i1
from scipy.optimize import minimize_scalar

def rayleigh_sigma(kR, sigma_s=0.072, rho=1000.0, R=1e-3):
    """非粘性プラトー・レイリー成長率 (s^-1)。"""
    if kR <= 0 or kR >= 1:
        return 0.0
    coeff = sigma_s / (rho * R**3)
    return np.sqrt(coeff * kR * (1 - kR**2) * i1(kR) / i0(kR))

def fastest_mode(R, sigma_s=0.072, rho=1000.0):
    """最も速く成長する波数と対応する波長。"""
    res = minimize_scalar(
        lambda x: -rayleigh_sigma(x, sigma_s, rho, R),
        bounds=(0.01, 0.99), method='bounded'
    )
    kR_star = res.x
    wavelength = 2 * np.pi * R / kR_star
    sigma = rayleigh_sigma(kR_star, sigma_s, rho, R)
    return kR_star, wavelength, sigma

if __name__ == "__main__":
    R = 1e-3          # 半径 1 mm の水柱
    kR_star, lam, sig = fastest_mode(R)
    t_break = np.log(R / 1e-6) / sig   # ε_0 = 1 μm と仮定
    print(f"kR* = {kR_star:.3f}")
    print(f"lambda_max = {lam*1e3:.2f} mm  (= {lam/R:.2f} R)")
    print(f"sigma_max = {sig:.1f} /s")
    print(f"breakup time ~ {t_break*1e3:.1f} ms")
```

実行結果は `kR* ≈ 0.697`、`λ_max ≈ 9.02 R`、`σ_max ≈ 380 /s`、分裂時間は約 18 ms です。$U = 1\,\text{m/s}$ を掛けると落下距離は 1.8 cm です。蛇口の 10～15 cm をこのケースの確認に使うと、長さが余ります。初期の凹凸を 1 μm と置けば振幅が 1000 倍に伸びる時間なので、$\ln 1000 \approx 6.9$ を 380 で割ると、その 18 ms が戻ってきます。

## 1 mm の 18 ms で蛇口の高さを合わせると位置がずれる

1.8 cm と 10 cm は同じ柱ではありません。$\sigma$ が $R^{-3/2}$ で小さくなるので、太さを測る前に 18 ms を設計値として固定すると分裂長さが短くなります。$\lambda_{\max} \approx 9 R$ は波長の選択であって、落下距離の万能定規ではありません。

太い滴を残すなら Rayleigh に置き、波長をその 9 倍付近に固定すれば足ります。霧が要るなら $We$ を $10^{5}$ より上へ上げて微粒化へ越えます。粘性がその境界をどれだけ傾けるかは $Oh$ だけでは読みにくいです。慣性に対する粘性の目盛りは [Reynolds 数が流れの世界を分ける話](/ja/posts/2026-04-21-reynolds-number-scale-fluid-mechanics/)に別途あります。
