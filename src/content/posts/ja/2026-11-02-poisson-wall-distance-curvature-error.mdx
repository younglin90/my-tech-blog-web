## 円柱から半径1つ分離れた点の壁距離はいくつか

答えは当然 $a$ です。ところが商用ソルバーの「PDE壁距離」オプションは、この点で $1.38a$ を返します。球の横で同じ距離を測ると $2.0a$、管の中心では $0.71a$ です。本記事では、この数字がどこから来るのかを追います。1994年のSpaldingの着想から出発し、曲率誤差の式 $d \approx y(1+\kappa y/2)$ を導きます。最後に1D半径方向の実験でその式を確かめます。読み終えれば、PDE壁距離をどこまで信じてよいかを一行で判断できます。

壁距離(wall distance、セル中心から最も近いno-slip壁までの距離)は乱流モデルの必須入力です。Spalart–Allmarasの消散項は $(\tilde\nu/d)^2$ に比例します。SSTのブレンディング関数や2層モデルも $d$ を使います。厳密な距離の求め方は[Eikonal方程式とFast Marchingの記事](/ja/posts/2026-04-22-wall-distance-eikonal-fast-marching/)で扱いました。今回はそれより古く、より単純な方法です。

形状を `Flat wall` から `Convex` と `Concave` に切り替えてみてください。色は $d_{PDE}/d_{exact}$ で、半径 $a$ が曲率を決めます。

`Flat wall` では実線(PDE)と点線(厳密)が重なり、色は白のままです。`Convex` に切り替えると円柱の周りが赤く(過大評価)、`Concave` では青く(過小評価)なります。半径 $a$ を小さくして曲率を上げると、同じプローブ距離でも比率がさらに開きます。

## 1994年、熱伝導で距離を測る

Spaldingは障害物の多い室内空間(「cluttered spaces」)の乱流熱伝達を解いていました。無数の障害物それぞれへの距離を幾何学的に探すのは、当時の計算機には重い作業でした。そこで彼は手元にある道具、拡散方程式ソルバーを使いました。壁で0、内部に一様な熱源がある定常熱伝導問題を解きます。温度が高いほど壁から遠い、という直観です。

STAR-CCM+の理論ガイドはこれをそのまま記しています。

$$
\nabla^2 \phi = -1, \qquad \phi = 0 \ \text{on } \Gamma_w, \qquad \nabla\phi\cdot\mathbf{n} = 0 \ \text{on } \Gamma_o
$$

$\phi$ は距離に関係する補助変数、$\Gamma_w$ は壁、$\Gamma_o$ はその他の境界、$\mathbf{n}$ は境界の法線です。距離は次の式で復元します。

$$
d = -|\nabla\phi| + \sqrt{|\nabla\phi|^2 + 2\phi}
$$

同じガイドは2つの方法を並べています。Implicit Treeは表面三角形への厳密な射影で、PDEは「速いが近似」とされています。その近似がどれほどかは書かれていません。

## なぜ1Dでは厳密なのか

平板1枚と高さ $H$ の対称境界を考えます。$\phi'' = -1$、$\phi(0)=0$、$\phi'(H)=0$ の解は次のとおりです。

$$
\phi(y) = Hy - \frac{y^2}{2}, \qquad \phi'(y) = H - y
$$

$y$ は壁からの距離です。2式から $H$ を消すと $\phi = y\,\phi' + y^2/2$ が残ります。これは $y$ の2次方程式で、その正の根がまさに上の復元式です。つまり復元式は「局所的に1Dの放物線プロファイル」を仮定して逆算したものです。この仮定が成り立てば、$H$ がいくつでも $d=y$ が厳密に得られます。2枚の壁の間のチャネルでも、$\phi = y(L-y)/2$ を入れると $d=\min(y, L-y)$ が厳密に出ます。

## 曲面では何が崩れるのか

円柱の外側($r \ge a$)では、ラプラシアンに $\phi'/r$ の項が付きます。半径方向の式は $\phi'' + (k/r)\phi' = -1$ です。$k$ は0(平板)、1(円柱)、2(球)です。外側境界 $R$ でNeumann条件を課した円柱の解は次のようになります。

$$
\phi = \frac{R^2}{2}\ln\frac{r}{a} - \frac{r^2-a^2}{4}, \qquad \phi' = \frac{R^2}{2r} - \frac{r}{2}
$$

$R \gg r$ なら $\phi'^2 \gg 2\phi$ なので、$d \approx \phi/\phi' \approx r\ln(r/a)$ となります。$y=r-a$ で展開すると次のとおりです。

$$
d \approx y\left(1 + \frac{k\,y}{2a}\right)
$$

球も同様に $d \approx r(r-a)/a = y(1+y/a)$ となり、$k=2$ に一致します。$k/a$ は壁の主曲率の和 $\kappa$(凸が正)です。原因は単純です。凸面の外側では等値線が広がってフラックスが薄まり、$\phi'$ が1D放物線より速く減ります。復元式はその減少を「壁から遠い」と読みます。凹面では逆にフラックスが集まり、距離を短く読みます。管内部の中心では $\phi = (a^2-r^2)/4$ を入れて $d = a/\sqrt2 \approx 0.707a$ が厳密に出ます。

## コード:平板・円柱・球・管内部を半径方向1Dで

半径方向の式を160ノードで離散化し、SOR(Successive Over-Relaxation、重み付きGauss–Seidel)で解きます。外側境界はゴーストノードでNeumann条件を与えます。復元式で $d$ を求めた後、壁から $y=0.1, 0.5, 1.0$ の点での $d_{PDE}/y$ を出力します。

```python
import math

def poisson_phi(k, r0, r1, wall_at_r1, n, tol=1e-9):
    """phi'' + (k/r) phi' = -1 をSORで解く。壁(phi=0)は片端、反対側は dphi/dr=0。"""
    h = (r1 - r0) / n
    r = [r0 + i * h for i in range(n + 1)]
    phi = [0.0] * (n + 1)
    omega = 2.0 / (1.0 + math.sin(math.pi / (2 * n)))
    wall = n if wall_at_r1 else 0
    for it in range(1, 200001):
        dmax = 0.0
        for i in range(n + 1):
            if i == wall:
                continue
            if i == 0 and r[0] == 0.0:          # 管中心: (1+k) phi'' = -1
                new = phi[1] + h * h / (2.0 * (1 + k))
            elif i == 0 or i == n:              # 外側境界 Neumann (ghost = 内側の隣接点)
                j = 1 if i == 0 else n - 1
                new = phi[j] + 0.5 * h * h
            else:
                c = k * h / (2.0 * r[i])
                new = 0.5 * ((1 - c) * phi[i - 1] + (1 + c) * phi[i + 1] + h * h)
            du = omega * (new - phi[i])
            phi[i] += du
            dmax = max(dmax, abs(du))
        if dmax < tol * max(phi[0], phi[n]):
            return r, phi, it
    return r, phi, it

def spalding_d(r, phi):
    """d = -|grad phi| + sqrt(|grad phi|^2 + 2 phi)"""
    n = len(r) - 1
    h = r[1] - r[0]
    d = []
    for i in range(n + 1):
        if i == 0:
            g = (-3 * phi[0] + 4 * phi[1] - phi[2]) / (2 * h)
        elif i == n:
            g = (3 * phi[n] - 4 * phi[n - 1] + phi[n - 2]) / (2 * h)
        else:
            g = (phi[i + 1] - phi[i - 1]) / (2 * h)
        g = abs(g)
        d.append(-g + math.sqrt(g * g + 2 * max(phi[i], 0.0)))
    return d

def ratio_at(r, d, wall_r, y):
    """壁から y 離れた点の d_PDE / d_exact (線形補間)"""
    target = wall_r + y if r[0] == wall_r else wall_r - y
    for i in range(len(r) - 1):
        lo, hi = sorted((r[i], r[i + 1]))
        if lo <= target <= hi:
            t = (target - r[i]) / (r[i + 1] - r[i])
            return (d[i] + t * (d[i + 1] - d[i])) / y
    return float('nan')

a = 1.0
cases = [  # (名前, k, r0, r1, 壁が r1 側か)
    ("flat  H=5", 0, a, a + 5, False),
    ("cyl   R=2", 1, a, 2.0, False),
    ("cyl   R=5", 1, a, 5.0, False),
    ("cyl   R=20", 1, a, 20.0, False),
    ("sph   R=5", 2, a, 5.0, False),
    ("sph   R=20", 2, a, 20.0, False),
    ("pipe  inside", 1, 0.0, a, True),
]
ys = [0.1, 0.5, 1.0]
print(f"{'case':<13}{'k':>3}{'N':>5}{'SOR it':>8}" + "".join(f"{'y='+str(y):>9}" for y in ys))
for name, k, r0, r1, wall_hi in cases:
    n = 160
    r, phi, it = poisson_phi(k, r0, r1, wall_hi, n)
    d = spalding_d(r, phi)
    wall_r = r1 if wall_hi else r0
    row = [ratio_at(r, d, wall_r, y) for y in ys]
    print(f"{name:<13}{k:>3}{n:>5}{it:>8}" + "".join(f"{v:>9.3f}" for v in row))

print("\nnear-wall model d/y = 1 + k*y/(2a):", "  ".join(
    f"k={k}: " + "/".join(f"{1 + k * y / (2 * a):.3f}" for y in ys) for k in (1, 2)))
```

## 1.38、2.00、0.71が語ること

平板はすべての $y$ で1.000です。1Dの導出どおりです。円柱は $y=0.1a$ で1.05となり、モデル $1+y/2a$ と一致します。$y=a$ では1.38で、モデルの1.50より小さくなります。2次展開がすでに崩れる距離だからです。球は $1+y/a$ をほぼそのままたどり、$y=a$ で2.0になります。

外側境界 $R$ も結果を変えます。厳密な壁距離は外側の箱の大きさを知りません。しかしPoissonの解はNeumann境界までの領域全体に依存します。$R=2$ の円柱の $y=a$ での値1.128は、曲率ではなく境界が近いことによる「偶然の精度」です。

反復回数も見ておくべきです。平板は1,006回、球 $R=20$ は22,189回です。球の外側領域の大部分は $\phi$ が大きい遠方で、Neumann境界側の誤差がゆっくりとしか抜けません。「PDEは速い」という言葉は、線形ソルバーが優秀だという前提の上に立っています。実務のソルバーはSORではなく[マルチグリッド](/ja/posts/2026-05-06-multigrid-v-cycle-poisson-acceleration/)を使います。

## 今日のPDE壁距離はどう使われているか

それでもこの方法は生き残りました。理由は乱流モデルが $d$ を使う方法にあります。SAの消散項 $(\tilde\nu/d)^2$ は壁近くで大きく、離れると急速に消えます。第1セルが $y^+ \sim 1$ の格子なら、壁近くの $y$ は曲率半径より数千倍小さくなります。その領域の誤差 $\kappa y/2$ は0.1%にも届きません。

問題は曲率半径と境界層厚さが同程度になる場所です。細いワイヤー、翼の後縁、ブレード先端隙間がそうです。円柱の $y=a$ で $d$ が1.38倍なら、SAの消散は $1/1.38^2 \approx 0.52$ 倍になります。凹んだ角の内側では逆に消散が大きくなります。

改良版もあります。Tucker系の手法は $p$-Poisson($\nabla\cdot(|\nabla\phi|^{p-2}\nabla\phi)=-1$)を使い、$p\to\infty$ でEikonalに近づきます。Hamilton–Jacobi形式を直接解く方法もあります。非構造格子では $\nabla\phi$ そのものが[非直交補正](/ja/posts/2026-07-01-non-orthogonal-diffusion-correction/)の品質に左右される点も覚えておきましょう。

## 壁距離オプションをPDEに切り替える前に見る1つの値

自分の格子で最も小さい曲率半径 $a_{min}$ を探します。そしてその近くで乱流モデルが $d$ に敏感な高さ、おおよそ境界層厚さ $\delta$ を見積もります。$\delta/a_{min}$ が0.1未満なら、PDE壁距離の誤差は5%以内です。0.5を超えると、球状の形状では50%まで外れます。その場合はImplicit TreeかEikonal系に切り替えるほうが安全です。
