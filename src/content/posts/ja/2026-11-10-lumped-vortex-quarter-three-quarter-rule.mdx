## パネル1枚で解いたのに揚力が正確だった

迎角5°の平板翼を、渦(vortex)1つで近似しました。パネルはたった1枚です。それでも揚力係数は理論値 $2\pi\alpha$ と小数第4位まで一致しました。次に制御点を半区間だけ前へ動かしました。今度はパネルを64枚に増やしても、揚力はぴったり半分でした。

格子を細かくすれば誤差は減る、という直感がここでは通用しません。この記事では、空力の教科書にある「渦は1/4、制御点は3/4」という規則がどこから来るのかを導きます。そして位置をずらすと何が壊れるのかをコードで測ります。読み終えれば、渦格子法(VLM)やパネルコードの配置規則を数字1つで点検できるようになります。

## 薄翼理論が求めるもの:渦シート γ(x)

薄翼理論(thin airfoil theory)は、翼を翼弦線上に敷いた渦シート(vortex sheet、連続的に分布した渦)に置き換えます。シートの強さを $\gamma(x)$ とします。条件は1つです。翼面を貫く流れがあってはなりません。

$$
\frac{1}{2\pi}\int_0^c \frac{\gamma(x')\,dx'}{x-x'} = V_\infty\left(\alpha - \frac{dz}{dx}\right), \qquad 0<x<c
$$

$V_\infty$ は一様流速度、$\alpha$ は迎角、$z(x)$ はキャンバー線、$c$ は翼弦長です。左辺はシートが誘起する吹き下ろし(downwash、下向きの垂直速度)です。これに後縁で $\gamma(c)=0$ とする Kutta 条件が加わります。

平板($z=0$)の解はよく知られています。

$$
\gamma(x) = 2V_\infty\alpha\sqrt{\frac{c-x}{x}}, \qquad \Gamma = \int_0^c\gamma\,dx = \pi c V_\infty\alpha
$$

$\Gamma$ は全循環です。Kutta–Joukowski の定理 $L'=\rho V_\infty\Gamma$ に代入すると $C_L = 2\pi\alpha$ が得られます。循環と揚力の関係は[循環と揚力、Kutta–Joukowski](/ja/posts/2026-05-07-circulation-lift-kutta-joukowski/)で扱いました。もう1つ大事な事実があります。この分布の図心(centroid)はちょうど $c/4$ にあります。だから平板の1/4翼弦点まわりのモーメントはゼロです。

## 渦1つ、制御点1つ — 半翼弦則はどこから来るか

連続シートを点渦1つに置き換えます。渦は $x=a$、制御点(collocation point、非貫通条件を課す点)は $x=b$ に置きます。点渦が距離 $r$ に誘起する速度は $\Gamma/(2\pi r)$ です。制御点で吹き下ろしが $V_\infty\alpha$ に等しくなければなりません。

$$
\frac{\Gamma}{2\pi(b-a)} = V_\infty\alpha \quad\Longrightarrow\quad \Gamma = 2\pi(b-a)V_\infty\alpha
$$

この $\Gamma$ が正確な値 $\pi cV_\infty\alpha$ と一致するには $b-a=c/2$ が必要です。揚力は間隔だけで決まります。渦の位置 $a$ そのものは揚力に入りません。

$a$ はモーメントに現れます。前縁モーメントは $M_{LE}=-\rho V_\infty\Gamma a$ です。正確なシートの合力は $c/4$ に作用します。したがってモーメントまで合わせるには $a=c/4$ が必要です。2つの条件を合わせると $a=c/4$、$b=3c/4$ です。これが教科書の lumped vortex 則です。翼弦方向の圧力差分布 $\Delta C_p = 2\gamma/V_\infty$ で言い換えても同じです。合力の大きさと作用点という2つの数を、点渦1つで合わせる配置なのです。

ここまではパネル1枚の話です。パネルを $N$ 枚に分け、各パネル内に同じ比率で渦と制御点を置いたらどうなるでしょうか。直感では、$N$ が大きくなるほど配置の影響は消えるはずです。

## コード:渦と制御点の位置を変えながらパネル1〜64枚

翼弦を $N$ 枚の等間隔パネルに分けます。パネル $j$ の渦は $x_j + a\,\Delta x$、制御点は $x_j + b\,\Delta x$ に置きます。すべての制御点で非貫通条件を課すと $N\times N$ の線形系になります。1つ目の実験は平板で $a=0.25$ を固定し、$b$ だけを変えます。2つ目の実験は放物線キャンバー $z=4hx(1-x)$ で3通りの配置を比べます。

```python
import numpy as np

def lumped_vortex(N, a, b, alpha, h=0.0):
    """薄翼(c=1, V=1):各パネルで渦は比率 a、制御点は比率 b の位置"""
    xe = np.linspace(0.0, 1.0, N + 1)
    dx = xe[1:] - xe[:-1]
    xv = xe[:-1] + a * dx                  # 渦の位置
    xc = xe[:-1] + b * dx                  # 制御点の位置
    slope = 4 * h * (1 - 2 * xc)           # 放物線キャンバー z = 4h x(1-x)
    A = 1.0 / (2 * np.pi * (xc[:, None] - xv[None, :]))
    G = np.linalg.solve(A, alpha - slope)  # 制御点で垂直速度ゼロ
    CL = 2 * G.sum()                       # Kutta-Joukowski
    Cm_le = -2 * (G * xv).sum()
    return CL, Cm_le

Ns = (1, 2, 4, 16, 64)
alpha = np.radians(5.0)
CL0 = 2 * np.pi * alpha
print(f"[1] flat plate, alpha=5deg, CL / 2*pi*alpha   (a = 0.25)")
print(f"{'b':>6} " + "".join(f"{'N=' + str(n):>9}" for n in Ns))
for b in (0.50, 0.65, 0.75, 0.85, 1.00):
    print(f"{b:6.2f} " + "".join(f"{lumped_vortex(n, 0.25, b, alpha)[0] / CL0:9.4f}" for n in Ns))

al, h = np.radians(2.0), 0.04
CLx = 2 * np.pi * (al + 2 * h)
Cmx = -np.pi / 2 * (al + 4 * h)
print(f"\n[2] parabolic camber h=0.04c, alpha=2deg  exact CL={CLx:.4f}  Cm_le={Cmx:.4f}")
print(f"{'(a,b)':>11} " + "".join(f"{'N=' + str(n):>9}" for n in Ns) + "   <- CL error %")
for a, b in ((0.25, 0.75), (0.00, 0.50), (0.50, 1.00)):
    errs = [100 * (lumped_vortex(n, a, b, al, h)[0] / CLx - 1) for n in Ns]
    print(f"({a:.2f},{b:.2f}) " + "".join(f"{e:+9.2f}" for e in errs))
print(f"{'(a,b)':>11} " + "".join(f"{'N=' + str(n):>9}" for n in Ns) + "   <- Cm_le error %")
for a, b in ((0.25, 0.75), (0.00, 0.50), (0.50, 1.00)):
    errs = [100 * (lumped_vortex(n, a, b, al, h)[1] / Cmx - 1) for n in Ns]
    print(f"({a:.2f},{b:.2f}) " + "".join(f"{e:+9.2f}" for e in errs))
```

## 2(b−a) がパネル数に無関係な理由

表[1]の数字はきれいです。どの行も $2(b-a)$ です。$b=0.5$ なら0.5、$b=1.0$ なら1.5です。64枚に増やしても小数第4位まで変わりません。

理由は等間隔格子の自己相似性にあります。影響係数は $1/\big(2\pi\Delta x\,(i-j+b-a)\big)$ の形です。行列全体が間隔比 $b-a$ だけに依存します。パネル1枚で生じた $2(b-a)$ 倍の誤差が、分割しても同じ構造で繰り返されます。格子をどれだけ細かくしても、各パネルが同じ間違った規則を使っているわけです。収束しない整合性誤差(consistency error)です。

逆に $b-a=1/2$ なら、$N$ によらず全循環が正確です。J. C. James が1972年にこの「驚くべき精度」を解析的に示しました。個々の離散循環 $\Gamma_j$ は、正確な $\gamma$ をパネル上で積分した値とは異なります。それでも合計だけはぴったり合います。

## キャンバーが付くと a = 1/4 だけが生き残る

平板では $b-a=1/2$ でさえあれば十分でした。実際、コードでは $(0, 0.5)$ や $(0.5, 1.0)$ も平板の揚力は正確です。キャンバーが付くと話が変わります。放物線キャンバーの厳密解は $C_L = 2\pi(\alpha + 2h/c)$ です。

$(0.25, 0.75)$ はパネル1枚から誤差0.00%です。$(0, 0.5)$ は−69.62%から始まり、$N$ が2倍になるたびに誤差が半分になります。1次収束です。$(0.5, 1.0)$ は符号が逆で大きさは同じです。渦が前に寄ると揚力は小さく、後ろに寄ると大きく出ます。

キャンバーの傾き $dz/dx$ は位置ごとに異なります。制御点が前後に動けば、別の傾きをサンプリングします。渦と制御点の位置が同時に合って初めて、このサンプリング誤差が打ち消されます。そのつり合い点が $a=1/4$ です。

モーメントは違う動きをします。$(0.25, 0.75)$ の $C_{m,LE}$ 誤差は −41.05 → −10.26 → −2.57 と4分の1ずつ減ります。2次収束です。パネル1枚ではモーメントが41%ずれます。平板なら合力は $c/4$ に作用しますが、キャンバーは1/4点まわりに純粋なモーメント $C_{m,c/4} = -\pi h/c$ を生みます。点渦1つでは、この偶力(couple)を表現できません。ほかの2つの配置はモーメントも1次でしか収束しません。

## 渦格子法・パネル法の中の1/4–3/4

この規則は教科書の演習問題で終わりません。3次元の渦格子法(VLM)は、馬蹄渦(horseshoe vortex)の束縛渦を各パネルの1/4翼弦に置きます。制御点は3/4翼弦です。翼弦方向にパネルを1枚しか使わなくても2次元断面の揚力が合うのは、まさに上の結果によるものです。

複素ポテンシャルで円柱まわりの流れを作った方法([複素ポテンシャルと d'Alembert のパラドックス](/ja/posts/2026-05-21-complex-potential-cylinder-dalembert/))と比べると違いが見えます。あちらは等角写像で厳密解を得ます。パネル法は厳密解をあきらめ、特異点を離散的に配置します。その配置規則が精度を決めます。

不等間隔格子では注意が必要です。コサイン間隔のようにパネル長が変わると、自己相似性が崩れます。すると1/4–3/4は「パネル数によらず正確」ではなくなります。代わりに、格子を細かくすれば収束する普通の近似になります。

## 渦の位置を動かす前に確かめたい比1つ

自分の VLM やパネルコードを点検する方法は簡単です。平板をパネル1枚で解き、$C_L/2\pi\alpha$ を出力します。1でなければ、その値を2で割ったものが実際に使っている渦と制御点の間隔です。0.5000が出たなら、制御点は渦から半パネルではなく1/4パネルしか離れていません。その誤差は格子を64倍にしても消えません。

続いて放物線キャンバーを入れ、$N=1$ で $C_L$ が $2\pi(\alpha+2h)$ に一致するかを見ます。一致すれば渦は1/4点にあります。この2行のテストは、格子収束の検討より先に配置の誤りを捕まえてくれます。
