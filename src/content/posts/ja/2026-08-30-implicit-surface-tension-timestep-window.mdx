## 3日回り続ける液滴の前で

2次元の振動液滴が3日目の計算に入っています。流速は遅く、格子も大きくありません。それなのに時間刻みは
$10^{-6}$秒です。表面張力を陽的に扱った瞬間、時間刻みを決めるのは流速ではなく毛管波になります。

ここで出てくる提案が、表面張力を陰的に(新しい時刻の値として解く形で)扱うことです。制約を破れば時間刻みを
5倍、10倍にできると言われます。では3日が1日になるのでしょうか。

答えは「5倍までなら」です。Janodet、van Wachem、Dennerが2025年に発表した完全連成アルゴリズムの論文は、
密度比1000でこの窓の両端を実際に測っています。上からは安定限界が、下からはステップあたりの費用が窓を
閉じます。この記事では、その二つの壁がどこに立っているのか、そして格子を細かくしても誤差がなぜ止まるのかを
数値で追います。

## 時間刻みを縛るのは流速ではなく毛管波です

界面に表面張力があると、格子が分解できる最短の毛管波が一つ生まれます。波長は
$\lambda_\sigma = 2\Delta x$ です。この波が1セルを渡る時間より大きな時間刻みを使うと、陽的な表面張力項は
発散します。Dennerとvan Wachemが整理した形は次の通りです。

$$
\Delta t_\sigma = \sqrt{\frac{\rho_A + \rho_B}{2\pi\sigma}\,\Delta x^3} \propto \Delta x^{3/2}
$$

$\rho_A, \rho_B$ は二流体の密度、$\sigma$ は表面張力係数、$\Delta x$ は格子幅です。問題は指数の $3/2$ です。
格子幅を半分にすると時間刻みは2.8倍小さくなります。移流CFL条件の $\Delta x^1$ より速く締まります。拡散項は
陰的に解いて制約から外せますが、表面張力は長くそれができませんでした。この制約がなぜ生じ、どう陰的化するかは
[毛管時間刻み制約を扱った記事](/ja/posts/2026-06-28-implicit-surface-tension-capillary-timestep/)に書きました。

`dt/dt_sigma` を0.5から8まで動かすと、曲率誤差が有効なとき青い振幅は灰色の破線からほとんど離れません。

密度比1000の二流体の間の毛管波が、粘性で減衰する場面です。灰色の破線がProsperettiの解析解、青い線が離散
ソルバーの出した振幅です。`lambda/dx` を上げると二本が近づきます。`curvature dx^0.5` が有効なときに
`dt/dt_sigma` を0.5から8まで動かすと、誤差がほとんど動きません。それが二節先の主題です。

## 一つ目の壁が倒れた場所に残る二つ目の上限

表面張力を陰的に入れれば $\Delta t_\sigma$ は越えられます。ただし任意に大きな時間刻みにはなりません。
GalusinskiとVigneauxの解析に沿ってDennerらが整理した上限は、二つの時間スケールの競合として現れます。

$$
\Delta t^{*} = \frac{a_2 \tau_{vc} + \sqrt{(a_2 \tau_{vc})^2 + 4 a_1 \tau_\sigma^2}}{2}
$$

$\tau_{vc} = \hat\mu \lambda_\sigma / \sigma$ は粘性-毛管時間スケール、
$\tau_\sigma = \sqrt{\hat\rho \lambda_\sigma^3 / \sigma}$ は毛管時間スケールです
($\hat\rho = \rho_A + \rho_B$、$\hat\mu = \mu_A + \mu_B$)。$a_1, a_2$ はケースごとに変わる定数で、
$a_1 = 1/(16\pi)$、$a_2 = 0$ とすると元の $\Delta t_\sigma$ がそのまま出ます。

二つのスケールの比が格子オーネゾルゲ数です。

$$
\mathrm{Oh}_{\Delta x} = \frac{\tau_{vc}}{\tau_\sigma} = \frac{\hat\mu}{\sqrt{\hat\rho \sigma \lambda_\sigma}}
$$

$\mathrm{Oh}_{\Delta x} \ll 1$ なら慣性が支配して $\Delta t^{*} \propto \tau_\sigma$、逆なら粘性が支配して
$\Delta t^{*} \propto \tau_{vc}$ です。実務で効くのは後者です。粘度が大きいか毛管波が短ければ、上限は大きく
開きます。

数字が痛いのは密度比です。静止液滴(Laplace平衡)のケースでは、$\mathrm{Oh}_{\Delta x} \ll 1$ 領域の上限が
密度比1000で $1.5\,\Delta t_\sigma$ でした。同じ系列のアルゴリズムが密度比1で $15\,\Delta t_\sigma$ を
使えたことと比べると、10倍が消えたことになります。大きな $\mathrm{Oh}_{\Delta x}$ 領域でも一桁の差が出ます。
現実的な気液密度比は窓を狭くします。

格子を一度半分にすると $\Delta t_\sigma$ は $2^{3/2}\approx 2.83$ 倍になります。$\lambda/\Delta x$ を25から200へ上げるのは間隔を8倍細かくする作業です。$8^{3/2}\approx 22.6$ なので、同じ物理時間を陽的な表面張力で進めるにはステップ数が約23倍要ります。3日が2か月を超えます。

陰的にしてもそこは開きません。密度比1000の静止液滴では上限が $1.5\,\Delta t_\sigma$ で閉じます。密度比1で同じ系列が使えた $15\,\Delta t_\sigma$ の10分の1です。$\Sigma=5$ はその上限の外です。慣性支配では5倍でも発散し、10倍はさらに外です。粘度が大きく $\Delta t^{*}\propto\tau_{vc}$ に移って初めて、5倍が安定域に入ります。$a_2=0$、$a_1=1/(16\pi)$ なら $\Delta t^{*}$ は元の $\Delta t_\sigma$ に戻ります。窓を開ける項は $a_2\tau_{vc}$ です。

## 格子を8倍細かくしても誤差は半分にしか減りませんでした

論文の二つ目の検証は減衰する毛管波です。密度比も粘度比も1000、ラプラス数
$\mathrm{La} = \rho\lambda\sigma/\mu^2 = 300$、格子 $\lambda/\Delta x = \{25, 50, 100, 200\}$、時間刻み
$\Delta t/\Delta t_\sigma = \{0.5, 2, 8\}$。解析解との差を振幅の $L_2$ ノルムで測ります。

結果の表で目を引くのは誤差の大きさではなく収束次数です。ほとんどの欄が0.46から0.95の間にあります。同じ問題を
密度比1で解けば2次が出る場所です。格子を8倍細かくしても誤差は半分ほどしか減りません。

論文が指した原因は時間離散化ではありません。界面輸送です。論理は2行です。使われる界面捕捉スキームはよくて
2次精度です。曲率は色関数の2階微分なので精度が2段落ちます。つまり曲率は**よくて0次**です。十分細かい格子では
振幅誤差の収束次数は結局0に向かいます。誤差が定数に居座り、それ以上減らないという意味です。

## 収束次数の持ち主をPythonで確かめる

この論理は減衰振動子一つに縮めて確認できます。毛管波の振幅は線形領域で
$A'' + 2\nu k^2 A' + \omega_0^2 A = 0$ に従います。ソルバーが見るのは $\omega_0$ ではなく、曲率誤差の混じった
$\omega_{num} = \omega_0\sqrt{1 + C(\Delta x/\lambda)^q}$ です。$q$ だけを変えて台形則で進め、解析解との
$L_2$ ノルムと収束次数を取り出します。

```python
import math

SIGMA, RHO_HAT, LAMBDA, K, LA = 1.0, 1.0, 2*math.pi, 1.0, 300.0
MU = math.sqrt(RHO_HAT * LAMBDA * SIGMA / LA)
NU = MU / RHO_HAT
A0, T_END = LAMBDA / 100.0, 25.0


def capillary_omega(dx, q, c_kappa=0.6):
    """離散ソルバーが実際に見る振動数 — 曲率誤差は O(dx^q)"""
    w0 = math.sqrt(SIGMA * K**3 / RHO_HAT)
    return w0 * math.sqrt(1.0 + c_kappa * (dx / LAMBDA) ** q)


def analytic_amplitude(t):
    """A'' + 2*nu*k^2*A' + w0^2*A = 0 の解析解"""
    w0 = math.sqrt(SIGMA * K**3 / RHO_HAT)
    g = NU * K**2
    wd = math.sqrt(w0**2 - g**2)
    return A0 * math.exp(-g*t) * (math.cos(wd*t) + g/wd * math.sin(wd*t))


def march_amplitude(dt, w, n_steps):
    """[A, A'] を台形則(Crank-Nicolson)で前進させる"""
    g = NU * K**2
    a, v, hist = A0, 0.0, [A0]
    for _ in range(n_steps):
        h = 0.5 * dt
        rhs_a, rhs_v = a + h*v, v + h*(-w**2 * a - 2*g*v)
        det = (1 + 2*g*h) + h*h*w**2
        a = ((1 + 2*g*h) * rhs_a + h * rhs_v) / det
        v = (-h * w**2 * rhs_a + rhs_v) / det
        hist.append(a)
    return hist


def l2_amplitude(hist, dt):
    """振幅の L2 誤差ノルム (論文 Eq. 61)"""
    acc = 0.0
    for i, a in enumerate(hist):
        w = 0.5 if i in (0, len(hist)-1) else 1.0
        acc += w * (a - analytic_amplitude(i*dt))**2 * dt
    return math.sqrt(acc / (len(hist)-1) / dt) / A0


def order_of(e_coarse, e_fine):
    return math.log(e_coarse / e_fine) / math.log(2.0)


for label, q in [("curvature error ~ dx^2", 2.0), ("curvature error ~ dx^0.5", 0.5)]:
    print(f"\n{label}")
    print("lam/dx |  dt/dt_s=0.5        dt/dt_s=2          dt/dt_s=8")
    prev = {}
    for n in [25, 50, 100, 200]:
        dx = LAMBDA / n
        dt_sigma = math.sqrt(RHO_HAT * dx**3 / (2*math.pi*SIGMA))
        w = capillary_omega(dx, q)
        row = []
        for s in [0.5, 2.0, 8.0]:
            dt = s * dt_sigma
            e = l2_amplitude(march_amplitude(dt, w, int(T_END/dt)), dt)
            tag = "  (-- )" if s not in prev else f" ({order_of(prev[s], e):4.2f})"
            row.append(f"{e:.3e}{tag}")
            prev[s] = e
        print(f"{n:6d} | " + "  ".join(row))
```

## 5倍で1.9倍、10倍では横ばい

三つ目の検証は2次元楕円液滴の減衰振動です。長半径0.15 m、短半径0.1 mから出発し、$n=2$ モードで振動して粘性で
止まります。適用される時間刻みは二つの制約の最小値です。

$$
\Delta t = \min\left(\Delta t_{CFL},\ \Sigma\,\Delta t_\sigma\right)
$$

$\Sigma$ は毛管制約を何倍破るかを決める因子です。論文は $\Sigma \in \{2, 5, 10\}$ を回し、CFL上限は0.05に
固定しました。

まず精度です。振動周波数の誤差は $\Sigma = 2$ と $5$ で約3%でした。同じ解像度で陽的な表面張力処理から得られた
約4.5%より小さい値です。一方 $\Sigma = 10$ は運動エネルギーの減衰を追えませんでした。表面張力が駆動する界面
運動が時間的に分解されていないため、時間離散化の形式的な2次精度は期待できない、というのが論文の説明です。

費用の数字がこの記事の題です。$\Sigma$ を2から5へ、つまり2.5倍にしたとき、全体の実時間は1.9倍短くなりました。
ところが10まで上げるとこの利得は保たれませんでした。ステップあたりの換算計算時間が大きく増えたためです。原因は
一つです。時間刻みが大きいほど、各ステップの非線形反復の収束が遅くなります。ステップ数は減っても、1ステップの
費用がその分上がります。2.5倍に上げて実時間が1.9倍しか縮まなかった残りの0.6倍は、ステップごとに増えたNewton反復が食べています。

## 壁はそれぞれ違う場所に立っています

このケース一つに掛かる制約と最適点を一枚の表にすると5行になります。性格はすべて違います。

| 上限 | 何が決めるか | 越えると | この論文での位置 |
|---|---|---|---|
| $\Delta t_{CFL}$ | 移流速度と界面捕捉スキーム | 界面がなまる | CFL 0.05に固定 |
| $\Delta t_\sigma$ | 毛管波、$\Delta x^{3/2}$ | 陽的だと発散 | 陰的化で破った |
| $\Delta t^{*}$ | $\mathrm{Oh}_{\Delta x}$とケース定数 | 連成ソルバーも発散 | 密度比1000で $1.5\,\Delta t_\sigma$ |
| 精度の上限 | 物理時間スケールの分解 | 答えが違う | $\Sigma = 10$でエネルギー減衰に失敗 |
| 費用の最適 | ステップあたりNewton反復 | かえって遅くなる | $\Sigma \approx 5$ |

$\Delta t_\sigma$ を破るアルゴリズムは、この表の2行目だけを消します。残りはそのままです。静止液滴で力の釣り合いが
どう保たれるかは[寄生流を扱った記事](/ja/posts/2026-07-19-parasitic-currents-surface-tension/)で扱いました。

## $\Sigma=10$ は安定でも減衰を取り逃がす

$\mathrm{Oh}_{\Delta x}$ が1よりずっと小さいと、安定窓は $1.5\,\Delta t_\sigma$ の近くで閉じます。密度比1000の静止液滴がまさにその場合です。ここで $\Sigma$ を10から始めると窓の外です。振動1周期を何ステップで切っているかも一緒に数えます。$\Sigma=2$ と $5$ の周波数誤差は約3%で、陽的処理の約4.5%より小さくなりました。$\Sigma=10$ は発散しなかったのに、運動エネルギーの減衰を追えませんでした。

非線形反復が $\Sigma$ に比例して増えるなら、実時間はすでに底を過ぎています。2から5へ、2.5倍上げたとき時間は1.9倍短くなり、10ではその利得が戻ってきました。ステップ数は減っても、ステップあたりのNewton反復が空きを埋めます。CFLはこの計算で0.05に固定されています。$\Sigma$ をさらに上げても、移流側が先に時間刻みを止める格子があります。
