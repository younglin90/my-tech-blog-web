## 格子を8倍細かくしたのに一つの数だけ動かなかった

1次元の熱伝導を格子64点で解きました。続いて128、256、512と上げていきます。L2誤差は予想どおり順調に下がりました。

ところが表に並べて出していた数が一つだけ動きません。2.4674。四つの格子すべてで小数第4位まで同じでした。

格子間隔 $\Delta x$ を8分の1にしたのに、なぜある誤差はそのままなのか。この記事ではその数の正体を追います。答えは $\pi^2/4$ で、出発点は1807年のパリです。

## 1807年、審査員三人が問題にしたのは収束でした

フーリエ（Joseph Fourier）は1807年、固体の熱伝導に関する論文をパリ科学アカデミーに提出しました。固体内部の温度分布がサインとコサインの和で書ける、という内容です。

審査員はLagrange、Laplace、Legendreの三人でした。論文は差し戻されます。理由は物理ではなく数学でした。級数が収束するかが示されていない、というものです。

Lagrange自身が証明を試みました。果たせないまま1813年に世を去ります。証明が埋まったのはずっと後、フーリエの弟子Dirichletによってでした。

審査員が細かかったわけではありません。彼らが見たものは実際にそこにありました。不連続を含む関数にサイン級数をかけると、項をいくら増やしても消えないものが残ります。

## 矩形波をサインで積み上げると8.9490%が残る

周期区間に幅0.5の矩形波を置きます。フーリエ係数は手で書けます。

$$
f(x) = \frac{1}{2} + \sum_{m=1}^{\infty} \frac{2}{\pi m}\sin\!\left(\frac{m\pi}{2}\right)\cos\big(2\pi m (x - 0.5)\big)
$$

$m$ は項の番号、$x$ は位置です。奇数の $m$ だけが残ります。この級数を $N$ 項で打ち切ると、不連続点のすぐ隣で部分和が1を超えます。

下のシミュレーションで項数 $N$ を自分で増やしてみてください。

<GibbsOvershootSeriesLab />

スライダーで $N$ を大きくすると、飛び出した山が不連続点にぴたりと寄っていきます。ところが山の**高さ**は8.95%付近で止まります。`Fejer average` を入れると山は消えますが、代わりに階段がぼやけます。

これがGibbs現象です。極限値は8.9490%で、項数によらない定数です。精度を買って消せる誤差ではありません。

## 熱方程式がサイン級数を好む理由

フーリエがサインを選んだのは好みではありません。熱方程式

$$
\frac{\partial T}{\partial t} = \alpha \frac{\partial^2 T}{\partial x^2}
$$

の $\alpha$ は熱拡散率です。ここに $T = e^{ikx}$ を入れると、2階微分が $-k^2 e^{ikx}$ になります。つまり $e^{ikx}$ はラプラシアンの固有関数で、固有値は $-k^2$ です。

そのため各モードは互いに干渉せず、単独で $e^{-\alpha k^2 t}$ として減っていきます。偏微分方程式がモードごとの常微分方程式に分解されるわけです。

肝心なのは指数の中の $k^2$ です。波長が半分なら減衰は4倍速い。短い波ほど先に消える、という拡散のすべてがこの一つに入っています。

## 格子は $-k^2$ の代わりに何を返すのか

同じ計算を格子の上で行います。2階微分を2次の中心差分に置き換え、$T_j = e^{ikj\Delta x}$ を入れます。

$$
\frac{T_{j+1} - 2T_j + T_{j-1}}{\Delta x^2} = -\frac{4}{\Delta x^2}\sin^2\!\left(\frac{k\Delta x}{2}\right) e^{ikj\Delta x}
$$

$j$ は格子点の番号です。離散演算子も $e^{ikj\Delta x}$ を固有関数に持ちます。格子の上でもフーリエ分解がそのまま通る、ということです。

変わったのは固有値です。$-k^2$ ではなく $-k'^2$ で、

$$
k'^2 = \frac{4}{\Delta x^2}\sin^2\!\left(\frac{k\Delta x}{2}\right)
$$

となります。この $k'$ を実効波数（modified wavenumber）と呼びます。スキームが「私の考える $k$ はこれです」と告白する値です。

下で $\theta = k\Delta x$ を動かし、差分の次数を切り替えてみてください。

<NyquistDecayLagDial />

左は厳密な $\theta^2$ の放物線と、各次数の実効曲線です。$\theta$ が小さいうちは重なり、右端に向かうほど離れます。右側では同じ波が二つ、それぞれの速さで減衰し、格子側が目に見えて遅れます。

## ナイキスト限界で $\pi^2/4$ が出てくる場所

格子が表せる最短波長は $2\Delta x$ です。1格子上がって1格子下がる鋸歯の形で、このとき $\theta = k\Delta x = \pi$ です。

上の式に入れると

$$
\frac{k'^2}{k^2} = \frac{4\sin^2(\pi/2)}{\pi^2} = \frac{4}{\pi^2} = 0.4053
$$

逆数が $\pi^2/4 = 2.4674$。先ほど動かなかったあの数です。

重要なのは $\Delta x$ が式から約分されたことです。比は格子間隔に依存しません。どれだけ細かくしても、「その格子の鋸歯」は常に2.4674倍遅く死にます。

次数を上げても事情は似ています。実際のステンシルで確かめます。

```python
import numpy as np

STENCILS = {
    2: [1.0, -2.0, 1.0],
    4: [-1/12, 4/3, -5/2, 4/3, -1/12],
    6: [1/90, -3/20, 3/2, -49/18, 3/2, -3/20, 1/90],
}

def modified_k2(order, theta):
    """中心差分による2階微分の実効波数の2乗（dx=1基準）。厳密値は theta**2。"""
    c = STENCILS[order]
    h = len(c) // 2
    sym = sum(c[h + j] * np.cos(j * theta) for j in range(-h, h + 1))
    return -sym

theta = np.array([np.pi/8, np.pi/4, np.pi/2, 3*np.pi/4, np.pi])
print("theta/pi   exact k^2    order2    order4    order6    (ratio)")
for th in theta:
    ex = th**2
    row = [modified_k2(o, th) for o in (2, 4, 6)]
    print(f"{th/np.pi:6.3f}  {ex:10.5f}  " + "  ".join(f"{v:7.4f}" for v in row)
          + "   " + " ".join(f"{v/ex:6.4f}" for v in row))

print()
for o in (2, 4, 6):
    r = modified_k2(o, np.pi) / np.pi**2
    print(f"order {o}: Nyquist ratio = {r:.4f}   decay is {1/r:.3f}x slower")
```

## 同じ矩形波を四つの格子にかけてみた

実際に解きます。時間積分の誤差が混ざらないよう時間方向は解析的に積分し、空間離散化の差だけを残します。

```python
import numpy as np

L, ALPHA, TEND = 1.0, 1.0, 2.0e-3

def tophat_coeffs(m):
    """周期 [0,1) 上の 0.25 <= x < 0.75 の矩形波の複素フーリエ係数。"""
    m = np.asarray(m, dtype=float)
    out = np.zeros(m.shape, dtype=complex)
    out[m == 0] = 0.5
    mm = m[m != 0]
    out[m != 0] = (np.exp(-2j*np.pi*mm*0.75) - np.exp(-2j*np.pi*mm*0.25)) / (-2j*np.pi*mm)
    return out

def gibbs_overshoot(nterm):
    """2N+1項の部分和の最大超過量(%)。飛び出す位置の近傍だけを細かく見る。"""
    x = np.linspace(0.25, 0.25 + 4.0/nterm, 40001)
    m = np.arange(-nterm, nterm + 1)
    c = tophat_coeffs(m)
    s = (c[None, :] * np.exp(2j*np.pi*m[None, :]*x[:, None])).sum(axis=1).real
    return (s.max() - 1.0) * 100.0

def heat_error(ngrid, smooth):
    """熱方程式は時間方向を厳密に積分。空間離散化の差だけを残す。"""
    dx = L / ngrid
    x = np.arange(ngrid) * dx
    m = np.fft.fftfreq(ngrid, d=1.0/ngrid)
    k = 2*np.pi*m
    kmod2 = (4.0/dx**2) * np.sin(k*dx/2.0)**2          # 格子が返す k^2
    mref = np.arange(-8192, 8193)
    if smooth:
        t0 = np.cos(2*np.pi*x) + 0.3*np.cos(6*np.pi*x)
        ref = (np.cos(2*np.pi*x)*np.exp(-ALPHA*(2*np.pi)**2*TEND)
               + 0.3*np.cos(6*np.pi*x)*np.exp(-ALPHA*(6*np.pi)**2*TEND))
    else:
        t0 = ((x >= 0.25) & (x < 0.75)).astype(float)
        c = tophat_coeffs(mref)*np.exp(-ALPHA*(2*np.pi*mref)**2*TEND)
        ref = (c[None, :]*np.exp(2j*np.pi*mref[None, :]*x[:, None])).sum(axis=1).real
    num = np.fft.ifft(np.fft.fft(t0)*np.exp(-ALPHA*kmod2*TEND)).real
    nyq = ngrid//2
    return np.sqrt(np.mean((num-ref)**2)), 1.0/(ALPHA*k[nyq]**2), 1.0/(ALPHA*kmod2[nyq])

print("N_terms   Gibbs overshoot[%]")
for n in (16, 32, 64, 128, 256, 512):
    print(f"{n:6d}    {gibbs_overshoot(n):9.5f}")

for smooth in (True, False):
    print(f"\ninitial condition: {'smooth cosine' if smooth else 'square wave (discontinuous)'}")
    print("grid      L2 error     order     sawtooth decay time exact/grid    ratio")
    prev = None
    for ng in (64, 128, 256, 512):
        l2, t_ex, t_gr = heat_error(ng, smooth)
        order = "  -  " if prev is None else f"{np.log2(prev/l2):5.2f}"
        print(f"{ng:4d}   {l2:.4e}    {order}     {t_ex:.3e} / {t_gr:.3e}   {t_gr/t_ex:.4f}")
        prev = l2
```

## 細分化で減る誤差と、細分化しても減らない誤差

表から読むべきものが三つあります。

第一に、滑らかな初期条件では収束次数がちょうど2.00です。スキームは約束どおり2次です。

第二に、同じスキームに矩形波を与えると1.00に落ちます。不連続があるとフーリエ係数が $1/m$ でしか減らず、この遅い尾がエイリアシングとなって戻ってきます。収束次数を決めるのはスキームの次数ではなく**解の滑らかさ**です。

第三に、右端の比は8行のどの格子でも2.4674です。L2誤差は8分の1になったのに、この値は小数点以下まで同じです。

第二と第三を混ぜてはいけません。L2が下がるのは鋸歯モードの**振幅**が小さくなるからで、鋸歯の扱いが上手くなったからではありません。格子を細かくすることは問題をよりよく解くことではなく、問題を移すことです。

この区別は、[テイラー展開が離散LBEに半ステップを残す話](/ja/posts/2026-09-28-lbm-half-step-viscosity-taylor-expansion/)と同じ場所にあります。あちらでも「格子が実際に解く方程式」は「書き下した方程式」と違っていました。

## 6次でも0.6124である理由、そしてフィルタ

次数を上げるのは低波数でだけ得をする商売です。表の $\theta/\pi = 0.125$ の行で6次は1.0000ですが、ナイキストでは0.6124です。有限のステンシルはどれも鋸歯を正しく扱えません。$2\Delta x$ の波は格子の上では微分そのものが曖昧だからです。

そこで実務は二手に分かれます。一つは鋸歯を生ませないことです。スタッガード格子やRhie–Chow補間がその役目を果たし、[離散演算子を互いに整合させる問題](/ja/posts/2026-09-20-curl-involution-staggered-twophase/)と地続きです。

もう一つは生じた鋸歯を明示的に消すことです。スペクトルフィルタ、人工粘性、WENOの重みがすべてここに属します。上のvizの `Fejer average` が最も単純な形で、代償も同じ絵の中に見えます。Gibbsの山は消え、階段はぼやけます。

どちらも無料ではありません。選べるのは誤差をなくすかどうかではなく、どこに置くかです。

## Dirichletが1829年に埋めた空欄

Lagrangeの反対は形式論理ではありませんでした。彼は級数が不連続に出会ったとき何が起きるかを疑い、その場所に実際に8.9490%がありました。

Dirichletは1829年に条件付き収束を証明し、その空欄を埋めます。各点で収束する、ただし一様ではない。Gibbsの山は反例ではなく、その「一様ではない」の姿でした。

今日、格子収束試験を回すとき私たちは同じ問いを繰り返しています。この誤差は細分化で減る種類か、それとも $\pi^2/4$ のように格子間隔が約分されて消えない種類か。収束次数の一行が答えるのは前者だけです。

収束次数が2.00と出て安心したことがあるなら、実効波数を一度描いてみる価値があります。スキームが鋸歯について何を告白するかは、そこにしか書かれていません。
