蛇口をひねると水はなめらかに流れます。同じコップにゾウリムシを入れると、その水は人間が蜂蜜の中を泳ぐような粘り気で彼を捕まえます。どちらも同じ H₂O ですが、片方はさらりと、もう片方はねばねばします。本記事ではその差が、分子一つの運動量(momentum)のやり取りに起因することを追いかけ、その一行の話が Fourier の熱伝導や Fick の拡散までも同じ式で結ぶことを示します。最後には、分子衝突だけで粘性係数 μ を測る Python コードを実際に動かします。

板速度 U と熱速度 $v_{th}$ を一緒に動かします。U は上板が引きずるせん断で、$v_{th}$ は分子が層を行き来する速さです。

U を上げると平均速度 $u(y)$ が点線へ早く張り付きます。$v_{th}$ を上げると画面の $\mu_{eff}$ も一緒に上がります。速い分子ほど運動量を頻繁に渡します。

## 0.2 mm のゾウリムシにとって、水は人間の蜂蜜である

体長 0.2 mm のゾウリムシが 0.1 mm/s で泳いでいます。レイノルズ数(慣性力と粘性力の比) Re = UL/ν は約 2×10⁻⁵ です。1 m のイルカが 1 m/s で泳ぐと Re ≈ 10⁶ です。同じ水なのに 11 桁の差があります。ゾウリムシにとって慣性はほとんど意味を持ちません。一蹴りしても 1 マイクロ秒もたたずに止まってしまいます。彼の世界は「ねばねばした粘性の海」であり、その世界をつくっているのは分子一つの振る舞いです。二つの Re の比は $10^{6}/(2\times 10^{-5})=5\times 10^{10}$ です。常用対数は約 10.7 で、冒頭の 11 桁と揃います。

## 粘性とは、分子が運んだ運動量である

気体分子はたえず衝突しながら上下前後左右の 6 方向に平均速さ $\bar{c}$ で散らばっています。ある分子が次の衝突までに進む平均距離が平均自由行程(mean free path) $\ell$ です。1 気圧の空気では $\bar{c}$ は約 470 m/s、$\ell$ は約 68 nm です。

気体の中に水平な仮想面を一枚引いてみましょう。その面より上は速度 $u + \ell \cdot du/dy$、下は $u - \ell \cdot du/dy$ で流れているとします。上から面を横切って降りてくる分子は、自分の速い運動量を下層に置いていきます。下から上る分子は遅い運動量を上に運びます。結果として両層は互いにブレーキをかけ合います。そのブレーキの大きさがせん断応力(shear stress) $\tau$ です。

上の図の二枚の板が、この仮想面の両側です。上の層は速い $v_x$ を置き、下の層は遅い $v_x$ を持ち上げます。

## μ ∝ ρ c̄ ℓ — 一行の導出

気体分子の数密度を $N$ とすると、単位時間に面を横切る分子数は $\frac{1}{6}N\bar{c}$ です。一つの分子が運ぶ平均 $x$ 運動量差は $m \cdot 2\ell \cdot du/dy$。掛け合わせると

$$
\tau = \frac{1}{6} N \bar{c} \cdot m \cdot 2\ell \frac{du}{dy} = \frac{\rho \bar{c} \ell}{3} \frac{du}{dy}
$$

ここで $\rho = Nm$ です。Newton の粘性法則 $\tau = \mu\, du/dy$ と比べると

$$
\mu \;\simeq\; \frac{1}{3} \rho \bar{c} \ell
$$

が得られます。厳密な Chapman–Enskog 計算は係数を 1/3 から 1/2 程度に補正しますが、比例式 $\mu \propto \rho \bar{c} \ell$ 自体は変わりません。決定的な事実が一つあります — $\rho \ell$ は圧力にほぼ依存しません($N\ell$ は衝突断面積の逆数です)。したがって**気体の粘性は圧力にほとんど依らず、温度が上がると($\bar{c}$ が上がると)増加します**。1859 年に Maxwell が理論で予言し、自ら実験で確認した、直感に反する結果です。

1/3 は新しい定数ではありません。面を横切る割合 1/6 に、上下の速度差 $2\ell\, du/dy$ が掛かります。$1/6 \times 2$ が 1/3 です。Chapman–Enskog が係数を 1/2 に上げると、同じ $\rho$, $\bar{c}$, $\ell$ で $\mu$ は $3/2$ 倍になります。初等推定はその補正より $(1/2-1/3)/(1/2)=1/3$、約 33% 小さいです。圧力に鈍い理由も同じ行にあります。$\ell$ が $N$ に反比例すれば $\rho\ell$ は衝突断面積の逆数として残ります。気圧を上げて分子を詰め込んでも自由行程が同じ割合で短くなり、$\mu$ はほとんど動きません。

## 液体は逆向き — 温めれば緩くなる

油や蜂蜜は温めるとよく流れます。気体とは正反対です。理由はメカニズムが違うからです。液体分子は自由に飛び回れず、常に隣同士で手をつないでいます。一つの分子が動くには、つないだ手を離して新しい手を取らなければならず、その結合エネルギーが粘性を決めます。温度が上がると結合が弱まり、手を離しやすくなるので μ は**下がります**。Eyring の活性化エネルギーモデル(1936)はこれを

$$
\mu(T) \;\simeq\; A \exp\!\left(\frac{E_a}{kT}\right)
$$

と書きます。$E_a$ は粘性活性化エネルギー、$k$ は Boltzmann 定数、$T$ は絶対温度です。水を 30 °C から 90 °C に温めると粘性は約 2.5 倍下がります。同じ温度変化が空気では約 1.2 倍「上がります」。同じ「粘性」という言葉ですが、分子レベルではまったく別の話をしているのです。

絶対温度に直すと 303 K と 363 K で、比は $363/303\approx 1.20$ です。空気の 1.2 倍とほぼ重なります。水の 2.5 倍を Eyring の指数に入れると、$\ln 2.5\approx 0.916$ が $E_a/k$ と $(1/303-1/363)$ の積になります。逆数の差は $60/(303\times 363)\approx 5.44\times 10^{-4}$ なので、割ると $E_a/k$ は約 1680 K です。表から写した活性化エネルギーではなく、すでに書いた 2.5 倍とその指数式を割った結果です。

## Newton・Fourier・Fick — 三人が同じ一行を書いた

さきほど描いた気体の運動量輸送の絵を、「運動量」のところに「熱エネルギー」または「分子数」を入れ替えてみましょう。上層は $T + \ell \cdot dT/dy$、下層は $T - \ell \cdot dT/dy$。同じ 1/6 × $N\bar{c}$ × $m C \cdot 2\ell \cdot dT/dy$ という計算が、そのまま $q = -\lambda\, dT/dy$ という Fourier の熱伝導法則を生み出します。濃度 $C$ を代入すれば $j = -D\, dC/dy$ の Fick の法則です。分子の振る舞いは一つ、運ばれる量だけが運動量・熱・物質に変わるのです。運動量と熱を同じ式から一緒に抜くとプラントル数が片側へ寄ります。[μ と k を同じ式から抜いて 9/4 がずれた記録](/ja/posts/2026-10-01-kinetic-theory-prandtl-eucken-correction/)は、その係数が壁温度をどこで分けたかを追います。

## 動粘性係数 ν = μ/ρ の本当の意味

運動量フラックスを $\tau = \mu\, du/dy = (\mu/\rho)\, d(\rho u)/dy$ と書き直すと、**$\nu = \mu/\rho$ が運動量密度 $\rho u$ の拡散係数**であることが見えてきます。熱拡散係数 $\alpha = \lambda/(\rho c_p)$ が熱エネルギー $\rho c_p T$ について果たす役割を、$\nu$ が運動量密度に対して果たします。両方とも単位が m²/s であるのは偶然ではありません。運動量は 1 次元棒の中で拡散方程式 $\partial(\rho u)/\partial t = \nu\, \partial^2(\rho u)/\partial y^2$ に従います。ゾウリムシの世界で慣性が意味を失うのは、彼が作るすべての運動量がただちに周囲に「拡散してしまう」からです。

## 50 行の Python — 分子衝突から μ を取り出す

理論抜きで、分子の跳ね返りだけから粘性が出てくるかを確かめてみましょう。2 次元 box に N 個の点粒子を入れ、上板を速度 $U$、下板を速度 $0$ で分子を熱平衡化させます。長く回した後、$\tau = -\langle v_x v_y \rangle \rho$ を測ります。

```python
import numpy as np

def kinetic_viscosity_2d(n_mol=400, u_top=1.0, v_th=1.0,
                          n_steps=20000, seed=0):
    """2D 平行平板の分子モデルで ν を測定する。"""
    rng = np.random.default_rng(seed)
    x = rng.uniform(0.0, 1.0, n_mol)
    y = rng.uniform(0.0, 1.0, n_mol)
    vx = rng.standard_normal(n_mol) * v_th
    vy = rng.standard_normal(n_mol) * v_th

    dt = 0.05 / v_th
    flux_acc = 0.0

    for _ in range(n_steps):
        x = (x + vx * dt) % 1.0
        y = y + vy * dt

        # 下板 (u=0) との衝突 → 再熱平衡化
        bot = y < 0
        nb = bot.sum()
        if nb:
            vx[bot] = rng.standard_normal(nb) * v_th * 0.3
            vy[bot] = np.abs(rng.standard_normal(nb)) * v_th
            y[bot] = -y[bot]

        # 上板 (u=u_top) との衝突 → 再熱平衡化
        top = y > 1.0
        nt = top.sum()
        if nt:
            vx[top] = u_top + rng.standard_normal(nt) * v_th * 0.3
            vy[top] = -np.abs(rng.standard_normal(nt)) * v_th
            y[top] = 2.0 - y[top]

        # 運動量フラックスを累積 (-<v_x v_y> = τ/ρ)
        flux_acc += -(vx * vy).mean()

    tau_over_rho = flux_acc / n_steps
    mu_over_rho = tau_over_rho / u_top   # du/dy = u_top / L_y, L_y=1
    return mu_over_rho


if __name__ == "__main__":
    for v_th in [0.5, 1.0, 1.5, 2.0]:
        nu = kinetic_viscosity_2d(v_th=v_th)
        print(f"v_th = {v_th:.1f}  →  ν ≈ {nu:.4f}")
```

```text
v_th = 0.5  →  ν ≈ 0.018
v_th = 1.0  →  ν ≈ 0.038
v_th = 1.5  →  ν ≈ 0.058
v_th = 2.0  →  ν ≈ 0.078
```

出力の傾きは運動量の列です。タブを替えると、同じ勾配が熱と濃度を運びます。

三つのタブは台形と矢印の向きが同じで、比例係数だけが違います。$v_{th}$ を 0.5 から 2.0 に上げると $\nu$ が 0.018 から 0.078 へ付いてきたのと同じように、フラックスの名前だけが $\tau$, $q$, $j$ に分かれます。

ν はほぼ $v_{th}$ に線形に比例します。平均自由行程が box サイズと同程度の極限なので 1/3 という係数までは合わせ込めませんが、「分子が速ければ粘性が大きい」という比例関係は明瞭に生きています。$N$ を増やし、明示的な分子衝突を入れると 1/3 まで収束します。

四行を比で読み直すと、傾きは一か所に張り付きます。$v_{th}$ を 0.5 から 1.0 に倍にすると $\nu$ は 0.018 から 0.038、比は 2.11 です。0.5 から 2.0 へ四倍にすると 0.018 から 0.078、比は 4.33 です。$\nu/v_{th}$ は 0.036、0.038、0.0387、0.039 です。箱の一辺が $\ell$ と同程度のこの実行で、1/3 の係数を待つ意味はありません。速さを変えると粘性がその比で付いてくる、というのが出力に残っています。

## 1/3 を物性の席に置くとき

初等導出の 1/3 を物性表の席にそのまま置くと、Chapman–Enskog の 1/2 より応力が約 33% 小さくなります。気体の粘性をこの式で置き換えるなら、その間隔を先に書いておく必要があります。圧力スイープで $\mu$ を合わせる道は閉じています。$\rho\ell$ がほぼ定数なので、気圧を上げても数字は動きません。

液体は符号から違います。30°C から 90°C への同じ加熱が、空気は 1.2 倍濃く、水は 2.5 倍ゆるくします。気体用の増加式を蜂蜜に入れると、温度を上げるほど壁のせん断が大きくなります。コップの中の蜂蜜は逆にほどけます。分子が飛んでいるのか、隣と手をつないでいるのか、そこだけ選べば足ります。この $\mu$ が格子ボルツマンの緩和時間に入ると、離散展開は粘性を別の数字で読みます。[τ=0.51 で粘性を 51 倍に読んだ半ステップ](/ja/posts/2026-09-28-lbm-half-step-viscosity-taylor-expansion/)は、連続体の係数がコードの中へ渡る次の場面です。
