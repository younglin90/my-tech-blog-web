## 格子を4倍細かくしたら粒子の冷却が2.6倍遅くなった

アルミニウム粒子の燃焼を計算していた研究室が、格子を増やしました。ノード1台・2,662セルから、ノード20台へ。解像度が上がれば答えも良くなるはずでした。ところが粒子近くの気体温度がおかしく跳ねました。本記事はその原因を、セル1個だけの熱源に求めます。読み終えると、粒子のソース項(source term、粒子が気体に渡す質量・熱・運動量)をどの幅で広げるべきか、数値で判断できるようになります。

結論から述べます。同じ粒子・同じ物理条件で、格子だけを16³から64³に変えました。粒子温度が半分になる時間は0.0106から0.0274に伸びました。物理は同じなのに、答えが格子に引きずられています。格子収束(grid convergence、格子を細かくすると答えが一つの値に集まる性質)が壊れたのです。

## スライド1枚:セル1個ではなく27個

元資料は論文レビューのスライドです。Al粒子燃焼を扱ったBeckstead(2005)とFeng(2018)を引用しています。要点のメモは短いものです。「従来の計算方式:粒子を含むcell + 26 sten」。そして「差を周囲のstenに分配」。代償も書かれています。「計算時間増加、約2週間」。

粒子の過程は3段階です。気相(gas phase)段階と、2回の気化(vaporizing)段階です。気化段階で粒子は質量と熱を気体に放出します。その量を粒子を含むセル1個にすべて入れると問題が起きます。そこで周囲26セルまで、3×3×3ブロックに分けて入れました。

この処方が本当に問題を解決するのか。それが本記事の問いです。下のシミュレーションで実際に操作してみましょう。

## 点熱源は3次元で無限大になる

定常状態では、点熱源 $Q$ の周りの温度は距離 $r$ に反比例します。

$$
T(r) = \frac{Q}{4\pi k\, r}
$$

$k$ は気体の熱伝導率、$r$ は粒子中心からの距離です。$r \to 0$ で温度は発散します。1次元では点熱源の温度は有限です。2次元では対数的に発散します。3次元だけが $1/r$ で発散します。

セル1個に熱を入れると、数値解はこの発散をセルサイズで打ち切ります。そのため粒子が「見る」セル温度は次のようになります。

$$
T_{\text{seen}} = \frac{g\,Q}{k\,\Delta x}, \qquad g \approx 0.253
$$

$\Delta x$ はセル間隔、$g$ は7点ラプラシアンの格子グリーン関数(lattice Green's function)の原点値です。格子を半分にすると、粒子が見る温度は2倍になります。

粒子の熱損失は、粒子と周囲の温度差で決まります。

$$
Q = H\,(T_p - T_{\text{seen}}) = \frac{H\,T_p}{1 + H g / (k\,\Delta x)}
$$

$H$ は粒子-気体の熱交換係数、$T_p$ は粒子温度です。分母の2項は直列抵抗です。$1/H$ は粒子表面の抵抗、$g/(k\Delta x)$ は粒子が自ら温めたセルの抵抗です。[円筒の臨界断熱半径](/ja/posts/2026-11-24-critical-insulation-radius-cylinder/)で見たものと同じ抵抗の足し算です。違いが一つあります。2番目の抵抗は物理ではなく格子から来ています。

## 3つの分配方式の比較

27セルブロックに均等分配すると、実効幅は $3\Delta x$ になります。自己加熱はおよそ1/3に減ります。しかし依然として $\Delta x$ に比例します。格子をさらに3倍細かくすれば、同じ問題が戻ってきます。

解決策は、幅を物理長さに結びつけることです。ガウシアンカーネル(Gaussian kernel、釣鐘型の重み)の標準偏差 $\sigma$ を固定します。

$$
w_i = \frac{\exp\!\left(-|\mathbf{x}_i - \mathbf{x}_p|^2 / 2\sigma^2\right)}{\sum_j \exp\!\left(-|\mathbf{x}_j - \mathbf{x}_p|^2 / 2\sigma^2\right)}
$$

$w_i$ はセル $i$ が受け取る割合、$\mathbf{x}_p$ は粒子位置です。粒子が見る温度も同じ重みで平均します。すると自己加熱の抵抗は $\Delta x$ ではなく $\sigma$ に結びつきます。格子を細かくしても $\sigma$ は変わりません。

## コード:周期箱の中の粒子1個、カーネル3種 × 格子5段階

一辺1の周期箱の中央に温度1の粒子を置きます。気体は0から始まり、3Dで拡散します。粒子と気体は熱をやり取りします。粒子温度が0.5になるまでの時間を測ります。結合項は点陰解法(point-implicit)で解き、細かい格子でも暴走しないようにしました。

```python
import numpy as np

# 周期箱(L=1)内の高温粒子1個:気体の3D拡散 + 粒子-気体熱交換(双方向連成)
ALPHA, H, CP, SIGMA = 1.0, 0.25, 0.002, 0.06

def kernel_weights(N, kind):
    dx = 1.0 / N
    c = N // 2
    W = np.zeros((N, N, N))
    if kind == "cell":
        W[c, c, c] = 1.0
    elif kind == "stencil27":
        W[c-1:c+2, c-1:c+2, c-1:c+2] = 1.0
    else:  # 物理幅SIGMAで固定したガウシアン
        x = (np.arange(N) - c) * dx
        r2 = x[:, None, None]**2 + x[None, :, None]**2 + x[None, None, :]**2
        W = np.exp(-r2 / (2 * SIGMA**2))
    return W / W.sum()

def cool_particle(N, kind):
    dx = 1.0 / N
    dt = 0.9 * dx**2 / (6 * ALPHA)
    W = kernel_weights(N, kind)
    s = (W**2).sum() / dx**3          # 実効逆体積:粒子が「見る」気体の大きさ
    Tg = np.zeros((N, N, N))
    Tp, t, seen_max = 1.0, 0.0, 0.0
    while Tp > 0.5:
        lap = sum(np.roll(Tg, k, a) for a in range(3) for k in (1, -1)) - 6 * Tg
        Tg += dt * ALPHA * lap / dx**2
        seen = (W * Tg).sum()
        Q = H * (Tp - seen) / (1 + H * dt * (1 / CP + s))   # 点陰解法による連成
        Tg += dt * Q * W / dx**3
        Tp -= dt * Q / CP
        t += dt
        seen_max = max(seen_max, seen + dt * Q * s)
    return t, seen_max

print(f"isolated particle (Tg fixed 0): t_half = {CP/H*np.log(2):.5f}")
print(f"{'N':>4} {'dx':>7} | {'cell':>14} | {'stencil27':>14} | {'gauss':>14}")
for N in (16, 24, 32, 48, 64):
    row = [cool_particle(N, k) for k in ("cell", "stencil27", "gauss")]
    print(f"{N:>4} {1/N:7.4f} | " + " | ".join(f"{t:.5f} ({m:.3f})" for t, m in row))
```

## 表を読む:0.0274、0.0096、0.0059

基準は、気体を0に固定した孤立粒子です。このときの半減時間は0.00555です。

セル1個方式は、N=16ですでに1.9倍遅くなります。N=64では4.9倍です。括弧内の数字は、粒子が見た気体温度の最大値です。0.383から0.770まで上がりました。粒子は自分の温度1の77%を、自ら温めたセルに見ています。熱を逃がす温度差が消えたのです。

27セル方式はましですが、同じ方向に動きます。0.00645から0.00956へ、48%増えました。セル1個方式のN=24付近の誤差が、27セルのN=64で再び現れます。ブロック幅が $3\Delta x$ なので予想どおりです。

ガウシアンはN=24以降、0.0059〜0.0060にとどまります。見る温度も0.045で固定です。N=16で0.00645とやや異なるのは、$\sigma=0.06$ が $\Delta x=0.0625$ より小さいためです。カーネルがセル1個を覆えないと、セル方式に戻ってしまいます。

## 比較マトリクス:何を固定し、何を支払うか

| 方式 | 実効幅 | 格子収束 | コスト | 落とし穴 |
|---|---|---|---|---|
| セル1個 | $\Delta x$ | 崩れる ($\propto 1/\Delta x$) | 最小 | 細かいほど悪化 |
| 27セル均等 | $3\Delta x$ | 崩れる (3倍の先送り) | 27倍のアクセス | 境界・並列分割境界でゴーストセルが必要 |
| ガウシアン $\sigma$ 固定 | $\sigma$ | 保たれる ($\Delta x < \sigma$) | $(\sigma/\Delta x)^3$ セル | $\sigma$ が新しいモデル定数になる |

27セル方式の「2週間」は、この表の2行目のコストです。セルごとに隣接26個を読み書きすると、並列分割境界での通信が増えます。[DEMのセクターサイズ](/ja/posts/2026-10-08-dem-sector-neighbor-search/)の記事で見た近傍探索コストと同じ種類です。

ガウシアンもタダではありません。$\Delta x$ が小さくなると、カーネルが覆うセル数は3乗で増えます。そして $\sigma$ をどう決めるかが新しい問いになります。よくある選択は、粒子直径の数倍、または粒子周りの境界層厚さです。

## Al粒子計算でカーネル幅を決めるときに問うべきこと

まず $\Delta x$ と粒子直径 $d_p$ を比べます。$\Delta x \gg d_p$ ならセル方式でも持ちこたえます。自己加熱の抵抗が表面抵抗より小さいからです。$H g/(k\Delta x)$ を一度計算すれば十分です。この値が0.1を超えたら、カーネルを変える時です。

次に、格子を1段階細かくして、同じ粒子の燃焼時間を比べます。Becksteadの相関式は、燃焼時間を粒子直径のおよそ1.8乗に結びつけます。格子だけを変えたのに燃焼時間が動いたなら、その差は物理ではありません。

最後に、分配幅と補間幅をそろえます。熱を入れるカーネルと温度を読むカーネルが違うと、エネルギー保存と自己加熱の相殺が同時に崩れます。上のコードは `W` 一つで両方を処理しています。
