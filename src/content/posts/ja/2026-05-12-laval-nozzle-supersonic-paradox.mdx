## マッハ数 — 圧縮性を分ける一つの比

マッハ数（流速 $U$ と音速 $a$ の比）は単なる速さの尺度ではありません。単位体積あたりの慣性力は $\rho U^2 / l$、弾性力は $K l^2 / l^3$ に比例するため、両者の比の平方根がマッハ数そのものになります。

$$
\mathrm{Ma} = \frac{U}{a}, \qquad a = \sqrt{\frac{K}{\rho}}
$$

ここで $K$ は体積弾性率（体積変化に対する剛性）、$\rho$ は密度です。マッハ数は「流れが媒質の弾性をどれだけ叩いているか」の指標です。経験則として $\mathrm{Ma} < 0.3$ なら密度変化は5%未満で、非圧縮の仮定が使えます。それを越えると流れ自身が媒質を押し縮め始めます。

## 音速を越える瞬間 — ドップラーからマッハ円錐まで

静止した音源が出す波面は同心円です。音源が動くと前方の波長は縮み、後方は伸びる。これがドップラー効果です。音速に達すると、全ての波面が一つの平面に重なります。音速を越えると、音源は自分の出した波面を追い越し、その包絡線が円錐になります。このマッハ円錐の外側には音は一切届きません。

円錐の半角 $\mu$ は幾何だけで決まります。

$$
\sin\mu = \frac{1}{\mathrm{Ma}}
$$

マッハ2の機体が引きずる円錐は $\mu \approx 30°$、マッハ5なら $11.5°$ まで狭まります。スライダが 1 を越えた直後に見えた斜線が、この半角です。

## 逆説の一行 — (1−1/Ma²)dρ/ρ + dA/A = 0

ここから本題です。断面積 $A(x)$ が変化する1次元定常流を考えます。質量保存を微分形で書くと

$$
\frac{d\rho}{\rho} + \frac{dA}{A} + \frac{du}{u} = 0
$$

となり、等エントロピー仮定の下でオイラー方程式と音速の定義 $a^2 = dp/d\rho$ を組み合わせると

$$
u\, du = -\frac{dp}{\rho} = -a^2 \frac{d\rho}{\rho}
$$

が得られます。両者から $du$ を消去すると次の一行が残ります。

$$
\left(1 - \frac{1}{\mathrm{Ma}^2}\right) \frac{d\rho}{\rho} + \frac{dA}{A} = 0
$$

$\rho$ は密度、$A$ は断面積、$\mathrm{Ma}$ はマッハ数です。符号解析で全ての矛盾が解けます。

**亜音速 ($\mathrm{Ma} < 1$、括弧が負)**: 断面積が縮むと ($dA<0$) 密度も下がり ($d\rho<0$)、結果として速度が増す。ホースの先端で起こることと同じです。

**超音速 ($\mathrm{Ma} > 1$、括弧が正)**: 全ての符号が反転します。断面積が縮むと密度は増え、速度は落ちる。狭い管にもっと速く押し込もうとすると逆に流れが詰まる。加速したいなら断面積を広げる必要があります。

マッハ 0.3 では 1/Ma² が 1/0.09、約 11.1 です。括弧 (1−1/Ma²) は約 −10.1 になります。密度変化は、面積変化をこの数で割った大きさです。面積を 10% 変えても密度は 1% ほどしか動きません。音速に大きく届かないうちは、面積と密度はほとんど別々です。

マッハ 2 では 1/Ma² が 0.25、括弧は +0.75 です。符号が反転したあと、密度変化は面積変化の約 1.33 倍です。面積を 10% 広げると密度は約 13% 下がり、速度は増します。マッハ 1 では括弧が 0 なので、式が残るには面積変化も 0 でなければなりません。スロートが一点になる理由の数字です。

## ラバルノズル — 絞れば速くなる、とは限らない

この符号反転がラバルノズルの形を決めます。亜音速から超音速まで加速するには、まず絞って音速に達し、そこから再び広げる必要があります。中央の細い部分（スロート）でちょうど $\mathrm{Ma} = 1$ になります。$1 - 1/\mathrm{Ma}^2 = 0$ のとき式が成り立つには $dA = 0$ でなければならないからです。

スロート断面積 $A^*$ と任意断面積 $A$ の比はマッハ数のみで決まります。

$$
\frac{A}{A^*} = \frac{1}{\mathrm{Ma}} \left[ \frac{2}{\gamma+1} \left( 1 + \frac{\gamma-1}{2}\mathrm{Ma}^2 \right) \right]^{\frac{\gamma+1}{2(\gamma-1)}}
$$

同じ面積比に対して亜音速解と超音速解が同時に存在します。どちらの枝を取るかは出口背圧 $P_b$ が決めます。背圧を十分下げると、拡大部のマッハ分布が1を越えて単調増加します。逆に背圧を設計値より上げると、ノズル内のどこかで垂直衝撃波が発生し、流れが再び亜音速に落ちます。

## Pythonで見る等エントロピー面積—マッハ関係

面積比公式と等エントロピー圧力比をNumPy30行で辿ります。二分法で面積比からマッハ数を逆に解きます。

```python
import numpy as np

GAMMA = 1.4

def area_mach_relation(M, gamma=GAMMA):
    """A/A* — 等エントロピー面積-マッハ式."""
    exp = (gamma + 1) / (2 * (gamma - 1))
    inner = (2 / (gamma + 1)) * (1 + 0.5 * (gamma - 1) * M ** 2)
    return (1 / M) * inner ** exp

def solve_supersonic_branch(area_ratio, gamma=GAMMA, lo=1.0001, hi=25.0):
    """面積比 -> 超音速マッハ数 (二分法)."""
    for _ in range(80):
        mid = 0.5 * (lo + hi)
        if area_mach_relation(mid, gamma) < area_ratio:
            lo = mid
        else:
            hi = mid
    return 0.5 * (lo + hi)

def pressure_ratio_isentropic(M, gamma=GAMMA):
    """p/p0 — 静圧と全圧の比."""
    return (1 + 0.5 * (gamma - 1) * M ** 2) ** (-gamma / (gamma - 1))

def normal_shock_p2_p1(M1, gamma=GAMMA):
    """垂直衝撃波の静圧比 p2/p1."""
    return 1 + (2 * gamma / (gamma + 1)) * (M1 ** 2 - 1)

A_ratio = 2.5
M_exit = solve_supersonic_branch(A_ratio)
p_exit = pressure_ratio_isentropic(M_exit)

print(f"design exit  Ma = {M_exit:.3f}")
print(f"design exit  p/p0 = {p_exit:.4f}")
print(f"if Ma1=1.5 normal shock, p2/p1 = {normal_shock_p2_p1(1.5):.3f}")
```

出力は次の通りです。

```text
design exit  Ma = 2.443
design exit  p/p0 = 0.0633
if Ma1=1.5 normal shock, p2/p1 = 2.458
```

出口面積比のスライダを 2.5 に置き、背圧比のスライダを設計静圧より下げると、画面の設計出口マッハが出力の 2.44 付近に揃います。

面積比2.5のノズルを設計通り運用すると、出口でマッハ2.44、静圧は全圧の6.3%まで下がります。背圧比を 0.063 より上げると、拡大部の曲線がスロートの後ろで折れ、マッハは 1 を下回ります。ノズル内部にマッハ1.5の垂直衝撃波が発生すると、圧力は2.46倍に跳ね上がり、流れは瞬時に亜音速に切り替わります。

出口マッハ 2.443 を円錐の式に戻すと、sin μ = 1/2.443 は約 0.409、半角は約 24 度です。マッハ 2 の 30 度より狭くなります。出力の 2.458 は別の計算ではありません。γ=1.4 で 2γ/(γ+1) は 2.8/2.4、マッハ 1.5 の Ma²−1 は 1.25 です。1 に (2.8/2.4)×1.25 を足すと 2.458 になります。

## 衝撃波 — 圧縮の極限

圧縮波が自分自身に追いつくと衝撃波になります。波の後縁が圧縮で温められて音速が上がり、後方が前方を追い越す。最終的に、圧力跳びの全てが分子平均自由行程の数倍程度の薄い面に集約されます（空気中ではミクロン単位）。

垂直衝撃波の圧力比 $p_2/p_1 = 1 + \frac{2\gamma}{\gamma+1}(\mathrm{Ma}_1^2 - 1)$ はマッハ1で0になり、それ以上で2次的に増加します。超音速ラバルノズルで背圧が設計値より高いと、流れはその圧力差を埋めるためにノズル内部に衝撃波を立てて自己減速します。これが「過膨張」状態です。

キャビテーション気泡の崩壊が放つ微小衝撃波、鞭の先端が音速を越えるときの「パン」という音、大気圏に突入する隕石の加熱は、同じ式の別の顔です。同じ跳びが自由表面に立つと、[流し台の跳水](/ja/posts/2026-07-02-froude-hydraulic-jump-open-channel/)になります。速度の基準が音速からフルード数に変わるだけです。

## 背圧が 0.063 を超えると出口マッハが死ぬ

設計静圧比 0.0633 より背圧が高いと、拡大部は超音速分枝に留まれません。マッハ 2.443 と静圧 6.33% はセットで出ます。背圧だけを上げると、面積比 2.5 のままでも出口マッハは 1 を下回ります。内部に立ったマッハ 1.5 の衝撃が圧力を 2.458 倍にして、その隙間を埋めます。

スロートで質量流量がロックする条件は、このノートの外です。[縮流−拡大ノズルが流量をロックする場所](/ja/posts/2026-06-18-de-laval-nozzle-choked-flow/)が、スロートマッハ 1 のあとの流量を扱います。面積比と背圧を合わせたあとも流量が設計と違うなら、スロートが本当に音速かどうかをそちらで見る方がよいです。
