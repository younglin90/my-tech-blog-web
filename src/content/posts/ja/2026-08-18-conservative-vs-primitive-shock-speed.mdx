1次元Burgersソルバーを2通り書いて並べたことがあります。一方はフラックス差分、もう一方は速度に勾配を掛けた形です。紙の上では連鎖律ひとつで互いに移り変わります。ところがリーマン問題を入れた途端、片方の衝撃波がまったく動きませんでした。この記事ではその停止の原因を検査体積の導出まで遡り、格子を8倍にしても回復しないことをPythonで確かめます。

## 衝撃波がスタート地点から動かなかった

同じ方程式には二通りの書き方があります。保存形（conservative form）は時間変化率とフラックス発散で書きます。

$$
\frac{\partial u}{\partial t} + \frac{\partial}{\partial x}\left(\frac{u^2}{2}\right) = 0
$$

原始形（primitive form、非保存形）は微分を展開し、速度に勾配を掛けます。

$$
\frac{\partial u}{\partial t} + u\,\frac{\partial u}{\partial x} = 0
$$

$u$ が滑らかなら $\partial_x(u^2/2) = u\,\partial_x u$ ですから、二つは同じ式です。積の微分則がそう言っています。

ここでリーマン問題を入れます。左が $u_L = 1$、右が $u_R = 0$。厳密解は速度 $0.5$ で右に進む衝撃波です。保存形のGodunovスキームは $0.5006$ を返しました。原始形の風上差分は $0.0000$ を返しました。衝撃波が出発点に立ったままです。

`u_R` を0へ下げるとピンクの前線だけが出発点に残り、`grid N` を増やしてもそのセルは動きません。

## 検査体積から出てきた式は最初からフラックス形だった

なぜフラックス形が原型なのか。導出を辿ると見えてきます。

微小な直方体 $dx\,dy\,dz$ を取り、各面を通る質量流量を数えます。ある面を通過する量は、面中心の密度と面に垂直な速度と面積の積、すなわち $\dot m = \rho V_n A$ です。面中心の値はセル中心からのテイラー展開で求め、2次以上を落とします。6面すべてを足して $dx\,dy\,dz$ で割ると連続の式が出ます。

$$
\frac{\partial \rho}{\partial t} + \frac{\partial (\rho u_j)}{\partial x_j} = 0
$$

運動量も手順は同じです。面を通って出入りした運動量、体積力、表面力を足します。

$$
\frac{\partial (\rho u_i)}{\partial t} + \frac{\partial (\rho u_i u_j + p\,\delta_{ij})}{\partial x_j} = \frac{\partial \tau_{ij}}{\partial x_j}
$$

ここで $\rho$ は密度、$u_i$ は速度成分、$p$ は圧力、$\tau_{ij}$ は粘性応力テンソル（ニュートン流体の仮定のもとで速度勾配に線形な偏差応力）です。

重要なのは式の見た目ではなく出自です。**すべての項が「面を通って行き来した量」として定義されています。** 発散形なのは趣味ではなく、導出そのものがその形だからです。

原始形はここからもう一歩進みます。積の微分を展開し、連続の式に $u_i$ を掛けて引き、$\rho$ で割ります。$\rho = \text{const}$ を仮定すれば $\partial u_i / \partial x_i = 0$ とともに次が残ります。

$$
\frac{\partial u_i}{\partial t} + \frac{\partial (u_i u_j)}{\partial x_j} = -\frac{1}{\rho}\frac{\partial p}{\partial x_i} + \nu\,\frac{\partial^2 u_i}{\partial x_j \partial x_j}
$$

これらの操作はすべて微分可能性を前提にしています。不連続の上には前提にできるものがありません。

## 割り算ひとつが消した望遠鏡和

離散のレベルで見るとさらに明快です。保存形の有限体積法の更新式はこうなります。

$$
u_i^{n+1} = u_i^{n} - \frac{\Delta t}{\Delta x}\left(f_{i+1/2} - f_{i-1/2}\right)
$$

全セルについて和を取ります。内部の面フラックス $f_{i+1/2}$ はセル $i$ で引かれ、セル $i+1$ で足されます。符号が逆なので厳密に打ち消し合います。これが望遠鏡和（telescoping sum）で、残るのは領域両端のフラックスだけです。

$$
\Delta \sum_i u_i \Delta x = -\Delta t \left(f_{N+1/2} - f_{1/2}\right)
$$

総量の変化は境界を出入りした量と厳密に一致します。丸め誤差を除けば例外はありません。

原始形はここが壊れます。$u_i \cdot (u_i - u_{i-1})/\Delta x$ にはセルごとに異なる係数 $u_i$ が前に付きます。隣り合う項の大きさが違うため打ち消し合いません。残りかすが毎ステップ積み上がります。

コードで測った結果が下にあります。二つ目のリーマン問題（$u_L = 1$、$u_R = 0.4$）で領域に入るべき量は $+0.168000$ です。保存形は小数第6位までその値を出します。原始形は $+0.152765$ で、約9%を失っています。

同種の漏れは、前線ができる前から予告されています。[Burgers方程式で特性線がぶつかって衝撃波が生まれる場所](/ja/posts/2026-05-01-burgers-characteristics-shock-formation/)では、交差の前まで二つの形が同じ答えを出します。前線のあとの帳簿が合わなければ、総量は漏れます。

## Rankine–Hugoniotはフラックスにしか答えない

衝撃波速度はどこから来るのか。不連続を薄く包む検査体積に保存則を適用すると出てきます。

$$
s\,(u_L - u_R) = f(u_L) - f(u_R)
$$

$s$ は不連続の伝播速度、$f$ はフラックスです。Burgersでは $f = u^2/2$ なので次になります。

$$
s = \frac{u_L^2/2 - u_R^2/2}{u_L - u_R} = \frac{u_L + u_R}{2}
$$

この関係式に入っているのは $f$ だけです。$u\,\partial_x u$ という表現は登場しませんし、登場できません。不連続では $\partial_x u$ はデルタ関数であり、そこに跳ぶ $u$ を掛ける演算は超関数の理論で定義されていません。これを非保存積（non-conservative product）と呼びます。

Lax–Wendroffの定理が保証しているのもまさにこの点です。保存形スキームの数値解が収束すれば、その極限は必ず保存則の弱解であり、したがってRankine–Hugoniotを満たします。非保存形にはその保証がありません。HouとLeFlochが示したのはもっと悪い事実です。非保存形も収束はしますが、誤った速度に収束します。

## Pythonで測った伝播速度と総量

同じ格子、同じCFL、同じ初期条件で二つのスキームを回しました。標準ライブラリのみを使います。

```python
def riemann_setup(nx, ul, ur, xs=0.3):
    dx = 1.0 / nx
    return dx, [ul if (i + 0.5) * dx < xs else ur for i in range(nx)]

def godunov_flux(a, b):
    if a > b:                                  # 衝撃波: 風上側を選ぶ
        return 0.5 * a * a if a + b >= 0 else 0.5 * b * b
    if a >= 0:
        return 0.5 * a * a
    return 0.5 * b * b if b <= 0 else 0.0      # 音速をまたぐ膨張波

def step_conservative(u, dx, dt):              # u_t + (u^2/2)_x = 0
    n = len(u)
    f = [0.5 * u[0] ** 2] + [godunov_flux(u[i], u[i + 1]) for i in range(n - 1)] \
        + [0.5 * u[-1] ** 2]
    return [u[i] - dt / dx * (f[i + 1] - f[i]) for i in range(n)]

def step_primitive(u, dx, dt):                 # u_t + u u_x = 0
    n, out = len(u), []
    for i in range(n):
        im, ip = max(i - 1, 0), min(i + 1, n - 1)
        g = (u[i] - u[im]) / dx if u[i] >= 0 else (u[ip] - u[i]) / dx
        out.append(u[i] - dt * u[i] * g)
    return out

def shock_locate(u, dx, level):
    for i in range(1, len(u)):
        if u[i] < level <= u[i - 1]:
            return (i - 0.5) * dx + dx * (u[i - 1] - level) / (u[i - 1] - u[i])
    return float("nan")

def march_burgers(nx, ul, ur, tend, step):
    dx, u = riemann_setup(nx, ul, ur)
    t = 0.0
    while t < tend - 1e-12:
        dt = min(0.4 * dx / max(max(abs(v) for v in u), 1e-12), tend - t)
        u = step(u, dx, dt)
        t += dt
    return dx, u

T, XS = 0.4, 0.3
for ul, ur in ((1.0, 0.0), (1.0, 0.4)):
    s = 0.5 * (ul + ur)
    influx = (0.5 * ul ** 2 - 0.5 * ur ** 2) * T        # 領域に入るべき正味フラックス
    print("uL=%.1f uR=%.1f | Rankine-Hugoniot speed = %.3f" % (ul, ur, s))
    print("    N   conservative   primitive")
    for nx in (100, 200, 400, 800):
        v = []
        for step in (step_conservative, step_primitive):
            dx, u = march_burgers(nx, ul, ur, T, step)
            v.append((shock_locate(u, dx, s) - XS) / T)
        print("%5d      %7.4f     %7.4f" % (nx, v[0], v[1]))
    for name, step in (("conservative", step_conservative), ("primitive  ", step_primitive)):
        dx, u = march_burgers(400, ul, ur, T, step)
        dx0, u0 = riemann_setup(400, ul, ur)
        print("  N=400 %s : d(int u dx) = %+.6f  (exact %+.6f)"
              % (name, sum(u) * dx - sum(u0) * dx0, influx))
    print()
```

一つ目が極端な例です。$u_R = 0$ なら不連続の右側のセルで $u\,\partial_x u$ が丸ごとゼロになります。更新するものがないので前線は動き出せません。総量の変化も厳密にゼロです。左境界から入った $0.2$ がどこにも現れません。

停止と漏れは同じ式から出ます。$u_L=1$、$u_R=0$ なら $s=(u_L+u_R)/2=0.5$ です。$T=0.4$ の間に前線は $0.5 \times 0.4 = 0.2$ だけ動きます。出発が $x_s=0.3$ なら到着は $0.5$ です。保存形の N=100 での 0.5006 は、位置誤差 $0.0006 \times 0.4 = 0.00024$ に相当します。原始形の 0.0000 は移動がゼロなので、前線は $x=0.3$ に残ります。

総量も同じフラックスです。左境界は $u_L^2/2 = 0.5$、右は 0 です。$0.5 \times 0.4 = 0.2$ が入るべきで、出力の $+0.200000$ がその値です。原始形の $+0.000000$ は、その 0.2 がセル和から落ちたという意味です。

$u_R=0.4$ なら $s=(1.0+0.4)/2=0.7$ です。正味流入は $(0.5 - 0.08)\times 0.4 = 0.168$ で、出力の $+0.168000$ と一致します。原始形は $+0.152765$ なので差は $0.015235$、$0.015235/0.168 \approx 0.091$ で約9%です。速度は N=800 でも 0.6379 です。$(0.700-0.6379)/0.700 = 0.0887$ なので、表の最後の列は 8.7% 低い値です。Nを倍にするたびに原始形の増分は 0.0067、0.0033、0.0016 と半分ずつ減ります。目は 0.639 付近への収束と読みますが、行き先は 0.700 ではありません。保存形の同じ四つの欄は 0.7009、0.7005、0.7002、0.7001 です。0.700 との差が 0.0009 から 0.0001 へ縮むあいだ、原始形の残差 0.062 はその比例に従いません。

## 格子を細かくすれば済むのか

実務で危ないのは二つ目です。原始形の速度が $0.6263 \to 0.6330 \to 0.6363 \to 0.6379$ と動きます。格子を8倍にすると値が落ち着きます。収束しているように見えます。

問題は収束先です。正解は $0.700$ ですが、この数列は概ね $0.639$ へ向かいます。約8.7%低い値です。格子収束検証（grid convergence study）を正直に回してもこの誤差は捕まりません。三つの格子で値が近づくのを確認し、「収束した」と書いて終わりです。

保存形は $0.7009 \to 0.7001$ と正解に張り付きます。誤差が $\Delta x$ に比例して減ります。二つの数列の差は精度の差ではなく、解いている方程式の差です。

滑らかな解しかない問題ではこの差は表に出ません。だからTaylor–Greenのような検証ケースだけを回したコードは無事に通ります。不連続が初めて生じた瞬間、そこまで正しかったコードが静かに別の物理を解き始めます。

## それでも原始形が居場所を持つ理由 — $\rho=\text{const}$ の有効期限

とはいえ原始形が使えない形というわけではありません。非圧縮性解析はほぼすべて原始形です。理由があります。

未知数が減ります。2次元圧縮性では $\rho, u, v, p, T$ の5つを、質量・運動量2成分・エネルギー・状態方程式の5式で解きます。非圧縮性は $\rho$ を定数にし、エネルギー式と状態方程式を外します。残るのは $u, v, p$ だけです。圧力は熱力学量ではなく発散拘束のラグランジュ乗数になり、圧力Poisson方程式で別に解きます。

非圧縮性流れには衝撃波がありません。Rankine–Hugoniotが支配すべき不連続がそもそも存在せず、上の問題は起きません。

有効期限を決めるのはマッハ数です。等エントロピー関係から密度はこう変わります。

$$
\frac{\rho}{\rho_0} = \left(1 + \frac{\gamma-1}{2}M^2\right)^{-\frac{1}{\gamma-1}}
$$

$\rho_0$ はよどみ点密度、$\gamma$ は比熱比、$M$ はマッハ数です。小さな $M$ で展開すると密度変化は $M^2/2$ で進みます。$M = 0.2$ で約2%、$M = 0.3$ で約4.5%です。よく使われる $M < 0.2$ の目安はここから出た数字です。

`exit Mach` を0.05から上げていくと、上の緑の点（密度変化を反映）と下のピンクの点（密度固定）の間隔が開きます。0.2以下では二列がほぼ重なり、0.3を超えると右の黄色い点が $M^2/2$ の破線から離れていきます。

## 衝撃波が遅れて着いたとき最初に見る場所

ソルバーが衝撃波を見当違いの場所に立てたら、時間前進が面フラックスの差分かどうかを先に見ます。$\sum_i u_i \Delta x$ の変化が境界フラックスと桁まで一致しているかが基準です。N=400、$u_R=0$ で保存形は $+0.200000$、原始形は $+0.000000$ です。この二つの欄がすでに形を分けます。曲線座標や軸対称の項を整理して、発散の中にあるべきものをソース項へ移すと、同じ症状が出ます。滑らかな解では静かで、不連続で速度がずれます。

多相流の $\alpha\,\partial_x p$ のような項は原理的に非保存で、経路積分の解釈が別に必要です。そうした項があると、格子を100から800へ増やしても速度は 0.6379 付近に残ります。セルごとにリーマン問題を解く帳簿は、[Godunovが格子一セルを衝撃管として扱うやり方](/ja/posts/2026-05-18-godunov-exact-riemann-shock-tube/)と同じです。細分化しても衝撃波が動かないなら、疑うのは精度ではなく更新式がフラックス差分かどうかです。
