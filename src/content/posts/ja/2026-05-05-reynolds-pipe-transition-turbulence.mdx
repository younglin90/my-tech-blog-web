蛇口をゆっくりひねると、水流はガラスの棒のようになめらかに落ちます。ところがハンドルを少し回した瞬間、そのなめらかな筋が細かく砕けて散らばります。同じ水、同じ蛇口、変わったのは速さだけです。何がその閾値を決めるのでしょうか。1883年、マンチェスターのレイノルズが一筋の色素でこの問いに答え、その答えは一つの無次元数に凝縮されます。本記事では、その閾値が Re ≈ 2300 となる理由、その先の乱流境界層が粘性底層・緩和層・対数則領域へと積み重なる仕組みを追います。最後に、Re を直接動かして色筋が乱れる様子を確かめられます。

## 色筋が突然乱れる臨界点

レイノルズはガラス管の中央に色素を注入しました。直径 $d$、平均流速 $u$、動粘度 $\nu$ を様々に変えながら、色筋がいつ崩れるのかを問い続けました。

その答えは一つの無次元数の値でした。条件をどう組み合わせても、乱れの開始はほぼ同じ値で起こります。

$$
\mathrm{Re} = \frac{u\, d}{\nu}
$$

ここで $u$ は平均流速、$d$ は特性長さ(管では直径)、$\nu = \mu / \rho$ は動粘度(粘度を密度で割った量)です。Re が臨界値を超えると色筋は均衡を失います。

## Re = 2300 が意味するもの

Re は単なる実験定数ではありません。運動量方程式を無次元化すると、粘性項の前に正確に $1/\mathrm{Re}$ が掛かります。つまり Re は **慣性力と粘性力の比**です。

- Re が小さい → 粘性が支配し、小さな擾乱を素早く均質化 → 層流が保たれる。
- Re が大きい → 慣性が支配し、小さな擾乱が非線形項で自己増幅 → 乱流へ遷移。

円管内部の臨界 Re は実験的に約 2300 です。ただしこの値は外乱条件で揺らぎます。研磨された管、振動のない支持、清浄な入口条件であれば、Re が 5 万まで層流が保たれた報告もあります。したがって「臨界 Re ≈ 2300」は工学的な実用基準であり、遷移の本質は擾乱を成長させる **エネルギー経路**が開いているかどうかにあります。

平板境界層(boundary layer、壁近傍で粘性が支配する薄い層)では尺度が異なります。前縁からの距離 $x$ で定義した $\mathrm{Re}_x = U_\infty x / \nu$ の臨界値は約 $3 \times 10^5$、境界層厚さ $\delta$ で定義した $\mathrm{Re}_\delta$ は約 2700 で乱れます。同じ遷移現象が形状に応じて別の無次元数に現れるのです。

## プラントルが見た境界層 — 外層と内層

レイノルズが臨界条件を示した翌年(1904年)、プラントルは別の問いを立てました。粘性が小さくても、なぜ壁の近くでは摩擦が無視できないのか。

答えは、粘性が効く領域を明示的に分離することでした。彼は壁に粘着(no-slip)した流体から自由流速度まで加速される薄い層を **境界層**と命名し、その外側はポテンシャル流として扱いました。この分割によって、航空機翼上の 2.5–25 mm の層だけ追えば粘性の影響を捉えられるようになりました。

乱流境界層は一枚岩ではありません。壁からの距離 $y$ を適切に無次元化すると普遍構造が現れます。

$$
y^+ = \frac{y\, u_\tau}{\nu}, \qquad u_\tau = \sqrt{\tau_w / \rho}
$$

$u_\tau$ は **壁面摩擦速度**(wall friction velocity、壁面せん断応力 $\tau_w$ を密度で割った平方根)です。$\nu / u_\tau$ は粘性が運動量を運ぶ距離、すなわち**粘性長さ**です。つまり $y^+$ は「粘性長さで測った壁からの距離」になります。

## 壁の法則 — 粘性底層・緩和層・対数則領域

平板乱流境界層内部の速度分布を $u^+ = u / u_\tau$ で無次元化すると三つの領域が現れます。

| 領域 | 範囲 | 速度分布 |
|------|------|-----------|
| 粘性底層 (viscous sublayer) | $0 < y^+ < 5$ | $u^+ = y^+$ |
| 緩和層 (buffer layer) | $5 < y^+ < 30$ | 二式の滑らかな遷移 |
| 対数則領域 (log-law / inertial) | $30 < y^+ < 0.2\, \delta^+$ | $u^+ = \frac{1}{\kappa} \ln y^+ + B$ |

ここで $\kappa \approx 0.41$ はフォン・カルマン定数、$B \approx 5.0$ は滑面に対する定数です。

壁のすぐ隣では渦塊の運動が壁に抑えられて分子拡散が支配します。せん断応力がほぼ一定の領域で $\tau_w = \mu \, du/dy$ を積分すると正確に $u^+ = y^+$ が得られます。厚さは風速 20 m/s、前縁から 2 m の位置で $y^+ = 1$ がおよそ 0.02 mm — 粘性底層は髪の毛の太さの 1/5 です。

対数則領域はプラントルの **混合長理論**(mixing length、渦塊が周囲と同化するまでの平均移動距離)から導かれます。壁近傍で混合長が距離 $y$ に比例すると置けば $\ell = \kappa y$、一定せん断応力の仮定と組み合わせて積分すると上の対数式が自然に現れます。

## 混合長理論 — 渦塊を分子のように

層流で運動量を運ぶ主役は **分子**です。ニュートンの粘性法則 $\tau = \mu\, du/dy$ がその結果です。乱流では渦塊(eddy、様々な大きさを持つ組織化された流体塊)がその役を担います。

プラントルは気体分子運動論で平均自由行程が分子摩擦を決めるという発想を借り、渦塊の平均移動距離を **混合長** $\ell$ と名付けました。変動速度 $u'$ は距離 $\ell$ 移動して出会う平均速度差で近似されます。

$$
\overline{u' v'} \approx -\ell^2 \left(\frac{d\bar{u}}{dy}\right)^2
$$

これにより **渦粘性**(eddy viscosity)$\nu_t$ が定義されます。

$$
\nu_t = \ell^2 \left|\frac{d\bar{u}}{dy}\right|
$$

この量は壁近傍で分子粘性より $10^4$ 倍にもなり得ます。空気の分子動粘度 $\nu \approx 1.5 \times 10^{-5}$ m²/s に対し、地表付近の渦粘性は 0.01–0.1 m²/s、大規模な大気現象では 1–100 m²/s に達します。

混合長理論は仮説ですが、0次 RANS モデル、$k$-$\varepsilon$、$k$-$\omega$ の発想骨格はすべてここに繋がります。渦動を分子のように扱うという単純化が 1925 年に作られ、100 年後も産業用 CFD ソルバの基本オプションとして生き残っています。

## NumPy で見る層流と乱流の速度分布

円管内層流には正確解があります — 回転放物面(Hagen–Poiseuille)です。乱流は冪乗則(power law)で近似すると、同じ無次元断面でずっと平坦になります。

```python
import numpy as np
import matplotlib.pyplot as plt

def laminar_poiseuille(r, R, U_max):
    """Hagen–Poiseuille: 回転放物面の速度分布。"""
    return U_max * (1.0 - (r / R) ** 2)

def turbulent_power_law(r, R, U_centerline, n=7):
    """1/n 冪乗則による乱流近似 (n=7 は Re ~ 1e5 でよく合う)。"""
    return U_centerline * (1.0 - np.abs(r) / R) ** (1.0 / n)

def law_of_the_wall(y_plus, kappa=0.41, B=5.0):
    """三領域の合成: 粘性底層 / 滑らかな緩和 / 対数則。"""
    y_plus = np.asarray(y_plus, dtype=float)
    u_visc = y_plus
    u_log = (1.0 / kappa) * np.log(np.maximum(y_plus, 1e-12)) + B
    in_buffer = (y_plus > 5) & (y_plus < 30)
    t = np.clip((y_plus - 5) / 25.0, 0.0, 1.0)
    u_blend = u_visc * (1 - t) + u_log * t
    return np.where(y_plus <= 5, u_visc,
           np.where(y_plus >= 30, u_log, u_blend))

R = 1.0
r = np.linspace(-R, R, 201)
u_lam = laminar_poiseuille(r, R, U_max=1.0)
u_tur = turbulent_power_law(r, R, U_centerline=1.0, n=7)

bulk_lam = np.trapz(u_lam * np.abs(r), r) / np.trapz(np.abs(r), r)
bulk_tur = np.trapz(u_tur * np.abs(r), r) / np.trapz(np.abs(r), r)
print(f"laminar  bulk/centerline = {bulk_lam:.3f}")
print(f"turbulent bulk/centerline = {bulk_tur:.3f}")
# laminar  bulk/centerline = 0.500
# turbulent bulk/centerline = 0.817

y_plus = np.logspace(-1, 3, 200)
u_plus = law_of_the_wall(y_plus)

fig, axes = plt.subplots(1, 2, figsize=(10, 4))
axes[0].plot(r, u_lam, label="laminar")
axes[0].plot(r, u_tur, label="turbulent (n=7)")
axes[0].set(xlabel="r/R", ylabel="u / U_max", title="pipe profile")
axes[0].legend()
axes[1].semilogx(y_plus, u_plus)
axes[1].set(xlabel="y+", ylabel="u+", title="law of the wall")
plt.tight_layout()
```

要点は二行です。**層流**の平均流速はちょうど中心線速度の半分 — 回転放物面と外接円柱の体積比です。**乱流**の平均流速は中心線速度の 81%。同じ平均流速を得るのに乱流はより低い中心線速度で済む、つまり **乱流は断面全体に運動量を均質に広げる**ということです。これが渦粘性が分子粘性より 1 万倍大きいという主張の可視化です。

## 遷移が産業で意味すること

層流と乱流の分かれ目は単なる理論問題ではありません。

- 航空機翼で**層流域を長く伸ばせば**、摩擦抗力は約 50% 減ります — NLF(natural laminar flow)設計の核心動機です。
- 熱交換器は**意図的に乱流を起こして**熱伝達係数を上げます。乱流の運動量均質化はそのまま熱の均質化です。
- パイプ送油は臨界 Re 付近でポンプ動力が急に大きくなります。遷移領域を避けて作動点を取ることが運用コストを左右します。
- LES や RANS では、最初の格子点が $y^+ \approx 1$ にあれば粘性底層を解像でき、$30 < y^+ < 300$ なら壁関数で補完します。一桁の数値が格子コストを左右します。

## 三行のまとめ

- **臨界 Re ≈ 2300** は慣性と粘性の比が擾乱を成長させるほど大きくなる地点です。外乱環境次第で 5 万まで揺らぎますが、工学実用には一つの数で十分です。
- **乱流境界層は多層構造**です。粘性底層($y^+ < 5$、線形)、緩和層($5 < y^+ < 30$)、対数則領域($30 < y^+$)。この普遍構造が RANS・LES の格子設計の基準になります。
- **混合長理論**は 100 年前の仮説ですが、渦粘性を分子粘性と同じ形で扱うという単純化が今日の産業ソルバの中で生きています。壁近傍の $\ell = \kappa y$ が対数則の出発点です。
