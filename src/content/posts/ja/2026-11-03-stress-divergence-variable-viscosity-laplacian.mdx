## 圧力は1で押しているのに、壁は1.5を支えていた

平行チャネルに圧力勾配をひとつ掛けました。上壁は加熱されていて、粘性は下壁の10分の1です。定常状態では、両壁のせん断力の和が圧力の力と等しくなるはずです。ところが計算では、壁は圧力の1.5倍の力を支えていました。流量は解析解より17.7%多く出ました。

バグは1行でした。粘性項を $\mu\nabla^2\mathbf{u}$ と書いていたのです。教科書の非圧縮 Navier–Stokes 式そのままです。この記事では、その式を流体要素ひとつから導き直します。そして「粘性一定」という仮定が導出のどこで入り込むかを示します。最後に、自分のコードの粘性項がどちらの形かを見分ける1行テストを紹介します。

## 流体要素ひとつに Newton の第2法則を書くと

小さな直方体の流体要素を切り出します。質量の代わりに密度を使うと、Newton の第2法則は単位体積あたりの式になります。

$$
\rho \frac{D\mathbf{u}}{Dt} = \rho\,\mathbf{g} + \mathbf{f}_{\text{surf}}
$$

$D/Dt$ は物質微分（要素に沿って見た時間変化）、$\rho\mathbf{g}$ は体積力、$\mathbf{f}_{\text{surf}}$ は単位体積あたりの表面力です。

表面力は要素の6つの面にかかる応力から生まれます。応力 $\sigma_{ij}$ は $i$ 軸に垂直な面にかかる $j$ 方向の力です。静止または等速の要素なら、前面と背面の応力は打ち消し合います。要素が加速するということは、前後の応力が違うということです。$x$ 方向の正味の力を書くと、3つの微分が残ります。

$$
f_x\,dx\,dy\,dz = \left(\frac{\partial \sigma_{xx}}{\partial x} + \frac{\partial \sigma_{yx}}{\partial y} + \frac{\partial \sigma_{zx}}{\partial z}\right) dx\,dy\,dz
$$

括弧の中は応力テンソルの発散です。テンソルの発散はベクトルになります。こうして運動方程式は1行にまとまります。

$$
\rho \frac{D\mathbf{u}}{Dt} = \rho\,\mathbf{g} + \nabla\cdot\boldsymbol{\sigma}, \qquad \sigma_{ij} = -p\,\delta_{ij} + \tau_{ij}
$$

$p$ は圧力、$\tau_{ij}$ は粘性応力、$\delta_{ij}$ はクロネッカーのデルタです。ここまで粘性については何も仮定していません。あるのは「粘性力は面応力の差である」という事実だけです。

下のシミュレーションで実際に操作してみましょう。加熱チャネル内の流体要素ひとつについて、上下面のせん断応力と、その差を2通りに計算した値を並べて表示します。

緑のバー $\partial\tau/\partial y$ は、要素の位置や大きさに関係なく常に −1 です。圧力の1とちょうど釣り合います。粘性比 $r$ を上げて要素を上下に動かしてみてください。オレンジのバー $\mu\,\partial^2u/\partial y^2$ は位置ごとに変わり、赤い「偽の正味の力」がゼロから外れます。

## 応力テンソルはなぜ対称でなければならないか

$\tau_{xy}$ と $\tau_{yx}$ が違うとしてみます。その差は要素を $z$ 軸まわりに回すトルクを生みます。トルクは面積 × 腕の長さ、つまり $dx^3$ に比例します。慣性モーメントは質量 × 長さ²、つまり $dx^5$ に比例します。

$$
\dot\omega_z \approx \frac{12\,(\tau_{xy}-\tau_{yx})}{\rho\,(dx^2+dy^2)}
$$

$\dot\omega_z$ は要素の角加速度です。要素をゼロまで縮めると角加速度は無限大になります。連続体が意味を持つには $\tau_{xy}=\tau_{yx}$ でなければなりません。3軸すべてに同じ論理が当てはまります。だから応力テンソルは対称で、独立成分は6つです。

## ∇·τ が μ∇²u になる2つの条件

ニュートン流体（応力がひずみ速度に線形比例する流体）の構成式は次のとおりです。

$$
\tau_{ij} = \mu\left(\frac{\partial u_i}{\partial x_j} + \frac{\partial u_j}{\partial x_i}\right) + \lambda\,\delta_{ij}\,\nabla\cdot\mathbf{u}
$$

$\mu$ は粘性係数、$\lambda$ は第2粘性係数です。括弧の中はひずみ速度テンソルの2倍です。静止流体は変形しないので、粘性応力もゼロです。[粘性の分子運動論的起源](/ja/posts/2026-05-14-viscosity-kinetic-origin-transport-analogy/)で扱った $\mu$ が、まさにこの比例定数です。

ここで発散をとります。$\mu$ は微分の外に出さず、そのまま残します。

$$
\frac{\partial \tau_{ij}}{\partial x_j} = \mu\,\nabla^2 u_i + \mu\,\frac{\partial (\nabla\cdot\mathbf{u})}{\partial x_i} + \frac{\partial \mu}{\partial x_j}\left(\frac{\partial u_i}{\partial x_j} + \frac{\partial u_j}{\partial x_i}\right) + \frac{\partial (\lambda\,\nabla\cdot\mathbf{u})}{\partial x_i}
$$

第1項だけを残すには2つの条件が必要です。ひとつは非圧縮性 $\nabla\cdot\mathbf{u}=0$ で、これで第2項と第4項が消えます。もうひとつは $\nabla\mu=0$、つまり粘性一定です。第3項はこの条件なしには消えません。

平行チャネル $u(y)$ では式がさらに簡単になります。圧力勾配を $G=-dp/dx$ とすると、定常の運動量式は次のとおりです。

$$
0 = G + \frac{d}{dy}\left(\mu\,\frac{du}{dy}\right) \;\Rightarrow\; \tau(y) = \mu\,\frac{du}{dy} = C - G\,y
$$

$C$ は壁条件 $u(0)=u(1)=0$ で決まる定数です。せん断応力は $\mu$ がどう変わっても直線です。$\mu$ が変えるのは速度勾配だけです。一方 $\mu\nabla^2u$ 形は $\mu u''=-G$ を解きます。両者の差はちょうど $\mu' u'$ です。粘性一定なら、チャネルは [Poiseuille 流れの解析解](/ja/posts/2026-03-28-poiseuille-flow-analytical-solution/)に戻ります。

## コード: 加熱チャネル、2つの粘性項

無次元チャネル $H=1$, $G=1$ で、粘性を下壁1から上壁 $1/r$ へ指数的に分布させます。静止状態から時間発展させて定常状態まで進めます。変えるのは粘性項だけです。`div` はセル面で $\mu\,\partial u/\partial y$ を作り、その差をとります。`lap` はセル中心の $\mu$ に2階差分を掛けます。最後に、内部検査体積の運動量収支（圧力の力 − 両端面のせん断力）を残差として出力します。

```python
import numpy as np

# 無次元チャネル: H=1, rho=1, 圧力勾配 G=-dp/dx=1
# 粘性は下壁 1 → 上壁 1/r へ指数的に減少 (加熱された上壁)
N = 41
y = np.linspace(0.0, 1.0, N)
dy = y[1] - y[0]

def trap(f, x):
    return float(np.sum(0.5 * (f[1:] + f[:-1]) * np.diff(x)))

def mu_profile(yy, r):
    return np.exp(-np.log(r) * yy)

def exact_heated_channel(r, m=20001):
    # mu u' = C - y,  u(0)=u(1)=0  → C = ∫y/mu / ∫1/mu
    s = np.linspace(0.0, 1.0, m)
    w = 1.0 / mu_profile(s, r)
    C = trap(s * w, s) / trap(w, s)
    du = (C - s) * w
    u = np.concatenate([[0.0], np.cumsum(0.5 * (du[1:] + du[:-1]) * (s[1] - s[0]))])
    return trap(u, s), C, -(C - 1.0)   # Q, tau_bottom, tau_top(壁が流体に及ぼす力)

def viscous_term(u, mu_c, mu_f, form):
    if form == "div":       # ∂y(mu ∂y u): 面応力の差
        tau_f = mu_f * (u[1:] - u[:-1]) / dy
        return (tau_f[1:] - tau_f[:-1]) / dy
    else:                   # mu ∇²u: 中心粘性 × 曲率
        return mu_c[1:-1] * (u[2:] - 2 * u[1:-1] + u[:-2]) / dy**2

def time_march_channel(r, form, tol=1e-10):
    mu_c = mu_profile(y, r)
    mu_f = mu_profile(0.5 * (y[1:] + y[:-1]), r)
    dt = 0.4 * dy**2 / mu_c.max()
    u = np.zeros(N)
    for n in range(1, 2_000_000):
        du = dt * (1.0 + viscous_term(u, mu_c, mu_f, form))
        u[1:-1] += du
        if np.abs(du).max() / dt < tol:
            break
    Q = trap(u, y)
    tau_f = mu_f * (u[1:] - u[:-1]) / dy
    # 内部検査体積 [dy/2, 1-dy/2] の運動量収支: 圧力の力 = 両端面のせん断力 → 残差
    balance = 1.0 * (1.0 - dy) - (tau_f[0] - tau_f[-1])
    return Q, balance, n

print(" r    Q_exact   Q_div     Q_lap     err_lap%  balance_div  balance_lap  steps")
for r in [1, 2, 5, 10, 30]:
    Qe, tb, tt = exact_heated_channel(r)
    Qd, bd, nd = time_march_channel(r, "div")
    Ql, bl, nl = time_march_channel(r, "lap")
    print(f"{r:3d}  {Qe:.5f}  {Qd:.5f}  {Ql:.5f}  {100*(Ql-Qe)/Qe:+7.1f}  {bd:+.1e}     {bl:+.1e}       {nd}")
```

## 17.7% と −0.5 が同じ原因である理由

`div` の残差は $10^{-11}$、つまり収束許容値の水準です。これは偶然ではありません。内部セルの粘性項をすべて足すと、隣り合う面応力が打ち消し合う望遠鏡和になります。残るのは両端面の応力だけです。導出で見た「面応力の差」が、離散式でもそのまま成り立っています。

`lap` にはこの構造がありません。セルごとに中心の $\mu_i$ を掛けるので、隣のセルと共有する面応力がありません。足しても消えません。その結果、$r=10$ では領域内に圧力の50%に相当する偽の体積力が生まれます。壁は圧力1に加えて偽の力0.5まで支えます。それが残差 −0.5 です。

流量の過大評価も同じ項から来ます。抜け落ちた項は $\mu' u' = -\ln r\,(C-y)$ です。大きさは $\ln r$ に比例し、両壁の近くで最大になります。`lap` は曲率を局所の粘性ひとつで決めます（$u''=-G/\mu$）。粘性が $1/r$ の上壁側では曲率が $r$ 倍になり、その効果が積み重なって速度分布全体が膨らみます。$r=30$ では誤差は39%に、残差は −1.3 になります。圧力より大きな偽の力です。

$r=1$ の −0.1% は別種の誤差です。2つの形が同じ値を出し、格子を細かくすれば減ります。2階差分の離散化誤差にすぎません。

## この誤差が実際に潜んでいる場所

温度依存粘性（加熱壁、潤滑油、マグマ）が最もよくある例です。乱流の RANS ソルバーも同じです。渦粘性 $\mu_t$ は壁でゼロで、外側に向かって数百倍に増えます。この場合、$\nabla\cdot[(\mu+\mu_t)(\nabla\mathbf{u}+\nabla\mathbf{u}^T)]$ の転置項 $\nabla\mathbf{u}^T$ も捨ててはいけません。平行流ではゼロですが、2D の剥離流では効いてきます。混相流の界面は粘性比が100倍を超えるので、さらに深刻です。

有限体積法（FVM）は面フラックスで書くので、たいてい `div` 形です。危ないのは有限差分コードと、「非圧縮だから」とラプラシアン演算子を流用したコードです。OpenFOAM の `fvm::laplacian(nuEff, U)` も面粘性を使う `div` 形です。ただし転置項は `fvc::div(nuEff*dev2(T(fvc::grad(U))))` として別に加えられます。

## 粘性一定の仮定を外す前に回す1行テスト

粘性比10の指数分布を与えて定常状態まで回します。そして、内部セルの粘性項の和と、両端面の応力差を比べます。収束許容値の範囲で一致すれば保存形です。0.5ずれていれば、どこかに $\mu\nabla^2u$ が残っています。この残差は流量より先に問題を捉えます。流量の17.7%は他の誤差に紛れますが、残差はゼロかどうかで白黒がつきます。
