## FlameMasterを動かす前に、手計算が458 Kずれていた

2018年の夏、FlameMaster(層流フレームレット計算コード)を初めてインストールしました。結果を検証するため、まず断熱火炎温度を手で計算しました。量論メタン–空気で2783 Kです。コードは2200 K台を返しました。コードが間違っていると思い、入力ファイルを長い間調べました。間違っていたのは手計算のほうでした。

原因は比熱でした。手計算では298 Kのcp(定圧比熱)を最後まで使っていました。コードは`gri.30.therm`ファイルの温度多項式を使っていました。この記事では、その多項式が何で、ファイルからどう読むのかを扱います。さらに同じエネルギー収支を2通りに解き、458 Kの差がどこから来るのかを数字で示します。

## 断熱火炎温度は面積合わせである

断熱火炎温度(adiabatic flame temperature)とは、熱損失なしで燃焼したときに生成物が到達する温度です。反応が放出した熱$Q$は、すべて生成物を温めるのに使われます。式では$Q = \int_{T_0}^{T_{ad}} C_p(T)\,dT$です。ここで$C_p$は生成物全体の熱容量です。

グラフで見ると、$C_p(T)$曲線の下の面積が$Q$に等しくなる点が$T_{ad}$です。$C_p$が一定なら面積は長方形です。$C_p$が温度とともに大きくなると、同じ面積をより短い区間で埋めます。下のシミュレーションで実際に操作してみましょう。

<NasaCpAreaFillLab />

熱が溜まる間、青い面積(NASA多項式)と赤い長方形(常温cp)は同じ速さで広がります。しかし青い曲線は1000 K以降も上がり続けます。そのため青い端点が先に止まります。化学種ごとの積み上げをオンにすると、差の大部分がH₂OとCO₂の帯から来ているのが分かります。φ(当量比)を下げるとN₂と残りのO₂の比重が増え、差は縮まります。

## 1971年、熱力学表が係数14個になった

1960年代のロケット推進剤計算にはJANAF熱化学表が使われていました。温度ごとにcp、h、sを並べた分厚い表です。計算機で平衡を解くには表を補間する必要がありました。NASA Lewis研究所のGordonとMcBrideは、これを多項式に置き換えました。1971年の報告書NASA SP-273にまとめられた形式が、現在の7係数多項式です。

1つの化学種の温度範囲を2つに分けます。通常は300–1000 Kと1000–5000 Kです。区間ごとに係数を7個持つので、1種あたり14個です。1980年代にSandiaのCHEMKINがこの形式を採用しました。以降、GRI-Mech、Cantera、FlameMasterが同じファイルをそのまま読みます。2002年には区間を増やした9係数形式も登場しました。ただし燃焼反応機構ファイルの多くはまだ7係数です。

## 導出:cp多項式1つからhとsが出てくる

出発点はcpだけです。

$$
\frac{c_p}{R} = a_1 + a_2 T + a_3 T^2 + a_4 T^3 + a_5 T^4
$$

$R$は気体定数、$a_1$–$a_5$はその区間の係数です。エンタルピーは$dh = c_p\,dT$を積分して得ます。積分定数が$a_6$です。

$$
\frac{h}{RT} = a_1 + \frac{a_2}{2}T + \frac{a_3}{3}T^2 + \frac{a_4}{4}T^3 + \frac{a_5}{5}T^4 + \frac{a_6}{T}
$$

$a_6$には生成エンタルピー(元素の基準状態からその化学種を作るときのエンタルピー)が含まれます。そのため$h(298.15\,\text{K})$を計算すると、H₂Oでは−241.8 kJ/molが出ます。エントロピーは$ds = c_p\,dT/T$を積分します。積分定数が$a_7$です。

$$
\frac{s^\circ}{R} = a_1 \ln T + a_2 T + \frac{a_3}{2}T^2 + \frac{a_4}{3}T^3 + \frac{a_5}{4}T^4 + a_7
$$

$s^\circ$は標準圧力1 barでのエントロピーで、平衡定数の計算に使います。断熱火炎温度には$h$だけで足ります。

### thermoファイルの1化学種は4行

元のノートの最初の手順は`CreateBinFile -i gri.30.therm -m gri.30.trans`でした。このコマンドが読む`.therm`ファイルは80桁の固定幅です。1つの化学種が4行を占めます。

- 1行目:化学種名、元素組成、相(G)、そして$T_{low}$、$T_{high}$、$T_{mid}$
- 2行目:**高温区間**の$a_1$–$a_5$
- 3行目:高温の$a_6$、$a_7$、低温の$a_1$–$a_3$
- 4行目:低温の$a_4$–$a_7$

高温係数が先に来ます。自分でパーサーを書くと、この順序を逆にしがちです。逆にすると常温で高温多項式を使うことになり、結果は静かに間違います。$T_{mid}$も化学種ごとに異なることがあります。1行目の66–73桁の値を読む必要があります。1000 Kをハードコードすると、出典の異なるデータを混ぜたときに壊れます。

## コード:同じ収支を2種類の比熱で解く

メタン–空気の希薄燃焼を仮定します。解離は無視し、完全燃焼だけを考えます。反応式は$\text{CH}_4 + \tfrac{2}{\phi}(\text{O}_2 + 3.76\,\text{N}_2) \to \text{CO}_2 + 2\text{H}_2\text{O} + 2(\tfrac{1}{\phi}-1)\text{O}_2 + \tfrac{7.52}{\phi}\text{N}_2$です。解く式は次のとおりです。

$$
f(T) = H_\text{prod}(T) - H_\text{reac}(T_0) = 0, \qquad T^{k+1} = T^k - \frac{f(T^k)}{C_{p,\text{prod}}(T^k)}
$$

$f$の導関数がちょうど$C_p$なので、Newton反復が自然です。係数はGRI-Mech 3.0の`.therm`からそのまま写しました。

```python
# gri.30.thermから写したNASA 7係数: (T_mid, 低温 a1..a7, 高温 a1..a7)
NASA = {
 "CH4": (1000., [5.14987613E+00,-1.36709788E-02,4.91800599E-05,-4.84743026E-08,1.66693956E-11,-1.02466476E+04,-4.64130376E+00],

 "O2":  (1000., [3.78245636E+00,-2.99673416E-03,9.84730201E-06,-9.68129509E-09,3.24372837E-12,-1.06394356E+03,3.65767573E+00],

 "N2":  (1000., [3.298677E+00,1.4082404E-03,-3.963222E-06,5.641515E-09,-2.444854E-12,-1.0208999E+03,3.950372E+00],
                [2.92664E+00,1.4879768E-03,-5.68476E-07,1.0097038E-10,-6.753351E-15,-9.227977E+02,5.980528E+00]),
 "CO2": (1000., [2.35677352E+00,8.98459677E-03,-7.12356269E-06,2.45919022E-09,-1.43699548E-13,-4.83719697E+04,9.90105222E+00],
                [3.85746029E+00,4.41437026E-03,-2.21481404E-06,5.23490188E-10,-4.72084164E-14,-4.87591660E+04,2.27163806E+00]),
 "H2O": (1000., [4.19864056E+00,-2.03643410E-03,6.52040211E-06,-5.48797062E-09,1.77197817E-12,-3.02937267E+04,-8.49032208E-01],
                [3.03399249E+00,2.17691804E-03,-1.64072518E-07,-9.70419870E-11,1.68200992E-14,-3.00042971E+04,4.96677010E+00]),
}
R = 8.314462618  # J/(mol K)

def coeffs(sp, T):
    tm, lo, hi = NASA[sp]
    return lo if T < tm else hi

def cp_R(sp, T):
    a = coeffs(sp, T)
    return a[0] + a[1]*T + a[2]*T**2 + a[3]*T**3 + a[4]*T**4

def h_RT(sp, T):
    a = coeffs(sp, T)
    return a[0] + a[1]*T/2 + a[2]*T**2/3 + a[3]*T**3/4 + a[4]*T**4/5 + a[5]/T

def mixture(phi):
    # CH4 + (2/phi)(O2 + 3.76 N2) -> CO2 + 2 H2O + 2(1/phi-1) O2 + 7.52/phi N2  (phi<=1)
    reac = {"CH4": 1.0, "O2": 2/phi, "N2": 7.52/phi}
    prod = {"CO2": 1.0, "H2O": 2.0, "O2": 2*(1/phi - 1), "N2": 7.52/phi}
    return reac, prod

def H(mix, T, frozen_cp=False):
    # 混合物エンタルピー [J]; frozen_cp=Trueなら298 Kの比熱を最後まで使う
    if frozen_cp:
        return sum(n*R*(h_RT(s, 298.15)*298.15 + cp_R(s, 298.15)*(T-298.15)) for s, n in mix.items())
    return sum(n*R*T*h_RT(s, T) for s, n in mix.items())

def Cp(mix, T, frozen_cp=False):
    Tc = 298.15 if frozen_cp else T
    return sum(n*R*cp_R(s, Tc) for s, n in mix.items())

def flame_newton(phi, frozen_cp=False, T0=1500.0, tol=1e-6):
    reac, prod = mixture(phi)
    Hr = H(reac, 298.15)
    T, it = T0, 0
    while True:
        f = H(prod, T, frozen_cp) - Hr
        dT = -f / Cp(prod, T, frozen_cp)
        T += dT; it += 1
        if abs(dT) < tol: return T, it

print("species  h(298)/kJ/mol  cp(298)/R  cp(2000)/R  jump@1000K(cp/R)")
for s in NASA:
    jump = cp_R(s, 1000.0) - cp_R(s, 999.999999)
    print(f"{s:5s} {h_RT(s,298.15)*R*298.15/1000:12.2f} {cp_R(s,298.15):10.3f} {cp_R(s,2000.):11.3f} {jump:+14.2e}")

print("\nphi   T_ad(NASA)  iters  T_ad(cp298)  iters  overshoot")
for phi in [0.5, 0.6, 0.7, 0.8, 0.9, 1.0]:
    Tn, itn = flame_newton(phi)
    Tf, itf = flame_newton(phi, frozen_cp=True)
    print(f"{phi:.1f} {Tn:10.1f} {itn:5d} {Tf:11.1f} {itf:5d} {Tf-Tn:+9.1f}")

reac, prod = mixture(1.0)
Tn, _ = flame_newton(1.0)
cpm = (H(prod, Tn) - H(prod, 298.15)) / (Tn - 298.15)
print(f"\nphi=1: mean cp of products = {cpm/Cp(prod,298.15):.3f} x cp(298)")
```

## 数字を読む:1.226、458、そして2

最初の表で、$h(298)$が文献値と合うかをまず確認します。CO₂ −393.51、H₂O −241.82、CH₄ −74.60 kJ/molです。係数を写すときの誤記はここですぐに分かります。1000 Kでの低温・高温cpの差は$10^{-6}$以下です。GRIデータは$T_{mid}$でつながるように調整されています。

cpの温度依存性は化学種ごとに違います。298 Kから2000 Kまでで、N₂は24%、H₂Oは54%、CO₂は63%上がります。CH₄は2.8倍です。生成物全体で平均すると298 Kの値の1.226倍です。温めるべき温度幅はその分だけ短くなります。$(2783.4 - 298)/(2325.6 - 298) = 1.226$がまさにこの比です。

過大評価の幅はφとともに大きくなります。φ = 0.5で154 K、φ = 1で458 Kです。火炎が熱いほど、cpが大きく上がった区間を長く通るからです。常温cp側の反復は常に2回です。$f(T)$が直線なので、最初のNewton 1回で根に届きます。2回目は確認です。

この2325.6 Kも実際の値ではありません。2000 Kを超えると、CO₂とH₂OがCO、H₂、OHに一部解離します。解離は吸熱です。平衡計算をすると量論メタン–空気は約2225 Kになり、さらに100 K下がります。解離まで入れるには平衡定数が必要です。そこで$s^\circ$と$a_7$が使われます。

## この多項式が今使われている場所

FlameMasterノートの次の手順は、`ScanMan`で反応機構を読むことでした。逆反応の速度定数は平衡定数から計算されます。その平衡定数は、この多項式の$h$と$s$から出てきます。熱力学データの誤りは、温度だけでなく反応速度まで汚染します。逆反応定数の計算は[平衡定数の単位を扱った記事](/ja/posts/2026-10-22-reverse-rate-kp-kc-unit-dissociation/)で詳しく見ました。

フレームレットライブラリ(flamelet library)でも同じです。FlameMasterが作る温度テーブルはβ-PDFで積分され、乱流燃焼モデルに入ります。テーブルの温度が数百Kずれていれば、平均温度も同じだけずれます。その積分過程は[presumed β-PDFの記事](/ja/posts/2026-10-27-presumed-beta-pdf-mean-flame-temperature/)にあります。燃焼器の中でこの熱が圧縮性流れをどう変えるかは、[Rayleigh流れと熱的チョーク](/ja/posts/2026-11-17-rayleigh-flow-thermal-choking-combustor/)で扱いました。

CFDコードが化学種輸送方程式を解くときも同様です。セルごとに$h$から$T$を逆算します。上のコードのNewton反復が、毎セル・毎時間ステップで回ります。そのため商用コードは係数をあらかじめテーブル化しています。

## 反応機構ファイルを受け取ったら、まず手で確かめる3つの数字

新しい反応機構を受け取ったら、まず`.therm`を開きます。主要生成物の$h(298)$が文献値と合うかを計算します。$T_{mid}$でcpがつながっているかを確認します。最後に完全燃焼の断熱火炎温度をNewton数回で求め、コードの結果と比べます。コードの結果がこれより100 K前後低ければ解離の効果です。400 K以上ずれていれば、どこかに常温cpが隠れています。
