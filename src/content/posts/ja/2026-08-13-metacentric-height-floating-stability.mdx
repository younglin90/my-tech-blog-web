コンテナ船の重心は、水没部分の中心より数メートル上にあります。重い側が上に載っているのに、船は自分で起き上がります。逆に重心が浮心より下にあるのに転覆する台船(barge)もあります。上下関係だけでは何も決まらないということです。この記事では、その判定を実際に下す量 — メタセンタ高さ $GM$ — がどこから来るのか、そしてタンクの液体がなぜその値を丸ごと消してしまうのかを扱います。

## 重心が浮心より上にある

まず記号を揃えます。$K$ は竜骨(keel、船底中心)、$G$ は重心、$B$ は浮心です。浮心は水没体積の図心(centroid)です。アルキメデスが述べたのは大きさだけです。浮力の大きさは押しのけた水の重さに等しく、作用線は水没体積の図心を通ります。

まっすぐ浮いているとき、$G$ と $B$ は同じ鉛直線上にあります。重力と浮力は大きさが等しく向きが逆なので、モーメントはゼロです。この状態では $G$ が上でも下でも何も起こりません。安定性は静止状態ではなく、**わずかに傾けたときに何が生じるか**で定義されます。

傾けると事情が変わります。$B$ は水没形状の図心なので、形状が変われば一緒に移動します。$G$ は船と一緒に回転するだけで、船の中では動きません。二つの鉛直線がずれることでモーメントの腕ができます。これを復原挺(righting arm)$GZ$ と呼び、排水量 $\Delta$ に対して復原モーメントは $M = \Delta \cdot GZ$ です。

$B$(緑)が傾けた側へ引かれ、$G$(黄)を通る鉛直線との間隔が $GZ$ です。紫の $M$ は浮力の作用線が船体中心線と交わる点です。`KG` スライダを 7.33 m より上に上げると $M$ が $G$ の下に下がり、船は戻る代わりに片側に倒れたまま止まります。

## $BM = I/\nabla$ — 水線面の慣性モーメントがすべて

小さな傾斜角 $\phi$ では、水没形状の変化はくさび二つに整理されます。片舷で水面上に出たくさびと、反対舷で新たに沈んだくさびです。排水量は変わらないので二つの体積は等しく、左右に離れています。この体積移動が $B$ を動かします。

水線面(waterplane、水面が船体を切った断面)の微小帯 $dA$ が中心線から $x$ だけ離れていれば、その帯が生む体積変化は $x\phi\,dA$、モーメントは $x^2\phi\,dA$ です。全部足すと断面二次モーメントが出ます。

$$
\overline{BB'} = \frac{\phi \int_A x^{2}\,dA}{\nabla} = \frac{I\,\phi}{\nabla}, \qquad BM = \frac{I}{\nabla}
$$

$I$ は中心線まわりの水線面の断面二次モーメント、$\nabla$ は排水体積です。幅 $b$ の長方形断面なら単位長さあたり $I = b^3/12$、$\nabla = b\,T$ なので

$$
BM = \frac{b^{2}}{12\,T}
$$

となります。ここで幅が**三乗で**入り、分母の $\nabla$ で一度打ち消されて二乗が残る点が重要です。幅を 20% 広げれば $BM$ は 44% 大きくなります。カヌーが不安定で筏が安定なのはこのためです。そして判定式は一行で終わります。

$$
GM = KB + BM - KG
$$

$KB$ は浮心高さ、$KG$ は重心高さです。$GM > 0$ なら復原、$GM < 0$ なら転覆です。幅 $b = 16$ m、喫水 $T = 4$ m の台船なら $KB = 2.0$ m、$BM = 5.333$ m なので $KM = 7.333$ m です。$KG$ が 6.6 m なら余裕は 0.733 m しかありません。

## $GM \sin\phi$ が裏切る角度

$GM$ は $\phi \to 0$ での傾きです。小角度では $GZ \approx GM \sin\phi$ がよく合います。問題はこの近似がいつ崩れるかです。

崩れる地点は幾何が決めます。水線面が変わらない間だけ $I$ が一定だからです。上の台船は乾舷(freeboard、水面上の船体高さ)が 4 m なので、$\tan\phi = 2 \times 4/16$、つまり 26.6° で甲板端が水に浸かります。その瞬間から水線面はもう広がれず、むしろ縮みます。$BM$ が崩れ、$GZ$ 曲線は折れます。

上のシミュレーションで `hold heel` を押し、角度を 30° 超まで動かすと、緑の実線(厳密値)が紫の点線($GM\sin\phi$)から離れていくのが見えます。二つの曲線の符号が分かれる角度が消失角です。

## タンクの液体が GM を丸ごと奪う

次に船内に液体タンクを入れます。バラストタンク、燃料タンク、貨物タンク、消火水で浸かった車両甲板まで、すべて同じ問題です。

液体の重さは傾けても変わりません。移動するだけです。ところがその移動が $G$ を低い側の舷へ引っ張ります。計算の構造は $BM$ とまったく同じです。タンク内の自由表面もひとつの水線面であり、傾けばくさび二つが入れ替わります。

$$
\delta GM = \frac{\rho_f\, i}{\rho\, \nabla}
$$

$i$ はタンク自由表面の断面二次モーメント、$\rho_f$ はタンク液体の密度、$\rho$ は外の水の密度です。この値は船体から実際に引くのではなく、$G$ がその分だけ上がったものとして扱います(仮想上昇、virtual rise)。**タンクにどれだけ液体が入っているかは式に現れません。**あふれるほど満たして自由表面がなくなるか、完全に空になるかしない限り、20 cm でも 2 m でも損失は同じです。

## 隔壁一枚が損失を 1/4 にする

幅 $b_t$ のタンクを $n$ 個に分ければ、各区画の幅は $b_t/n$ で、区画が $n$ 個です。

$$
i = n \cdot \frac{(b_t/n)^{3}}{12} = \frac{b_t^{3}}{12\,n^{2}}
$$

損失は $1/n$ ではなく $1/n^2$ で減ります。幅の三乗が個数の一乗に勝つからです。上の台船に幅 12 m のタンクが一つあれば $i = 144$ m⁴、$\nabla = 64$ m³/m なので $\delta GM = 2.195$ m です。$GM$ の 0.733 m はとうに消えています。中央に隔壁を一枚立てるだけで 0.549 m に落ち、船は再び起き上がります。

タンカーの中央に縦隔壁が立っているのはこのためです。積載量も重心高さも変わりません。自由表面の幅だけが半分になります。

## Python で描いた GZ 曲線と消失角

$GM$ は接線の傾き一つにすぎません。大角度の $GZ$ は、水没多角形を直接切って図心を求めるほうが速いです。船体断面を多角形として置き、水没面積が排水面積と等しくなる水線高さを二分法で探し、その多角形の図心を計算します。

```python
import math

def poly_area_centroid(poly):
    a = cx = cy = 0.0
    n = len(poly)
    for i in range(n):
        x0, y0 = poly[i]
        x1, y1 = poly[(i + 1) % n]
        cr = x0 * y1 - x1 * y0
        a += cr
        cx += (x0 + x1) * cr
        cy += (y0 + y1) * cr
    a *= 0.5
    if abs(a) < 1e-14:
        return 0.0, 0.0, 0.0
    return a, cx / (6 * a), cy / (6 * a)

def clip_below(poly, phi, h):
    """傾斜角 phi のとき、地球基準の高さが h 以下の部分だけを残す"""
    def f(p):
        return p[1] * math.cos(phi) - p[0] * math.sin(phi) - h
    out = []
    n = len(poly)
    for i in range(n):
        p, q = poly[i], poly[(i + 1) % n]
        fp, fq = f(p), f(q)
        if fp <= 0.0:
            out.append(p)
        if (fp < 0.0) != (fq < 0.0):
            t = fp / (fp - fq)
            out.append((p[0] + t * (q[0] - p[0]), p[1] + t * (q[1] - p[1])))
    return out

def waterline_offset(poly, phi, area0):
    """水没面積が area0 になる水線高さを二分法で探す"""
    lo, hi = -60.0, 60.0
    for _ in range(80):
        mid = 0.5 * (lo + hi)
        a, _, _ = poly_area_centroid(clip_below(poly, phi, mid))
        if a < area0:
            lo = mid
        else:
            hi = mid
    return 0.5 * (lo + hi)

def righting_arm(beam, depth, draft, kg, phi):
    hull = [(-beam / 2, 0.0), (beam / 2, 0.0), (beam / 2, depth), (-beam / 2, depth)]
    h = waterline_offset(hull, phi, beam * draft)
    _, xb, yb = poly_area_centroid(clip_below(hull, phi, h))
    return xb * math.cos(phi) + (yb - kg) * math.sin(phi), xb, yb

def gz_curve(beam, depth, draft, kg, deg_max=70, step=1):
    return [(d, righting_arm(beam, depth, draft, kg, math.radians(d))[0])
            for d in range(0, deg_max + 1, step)]

BEAM, DEPTH, DRAFT = 16.0, 8.0, 4.0
KG = 6.6
KB = DRAFT / 2
BM = BEAM ** 2 / (12 * DRAFT)
GM = KB + BM - KG
print(f"KB={KB:.3f} m  BM=B^2/12T={BM:.3f} m  KM={KB+BM:.3f} m  KG={KG:.3f} m  GM={GM:.3f} m")
print(f"deck edge immerses at phi = {math.degrees(math.atan(2*(DEPTH-DRAFT)/BEAM)):.1f} deg")
print()
print(" phi[deg]   GZ[m]   GM*sin(phi)[m]   error[%]")
for d, gz in gz_curve(BEAM, DEPTH, DRAFT, KG, 60, 5):
    lin = GM * math.sin(math.radians(d))
    err = f"{100 * (lin - gz) / gz:8.1f}" if abs(gz) > 0.01 else "       -"
    print(f"  {d:5.1f}   {gz:7.4f}   {lin:11.4f}   {err}")

curve = gz_curve(BEAM, DEPTH, DRAFT, KG, 70, 1)
dmax, gzmax = max(curve, key=lambda t: t[1])
vanish = next((d for d, g in curve if d > 5 and g <= 0.0), None)
print()
print(f"max GZ = {gzmax:.3f} m at {dmax} deg,  vanishing stability at {vanish} deg")
```

5° での誤差は 2.7% です。30° では $GM\sin\phi$ が実際の $GZ$ の半分しかありません。甲板が浸かるまで水線面が広がり続け、実際の復原力が線形予測より大きくなるからです。ところが 45° を超えると符号が逆転し、今度は線形近似が危険側に嘘をつきます。50° で実際の $GZ$ はゼロなのに、$GM\sin\phi$ はまだ 0.56 m を約束します。

自由表面損失は多角形を切らなくても確認できます。甲板が浸かるまでは舷側が垂直なので、復原挺に閉じた式があるからです。損失は仮想上昇なので、$GM$ から $\delta GM$ を引いて入れるだけです。

```python
import math

BEAM, DRAFT, KG = 16.0, 4.0, 6.6
NABLA = BEAM * DRAFT
BM = BEAM ** 2 / (12 * DRAFT)
GM = DRAFT / 2 + BM - KG

def free_surface_loss(rho_f, rho, b, n, nabla):
    """隔壁 n 枚で分けた幅 b のタンクの自由表面損失 [m]"""
    i_free = n * (b / n) ** 3 / 12
    return rho_f * i_free / (rho * nabla)

def wall_sided_gz(gm, bm, phi):
    """甲板が浸かる前、舷側が垂直な範囲の復原挺"""
    return (gm + 0.5 * bm * math.tan(phi) ** 2) * math.sin(phi)

print(" tanks   i[m^4]   dGM[m]   GM_eff[m]   GZ(20deg)[m]")
for n in (1, 2, 3, 4):
    d_gm = free_surface_loss(1000.0, 1025.0, 12.0, n, NABLA)
    gz20 = wall_sided_gz(GM - d_gm, BM, math.radians(20))
    print(f"  {n:4d}  {n*(12.0/n)**3/12:7.1f}  {d_gm:7.3f}   {GM-d_gm:8.3f}   {gz20:11.3f}")
```

隔壁一枚で $i$ が 144 から 36 へ、ちょうど 1/4 になります。20° での復原挺は −0.379 m から +0.184 m へ符号が変わります。ここで使った閉じた式 $GZ = (GM + \tfrac{1}{2}BM\tan^2\phi)\sin\phi$ は、甲板が浸かる前の範囲では多角形計算と一致します。損失がないときの 20° の値 0.3716 m が上の表と同じです。

## 6-DOF VOF 解析に船を浮かべる前に

浮体を CFD で解いた瞬間、これらの値はすべて検証基準になります。

第一に、初期喫水を合わせる前に $GM$ を手計算しておきましょう。VOF で自由表面を捉え([界面捕捉手法の比較](/ja/posts/interface-capturing/))、6-DOF 剛体運動を付ければ([クォータニオンによる剛体 FEM](/ja/posts/2026-04-20-fem-rigid-body-dynamics-quaternion/))、船は自分で揺れます。その自由減衰振動の周期 $T_\phi = 2\pi k/\sqrt{g\,GM}$ が手計算値と合わなければ、格子か入力した慣性モーメントを疑うべきです。$k$ は横揺れの回転半径です。

第二に、格子解像度が $BM$ を直接削ります。$BM$ は水線面の $x^2$ 重み積分なので、舷側近くのセルが最も大きく寄与します。自由表面が二、三セルにわたって滲むと有効水線面幅がぼやけ、復原力が過小評価されます。喫水線付近を局所的に細かく取るほうが安上がりです。

第三に、タンクを満たしたまま解析するなら、自由表面損失は解析の中で自動的に出てきます。スロッシングと一緒に出てくるということです。液体が船体運動と位相がずれると、準静的な $\delta GM$ より悪くも良くもなり得ます。自由水面を陰的に扱う手法([Casulli–Zanolli の入れ子 Newton 法](/ja/posts/2026-05-16-casulli-zanolli-2012-nested-newton-free-surface/))が要るのもこの地点です。手計算はそこでも有効です。ただし答えとしてではなく、結果を疑うための基準線として使います。
