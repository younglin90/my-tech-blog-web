## 断面が2倍になる継手で、圧力はどれだけ上がるか

細い管が突然太い管につながります。断面積は2倍、流速は半分になります。ベルヌーイの式では圧力上昇は $\tfrac12\rho V_1^2 \times 0.75$ です。実測すると $0.5$ 付近になります。ベルヌーイは1.5倍大きく見積もっているのです。

この差を最初に式にしたのは、18世紀フランスの工兵学者たちでした。本記事ではその式、Borda–Carnotの式をたどります。導出にはエネルギーではなく運動量を使います。損失の行き先はCarnotの「失われた速度」の定理で説明します。最後に、2つの流れが混ざるダクトを実際に解いて数値で確認します。読み終えると、急拡大の損失係数 $K=(1-\sigma)^2$ がいつ正しく、いつ外れるかを判断できます。

## 革命期の工兵将校が見た「失われた速度」

Lazare Carnotは1771年にMézièresの王立工科学校に入学しました。師はGaspard Mongeです。Mongeはこの学校の数学教授職をBossutから引き継いでいました。Bossutはのちにダランベールと流体抵抗を測定します。Bordaはそれ以前にニュートンの流体抵抗を深く研究した学者です。

Carnotは1784年に機械に関する論文を発表しました。そこで非弾性衝突における「エネルギー損失」という、当時としては耳慣れない概念を導入します。2つの物体がぶつかって一体になると、運動量は残りますが運動エネルギー(vis viva、当時の言葉で「活力」)は減ります。Carnotはその減少量を正確に数えました。各物体が衝突で**失った速度**の運動エネルギーをすべて足した値が損失だ、というものです。

Carnotは同じ考えを管内流れに当てはめました。断面が急に広がったり狭まったりすると、ベルヌーイの定理は成り立ちません。損失ヘッド(流れが失うエネルギーを高さに換算した値)が生じます。この関係式が今日のBorda–Carnotの式です。Carnotはのちに革命政府の公安委員会で軍を再編しました。息子は熱力学のSadi Carnotです。

スライダー $\sigma=A_1/A_2$ を動かし、中央のグラフの2本の圧力線を比べてください。紫の破線(ベルヌーイ)と緑の実線(Borda–Carnot)の間が赤い損失帯です。$\sigma$ が小さいほど噴流が強く「ぶつかり」、損失が大きくなります。

## 導出:段差面の圧力は $p_1$ という仮定ひとつ

検査体積(質量・運動量の収支を数える仮想の箱)を、段差の直後から流れが再び一様になる位置までとります。壁面摩擦は無視します。質量保存は単純です。

$$V_2 = \sigma V_1, \qquad \sigma = \frac{A_1}{A_2}$$

$V_1, V_2$ は細い管と太い管の平均流速、$\sigma$ は断面積比です。

鍵となる仮定はひとつです。段差面(広がる壁、面積 $A_2-A_1$)に作用する圧力が、流入噴流の圧力 $p_1$ に等しいというものです。段差の角の後ろの渦領域はほぼ静止しており、噴流はその脇をまっすぐ抜けます。そのため噴流の圧力がそのまま静止流体に伝わります。この仮定のもとで軸方向の運動量収支は次のとおりです。

$$p_1 A_1 + p_1 (A_2 - A_1) - p_2 A_2 = \rho V_2^2 A_2 - \rho V_1^2 A_1$$

左辺は入口・段差面・出口に働く圧力の合力、右辺は流出運動量流束から流入流束を引いた値です。整理すると次を得ます。

$$p_2 - p_1 = \rho V_2 (V_1 - V_2) = \rho V_1^2\,\sigma(1-\sigma)$$

一方、ベルヌーイは $p_2-p_1=\tfrac12\rho V_1^2(1-\sigma^2)$ を与えます。$\sigma=0.5$ なら運動量側は $0.25\rho V_1^2$、ベルヌーイ側は $0.375\rho V_1^2$ です。冒頭の1.5倍はこの比です。両者の差を単位質量あたりのエネルギーに直すと損失になります。

$$h_L = \frac{(V_1 - V_2)^2}{2g} = (1-\sigma)^2 \frac{V_1^2}{2g}$$

$h_L$ は損失ヘッド、$g$ は重力加速度です。損失係数 $K=(1-\sigma)^2$ は、管を大きなタンクへ放出する極限($\sigma\to0$)で1になります。噴流の運動エネルギーがすべて失われるという意味です。

## 損失は失われた速度の運動エネルギーである

$h_L$ の分子 $(V_1-V_2)^2$ をもう一度見てください。流体粒子は $V_1$ で入り $V_2$ で出ていきます。失った速度は $V_1-V_2$ です。損失はちょうど、その失った速度で動く運動エネルギーです。Carnotの衝突定理と同じ形です。

質量 $m_1$ が速度 $V_1$ で静止した $m_2$ にぶつかって一体になる場合を考えます。衝突後の速度は $V=m_1V_1/(m_1+m_2)$ です。損失は次のとおりです。

$$\Delta E = \tfrac12 m_1 (V_1 - V)^2 + \tfrac12 m_2 (0 - V)^2$$

各項は、その物体が失った(または得た)速度の運動エネルギーです。急拡大では、段差の後ろの静止流体が $m_2$ の役を担います。ただしその流体は下流へ運ばれません。質量流量に寄与しないので、第2項が消えます。

この見方は、2つの流れが混ざる場合にそのまま拡張できます。速度の異なる流管(流線で囲まれた細い管)がひとつのダクトで混ざると、損失は次のようになります。

$$\Delta e = \frac{1}{Q}\sum_k \tfrac12 (u_k - V_2)^2\, \Delta\psi_k$$

$Q$ は総流量、$\Delta\psi_k$ は流管 $k$ が運ぶ流量、$u_k$ はその流管の入口速度です。混合過程の詳細(乱流か層流拡散か)はこの式に入りません。運動量と質量が合えば損失は決まります。以前の記事[流線ごとに異なるベルヌーイ定数](/ja/posts/2026-09-03-bernoulli-constant-across-streamlines/)で見たように、流管ごとにベルヌーイ定数が違うことがここで効いてきます。

## コード:2つの流れが混ざるダクトを流管80本で

実際の段差後ろの渦には2D計算が必要です。ここではもっと単純で、同じ原理を含む問題を解きます。断面一定のダクトに、中央の噴流(幅 $\sigma$、速度1)と外側の遅い流れ(速度 $\varepsilon$)が流入します。壁はすべり壁です。2つの流れは粘性 $\nu$ で混ざります。

境界層近似(流れ方向の拡散を無視する放物型近似)をvon Mises座標(流れ関数 $\psi$ を横方向座標に使う変換)で書くと次のようになります。

$$\frac{\partial u}{\partial x} = \nu\,\frac{\partial^2}{\partial \psi^2}\!\left(\frac{u^2}{2}\right) - \frac{1}{\rho u}\frac{dp}{dx}$$

各格子は同じ流量を運ぶ流管1本です。圧力勾配 $dp/dx$ は、流管幅の和 $\sum \Delta\psi/u$ がダクト幅に等しくなるよう、毎ステップニュートン法で決めます。こう書くと離散式でも運動量が厳密に保存されます。$\varepsilon\to0$ がBorda–Carnotの静止流体極限です。

```python
import numpy as np

def stream_tubes(sigma, eps, n=40):
    # 流管 n 本(等流量 dpsi): 中央は噴流(u=1)、外側は遅い流れ(u=eps)
    Q = sigma + eps * (1 - sigma)
    dpsi = Q / n
    n_jet = round(n * sigma / Q)
    k = np.arange(n)
    jet = np.abs(k - (n - 1) / 2) < n_jet / 2
    u = np.where(jet, 1.0, eps)
    return u, dpsi, jet

def mix_step(u, P, dpsi, nu, H, dx):
    q = u**2 / 2
    qg = np.concatenate(([q[0]], q, [q[-1]]))          # すべり壁: dq/dpsi = 0
    Dq = nu * (qg[2:] - 2 * q + qg[:-2]) / dpsi**2     # (1/u) * 粘性項
    for _ in range(20):                                 # ダクト幅の保存から dp/dx を決定 (ニュートン法)
        un = u + dx * (Dq - P / u)
        if un.min() <= 0:
            return None, P                              # 遅い流管が停止 -> 逆流
        f = np.sum(dpsi / un) - H
        df = np.sum(dpsi * dx / (u * un**2))
        P -= f / df
        if abs(f) < 1e-13:
            break
    return u + dx * (Dq - P / u), P

def mixing_duct(sigma, eps, nu, n=40, tol=1e-3):
    u, dpsi, jet = stream_tubes(sigma, eps, n)
    u0 = u.copy()
    H = np.sum(dpsi / u)                    # ダクト幅 (~1)
    Q = n * dpsi                            # 各流管は同じ流量
    V2 = Q / H
    M0 = np.sum(u * dpsi) / H               # 入口運動量流束 / H
    dp_mom = M0 - V2**2                     # 運動量保存が与える圧力上昇
    E0 = np.sum(u**2 / 2 * dpsi) / Q
    x, p, P, x99 = 0.0, 0.0, 0.0, None
    while np.abs(u - V2).max() > tol:
        dx = 0.4 * dpsi**2 / (nu * u.max())
        un, P = mix_step(u, P, dpsi, nu, H, dx)
        if un is None:
            return dict(stall=True, x=x, dp=p, dp_mom=dp_mom)
        u, x, p = un, x + dx, p + P * dx
        if x99 is None and p >= 0.99 * dp_mom:
            x99 = x
    loss = E0 - (p + np.sum(u**2 / 2 * dpsi) / Q)
    # Carnot の定理: 各流管が失った(得た)速度の運動エネルギーの和
    carnot = np.sum(0.5 * (u0 - V2)**2 * dpsi) / Q
    return dict(stall=False, x99=x99, V2=V2, dp=p, dp_mom=dp_mom,
                dp_bern=0.5 * (1 - V2**2), loss=loss, carnot=carnot)

print("Borda-Carnot limit (eps=0, sigma=0.5): dp = %.4f, loss = %.4f, Bernoulli dp = %.4f"
      % (0.5 * 0.5, 0.5 * 0.5**2, 0.5 * (1 - 0.5**2)))
print(" eps    nu     V2    dp_num  dp_mom  dp_Bern  loss    Carnot   x99")
for eps, nu in [(0.8, 0.004), (0.6, 0.004), (0.4, 0.004), (0.2, 0.004),
                (0.1, 0.004), (0.05, 0.004), (0.2, 0.002), (0.2, 0.008)]:
    r = mixing_duct(0.5, eps, nu, n=80)
    if r["stall"]:
        print(f"{eps:4.2f} {nu:6.3f}  STALL at x={r['x']:.2f}  "
              f"dp={r['dp']:.4f} of {r['dp_mom']:.4f}")
        continue
    print(f"{eps:4.2f} {nu:6.3f} {r['V2']:6.3f} {r['dp']:7.4f} {r['dp_mom']:7.4f} "
          f"{r['dp_bern']:7.4f} {r['loss']:7.4f} {r['carnot']:7.4f} {r['x99']:6.1f}")
```

## 0.1599と0.3270、そしてνが変えられなかったもの

出力表から3つのことが読み取れます。

第一に、`dp_num` と `dp_mom` はすべての行で小数第4位まで一致します。数値解は混合過程を1ステップずつ計算しました。それでも結果は、入口と出口の運動量の差ですでに決まっていました。圧力上昇は運動量収支の帰結です。

第二に、`loss` と `Carnot` もすべての行で一致します。ダクトは、各流管の速度が $V_2$ に変わる間にエネルギーを失いました。その量は、失った速度の運動エネルギーの和と厳密に一致します。Carnotが衝突で数えた量そのものです。

第三に、$\nu$ を0.002から0.008まで4倍変えました。`x99`(最終圧力の99%に達する距離)は16.2から4.1に縮みました。`dp_num` と `loss` は0.1599、0.0831のままです。粘性は損失が**どこで**生じるかだけを決めます。**どれだけ**生じるかは決めません。

ベルヌーイ(噴流の流線基準)は同じ行で0.3270を与えます。実際の2.0倍です。$\varepsilon=0.8$ では0.0960対0.0100で、9.6倍まで開きます。2つの流れの速度差が小さいほど圧力上昇自体が小さくなりますが、ベルヌーイはそれに追従できません。$\varepsilon$ を下げると `dp_num` は0.2255($\varepsilon=0.05$)まで近づきます。Borda–Carnotの極限値0.25の方向です。

$\varepsilon=0.03$ 以下では計算が止まります。逆圧力勾配が遅い流体を止めてしまうからです。放物型の前進計算は逆流を表現できません。実際の急拡大では、まさにこの位置に再循環領域ができます。Bordaの仮定「段差面の圧力 = $p_1$」は、この再循環領域を静止流体で置き換えたものです。

## 今日のBorda–Carnot:配管網のK値から1Dコードまで

配管設計便覧にある急拡大の損失係数 $K=(1-A_1/A_2)^2$ はこの式そのものです。乱流の実験値ともおおむねよく合います。段差後ろの再循環が静止流体の仮定に近いからです。この値は配管網解析コード、1D熱流体システムコード、燃料系統解析で今も既定値として使われています。

合わない場合もはっきりしています。第一に、入口の速度分布が一様でなければ、運動量流束は $\rho V^2 A$ ではありません。完全発達した層流管内流なら、運動量補正係数 $\beta=4/3$、エネルギー補正係数 $\alpha=2$ がつきます。[管断面の速度分布と運動エネルギー係数](/ja/posts/2026-09-17-kinetic-energy-coefficient-pipe-profile/)で扱った $\alpha$ がそのまま式に入ります。第二に、低レイノルズ数では再循環領域そのものが長くなり、壁面摩擦が混ざってきます。第三に、緩やかなディフューザーでは剥離が遅れ、$K$ はずっと小さくなります。

CFDでも同じ問いが出てきます。準1次元(quasi-1D)の管内流コードは、面積変化項 $p\,dA/dx$ を別に離散化します。面積が1セル内で急変するとき、その $p$ をどの値にとるかがまさにBordaの仮定です。上流の圧力を使えばBorda–Carnot損失が出ます。滑らかなノズルのように扱えば、損失のないベルヌーイ解が出ます。エジェクター(速い噴流で遅い流れを引き込む装置)やジェットポンプの混合管設計も、上のコードの運動量収支をそのまま使います。

## 急拡大のKを表から取り出す前に確かめる2つの条件

$K=(1-\sigma)^2$ を使う前に2点を確認します。入口の速度分布はほぼ一様か(乱流が完全発達していれば $\beta\approx1.02$ で十分です)。段差の後ろに静止流体とみなせる再循環領域ができるほどレイノルズ数は大きいか。どちらも満たせば、圧力上昇は $\rho V_2(V_1-V_2)$ で、損失は失われた速度の運動エネルギーです。混ざり方を問う必要はありません。
