保存形スキームは質量を一粒も失いません。面を通って出た量がそのまま隣が受け取った量になるので、領域全体の総和は機械精度まで一定です。ところがそのスキームが密度 −0.003 を作ります。総和は合っているのに個別のセルが負です。

`|dF| scale` を上げると、セル2の両脇の $\theta$ が黄色になって下がります。面が削る量が増えるほど、高次の割合を落とすダイヤルです。

<ThetaBudgetSplitDial />

"full budget per face" を押すと二つの $\theta$ は再び1の近くまで跳ねますが、セル2のバーだけが緑の底線を突き抜けます。面ごとには合法です。セルは左右の予算が重なって負になります。

## 発散ではなく定義域の外へ出たのです

ログがNaNで終わったとき、まず疑うのは時間刻みです。CFLを半分に下げます。それでも落ちます。格子を細かくします。もっと早く落ちます。

このときは安定性の問題ではない可能性が高いです。先に見るべきは音速の行です。

$$
c = \sqrt{\frac{\gamma p}{\rho}}
$$

$\gamma$ は比熱比、$p$ は圧力、$\rho$ は密度です。$p$ か $\rho$ のどちらかが負になった瞬間に $c$ はNaNになります。次のステップの時間間隔もNaN、その次のフラックスも全部NaN。実際の事故はNaNが出力された行より一ステップ手前ですでに終わっています。

NaNの出どころはたいていここです。Euler方程式の解が生きているためには、保存変数 $\mathbf{U} = (\rho,\ \rho u,\ E)$ が**許容集合**(admissible set)の中になければなりません。

$$
G = \left\{ \mathbf{U} : \rho > 0,\ \ p = (\gamma-1)\left(E - \frac{(\rho u)^2}{2\rho}\right) > 0 \right\}
$$

保存性は「総和が保たれる」という性質であって、「各セルが $G$ の中に留まる」という性質ではありません。二つはまったく別の要求です。

## 高次再構成は符号を守ってくれません

$G$ を外れる典型的な状況は真空の近くです。強い膨張波、高高度の再突入流れ、キャビテーション気泡の内部、そして爆風の後方。こうした場所で $\rho$ と $p$ は $10^{-4}$ のレベルまで落ちます。

ここにMUSCLやWENO再構成を載せると、セル平均 $\bar\rho_i$ が正でも面の値 $\rho_{i+1/2}^{L}$ は負になり得ます。勾配にセル幅の半分を掛けて足すからです。再構成はセル平均を保存するだけで、符号については何も約束しません。

圧力はもっと悪いです。$p$ は保存変数の**非線形**関数です。$\rho$ と $E$ がそれぞれ正でも、運動エネルギー $(\rho u)^2/2\rho$ が $E$ を超えれば $p$ は負になります。後で回す二重希薄波では、密度が0.37と無事な状態で圧力のほうが先に −0.163 まで落ちます。

初期条件をほどくと、この順序は不自然ではありません。$\rho=1$、$u_0=4$、$p=0.4$、$\gamma=1.4$ なら比内部エネルギーは $p/((\gamma-1)\rho)=1$ です。運動エネルギーは $u_0^2/2=8$ です。内部エネルギーは運動エネルギーの8分の1しかありません。再構成が運動量を少し大きめに取ると $(\rho u)^2/(2\rho)$ が $E$ を超えます。すると $p=(\gamma-1)\left(E-\frac{(\rho u)^2}{2\rho}\right)$ が先に負になります。密度の式はその割り算をしないので、0.37のまま残ります。

## Lax–FriedrichsがCFL 0.5で耐える理由

では何を信じられるのか。1次のLax–Friedrichs(LF)フラックスです。

$$
\hat{\mathbf{F}}^{LF}_{i+1/2} = \frac{1}{2}\left[\mathbf{F}(\mathbf{U}_i) + \mathbf{F}(\mathbf{U}_{i+1}) - \alpha\,(\mathbf{U}_{i+1} - \mathbf{U}_i)\right]
$$

$\alpha = \max_j(|u_j| + c_j)$ は最大特性速度です。このフラックスで更新式を展開すると、次のように整理されます。

$$
\mathbf{U}_i^{n+1} = (1 - \lambda\alpha)\,\mathbf{U}_i + \frac{\lambda\alpha}{2}\left(\mathbf{U}_{i+1} - \frac{\mathbf{F}_{i+1}}{\alpha}\right) + \frac{\lambda\alpha}{2}\left(\mathbf{U}_{i-1} + \frac{\mathbf{F}_{i-1}}{\alpha}\right)
$$

$\lambda = \Delta t/\Delta x$ です。三つの係数の和はちょうど1で、$\lambda\alpha \le 1$ ならすべて非負です。つまり**凸結合**です。

$G$ は凸集合なので、結合に入る三項がすべて $G$ の中なら結果も $G$ の中です。問題は $\mathbf{U} \pm \mathbf{F}/\alpha$ が再び $G$ に入るかどうかですが、Perthame–Shuがこの条件は $\lambda\alpha \le 1/2$ で成り立つことを示しました。よく使われる「LFはCFL 0.5で正値性保存」という一文の出所がここです。

手元のフラックスは二つです。正確だが符号を守らない高次フラックス $\hat{\mathbf{F}}^{H}$、そして不正確だが符号を守る $\hat{\mathbf{F}}^{LF}$ です。[段差で勾配を切るTVDリミター](/ja/posts/2026-04-24-flux-limiter-tvd-advection/)は振動を殺します。こちらはセルが $G$ の外へ出ないように止めます。仕事が違います。

## 二つのフラックスを結ぶ線分の上でθを探す

Hu, Adams, Shu(2013)のアイデアは単純です。二つを混ぜる、ただし混ぜる比率を**面ごとに別々に**決めるのです。

$$
\hat{\mathbf{F}}_{i+1/2} = \hat{\mathbf{F}}^{LF}_{i+1/2} + \theta_{i+1/2}\left(\hat{\mathbf{F}}^{H}_{i+1/2} - \hat{\mathbf{F}}^{LF}_{i+1/2}\right), \qquad \theta_{i+1/2} \in [0, 1]
$$

$\theta = 1$ なら純粋な高次スキーム、$\theta = 0$ ならLFへ後退します。どんな $\theta$ を使ってもフラックス形式なので、**保存性は自動的に保たれます**。リミターが質量を作りも消しもしないという意味です。この点が、人工粘性を局所的に注ぎ込むやり方と決定的に違います。

$\Delta\mathbf{F}_{i+1/2} \equiv \hat{\mathbf{F}}^{H} - \hat{\mathbf{F}}^{LF}$ と書くと、更新式はこう分かれます。

$$
\mathbf{U}_i^{n+1} = \underbrace{\mathbf{U}_i^{LF}}_{\text{安全な基準点}} - \lambda\left(\theta_{i+1/2}\Delta\mathbf{F}_{i+1/2} - \theta_{i-1/2}\Delta\mathbf{F}_{i-1/2}\right)
$$

第一項はCFL条件さえ守れば $G$ の中にあることが保証されます。残りは、その安全な点から高次解のほうへ伸びる線分です。私たちがやることは、線分が $G$ を外れる直前で止まることだけです。

下限値は0ではなく、ごく小さい正の数 $\varepsilon$ に取ります。

$$
\varepsilon = \min\left(10^{-13},\ \min_j \rho_j^0,\ \min_j p_j^0\right)
$$

$\rho_j^0$、$p_j^0$ は初期状態の密度・圧力です。ちょうど0を狙うと、丸め一回でまた負になります。

## 予算を半分ずつ使う — 面一つがセル二つに触れる

密度は保存変数そのものなので、$\rho_i^{n+1}$ は $\theta$ について**1次関数**です。だから条件を代数的に解けます。

セル $i$ が持つ余裕を予算と呼びましょう。$b_i = \rho_i^{LF} - \varepsilon \ge 0$ です。面 $i+1/2$ で $\Delta F^\rho > 0$ なら、この面は左のセル $i$ の密度を削ります。逆なら右のセルを削ります。

ここに落とし穴が一つあります。内部セルは左右の二つの面から**同時に**削られます。各面が自分の削るセルの予算を全部使えると計算すると、二つの面がそれぞれは合法でありながら、合わせて予算の二倍を使ってしまいます。そこで各面には半分ずつだけ許します。

$$
\theta_{i+1/2} = \min\left(1,\ \frac{b_{\text{victim}} / 2}{\lambda\,|\Delta F^\rho_{i+1/2}|}\right)
$$

分母の $\lambda|\Delta F^\rho|$ が予算の半分を超えると、$\theta$ は1より下へ下がります。内部セルは左右の面から同時に削られます。半分を残しておかないと、面がそれぞれ合法でも合計は $2b_i$ まで出ます。その差は、冒頭のダイヤルでセル2のバーがすでに見せています。

## 圧力は密度の次に、そして二分法で

密度が片付いたら圧力を見ます。順序が重要です。$p$ を計算するには $\rho$ で割る必要があるので、$\rho > 0$ が先に確保されていなければなりません。

$p$ は $\mathbf{U}$ の非線形関数なので1次式では解けません。代わりに良い性質が一つあります。$p(\mathbf{U})$ は $G$ 上で**凹関数**(concave)です。$\mathbf{U}(\theta)$ が $\theta$ について線形なので $p(\theta)$ も凹です。凹関数の上位準位集合 $\{\theta : p(\theta) \ge \varepsilon\}$ は区間であり、$\theta = 0$(LF状態)ですでに条件を満たすので、その区間は0を含みます。

つまり根は一つだけです。二分法が安全に働きます。20〜40回で倍精度の限界まで絞り込めます。

一つ注意点があります。セル $i$ のために $\theta_{i\pm1/2}$ を下げると、隣のセル $i\pm1$ の計算が変わります。一度なぞって終わりにすると、まれに違反が残ります。違反セルが消えるまでスイープを繰り返す必要があります。$\theta \to 0$ ならLF状態へ収束するので、反復は必ず終わります。

$\varepsilon$ も初期値からそのまま出ます。$\rho^0=1$、$p^0=0.4$ なので $\varepsilon=\min(10^{-13},1,0.4)=10^{-13}$ です。二分法40回は区間 $[0,1]$ をその回数だけ半分に切ります。外側のスイープは最大20回です。一つのセルで $\theta$ を下げると、隣の圧力が再び $\varepsilon$ の下へ落ちることがあります。違反が消えるまで両側の面を一緒に削るのはそのためです。$\theta=0$ なら更新は $\mathbf{U}^{LF}$ そのものなので、ループは止まります。

## Pythonで蘇らせた二重希薄波

トイ問題は二重希薄波です。管の中央を境に左右が $\mp u_0$ で互いに離れていきます。中央に真空に近い穴が開き、その穴が高次スキームを殺します。

```python
import numpy as np

GAMMA = 1.4


def to_primitive(U):
    rho = U[0]
    u = U[1] / rho
    p = (GAMMA - 1.0) * (U[2] - 0.5 * rho * u * u)
    return rho, u, p


def euler_flux(U):
    rho, u, p = to_primitive(U)
    return np.array([rho * u, rho * u * u + p, (U[2] + p) * u])


def lf_face_flux(UL, UR, alpha):
    return 0.5 * (euler_flux(UL) + euler_flux(UR) - alpha * (UR - UL))


def density_theta(rho_lf, dF_rho, lam, eps_rho):
    """面ごとにthetaを決める。各面は自分が削るセルの予算を半分までしか使わない。"""
    n = rho_lf.size
    budget = np.maximum(rho_lf - eps_rho, 0.0)
    theta = np.ones(dF_rho.size)
    for f in range(1, n):                      # 内部の面のみ
        d = dF_rho[f]
        if d > 0.0:                            # 左のセルを削る
            cap = 0.5 * budget[f - 1] / (lam * d)
        elif d < 0.0:                          # 右のセルを削る
            cap = 0.5 * budget[f] / (lam * (-d))
        else:
            cap = 1.0
        theta[f] = min(1.0, cap)
    return theta


def pressure_at(U_lf, dFl, dFr, tl, tr, lam):
    U = U_lf - lam * (tr * dFr - tl * dFl)
    return to_primitive(U)[2]


def pressure_theta(U_lf, dF, theta, lam, eps_p):
    """p(theta)は凹なので安全区間は一つ。二分法で境界を探す。
    あるセルのthetaを下げると隣が影響を受けるので、違反がなくなるまで繰り返す。"""
    n = U_lf.shape[1]
    for _ in range(20):
        dirty = False
        for i in range(n):
            tl, tr = theta[i], theta[i + 1]
            if pressure_at(U_lf[:, i], dF[:, i], dF[:, i + 1], tl, tr, lam) >= eps_p:
                continue
            dirty = True
            lo, hi = 0.0, 1.0
            for _ in range(40):
                mid = 0.5 * (lo + hi)
                ok = pressure_at(U_lf[:, i], dF[:, i], dF[:, i + 1],
                                 tl * mid, tr * mid, lam) >= eps_p
                lo, hi = (mid, hi) if ok else (lo, mid)
            theta[i] *= lo
            theta[i + 1] *= lo
        if not dirty:
            return theta
    return theta
```

時間前進ループは毎ステップ二つのフラックスを作り、$\theta$ を求め、混ぜて更新します。

```python
def minmod(a, b):
    return np.where(a * b <= 0.0, 0.0, np.where(np.abs(a) < np.abs(b), a, b))


def face_states(U):
    """MUSCL-minmod再構成 -> 各面の左/右状態"""
    d = minmod(U[:, 1:-1] - U[:, :-2], U[:, 2:] - U[:, 1:-1])
    s = np.zeros_like(U)
    s[:, 1:-1] = d
    return U[:, :-1] + 0.5 * s[:, :-1], U[:, 1:] - 0.5 * s[:, 1:]


def march_double_rarefaction(n=200, cfl=0.45, u0=4.0, t_end=0.15, limiter=True):
    dx = 1.0 / n
    x = (np.arange(n) + 0.5) * dx
    rho = np.ones(n)
    u = np.where(x < 0.5, -u0, u0)
    p = np.full(n, 0.4)
    U = np.vstack([rho, rho * u, p / (GAMMA - 1.0) + 0.5 * rho * u * u])

    eps = min(1e-13, rho.min(), p.min())
    t, step, clipped, total = 0.0, 0, 0, 0

    while t < t_end:
        r, v, pr = to_primitive(U)
        if r.min() <= 0.0 or pr.min() <= 0.0:                 # 許容集合からの逸脱
            return dict(crashed=True, step=step,
                        rho_min=r.min(), p_min=pr.min())
        a = np.sqrt(GAMMA * pr / r)
        alpha = float(np.max(np.abs(v) + a))
        dt = min(cfl * dx / alpha, t_end - t)
        lam = dt / dx

        Ug = np.hstack([U[:, :1], U, U[:, -1:]])              # zero-gradient ghost
        UL, UR = face_states(Ug)
        Flow = np.zeros((3, n + 1))
        Fhigh = np.zeros((3, n + 1))
        for f in range(n + 1):
            Flow[:, f] = lf_face_flux(Ug[:, f], Ug[:, f + 1], alpha)
            Fhigh[:, f] = lf_face_flux(UL[:, f], UR[:, f], alpha)

        dF = Fhigh - Flow
        U_lf = U - lam * (Flow[:, 1:] - Flow[:, :-1])          # 安全な基準点

        if limiter:
            th = density_theta(U_lf[0], dF[0], lam, eps)
            th = pressure_theta(U_lf, dF, th, lam, eps)
            clipped += int(np.sum(th[1:n] < 1.0 - 1e-12))
            total += n - 1
        else:
            th = np.ones(n + 1)

        F = Flow + th * dF                                     # 混ぜたフラックス
        U = U - lam * (F[:, 1:] - F[:, :-1])
        t += dt
        step += 1

    r, _, pr = to_primitive(U)
    return dict(crashed=False, step=step, rho_min=float(r.min()),
                p_min=float(pr.min()), clipped=100.0 * clipped / max(total, 1))


for lim in (False, True):
    o = march_double_rarefaction(limiter=lim)
    tag = "limiter ON " if lim else "limiter OFF"
    if o["crashed"]:
        print(f"{tag}: crashed at step {o['step']}  "
              f"rho_min={o['rho_min']:.4f}  p_min={o['p_min']:+.4f}")
    else:
        print(f"{tag}: reached t=0.15 in {o['step']} steps  "
              f"rho_min={o['rho_min']:.3e}  p_min={o['p_min']:.3e}  "
              f"theta<1 on {o['clipped']:.3f}% of faces")
```


`u0` を3.5より上にすると、出力どおり2ステップで密度の最小値は0.3698、圧力の最小値は −0.1630 になります。`limiter ON` では $\theta$ のバーが数本だけ緑から下がり、$t=0.15$ まで300ステップを埋めます。

リミターなしでは二番目のステップで終わります。その瞬間の密度0.3698は危なく見えません。先に負へ落ちたのは圧力です。密度だけを監視するコードはこの事故を見逃します。

## θが1より小さくなった面は全体の何%か

測定値は0.027%です。内部の面はステップあたり $n-1=199$ 枚です。300ステップなら $199\times 300=59700$ 枚。その0.027%はおよそ16枚です。$u_0$ を8まで上げても割合は0.093%に留まります。

生き残った二つの最小値を割ると $5.140/9.560\approx 0.54$ です。初期の $p/\rho=0.4$ と同じ桁です。真空の穴は空っぽではありません。$\gamma=1.4$ を入れると $c=\sqrt{\gamma p/\rho}$ は1より小さいもののNaNではありません。時間刻みを殺す事故はここでは起きません。

リミターは事実上眠っています。真空が開く数個のセル、数個のステップでだけ目を覚まし、その面のフラックスをLF側へ少し引き寄せます。残り99.97%の面では、元の高次スキームがそのまま回ります。

CFL 0.45は $\lambda\alpha=0.45$ と読めます。更新の三つの係数は $1-\lambda\alpha=0.55$、両隣がそれぞれ $\lambda\alpha/2=0.225$ です。三つとも正で、和は1です。$\lambda\alpha=1/2$ の境界では自分の重みが0.5、隣が0.25ずつです。コードの0.45はその内側なので、LFの基準点 $\mathbf{U}^{LF}$ は $G$ の中に残ります。ここで $\theta$ を下げることに意味があります。

人工粘性を全域で上げて問題を覆い隠すやり方と比べれば違いは明確です。あちらは滑らかな領域の精度まで一緒に削ります。こちらは $\theta = 1$ が保たれる限り、元のスキームとビット単位で同一です。収束次数を測る格子収束試験でリミターが次数を落とさない理由がこれです。

## コードに入れる前に確認する三つ

最初に見るのはCFLの上限です。この手法全体が「$\mathbf{U}^{LF}$ は安全だ」という前提の上に立っています。LFの正値性保存は $\lambda\alpha \le 1/2$ でのみ成り立ちます。普段CFL 0.8で回しているコードなら基準点からすでに崩れているので、$\theta$ を0まで下げても生き返りません。リミターが効かないなら、ここからです。

SSP-RKは各ステージが前進Eulerの凸結合です。ステージ一つ一つが $G$ の中にあってこそ、最終結果も $G$ の中に入ります。最後に一度だけ検査すると、途中のステージですでに $\sqrt{}$ の中が負になった後です。$\varepsilon$ を0のまま二分法を回すと、最後の丸めで $-10^{-17}$ が出ます。初期最小値を基準にした小さい正の数を下限に敷きます。

## θを0に下げても、もう遅いCFL

基準点 $\mathbf{U}^{LF}$ がすでに $G$ の外なら、混合は死んだ状態と高次更新をつなぐだけです。$\lambda\alpha$ が1/2を超えたあとの $\theta$ は安全装置ではありません。リミターを入れる前に決めるのは、CFLを0.45のように境界の内側へ置くかどうかです。

介入する面は0.1%未満で、$\theta$ が何であっても更新はフラックス差分のままです。質量の総和は動きません。音速が定義できない段階では、[面法線方向の固有構造](/ja/posts/2026-06-03-euler-eigensystem-general-normal/)を使う前に計算は終わっています。符号を先に固定しないと、波動分解の入る場所がありません。
