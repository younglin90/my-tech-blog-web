## 板は前へ進むのに、底の流体は後ろへ進む

2枚の平板の間に流体があります。上板は右へ動き、下板は固定です。常識的には、流体はすべて右へ引きずられるはずです。ところが下流の圧力を少し上げると、底付近の流体が左へ流れ始めます。この記事では、その境目がなぜちょうど $P=-1$ なのかを示します。断面流量がゼロになる $P=-3$ も扱います。最後に有限体積法(FVM、セル平均値で保存則を解く離散化)で同じ結果を再現します。そして閾値の真上で格子が符号を反転させる落とし穴を、数値で確認します。

元ネタは学部の粘性流体力学の手書きノートです。クエット流れ(移動平板が引きずるせん断流)の横に「adverse pressure gradient」というメモがあります。その下の図には、底付近で後ろへ折れた速度の矢印が描かれています。境界層はく離を学ぶ前に出会う、いちばん単純なはく離のモデルです。

## 直線ひとつと放物線ひとつ

板の間隔を $h$、上板の速度を $U$ とします。流れが十分発達すると、速度は $y$ だけに依存します。このとき運動量方程式は、圧力勾配と粘性力のつり合いだけが残ります。

$$
\mu \frac{d^2 u}{dy^2} = \frac{dp}{dx}, \qquad u(0)=0,\quad u(h)=U
$$

$\mu$ は粘性係数、$dp/dx$ は流れ方向の圧力勾配です。この式は線形です。したがって解は2つの部分の和に分かれます。圧力勾配のないクエット解と、両板が静止したポアズイユ解(圧力差が押す放物線状の流れ)です。

$$
\frac{u}{U} = \frac{y}{h} + P\,\frac{y}{h}\left(1-\frac{y}{h}\right), \qquad P = -\frac{h^2}{2\mu U}\frac{dp}{dx}
$$

$P$ は無次元の圧力パラメータです。下流ほど圧力が下がる($dp/dx<0$)と $P>0$ で、順圧力勾配です。下流の圧力が高いと $P<0$ で、これが逆圧力勾配(adverse pressure gradient)です。放物線部分は[平板ポアズイユ流れの解析解](/ja/posts/2026-03-28-poiseuille-flow-analytical-solution/)と同じ形で、符号だけを $P$ が決めます。

スライダーで $P$ を0から−1、−3へ下げてみてください。緑の直線はそのままで、紫の放物線が左へふくらみます。合計の白い曲線が底で負になった瞬間、粒子が赤く変わり後ろへ流れます。

## P = −1:壁面せん断がゼロになる瞬間

固定壁のせん断応力は速度勾配に比例します。上の解を微分するとすぐに得られます。

$$
\tau_{\text{bottom}} = \mu \left.\frac{du}{dy}\right|_{0} = \frac{\mu U}{h}(1+P), \qquad \tau_{\text{top}} = \frac{\mu U}{h}(1-P)
$$

$\tau_{\text{bottom}}$ は下壁、$\tau_{\text{top}}$ は上板にかかるせん断です。$P=-1$ で下壁のせん断はちょうどゼロです。境界層理論ではく離点を定義する条件も、壁面せん断ゼロです。$P<-1$ なら壁近くの勾配は負です。つまり壁のすぐ上の流体が逆流します。

逆流層の厚さは $u=0$ となる高さで、$y/h\,(1+P-Py/h)=0$ から求まります。

$$
\frac{y_r}{h} = 1 + \frac{1}{P} \quad (P<-1)
$$

$P=-2$ なら下半分が逆流し、$P=-3$ なら下の2/3が逆流します。断面流量も計算しておきます。

$$
\frac{Q}{Uh} = \int_0^1 \frac{u}{U}\, d\!\left(\frac{y}{h}\right) = \frac{1}{2} + \frac{P}{6}
$$

$P=-3$ で流量はゼロです。上板は動き続けているのに、断面を通る正味の質量はありません。前へ進む上層と後ろへ進む下層がちょうど打ち消し合います。

なぜ底から先に反転するのでしょうか。逆圧力勾配は断面全体に同じ力をかけます。上板近くの流体は板が引き続けてくれます。底の流体は壁に捕まっていて、もともと遅いです。同じ逆向きの力を受けると、いちばん遅い層が先にゼロを越えます。[抗力危機と境界層はく離](/ja/posts/2026-06-09-drag-crisis-boundary-layer-separation/)で見たメカニズムと同じです。違いはひとつです。ここでは流れが平行なので、はく離泡が閉じません。逆流層が $x$ 方向に果てしなく続きます。

## コード:静止状態から定常状態まで時間発展

解析解があるので、コードは検証用です。静止した流体から出発し、非定常方程式を定常状態まで進めます。無次元形は $u_t = 2P + u_{yy}$ で、時間の単位は $h^2/\nu$ です。

- 格子:セル中心40個、$\Delta y = 1/40$。
- 壁条件:ゴーストセル(壁の外に置く仮想セル)で壁値を線形補間して合わせる。
- 時間:陽的オイラー、$\Delta t = 0.4\Delta y^2$(拡散の安定限界0.5未満)。
- 停止条件:1ステップの変化率 $\max|\Delta u|/\Delta t < 10^{-8}$。
- 測定:下壁の勾配(2次精度の式)、流量、負のセルの割合、解析解との最大誤差。

```python
def exact_profile(y, P):
    # u/U = y/h + P (y/h)(1 - y/h)
    return y + P * y * (1.0 - y)

def couette_poiseuille_march(P, N=40, tol=1e-8):
    # 無次元: u_t = 2P + u_yy, u(0)=0, u(1)=1, 静止状態から出発
    dy = 1.0 / N
    y = [(j + 0.5) * dy for j in range(N)]
    dt = 0.4 * dy * dy
    u = [0.0] * N
    steps = 0
    while True:
        ue = [-u[0]] + u + [2.0 - u[-1]]   # ghost: 下壁 u=0, 上壁 u=1
        dmax = 0.0
        for j in range(N):
            lap = (ue[j + 2] - 2.0 * ue[j + 1] + ue[j]) / (dy * dy)
            du = dt * (2.0 * P + lap)
            u[j] += du
            dmax = max(dmax, abs(du))
        steps += 1
        if dmax / dt < tol:
            break
    tau0 = (9.0 * u[0] - u[1]) / (3.0 * dy)      # 2次精度の壁勾配
    Q = sum(u) * dy
    back = sum(1 for v in u if v < 0) * dy
    err = max(abs(u[j] - exact_profile(y[j], P)) for j in range(N))
    return steps, steps * dt, tau0, Q, back, err

print(f"{'P':>5} {'steps':>6} {'t_ss':>6} {'tau_bot':>8} {'exact':>6} {'Q':>7} {'backflow':>8} {'max_err':>9}")
for P in [2.0, 0.0, -0.5, -1.0, -2.0, -3.0, -4.0]:
    s, t, tau, Q, b, e = couette_poiseuille_march(P)
    print(f"{P:5.1f} {s:6d} {t:6.3f} {tau:8.4f} {1 + P:6.2f} {Q:7.4f} {b:8.3f} {e:9.2e}")
```

## 出力を読む:8,000ステップ、0.675、そして−0.0167

**定常までの時間は $P$ にほぼ依存しません。** どのケースも $t_{ss}\approx 2$、約8,000ステップです。拡散のいちばん遅いモードは $e^{-\pi^2 t}$ で減衰します。残差を $10^{-8}$ まで下げるには $t \approx \ln(10^{9})/\pi^2 \approx 2$ が必要です。圧力勾配は最終的な形を変えるだけで、時間スケールは変えません。

**流量と逆流厚さは解析解と一致します。** $P=-3$ で $Q=-0.0006$ で、解析値0と格子誤差の範囲で等しいです。逆流割合0.675は解析値 $2/3$ にセル幅1つ以内で一致します。$P=-2$ の0.500、$P=-4$ の0.750も $1+1/P$ のとおりです。

**問題は $P=-1$ です。** 解析解は $u=y^2$ で、負の値はないはずです。ところがコードは壁勾配−0.0167と逆流セル1つ(0.025)を報告します。原因はゴーストセルです。線形補間は壁近くの曲率を取りこぼします。そのため全セルが $|P|\Delta y^2/4$ だけずれます。`max_err` 列がまさにその値です($P=2$ で $3.12\times10^{-4}$)。壁勾配の誤差も表から読めて、どの行でも $\tfrac{2}{3}P\Delta y$ です。$P=-1$ ではその誤差が−0.0167で、真値が0なので符号がそのまま反転します。

教訓は単純です。壁面せん断の符号ではく離を判定すると、閾値付近では格子誤差が判定を握ります。[同じコードが2つの収束次数を出した理由](/ja/posts/2026-10-07-sod-vortex-order-verification/)と同じ話です。測定量が何に敏感かを先に知る必要があります。この場合、壁境界処理の1次誤差が内部の2次精度を覆い隠しています。

## このプロファイルが実際に使われる場所

**潤滑理論。** ジャーナル軸受のすき間は、間隔が非常に小さいクエット・ポアズイユ流れです。レイノルズ潤滑方程式は、上の流量式 $Q = Uh/2 - (h^3/12\mu)\,dp/dx$ を質量保存に代入したものです。すき間が狭まる側で圧力がたまります。その圧力が逆圧力勾配として働き、流量を合わせます。

**壁関数とはく離判定。** 乱流モデルの壁関数は、壁近くをクエット流れのように扱います。逆圧力勾配が強いと、その仮定が崩れます。はく離直前の領域で壁関数が不正確になる理由はここにあります。

**コード検証。** この解は圧力勾配・移動壁・粘性項を一度に検査します。解析解が2次多項式なので、2次精度スキームなら内部誤差はゼロのはずです。残る誤差はほぼすべて境界処理から来ます。だから壁境界の実装を単独でテストするのに向いています。
