## 1993年、衝撃だったVolpeのグラフ

VolpeとGodfreyが同じ年に報告した内容は一文に要約できます — *遷音速向けに設計された標準Roeをそのままにして Mach 0.01に持っていくと、圧力場が非物理的に崩れる*。Godfreyは「前処理ヤコビアンに合わせた人工拡散」でグラフを救いました。その後AUSM、Zha–Bilgen、Roe–LM、Thornberなど数多くの変種が現れます。

**なぜ壊れるのか。** 無次元化したEulerの運動量方程式には、圧力勾配の前に $M^{-2}$ という係数があります。Machが小さくなるとこの項が暴走し、釣り合うために $p$ の摂動を $M^2$ オーダーに押し下げます。その階層を無視した人工拡散は、安定化するはずだった揺らぎ自体を平らに均してしまいます。

この論文の良さは、**離散化に依存しない**ことです。有限体積か有限差分か、中心か風上か、低Mach挙動を決めるのは「拡散行列の各成分が $M$ の何乗で入っているか」だけなのです。

## 3つの低Mach極限 — convective・acoustic・mixed

無次元化したエントロピー変数のEuler方程式に人工拡散を加えると次のようになります。

$$
\partial_t p + u\,\partial_x p + \gamma p\,\partial_x u = A_{11}\partial_{xx}p + A_{12}\partial_{xx}u
$$

$$
\rho\,\partial_t u + M^{-2}\,\partial_x p + \rho u\,\partial_x u = A_{21}\partial_{xx}p + A_{22}\partial_{xx}u
$$

ここで $p,u,\rho$ は圧力・速度・密度、$M$ は基準Mach数、$A_{ij}$ は人工拡散の係数行列です。右辺を0にすると元のEuler方程式。スケーリングを間違えると低Machで正しい答えが出ません。

各変数を $\psi = \psi^{(0)} + M\psi^{(1)} + M^2\psi^{(2)} + \dots$ と展開して $M$ のべきごとに整理すると、単一時間スケール解析は3つの極限を吐き出します。

- **Convective極限**: $\partial_x p^{(0)} = 0$, $\partial_x p^{(1)} = 0$。圧力変動は $O(M^2)$ のみ、発散は0 — 非圧縮の漸近。
- **Acoustic極限**: $\partial_\tau u^{(0)} + \partial_x p^{(1)}/\rho^{(0)} = 0$。線形音響波のみ。
- **Mixed極限**: 短い空間スケールの音波が長い空間スケールの対流の上に乗る多重スケール流。

3つの極限はそれぞれ異なる *圧力の階層* を強制します。人工拡散はその階層と自分自身を同時に合わせる必要があります。

## 拡散行列を3通りに設計する

Turkel(1969 → 1994)の手順は単純です。① $M\to 0$ で左辺($\mathcal{L}$)の最大項だけ残す。② 右辺($\mathcal{R}$)も同じ階数になるように $A_{ij}$ の $M$ のべきを取る。結果は3つの行列です。

$$
\underline{A}^{c} \sim \mathcal{O}\!\begin{pmatrix} M^{-2} & M^{0} \\ M^{-2} & M^{0} \end{pmatrix},\quad
\underline{A}^{a} \sim \mathcal{O}\!\begin{pmatrix} M^{-1} & M^{0} \\ M^{-2} & M^{-1} \end{pmatrix},\quad
\underline{A}^{m} \sim \mathcal{O}\!\begin{pmatrix} M^{-1} & M^{0} \\ M^{-2} & M^{0} \end{pmatrix}
$$

$\underline{A}^c$ は対流極限、$\underline{A}^a$ は音響極限、$\underline{A}^m$ はその混合処方です。要は対角の (1,1) と (2,2) の階層です。$A^c_{11} \sim M^{-2}$ は音響圧力 $p^{(1)}$ を過剰減衰させ、圧力方程式を放物型に落として波そのものを消してしまいます。$A^a_{22} \sim M^{-1}$ は対流速度 $u^{(0)}$ を滑らかにし、流れ自体を平らにします。Mixedはその2つの落とし穴のあいだの細い道です。

マスの大きさは上で既に $10^4$ と $10^2$ に分かれています。音速点の空白を埋める処置は [Roe 線形化にエントロピー修正を載せる場所](/ja/posts/2026-07-13-roe-approximate-riemann-solver-entropy-fix/) の方です。今日の平坦化はそちらの修正ではなく、(1,1) の $M$ の指数です。

## Pythonで見る音波の3つの運命

トイ問題は *孤立した1D音波* です。長さ1の周期領域に $p \propto \sin(2\pi x)$ を置き、1音響周期だけ進めます。比べるのは1つ — 1周期後にどれだけ振幅が残っているか。

```python
import numpy as np

GAMMA = 1.4

def lowmach_step(p, u, rho0, M, dx, dt, scaling="mixed"):
    """線形化Euler + 人工拡散 1ステップ。
    p: 圧力摂動、u: 速度、rho0: 基準密度、M: 基準Mach。
    scaling: 'convective' | 'acoustic' | 'mixed'  (Hope-Collins eq. 15/17/21)。
    """
    # 対角のみの人工拡散。漸近的な効果だけを比較するため Mのべき部分のみ残す。
    if scaling == "convective":
        a11, a22 = 1.0 / M**2, 1.0
    elif scaling == "acoustic":
        a11, a22 = 1.0 / M, 1.0 / M
    elif scaling == "mixed":
        a11, a22 = 1.0 / M, 1.0
    else:
        raise ValueError(scaling)

    lap_p = (np.roll(p, -1) - 2 * p + np.roll(p, 1)) / dx**2
    lap_u = (np.roll(u, -1) - 2 * u + np.roll(u, 1)) / dx**2
    dp_dx = (np.roll(p, -1) - np.roll(p, 1)) / (2 * dx)
    du_dx = (np.roll(u, -1) - np.roll(u, 1)) / (2 * dx)

    # 左辺はEuler、右辺は人工拡散(本質を見るため非対角は落とす)
    p_new = p + dt * (-GAMMA * du_dx + 0.5 * dx**2 * a11 * lap_p)
    u_new = u + dt * (-dp_dx / (rho0 * M**2) + 0.5 * dx**2 * a22 * lap_u)
    return p_new, u_new


def one_period_amplitude(M, scaling, N=128):
    """Mach Mで1音響周期後の最大圧力振幅を返す。"""
    x = np.linspace(0.0, 1.0, N, endpoint=False)
    dx = x[1] - x[0]
    # 音速 a = 1/M、1周期 T = L / a = M (無次元)
    a = 1.0 / M
    dt = 0.25 * dx / a  # 音響CFL
    n_steps = int(np.ceil(1.0 / a / dt))

    p = M * np.sin(2 * np.pi * x)  # 圧力摂動はO(M)
    u = M * np.sin(2 * np.pi * x)  # 前方進行波

    for _ in range(n_steps):
        p, u = lowmach_step(p, u, rho0=1.0, M=M, dx=dx, dt=dt, scaling=scaling)
    return float(np.max(p) / M)


for Mach in [1e-1, 1e-2, 1e-3]:
    row = [f"M={Mach:>6.0e}"]
    for s in ("convective", "acoustic", "mixed"):
        row.append(f"{s}:{one_period_amplitude(Mach, s):.3f}")
    print("  ".join(row))
```

```text
M= 1e-02  convective:0.018  acoustic:0.974  mixed:0.971
M= 1e-03  convective:0.000  acoustic:0.973  mixed:0.971
```

$M$ が $10^{-1}$ 付近では3本の曲線はほぼ重なります。しかし $10^{-2}$ を越えると赤(対流)の曲線は最初の1/4周期で潰れます。シアン(音響)と黄(混合)はMachによらずほぼ同じ振幅を保ちます。

表の3行をそのまま読みます。$M=10^{-1}$ では convective 0.832、acoustic 0.978、mixed 0.974。間隔は 0.15 を越えません。$M=10^{-2}$ では convective だけが 0.018 になり、acoustic は 0.974、mixed は 0.971 です。0.018 と 0.974 を並べると、1周期で対流スケールだけが振幅の大半を失います。$M=10^{-3}$ では convective は3桁出力で 0.000、acoustic 0.973、mixed 0.971。mixed と acoustic の差は 0.004、0.003、0.002 で、Mach が下がるほど狭くなります。

格子 $N=128$ なら $\Delta x=1/128$。音速 $a=1/M$、1周期は $T=M$、時間刻みは $0.25\,\Delta x/a$ です。$M$ は分子と分母から落ち、ステップ数は Mach に残りません。$1/(0.25\Delta x)=512$。三つの Mach が同じ 512 ステップを回します。差はステップ数ではなく $a_{11}$ です。convective は $1/M^2$ なので $M=10^{-2}$ で $10^4$。mixed と acoustic の $a_{11}$ は $1/M=10^2$。行列 (1,1) の100倍が減衰係数としてそのまま入ります。

初期圧力は $p=M\sin(2\pi x)$ なので摂動振幅そのものが $O(M)$ です。表は $\max(p)/M$、つまり $M$ で割った値です。0.018 はその正規化振幅が1周期後に 0.018 まで落ちたという意味で、0.000 は小数3桁から消えたという意味です。数学的に零だと証明されたわけではありません。$\gamma=1.4$ は左辺の圧力-速度結合にだけ入り、この線形テストの密度は $\rho_0=1$ で固定です。

## Mixedの影 — 格子モードとinf–sup

Mixedスキームも万能ではありません。論文6.1.2節の低Mach衝撃管 — 両側の圧力差が約 $0.03\%$ しかない接触波を挟んで2つの弱い衝撃が後退する — では、mixedフラックスのMach分布に*格子モード振動*が現れます。格子2セルおきに小刻みに揺れるのこぎり波。Acousticフラックスはきれいな単調解を返します。

原因は対角階層の*非対称性*です。Mixedの質量保存式は $A^m_{11}\partial_{xx}p \sim O(M^{-1})\cdot O(M)$ で有用な音響残留拡散を保ちますが、運動量保存式の $A^m_{22} \sim O(M^0)$ は $u^{(0)} \sim O(M)$ の音響速度摂動には弱すぎます。格子スケールの音響モードが減衰されずに残ってしまうのです。

さらに **inf–sup** という罠が乗ります。同位置格子では圧力-速度ペアが分離するチェッカーボードモードが起こります。Brezzi–Pitkärantaの安定化は連続式に微小な圧力拡散を入れて防ぐ。Rhie–Chowは面速度の段階で防ぐ。どちらの道を取っても、(1,1)成分の設計と整合する必要があります。

## この論文が触れていない限界

この論文には*階層*はあっても*定数*はありません。$A^a_{11} \sim O(M^{-1})$ という結果は、先頭定数を5にすべきか0.5にすべきかは答えてくれません。その定数はvon Neumann解析と数値実験で決めるしかない。適応的mixed処方(非定常Mach $M_u$ で(1,1)と(2,2)を補間する)も結局この定数選択の問題を引き継ぎます。

もう1つ。粘性項が抜けています。Hope–Collinsの本文解析はEulerに限られます。Navier–Stokesに行くと物理粘性が $O(M^0)$ 以上で対角成分に直接寄与するため、人工拡散+物理粘性の合計階層は別の解析が必要になります。続編Part II とDimarco(2017)が引き継ぐテーマです。

OpenFOAMの`reactingFoam`やSU2のRoe–LMオプションは本論文のmixed処方に相当します。実務で報告される格子モード振動の出所も、本論文が正確に診断しています。

## 対流スケーリングを音波に使うとき

$M=10^{-2}$ で convective の残幅は 0.018、mixed は 0.971 です。音波が解の一部なら convective 行列は使えません。定常で非圧縮に近く、音響を消してよいなら $A^c_{11}\sim M^{-2}$ の方が合います。表が分ける基準はその二つの数字です。

衝撃の近くに格子モードが見えるなら、mixed の (2,2) が $O(M^0)$ であることの跡です。そのときは acoustic 行列に替えるか、inf–sup 安定化を (1,1) と揃えます。音を時間積分から分ける道は [漸近保存 IMEX が音波を残すやり方](/ja/posts/2026-06-21-asymptotic-preserving-low-mach-wave/) です。圧力場だけでよいなら mixed で足ります。残幅 0.971 を守るなら convective は捨てます。
