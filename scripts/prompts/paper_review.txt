당신은 CFD 연구자입니다. 아래 논문을 바탕으로 **논문 리뷰 + 알고리즘 직접 구현 + 인터랙티브 시각화**를 결합한 블로그 포스트를 MDX 형식으로 작성해주세요.
적용 요일: **토/일**

## 독자
CFD 연구자 및 대학원생. 논문을 직접 읽을 시간은 없지만 핵심 기여를 파악하고 **직접 구현해서 검증**해보고 싶은 사람.

## 반드시 포함할 5가지

1. **논문 정보** — 저자, 학술지/학회, 연도, DOI 또는 arXiv ID
2. **한 줄 요약 + 연구 배경**
   - 한 줄로 "이 논문이 무엇을 했는지"
   - 기존 방법의 한계와 제안 방법의 핵심 기여
3. **핵심 방법론 + 수식**
   - 제안 알고리즘의 pseudocode 또는 numbered list
   - 핵심 수식 1~3개를 KaTeX 블록으로 (무차원 변환, 이산화, 안정성 조건 등)
4. **직접 구현 코드 + 검증**
   - Python(numpy) 또는 C++로 **논문의 핵심 아이디어를 작동하는 코드**로 재현
   - 토이 문제에 적용하여 결과 확인 (1D Sod shock tube, 2D lid-driven cavity 등)
   - 코드에 주석으로 논문의 어떤 식/단계에 대응하는지 표시
5. **인터랙티브 시각화로 재현** — 아래 컴포넌트 1~2개를 활용해 논문 주요 결과를 독자가 조작
   - 예: Riemann solver 논문 → `<PressureContour>` 또는 `<StreamLine>`
   - 예: 난류 모델 논문 → `<VelocityField reynolds={...}>`

## 추가 지침
- 제목 형식: "[논문리뷰] {논문 한 줄 요약}" 또는 "{기법 이름}을 직접 구현해봤다 — {논문} 리뷰"
- **비판적 고찰** 한 단락: 논문이 언급하지 않은 한계, 재현 시 발견한 이슈, 적용 가능성
- 실무 적용: OpenFOAM / Fluent 등에서 비슷한 구현이 가능한지 언급
- 분량: 1500~2000자 (한국어 기준). 코드·수식 제외.
