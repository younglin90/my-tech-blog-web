## 반드시 포함할 5가지

1. **논문 정보** — 저자, 학술지/학회, 연도, DOI 또는 arXiv ID
2. **한 줄 요약 + 연구 배경**
   - "이 논문이 무엇을 했는지" 한 줄
   - 기존 방법의 한계와 제안 방법의 핵심 기여
3. **핵심 방법론 + 수식** — pseudocode 또는 numbered list + 핵심 수식 1~3개 (KaTeX)
4. **직접 구현 코드 + 검증** — Python(numpy) 또는 C++로 논문의 핵심 아이디어를 **작동하는 코드**로 재현
   - 토이 문제에 적용해 결과 확인 (아래 "토이 문제 풀"에서 최근 안 쓴 것 선택)
   - 주석으로 논문의 어떤 식/단계에 대응하는지 명시
5. **인터랙티브 시각화로 재현 (1~2개 필수, 0개 = 실패)** — **원칙: 논문의 핵심 결과를 재현하는 custom React 컴포넌트를 즉석 작성한다.**
   - 파일 경로: `src/components/post-viz/{오늘 slug}/{ComponentName}.tsx`
   - 첫 줄 `'use client'`, 외부 라이브러리 금지, Canvas/SVG로 논문 figure 재현
   - 컴포넌트 이름은 논문 기법 + 전역 유일 (예: `APECEnergyFluxDemo`, `AUSMPlusUpLowMach`, `GRPGodunovSolver1D`)
   - 사용자가 직접 파라미터(CFL·격자·초기조건 등) 조작해 논문 수렴 결과 체험
   - **MDX frontmatter 바로 아래에 `import { ... } from '@/components/post-viz/{slug}/...'` 추가** → 본문에서 `<ComponentName />` 사용
   - pre-built 7개는 fallback. `{USED_VIZ_COMPONENTS}` 중복 회피 규칙 적용.

## 도입부 5종 템플릿 (최근에 쓰인 것은 피한다)

1. **한 줄 요약 + 왜 중요한가**: "Roe 플럭스의 엔트로피 위반은 ... 이 논문은 그걸 고쳤다."
2. **재구현 도전기**: "이 논문 재구현을 시작했다. 3시간 만에 발산했다..."
3. **기존 방법의 실패 사례**: "HLLC는 완벽해 보였다. 그런데 계면에서..."
4. **저자 인용 (원문 번역)**: "Luo et al.이 말했다: '고차 정확도의 진짜 비용은...'"
5. **비교 매트릭스 예고**: "Roe vs HLLC vs AUSM+ — 이 논문은 그 셋을 모두 뒤흔든다."
