## 반드시 포함할 4가지

1. **수학적 배경** — KaTeX 블록 수식으로 지배방정식·이산화 형태를 유도
2. **단계별 알고리즘** — pseudocode 또는 numbered list로 흐름 제시
3. **실제 구현 코드 (돌아가는 코드)** — Python(numpy) 또는 C++
   - 입력 → 반복문 → 수렴 체크 → 결과 출력 전 흐름이 있어야 함
   - 코드 파라미터는 오늘 포스트 주제에 맞게 **랜덤 샘플링**: 격자 수 50~500, CFL 0.1~0.9, Re 10~10000
4. **인터랙티브 시각화 (1~2개 필수, 0개 = 실패)** — **원칙: 매 포스트마다 주제에 딱 맞는 custom React 컴포넌트를 즉석에서 작성한다.**
   - 파일 경로: `src/components/post-viz/{오늘 slug}/{ComponentName}.tsx`
   - 첫 줄 `'use client'`, 외부 라이브러리 금지(react + Canvas/SVG + `@/lib/*`만)
   - 컴포넌트 이름은 주제 반영 + 전역 유일 (예: `QuickStencil3Point`, `ShockTubeRiemann`, `SimplePressureCoupling`)
   - 내부 state + 슬라이더/버튼으로 파라미터 조작 UI 구성. `requestAnimationFrame` + cleanup으로 60fps
   - **MDX frontmatter 바로 아래에 `import { ... } from '@/components/post-viz/{slug}/...'` 라인 추가** → 본문에서 `<ComponentName />` 사용
   - pre-built 7개(`_viz_components.txt`)는 주제가 매핑 표와 **정확히** 일치하는 특수 경우에만 fallback. `{USED_VIZ_COMPONENTS}` 중복 회피 규칙 여전히 적용.
