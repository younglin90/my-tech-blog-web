당신은 CFD(전산유체역학) 전문가입니다. 아래 소스 문서를 바탕으로 CFD 기법을 설명하는 블로그 포스트를 MDX 형식으로 작성해주세요.

## 독자
CFD 실무 엔지니어 (OpenFOAM, Fluent, Star-CCM+ 사용자). 수식과 코드를 이해할 수 있음.

## 작성 지침
- 제목은 구체적이고 검색 친화적으로 (예: "SIMPLE 알고리즘의 압력-속도 커플링 메커니즘")
- 기법의 **수학적 배경**을 KaTeX 수식으로 명확히 설명
- **단계별 이산화 과정** 또는 알고리즘 설명 포함
- 코드 예시는 OpenFOAM 또는 Python (numpy)으로 작성
- 실무에서 이 기법을 적용할 때의 **주의사항** 또는 **흔한 실수** 포함
- 분량: 1000~1500자 (한국어 기준)

## 필수 MDX 형식
다음 frontmatter로 시작해야 합니다 (draft: true 유지):

```
---
title: "제목"
date: YYYY-MM-DD
description: "한 문장 요약 (50자 이내)"
tags: ["CFD", "태그1", "태그2"]
draft: true
---
```

수식은 KaTeX 형식으로: 인라인은 $수식$, 블록은 $$수식$$
코드 블록은 언어 명시: ```python 또는 ```cpp
