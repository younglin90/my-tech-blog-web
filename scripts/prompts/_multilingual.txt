## 다국어 출력 (5개 locale 동시 작성)

이 포스트는 **5개 언어로 동시에 작성**한다. 각 언어 버전은 동일한 정보·수식·코드·post-viz 컴포넌트를 사용하되 본문 문장만 해당 언어로 자연스럽게 작성한다.

### 산출물 5개 파일 (모두 동일 slug)

1. `src/content/posts/ko/{DATE}-{slug}.mdx` (한국어, primary)
2. `src/content/posts/en/{DATE}-{slug}.mdx` (English)
3. `src/content/posts/ja/{DATE}-{slug}.mdx` (日本語)
4. `src/content/posts/zh/{DATE}-{slug}.mdx` (简体中文)
5. `src/content/posts/es/{DATE}-{slug}.mdx` (Español)

### 각 파일 frontmatter (locale 필드 필수)

```yaml
---
title: "(해당 언어로 자연스러운 제목)"
date: {DATE}
description: "(해당 언어 한 문장 요약, 50자/100자 이내)"
tags: ["CFD", ...]   # 태그는 모든 locale 공통(영문 slug 형태)
locale: ko           # ← 파일별로 ko / en / ja / zh / es
slug: {공통 영문 slug}
draft: false
---
```

### 본문 작성 규칙

- 수식/코드/post-viz import 구문은 **5개 파일 모두 동일** (수식은 언어 무관, 코드 주석만 해당 언어로 번역)
- post-viz 컴포넌트(`src/components/post-viz/{slug}/X.tsx`)는 **1번만 작성**, 모든 locale에서 같은 import 사용
- post-viz 내부 UI 문자열(슬라이더 라벨 등)은 **영어로 통일**하거나 prop으로 받도록 설계 (locale-agnostic)
- 본문 톤은 각 언어 모국어 화자에게 자연스럽게 — **직역 금지**. 비유·도입부 일화는 각 언어권 독자에게 친숙한 것으로 적절히 현지화 가능 (예: 한국어 도입부의 "박테리아는 꿀 속에서 헤엄친다"가 영어판에서는 "A bacterium swims as if through honey"로 직역할지 다른 비유로 갈지 자연스러움 우선).

### 번역 품질 지침

- 기술 용어는 **국제 표준**으로 통일 (Reynolds = 雷诺 = レイノルズ = Reynolds)
- 한국어 원본의 길이가 1,500단어이면 다른 언어도 ±20% 범위로 유지
- 중국어는 **간체(zh-CN)** 사용
- 스페인어는 **중립 스페인어(LATAM 시장 고려)**, 격식체(usted) 대신 비인칭 활용. tú는 가급적 피한다
- 일본어는 **です/ます 체** (기술 블로그 톤)
- 영어는 **미국 표기**(color, behavior) 통일

### 자체 검증 (각 locale 파일마다)

기존 7.5단계의 검증을 **5개 파일 모두에 동일하게 적용**한다:
- viz import 구문 존재
- 도입부 첫 문장이 해당 언어의 클리셰로 시작 안 함
  - 영어: "It is essential to...", "Let us examine...", "It is well-known that..."
  - 일본어: "〜は不可欠である", "〜について見てみよう"
  - 중국어: "...是必不可少的", "让我们来看看..."
  - 스페인어: "Es esencial...", "Vamos a ver..."
- 섹션 헤딩 4개 이상 겹치지 않음 (locale 무관, 동일 포스트의 5개 파일은 같은 섹션 구조 유지가 정상)

### git 커밋 (한 커밋으로 5개 locale 전부)

```bash
git add \
  src/content/posts/{ko,en,ja,zh,es}/{DATE}-{slug}.mdx \
  src/components/post-viz/{DATE}-{slug}/ \
  source-docs/index.yaml
git commit -m "post: {요일-전체} 자동 생성 [5 locales] - {ko 제목}"
git push origin main
```
