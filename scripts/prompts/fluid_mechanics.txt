## 반드시 포함할 4가지

1. **흥미로운 유동 현상 (실제 사례로 시작)** — 최근에 안 다룬 현상 선택. 아래 "현상 풀"에서 1개 이상 선택.
2. **물리적 배경 + 지배 방정식** — KaTeX 블록 수식으로 유도
   - Navier–Stokes, Bernoulli, 경계층, 와도, 연속방정식, 열방정식, 상태방정식 등
   - 무차원화의 의미를 강조하되 **Reynolds만 쓰지 말 것**. 주제에 맞는 다른 무차원수도 함께 소개.
3. **인터랙티브 시각화 (1~2개 필수, 0개 = 실패)** — **원칙: 매 포스트마다 현상에 딱 맞는 custom React 컴포넌트를 즉석 작성한다.**
   - 파일 경로: `src/components/post-viz/{오늘 slug}/{ComponentName}.tsx`
   - 첫 줄 `'use client'`, 외부 라이브러리 금지, Canvas/SVG로 현상 시뮬레이션
   - 컴포넌트 이름은 현상 반영 + 전역 유일 (예: `RayleighBenardCells`, `TaylorCouetteRings`, `SoapFilmInterference`, `CoandaJetPlayground`)
   - 슬라이더/버튼으로 파라미터(속도·점성·온도차 등) 조작 UI 구성. 애니메이션은 `requestAnimationFrame` 사용
   - **MDX frontmatter 바로 아래에 `import { ... } from '@/components/post-viz/{slug}/...'` 추가** → 본문에서 `<ComponentName />` 사용
   - pre-built 7개는 주제가 매핑 표와 **정확히** 일치하는 경우에만 fallback. `{USED_VIZ_COMPONENTS}` 중복 회피 규칙 적용.
4. **직관 구축** — "이 현상의 본질은 ~다" 한 줄 + 기억에 남는 비유/그림 설명

## 현상 풀 (최근에 안 다룬 것 우선 선택)

`{RECENT_POSTS}` 확인 후 중복되지 않는 주제:

- Tollmien–Schlichting wave (경계층 천이의 시작)
- Stokes' 제2법칙 (진동 평판 경계층)
- Rayleigh–Bénard 대류 (열 불안정성)
- Taylor–Couette 흐름 (회전 원통 사이)
- Marangoni 효과 (표면장력 구배)
- Faraday 파동 (진동하는 용기의 표면파)
- Soap film flow (2D 유체 실험)
- Worthington jet (물방울 떨어질 때 솟구치는 제트)
- Bubble rising in viscous fluid (Stokes drag)
- Saffman–Taylor instability (Hele-Shaw 셀 핑거링)
- Vortex ring (반지 모양 와류)
- Horseshoe vortex (장애물 앞 말굽 와류)
- Boundary layer separation with suction/blowing
- Secondary flow in curved pipe (Dean 와류)
- Coanda effect (벽을 따라 흐르는 제트)
- Coffee ring effect (증발 수송)
- Air entrainment by waterfall
- Granular flow vs fluid flow (모래-유체 유비)
