# 다국어(i18n) 시스템

5개 locale `ko / en / ja / zh / es`. URL은 `/{locale}/...`.
**포스트를 5 locale로 쓰는 규칙은 `.claude/rules/daily-post.md`에 있다 — 여기 중복 기재하지 않는다.**

## 라우팅
`/` → `functions/_middleware.ts`가 cookie > Accept-Language > cf-ipcountry 순으로 redirect.
`/{locale}/{posts|tags|about|bookmarks}/...`. `/admin`·`/preview/{slug}`·`/read?id=`는 locale 무관(관리자 전용).

## Fallback
해당 locale에 slug 파일이 없으면 ko 원문 + 안내 배너.
구현: `src/app/[locale]/posts/[slug]/page.tsx`의 `findPost(loc, slug)`.
자동 포스트가 5 locale 동시 작성을 지키면 배너는 나타나지 않는다.

## UI 사전
`src/i18n/{locale}.json`에 키 등록 → `t(locale, 'nav.posts')`.
새 UI 문자열은 **5개 사전 모두에** 추가해야 한다.
헤더 LanguageSwitcher가 `locale` 쿠키(1년)에 저장.

## 배포 산출물
`sitemap.xml`(5 locale × 전 페이지) · `feed-{locale}.{xml,json}` · `feed.xml`(ko, 역호환) ·
`opengraph-image.tsx`(locale 라벨 포함 5종).

## 기존 포스트 일괄 번역
`node scripts/translate-existing-posts.mjs [--dry-run|--only en|--slug X|--force]`
(Anthropic API 사용, 모델은 `ANTHROPIC_MODEL`. 수식·코드·import 유지, 주석만 번역.)
